# 에르덴 외곽 가족 생애 정본

외곽 정착지는 고정 인원 배치가 아니라 세대를 이어가는 실제 가구 단위로 취급한다.

## 현재 정본

- 초기 `adult_head + adult_partner`는 같은 실제 주택을 공유하는 창립 부부로 영구 저장한다.
- 배우자 한쪽이 사망하면 해당 혼인은 종료되며, 최소 1년의 대기 기간 뒤 재혼 후보가 될 수 있다.
- 새 혼인은 직계 부모·자식과 같은 부모를 둔 형제자매를 후보에서 제외한다.
- 서로 다른 창립 가구의 창립 주민끼리는 결혼으로 원래 노동·거주 배치를 깨지 않는다.
- 창립 주민과 후손이 결혼하면 후손만 창립 주민의 실제 주택으로 이동한다.
- 후손끼리 결혼하면 수용 인원이 남은 배우자 가구를 선택해 한 명이 실제 거주 가구를 옮긴다.
- 결혼에 따른 거주 이동은 `householdId`만 바꾸고 기존 작업장 `nodeId`는 유지한다. 결혼이 직업을 자동 변경하지 않는다.
- 주택 최대 수용 인원 5명을 넘는 결혼 이주는 허용하지 않는다.
- 실제 플레이의 출생은 같은 가구에 거주하는 활성 혼인 관계의 배우자 두 명이 모두 20~44세이고 생존·비은퇴 상태일 때만 부모 후보가 된다.
- 기존 장기 CI 미래투영은 회귀 비교를 위해 비영구 계산만 종전 부모 후보 규칙을 유지한다.

## 다음 단계

가족관계 정본 위에 독립 분가·지역 간 이주, 세입자/임대료, 공실 주택 재점유를 연결한다. 이 단계에서는 소유 가구와 거주 가구를 구분해 상속과 임대가 서로 덮어쓰지 않도록 한다.

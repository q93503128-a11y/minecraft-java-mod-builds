# Living Kingdoms — Next Playable Test Gate

이 문서는 다음 테스트 JAR을 사용자에게 전달하기 전에 반드시 충족해야 하는 최소 플레이 가능 조건이다.

## 목표

기능을 넓고 얕게 많이 넣지 않는다. 새 월드에서 첫 10~20분 동안 판타지 세계 RPG의 정체성과 선택의 의미가 실제 플레이로 느껴지는 작은 수직 구간을 완성한다.

## 필수 통과 조건

### 1. 별도 설정 없는 시작

- 사용자는 일반적인 새 월드 생성 절차만 거친다.
- 데이터팩, 월드 유형, 게임 규칙을 수동으로 설정할 필요가 없다.
- 첫 접속 시 일반 바닐라 스폰에서 자유 행동이 시작되지 않는다.

### 2. 캐릭터 생성 화면

- 첫 접속 플레이어에게 전용 전체 화면 UI가 자동으로 열린다.
- 최소 선택 항목:
  - 종족
  - 출신 세력
  - 사회적 배경
  - 시작 거주지
- 선택 전에는 이동·전투·아이템 투기 등 정상 플레이를 시작할 수 없다.
- 각 선택에는 짧고 명확한 설명과 실제 시작 효과가 표시된다.
- 선택 결과는 서버 권한형으로 검증하고 플레이어별로 영구 저장한다.
- 재접속 시 완료된 캐릭터 생성창이 다시 강제로 열리지 않는다.

### 3. 테스트용 선택 범위

첫 테스트에서는 모든 설정을 한꺼번에 넣지 않는다.

- 종족 3종: 인간, 엘프, 드워프
- 출신 지역 3곳: 인간 변경 생활권, 엘프 삼림 거주지, 드워프 산악 정착지
- 배경 4종: 평범한 주민, 낚시꾼 집안, 방랑자, 학문 수련생
- 각 출신 지역마다 최소 2개의 시작 거주지

데이터 구조는 향후 종족과 국가를 추가할 수 있게 일반화하되, 테스트 화면에는 검증된 항목만 노출한다.

### 4. 전용 판타지 시작 지역

- 주변 바닐라 지형을 검색한 뒤 왕국을 얹는 방식을 사용하지 않는다.
- 테스트 구역은 Living Kingdoms가 소유하는 전용 판타지 지형과 구조 배치 규칙으로 생성한다.
- 대륙 전체는 아직 만들지 않되, 시작 지역 경계 안에서는 바닐라 마을처럼 보이지 않아야 한다.
- 최소 구성:
  - 판타지형 지형 실루엣
  - 중심 정착지
  - 주거 구역
  - 시장 또는 공동 공간
  - 외곽 숲·강·광산 중 지역에 맞는 생활 구역
  - 도로와 지역 표식
- 모든 시작·건축 좌표는 생성이 완료된 지표면을 기준으로 계산한다.
- 월드 최저 높이, 동굴, 수중, 절벽 내부, 기반암층에는 정착지를 만들지 않는다.

### 5. 선택에 따른 실제 시작

- 인간 주민: 변경 마을 주거지
- 인간 낚시꾼: 강변 또는 호숫가 집
- 엘프: 삼림 수관 또는 숲 정착지
- 드워프: 산악 입구 또는 지하도시 상층
- 방랑자: 도시 내부가 아닌 안전한 길가 야영지
- 학문 수련생: 서고·연구소·길드 근처 숙소

선택마다 위치만 바꾸지 않고 시작 물품, 지역 평판, 기본 지식 또는 관계가 달라져야 한다.

### 6. 첫 플레이 루프

테스트판에는 최소 다음이 실제로 가능해야 한다.

1. 캐릭터 생성 완료
2. 선택한 거주지에서 안전하게 시작
3. 주변 NPC 3명 이상과 대화
4. 자신의 거주지 또는 침상 확인
5. 지역에 맞는 생활 활동 1개 수행
6. 작은 부탁 또는 작업 1개 완료
7. 돈·평판·생활 숙련 중 최소 하나 획득
8. 저장 후 재접속해 상태 유지 확인

### 7. 기본 NPC

- NPC는 표지판 역할만 하지 않는다.
- 최소 역할: 거주민, 생활 직업인, 지역 안내자 또는 관리인
- 이름, 역할, 소속, 짧은 일정, 기본 대사를 가진다.
- 밤낮 전체 사회 시뮬레이션은 다음 단계로 미루되, 같은 자리에 영구 정지한 상점 껍데기로 만들지 않는다.

### 8. 디자인 최소 기준

- 캐릭터 생성창은 기본 회색 Minecraft 버튼 나열로 제출하지 않는다.
- 양피지·가문 문장·지역 상징을 사용한 한 화면 중심 구성으로 만든다.
- 장식 때문에 글자가 작아지거나 선택 결과가 불명확해지면 안 된다.
- 닫기 버튼으로 캐릭터 생성을 우회할 수 없다.
- 인게임 HUD 전체 개편과 고급 셰이더 통합은 이번 테스트 범위에서 제외한다.
- 셰이더 없이도 지형, 건축, 안개, 색감과 조명 배치로 판타지 분위기가 보여야 한다.

## 이번 테스트에서 제외

- 대륙 전체 생성
- 9개 왕국 전부
- 대규모 전쟁과 정치
- 왕·영주 플레이 완성
- 복잡한 경제 시뮬레이션
- 수십 종족
- 대형 던전과 최종 보스
- 완전한 과학·공학 연구 트리
- 고급 셰이더 번들

이 기능들은 첫 수직 구간의 저장 구조와 세계 규칙이 안정된 뒤 확장한다.

## 검증 계약

테스트 JAR 전달 전 최소한 다음을 수행한다.

- Java 25 `clean build`
- JAR 내부 검사
- 전용 서버 최소 부팅
- 가능하면 클라이언트 월드 진입
- 새 캐릭터 생성 완료
- 세 가지 출신 지역 중 최소 하나의 실제 스폰
- 지표 높이와 안전 스폰 검사
- 저장 후 재접속
- 멀티플레이 플레이어별 프로필 분리 정적 또는 런타임 검사

실행하지 않은 항목은 명시하며, 이 문서의 핵심 플레이 흐름이 구현되지 않은 JAR을 플레이 테스트판이라고 부르지 않는다.

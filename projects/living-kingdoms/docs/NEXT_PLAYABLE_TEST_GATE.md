# Living Kingdoms — 다음 에르덴 플레이 테스트 Gate

이 문서는 다음 테스트 JAR을 전달하기 전에 반드시 충족해야 하는 현재 정본이다.

과거 문서에 있던 인간·엘프·드워프 3종, 에르덴·실바나·카르둠 3지역, 다중 시작 배경 요구는 **폐기된 선행 프로토타입 범위**다. 현재는 에르덴 왕국을 먼저 완성한다.

## 1. 별도 설정 없는 시작

- 일반 새 월드 생성 후 추가 데이터팩·월드 타입·게임 규칙 설정이 필요 없어야 한다.
- 첫 접속에서 바닐라 스폰 자유행동을 시작하지 않는다.
- origin 등록이 끝나기 전 이동·전투 등 정상 플레이를 우회하지 못한다.

## 2. 에르덴 시민등록

현재 노출되는 값은 정확히 다음 하나씩이다.

- 종족: 인간
- 국가: 에르덴 왕국
- 신분: 평범한 주민
- 거주지: 왕도 시민구 임대방

화면은 가짜 선택지를 반복해서 누르게 하지 않고 네 항목을 고정 시민기록으로 보여준다.

- `에르덴에서 삶을 시작하기` 버튼으로 한 번 확정
- ESC 우회 금지
- 서버 권위 ID 검증
- 플레이어별 영구 저장
- 재접속 시 이미 완료한 등록창 재강제 금지
- 비활성 종족/국가/배경/거주지 ID 제출 거부

## 3. 전용 판타지 세계

- Living Realm 전용 지형/구조 규칙 사용
- 바닐라 마을·전초기지 등 부적절한 구조 생성 차단
- 1블록=1m 거리 규칙 유지
- 미완성 수도 건설 과정을 플레이어에게 노출하지 않음
- 서버 진행률과 연결된 로딩 화면 유지

현재 최소 검증 대상:

- 에르덴 왕도 2.4×1.8km 성벽권
- 233개 시가지 필지와 출입 가능한 내부
- 왕궁 Citadel
- 왕도 주민·경제·운송·법/치안
- 지역 정착지 6곳
- 지역 주민 144명
- 시장·행정·경비·공동체 생활
- 국도 8회랑 / 역참 4곳
- 에르덴 전용 생태 초기 종

## 4. 첫 플레이 규칙

`ERDEN_GAMEPLAY_RULES_LOCK.md`를 따른다.

필수:

- 개인 2×2 crafting 우회 차단
- 바닐라 생산 workstation/menu 우회 차단
- 침대로 밤 즉시 건너뛰기 금지
- 침대/명령 기반 개인 부활 체크포인트 금지
- 치명 피해는 전투불능 구조로 전환
- 소지품 보존
- 구조·치료비 최대 은화 8
- 개인 회복 페널티 동안 공유 세계 시계는 정상 진행
- 최초 입국/제도적 구조를 제외한 무료 순간이동을 일반 교통으로 사용하지 않음

## 5. 치안·위험 구역

왕도와 지역 마을이 야생과 똑같이 밤마다 랜덤 적대몹 생성장이 되어서는 안 된다.

- 왕도 성벽권 + 32m buffer: ambient hostile spawn 금지
- 지역 정착지 6곳의 220m 생활권: ambient hostile spawn 금지
- 국도: 위험 유지, 실제 경비와 역참이 위험을 줄임
- 야생: 위험 유지
- scripted/command/spawner 기반 의도된 사건은 ambient spawn 필터가 자동 삭제하지 않음

## 6. 주민과 경제 우회 방지

- 이름 있는 관리 NPC는 바닐라 주민 trade UI를 열지 않음
- 공방/길드/시장/계약이 생산과 거래의 권위 경로
- 야생 채집·전리품 자체는 허용 가능
- 그러나 일반 아이템이 자동으로 왕국 은화·공식 생산량으로 변환되지 않음
- 플레이어 소유지 건축과 합법 자동 생산은 별도 소유권/사업체 단계에서 추가

## 7. 멀티플레이

공유:

- 세계와 시간
- 주민/NPC
- 시장과 재고
- 행정·치안·법
- 물류
- 공공 건축

플레이어별:

- origin profile
- 은화/명망/직업
- 숙련
- 개인 범죄 기록
- 향후 개인 재산/계약

한 플레이어의 수면·패배 때문에 다른 플레이어의 세계 시간을 순간 이동시키면 실패다.

## 8. 실제 플레이 확인 항목

다음 테스트에서는 최소한 직접 확인한다.

1. 새 월드 → 시민등록 화면 자동 진입
2. 에르덴 단일 origin 표시
3. 등록 완료 후 안전한 시민구 입국
4. 왕도 건설 완료 상태만 노출
5. 주요 시민과 상호작용
6. 바닐라 주민 거래창 미노출
7. 개인 crafting/workstation 우회 불가
8. 침대 night skip 불가
9. 침대 respawn checkpoint 우회 불가
10. 왕도에서 자연 적대몹 생성 억제
11. 지역 마을에서 자연 적대몹 생성 억제
12. 국도/야생에서는 위험이 남음
13. 치명 피해 → death screen 대신 구조, 비용/상태 이상 적용, 아이템 보존
14. 은화·명망·숙련 저장
15. 저장 후 재접속 상태 유지
16. 멀티플레이 두 플레이어의 개인 기록 분리

## 9. 자동 검증 계약

테스트 JAR 전달 전 최소:

- Java 25 `clean build`
- licensed asset audit
- fresh dedicated server complete Erden audit
- `LK_ERDEN_GAMEPLAY_RULES_LOCK` marker
- 기존 왕도/지역/Community/Governance/Citadel 회귀 marker
- graphical client startup/UI audit
- JAR 압축 무결성
- 중복 entry 0
- 필수 gameplay rules class 존재
- canonical main build 성공

자동검사가 녹색이어도 에르덴 왕국 전체가 완성됐다고 선언하지 않는다. 실제 완성 기준은 `ERDEN_KINGDOM_WORLD_BIBLE.md`의 국가 규모·시장도시·촌락·생산·법·생태·수운·지도·UI 조건이다.

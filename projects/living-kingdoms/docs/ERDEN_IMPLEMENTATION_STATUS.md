# 에르덴 왕국 구현 상태

이 문서는 사용자 배포용 패치 노트가 아니라 왕국 완성도를 판단하기 위한 내부 구현 기준이다.

## 현재 구현된 기반

- 1블록 = 1미터의 48km × 40km 에르덴 고정 국토
- 2.4km × 1.8km 왕도 성벽 내부 경계
- Living Realm 전용 구조물 비활성 노이즈 생성기
- 바닐라 마을, 전초기지, 사원, 폐허 포털 등 레지스트리 구조물 시작 차단
- 청크가 열릴 때 16m × 16m 단위로 왕도를 조립하는 스트리밍 건설
- 플레이어가 바라보는 청크를 우선 처리하는 가시 구역 우선 건설 대기열
- 실제 지표를 따라가는 왕실대로, 간선도로, 내부 순환로, 생활 골목
- CC BY 4.0 외부 성채에서 추출한 성벽, 탑, 문루 파츠
- 은빛강의 흐름을 막지 않는 북·남 성벽 수문 공간
- CC BY 4.0 외부 건물 4종을 기능에 맞춰 배치한 16개 구역 랜드마크
- 같은 외부 건축 계열을 방향과 구역에 맞춰 분산한 24개 주거 블록 앵커
- 외부 건축물의 실제 최저층 출입구를 기준으로 외벽·실내 구간을 잘라 만든 소형 건축 파츠
- 원본 지형판 제거 뒤 문이 파츠 외곽 5블록 안에 없더라도 가상 입구 대신 실제 최저층 문을 유지하는 출입구 선택
- 잘린 단면을 원본 건물의 주 외벽 재료로 봉합하고 계단·문·울타리 등 블록 상태를 보존하는 파츠 조립
- 왕도 여섯 생활권의 빈 필지를 채우는 1차 연속 시가지 생성
- 연립주택 77곳, 상점 50곳, 여관 31곳, 제빵소 21곳, 마구간 17곳, 창고 15곳, 경비초소 12곳, 목욕시설 10곳으로 구성된 233개 시가지 필지 계획
- 성채·랜드마크·대형 주거 앵커·도로·우물·저수조를 침범하지 않는 필지 검증
- 각 소형 건물 출입구가 가장 가까운 생활 골목을 향하도록 회전하고 3m 폭 연결로 생성
- 시가지 청크의 외벽 조립이 끝난 뒤 완성된 월드에서 실제 문 블록과 바닥 높이, 도로 반대쪽 실내 방향을 다시 탐색하는 내부 후처리
- 출입문 뒤에 폭 7m, 깊이 9m, 유효 높이 4m의 소형 1층 기능 공간과 막히지 않는 중앙 통로를 조립하는 스트리밍 내부 생성
- 연립주택의 침대·수납, 상점의 진열대·창고, 제빵소의 화로·훈연기·작업대, 여관의 침대·탁자, 마구간의 칸막이·건초·급수, 경비초소의 철창·모루·훈련 표적, 목욕시설의 수조·급수, 창고의 다단 통 적재 설비
- 건물당 내부 완료 상태와 내부 리비전을 월드 저장 데이터에 기록해 이미 처리된 건물을 반복 훼손하지 않는 호환 처리
- 서버 부하를 줄이기 위해 한 틱에 최대 두 건물만 내부를 완성하고 아직 열리지 않은 시가지에는 해당 청크가 생성될 때 지연 적용하는 방식
- 내부 완성 직후 실제 출입문 보존, 입구 중앙 통로 3m 이상 확보, 역할별 핵심 설비 존재를 검사하는 런타임 검증
- 새 월드에서 제빵소 표본의 실제 문·통로·기능 설비를 확인한 내부 진단 경로
- 1층 바닥보다 5m 높은 위치에 실제 계단실과 4단 계단, 착지 공간, 3m 높이 보행 공간을 갖춘 상층 내부 후처리
- 연립주택 침실, 여관 객실, 상점·제빵소 주인방, 마구간 건초 다락, 경비 숙소, 목욕시설 탈의 공간, 창고 적재 다락의 8개 상층 역할 공간
- 상층 완료 출입구와 상층 리비전을 별도 월드 저장 데이터에 기록해 이미 완성된 건물을 반복 개조하지 않는 처리
- 기록관 마렌, 어업조합원 로안, 석공 엘라, 시장서기 페른, 철공조합장 하벨, 약제사 미라, 성문부사관 토렌, 마차조합원 베아에게 중복 없는 주택과 직종별 작업장을 배정하는 저장 구조
- 주요 시민이 낮에는 작업장, 저녁과 밤에는 상층 주거 공간으로 이동하도록 요청하는 로드 구역 한정 생활 동선
- 새 월드에서 제빵소의 4단 계단, 상층 착지 공간, 역할 설비, 빈 중앙 통로와 주요 시민 8명의 집·직장 배정을 확인한 런타임 진단
- 77개 연립주택마다 고유 가문과 주택 소유권을 배정한 왕도 가구 명부
- 가구당 성인 노동자 2명과 아이 또는 노인 1명으로 구성된 77가구·231명 인구 계획
- 성인 노동자 154명을 서로 겹치지 않는 154개 작업장에 배정하고, 향후 이주·고용에 사용할 공석 2곳을 유지하는 직장 계획
- 제빵소·마구간·창고의 이른 교대, 상점·목욕시설의 주간·늦은 교대, 여관·경비초소의 야간 교대를 포함한 직종별 근무 시간
- 가구·주민·생애 단계·침상 슬롯·직장·교대 시간·사망 상태를 별도 월드 저장 데이터에 기록하는 인구 스키마
- 플레이어가 머무는 로드 생활권에서만 주민을 한 번에 최대 두 명씩 실체화하고, 전체 231명을 상시 엔티티로 유지하지 않는 성능 보호
- 로드된 집과 직장 사이에서 순간이동 없이 길찾기로 출퇴근하고, 언로드 구역을 억지로 불러오지 않는 주민 동선
- 주민 사망 시 명부에 영구 기록하고 이후 재생성·생산·소비 계산에서 제외하는 처리
- 주민 상호작용 시 가문, 직업, 교대 근무 또는 아이·노인 역할을 자연스러운 한국어로 설명하는 대화
- 제빵소·여관의 식량, 상점의 생활품, 마구간의 운송력, 경비초소의 치안력, 목욕시설의 위생력, 창고의 물류력을 일일 생산량으로 집계하는 왕도 장부
- 살아 있는 주민과 가구 수에 따라 식량·생활품·위생·치안·물류·운송을 소비하고 재고와 누적 부족분을 저장하는 일일 경제 집계
- 장기간 월드를 닫았을 때 최대 30일까지만 밀린 장부를 정산해 시작 지연을 제한하는 처리
- 연립주택을 제외한 156개 작업장마다 원료·완제품·현금·수령량·출고량·판매량·임금 지급액을 저장하는 물리 경제 스키마
- 77개 가구마다 보유 화폐·누적 소득·누적 지출을 별도 저장하고 성인 노동자의 일일 임금을 해당 가구 지갑에 지급하는 처리
- 창고 15곳에 밀·석탄·가죽·종이·철·건초를 입고하고 가장 가까운 생산·서비스 시설에 필요한 원료만 배송하는 작업장 공급망
- 제빵소가 밀과 석탄을 소비해 빵을 만들고, 상점이 가죽과 종이를 소비해 생활품을 만드는 실제 원료·완제품 변환
- 상점과 여관에 빵을 배송하고 마구간·경비초소·목욕시설이 건초·철·석탄을 소비해 운송·치안·위생 서비스를 생산하는 처리
- 모든 생존 가구가 보유 화폐로 빵과 생활품 구매를 시도하고 성공·휴무·품절·구매력 부족 결과와 판매 수입을 실제 가구·상점 장부에 남기는 왕도 소매 거래
- 첫날 배송·제작·판매·임금과 구매 성공·실패 결과의 합계가 77가구 장부와 일치하는지 확인하는 새 월드 검증
- 하루 영업 후 남은 상점 빵을 회수해 21개 제빵소마다 다음 영업용 빵 2개, 총 42개를 보존하며 총재고를 늘리지 않는 재고 조정
- 로드된 창고·제빵소·상점의 생성된 배럴·상자에 밀·석탄·가죽·종이·철·건초·빵·생활품 재고를 실제 아이템으로 표시하는 물리 재고
- 플레이어가 지원 재고 아이템을 꺼내면 다음 동기화 때 저장 재고 감소로 반영하고, 언로드 작업장은 숫자 상태만 유지하는 성능 보호
- 작업장 컨테이너 상호작용 시 직종, 현재 재고, 현금, 누적 수령·출고·임금을 한국어로 표시하는 물류 정보
- 새 월드에서 창고·제빵소·상점 컨테이너 3곳의 실제 아이템 재고와 77가구 구매·154명 임금·제빵소 보존 재고를 동시에 확인하는 전용 회귀 검사
- 출발 시 원재고를 차감해 출고 중으로 묶고, 실제 하역 완료 때만 도착 재고에 반영하며 실패 화물은 출발지로 반환하는 권위적 운송 정산
- 플레이어 주변 배송만 도로 경로·짐꾼·화물 수레·적재·이동·하역 상태로 실체화하고 언로드 구역은 같은 운송 시간을 집계 정산하는 성능 보호
- 새 월드에서 빵 1개를 상점에서 실제 출고한 뒤 제빵소에 하역·입고하고 총수량 보존을 확인하는 화물 에스크로 회귀 검사
- 50개 상점에 실제 영업시간과 서로 분산된 7일 주간 휴무를 배정하고, 휴무일에는 생산·서비스·구매가 중단되는 생활 경제
- 상점의 남은 빵·생활품 재고와 연속 품절 기간에 따라 빵·생활품·가구 묶음 가격이 제한 범위 안에서 변하는 동적 가격
- 77가구가 정해진 장보기 시간에 가까운 상점을 순서대로 탐색하고 휴무·품절·구매력 부족 시 다른 상점을 찾거나 실패 사유를 저장하는 구매 행동
- 로드된 가구의 아이·노인이 저장된 장보기 시간에 실제 상점 앞까지 이동하며, 주민 상호작용에서 오늘의 구매 성공·대체 상점·휴무·품절·가격 부족 결과를 설명하는 생활 동선
- 새 월드에서 77가구 시장 기록, 50개 상점 일정, 7일 휴무 분산, 동적 가격과 성공·휴무·품절·구매력 부족 네 경로를 확인하는 생활 경제 회귀 검사
- 왕실 행정, 재무, 귀족, 사원, 병원, 병영, 경비학교, 상단, 공방, 시민 안뜰, 강변 창고 역할 구분
- 외부 설계도에서 실제 저층 출입문을 탐색하고 가장 가까운 도시 도로까지 3m 폭 연결로 생성
- 왕실대로 지하 석조 배수관과 도로 가장자리 측구·빗물 유입구
- 왕도 생활권에 분산된 공공 우물 12곳과 화재 저수조 8곳
- 우물·화재 저수조를 작성 지형 높이에 설치하고 청크의 모든 건축 작업이 끝난 뒤 중앙 수원과 상부 공간을 다시 확정하는 완료 처리
- 각 스트리밍 청크 건설 직후 해당 청크의 건설 아이템을 제거하고 왕도 전체 ±1,300블록의 지연 식생 잔해를 정리하는 완료 처리
- 원본 흙판, 잎 플랫폼, 꽃밭, 나무, 물, 작물, 도로와 고립된 작은 잔해 제거
- 새 월드 서버에서 성채, 북문, 왕실대로, 행정구, 사원구, 병영구, 시민구, 주거구, 우물, 화재 저수조, 배수관, 대형·소형 건물 출입 연결로, 시가지 역할 분포, 1층 기능 공간과 상층 생활 표본을 검사하는 진단 경로

- 완성된 로드 청크의 비기능 공터·후면 마당·골목 모서리를 도로·출입 통로·기능 필지를 침범하지 않는 안뜰·적재공간·세탁공간·정원·휴게공간·목재 야드로 채우는 2차 미세 필지 조립
- 왕도 외곽 생산 거점이 실제 재고·운송 에스크로를 통해 왕도 창고 원료를 공급하고, 로드된 생산 거점은 물리 컨테이너 재고로 동기화되는 왕국 단위 공급망
- 왕도 화재를 감지해 경비초소 근무자가 8개 화재 저수조 중 가까운 곳에서 급수한 뒤 현장까지 실제 길찾기로 이동해 근거리에서 진압하는 소방 대응
- 강우·막힘·하천 수위에 반응해 도로 측구·빗물 유입구·지하 배수관·6개 하수 처리 거점을 연결하는 실제 배수 시뮬레이션
- 은빛강 가항 수로, 서부 부두, 세관, 조선소·슬립웨이와 공급 장부의 바지선 화물을 실제 보트 엔티티 이동으로 연결한 수운

- 에르덴 범죄를 즉시 수배로 바꾸지 않고 범행 순간 실제 로드된 주민만 목격자로 확정해 실제 경비초소 근무자에게 걸어가 신고한 뒤 수배장을 발부하며, 주민 경비의 근접 체포·구금·실제 시민법정 심리·판결·형기 집행으로 이어지는 시민 사법 절차

## 왕국 완성 전 남은 핵심

- 현재 표준화된 1층·상층 공간을 원본 건물의 모든 층과 실제 방 배치로 확장하고 원본 계단·복도·상층 출입을 전부 연결하는 작업
- 모든 랜드마크와 주거 앵커까지 포함해 문, 계단, 침대, 작업대, 저장고를 실제 보행 경로로 연결하는 전수 검사
- 출생, 성장, 결혼, 상속, 재혼, 이주, 임대료와 주택 공실을 반영하는 세대 변화
- 왕도 교외 농경지와 왕국 내 시장도시·촌락·역참·광산
- 전용 동물, 몬스터, 정령과 지역별 스폰 생태
- 외부 UI 디자인의 왕국 기능별 최종 통합

위 항목들이 완료되기 전에는 사용자에게 왕국 완성 테스트를 요청하지 않는다.

# 에르덴 왕국 구현 상태

이 문서는 사용자 배포용 패치 노트가 아니라 왕국 완성도를 판단하기 위한 내부 구현 기준이다.

## 현재 구현된 기반

- 1블록 = 1미터의 48km × 40km 에르덴 고정 국토
- 2.4km × 1.8km 왕도 성벽 내부 경계
- Living Realm 전용 구조물 비활성 노이즈 생성기
- 바닐라 마을, 전초기지, 사원, 폐허 포털 등 레지스트리 구조물 시작 차단
- 청크가 열릴 때 16m × 16m 단위로 왕도를 조립하는 스트리밍 건설
- 플레이어가 바라보는 청크를 우선 처리하는 가시 구역 우선 건설 대기열
- 실제 지표를 따라가는 왕실대로, 간선도로, 내부 순환로, 생활 골목
- CC BY 4.0 외부 성채에서 추출한 성벽, 탑, 문루 파츠
- 은빛강의 흐름을 막지 않는 북·남 성벽 수문 공간
- CC BY 4.0 외부 건물 4종을 기능에 맞춰 배치한 16개 구역 랜드마크
- 같은 외부 건축 계열을 방향과 구역에 맞춰 분산한 24개 주거 블록 앵커
- 외부 건축물의 실제 최저층 출입구를 기준으로 외벽·실내 구간을 잘라 만든 소형 건축 파츠
- 원본 지형판 제거 뒤 문이 파츠 외곽 5블록 안에 없더라도 가상 입구 대신 실제 최저층 문을 유지하는 출입구 선택
- 잘린 단면을 원본 건물의 주 외벽 재료로 봉합하고 계단·문·울타리 등 블록 상태를 보존하는 파츠 조립
- 왕도 여섯 생활권의 빈 필지를 채우는 1차 연속 시가지 생성
- 연립주택, 상점, 제빵소, 여관, 마구간, 경비초소, 목욕시설, 창고의 8개 생활 기능 배정
- 성채·랜드마크·대형 주거 앵커·도로·우물·저수조를 침범하지 않는 필지 검증
- 각 소형 건물 출입구가 가장 가까운 생활 골목을 향하도록 회전하고 3m 폭 연결로 생성
- 왕실 행정, 재무, 귀족, 사원, 병원, 병영, 경비학교, 상단, 공방, 시민 안뜰, 강변 창고 역할 구분
- 외부 설계도에서 실제 저층 출입문을 탐색하고 가장 가까운 도시 도로까지 3m 폭 연결로 생성
- 왕실대로 지하 석조 배수관과 도로 가장자리 측구·빗물 유입구
- 왕도 생활권에 분산된 공공 우물 12곳과 화재 저수조 8곳
- 우물·화재 저수조를 작성 지형 높이에 설치하고 청크의 모든 건축 작업이 끝난 뒤 중앙 수원과 상부 공간을 다시 확정하는 완료 처리
- 각 스트리밍 청크 건설 직후 해당 청크의 건설 아이템을 제거하고 왕도 전체 ±1,300블록의 지연 식생 잔해를 정리하는 완료 처리
- 원본 흙판, 잎 플랫폼, 꽃밭, 나무, 물, 작물, 도로와 고립된 작은 잔해 제거
- 새 월드 서버에서 성채, 북문, 왕실대로, 행정구, 사원구, 병영구, 시민구, 주거구, 우물, 화재 저수조, 배수관, 대형·소형 건물 출입 연결로와 시가지 역할 분포를 검사하는 진단 경로

## 왕국 완성 전 남은 핵심

- 1차 시가지 파츠 사이의 남은 공터·후면 마당·골목 모서리를 채우는 2차 미세 필지 조립
- 모든 소형 건물 내부가 실제 기능에 맞는지 확인하고 여관 객실, 상점 진열대, 제빵 작업대, 마구간 칸, 목욕탕 수조 등을 기능별로 보정
- 모든 건물 내부의 출입 가능 여부, 계단·침대·작업대·저장고까지 포함한 보행 검사
- 화재 시 소방 인력과 저수조를 사용하는 대응 동선
- 강우량·막힘·하천 수위에 반응하는 실제 배수·하수 시뮬레이션
- 강변 부두, 세관, 조선소와 실제 수운
- 주민 가족, 주택, 직장, 일과, 소비, 운송, 휴일 시뮬레이션
- 경비대 목격과 신고, 체포, 구금, 재판, 판결, 형 집행
- 왕도 교외 농경지와 왕국 내 시장도시·촌락·역참·광산
- 전용 동물, 몬스터, 정령과 지역별 스폰 생태
- 외부 UI 디자인의 왕국 기능별 최종 통합

위 항목들이 완료되기 전에는 사용자에게 왕국 완성 테스트를 요청하지 않는다.

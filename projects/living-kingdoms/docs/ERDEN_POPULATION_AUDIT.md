# 에르덴 왕도 인구 단계 감사

## 확정 구현

- 연립주택 77곳과 일대일로 연결된 77가구
- 가구당 성인 노동자 2명과 아이 또는 노인 1명
- 총 주민 명부 231명
- 성인 노동자 154명과 부양 구성원 77명
- 서로 겹치지 않는 작업장 154곳과 향후 이주·고용용 공석 2곳
- 가문, 주택, 침상 슬롯, 생애 단계, 직장, 교대 시간과 사망 상태의 월드 저장
- 제빵소·마구간·창고의 이른 교대, 상점·목욕시설의 주간·늦은 교대, 여관·경비초소의 야간 교대
- 로드된 생활권의 주민만 한 번에 최대 두 명씩 실체화하는 성능 보호
- 언로드 구역을 강제로 불러오거나 주민을 순간이동시키지 않는 일반 플레이 동선
- 주민 사망 시 재생성, 생산과 소비 계산에서 영구 제외
- 식량, 생활품, 운송력, 치안력, 위생력, 물류력과 숙박력을 집계하는 일일 왕도 장부
- 살아 있는 주민과 가구 수를 기준으로 한 일일 소비, 재고와 누적 부족분 저장
- 장기 미접속 시 최대 30일까지만 밀린 장부를 정산하는 시작 부하 제한

## 새 월드 검증 결과

검증 실행 `30752461246`에서 다음 항목을 같은 새 월드 서버 실행으로 확인했다.

- Java 25 클린 빌드 통과
- Minecraft 26.2 / NeoForge 26.2.0.38-beta 전용 서버 실행 통과
- 77가구, 주민 231명, 노동자 154명, 부양 구성원 77명 확정
- 소유 주택 77곳과 중복 없는 작업장 154곳 확정
- 작업장 공석 2곳 유지
- 첫날 생산·소비 장부 계산 통과
- 첫날 누적 부족분 0
- 표본 가구의 주택 외벽, 실제 출입문, 1층 내부와 상층 생활 공간 완성
- 표본 가구 구성원 세 명의 실제 주민 엔티티 생성
- 기존 왕도 구조물, 도로, 배수, 우물, 저수조와 상층 검사 유지
- 왕도 건설 아이템 잔해 0

231명을 항상 엔티티로 유지하는 방식은 사용하지 않는다. 명부와 경제는 전역 저장하되 플레이어가 실제로 머무는 로드 생활권의 주민만 실체화한다.

## 다음 단계

현재 생산과 소비는 안정적인 집계 장부다. 다음 단계에서는 이를 작업대 투입물, 완제품, 창고 상자, 점포 재고, 임금과 구매, 짐꾼·수레 배송으로 연결한다. 출생, 성장, 결혼, 상속, 이주와 임대료를 포함한 세대 변화는 그 이후 단계다.

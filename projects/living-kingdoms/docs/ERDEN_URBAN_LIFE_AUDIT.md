# 에르덴 왕도 다층 생활 감사 기준

이 문서는 사용자에게 노출하는 패치 노트가 아니라 왕국 완성 전 내부 검증 기준이다.

## 다층 내부

- 대상: 연립주택, 상점, 제빵소, 여관, 마구간, 경비초소, 목욕시설, 창고의 8개 역할
- 건물의 실제 최저층 문과 도로 방향을 기준으로 내부 방향을 판정한다.
- 1층 기능 공간이 완료된 건물만 상층을 조립한다.
- 계단은 4단으로 구성하며 계단실 상층 바닥을 비워 실제 이동 공간을 남긴다.
- 상층 바닥 높이는 1층 바닥보다 5m 높다.
- 상층에는 3m 높이의 머리 공간과 중앙 보행 통로를 유지한다.
- 역할별 상층 설비는 침대, 장부대, 수납함, 건초 다락, 경비 숙소, 탈의 공간, 적재 다락으로 구분한다.
- 완료 여부는 출입문 좌표와 상층 리비전으로 월드 저장 데이터에 기록한다.
- 아직 열리지 않은 시가지 청크는 플레이어 접근 시 순차적으로 완성한다.

## 주요 시민 생활 배정

- 기록관 마렌: 상점 계열 기록 작업장
- 어업조합원 로안: 창고
- 석공 엘라: 창고
- 시장서기 페른: 상점 계열 사무 공간
- 철공조합장 하벨: 경비초소의 대장 작업 공간
- 약제사 미라: 상점
- 성문부사관 토렌: 경비초소
- 마차조합원 베아: 마구간

각 시민은 기존 등장 위치에서 가장 가까운 적합 작업장을 배정받는다. 주택은 작업장과 가까운 연립주택을 중복 없이 배정한다. 낮에는 작업장, 저녁과 밤에는 상층 주거 공간으로 길찾기를 요청한다. 주민이 있는 청크가 로드되지 않은 경우 강제 로드나 순간이동을 하지 않는다.

## 자동 검사

새 월드 서버 검사는 다음을 확인해야 한다.

- Java 25 및 NeoForge 26.2 컴파일
- 진단용 제빵소의 1층 내부 완료
- 4개 계단 블록 존재
- 상층 착지 바닥 존재
- 제빵소 상층 역할 설비 존재
- 상층 중앙 통로가 비어 있음
- 주요 시민 8명의 집·직장 배정 저장
- 기존 왕도, 배수, 외부 건축, 잔해 제거 검사 유지

왕국 전체 완성 전에는 이 기능만으로 사용자 테스트 빌드를 배포하지 않는다.

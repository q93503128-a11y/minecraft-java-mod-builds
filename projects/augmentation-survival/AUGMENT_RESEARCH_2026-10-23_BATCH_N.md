# Augmentation Survival — Batch N Missing Staples / Mythic Expansion

Date: 2026-10-23
Status: proposal only; user review pending

## 1. 목적

현재 확정 방향 114개를 기준으로 단순 총량이 아니라 역할군 공백을 다시 감사한다. 특히 직접 회복, 실제 부활, 전투 지속 회복, 신화 등급의 선택지 부족을 우선 해결한다.

현재 신화 확정은 `시간 정지`, `공간 연결` 2개뿐이다. 기본 뽑기 UX가 같은 등급의 유효 후보 3개 중 하나를 고르는 구조이므로 신화 2개는 최초 선택 화면조차 3장을 구성할 수 없다. 신화는 최소 6개 이상으로 확장하는 방향을 우선한다.

또한 최대 레벨 증강이 후보 풀에서 제거되므로 모든 등급에서 유효 후보가 마지막 1~2개만 남는 상황이 발생할 수 있다. 완주 규칙으로 `유효 후보가 3개 이상이면 3개 제시, 1~2개면 남은 후보 전부 제시, 0개면 코어 소비 없이 사용 불가`를 검토한다.

## 2. 현재 공백

- 직접 체력을 채우는 액티브 힐이 없음.
- 적 처치로 전투를 계속 이어가는 지속 회복 축이 없음.
- `한 번 버티기`, `비상 토템`은 사망 방지이며 실제 부활 판타지와 다름.
- 다른 플레이어/전투 동료를 되살리는 지원형 부활이 없음.
- 신화가 시간/공간 2축뿐이라 3장 선택 UX와 신화 빌드 다양성이 부족함.
- 비전투 신화급 파워 판타지(자원, 채굴 등)가 부족함.
- 몹의 소유/적대 관계 자체를 바꾸는 상위 규칙 변경형 증강이 없음.

## 3. 신규 후보

### 희귀 — 사냥의 활력 Lv.3

- 자신이 직접 피해를 주어 적대적 개체를 처치하면 최대 체력의 **3% / 5% / 7%**를 즉시 회복한다.
- 보스 처치 시에는 **9% / 15% / 21%**로 3배 적용한다.
- 자연회복이 아니므로 `회복 증폭`, `넘치는 회복`, `회복 나눔`과 정상 연계한다.
- 분신/동료/자동 피해가 대신 처치한 경우에는 발동하지 않는다.

### 영웅 — 치유 파동 Lv.3

- 액티브.
- 자신과 반경 8블록 안의 아군 플레이어/길들인 전투 동료를 각자의 최대 체력 기준 **20% / 30% / 40%** 즉시 회복한다.
- 재사용 대기시간 **30 / 25 / 20초**.
- 자연회복이 아니므로 회복 관련 증강과 정상 연계한다.
- 이미 최대 체력인 대상의 초과분은 대상이 `넘치는 회복` 효과를 받을 수 있는 경우에만 그 규칙을 따른다.

### 전설 — 소생 Lv.1

- 아군 플레이어 또는 길들인 전투 동료가 자신에게서 20블록 안에서 사망하면 해당 위치에 **20초 동안 소생 표식**을 남긴다.
- 표식에 3초 집중 상호작용하면 대상을 최대 체력의 **50%**로 사망 위치에서 되살린다.
- 플레이어 소생은 정상 사망 드롭/XP를 복제하지 않으며, 이미 발생한 드롭은 그대로 월드에 남는다. 소생된 플레이어가 다시 회수할 수 있다.
- 집중 중 이동/공격/피격 시 취소된다.
- 성공 재사용 대기시간 **120초**.
- 자기 자신에게는 사용할 수 없다.

### 신화 — 재림 Lv.1

- 다른 사망 방지 효과(`한 번 버티기`, 손/인벤토리 토템 등)가 모두 실패해 실제 사망이 확정되려는 순간 발동한다.
- 3초 동안 무적·행동불가 상태가 된 뒤 **사망 위치에서 최대 체력 100%로 부활**한다.
- 이 부활에서는 인벤토리와 XP를 떨어뜨리지 않는다.
- 화염/익사/낙하 등 즉시 재사망 가능한 환경이면 서버가 사망 지점 주변의 가장 가까운 안전 위치로 보정한다.
- 재사용 대기시간 **180초**.
- 일반 사망/respawn을 우회하는 신화급 생명 규칙 변경이다.

### 신화 — 풍요 Lv.1

- 플레이어가 직접 발생시킨 일반 자원 획득의 최종 **스택 가능한 아이템 드롭을 2배**로 만든다.
- 직접 채굴, 직접 수확, 직접 낚시, 직접 처치한 일반 몹 드롭에 적용한다.
- 증강 코어, 고유 보스 보상, 퀘스트/진행 아이템, 고유 NBT 장비, 비스택 장비는 복제하지 않는다.
- Fortune, Looting, `전리품 챙기기`, 농사/채광 증강 등 기존 보너스 계산이 끝난 최종 일반 드롭 수량을 2배로 한다.
- 자동화/호퍼/분신/동료 처치는 플레이어 직접 행동으로 보지 않는다.

### 신화 — 순간 채굴 Lv.1

- 전용 키로 켜고 끄는 토글형.
- 활성화 중 플레이어가 현재 든 도구로 **정상적으로 수확 가능한 블록**을 직접 채굴하면 해당 블록의 파괴 시간을 1 game tick으로 만든다.
- Bedrock 등 원래 파괴 불가 블록은 대상이 아니다.
- 올바른 도구/수확 조건, Silk Touch/Fortune, 내구도 소비, 드롭 계산은 정상 적용한다.
- 연속 대량 파괴가 아니라 플레이어가 실제로 조준해 채굴을 시작한 블록 하나씩만 적용한다.
- 실수로 건축물을 뜯는 상황을 막기 위해 토글 상태를 HUD에서 명확히 표시한다.

### 신화 — 지배 Lv.1

- 액티브 대상 지정형.
- 시야가 닿는 24블록 이내의 **비보스 적대적 몹 1체**를 영구적인 아군 전투 개체로 전환한다.
- 최대 **3체**까지 지배할 수 있으며, 4번째 대상을 지배하면 관리 UI에서 기존 지배 개체 하나를 해제하거나 새 시전을 취소한다.
- 지배된 개체는 원래 공격/이동 능력을 유지하지만 소유자와 소유자의 아군을 공격하지 않고 주변 적대적 개체와 싸운다.
- 보스, 스크립트 핵심 개체, 소유권을 이미 가진 특수 개체는 대상에서 제외한다.
- 지배 개체의 처치는 증강 코어/고유 진행 보상을 생성하지 않아 자동 진행 파밍을 막되, 일반 월드 전투 보조 역할은 유지한다.
- 별도 지속시간은 없으며 지배 개체가 죽거나 소유자가 해제할 때까지 유지한다.

## 4. 이번 배치 적용 시 분포

현재 114개에서 전부 확정될 경우 +7개 = 121개.

- 일반 20
- 고급 27
- 희귀 29 (`사냥의 활력` +1)
- 영웅 29 (`치유 파동` +1)
- 전설 12 (`소생` +1)
- 신화 6 (`재림`, `풍요`, `순간 채굴`, `지배` +4)
- 총 121

신화가 6개가 되므로 최초 신화 코어 사용 시 3장 선택을 정상 구성할 수 있고, 여러 번 신화를 획득해도 초반 몇 회는 실제 선택 폭이 유지된다.

## 5. 외부 참고

ARAM: Mayhem에는 직접/조건부 회복과 부활을 별도 증강 판타지로 사용한다. `Dawnbringer's Resolve`는 저체력 조건에서 큰 회복을 제공하고 `Hellbent`는 치명 피해 후 resurrection 상태를 거쳐 다시 전투에 복귀한다. 이 프로젝트는 해당 수치를 복제하지 않고, Minecraft 장기 서바이벌에 맞는 서버 권한형 회복/부활 규칙으로 재구성한다.

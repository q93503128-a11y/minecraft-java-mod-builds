# Augmentation Survival — Batch N Final Decisions

Date: 2026-10-23

사용자 규칙에 따라 별도 폐기 지시가 없는 Batch N 후보는 확정으로 처리한다.

## 공통 표기 규칙

- 앞으로 액티브 증강은 후보 표와 정본 설명에서 이름 옆에 **`(액티브)`**를 명시한다.
- 토글형 액티브는 **`(액티브 · 토글)`**로 명시한다.
- 자동 발동/상시 효과는 액티브로 표기하지 않는다.
- 유효 후보가 부족할 때의 뽑기 처리 규칙은 이미 기존 기획에 존재하므로 이번 Batch N에서 새 규칙으로 추가하지 않는다. 기존 정본을 그대로 따른다.

## 폐기

### 사냥의 활력

- 처치 시 회복 축은 기존 증강과 의미가 중복되므로 폐기한다.
- 이후 이름이나 수치만 바꾼 같은 의미 후보를 다시 제안하지 않는다.

## 확정

### 영웅 — 치유 파동 Lv.3 (액티브)

- 자신과 반경 8블록 안의 아군 플레이어/길들인 전투 동료를 각자의 최대 체력 기준 **20% / 30% / 40%** 즉시 회복한다.
- 재사용 대기시간 **30 / 25 / 20초**.
- 자연회복이 아니므로 `회복 증폭`, `넘치는 회복`, `회복 나눔`과 정상 연계한다.
- 최대 체력을 넘는 회복은 대상이 `넘치는 회복`을 보유한 경우 그 규칙을 따른다.

### 전설 — 소생 Lv.1 (액티브)

- 아군 플레이어 또는 길들인 전투 동료가 자신에게서 20블록 안에서 사망하면 해당 위치에 **20초 동안 소생 표식**을 남긴다.
- 표식에 3초 집중 상호작용하면 대상을 최대 체력의 **50%**로 사망 위치에서 되살린다.
- 플레이어 소생 시 이미 발생한 정상 사망 드롭/XP는 월드에 그대로 남고 복제하지 않는다.
- 집중 중 이동/공격/피격 시 취소된다.
- 성공 재사용 대기시간 **120초**.
- 자기 자신에게는 사용할 수 없다.

### 전설 — 재림 Lv.1

- 최초 신화 제안에서 **전설**로 조정한다.
- 다른 사망 방지 효과(`한 번 버티기`, 손/인벤토리 토템 등)가 모두 실패해 실제 사망이 확정되려는 순간 자동 발동한다.
- 3초 동안 무적·행동불가 상태가 된 뒤 사망 위치에서 **최대 체력 100%**로 부활한다.
- 이 부활에서는 인벤토리와 XP를 떨어뜨리지 않는다.
- 즉시 재사망 가능한 환경이면 서버가 사망 지점 주변의 가장 가까운 안전 위치로 보정한다.
- 재사용 대기시간 **180초**.
- 자동 발동이므로 액티브로 표기하지 않는다.

### 신화 — 풍요 Lv.1

- 플레이어가 직접 발생시킨 일반 자원 획득의 **최종 스택 가능한 아이템 드롭 수량에 ×2를 곱한다.**
- 적용 순서는 `바닐라 원본 드롭 → Fortune/Looting 및 호환 증강/모드 보너스 → 최종 일반 드롭 확정 → 풍요 ×2`다.
- 직접 채굴, 직접 수확, 직접 낚시, 직접 처치한 일반 몹 드롭에 적용한다.
- `전리품 챙기기`, 농사/채광 자원 보너스처럼 호환 가능한 기존 효과가 만든 최종 수량도 곱연산 대상이다.
- 증강 코어, 고유 보스 보상, 퀘스트/진행 아이템, 고유 NBT 장비, 비스택 장비는 복제하지 않는다.
- 자동화/호퍼/분신/동료 처치는 플레이어 직접 행동으로 보지 않는다.

### 신화 — 순간 채굴 Lv.1 (액티브 · 토글)

- 전용 키로 켜고 끈다.
- 활성화 중 현재 든 도구로 정상적으로 수확 가능한 블록을 직접 채굴하면 해당 블록의 파괴 시간을 **1 game tick**으로 만든다.
- 원래 파괴 불가 블록은 대상이 아니다.
- 올바른 도구/수확 조건, Silk Touch/Fortune, 내구도 소비, 드롭 계산은 정상 적용한다.
- 플레이어가 실제로 조준해 채굴을 시작한 블록 하나씩만 적용한다.
- 토글 상태를 HUD에 명확히 표시한다.

### 신화 — 지배 Lv.3 (액티브)

- 시야가 닿는 24블록 이내의 **비보스 적대적 몹 1체**를 영구적인 아군 전투 개체로 전환한다.
- 최대 지배 개체 수는 **3 / 5 / 10체**.
- **재사용 대기시간은 없다.** 보유 한도까지 연속으로 사용할 수 있다.
- 한도에 도달한 상태에서 새 대상을 지배하려 하면 기존 지배 개체를 해제하거나 새 시전을 취소한다.
- 지배된 개체는 소유자와 소유자의 아군을 공격하지 않는다.
- 지배된 개체는 서버 AI가 주변 적대적 몹을 스스로 탐색·추적하여 자동 전투한다. 플레이어가 직접 공격 명령을 반복해서 내릴 필요가 없다.
- 가능한 경우 원래 개체의 이동/공격 방식과 특수 능력을 유지한다.
- 보스, 스크립트 핵심 개체, 기존 소유권을 가진 특수 개체는 대상에서 제외한다.
- 지배 개체가 만든 처치는 증강 코어/고유 진행 보상을 새로 생성하지 않아 자동 진행 파밍을 막는다.
- 지속시간은 없으며 지배 개체가 죽거나 소유자가 해제할 때까지 유지한다.

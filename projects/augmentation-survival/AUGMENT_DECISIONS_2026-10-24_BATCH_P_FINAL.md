# Augmentation Survival — Batch P Final Decisions

Date: 2026-10-24
Status: confirmed

이번 Batch P는 Arena / ARAM: Mayhem 류 증강에서 얻은 `행동 변환`, `대가-보상`, `행동 기반 영구 성장`, `규칙 변화형 대형 액티브`라는 설계 축을 Minecraft 장기 서바이벌에 맞게 변환한 결과다.

사용자가 별도 폐기 지시를 하지 않았으므로 아래 5개는 모두 확정한다.

## 플레이어-facing 설명 원칙

- 아래 문서는 구현/호환성/계산 계약까지 포함한 개발 정본이다.
- 실제 게임 카드/툴팁에는 내부 이벤트명, 호환 예외, 재귀 차단, `ROOT`, `특수 피해라 다른 증폭 제외` 같은 개발자용 설명을 넣지 않는다.
- 실제 게임에서는 플레이어가 알아야 하는 효과, 수치, 발동 조건만 짧고 자연스럽게 쓴다.
- 문구는 Arena / ARAM: Mayhem처럼 짧고 즉시 이해되는 설명 방식을 참고하되 문장을 복제하지 않는다.
- `P0/P1`, TODO, debug, compat, adapter, 개발 로그 같은 표현은 플레이어-facing 텍스트에 사용하지 않는다.

## 영웅 — 보호막 폭발 Lv.3

- 증강으로 생성된 보호막 또는 흡수 체력 풀이 완전히 소진되거나 지속시간 만료로 종료될 때 주변에 폭발 피해를 준다.
- 반경 4블록.
- 해당 보호막 풀의 유효량을 기준으로 피해 배율 x1.0 / x1.5 / x2.0.
- 최종 피해 상한 12 / 20 / 30 HP.
- 동일 보호막 풀은 종료당 1회만 폭발한다.
- `보호막`, `넘치는 회복` 등 증강이 만든 보호 계층과 연계한다.
- 폭발 자체가 새로운 보호막 폭발이나 회복 이벤트를 만들지 않는다.

## 영웅 — 속도 전환 Lv.3

- 현재 플레이어에게 적용 중인 양의 보너스 이동속도 1%당 ROOT 직접 공격 피해가 +0.4% / +0.6% / +0.8% 증가한다.
- 최대 증가량 +20% / +30% / +40%.
- 바닐라 기본 이동속도와 단순 질주 상태는 보너스 이동속도로 세지 않는다.
- 증강, 상태효과, 장비 등 서버가 실제 양의 이동속도 보너스로 계산하는 효과는 포함할 수 있다.
- `빠른 발`, `다급한 발걸음`, `연속 처치`, `관성 전환`, `시간 가속` 등과 정상 연계한다.

## 전설 — 유리 대포 Lv.3

사용자 수치 `체력 60/80/100, 피해 60/80/100`은 최초 제안의 체력 배율 구조를 기준으로 다음처럼 확정한다.

- 최대 체력: 다른 최대체력 계산이 끝난 값의 60% / 80% / 100%.
- 일반 전투에서 자신이 주는 피해: +60% / +80% / +100%.
- Lv.3에서는 체력 페널티가 사라지고 피해 보너스만 +100%가 남는다.
- `천벌`처럼 표시값 자체가 고정된 최대체력 비율 특수 피해는 내부 계산 계약상 증폭하지 않는다.
- 이 예외 문구는 인게임 카드에 넣지 않고 해당 효과들의 정본 계산 규칙으로만 관리한다.

## 전설 — 사냥 기록 Lv.1

- 플레이어가 해당 월드/세이브에서 처음으로 직접 처치한 적대적 entity type마다 영구 1스택을 얻는다.
- 스택당 최대체력 +1 HP, ROOT 직접 공격 피해 +0.5%.
- 최대 30스택.
- 최대 효과: 최대체력 +30 HP, ROOT 직접 공격 피해 +15%.
- 외부 모드 적도 entity type이 고유하면 정상적으로 새 종류로 기록한다.
- 분신, 지배 개체, 자동 피해가 대신 처치한 경우에는 새 기록을 만들지 않는다.
- 플레이어별 영구 저장 데이터이며 사망으로 초기화되지 않는다.

## 신화 — 거대화 Lv.2 (액티브)

- 20초 동안 거대화한다.
- 크기 배율: x1.75 / x2.50.
- 최대체력 및 현재체력 스케일: x1.75 / x2.50.
- 근접 공격거리: +3 / +6블록.
- 근접 공격 피해: +35% / +70%.
- 가하는 넉백: +100% / +100%.
- 종료 시 거대화 직전/중 체력 비율을 유지해 기본 체력 스케일로 복귀한다.
- 재사용 대기시간 60초.
- Lv.2로 발동하는 순간 반경 8블록 안의 일반 비보스 적대몹에게 2초 동안 공포를 건다.
- 공포 대상은 2초 동안 플레이어에게서 도망치며 정상 공격을 시도하지 않는다.
- 보스, 스크립트 핵심 개체, 명시적 공포 면역 대상은 제외한다.
- 거대화 종료 위치가 현재 크기에서 안전하지 않으면 서버가 가장 가까운 안전 위치로 보정한다.

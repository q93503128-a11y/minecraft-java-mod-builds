# Augmentation Survival — Augment Roster Canon

Date: 2026-10-23

이 문서는 개별 증강의 현재 정본이다. 이후 증강 후보를 제안하거나 구현할 때 이 파일을 먼저 확인해 의미 중복을 피한다.

## 1. 공통 규칙

- 증강 총 보유 개수 제한은 없다.
- 증강마다 최대 레벨을 개별 지정한다. Lv.1 고유형, Lv.3/Lv.5 성장형 등으로 통일하지 않는다.
- 최대 레벨에 도달한 증강은 같은 등급의 뽑기 후보 풀에서 제거한다.
- 배타 관계는 전역 규칙으로 두지 않고, 실제 충돌하거나 함께 허용하면 게임성이 무너지는 조합에만 개별 적용한다.
- 내부 설계상 전투/채광/농사/이동/생존/탐험/낚시/건축 등으로 분류할 수 있지만, 플레이어에게 카테고리를 표시하지 않는다.
- 인게임 카드에는 등급을 표시하고, 효과는 가능한 한 정확한 수치를 보여준다.
- `다음` 후보를 제안할 때는 확정/폐기/보류뿐 아니라 과거에 한 번이라도 제안된 후보와 의미가 겹치지 않는 신규 효과만 제안한다.
- 과거 후보를 다시 다룰 때는 사용자가 직접 재검토를 요청했을 때만 꺼낸다.

## 2. 카드 등급 표현

- 일반: 등급색 변화만
- 고급: 등급색 변화만
- 희귀: 등급색 변화만
- 영웅: 등급색 + 약한 네온 발광
- 전설: 네온 발광 + 카드 뒤쪽 후광
- 신화: 붉은색 중심 + 강한 오오라. 전설보다 명확히 강한 존재감을 주되 화면 전체를 가리는 과한 연출은 피한다.

## 3. 방어 계산 원칙

방어 관련 성장축은 합쳐버리지 않고 별도 층으로 유지한다.

기본 순서:

1. 원래 피해
2. Minecraft 갑옷 방어력 / 방어 강도
3. 보호 계열 인챈트
4. 증강의 일반 피해 감소
5. 조건부 / 속성별 증강 피해 감소
6. 최종 체력 피해

증강 피해 감소끼리는 단순 합산하지 않고 곱연산한다.

예: 상시 피해 10% 감소와 조건부 피해 20% 감소가 동시에 적용되면 최종 배율은 `0.9 * 0.8 = 0.72`, 즉 총 28% 감소다.

갑옷, 보호 인챈트, 증강은 모두 의미 있는 성장축으로 남긴다. 후반에 세 축을 모두 갖춰 매우 단단해지는 것은 허용한다.

## 4. 멀티플레이 / 서버 권한 원칙

- 피해, 드롭, 채굴, 낚시, 경험치, 인벤토리, 증강 획득/레벨, 기계 처리 등 중요한 결과는 서버가 최종 결정한다.
- 플레이어가 직접 수행한 행동은 그 행동을 수행한 플레이어의 증강 레벨만 적용한다. 다른 플레이어의 개인 증강을 합산하지 않는다.
- 공유 블록/기계에 영향을 주는 증강은 `누가 마지막으로 만졌는가` 같은 불안정한 판정을 사용하지 않는다. 각 증강마다 소유/범위/스냅샷 규칙을 명시한 뒤 구현한다.
- 주변 플레이어를 기준으로 작동하는 기계/오라형 효과가 여러 명에게서 겹칠 경우 기본값은 **가장 높은 유효 레벨 하나만 적용**하며 합산하지 않는다.
- 기계 처리 중간에 플레이어가 들어오거나 나가면서 효율이 매 tick 출렁이지 않도록, 연료 1개 시작/작업 1회 시작 등 명확한 시점에 효과를 스냅샷하는 방식을 우선한다.
- 자동화(호퍼 등)는 특정 플레이어의 행동으로 간주하지 않는다. 자동화에도 적용할 증강은 별도 범위/소유 규칙을 가져야 한다.
- 멀티플레이 구조는 위 원칙으로 설계하지만, 실제 멀티플레이 실테스트는 아직 하지 않았다. `MULTIPLAYER TESTED: NO`.

`연료 절약` 확정 멀티 규칙:

- 연료를 누가 넣었는지로 판정하지 않는다. 공유 스택과 호퍼에서 소유권이 모호해지기 때문이다.
- 화로/훈연기/용광로가 **새 연료 1개를 실제로 소모해 연소를 시작하는 순간**, 서버가 주변 8블록 안 플레이어 중 `연료 절약` 레벨이 가장 높은 한 명을 찾는다.
- 그 연료 1개의 연소시간에 해당 레벨 보너스를 스냅샷한다. 이후 플레이어가 멀어져도 이미 시작한 연료의 연소시간은 바뀌지 않는다.
- 주변에 해당 증강 보유자가 없으면 바닐라 연소시간을 사용한다.
- 호퍼로 넣은 연료도 연소 시작 시 주변 조건을 충족하면 보너스를 받을 수 있다.

## 8. 폐기

아래 후보는 다시 같은 의미로 제안하지 않는다.

- 재료 아끼기 — 블록 설치 시 재료 미소모. 복제/악용 가능성과 효과 자체의 매력이 부족해 폐기.
- 손 빠른 농부 — 농사 상호작용 속도 증가. 실제 체감 가치가 낮아 폐기.
- 낚시꾼 — `낚시 감각`과 의미 중복이라 폐기.
- 경험치 줍기 — 경험치 구슬 획득 반경 증가. 확정된 `줍는 손`에 포함되어 의미 중복.
- 등짐 정리 — 바닥 아이템/인벤토리 자동 정리 편의. 증강으로서 재미와 체감 가치가 부족해 폐기.

## 9. 아직 미확정 / 보류

아래는 과거에 이미 제안된 후보다. 사용자가 직접 재검토를 요청하지 않는 한 `다음` 목록에서 다시 출력하지 않는다.

- 불에 익숙함 — 화염/용암 피해 감소. 등급과 정확한 수치 미확정.
- 가벼운 몸 — 점프 높이 증가. 등급과 정확한 수치 미확정.
- 수리 습관 — 모루 경험치 비용 감소. 등급과 수치 미확정.
- 발소리 죽이기 — 적대 몹 인식 거리 감소. 등급과 수치 미확정.
- 사다리 타기 — 사다리/덩굴 상승 속도 증가. 등급과 수치 미확정.
- 첫 타 — 체력이 가득 찬 적에게 가하는 첫 피해 증가. 등급과 수치 미확정.
- 한 마리 더 — 낚시 결과가 물고기일 때 추가 물고기 획득. 등급과 수치 미확정.
- 빠른 장전 — 활 당기기와 쇠뇌 장전 시간 감소. 등급과 수치 미확정.
- 뜨거운 곡괭이 — 제련 가능한 광석 드롭을 즉시 제련 결과물로 바꾸는 효과. 등급 미확정.
- 광맥 채굴 — 연결된 동일 광석을 추가 채굴. 등급/범위 미확정.
- 벽차기 — 벽을 이용한 추가 공중 이동. 등급 및 세부 동작 미확정.
- 재빠른 손놀림 — 아이템 사용 준비시간 단축 계열. 범위와 등급 미확정.
- 경험 쌓기 — 획득 경험치 증가. 제안 수치 Lv.5, 레벨당 +5%. 등급 미확정.
- 노 젓기 — 플레이어 조종 보트 속도 증가. 제안 수치 Lv.3, 레벨당 +10%. 등급 미확정.
- 해독력 — 해로운 상태효과 지속시간 감소. 제안 수치 Lv.3, 레벨당 10%. 등급 미확정.
- 약효 오래가기 — 이로운 물약/상태효과 지속시간 증가. 제안 수치 Lv.3, 레벨당 +10%. 등급 미확정.
- 밭 돌보기 — 주변 작물의 자연 성장 추가 진행 확률 증가. 제안 수치 Lv.3, 15% / 30% / 45%. 등급 미확정.
- 새끼 돌보기 — 주변 새끼 가축 성장 속도 증가. 제안 수치 Lv.3, +25% / +50% / +75%. 등급 미확정.
- 불 지피기 — 주변 화로/훈연기/용광로 처리 속도 증가. 제안 수치 Lv.3, +15% / +30% / +45%. 여러 플레이어가 겹치면 최고 레벨 하나만 적용하는 방향. 등급 미확정.
- 방패 반격 — 방패로 공격을 완전히 막은 뒤 다음 근접 공격 강화. 제안 수치 Lv.3, +20% / +40% / +60%, 4초 내 1회. 등급 미확정.
- 몰아치기 — 같은 적을 연속 근접 공격할 때 피해가 누적 증가. 제안 수치 Lv.3, 타격당 +3% / +6% / +9%, 최대 5중첩. 등급 미확정.
- 내려찍기 — 4블록 이상 낙하 후 착지 시 주변 적에게 낙하거리에 비례한 피해. 제안 수치 Lv.3, 블록당 0.5 / 0.75 / 1 피해, 최대 10 / 15 / 20. 등급 미확정.
- 철벽 — 방어력 자체를 증가시키는 성장형. 제안 수치 Lv.3, 레벨당 방어력 +1. 등급 미확정.
- 폭발 버티기 — 폭발 피해 감소. 제안 수치 Lv.3, 레벨당 15% 감소. 등급 미확정.
- 밀어내기 — 플레이어가 가하는 넉백 증가. 제안 수치 Lv.3, 레벨당 +10%. 등급 미확정.
- 처형 — 체력 25% 이하 적에게 주는 피해 증가. 제안 수치 Lv.3, +10% / +20% / +30%. 등급 미확정.
- 흡혈 — 적대 몹 처치 시 체력 회복. 제안 수치 Lv.3, 1 / 2 / 3 체력 회복. 등급 미확정.
- 되받기 — 근접 피해를 받으면 공격자에게 고정 피해를 돌려준다. 제안 수치 Lv.3, 1 / 2 / 3 피해. 가시 인챈트와 별도 적용. 등급 미확정.
- 숨 돌리기 — 5초 동안 피해를 받지 않으면 자연회복 시작 조건을 보조하는 별도 회복 계열 후보. 상세 수치 미확정.
- 쇠붙이 줍기 — 철/금/구리 계열 드롭을 일정 확률로 추가 획득하는 자원 특화 후보. 상세 수치와 Fortune 중첩 규칙 미확정.
- 가벼운 방패 — 방패를 들고 있는 동안 받는 이동속도 페널티를 완화하는 후보. 현재 Better Combat/바닐라 실제 페널티 존재 여부를 구현 전에 확인 필요.

## 10. 이름 원칙

증강 이름은 짧고 기능이나 이미지가 바로 떠오르게 짓는다.

피한다:
- 과한 추상명사
- 의미 없이 거창한 판타지 조어
- `영겁`, `초월`, `운명의`, `심연의 파동`처럼 효과와 연결되지 않는 AI식 이름

고등급이라도 이름의 과장보다 실제 효과와 연출로 강함을 보여준다.

# Augmentation Survival — Augment Roster Canon

Date: 2026-10-23

이 문서는 개별 증강의 현재 정본이다. 이후 증강 후보를 제안하거나 구현할 때 이 파일을 먼저 확인해 의미 중복을 피한다.

## 1. 공통 규칙

- 증강 총 보유 개수 제한은 없다.
- 증강마다 최대 레벨을 개별 지정한다. Lv.1 고유형, Lv.3/Lv.5 성장형 등으로 통일하지 않는다.
- 최대 레벨에 도달한 증강은 같은 등급의 뽑기 후보 풀에서 제거한다.
- 배타 관계는 전역 규칙으로 두지 않고, 실제 충돌하거나 함께 허용하면 게임성이 무너지는 조합에만 개별 적용한다.
- 내부 설계상 전투/채광/농사/이동/생존/탐험/낚시/건축 등으로 분류할 수 있지만, 플레이어에게 카테고리를 표시하지 않는다.
- 인게임 카드에는 등급을 표시하고, 효과는 가능한 한 정확한 수치를 보여준다.
- `다음` 후보를 제안할 때는 확정/폐기/보류뿐 아니라 과거에 한 번이라도 제안된 후보와 의미가 겹치지 않는 신규 효과만 제안한다.
- 과거 후보를 다시 다룰 때는 사용자가 직접 재검토를 요청했을 때만 꺼낸다.
- **증강끼리는 기본적으로 연계를 허용한다.** 같은 행동을 강화하는 증강들은 가능한 한 함께 작동해야 하며, 강한 조합 자체를 이유로 임의 차단하지 않는다.
- 단, 자동 생성된 2차 행동이 다시 같은 범위/연쇄 생성 효과를 재귀적으로 발동해 무한 또는 기하급수적으로 커지는 경우만 재귀 발동을 차단한다.
- 자동 채굴/자동 수확 같은 2차 행동도 가능한 한 드롭, Fortune, 자원 보너스, 제련 변환, 내구도 절약 등 호환 가능한 수치형 증강의 효과를 이어받는다. 각 기능별 예외는 명시적으로 기록한다.
- 전용 능력 키는 Minecraft Controls에서 재지정 가능한 key mapping으로 등록한다. 공식 모드팩 전체 키맵을 구현 시 확인해 WASD, 점프, 웅크리기, 질주, 인벤토리, 공격/사용, 드롭, 손 바꾸기, 핫바 숫자키 등 **핵심 조작 키와는 겹치지 않게** 기본키를 선택한다. 필요하면 비중요 바닐라/모드 키는 사용할 수 있으나 사용자가 언제든 재지정할 수 있어야 한다.

### 액티브 증강 조작

- 일반 액티브 증강은 별도의 **증강 스킬 모드 키**를 누르고 있는 동안 숫자키 `1~0`을 액티브 슬롯 `1~10`으로 사용한다.
- 증강 스킬 모드 키를 누르지 않은 평상시에는 `1~9`가 기존 Minecraft 핫바 선택 기능을 그대로 유지한다. 숫자키를 상시 가로채지 않는다.
- 스킬 모드 중에는 숫자키가 핫바를 바꾸지 않고 해당 액티브 슬롯만 발동한다. `0`은 10번째 액티브 슬롯이다.
- 액티브 슬롯은 **설정 메뉴가 아니라 증강 전용 관리 화면**에서 편집한다. 인벤토리의 증강 탭에서 `액티브 관리` 화면으로 들어가 보유 액티브 목록과 10칸 빠른 슬롯 사이를 드래그/클릭해 장착·해제·순서 변경한다.
- 액티브 슬롯은 증강 보유 제한이 아니라 빠른 사용 슬롯이다. 패시브 증강에는 영향을 주지 않는다.
- 능력의 쿨다운/남은 지속시간은 슬롯 번호가 아니라 능력 자체에 귀속한다. 슬롯을 옮기거나 다시 배치해도 쿨다운이 초기화되지 않는다.
- 스킬 모드 중에는 핫바 근처에 별도 10칸 액티브 바를 표시해 배치된 능력, 쿨다운, 사용 가능 여부를 즉시 확인할 수 있게 한다.
- `회피`처럼 이동 중 즉각적인 단일 입력이 필요한 반응형 능력은 스킬 모드+숫자 조합을 강제하지 않고 별도 전용키를 허용한다. 이런 예외 키도 §1의 핵심 조작 충돌 금지 원칙을 따른다.
- 액티브 증강이 10개를 넘어갈 경우 소유 자체를 제한하지 않는다. 우선 10개 빠른 슬롯만 제공하고, 추가 능력의 페이지/보조 접근 방식은 실제 액티브 수가 10개를 넘는 시점에 UX를 검증한 뒤 확장한다.

## 2. 카드 / 표시 UI 원칙

- 일반: 등급색 변화만
- 고급: 등급색 변화만
- 희귀: 등급색 변화만
- 영웅: 등급색 + 약한 네온 발광
- 전설: 네온 발광 + 카드 뒤쪽 후광
- 신화: 붉은색 중심 + 강한 오오라. 전설보다 명확히 강한 존재감을 주되 화면 전체를 가리는 과한 연출은 피한다.

표시형 증강 공통 표현:
- 이름표, 큰 아이콘, 화면 중앙 안내를 난립시키지 않고 **얇은 외곽선 표시**를 기본으로 한다.
- 광석은 청록 계열, 자연 생성 전리품은 금색 계열, 적대적 개체는 붉은 계열을 기본 구분색으로 사용한다.
- 여러 표시형 증강을 동시에 보유해도 대상 종류가 색으로 즉시 구분되게 한다.
- 표시 범위 밖 대상은 보이지 않으며, 표시 자체는 실제 월드 상태·광원·AI·어그로를 변경하지 않는다.

## 3. 방어 계산 원칙

기본 순서:
1. 원래 피해
2. Minecraft 갑옷 방어력 / 방어 강도
3. 보호 계열 인챈트
4. 증강의 일반 피해 감소
5. 조건부 / 속성별 증강 피해 감소
6. 최종 체력 피해

증강 피해 감소끼리는 단순 합산하지 않고 곱연산한다. 예: 상시 피해 10% 감소와 조건부 피해 20% 감소가 동시에 적용되면 `0.9 * 0.8 = 0.72`, 즉 총 28% 감소다.

## 4. 멀티플레이 / 서버 권한 원칙

- 피해, 드롭, 채굴, 낚시, 경험치, 인벤토리, 증강 획득/레벨, 기계 처리 등 중요한 결과는 서버가 최종 결정한다.
- 플레이어가 직접 수행한 행동은 그 행동을 수행한 플레이어의 증강 레벨만 적용한다. 다른 플레이어의 개인 증강을 합산하지 않는다.
- 공유 블록/기계에 영향을 주는 증강은 `누가 마지막으로 만졌는가` 같은 불안정한 판정을 사용하지 않는다. 각 증강마다 소유/범위/스냅샷 규칙을 명시한다.
- 주변 플레이어를 기준으로 작동하는 기계/오라형 효과가 여러 명에게서 겹칠 경우 기본값은 가장 높은 유효 레벨 하나만 적용하며 합산하지 않는다.
- 자동화(호퍼 등)는 특정 플레이어의 행동으로 간주하지 않는다.
- 멀티플레이 구조는 위 원칙으로 설계하지만 실제 멀티플레이 실테스트는 아직 하지 않았다. `MULTIPLAYER TESTED: NO`.

`연료 절약` 멀티 규칙:
- 연료를 누가 넣었는지로 판정하지 않는다.
- 화로/훈연기/용광로가 새 연료 1개를 실제로 소모해 연소를 시작하는 순간, 서버가 주변 8블록 안 플레이어 중 `연료 절약` 레벨이 가장 높은 한 명을 찾는다.
- 그 연료 1개의 연소시간에 해당 레벨 보너스를 스냅샷한다. 이후 플레이어가 멀어져도 이미 시작한 연료의 연소시간은 바뀌지 않는다.
- 주변에 해당 증강 보유자가 없으면 바닐라 연소시간을 사용한다. 호퍼 연료도 같은 규칙을 쓴다.

- 신규 휩쓸기 생성형 — 기존 휩쓸기/Better Combat 다중 타격과 중복. `휩쓸기 강화`로 대체.
- 공중 제어 — Minecraft 기본 공중 방향 전환 자유도가 이미 높아 체감 가치 부족.
- 넓게 놓기 — 3×3/5×5/7×7 광역 블록 설치. 조작 편의 이상의 재미가 부족해 폐기.

## 12. 아직 미확정 / 보류

아래는 과거에 이미 제안된 후보다. 사용자가 직접 재검토를 요청하지 않는 한 `다음` 목록에서 다시 출력하지 않는다.

- 불에 익숙함 — 화염/용암 피해 감소. 등급/수치 미확정.
- 가벼운 몸 — 점프 높이 증가. 등급/수치 미확정.
- 수리 습관 — 모루 경험치 비용 감소. 등급/수치 미확정.
- 발소리 죽이기 — 적대 몹 인식 거리 감소. 등급/수치 미확정.
- 사다리 타기 — 사다리/덩굴 상승 속도 증가. 등급/수치 미확정.
- 첫 타 — 체력이 가득 찬 적에게 가하는 첫 피해 증가. 등급/수치 미확정.
- 한 마리 더 — 물고기 낚시 시 추가 물고기 획득. 등급/수치 미확정.
- 빠른 장전 — 활 당기기/쇠뇌 장전시간 감소. 등급/수치 미확정.
- 뜨거운 곡괭이 — 제련 가능한 광석 드롭을 즉시 제련 결과로 변환. 등급 미확정.
- 광맥 채굴 — 연결된 동일 광석 추가 채굴. 등급/범위 미확정.
- 벽차기 — 벽을 이용한 추가 공중 이동. 등급/세부동작 미확정.
- 재빠른 손놀림 — 아이템 사용 준비시간 단축. 범위/등급 미확정.
- 경험 쌓기 — 획득 경험치 증가. Lv.5, 레벨당 +5% 제안.
- 노 젓기 — 조종 보트 속도 증가. Lv.3, 레벨당 +10% 제안.
- 해독력 — 해로운 상태효과 지속시간 감소. Lv.3, 레벨당 10% 제안.
- 약효 오래가기 — 이로운 상태효과 지속시간 증가. Lv.3, 레벨당 +10% 제안.
- 밭 돌보기 — 주변 작물 자연 성장 추가 진행 확률 15% / 30% / 45% 제안.
- 새끼 돌보기 — 주변 새끼 가축 성장 속도 +25% / +50% / +75% 제안.
- 불 지피기 — 주변 화로 처리 속도 +15% / +30% / +45% 제안.
- 방패 반격 — 완전 방어 후 다음 근접 공격 +20% / +40% / +60%, 4초 내 1회 제안.
- 몰아치기 — 같은 적 연속 근접 공격 시 타격당 +3% / +6% / +9%, 최대 5중첩 제안.
- 내려찍기 — 4블록 이상 낙하 착지 시 주변 피해. 블록당 0.5 / 0.75 / 1, 최대 10 / 15 / 20 제안.
- 철벽 — 방어력 +1/레벨, Lv.3 제안.
- 폭발 버티기 — 폭발 피해 15%/레벨 감소, Lv.3 제안.
- 밀어내기 — 가하는 넉백 +10%/레벨, Lv.3 제안.
- 처형 — 체력 25% 이하 적에게 +10% / +20% / +30% 피해 제안.
- 흡혈 — 적대 몹 처치 시 체력 1 / 2 / 3 회복 제안.
- 되받기 — 근접 피격 시 공격자에게 1 / 2 / 3 고정 피해 제안.
- 숨 돌리기 — 5초 비피격 후 자연회복 보조. 상세 미확정.
- 쇠붙이 줍기 — 철/금/구리 계열 드롭 추가 획득. 상세/중첩 미확정.
- 가벼운 방패 — 방패 사용 중 이동 페널티 완화. 실제 페널티/Better Combat 확인 필요.
- 치명타 강화 — 이미 치명타인 공격 피해 +10% / +20% / +30%. 등급 미확정.
- 동료 강화 — 전투 동료 최대체력 +20% / +40% / +60%, 공격피해 +10% / +20% / +30%. 등급 미확정.
- 손 제작 — 제작대 없이 인벤토리에서 3×3 제작. 등급 미확정.
- 넓게 캐기 — 영웅 후보. 자연 석재 3×3 채굴, 웅크리면 단일. 추가 블록 정상 드롭/내구도 50%. `연속 채굴`과는 주 채굴 1회=1중첩, `굴파기`와는 3×3 터널형 연계. 재귀 범위 발동 금지.
- 폭발 화살 — 영웅 후보. 최종 충돌에서 블록 파괴 없는 반경 2 / 2.5 / 3 폭발, 주변 피해 40% / 55% / 70%.
- 물약 이어마시기 — 동일 이로운 효과 지속시간 합산, 높은 단계 유지, 기본 지속시간 3배 상한.
- 직접 수납 — 희귀 후보. 직접/파생 채굴 최종 드롭을 인벤토리에 직행, 초과분만 바닥 드롭.
- 긴 공격 — 희귀 후보. 근접 공격거리 +0.25 / +0.50 / +0.75블록.
- 추적 화살 — 영웅 후보. 발사 시 전방 30°·12블록 목표를 잡고 매 tick 2° / 3° / 4° 방향 보정.
- 동료 구조 — 영웅 후보. 동료 치명타를 10초 쓰러짐으로 전환, 2초 상호작용 시 체력 30% 부활, 동료별 300초 쿨다운.
- 넓게 심기 — 희귀 후보. 작물 심기 시 3×3 / 5×5 / 7×7 범위를 실제 재배 재료를 소비해 함께 심고 웅크리면 단일 심기. `싹쓸이 수확`과 연계.
- 회피 — 영웅 후보. 이동 입력 방향 3 / 4 / 5블록 돌진, 0.20 / 0.25 / 0.30초 일반 피해 무적, 쿨다운 4 / 3 / 2초. 반응형 능력이라 확정 시 별도 전용키를 우선한다.
- 갈고리 — 영웅 후보. 낚싯바늘을 최대 24블록 내 고체 블록 면에 걸고 줄을 감아 플레이어를 당긴다.
- 짧은 순간이동 — 전설 후보. 시야가 닿는 안전한 위치로 최대 16블록 순간이동, 쿨다운 2초.
- 비행 — 신화 후보. Survival에서도 Creative식 자유 비행, 자원/시간/쿨다운 없음.

## 13. 이름 원칙

증강 이름은 짧고 기능이나 이미지가 바로 떠오르게 짓는다.

피한다:
- 과한 추상명사
- 의미 없이 거창한 판타지 조어
- `영겁`, `초월`, `운명의`, `심연의 파동`처럼 효과와 연결되지 않는 AI식 이름

고등급이라도 이름의 과장보다 실제 효과와 연출로 강함을 보여준다.

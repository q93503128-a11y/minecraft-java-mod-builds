# Augmentation Survival — Batch O Mythic Expansion / Missing Combat Staples

Date: 2026-10-23
Status: proposal only; user review pending

## 목적

현재 확정 120개, 신화 5개 기준에서 아직 비어 있는 고등급 전투 규칙과 신화 선택 폭을 보강한다.

과거 제안/보류/폐기와 의미가 겹치는 흡혈, 처형, 치명타 강화, 회피, 갈고리, 비행, 철벽, 방패 반격, 밀어내기 등은 이번 배치에서 제외한다.

신화는 현재 `시간 정지 / 공간 연결 / 풍요 / 순간 채굴 / 지배` 5개이므로, 이번 배치의 신화 3개가 전부 확정되면 총 8개가 된다.

## 신규 후보

### 영웅 — 강인한 정신 Lv.3

- 제거 가능한 일반 해로운 상태효과의 지속시간을 **33% / 66% / 100% 감소**한다.
- Lv.3에서는 독, 위더, 실명, 나약함, 구속 등 일반 제거 가능 해로운 효과에 사실상 면역이 된다.
- 보스 고유 기믹, 시스템성 상태, 명시적으로 제거 불가능한 효과는 대상에서 제외한다.
- 이미 적용된 효과와 신규 적용 효과 모두 서버가 유효 지속시간을 계산한다.

### 영웅 — 전투 순환 Lv.3

- 플레이어가 직접 피해로 적대적 개체를 처치할 때 현재 재사용 대기 중인 **모든 비신화 액티브 증강**의 남은 쿨다운을 **1 / 2 / 3초 감소**한다.
- 보스를 직접 처치하면 각각 **5 / 10 / 15초 감소**한다.
- 분신, 지배된 개체, 동료, 자동 피해가 대신 처치한 경우에는 발동하지 않는다.
- 남은 쿨다운은 0 미만으로 내려가지 않는다.
- `능력 가속`, `이중 충전`과 정상 연계한다.

### 신화 — 무적 Lv.1 (액티브)

- 발동 후 **8초 동안 모든 피해를 무시**한다.
- 활성 중 넉백을 받지 않고 새 제거 가능 해로운 상태효과도 적용되지 않는다.
- 플레이어는 이동, 공격, 채굴, 아이템 사용을 정상 수행할 수 있다.
- 환경 피해도 포함한다.
- 보스의 전투 종료/추방/특수 스크립트처럼 단순 피해가 아닌 월드 규칙은 막지 않는다.
- 재사용 대기시간 **90초**.

### 신화 — 재설정 Lv.1 (액티브)

- 발동 즉시 현재 보유한 모든 **비신화 액티브 증강**의 남은 재사용 대기시간을 0으로 만들고, 충전형 액티브는 최대 충전까지 복구한다.
- `이중 충전`으로 2회 충전을 저장하는 능력은 두 충전을 모두 복구한다.
- 신화 액티브에는 적용하지 않는다.
- `재설정` 자신의 쿨다운은 어떤 효과로도 재설정되지 않는다.
- 재사용 대기시간 **180초**.

### 신화 — 천벌 Lv.1 (액티브)

- 발동하면 플레이어 반경 **32블록** 안의 모든 적대적 개체를 동시에 타격한다.
- 일반 적대몹은 자신의 최대 체력의 **70%**에 해당하는 특수 피해를 받는다.
- 보스는 최대 체력의 **15%**에 해당하는 특수 피해를 받는다.
- 이 피해는 일반 방어구 수치를 무시하지만 보스 무적 페이즈, 피해 차단 기믹, 스크립트성 보호 상태는 존중한다.
- 플레이어/아군/중립 개체는 피해를 받지 않는다.
- 화재와 블록 파괴를 일으키지 않는다.
- 재사용 대기시간 **60초**.

# Augmentation Survival — Batch Q Proposal

Date: 2026-10-24
Status: proposal only / not canonical until user review

목표: 기존 130종과 과거 보류/폐기 의미를 다시 확인한 뒤, 단순 스탯 추가보다 기존 증강 여러 개의 가치와 빌드를 바꾸는 변환형/연계형 후보만 제안한다.

## 1. 육중한 일격 — 영웅 Lv.3

- 완전히 충전된 근접 ROOT 공격이 적중할 때 내부 재사용 대기 4초가 준비되어 있으면 추가 타격을 발생시킨다.
- 추가 피해는 자신의 현재 최대체력의 5% / 7.5% / 10%.
- `강건함`, `사냥 기록`, `거대화`처럼 최대체력을 키우는 증강이 공격력 빌드로도 연결된다.
- `유리 대포`의 체력 감소와는 자연스러운 trade-off가 생긴다.
- 추가 타격은 새로운 `육중한 일격`, `메아리 타격`, `벼락` 카운트를 생성하지 않는다.

플레이어-facing 초안:
`최대 체력이 높을수록 강해지는 육중한 공격을 주기적으로 가합니다.`
Shift 상세: `재사용 대기 4초 · 최대체력 계수 5% / 7.5% / 10%`

## 2. 생명 파동 — 영웅 Lv.3

- 자연회복이 아닌 효과로 실제 HP를 회복하면 반경 4블록 적대몹에게 회복량 기반 피해 파동을 낸다.
- 피해 계수: 실제 회복량의 100% / 150% / 200%.
- 대상당 1회 피해 상한: 10 / 15 / 20 HP.
- 실제 HP를 회복한 양만 사용하며 흡수 체력 생성량은 포함하지 않는다.
- `회복 증폭`, `치유 파동`, `흡혈`, 물약 회복과 연계한다.
- `회복 나눔`으로 생성된 공유 회복은 재귀 파동을 만들지 않는다.

플레이어-facing 초안:
`체력을 회복할 때 주변 적에게 생명력의 파동을 방출합니다.`
Shift 상세: `반경 4 · 회복량 계수 100% / 150% / 200% · 대상당 최대 10 / 15 / 20 피해`

## 3. 난전 — 영웅 Lv.3

- 반경 8블록 안의 적대몹 수에 따라 전투력이 증가한다.
- 적 1체당 직접 공격 피해 +3% / +5% / +7%.
- 적 1체당 받는 피해 감소 +2% / +3% / +4%.
- 최대 5체까지 계산.
- 최대 효과: 직접 공격 피해 +15% / +25% / +35%, 피해 감소 10% / 15% / 20%.
- `끌어당기기`, `연쇄 폭발`, 광역/연쇄 빌드와 자연스럽게 연결된다.
- 지배된 아군은 적대몹 수에 포함하지 않는다.

플레이어-facing 초안:
`주변의 적이 많을수록 더 강하고 단단해집니다.`
Shift 상세: `반경 8 · 최대 5체 · 적당 피해 +3/5/7%, 피해 감소 +2/3/4%`

## 4. 연장전 — 전설 Lv.1

- 플레이어 직접 처치가 발생하면 현재 실행 중인 **비신화 지속형 액티브**의 남은 지속시간을 1초 늘린다.
- 보스 직접 처치는 4초 연장한다.
- 한 번의 액티브 사용이 추가로 연장될 수 있는 총 시간은 그 능력의 기본 지속시간 50%까지.
- 집중/시전 준비시간은 연장하지 않는다.
- `광폭화`, `보호막`, `위상 이동`, `시간 가속`, `분신` 등 지속형 액티브 빌드를 처치 연쇄와 연결한다.
- 신화 액티브(`시간 정지`, `거대화` 등)는 대상에서 제외한다.
- `전투 순환`은 쿨다운을 줄이고 `연장전`은 현재 효과를 오래 유지하므로 역할이 다르며 함께 빌드할 수 있다.

플레이어-facing 초안:
`적을 처치하면 사용 중인 지속형 증강의 시간이 조금 늘어납니다.`
Shift 상세: `일반 처치 +1초 · 보스 처치 +4초 · 사용당 최대 +50%`

## 중복 검사 메모

- `육중한 일격`: `마지막 힘`, `우두머리 사냥`, `유리 대포`와 발동/스케일 축이 다르며 기존 보류 `처형/첫 타/몰아치기`와도 의미가 다르다.
- `생명 파동`: `회복 나눔`, `넘치는 회복`, `보호막 폭발`과 입력/출력이 다르다. 회복을 공격으로 변환하는 신규 축.
- `난전`: 주변 적 수를 직접 자원으로 사용하는 확정/보류 증강 없음.
- `연장전`: 확정 `전투 순환`은 재사용 대기 감소, 본 후보는 현재 지속시간 연장이라 서로 다른 축. 폐기 `재설정`의 즉시 쿨다운 초기화와도 다르다.

이 파일은 제안 기록이며 사용자 수정/폐기 후에만 `AUGMENTS.md` 정본에 반영한다.

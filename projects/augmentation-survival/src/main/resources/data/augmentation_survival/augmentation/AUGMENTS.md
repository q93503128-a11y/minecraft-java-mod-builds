Date: 2026-10-27

## 1. 공통 규칙

- 증강 총 보유 개수 제한은 없다.
- 증강마다 최대 레벨을 개별 지정한다.
- 최대 레벨에 도달한 증강은 같은 등급의 뽑기 후보 풀에서 제거한다.
- 후보 수가 부족할 때의 처리 규칙은 이미 `GAME_DESIGN.md`에 정한 기존 규칙을 그대로 따른다.
- 배타 관계는 전역 규칙으로 두지 않고 실제 충돌하는 조합에만 개별 적용한다.
- 증강끼리는 기본적으로 연계를 허용한다. 강한 조합이라는 이유만으로 임의 차단하지 않는다.
- 자동 생성된 2차 행동이 같은 범위/연쇄 생성 효과를 다시 발동해 무한 또는 기하급수적으로 커지는 경우만 재귀를 차단한다.
- 자동 채굴/자동 수확 같은 2차 행동도 가능한 한 드롭, Fortune, 자원 보너스, 제련 변환, 내구도 절약 등 호환 가능한 효과를 이어받는다.
- 인게임 카드에는 등급과 가능한 한 정확한 효과 수치를 표시한다.
- 플레이어에게 내부 카테고리(전투/채광/이동 등)는 표시하지 않는다.
- 신규 후보는 확정/폐기/보류뿐 아니라 과거에 한 번이라도 제안된 의미까지 확인한 뒤 제안한다.
- 사용자가 별도 폐기/보류를 말하지 않은 현재 Batch 후보는 통과로 처리한다.

### 동일 스탯 / 상호작용 계약

- 동일한 양의 퍼센트 스탯을 강화하는 **증강끼리는 합연산 후 한 번 적용**한다. 공격속도·이동속도·채굴속도 등에서 증강별 퍼센트를 서로 곱하지 않는다.
- 피해 감소는 기존대로 곱연산한다.
- ROOT/DERIVED 공격, 회복, 사망, 투사체, 쿨다운, 동료, 보스 제어, 도탄 비행 구간의 상세 계산 계약은 `AUGMENT_INTERACTION_CONTRACT_2026-10-24.md` V2를 정본으로 사용한다.
- `무적`으로 피해가 취소된 경우 실제 피격으로 보지 않으며 `피해 지연`, `피해 적응`, `다급한 발걸음` 같은 피격 기반 효과를 새로 발동하지 않는다.

### 액티브 표기 / 조작

- 액티브 증강은 이름 옆에 **`(액티브)`**를 명시한다.
- 토글형 액티브는 **`(액티브 · 토글)`**로 명시한다.
- 자동 발동/상시 효과는 액티브로 표기하지 않는다.
- 일반 액티브는 **증강 스킬 모드 키를 누르는 동안 숫자키 `1~0`**을 액티브 슬롯 `1~10`으로 사용한다.
- 평상시 `1~9`는 기존 핫바 선택을 그대로 유지한다.
- 액티브 슬롯은 보유 제한이 아니라 빠른 사용 슬롯이다.
- 배치는 인벤토리의 증강 탭 → `액티브 관리` 화면에서 편집한다.
- 쿨다운/지속시간은 슬롯이 아니라 능력 자체에 귀속한다.
- 대상 선택이 필요한 일부 액티브만 `탭=즉시 시전`, `홀드=프리뷰`, `릴리스=확정`을 사용한다.
- 유효 대상 없음/취소/서버 검증 실패 시 능력과 쿨다운을 소비하지 않는다.
- `회피` 같은 반응형 이동기는 확정 시 별도 전용키를 허용한다.
- 전용키는 Minecraft Controls에서 재지정 가능해야 하며 핵심 조작과 기본 충돌하지 않게 한다.
- `권능 탈취`는 일반 액티브 10칸이나 별도 장착 슬롯을 사용하지 않는다. 전용 권능 키 1개로 지금까지 탈취한 모든 보스 권능을 한 번에 해방한다.

### 카드 / 표시 UI

- 일반/고급/희귀: 등급색 변화 중심.
- 영웅: 등급색 + 약한 네온.
- 전설: 네온 + 카드 뒤 후광.
- 신화: 붉은색 중심 + 전설보다 명확히 강한 오오라.
- 표시형 증강은 큰 아이콘/이름표 난립보다 얇은 외곽선을 기본으로 한다.
- 광석 청록, 자연 전리품 금색, 적대몹 붉은색을 기본 구분색으로 사용한다.
- 설계 정본의 내부 계산/호환성 문구를 플레이어 카드에 그대로 노출하지 않는다. 실제 카드/툴팁 문체는 `HUD_AND_PLAYER_TEXT_STANDARD.md`를 따른다.
- 기본 툴팁은 짧게 유지하고 Shift 상세정보에서 레벨별 계수·범위·쿨다운·중첩·대상 수 등을 확장 표시한다.

### 피해 감소 계산

1. 원래 피해
2. Minecraft 갑옷 방어력 / 방어 강도
3. 보호 계열 인챈트
4. 증강의 일반 피해 감소
5. 조건부 / 속성별 증강 피해 감소
6. 최종 체력 피해

증강 피해 감소끼리는 단순 합산하지 않고 곱연산한다.

### 멀티플레이 / 서버 권한

- 피해, 드롭, 채굴, 낚시, XP, 인벤토리, 증강 획득/레벨, 기계 처리 등 중요한 결과는 서버가 최종 결정한다.
- 직접 행동은 행동한 플레이어의 증강만 적용한다.
- 공유 기계/오라 효과가 겹칠 때 기본값은 가장 높은 유효 레벨 하나다.
- 호퍼 등 자동화는 특정 플레이어 직접 행동으로 간주하지 않는다.
- `연료 절약`: 연료가 실제 소모되는 순간 반경 8블록 내 최고 레벨 보유자를 찾아 해당 연료 1개의 연소 보너스를 스냅샷한다.
- `MULTIPLAYER TESTED: NO`.

## 8. 폐기 / 대체 완료

아래 효과는 이름이나 수치만 바꿔 다시 제안하지 않는다.

- 재료 아끼기 — 설치 재료 미소모. 복제/악용 및 매력 부족.
- 손 빠른 농부 — 농사 상호작용 속도 증가. 체감 부족.
- 낚시꾼 — `낚시 감각`과 중복.
- 경험치 줍기 — `줍는 손`에 포함.
- 등짐 정리 — 자동 정리 편의만 남아 증강 가치 부족.
- 신규 휩쓸기 생성형 — `휩쓸기 강화`로 대체.
- 공중 제어 — 기본 공중 방향 전환 자유도가 높아 체감 부족.
- 넓게 놓기 — 대량 설치 편의 이상의 재미 부족.
- 교대 공격 — 조작 강제감 대비 재미 부족.
- 중력 역전 — Batch J에서 폐기.
- 반동 사격 — Batch K에서 폐기.
- 낚아채기 — Batch L에서 폐기.
- 사냥의 활력 — 확정 `흡혈`과 처치 회복 축 중복.
- 재설정 — 모든 비신화 액티브 쿨다운/충전 즉시 복구 효과 폐기.
- 해독력 — 상태효과 지속시간 감소 축이 확정 `강인한 정신`으로 대체됨.
- 생명 교환 — 체력 비율 교환형 신화 제안 폐기.
- 완전 숙련 — 일반~전설 즉시 최대레벨 성장 스킵 제안 폐기.
- 복제 — 손에 든 스택 가능 아이템 복제 제안 폐기.
- 수리 습관 — 모루 반복 작업 비용 증가 억제 의미가 확정 `금단의 마법`에 흡수됨.
- 절단 — 64블록 지형/적 동시 절단 신화 제안 폐기.
- 피의 대가 — 최대체력을 일시 봉인해 쿨다운 중 액티브를 강제 재사용하는 제안 폐기.

## 9. 설계 확정 / 런타임 구현 대기

아래 후보는 **보류가 아니다**. 별도 폐기/보류 지시가 없었던 Batch 후보로서 설계상 통과 상태다. 다만 구현 상태와 설계 확정 상태는 분리한다. 실제 런타임 코드·데이터·검증이 완료되기 전에는 코어 후보 풀에 노출하지 않는다.

- 불에 익숙함 — 화염/용암 피해 감소.
- 가벼운 몸 — 점프 높이 증가.
- 발소리 죽이기 — 적대몹 인식 거리 감소.
- 사다리 타기 — 사다리/덩굴 상승 속도 증가.
- 첫 타 — 체력이 가득 찬 적 첫 피해 증가.
- 한 마리 더 — 물고기 낚시 시 추가 물고기.
- 빠른 장전 — 활 당기기/쇠뇌 장전시간 감소.
- 뜨거운 곡괭이 — 제련 가능한 광석 드롭 즉시 제련.
- 광맥 채굴 — 연결된 동일 광석 추가 채굴.
- 벽차기 — 벽을 이용한 추가 공중 이동.
- 재빠른 손놀림 — 아이템 사용 준비시간 단축.
- 경험 쌓기 — 획득 경험치 증가.
- 노 젓기 — 조종 보트 속도 증가.
- 약효 오래가기 — 이로운 상태효과 지속시간 증가.
- 밭 돌보기 — 주변 작물 성장 보조.
- 새끼 돌보기 — 주변 새끼 가축 성장 가속.
- 불 지피기 — 주변 화로 처리 속도 증가.
- 방패 반격 — 완전 방어 후 다음 근접 공격 강화.
- 몰아치기 — 같은 적 연속 근접 공격 누적 강화.
- 내려찍기 — 낙하 착지 주변 피해.
- 철벽 — 방어력 증가.
- 폭발 버티기 — 폭발 피해 감소.
- 밀어내기 — 가하는 넉백 증가.
- 처형 — 저체력 적 추가 피해.
- 되받기 — 근접 피격 시 공격자 고정 피해.
- 숨 돌리기 — 일정 시간 비피격 후 회복 보조.
- 쇠붙이 줍기 — 철/금/구리 계열 추가 드롭.
- 가벼운 방패 — 방패 사용 중 이동 페널티 완화.
- 치명타 강화 — 이미 치명타인 공격 피해 증가.
- 동료 강화 — 전투 동료 체력/공격 강화.
- 손 제작 — 제작대 없이 3×3 제작.
- 넓게 캐기 — 자연 석재 3×3 채굴.
- 폭발 화살 — 충돌 시 블록 비파괴 폭발 화살.
- 물약 이어마시기 — 동일 이로운 효과 지속시간 합산.
- 직접 수납 — 직접/파생 채굴 드롭 인벤토리 직행.
- 긴 공격 — 근접 공격거리 증가.
- 넓게 심기 — 실제 재배 재료를 소비한 광역 심기.
- 회피 — 방향 돌진 + 짧은 무적.
- 갈고리 — 낚싯바늘 블록 고정 후 플레이어 당김.
- 짧은 순간이동 — 시야 내 안전 위치 16블록 순간이동.
- 예비 도구 — 도구 파괴 시 인벤토리 동일 유형 자동 교체.
- 고지대 우위 — 상대보다 높은 위치에서 투사체 피해 증가.
- 상태 확산 — 처치한 적의 해로운 효과를 주변 적에게 확산.
- 공중 작업 — 공중 채굴 페널티 완화.
- 횃불 던지기 — 실제 횃불을 원거리 유효 면에 배치.
- 미끄러지기 — 질주+웅크리기 슬라이드 및 관성 점프.
- 급제동 — Elytra 감속/제동.
- 도발 — 적대몹 어그로를 능동 제어.
- 마법 추출 — 숫돌을 통해 제거 가능한 인챈트 하나를 책으로 이동.
- 최적 도구 — 채굴 시 핫바의 가장 빠른 적합 도구 자동 선택/복귀.
- 광차 질주 — 자신이 탄 일반 광차 최고 속도 강화.
- 수선 배분 — XP 오브가 메인 인벤토리 수선 장비까지 수리하고 손상률 우선 분배.
- 마법 미리보기 — 마법부여대 3선택의 실제 인챈트/레벨 사전 표시.
- 탐색 나침반 — 등록 구조물 검색 UI 및 최근 탐색 캐시.

## 10. 남은 전역 튜닝 파라미터

현재 **149종 런타임 로스터**의 구현 계약은 실제 코드·데이터를 최종 기준으로 한다. 9절의 추가 설계 확정 후보군은 런타임 구현·검증을 마치기 전 코어 후보 풀에 노출하지 않는다. 아래는 별도 시스템 차원의 플레이테스트/밸런스 튜닝 대상이다.

- 코어 획득처별 정확한 등급 확률
- 위협 단계 최종 수치 튜닝

## 11. 이름 원칙

증강 이름은 짧고 기능이나 이미지가 바로 떠오르게 짓는다.

피한다:
- 과한 추상명사
- 의미 없이 거창한 판타지 조어
- `영겁`, `초월`, `운명의`, `심연의 파동`처럼 효과와 연결되지 않는 AI식 이름

고등급이라도 이름의 과장보다 실제 효과와 연출로 강함을 보여준다.

## Batch 2026-10-23-E — 사용자 수정/확정 방향

- `경험 보존`: Minecraft Java 기본 규칙에서 `keepInventory=false`일 때 사망 시 경험치 대부분을 실제로 잃으므로 유지. 보존분과 사망 오브가 경험치를 복제하지 않도록 나머지 풀에서만 바닐라 사망 오브 상한을 적용한다. `keepInventory=true`이면 후보 풀에서 제외. 이후 수치를 **30% / 60% / 100%**로 상향 확정.
- `연쇄 화살`: 첫 연쇄 대상 피해를 원래 적중 피해의 100%로 상향. 두 번째부터 직전 연쇄 피해의 75%씩 감소.
- `귀환`: 등급을 영웅으로 내림. 전용 configurable key mapping으로 발동하며 5초 집중 구조는 유지. 재사용 대기시간 제거. 이동·공격·아이템 사용·피격 시 집중 취소.
- 전용 능력 기본키는 공식 모드팩 전체 key mapping을 확인해 이동·점프·웅크리기·질주·인벤토리·공격/사용·드롭·손 바꾸기·핫바 같은 중요 조작과 겹치지 않게 정한다. 비중요 키는 필요하면 사용할 수 있고 Controls에서 항상 재지정 가능해야 한다.
- `원격 창고`: Ender Chest 재사용안을 폐기하고 증강 전용 서버 저장 배낭으로 재설계. 개인 보유자마다 UUID 귀속 27칸(9×3) 세그먼트를 가진다. 인벤토리 UI에 원격 창고 탭/루트를 추가한다. 공유 기본 OFF, 명시적 공유 그룹 참가/허용 시 각 보유자의 27칸 세그먼트를 하나의 9열 논리 창고로 이어 붙인다. 총 용량은 `27×공유 보유자 수`. 보유자가 오프라인이어도 공유 허용 상태면 해당 세그먼트는 사용 가능. 공유 해제/그룹 이탈 시 소유자의 세그먼트와 내용물이 그대로 개인 창고로 분리되어 손실·복제가 없다. 여러 플레이어 동시 접근 허용, 모든 슬롯 변경은 서버 권한으로 동기화. 한 화면 최대 6행(54칸), 그 이상은 세로 스크롤.
- `직접 수납`, `긴 공격`, `추적 화살`, `동료 구조`: 별도 확정 지시가 없어 기존 제안 이력에 보류 유지.

- `공간 연결`: 신화 유지. **1쌍 제한을 폐기하고 여러 공간문을 영구 등록하는 네트워크형**으로 변경. 각 공간문은 이름/차원/좌표/접근권한을 서버 저장하며, 목적지가 여러 개면 전용 목적지 선택 UI에서 이름·차원·좌표를 보고 선택한다. 즐겨찾기/정렬/검색, 공간문별 기본 목적지, 이름 변경, 공유 설정, 제거를 관리 화면에서 지원한다. 거리/차원 제한과 이동 자원/쿨다운은 없고 탑승 탈것·길들인 동료 동반 이동과 목적지 안전성은 서버가 처리한다. 디자인상 공간문 수량을 한 쌍으로 제한하지 않는다.

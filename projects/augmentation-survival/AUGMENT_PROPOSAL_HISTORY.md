## Batch 2026-10-23-C — 사용자 수정/확정 방향

- `연속 채굴`: 중첩당 증가량을 레벨당 3%로 조정. Lv.1/2/3에서 중첩당 +3% / +6% / +9%, 최대 5중첩에서 +15% / +30% / +45%.
- `싹쓸이 수확`: 주변 작물 연쇄 수확 후 자동 재파종. 정상 드롭 중 재배 재료 1개를 소비.
- `관통 화살`: 관통 시 다음 대상 피해 감소율 10% / 5% / 0%.
- `휩쓸기`: 신규 공격 생성형 폐기, 기존 휩쓸기 범위·각도·보조 대상 피해 강화형으로 재설계.
- `한 번 버티기`: 치명타 방지 후 체력 1, 1초 완전 무적, 180초 쿨다운.
- `먹으면서 걷기`, `상자 찾기`, `두 번 점프`, `물 위 달리기`: 최초 제안 유지.

## Batch 2026-10-23-E — 사용자 수정/확정 방향

- `경험 보존`: Minecraft Java 기본 규칙에서 `keepInventory=false`일 때 사망 시 경험치 대부분을 실제로 잃으므로 유지. 보존분과 사망 오브가 경험치를 복제하지 않도록 `보존 XP=floor(총 XP×비율)`, 나머지 풀에서만 바닐라 사망 오브 상한을 적용한다. `keepInventory=true`이면 후보 풀에서 제외.
- `연쇄 화살`: **첫 연쇄 대상 피해를 원래 적중 피해의 100%**로 상향. 두 번째부터 직전 연쇄 피해의 75%씩 감소.
- `귀환`: 등급을 **영웅**으로 내림. 전용 configurable key mapping으로 발동하며 5초 집중 구조는 유지. **재사용 대기시간 제거**. 이동·공격·아이템 사용·피격 시 집중 취소. 기본키는 H를 우선하되 공식 모드팩 키 충돌 확인 후 조정 가능.
- `원격 창고`: Ender Chest 재사용안을 폐기하고 **증강 전용 서버 저장 배낭**으로 재설계. 개인 보유자마다 UUID 귀속 27칸(9×3) 세그먼트를 가진다. 인벤토리 UI에 원격 창고 탭/루트를 추가한다. 공유 기본 OFF, 명시적 공유 그룹 참가/허용 시 각 보유자의 27칸 세그먼트를 하나의 9열 논리 창고로 이어 붙인다. 총 용량은 `27×공유 보유자 수`. 보유자가 오프라인이어도 공유 허용 상태면 해당 세그먼트는 사용 가능. 공유 해제/그룹 이탈 시 소유자의 세그먼트와 내용물이 그대로 개인 창고로 분리되어 손실·복제가 없다. 여러 플레이어 동시 접근 허용, 모든 슬롯 변경은 서버 권한으로 동기화. 한 화면 최대 6행(54칸), 그 이상은 세로 스크롤.
- `직접 수납`, `긴 공격`, `추적 화살`, `동료 구조`: 이번 응답에서는 별도 확정 지시가 없어 기존 제안 이력에 보류 유지.

## 3. 신규 제안 규칙

사용자가 `다음`이라고 하면:

- `AUGMENTS.md`의 확정/폐기/보류 전부 확인
- `AUGMENT_PROPOSAL_HISTORY.md`의 과거 제안 전부 확인
- **한 번이라도 이미 제안된 효과와 의미가 겹치는 후보를 다시 내지 않는다**
- 이름만 바꾼 의미 중복도 금지
- 각 후보에 추천 등급, 최대 레벨, **레벨별 정확한 수치**를 반드시 제시
- 사용자 승인/수정 후 즉시 `AUGMENTS.md`에 정본 반영
- 제안/변경 이력도 `AUGMENT_PROPOSAL_HISTORY.md`에 남긴다
- 문서만 바뀐 경우 build/CI는 돌리지 않는다

증강끼리는 기본적으로 연계를 허용한다. 강한 조합 자체를 이유로 막지 않는다. 자동 생성된 2차 행동이 같은 범위/연쇄 생성 효과를 다시 호출해 무한/기하급수 재귀가 생길 때만 재귀 발동을 차단한다.

## 4. 액티브 증강 UX 정본

일반 액티브는 **증강 스킬 모드 키 + 숫자키 `1~0`**으로 10개 빠른 슬롯을 사용한다.

- 평상시 `1~9`는 Minecraft 핫바 그대로
- 스킬 모드 키를 누른 동안만 `1~0`이 액티브 슬롯 1~10으로 전환
- 액티브 보유 개수 제한이 아니라 빠른 슬롯만 10개
- 설정 메뉴에서 장착하지 않는다
- 인벤토리의 증강 탭 → `액티브 관리` 전용 화면에서 보유 액티브와 10칸 슬롯을 드래그/클릭해 장착·해제·순서 변경
- 쿨다운/지속시간은 슬롯이 아니라 능력 자체에 귀속. 위치 변경으로 초기화 불가
- 반응형 이동기인 `회피` 같은 능력은 별도 전용키 허용
- 핵심 Minecraft 조작키와 기본키 충돌 금지

### 선택형 액티브의 탭/홀드 방식

모든 액티브에 강제하지 않는다.

대상 선택이나 범위 미리보기가 실제로 의미 있는 액티브만:

- 짧게 누르기 → 현재 유효 대상에 즉시 시전
- 길게 누르기 → 대상/범위 프리뷰
- 홀드 중 얇은 외곽선 또는 월드 프리뷰 표시
- 시선을 옮기면 선택 대상 갱신
- 키를 놓으면 현재 프리뷰 대상으로 확정
- 대상 없음/취소/서버 유효성 실패 → 능력·쿨다운 미소비

`자리 바꾸기`가 대표 적용 사례다.

## 5. Batch I 최종 결정 — 93~100번째 확정 증강

### 희귀 — 진주 숙련 Lv.3

- 엔더 진주 순간이동 자해 피해 감소: **50% / 75% / 100%**
- 엔더 진주 재사용 대기시간 감소: **15% / 30% / 45%**

### 고급 — 길들이기 요령 Lv.3

- 길들이기 시 원래 성공 확률 배율: **x1.25 / x1.50 / x2.00**
- 최종 확률 100% 상한
- 아이템 소비 정상

### 영웅 — 약점 표식 Lv.3

- 같은 적을 5초 안에 직접 공격 3회 적중 → 6초 표식
- 표식 대상이 시전자와 같은 팀/공유 그룹 플레이어·전투 동료에게 받는 피해:
  - Lv.1 +8%
  - Lv.2 +12%
  - Lv.3 +16%
- 추가 직접 적중 시 지속시간 갱신

### 영웅 — 자리 바꾸기 Lv.1

- 시야가 닿는 24블록 이내 살아 있는 비플레이어 개체와 위치 교환
- 보스도 가능
- 플레이어 강제 교환은 기본 제외
- 짧게 누르면 현재 조준 대상과 즉시 교환
- 길게 누르면 유효 대상 외곽선 표시 → 시선으로 선택 → 손을 떼면 교환
- 양쪽 위치 안전성을 서버가 검사
- 실패/취소 시 쿨다운 없음
- 성공 쿨다운 **8초**

### 영웅 — 보호막 Lv.3

- 지속 8초
- 별도 보호막 HP: **8 / 12 / 16**
- 보호막이 피해를 먼저 흡수
- 쿨다운: **24 / 20 / 16초**
- 치유/흡수체력으로 취급하지 않음

### 전설 — 시간 가속 Lv.1

- **3초 집중 시전** 후 발동
- 집중 중 이동/공격/아이템 사용/피격 시 취소, 실패 시 쿨다운 없음
- 지속시간 **20초**
- 이동속도 +60%
- 공격속도 +60%
- 채굴속도 +60%
- 음식/물약 등 아이템 사용속도 +40%
- 자신이 발사한 투사체 속도 +40%
- 세계/다른 개체의 시간은 그대로
- 성공 쿨다운 45초

### 전설 — 분신 Lv.1

- 지속 20초
- 자율 전투 분신 1체 소환
- 분신 최대체력 = 발동 시 플레이어 최대체력의 50%
- 직접 공격 피해 = 발동 순간 플레이어 무기/장비/인챈트 스냅샷 기준 60%
- **서버 AI가 스스로 적을 탐색·추적하고 자동으로 싸운다**
- 복제한 무기 유형에 맞춰 근접/원거리 전투
- 장비 외형 복제
- 원본 아이템 내구도/탄약 소비 없음
- 드롭 증가, XP/처치 보상, 증강 연쇄 보상 트리거 생성 금지
- 쿨다운 60초

### 신화 — 공간 연결 Lv.1

기존 `공간문 한 쌍` 제한은 폐기했다.

- 플레이어가 여러 공간문을 영구 등록해 **다중 공간문 네트워크** 구성
- 거리 제한 없음
- 차원 제한 없음
- 이동 자원 소모 없음
- 이동 쿨다운 없음
- 각 공간문에 이름 지정 가능
- 서버가 소유자 UUID/차원/좌표/접근권한 저장
- 접근 가능한 목적지가 하나면 바로 이동 가능
- 여러 개면 전용 목적지 선택 UI 표시
- 목적지 UI에 이름·차원·좌표 표시
- 즐겨찾기 / 정렬 / 검색 지원
- 공간문별 기본 목적지 설정 가능
- 관리 화면에서 이름 변경 / 기본 목적지 / 공유 설정 / 제거
- 개인/공유 접근 지원
- 탑승 탈것과 길들인 동료 동반 이동
- 목적지 청크/충돌/바닥 안전성은 서버 검증
- 디자인상 한 쌍/소수 개수로 강제 제한하지 않는다. 성능 보호가 필요하면 진행 제한이 아니라 서버 설정/데이터 관리 문제로 처리한다.

## 6. 현재 신화 기준

신화는 단순히 숫자가 큰 능력이나 편리한 액티브가 아니다.

현재 확정 신화:

   - 일반 적대몹/보스/적대 투사체 모두 9초 완전 정지
   - 플레이어와 아군은 정상 행동
   - 정지 대상 공격 가능
   - 쿨다운 60초

2. `공간 연결`
   - 거리/차원을 사실상 무시하는 영구 다중 공간문 네트워크

앞으로 신화는 **게임의 전투·이동·월드 규칙을 상위 수준에서 바꾸는 효과**를 우선한다. `되감기`는 강하지만 이 기준에는 부족하다고 판단해 전설로 내렸다.

## 7. 중요한 현재 시스템 규칙

### 죽음 관련

- `경험 보존` 희귀 Lv.3: 총 XP 30% / 60% / 100% 보존
- `소지품 보존` 영웅 Lv.1: 전체 소지품 유지, XP는 별도
- `한 번 버티기`: 치명 피해를 1HP로 버티고 1초 일반 피해 무적, 180초 쿨
- `비상 토템`: 손에 없어도 인벤토리 토템 자동 사용, `한 번 버티기` 우선

### 방어 계산

`원피해 → 갑옷/방어강도 → 보호 인챈트 → 증강 일반 DR → 조건/속성 DR → 최종 체력 피해`

증강 DR끼리는 곱연산.

### 피해 지연

- 영웅 Lv.3
- 최종 피해의 20% / 30% / 40% 예약
- 10초 동안 2초마다 총 5회 분할
- 이미 최종 피해에서 떼어낸 값이므로 방어 계산 재적용 금지
- 분할 피해 재지연 금지

### 넘치는 회복

허기·포만도 기반 자연회복은 흡수 체력 전환 대상이 아니다. `회복력`으로 빨라진 자연회복도 제외한다.

### 표시형

- 광석: 청록 외곽선
- 자연 전리품: 금색 외곽선
- 적대 개체: 붉은 외곽선
- 이름표/큰 아이콘 난립 금지

### 채광 연계

- 증강끼리 기본 연계
- `넓게 캐기 × 연속 채굴`: 범위 채굴 1회 = 연속 채굴 1중첩
- `넓게 캐기 × 굴파기`: 3×3 터널형 연계 우선
- 자동 생성 블록이 다시 범위 효과를 재귀 발동하는 것만 차단

## 사용자 결정

### 영웅 — 벼락 Lv.3

- 모든 직접 공격의 적중 카운트를 서버가 관리한다.
- 발동 주기를 최초안의 전 레벨 4타 고정에서 **Lv.1 = 4타마다 / Lv.2 = 3타마다 / Lv.3 = 2타마다**로 강화한다.
- 발동 시 적중 대상을 시작점으로 반경 7블록 안 아직 맞지 않은 적대적 개체 최대 **2 / 3 / 4명**에게 연쇄 번개 피해를 준다.
- 각 연쇄 대상은 발동을 일으킨 최초 적중 대상이 실제로 받은 피해의 **50% / 65% / 80%**를 별도 번개 피해로 받는다.
- 블록 화재/블록 파괴는 만들지 않는다.
- 연쇄 피해는 `벼락` 적중 카운트, 자체 연쇄, 다른 직접 공격 판정으로 다시 처리하지 않는다.
- 상태: **수정 확정**.

### 영웅 — 메아리 타격 Lv.3

- 완전히 충전된 근접 공격을 같은 적에게 연속 적중시킬 때 발동한다.
- 발동 주기를 최초안의 전 레벨 3타 고정에서 **Lv.1 = 3타마다 / Lv.2 = 3타마다 / Lv.3 = 2타마다**로 강화한다.
- 발동 조건을 만족한 공격 0.25초 뒤 같은 대상에게 추가 타격을 가한다.
- 추가 타격 원피해는 발동 공격의 원피해 스냅샷 기준 **50% / 75% / 100%**.
- 대상의 갑옷·보호·피해감소 계산은 추가 타격에도 정상 적용한다.
- 추가 타격은 `메아리 타격`을 다시 발동하지 않고, 휩쓸기·치명타·별도 투사체 생성 같은 공격 이벤트를 복제하지 않는다.
- 상태: **수정 확정**.

### 전설 — 이중 충전 Lv.1

- 최초 제안 등급 `신화`에서 **전설**로 조정한다.
- 재사용 대기시간을 가진 모든 **비신화 액티브 증강**이 최대 2회분의 충전을 저장할 수 있다.
- 능력 사용 시 충전 1개를 소비하며, 충전이 남아 있으면 같은 능력을 즉시 다시 사용할 수 있다.
- 각 충전은 해당 능력의 원래 재사용 대기시간에 따라 하나씩 회복한다.
- 쿨다운이 없는 능력, 토글형 능력, 사망당 1회처럼 별도 횟수 규칙을 쓰는 능력은 적용 대상에서 제외한다.
- 신화 액티브는 적용 대상에서 제외한다.
- `능력 가속`이 나중에 확정될 경우 각 충전의 회복시간에도 정상 적용한다.
- 상태: **등급 수정 확정**.

# Augmentation Survival — Batch R Decisions / Mythic Redesign

Date: 2026-10-24
Status: final through authority / forbidden-magic decisions

## 사용자 결정 반영

### 폐기 — 생명 교환

- `생명 교환`은 폐기한다.
- 체력 비율 교환이라는 의미를 이름/수치만 바꿔 다시 제안하지 않는다.

### 확정 — 영역 가속 Lv.2 — 전설 (액티브)

- 최대 Lv: 2.
- 30초 동안 반경 24블록의 호환 가능한 작물·묘목·가축 성장과 생산/처리 속도를 가속한다.
- Lv.1: ×3.
- Lv.2: ×7.
- 화로·훈연기·용광로·양조 등 호환 가능한 생산 블록을 포함한다.
- 적 AI, 플레이어 행동속도, 월드 시간대 자체는 가속하지 않는다.
- 쿨다운 120초.
- 정확한 호환 목록은 데이터/adapter 기반으로 관리한다.
- 플레이어-facing 설명에는 내부 호환 구현 문구를 노출하지 않는다.

### 확정 — 두 번째 선택 Lv.1 — 신화

- 코어 1개를 사용해 나온 3개 후보 중 서로 다른 2개를 선택할 수 있다.
- 코어 소비량은 1개 그대로다.
- 모든 등급 코어에 적용한다.
- 후보 부족 시 `GAME_DESIGN.md`의 기존 후보 부족 규칙을 따른다.
- 증강 획득 규칙 자체를 깨는 신화급 효과로 유지한다.

### 폐기 — 완전 숙련

- 현재 보유/향후 획득 일반~전설 증강을 즉시 최대 레벨로 만드는 제안은 폐기한다.
- 장기 서바이벌의 수집/성장 루프를 통째로 생략하므로 이름/수치만 바꿔 다시 제안하지 않는다.

### 기존 보류 유지 — 비행

- `비행 — Survival Creative식 자유 비행`은 이미 과거 보류 목록에 존재한다.
- 신규 후보처럼 다시 제안하지 않는다.
- 사용자가 직접 보류안 재검토를 요청하기 전까지 보류 상태를 유지한다.

### 폐기 — 복제

- 손에 든 스택 가능 아이템을 복제하는 제안은 폐기한다.
- 단순 자원 복제 의미를 이름/수치만 바꿔 다시 제안하지 않는다.

## 확정 — 권능 탈취 Lv.1 — 신화

`권능 탈취`는 **권능 하나를 골라 장착하는 시스템이 아니다.**

지원 대상 보스를 쓰러뜨릴수록 그 보스의 전투 기술 묶음이 영구 누적되고, 전용 권능 키를 한 번 누르면 지금까지 탈취한 **모든 보스의 전투 권능을 한 번의 종결기처럼 전부 방출**한다.

### 핵심 구조

- 플레이어가 서로 다른 **지원 대상 보스 프로필을 처음 직접 처치할 때**, 그 보스의 플레이어용 `권능 패키지` 전체를 영구 해금한다.
- 한 보스의 권능 패키지는 대표 기술 하나가 아니라, 플레이어에게 옮길 수 있는 그 보스의 **의미 있는 전투 스킬 전체**를 포함한다.
- 페이즈 전환, 보스 무적 스크립트, 월드 진행 변경, 구조물 파괴처럼 보스 시스템 자체에 해당하는 요소는 스킬로 복제하지 않는다.
- 획득한 권능을 선택하거나 장착하지 않는다.
- 별도 권능 슬롯도 사용하지 않는다.
- 일반 증강 액티브 10칸을 사용하지 않는다.
- **전용 권능 키 1개**만 사용한다.
- 권능 키를 누르면 지금까지 해금한 모든 보스 권능 패키지가 하나의 `권능 해방` 시퀀스로 발동한다.
- 글로벌 재사용 대기시간은 **120초**로 한다.
- 해금한 보스 수가 늘수록 한 번의 권능 해방에 포함되는 기술 수와 위력이 실제로 늘어난다.

### 발동 / 연출 구조

플레이어 입장에서는 버튼 한 번으로 모든 권능이 한꺼번에 발동하는 종결기다.

구현에서는 서버/클라이언트 부하를 막기 위해 모든 기술을 같은 game tick에 생성하지 않고, 하나의 발동으로 묶인 **짧은 연속 시퀀스**로 스케줄한다.

- 발동 입력은 한 번만 받는다.
- 발동 중 플레이어의 일반 이동/공격을 불필요하게 잠그지 않는다.
- 공격형, 광역형, 투사체형, 소환형, 일시 강화형 등 권능의 성격을 유지한다.
- 대상 지정이 필요한 기술은 현재 조준 대상 또는 시야/범위 내 적을 사용하도록 각 권능 패키지에서 정의한다.
- 해금 기술 수가 많아져도 한 tick 폭발 생성량에 내부 예산을 두어 서버를 멈추게 하지 않는다.
- 이 실행 예산은 성능을 위한 스케줄링일 뿐, 해금한 권능을 생략하거나 횟수를 줄이는 밸런스 제한으로 사용하지 않는다.

### 구현 계약

- 보스 원본 AI/스크립트를 런타임에 그대로 복사하지 않는다.
- `boss profile -> authority package -> player-safe skills[]` 구조로 데이터/코드 어댑터를 둔다.
- 같은 보스의 페이즈별 엔티티나 변신체가 중복 권능으로 등록되지 않도록 entity type보다 안정적인 `bossProfileId`를 사용한다.
- Chrono Dawn / World Bosses / MCEndgame 등 공식 팩 보스부터 패키지를 작성한다.
- 외부 보스는 profile/adapter를 추가해 확장한다.
- 각 보스 스킬은 원본의 테마, 범위, 연출, 전투 정체성이 느껴지도록 플레이어용으로 재구성한다.
- 권능 피해/소환/상태효과는 서버가 최종 판정한다.
- 권능으로 생성된 파생 공격은 기본적으로 `ACTIVE_SPECIAL` 계열로 처리하여 자기 자신을 재귀 발동시키지 않는다.

### 플레이어-facing 방향

기본 카드:
`쓰러뜨린 우두머리의 권능을 빼앗습니다. 권능을 해방하면 지금까지 빼앗은 모든 힘을 한꺼번에 쏟아냅니다.`

Shift 상세:
- `해금: 지원 우두머리 최초 처치`
- `해방: 탈취한 모든 우두머리 권능 발동`
- `재사용 대기시간: 120초`
- 현재 탈취한 우두머리 수

adapter/스크립트/실행 예산 같은 개발 정보는 표시하지 않는다.

### 신화로 유지하는 이유

- 신화 하나가 `보스 사냥 -> 권능 패키지 수집 -> 종결기 성장`이라는 독립적인 후반 루프를 연다.
- 새 보스를 잡을 때마다 버튼 하나의 실제 성능과 연출이 계속 커진다.
- 액티브 슬롯 관리 노동을 늘리지 않으면서도 보스 콘텐츠 전체를 성장 자원으로 바꾼다.
- 단순 수치 상승이 아니라 플레이어가 세계의 보스 능력을 누적해 사용하는 새로운 전투 체계를 만든다.

## 확정 — 금단의 마법 Lv.1 — 전설

신화 제안에서 **전설**로 하향한다.

### 효과

- 모루에서 정상적으로 서로 배타적인 호환 인챈트를 같은 장비에 함께 부여할 수 있다.
- 해당 플레이어에게 모루의 `Too Expensive` 제한을 제거한다.
- 같은 장비를 반복해서 모루에서 작업해도 vanilla prior-work 페널티 때문에 요구 경험치가 계속 상승하지 않는다.
- 즉, **반복 작업 횟수 자체가 경험치 비용을 올리지 않는다.**
- 실제로 붙이는 인챈트/수리 재료에서 발생하는 기본 작업 비용까지 0으로 만드는 것은 아니다.
- 인챈트 최대레벨 자체를 자동으로 높이지 않는다. 최대레벨 초과 효과는 기존 `마법 공명` 역할을 유지한다.
- 기술적으로 동시 적용 시 실제 기능 충돌이 나는 외부 인챈트 조합만 데이터 기반 hard-conflict 예외로 둔다.

### 플레이어-facing 방향

`서로 양립할 수 없던 마법을 하나의 장비에 새길 수 있습니다. 모루를 반복해서 사용해도 작업 비용이 더 비싸지지 않습니다.`

Shift 상세:
- `상호 배타 인챈트 조합 허용`
- `Too Expensive 제거`
- `반복 작업 비용 증가 없음`

개발용 hard-conflict 목록은 인게임에 표시하지 않는다.

## 현재 확정 분포

Batch Q까지 134종에서 다음 4종을 추가 확정한다.

- 영역 가속 — 전설
- 두 번째 선택 — 신화
- 권능 탈취 — 신화
- 금단의 마법 — 전설

따라서:

- 일반 20
- 고급 27
- 희귀 29
- 영웅 34
- 전설 19
- 신화 9
- 총 **138**

## 신화 설계 기준

신화는 단순히 높은 수치의 영웅/전설이 아니다.

다음 중 최소 하나를 만족하는 종결급 효과를 우선한다.

1. Minecraft의 기본 행동 규칙을 영구적으로 바꾼다.
2. 증강 획득/성장 규칙 자체를 바꾸되 기존 성장 과정을 삭제하지 않는다.
3. 기존 시스템 여러 개의 가치/플레이 루프를 새롭게 연결한다.
4. 획득 순간 이전까지 불가능했던 플레이 방식을 연다.
5. 별도 후반 목표나 콘텐츠 루프를 만들어낸다.

단순 큰 수치, 단순 자원 복제, 기존 보류 후보 재포장, 성장 스킵은 신화 후보에서 제외한다.

Docs/design only. Build/CI not run.

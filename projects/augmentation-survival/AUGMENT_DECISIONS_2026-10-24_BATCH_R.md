# Augmentation Survival — Batch R Decisions / Mythic Redesign

Date: 2026-10-24
Status: final through authority / forbidden-magic decisions

## 사용자 결정 반영

### 폐기 — 생명 교환

- `생명 교환`은 폐기한다.
- 체력 비율 교환이라는 의미를 이름/수치만 바꿔 다시 제안하지 않는다.

### 확정 — 영역 가속 Lv.2 — 전설 (액티브)

- 최대 Lv: 2.
- 30초 동안 반경 24블록의 호환 가능한 작물·묘목·가축 성장과 생산/처리 속도를 가속한다.
- Lv.1: ×3.
- Lv.2: ×7.
- 화로·훈연기·용광로·양조 등 호환 가능한 생산 블록을 포함한다.
- 적 AI, 플레이어 행동속도, 월드 시간대 자체는 가속하지 않는다.
- 쿨다운 120초.
- 정확한 호환 목록은 데이터/adapter 기반으로 관리한다.
- 플레이어-facing 설명에는 내부 호환 구현 문구를 노출하지 않는다.

### 확정 — 두 번째 선택 Lv.1 — 신화

- 코어 1개를 사용해 나온 3개 후보 중 서로 다른 2개를 선택할 수 있다.
- 코어 소비량은 1개 그대로다.
- 모든 등급 코어에 적용한다.
- 후보 부족 시 `GAME_DESIGN.md`의 기존 후보 부족 규칙을 따른다.
- 증강 획득 규칙 자체를 깨는 신화급 효과로 유지한다.

### 폐기 — 완전 숙련

- 현재 보유/향후 획득 일반~전설 증강을 즉시 최대 레벨로 만드는 제안은 폐기한다.
- 장기 서바이벌의 수집/성장 루프를 통째로 생략하므로 이름/수치만 바꿔 다시 제안하지 않는다.

### 기존 보류 유지 — 비행

- `비행 — Survival Creative식 자유 비행`은 이미 과거 보류 목록에 존재한다.
- 신규 후보처럼 다시 제안하지 않는다.
- 사용자가 직접 보류안 재검토를 요청하기 전까지 보류 상태를 유지한다.

### 폐기 — 복제

- 손에 든 스택 가능 아이템을 복제하는 제안은 폐기한다.
- 단순 자원 복제 의미를 이름/수치만 바꿔 다시 제안하지 않는다.

## 확정 — 권능 탈취 Lv.1 — 신화

`권능 탈취`는 유지하되 기존 증강 액티브 10칸을 소모하지 않는 별도 시스템으로 설계한다.

### 핵심 구조

- 플레이어가 서로 다른 **지원 대상 보스 종류를 처음 직접 처치할 때**, 해당 보스의 대표 권능 하나를 영구 해금한다.
- 해금된 권능은 별도 `권능` UI에서 관리한다.
- 동시에 장착할 수 있는 권능은 **1개**다.
- 권능 슬롯은 일반 증강 액티브 슬롯 10칸과 완전히 별개다.
- 액티브형 권능은 모든 권능이 공유하는 **전용 권능 키 1개**로 발동한다.
- 패시브형 권능은 권능 슬롯에 장착한 동안 자동 적용한다.
- 권능을 여러 개 해금해도 플레이 중 필요한 키 수와 액티브 바 점유량은 늘어나지 않는다.

### 구현 계약

- 보스 원본 코드를 런타임에 임의 복제하지 않는다.
- `boss entity/tag/profile -> authority definition` 매핑을 데이터 기반으로 둔다.
- 각 권능은 플레이어용으로 별도 구현한 안전한 기술이다.
- Chrono Dawn / World Bosses / MCEndgame 등 공식 팩 보스부터 지원한다.
- 외부 보스는 profile/adapter를 추가해 확장한다.
- 보스마다 대표 능력을 1개씩 억지로 그대로 복사하지 않고, 플레이어가 써도 재미와 판정이 성립하도록 축약/재구성한다.
- 액티브형 권능 쿨다운은 권능별로 서버가 저장한다. 장착 교체로 쿨다운을 초기화할 수 없다.
- 전투 중 즉시 권능 갈아끼우기로 모든 권능을 연속 사용하는 악용을 막기 위해 권능 교체는 인벤토리/권능 화면에서만 허용하고, 전투 상태에서는 교체를 잠글 수 있다.

### 플레이어-facing 방향

`쓰러뜨린 우두머리의 권능을 빼앗습니다.`

Shift 상세에서는:
- 해금 조건: 서로 다른 우두머리 최초 처치
- 장착 가능 권능: 1개

정도만 노출한다. adapter/스크립트/서버 저장 같은 개발 정보는 표시하지 않는다.

### 신화로 유지하는 이유

- 신화 하나가 별도의 `보스 사냥 -> 권능 수집 -> 장착 선택` 후반 루프를 연다.
- 기존 보스 모드와 `우두머리 사냥`의 장기 가치를 높인다.
- 단순 수치 상승이 아니라 플레이어가 사용할 수 있는 행동 체계 자체가 확장된다.

## 확정 — 금단의 마법 Lv.1 — 전설

신화 제안에서 **전설**로 하향한다.

### 효과

- 모루에서 정상적으로 서로 배타적인 호환 인챈트를 같은 장비에 함께 부여할 수 있다.
- 해당 플레이어에게 모루의 `Too Expensive` 제한을 제거한다.
- 같은 장비를 반복해서 모루에서 작업해도 vanilla prior-work 페널티 때문에 요구 경험치가 계속 상승하지 않는다.
- 즉, **반복 작업 횟수 자체가 경험치 비용을 올리지 않는다.**
- 실제로 붙이는 인챈트/수리 재료에서 발생하는 기본 작업 비용까지 0으로 만드는 것은 아니다.
- 인챈트 최대레벨 자체를 자동으로 높이지 않는다. 최대레벨 초과 효과는 기존 `마법 공명` 역할을 유지한다.
- 기술적으로 동시 적용 시 실제 기능 충돌이 나는 외부 인챈트 조합만 데이터 기반 hard-conflict 예외로 둔다.

### 플레이어-facing 방향

`서로 양립할 수 없던 마법을 하나의 장비에 새길 수 있습니다. 모루를 반복해서 사용해도 작업 비용이 더 비싸지지 않습니다.`

Shift 상세:
- `상호 배타 인챈트 조합 허용`
- `Too Expensive 제거`
- `반복 작업 비용 증가 없음`

개발용 hard-conflict 목록은 인게임에 표시하지 않는다.

## 신화 설계 기준

신화는 단순히 높은 수치의 영웅/전설이 아니다.

다음 중 최소 하나를 만족하는 종결급 효과를 우선한다.

1. Minecraft의 기본 행동 규칙을 영구적으로 바꾼다.
2. 증강 획득/성장 규칙 자체를 바꾸되 기존 성장 과정을 삭제하지 않는다.
3. 기존 시스템 여러 개의 가치/플레이 루프를 새롭게 연결한다.
4. 획득 순간 이전까지 불가능했던 플레이 방식을 연다.
5. 별도 후반 목표나 콘텐츠 루프를 만들어낸다.

단순 큰 수치, 단순 자원 복제, 기존 보류 후보 재포장, 성장 스킵은 신화 후보에서 제외한다.

Docs/design only. Build/CI not run.

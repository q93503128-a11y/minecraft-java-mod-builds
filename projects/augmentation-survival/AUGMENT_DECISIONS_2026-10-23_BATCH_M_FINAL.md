# Augmentation Survival — Batch M Final Decisions

Date: 2026-10-23

사용자 규칙: 별도 폐기 지시가 없으면 이번 Batch M 후보는 통과로 처리한다.

## 확정

### 일반 — 속공 Lv.5
- 일반 공격속도 +4% / +8% / +12% / +16% / +20%.
- vanilla attack speed 기준으로 적용하며 Better Combat 호환 시 같은 공격속도 축을 사용한다.

### 희귀 — 회복 증폭 Lv.3
- 허기·포만도 기반 자연회복을 제외한 실제 치유량 +10% / +20% / +30%.
- 즉시 치유, 재생, 포션, 명시적 모드/증강 치유에 적용.
- 증폭된 회복량은 `넘치는 회복`의 입력으로 정상 사용 가능하며 재귀 치유는 금지.

### 영웅 — 광폭화 Lv.3
- 액티브, 8초 지속.
- 직접 공격 피해 +30% / +45% / +60%.
- 공격속도 +20% / +30% / +40%.
- 지속 중 받는 최종 피해 +25%.
- 재사용 대기시간 30 / 27 / 24초.

### 영웅 — 벼락 Lv.3
- 모든 직접 공격 기준 Lv.1/2/3에서 각각 **4 / 3 / 2번째 적중마다** 발동.
- 적중 대상을 시작점으로 반경 7블록 안 아직 맞지 않은 적대적 개체 최대 2 / 3 / 4명에게 연쇄 번개.
- 연쇄 피해는 최초 적중 대상 실제 피해의 50% / 65% / 80%.
- 화재·블록 파괴 없음. 번개 피해는 자체 카운트/연쇄를 재귀 발동하지 않음.

### 영웅 — 메아리 타격 Lv.3
- 완충 근접 공격을 같은 적에게 Lv.1/2/3에서 각각 **3 / 3 / 2회 적중할 때마다** 추가 타격.
- 추가 타격 원피해는 기준 공격 원피해 스냅샷의 50% / 75% / 100%.
- 대상 방어 계산은 정상 적용.
- 추가 타격은 자체 재귀, 휩쓸기/치명타/별도 발사체 생성 이벤트를 복제하지 않음.

### 전설 — 능력 가속 Lv.1
- 재사용 대기시간이 있는 비신화 액티브 증강의 쿨다운 25% 감소.
- 쿨다운 없는 능력, 토글형, 사망당 1회 같은 별도 자원형 능력, 신화 능력에는 적용하지 않음.

### 전설 — 이중 충전 Lv.1
- 기존 신화 제안에서 **전설**로 조정.
- 재사용 대기시간이 있는 비신화 액티브 증강이 최대 2회분 충전을 저장.
- 사용 시 충전 1개 소모, 각 충전은 원래 능력 쿨다운에 따라 하나씩 회복.
- 쿨다운 없는 능력, 토글형, 사망당 1회형, 신화 액티브는 제외.
- `능력 가속`과 함께 보유 시 충전 회복시간에도 정상 적용.

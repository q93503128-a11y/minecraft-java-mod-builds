# Augmentation Survival — Batch O Final Decisions

Date: 2026-10-23

사용자 규칙에 따라 별도 폐기 지시가 없는 Batch O 후보는 확정으로 처리한다.

## 확정

### 영웅 — 강인한 정신 Lv.3

- 제거 가능한 일반 해로운 상태효과의 지속시간을 **20% / 40% / 60% 감소**한다.
- 보스 고유 기믹, 시스템성 상태, 명시적으로 제거 불가능한 효과는 대상에서 제외한다.
- 이미 적용된 효과와 신규 적용 효과 모두 서버가 유효 지속시간을 계산한다.

### 영웅 — 전투 순환 Lv.3

- 플레이어가 직접 피해로 적대적 개체를 처치할 때 현재 재사용 대기 중인 **모든 비신화 액티브 증강**의 남은 쿨다운을 **1 / 2 / 3초 감소**한다.
- 보스를 직접 처치하면 각각 **5 / 10 / 15초 감소**한다.
- 분신, 지배된 개체, 동료, 자동 피해가 대신 처치한 경우에는 발동하지 않는다.
- 남은 쿨다운은 0 미만으로 내려가지 않는다.
- `능력 가속`, `이중 충전`과 정상 연계한다.

### 전설 — 무적 Lv.1

- 기존 신화 액티브 제안에서 **전설 패시브**로 변경한다.
- 서버 생존 타이머 기준 **10초마다 자동으로 3초간 무적** 상태가 된다.
- 무적 중 모든 일반/환경 피해를 무시하고 넉백과 새로 적용되는 제거 가능한 해로운 상태효과도 무시한다.
- 플레이어의 이동, 공격, 채굴, 아이템 사용은 정상적으로 가능하다.
- 보스의 추방/강제 이동/전투 종료처럼 단순 피해가 아닌 스크립트성 월드 규칙은 막지 않는다.
- 자동 발동이므로 액티브로 표기하지 않는다.

### 신화 — 천벌 Lv.2 (액티브)

- 발동하면 플레이어 반경 **32블록** 안의 모든 적대적 개체를 동시에 타격한다.
- Lv.1/2에서 일반 적대몹에게 각각 대상 최대 체력의 **60% / 90%** 특수 피해를 준다.
- Lv.1/2에서 보스에게 각각 대상 최대 체력의 **10% / 25%** 특수 피해를 준다.
- **Lv.2에서는 적중한 모든 대상에게 2초 스턴**을 추가한다. 보스도 기본 대상이지만 외부 보스 스크립트가 하드 스턴으로 깨지는 경우에만 compat 예외를 둔다.
- 일반 방어구 수치는 무시하지만 보스 무적 페이즈, 피해 차단 기믹, 스크립트성 보호 상태는 존중한다.
- 연출은 대상마다 하늘/천장 여부와 무관하게 식별 가능한 **전용 번개 VFX와 번개 사운드**를 사용한다.
- 실제 바닐라 번개 엔티티의 화재, 블록 변화, 원치 않는 엔티티 변환 효과는 발생시키지 않는다.
- 재사용 대기시간 **60초**.

## 폐기

### 재설정

- 모든 비신화 액티브의 쿨다운/충전을 즉시 복구하는 제안은 폐기한다.
- 이름이나 수치만 바꾼 동일 의미 후보는 다시 제안하지 않는다.

# Augmentation Survival — Augment Interaction Contract

Date: 2026-10-24
Status: CANONICAL DESIGN CONTRACT

이 문서는 `AUGMENTS.md`의 개별 증강 효과가 동시에 작동할 때의 계산 순서, 출처 판정, 재귀 차단, 외부 모드 호환 원칙을 확정한다. 개별 증강의 수치/등급/최대레벨은 `AUGMENTS.md`가 우선한다.

## 1. 같은 스탯의 증강 보너스

동일한 양의 퍼센트 스탯을 강화하는 **증강끼리는 합연산**한다.

예:
- 공격속도: `속공 + 연속 처치 + 광폭화 + 시간 가속`의 활성 보너스를 합산한 뒤 하나의 증강 공격속도 배율로 적용한다.
- 이동속도: `빠른 발 + 숨 고르기 + 야행성 + 다급한 발걸음 + 연속 처치 + 관성 전환 + 시간 가속` 등 현재 조건을 만족하는 증강 보너스를 합산한다.
- 채굴속도도 같은 원칙을 쓴다.

증강층 계산은 바닐라/외부 모드가 만든 유효 기준값 위에 한 번 적용한다. 서로 다른 증강의 퍼센트 보너스를 개별 곱해 기하급수적으로 커지게 하지 않는다.

피해 감소는 기존 정본대로 곱연산한다.

공격 피해는 다음 레이어를 기본으로 한다.
1. 무기/공격의 기준 원피해
2. 공격자 측 일반/조건부 증강 피해 보너스 합산
3. 대상 갑옷/방어 강도/보호 계산
4. `방어 무시` 같은 방어 수정
5. 대상 측 피해감소
6. `약점 표식`처럼 대상이 받는 최종 피해 증가

`천벌` 같은 명시적 최대체력 비율 특수 피해는 이 일반 공격 보너스 레이어를 사용하지 않는다.

## 2. 전투 이벤트 출처

모든 전투 이벤트는 최소 다음 출처를 구분한다.

- `ROOT_MELEE`: 플레이어가 직접 실행한 근접 적중
- `ROOT_PROJECTILE`: 플레이어가 직접 발사한 원본 투사체 적중
- `DERIVED_PROJECTILE`: `분산 사격` 등 증강이 생성한 보조 투사체
- `DERIVED_CHAIN`: `연쇄 화살`, `벼락` 등 연쇄 피해
- `DERIVED_AOE`: `연쇄 폭발` 같은 자동 광역 피해
- `ECHO`: `메아리 타격` 추가 타격
- `ACTIVE_SPECIAL`: `방패 던지기`, `천벌` 등 특수 액티브 피해
- `COMPANION`: `분신`, `지배` 등 동료가 준 피해
- `REFLECTED`: `돌려보내기`로 소유권이 바뀐 반사 투사체
- `SPECIAL_PERCENT_HP`: 최대체력 비율 특수 피해

용어:
- **직접 적중/직접 처치** = `ROOT_MELEE` 또는 `ROOT_PROJECTILE`만.
- **플레이어 귀속 처치** = 플레이어가 직접 또는 플레이어 소유 파생 피해로 죽였지만 `COMPANION`은 아닌 처치.

`벼락`, `메아리 타격`, `약점 표식`, `전투 순환`처럼 직접 행동을 요구하는 효과는 ROOT 이벤트만 카운트한다.

`분신`, `지배` 처치는 플레이어 직접 처치가 아니며 코어/진행 보상, `전투 순환`, `풍요`의 직접 행동 판정을 만들지 않는다.

## 3. 투사체 조합

### 분산 사격
- 한 번의 발사 행동당 보조 투사체를 정해진 개수만 추가한다.
- 보조 투사체가 다시 `분산 사격`을 발동하지 않는다.
- 바닐라 Crossbow Multishot도 한 번의 발사 행동으로 본다. 기존 Multishot 투사체 각각에 보조탄을 복제하지 않고 발사 행동 전체에 보조탄 수를 한 번만 더한다.
- `화살 아끼기`의 탄약 판정도 발사 행동당 한 번만 한다.

### 관통
- 바닐라 Piercing과 `관통 화살`은 **하나의 관통 예산**으로 합친다.
- 같은 투사체가 같은 대상을 두 번 관통 처리하지 않는다.

### 연쇄 화살
- 물리 투사체 **1개당 최초 유효 생명체 적중에서 최대 1개의 연쇄 시퀀스만 시작**한다.
- 이후 그 투사체가 관통해 다른 대상을 맞혀도 새 연쇄 시퀀스를 추가 생성하지 않는다.
- `분산 사격` 보조 투사체도 각자 물리 투사체이므로 각각 최초 적중에서 한 번의 연쇄 시퀀스를 시작할 수 있다.
- 연쇄 피해는 물리 투사체가 아니므로 관통/분산을 다시 발동하지 않는다.

### 벼락 / 메아리
- `벼락` 연쇄 피해는 벼락 카운트를 올리지 않는다.
- `메아리 타격`은 자기 자신을 다시 카운트하지 않는다.
- `분산 사격` 보조탄은 `관통/연쇄 화살` 같은 투사체 전용 효과를 이어받을 수 있지만 `벼락`, `약점 표식`, `메아리 타격` 같은 ROOT 직접 적중 카운터는 올리지 않는다.

## 4. 회복 파이프라인

기본 순서:
1. 1차 회복 원인이 발생한다.
2. 회복 받는 대상의 `회복 증폭`을 적용한다.
3. 실제 잃은 HP를 회복한다.
4. 1차 회복의 초과분은 `넘치는 회복`이 흡수 체력으로 전환할 수 있다.
5. `회복 나눔`은 **실제로 회복된 HP**만 기준으로 공유한다. 흡수 체력은 공유량에 포함하지 않는다.
6. `회복 나눔`으로 생성된 공유 회복은 다시 `회복 나눔` 또는 `넘치는 회복`을 발동하지 않는다.

### 물약 확산
지속형 이로운 물약:
- 동일 단계 효과를 원래 지속시간의 25% / 40% / 55%로 공유한다.

즉시형 이로운 물약:
- 지속시간 대신 **원래 즉시 효과량의 25% / 40% / 55%**를 공유한다.
- `즉시 치유`는 원래 회복량의 25% / 40% / 55%를 공유 회복량의 기준으로 사용한다.
- 공유된 즉시 치유는 받는 대상의 `회복 증폭`과 `넘치는 회복`을 정상 적용할 수 있다.
- 공유 복사본은 다시 `물약 확산`을 발동하지 않는다.
- 그 결과 실제 HP가 회복되면 대상의 `회복 나눔`은 정상 발동할 수 있으나, 그 공유 회복은 기존 재귀 금지 규칙을 따른다.

## 5. 피해 / 무적 / 피해 지연

`무적`은 피해 파이프라인의 가장 앞에서 동작한다.

- 무적 시간에 들어온 일반/환경 피해는 **피해 이벤트 자체를 0으로 취소**한다.
- 따라서 해당 공격으로 `피해 지연` 예약 피해가 새로 생성되지 않는다.
- `피해 적응`, `다급한 발걸음` 등 실제 피격 성공을 요구하는 효과도 발동하지 않는다.
- 이미 과거에 생성된 `피해 지연` 분할 피해가 무적 시간에 도착하면 그 분할 피해도 무적에 의해 0이 될 수 있다.

무적이 아닌 정상 피해의 순서:
1. 갑옷/방어 강도
2. 보호 인챈트
3. 일반 증강 피해감소
4. 조건부/속성 증강 피해감소
5. `피해 지연`이 예약할 비율 분리
6. `보호막`
7. 바닐라 흡수 체력/실제 HP
8. 치명 여부 판정

예약된 `피해 지연` 분할 피해는 방어 계산과 `피해 지연`을 다시 적용하지 않는다.

## 6. 치명 피해 / 사망 순서

치명 상황 처리 순서:
1. `한 번 버티기`
2. 주손/보조손 불사의 토템
3. `비상 토템`을 통한 인벤토리 토템
4. `재림`
5. 위 모두 실패했을 때만 실제 사망

`재림`은 실제 사망이 아니다.
- 아이템/XP 드롭 없음
- `소지품 보존`/`경험 보존` 사망 처리 없음
- 사망 지점 갱신 없음
- `소생` 표식 생성 없음

실제 사망에서만:
- `소지품 보존`
- `경험 보존`
- 사망 지점 기록
- 주변 보유자의 `소생` 표식 생성
을 처리한다.

## 7. 상태효과 순서

적이 건 제거 가능한 해로운 효과:
1. `무적`이면 적용 자체를 거부한다. 이 경우 `상태 반사`도 발동하지 않는다.
2. 적용 가능한 경우 `상태 반사`는 **원래 들어온 지속시간**을 기준으로 반사 복사본을 만든다.
3. 자기 자신에게 적용되는 지속시간에는 `강인한 정신` 20% / 40% / 60% 감소를 적용한다.
4. 이후 `정화`가 남은 제거 가능 효과를 지울 수 있다.

반사된 상태효과는 다시 `상태 반사`를 일으키지 않는다.

## 8. 쿨다운 / 이중 충전

- 능력의 저작된 기본 쿨다운에서 `능력 가속` 25%를 먼저 적용해 유효 충전 시간을 만든다.
- `이중 충전` 대상 능력은 최대 2충전을 저장한다.
- 두 충전을 모두 썼을 때는 **순차적으로 하나씩 재충전**한다. 두 개의 독립 타이머를 동시에 돌리지 않는다.
- `전투 순환`은 현재 진행 중인 충전 타이머를 줄인다.
- 쿨다운 감소량이 현재 충전의 남은 시간을 초과하면 해당 충전을 즉시 복구하고 **남는 감소량을 다음 비어 있는 충전 타이머로 이월**한다.

제외:
- 쿨다운 없는 능력
- 토글만 있는 능력
- 사망당 1회 자원형
- 신화 액티브

## 9. 자원 / 채굴 / 풍요

드롭 순서:
`기본 바닐라/모드 드롭 → Fortune/Looting → 호환 가능한 추가/복제 증강 → 최종 스택 확정 → 풍요 ×2`

- `풍요`는 최종 일반 스택 수량에 곱연산한다.
- 코어/고유 보스 보상/진행 아이템/고유 NBT 장비/비스택 장비는 제외한다.
- 자동 채굴/수확된 각 블록은 호환 가능한 드롭/Fortune/내구도 규칙을 이어받는다.
- 자동으로 처리된 블록은 또 다른 범위/연쇄 자동 채굴을 시작하지 않는다.
- `연속 채굴`은 플레이어가 직접 시작한 root 채굴 행동만 카운트한다.
- `순간 채굴`은 직접 조준한 root 블록의 파괴 시간만 1 tick으로 바꾼다.
- `굴파기`는 광석/원목/작물을 제외한 명시적 굴착 태그를 사용하고, 연결 원목 확장은 `나무 베기`가 담당한다.

`임시 발판`에 착지해 낙하 피해가 0이 되어도 4블록 이상 실제 낙하 후 착지했다면 `관성 전환` 조건은 만족한다.

## 10. 동료 분류

공통 아군 분류:
- 아군 플레이어
- 길들인 영구 전투 동료
- `지배`된 영구 전투 동료
- `분신` 임시 소환체

기본 지원 규칙:
- `치유 파동`, `회복 나눔`, `물약 확산`, `약점 표식`의 아군 효과는 길들인 동료와 지배 동료를 포함한다.
- `분신`도 전투 중 치유/버프를 받을 수 있으나 보상/진행 귀속은 만들지 않는다.
- `소생`은 길들인 영구 동료와 지배 동료를 되살릴 수 있다.
- `소생`은 임시 `분신`을 되살리지 않는다.
- 지배 동료가 `소생`되면 지배 소유권을 유지한다.
- 지배된 개체는 `위험 감지`, `천벌`, `끌어당기기`, `탄도 장막` 등의 적대 대상에서 즉시 제외한다.

외부 모드의 특수 AI는 무조건 강제 개조하지 않고 entity/namespace별 adapter 또는 exclusion을 사용한다.

## 11. 보스 제어 / 천벌

보스 호환은 data-driven profile로 관리한다.

필드 예시:
- `allowPull`
- `pullMultiplier`
- `allowPositionSwap`
- `allowTimeStop`
- `allowStun`
- `allowPercentHpDamage`
- `allowDominate` (기본 false)

현재 승인된 디자인을 우선하므로 보스의 pull/swap/time-stop/stun/percent damage는 **기본 허용**하고, 실제 외부 보스 스크립트가 깨지는 개체만 명시적으로 제한한다.

`천벌`:
- 표시된 일반몹 60% / 90%, 보스 10% / 25%는 정확한 최대체력 비율 피해다.
- `날 선 감각`, `정확한 조준`, `광폭화`, `우두머리 사냥`, `약점 표식` 등 일반 피해 보너스를 추가로 곱하지 않는다.
- `생명 연결`의 공유 피해 대상에서도 제외해 최대체력 비율 피해가 다시 복제되지 않게 한다.
- 갑옷은 무시하지만 보스 무적 페이즈/피해 차단 스크립트는 존중한다.
- HP를 직접 set하지 않고 정상 damage/hurt 경로를 사용한다.

`시간 정지` 중에는 대상 내부의 스턴/상태 타이머도 함께 정지한다. 따라서 시간 정지 중 `천벌 Lv.2`의 2초 스턴을 걸면 남은 스턴 시간은 시간 정지 종료 뒤 이어진다.

## 12. Better Combat

Better Combat을 사용할 때는 하나의 서버 권한 root melee hit 신호를 정규화한다.

- `속공`, `연속 처치`, `광폭화`, `시간 가속`은 공격 애니메이션을 따로 조작하지 않고 하나의 공격속도/쿨다운 축을 수정한다.
- `휩쓸기 강화`는 바닐라 Sweeping Edge만 가정하지 않고 Better Combat의 실제 target selection/hitbox 결과를 기준으로 확장한다.
- `벼락`, `메아리 타격`, `약점 표식`, 직접 처치 판정은 Better Combat 공격에서도 대상당 정확히 한 번의 ROOT 적중 이벤트를 받는다.
- `방패 던지기`의 무기 스냅샷은 현재 Better Combat 콤보 프레임의 임시 배율을 우연히 복제하지 않고, 현재 장비의 표준 완충 공격 원피해 계약을 사용한다.

실제 공존은 구현 후 플레이테스트가 필요하다.

## 13. 작물 / 외부 콘텐츠

Farmer's Delight와 외부 작물을 위해 `풍작`, `씨앗 챙기기`, `다시 심기`, `싹쓸이 수확`, `풍요`는 ID 하드코딩이 아니라 crop/harvest tag + adapter를 사용한다.

- age 기반 작물
- 우클릭 수확 작물
- 다중 블록/비표준 작물
- 실제 재파종 재료
을 구분한다.

음식 증강은 가능한 한 정상 food/use component를 기준으로 해 모드 음식도 자연스럽게 호환한다.

`광석 눈썰미`는 ore tag/compat set을 사용하고, `손재주`는 data-driven whitelist/tag를 사용한다.

`마법 공명`은 외부 인챈트를 무조건 최대레벨 초과시키지 않고, 레벨 증가가 안전하게 의미 있는 인챈트만 allow/compat contract에 등록한다.

## 14. 처치 회복 복구 원칙

사용자는 `사냥의 활력`을 폐기하면서 이미 처치 회복 증강이 존재한다고 명시했다. 현재 정본에는 과거 보류 `흡혈`만 남아 있어 정본 불일치가 발생했다.

이 불일치는 사용자 의도를 기준으로 다음처럼 복구한다.

- `흡혈` — 희귀 Lv.3 확정
- 플레이어 귀속으로 적대몹을 처치하면 체력 **1 / 2 / 3 HP** 회복
- `COMPANION` 처치는 제외
- 자연회복이 아니므로 `회복 증폭`, `넘치는 회복`, `회복 나눔`과 정상 연계
- `사냥의 활력`은 동일 축 중복으로 폐기 상태 유지

# Augmentation Survival — Batch M Power / Missing-Staple Proposals

Date: 2026-10-23
Status: proposal only; not confirmed roster

## 1. 목적

현재 실질 확정 107개와 과거 제안 이력을 다시 훑어, 단순히 새 효과를 추가하는 것이 아니라 `없으면 이상한 기본 축`과 `먹었을 때 즉시 강해졌다고 느끼는 고등급 축`을 찾는다.

이번 배치에서는 이미 과거 제안된 치명타 강화, 흡혈, 처형, 되받기, 방패 반격, 화염 저항, 점프 높이, 자동 제련, 광맥 채굴, 빠른 장전 등은 다시 제안하지 않는다.

## 2. 현재 로스터에서 확인된 공백

1. 근접/전체 전투의 기본 공격속도 성장축이 없다.
2. 자연회복이 아닌 치유 효과 자체를 강화하는 수치축이 없다.
3. 순수 화력 폭발형 액티브가 부족하다. `시간 가속`은 행동 속도를 올리지만 직접 피해량은 올리지 않는다.
4. 활 전용 연쇄/분산 계열은 많지만 무기 종류에 관계없이 발동하는 강력한 공격 proc이 적다.
5. 액티브 증강 시스템이 커졌지만, 액티브 쿨다운/충전 자체를 강화하는 고등급 메타 증강이 없다.
6. 현재 신화 2종은 시간/공간 규칙 변경형이라 훌륭하지만, 액티브 빌드 전체를 바꾸는 신화급 메타 능력은 없다.

## 3. Batch M 신규 후보

### 일반 — 속공 Lv.5

- 플레이어의 일반 공격속도 +4% / +8% / +12% / +16% / +20%.
- vanilla attack speed attribute를 기준으로 적용하고 Better Combat이 같은 공격속도 값을 사용하는 경우 자연스럽게 이어받도록 한다.
- 단순 피해량 증가와 다른 DPS/손맛 축을 채우는 기본형 증강.

### 희귀 — 회복 증폭 Lv.3

- 허기·포만도 기반 자연회복을 제외한 자신에게 적용되는 실제 치유량 +10% / +20% / +30%.
- 즉시 치유, 재생, 포션, 명시적 모드/증강 치유에 적용한다.
- 증폭된 실제 회복량은 `넘치는 회복`의 입력으로 정상 사용 가능하다.
- 공유 회복이 다시 자기 치유를 증폭시키는 재귀는 금지한다.

### 영웅 — 광폭화 Lv.3

- 액티브.
- 8초 동안 직접 공격 피해 +30% / +45% / +60%, 공격속도 +20% / +30% / +40%.
- 대신 지속 중 자신이 받는 최종 피해 +25%.
- 재사용 대기시간 30 / 27 / 24초.
- 순수 화력 폭발형 능력으로, `시간 가속`과 달리 이동/채굴/아이템 사용은 강화하지 않는다.

### 영웅 — 벼락 Lv.3

- 모든 직접 공격을 기준으로 4번째 적중마다 발동한다.
- 적중 대상을 시작점으로 반경 7블록 안 아직 맞지 않은 적대적 개체 최대 2 / 3 / 4명에게 번개가 연쇄된다.
- 각 연쇄 대상은 최초 적중 대상이 실제로 받은 피해의 50% / 65% / 80%를 별도 번개 피해로 받는다.
- 블록 화재/블록 파괴는 만들지 않는다.
- 연쇄 피해는 다시 `벼락` 적중 카운트나 자체 연쇄를 만들지 않는다.

### 영웅 — 메아리 타격 Lv.3

- 완전히 충전된 근접 공격을 같은 적에게 3회 적중시키면 세 번째 공격 0.25초 뒤 같은 대상에게 추가 타격이 발생한다.
- 추가 타격 원피해는 세 번째 공격의 원피해 스냅샷의 50% / 75% / 100%.
- 대상의 갑옷·보호·피해감소는 추가 타격에도 정상 적용한다.
- 추가 타격은 `메아리 타격`을 다시 만들지 않으며, 휩쓸기/치명타/별도 발사체 생성 같은 공격 이벤트를 복제하지 않는다.

### 전설 — 능력 가속 Lv.1

- 재사용 대기시간을 가진 **비신화 액티브 증강**의 재사용 대기시간을 25% 단축한다.
- 쿨다운이 없는 `귀환`, 토글 패시브, 사망당 1회 같은 별도 자원형 능력에는 적용하지 않는다.
- 신화 능력에는 적용하지 않는다.
- 각 능력의 실제 쿨다운 값을 서버가 최종 계산한다.

### 신화 — 이중 충전 Lv.1

- 재사용 대기시간을 가진 모든 **비신화 액티브 증강**이 최대 2회분의 충전을 저장할 수 있다.
- 능력을 한 번 사용하면 충전 1개를 소비하고 즉시 다시 사용할 수 있으며, 각 충전은 원래 능력 쿨다운에 따라 하나씩 회복된다.
- 쿨다운이 없는 능력, 토글형 능력, 사망당 1회처럼 별도 횟수 규칙을 쓰는 능력에는 적용하지 않는다.
- `시간 정지` 등 신화 액티브는 이 효과의 대상이 아니다.
- `능력 가속`을 함께 보유하면 각 충전의 회복시간에도 정상 적용한다.

## 4. 이번 배치의 성격

- `속공`, `회복 증폭`은 로스터에서 빠진 기본 성장축을 메우는 후보.
- `광폭화`, `벼락`, `메아리 타격`은 즉시 전투력이 느껴지는 영웅급 후보.
- `능력 가속`, `이중 충전`은 이미 커진 액티브 증강 시스템 자체를 빌드 축으로 만드는 고등급 후보.

이번 문서는 제안 기록이며 사용자 승인/수정 전에는 확정 107개 수량에 포함하지 않는다.

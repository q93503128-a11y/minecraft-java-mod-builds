# Survival Ascension

- Mod version: `0.12.0-alpha.1`
- Minecraft: `26.2`
- Java: `25`
- Loader: `NeoForge 26.2.0.38-beta`
- Existing-world compatibility: 공용 스킬 SavedData, 강화 적 엔티티 NBT, 0.11 affix ItemStack CustomData를 유지한다. 0.11 장비는 새 affix 키가 없어도 그대로 동작한다.

## 정체성
숙련이 오를수록 수치만 커지는 것이 아니라 한 번의 행동이 처리하는 물리적 범위와 선택지가 커진다. 플레이어 체급에 맞춰 적 세계와 전리품 체급도 상승하며, 희귀 장비는 다시 자원 소비와 파밍 루프로 연결한다.

## 6숙련
- 채굴: 3×3 → 5×5 → 7×7 → 9×9 + 광맥 추적.
- 벌목: 연결 통나무 16 → 48 → 128 → 256.
- 농사: 성숙 작물 3×3 → 5×5 → 7×7 → 9×9.
- 전투: 피해 성장 + 파급 2 → 4 → 8체.
- 건축: 선 5/9/17/33, 벽·바닥 3×3/5×5/9×9.
- 기동: 지상 질주 XP, 단차/안전낙하, R 지상돌진, 공중돌진, 최종 돌진 강화.

## 강화 적
- 주변 플레이어 6숙련 평균으로 정예 I / 승천 II / 신화 III 확률이 상승.
- 신속/철벽/흡혈/광전사 반응형 패턴.
- 스포너 생성은 반복 보상 파밍 방지를 위해 강화 판정 제외.

## 0.12 Affix 장비 경제
Apotheosis(MIT)의 `희귀도 → 장비 카테고리 → affix 조합` 분리를 참고한 26.2 ItemStack CustomData 구조를 유지한다.

### 희귀도/조합
- 정예 I: 철 장비, 5종 중 affix 1개, 장비 드랍 25%.
- 승천 II: 다이아 장비, 5종 중 affix 2개, 65%.
- 신화 III: 네더라이트 장비, 5종 중 affix 3개, 100%.
- 0.11의 `primary/scale/mastery`에 `secondary/utility`를 추가한다. 기존 0.11 장비는 누락 키를 false로 읽어 호환한다.

### 카테고리 예시
- 무기: 파괴 / 파급 / 숙련 / 사냥 / 충격.
- 곡괭이: 가속 / 굴착 / 숙련 / 광맥 / 정교.
- 도끼: 가속 / 연쇄 / 숙련 / 벌채 / 정교.
- 괭이: 가속 / 광역 / 숙련 / 풍작 / 정교.
- 숙련 해금 전에는 장비가 3×3·연쇄·파급 같은 행동을 새로 열지 않는다.

### M → 장비
MineMenu 계열 라디얼 UI 안에 `재련 / 분해 / 장비 정보 / 뒤로`를 배치한다.
- 재련은 주 손 affix 장비의 기반 아이템/희귀도/내구도/인챈트 등 다른 컴포넌트를 유지하면서 affix 조합만 재추첨한다.
- 서버가 장비 희귀도와 인벤토리 재료를 다시 검사한 뒤 비용을 원자적으로 소비한다.
- 정예: 자수정 16 + 철 8.
- 승천: 자수정 32 + 다이아 6.
- 신화: 자수정 64 + 다이아 12 + 네더라이트 파편 2.
- 분해는 해당 장비를 소멸시키고 위 비용의 일부만 반환한다.
- 크리에이티브 재련은 테스트 편의를 위해 무료, 크리에이티브 분해 보상은 복제 방지를 위해 금지한다.

## 조작/UI
- `M`: 통합 라디얼 메뉴.
- `M → 장비`: 재련/분해/정보.
- `R`: 기동 액션.
- `Shift`: 광역·대량 작업 정밀 단일 모드.

# Survival Ascension

- Mod version: `0.16.0-alpha.1`
- Minecraft: `26.2`
- NeoForge: `26.2.0.38-beta`
- Java: `25`
- Existing-world compatibility: 기존 스킬 SavedData, `infrastructure_v1`, 강화 적/전술 분대 persistent NBT, affix CustomData, 채굴 모드 persistent data를 유지한다.

## 핵심 방향
숙련 상승은 단순 수치 상승이 아니라 물리적 작업 규모와 선택지 증가다. 대량 생산된 자원은 공동 인프라·재련·대형 작업 해금으로 다시 소비되고, 강해진 플레이어에게는 세계의 적 조직과 전술도 함께 강해진다.

## 0.16 전술 분대
Warband MIT의 경량 분대/역할/사기 구조를 Survival Ascension에 맞게 적응했다.
- 주변 플레이어 6숙련 평균 30 이상부터 자연 적이 3~6체 전술 분대를 구성할 수 있다.
- 스포너 출신 적은 분대 후보에서 제외.
- 역할: 전단장 / 돌격 / 추적 / 지원.
- 분대는 같은 플레이어 타깃을 공유한다.
- 돌격: 중거리에서 돌진.
- 추적: 측면 이동과 거리 조절.
- 지원: 반경 내 부상 분대원 회복.
- 전단장 사망 시 나머지 분대원은 160틱(8초) 후퇴.
- 플레이어가 전단장을 처치하면 전투 Lv.에 따라 메아리 조각 1~4개 드랍.
- 기존 정예 I / 승천 II / 신화 III와 분대 역할은 동시에 붙을 수 있다.

## 전투 훈련장
네 번째 공동 인프라 프로젝트.
- 철 주괴 512
- 금 주괴 256
- 에메랄드 128
- 레드스톤 128
- 메아리 조각 32

완공 + 전투 Lv.90에서 질주 직접 근접 공격이 준비 상태일 때 360° 충격파로 승격한다.
- 반경 5.5블록
- 최대 12체
- 보조 피해는 주 공격 최종 스케일 피해의 45%
- 60틱(3초) 쿨다운
- 해당 타격에서는 기존 전방 파급 대신 충격파를 사용해 중복 폭주를 막는다.
- 적대 Enemy만 대상으로 하고 플레이어 동맹은 제외한다.

## 현재 주요 루프
숙련 성장 → 행동 체급 상승 → 강화 적/전술 분대 → 희귀 affix 장비 → 재련/분해 → 대량 자원 생산 → 공동 인프라 → 터널/재파종/입체 건축/충격파 해금.

## 기존 안전 계약
- 벌목: 잎이 붙은 자연 나무만 연쇄, 12로그/플레이어/틱·64로그/서버/틱.
- 채굴 터널: 정상 destroyBlock + 틱 분산 + 블록 엔티티/미로드 청크 제외.
- 농사 재파종: 실제 씨앗 소비 + 보호 배치 훅.
- 건축 입체: 실제 재료 소비 + 보호 훅 + 최대 256 pending/player.
- Shift: 광역 작업 정밀 단일 모드.

## UI
M 메인 라디얼: `숙련 / 채굴 / 건축 / 장비 / 인프라 / 가이드 / 닫기`.
인프라 라디얼: `채석장 네트워크 / 관개 시설 / 건축 공방 / 전투 훈련장 / 진행도 / 뒤로`.

## 외부 소스 정책
Skill Proficiencies, Veinminer++, MineMenu, Building Gadgets 2, Mob Champions, Apotheosis, Mekanism, Warband 등 확인된 permissive 소스는 라이선스 고지와 함께 필요한 구조를 적응한다. Create는 코드 MIT/에셋 ARR 경계를 지키며 현재 인프라 설계 참고만 한다. 제한 라이선스 프로젝트는 기능/UX만 참고하고 소스·에셋은 복사하지 않는다.

# Survival Ascension

- Mod version: `0.13.0-alpha.1`
- Minecraft: `26.2`
- Java: `25`
- Loader: `NeoForge 26.2.0.38-beta`
- Existing-world compatibility: 공용 스킬 SavedData, 강화 적 NBT, 0.11/0.12 affix CustomData를 유지한다. 채굴 모드는 플레이어 persistent data에 새 문자열 키로 저장한다.

## 정체성
숙련이 오를수록 한 번의 행동이 처리하는 물리적 범위와 선택지가 커진다. 고숙련에서는 같은 도구라도 작업 방식 자체를 선택하며, 강해진 플레이어에 맞춰 적/전리품/자원 소비처도 함께 커진다.

## 6숙련
- 채굴: 3×3 → 5×5 → 7×7 → 9×9, 연결 광맥, Lv.90 추출.
- 벌목: 연결 통나무 16 → 48 → 128 → 256.
- 농사: 성숙 작물 3×3 → 5×5 → 7×7 → 9×9.
- 전투: 피해 성장 + 파급 2 → 4 → 8체.
- 건축: 선 5/9/17/33, 벽·바닥 3×3/5×5/9×9.
- 기동: 지상 질주 XP, 단차/안전낙하, R 지상돌진, 공중돌진, 최종 돌진 강화.

## 0.13 채굴 모드
`M → 채굴`에서 MineMenu 계열 라디얼로 선택한다.
- 자동: 광석은 연결 광맥, 일반 블록은 시선 평면 굴착.
- 굴착(Lv.10): 광석 여부와 무관하게 현재 해금된 평면 굴착.
- 광맥(Lv.30): 가치 광석일 때 연결된 동일 광석군만 확장.
- 추출(Lv.90): 원점 기준 X/Z ±12, Y ±12의 이미 로드된 블록만 검사해 동일 광석군을 비연결 상태까지 찾는다.
- 추출은 현재 채굴 숙련/affix가 허용한 광맥 상한을 그대로 사용하며 새 상한을 만들지 않는다.
- 모든 보조 파괴는 `player.gameMode.destroyBlock`을 사용하므로 내구도, Fortune/Silk Touch, 드랍/이벤트/XP 흐름을 유지한다.
- 블록 엔티티, 수확 불가 블록, 잘못된 곡괭이, 미로드 청크는 제외한다.
- Shift는 어떤 모드에서도 1×1 정밀 채굴을 강제한다.

## 외부 설계 흡수
- Mekanism(MIT): Digital Miner의 `대상 필터 → 제한된 탐색 범위 → 일치 대상 처리` 아이디어를 플레이어 Lv.90 추출 동작으로 포팅. 머신/에너지/GUI/에셋은 가져오지 않는다.
- Create: 코드 MIT, 에셋 ARR임을 확인. 현재 0.13에는 Create 코드/에셋을 번들하지 않고 향후 대규모 인프라 소비 구조 참고 대상으로만 둔다.
- 기존 Skill Proficiencies / Veinminer++ / MineMenu / Building Gadgets 2 / Mob Champions / Apotheosis 고지와 정책 유지.

## 강화 적 / 장비 경제
- 정예 I / 승천 II / 신화 III + 신속/철벽/흡혈/광전사.
- 희귀 장비는 5종 affix 중 1/2/3개를 획득.
- `M → 장비`에서 재련/분해/정보.
- 최고 재련 비용은 자수정 64 + 다이아 12 + 네더라이트 파편 2.

## 조작
- `M`: 통합 라디얼.
- `M → 채굴`: 자동/굴착/광맥/추출.
- `M → 장비`: 재련/분해/정보.
- `R`: 기동.
- `Shift`: 정밀 단일 작업.

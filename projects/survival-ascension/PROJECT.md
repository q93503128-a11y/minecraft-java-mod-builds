# Survival Ascension

- Mod version: `0.22.0-alpha.1`
- Minecraft: `26.2`
- NeoForge: `26.2.0.38-beta`
- Java: `25`
- Network protocol: `8` (0.22의 EquipmentAction `신화 각성` 의미 추가로 0.21 클라이언트/서버 혼용 차단)
- Existing-world compatibility: 기존 스킬 SavedData, `infrastructure_v1`, `world_ascension_v1`, 강화 적/전술 분대/종말 변이 persistent NBT, affix CustomData, 채굴 모드 persistent data를 유지한다. 0.22는 새 SavedData 스키마를 만들지 않고 기존 승천 시련 런타임 상태와 affix CustomData 안에 전술 교리 런타임 선택/`awakened` 플래그만 추가한다.

## 핵심 방향
숙련 상승은 단순 수치 상승이 아니라 물리적 작업 규모와 행동 선택지 증가다. Lv.100은 최종 `숙련 VI`다. 플레이어가 강해질수록 세계/적/자원 소비처/반복 콘텐츠도 같이 커지며, 강한 적은 HP만 늘리지 않고 행동·역할·조합으로 난도를 만든다.

## 숙련 VI · Lv.100
- 채굴: 11×11, 광맥/추출 192, 채석장 터널 7×7×10.
- 벌목: 자연 나무 연쇄 384로그. 잎 검증과 12/player·64/global 틱 예산 유지.
- 농사: 11×11 성숙 작물 수확. 관개 재파종은 실제 씨앗/작물 1개 소비.
- 전투: 파급 10체 / 5블록 / 70%. 전투 훈련장 충격파 6.5블록 / 16체 / 55%, 50틱 쿨.
- 건축: 선49, 벽/바닥11×11, 건축 공방 입체7×7×7. 재료 소비·보호 훅·틱 큐 유지.
- 기동: 2블록 단차, 안전 낙하16, 대시 power1.80 / 16틱. 종말 + 승천 중추 완공이면 Lv.100 공중 돌진 3회.

## 월드 승천 / 종말
- 0 각성 → 위더 최초 격파 1 전설 → 엔더 드래곤 최초 격파 2 종말.
- 단계가 엘리트 랭크 확률과 전술 분대 규모/빈도를 높인다.
- 종말 자연 생성 좀비/스켈레톤 일부는 Withered / Phase / Plague 변이를 얻고 스포너 출신은 제외한다.
- 변이는 엘리트 랭크·전술 분대 역할과 중첩 가능하다.

## 승천 시련 0.22
- Stage 2 + 승천 중추 완공 후 `M → 인프라 → 승천 중추` 재선택으로 시작한다.
- 입장 비용: 메아리32 + 자수정64 + 드래곤의 숨결8.
- 4웨이브 / 웨이브당 60초 / 사이 5초 준비 / 보스바 상태 표시.
- 매 시련 시작 시 전술 교리 `쇄도 / 추격 / 봉쇄` 중 하나를 무작위 선택한다.
- 쇄도: Husk/Vindicator/Wither Skeleton/Ravager 중심 근접 압박.
- 추격: Spider/Enderman/Husk/Wither Skeleton/Vindicator 중심. 멀어진 추격형 적은 플레이어 쪽으로 navigation 압박을 다시 건다.
- 봉쇄: Skeleton/Stray/Pillager/Witch 중심 원거리·제어 조합.
- 각 웨이브의 초기 병력이 절반가량 남았을 때 교리별 증원을 1회만 추가한다. 제한시간은 연장하지 않는다.
- 별도 HP 배율을 추가하지 않는다. 기존 Stage2 변이·Elite·Warband가 정상 생성 경로 위에서 중첩될 수 있다.
- Evoker 직접 소환은 Vex 잔존 방지를 위해 제외한다.
- 기존 10초 소유자 이탈/사망 유예, 96블록 중복 간격, 120초 cooldown, 재시작 고아몹 정리, stale-server 정리를 유지한다.
- 완료 보상은 신화 III 장비1 + 네더라이트 파편2 + 다이아4 + XP200, 근처 협동 플레이어 XP80.

## 각성 신화 장비
- 일반 Mythic III는 정확히 3 affix여야 한다.
- `M → 장비 → 신화 각성`에서 1회만 각성 가능하며 기존 3 affix를 보존하고 빠진 affix 하나를 추가해 4 affix로 만든다.
- 각성 전에 서버가 rarity/category/정확히 3개의 알려진 affix를 다시 검증한다. 비정상 CustomData면 자원을 소비하지 않고 거절한다.
- 각성 비용: 자수정256 + 다이아24 + 네더라이트 파편8 + 메아리64 + 드래곤의 숨결16.
- 각성 신화 재련은 4 affix 상태를 유지하며 비용은 자수정128 + 다이아16 + 네더라이트 파편4 + 메아리16.
- 각성은 affix 수만 늘리고 숙련 액션의 조기 해금 규칙을 건드리지 않는다. 기존 `base <= 1`/`base <= 0` 해금 보호를 그대로 통과해야 증폭된다.
- 새 아이템/텍스처/레지스트리를 만들지 않고 기존 CustomData에 `awakened`만 저장한다.

## 경제와 인프라
- affix 장비 → 재련/분해 → 승천 시련 → 신화 III 파밍 → 신화 각성/고비용 4-affix 재련으로 이어진다.
- 각성 비용은 대량 채굴·종말 변이/전단장 전투·드래곤 자원·네더라이트 탐색을 동시에 요구해 대량 자원의 최종 소비처 역할을 한다.
- 채석장/관개/건축 공방/전투 훈련장/승천 중추 기존 계약은 유지한다.

## 안전 계약
- Shift는 광역 작업 강제 단일 정밀 모드.
- 대형 채굴/벌목/건축은 서버 틱 분산.
- 추가 채굴은 정상 destroyBlock 경로.
- 건축/재파종은 실제 재료 소비 + 상호작용/배치 보호 훅.
- 스포너 기반 엘리트/분대/종말 변이 보상 농장 차단.
- 승천 시련은 실재 입장 비용·중복 거리·단일 활성·cooldown·잔존 엔티티 정리 계약 유지.
- 교리 증원은 웨이브당 최대 1회이며 타이머를 연장하지 않는다.
- Mythic 각성은 검증 성공 뒤에만 자원 소비를 시작한다.
- Lv.100 작업 범위 증가 때문에 기존 동기식 처리 예산을 올리지 않는다.

## 외부 소스 정책
Gateways to Eternity(MIT)의 순차 웨이브/보스바와 wave-changing modifier 개념을 0.21~0.22에서 고수준으로 적응했다. Apotheosis(MIT)의 rarity/category/affix 분리 철학을 기존 장비 시스템에 계속 사용한다. 제한 라이선스 프로젝트는 기능/UX만 참고하고 소스·에셋은 복사하지 않는다.

# Survival Ascension

- Mod version: `0.17.0-alpha.1`
- Minecraft: `26.2`
- NeoForge: `26.2.0.38-beta`
- Java: `25`
- Existing-world compatibility: 기존 스킬 SavedData, `infrastructure_v1`, 강화 적/전술 분대 persistent NBT, affix CustomData, 채굴 모드 persistent data를 유지하며 `world_ascension_v1`을 새로 추가한다.

## 핵심 방향
숙련 상승은 단순 수치 상승이 아니라 물리적 작업 규모와 선택지 증가다. 대량 생산된 자원은 공동 인프라·재련·대형 작업 해금으로 다시 소비되고, 보스 처치 이후에는 세계의 적 조직과 상위 랭크 비율도 함께 승천한다.

## 월드 승천 0.17
Hostiles Are Too Easy(CC0)의 보스/진행 사건 기반 동적 난도 개념을 현대 NeoForge 26.2에 맞춰 적응한다.
- 0단계 `각성 단계`: 기본.
- 위더 최초 격파 → 1단계 `전설 단계`.
- 엔더 드래곤 최초 격파 → 2단계 `종말 단계`.
- `world_ascension_v1` SavedData에 서버 월드 공동 저장.
- 단계는 후퇴하지 않는다.
- M → 인프라 → 진행도에서 현재 서버 단계 확인.

### 엘리트 연동
- 기존 플레이어 평균 숙련 기반 확률 유지.
- 월드 단계당 엘리트 출현률 +0.04, 총 상한 0.28.
- 신화 III 확률에 단계당 +0.04, 상한 0.22.
- 승천 II 확률에 단계당 +0.05, 상한 0.50.
- 단순 HP 단계 버프가 아니라 기존 신속/철벽/흡혈/광전사 패턴의 출현 체급을 올린다.

### 전술 분대 연동
- 각성: 3~6체.
- 전설: 최소 4체, 최대 7체.
- 종말: 최소 5체, 최대 8체.
- 단계당 분대 형성 확률 +0.08, 총 상한 0.68.
- 기존 전단장/돌격/추적/지원 역할, 전단장 사망 8초 후퇴, 메아리 조각 보상 유지.

## 기존 후반 루프
숙련 성장 → 광역/대형 행동 → 강화 적/전술 분대 → affix 장비 → 재련/분해 → 대량 자원 → 공동 인프라 → 터널/재파종/입체 건축/충격파 → 위더/드래곤 격파 → 월드 승천으로 세계 자체가 강화.

## 안전 계약
- 벌목: 잎이 붙은 자연 나무만 연쇄, 12로그/플레이어/틱·64로그/서버/틱.
- 채굴 터널: 정상 destroyBlock + 틱 분산 + 블록 엔티티/미로드 청크 제외.
- 농사 재파종: 실제 씨앗 소비 + 보호 배치 훅.
- 건축 입체: 실제 재료 소비 + 보호 훅 + 최대 256 pending/player.
- 전투 충격파: 전투 Lv.90 + 훈련장 완공 + 질주 직접 근접 + 60틱 쿨.
- Shift: 광역 작업 정밀 단일 모드.

## 외부 소스 정책
Skill Proficiencies, Veinminer++, MineMenu, Building Gadgets 2, Mob Champions, Apotheosis, Mekanism, Warband 등 permissive 소스는 라이선스 고지와 함께 필요한 구조를 적응한다. Hostiles Are Too Easy는 CC0 보스 기반 동적 난도 개념을 적응한다. 제한 라이선스 프로젝트는 기능/UX만 참고하고 소스·에셋은 복사하지 않는다.

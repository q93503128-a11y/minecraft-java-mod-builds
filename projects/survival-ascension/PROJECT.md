# Survival Ascension

- Mod version: `0.11.0-alpha.1`
- Minecraft: `26.2`
- Java: `25`
- Loader: `NeoForge 26.2.0.38-beta`
- Existing-world compatibility: 기존 공용 스킬 SavedData를 유지한다. 강화 적은 엔티티 NBT, affix 장비는 ItemStack CustomData에 저장한다.

## 정체성
숙련이 오를수록 수치만 커지는 것이 아니라 한 번의 행동이 처리하는 물리적 범위와 선택지가 커진다. 플레이어 체급에 맞춰 적 세계와 전리품 체급도 상승한다.

## 6숙련
- 채굴: 3×3 → 5×5 → 7×7 → 9×9 + 광맥 추적.
- 벌목: 연결 통나무 16 → 48 → 128 → 256.
- 농사: 성숙 작물 3×3 → 5×5 → 7×7 → 9×9.
- 전투: 피해 성장 + 파급 2 → 4 → 8체.
- 건축: 선 5/9/17/33, 벽·바닥 3×3/5×5/9×9.
- 기동: 지상 질주 XP, 단차/안전낙하, R 지상돌진, 공중돌진, 최종 돌진 강화.

## 강화 적
- 주변 플레이어 6숙련 평균으로 정예 I / 승천 II / 신화 III 확률이 상승.
- 신속: 피격 후 측후방 회피.
- 철벽: 공격자 밀쳐내기.
- 흡혈: 실제 체력 피해 일부 회복.
- 광전사: 반피 이하 추가 피해 + 공격자 방향 재돌진.
- 스포너 생성은 반복 보상 파밍 방지를 위해 강화 판정 제외.

## 0.11 Affix 장비
Apotheosis(MIT)의 `희귀도 → 장비 카테고리 → affix 조합` 분리를 참고하여 26.2 ItemStack CustomData 기반으로 별도 구현한다.

### 희귀도/드랍
- 정예 I: 철 장비, affix 1개, 추가 장비 드랍 25%.
- 승천 II: 다이아 장비, affix 2개, 65%.
- 신화 III: 네더라이트 장비, affix 3개, 100%.
- 기존 금/에메랄드/다이아 + 경험치 보상은 유지.

### 장비 카테고리
- 무기: `파괴` 피해 증가 / `파급` 이미 해금된 cleave 강화 / `숙련` 전투 XP 증가.
- 곡괭이: `가속` 속도 / `굴착` 이미 해금된 굴착·광맥 체급 증가 / `숙련` 채굴 XP.
- 도끼: `가속` 속도 / `연쇄` 이미 해금된 연결 로그 상한 증가 / `숙련` 벌목 XP.
- 괭이: `가속` 속도 / `광역` 이미 해금된 수확 면적 증가 / `숙련` 농사 XP.

### 숙련 우선 규칙
장비의 체급 affix는 Lv.0에서 광역 기능을 새로 열지 않는다. 숙련이 먼저 해당 행동을 해금한 뒤 장비가 그 행동을 추가 확대한다. 따라서 드랍 운이 스킬 성장 구조를 대체하지 않는다.

## 조작/UI
- `M`: 통합 라디얼 메뉴.
- `R`: 기동 액션.
- `Shift`: 광역·대량 작업 정밀 단일 모드.
- Affix 장비는 아이템 이름에 `[정예]/[승천]/[신화]` 및 affix 조합을 표시한다.

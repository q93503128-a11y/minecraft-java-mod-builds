# Survival Ascension

- Mod version: `0.14.0-alpha.1`
- Minecraft: `26.2`
- Java: `25`
- Loader: `NeoForge 26.2.0.38-beta`
- Existing-world compatibility: 기존 공용 스킬 SavedData, 강화 적 NBT, affix CustomData, 채굴 모드 persistent data를 유지한다. 0.14는 별도 월드 공용 `infrastructure_v1` SavedData만 추가한다.

## 정체성
숙련이 오를수록 한 번의 행동이 처리하는 물리적 범위와 선택지가 커진다. 고숙련에서는 대량 생산된 자원을 공동 인프라에 다시 투입하여 새로운 작업 방식 자체를 해금한다.

## 6숙련
- 채굴: 3×3 → 5×5 → 7×7 → 9×9, 연결 광맥, Lv.90 추출, 인프라 터널 굴착.
- 벌목: 연결 통나무 16 → 48 → 128 → 256.
- 농사: 성숙 작물 3×3 → 5×5 → 7×7 → 9×9, 인프라 자동 재파종.
- 전투: 피해 성장 + 파급 2 → 4 → 8체.
- 건축: 선 5/9/17/33, 벽·바닥 3×3/5×5/9×9.
- 기동: 지상 질주 XP, 단차/안전낙하, R 지상돌진, 공중돌진, 최종 돌진 강화.

## 0.14 공동 인프라
`M → 인프라`에서 서버 월드 공동 프로젝트에 현재 인벤토리의 필요한 재료를 부분 투입한다. 여러 플레이어의 기여는 같은 진행도에 누적되고 월드 SavedData에 저장된다.

### 채석장 네트워크
비용:
- 조약돌 1024
- 철 주괴 256
- 레드스톤 128
- 다이아몬드 32

효과:
- 완공 + 채굴 Lv.90에서 `M → 채굴 → 터널` 사용 가능.
- 첫 파괴 위치를 기준으로 수평 진행 방향 5×5 단면 × 깊이 8블록을 작업 대상으로 만든다.
- 한 번에 즉시 파괴하지 않고 플레이어당 12블록/틱, 서버 전체 64블록/틱, 플레이어당 대기 최대 256으로 분산한다.
- 블록 엔티티, 미로드 청크, 잘못된 도구, 수확 불가 블록, 원점보다 과도하게 단단한 블록은 건너뛴다.
- 모든 파괴는 정상 `player.gameMode.destroyBlock` 경로를 사용한다.
- 내부 터널 파괴는 별도 guard로 다시 터널 작업을 예약하지 못한다.

### 관개 시설
비용:
- 구리 주괴 512
- 철 주괴 128
- 레드스톤 128
- 유리 128
- 슬라임볼 32

효과:
- 완공 + 농사 Lv.30 + 괭이 수확 시 밀/당근/감자/비트/네더와트를 자동 재파종한다.
- 재파종마다 밀씨/당근/감자/비트씨/네더와트 중 대응 재료를 실제로 1개 소비한다.
- 다음 서버 틱에 빈 자리인지, 청크가 로드됐는지, `mayInteract`, 생존 가능 블록 상태, NeoForge placement hook을 다시 확인한 뒤 심는다.
- 멜론/호박은 줄기가 남아 재성장하므로 별도 씨앗 재파종 대상이 아니다.
- 크리에이티브/관전자에는 자동 프로젝트 투입과 재파종 보상을 적용하지 않는다.

## UI 정리
M 메인 라디얼은 `숙련 / 채굴 / 건축 / 장비 / 인프라 / 가이드 / 닫기` 7개만 유지한다. 기존 해금표·통계·조작은 가이드 화면 내부 탭에 남겨 중복 버튼과 링 과밀을 제거한다.

## 외부 설계 흡수
- Mekanism(MIT): Digital Miner의 제한 탐색/대상 필터 철학을 0.13 추출에 적용.
- Create: 코드 MIT, 에셋 ARR. 0.14는 대량 자원 처리량을 단계형 공동 인프라와 새 물리 행동으로 되돌리는 설계 철학만 참고하며 Create 코드/에셋은 번들하지 않는다.
- Skill Proficiencies / Veinminer++ / MineMenu / Building Gadgets 2 / Mob Champions / Apotheosis 고지와 기존 적용은 유지.

## 강화 적 / 장비 경제
- 정예 I / 승천 II / 신화 III + 신속/철벽/흡혈/광전사.
- 희귀 장비는 5종 affix 중 1/2/3개를 획득.
- `M → 장비`에서 재련/분해/정보.
- 최고 재련 비용은 자수정 64 + 다이아 12 + 네더라이트 파편 2.

## 조작
- `M`: 7항목 통합 라디얼.
- `M → 채굴`: 자동/굴착/광맥/추출/터널.
- `M → 건축`: 단일/선/벽/바닥.
- `M → 장비`: 재련/분해/정보.
- `M → 인프라`: 공동 프로젝트 자원 투입/진행 확인.
- `R`: 기동.
- `Shift`: 정밀 단일 작업.

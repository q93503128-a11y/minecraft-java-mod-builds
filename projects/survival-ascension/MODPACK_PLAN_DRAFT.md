# Survival Ascension 모드팩 계획

## 목표
플레이어가 개별 모드 JAR과 필수 라이브러리를 하나씩 찾아 설치하지 않게 한다. 테스트/실플레이용 배포 단위는 `Survival Ascension <버전>.mrpack` 하나로 만들고, Modrinth App에서 가져오면 한 인스턴스가 자동 구성되는 것을 기준으로 한다.

Survival Ascension은 모드팩의 코어 통합 모드다. 외부 콘텐츠 모드가 추가하는 바이옴·광물·몹·보스·장비·차원은 가능한 한 원본 상태로 사용하고, Survival Ascension이 숙련 XP, 월드 승천, 원정, 산업/물류, 어픽스/보상 진행과 연결한다.

## 포장 원칙
- 외부 모드 JAR을 Survival Ascension JAR 안에 합치지 않는다.
- Modrinth에 호스팅된 외부 파일은 `.mrpack`의 `files` 항목에서 원본 CDN을 참조한다.
- Survival Ascension 자체 테스트 JAR은 `overrides/mods/`에 넣는다.
- 우리가 만든 설정, 데이터팩, 호환 설정만 `overrides/`에 넣는다.
- 외부 모드가 없을 때도 Survival Ascension 자체는 로드되도록 선택적 호환을 기본으로 한다.
- 외부 모드의 코드/리소스를 직접 흡수하는 경우는 해당 라이선스가 허용하는 범위에서만 한다.

## 1차 기본 팩
호환 문제를 찾기 쉽게 처음에는 콘텐츠 체감이 큰 소수 모드만 잠근다.

1. Survival Ascension
2. Biomes O' Plenty
3. GlitchCore
4. The Birth of Steve
5. Amethyst Resonance
6. Architectury API
7. Cloth Config API

이 조합의 목적은 한 번에 모든 유명 모드를 넣는 것이 아니라, 첫 실플레이에서 바로 느껴지는 `바이옴 증가 + 던전/보스 + 기능성 장비`를 확보하면서 충돌 원인을 추적할 수 있는 크기를 유지하는 것이다.

## 현재 0.56 원거리 귀속 안정화 상태
- Survival이 발사 순간 인식한 표준 활/쇠뇌 projectile은 기존 affix/Shift 상태와 함께 발사자 UUID를 같은 물리 발사체 NBT에 기록한다.
- 이후 `DamageSource`의 공격자 참조가 사라져도 발사자가 온라인이면 전투 성장·처치/강적 보상·엘리트/변이/전단장 보상을 같은 발사자에게 복구한다.
- 오프라인 보상을 별도 저장하거나 나중에 지급하는 시스템은 만들지 않으며 새 SavedData/패킷/강제청크도 추가하지 않는다.

## 현재 0.55 네이티브 26.2 통합 상태
- `minecraft:sulfur_caves`는 기존 심층권 원정에 들어가며 Sulfur/Cinnabar는 광맥/추출 대상이 아닌 일반 pickaxe-mineable 채굴 지형으로 둔다.
- `minecraft:spears`는 전용 승천 각인 카테고리로 편입하지만 엘리트 기본드롭으로 생성하지 않는다.
- 스피어의 바닐라 Jab/Charge는 그대로 두고, 실제 전진 운동량이 있는 직접 타격에만 0피해/0XP 좁은 돌파선 밀침을 추가한다.

## 현재 0.46 장비 통합 상태
- 표준 sword/pickaxe/axe/shovel/hoe 태그 장비가 승천 각인 대상이다.
- 삽은 채굴 숙련의 속도·XP와 평면 토공 규모를 사용하되 광맥/추출/터널은 사용하지 않는다.
- 잠긴 Amethyst Resonance 바이너리에서 Resonant 5도구의 표준 태그와 고유 기능 보존 경계를 직접 확인했다.
- 외부 장비는 원본 ItemStack과 DataComponent를 유지하고 Survival Ascension 전용 nested CustomData만 추가한다.

## 현재 0.45 통합 상태
- BOP 바이옴은 9지역 원정 태그를 통해 기존 발견/작업/복귀 규칙에 들어간다. Deep은 `glowing_grotto` + `spider_nest`다.
- TBS 핵심 적은 `Enemy`, 비-Enemy 외부 보스는 NeoForge 공용 `BOSSES` 계약을 사용한다.
- 표준 검/곡괭이/도끼/괭이 태그 장비는 0.44 승천 각인을 그대로 사용한다.
- BOP 신규 월드 생성, TBS 던전/보스, Amethyst Resonance 고유 장비 기능 보존은 실제 그래픽 클라이언트 스모크가 남아 있다.

## 2차 확장
### Twilight Forest: Re26
26.2 클라이언트 실행/신규 월드/차원 진입을 실제 검증한 뒤 우선 추가한다. 신규 차원, 지역, 던전, 순차 보스, 장비가 모두 있으므로 엔더 드래곤 이후 `종말 단계`의 대형 콘텐츠 층으로 연결하기 가장 좋은 후보다.

### 월드젠 대체 프로필
Biomes of Overworld 같은 대형 월드젠 모드는 Biomes O' Plenty와 기본으로 중첩하지 않는다. 둘 중 하나를 선택하는 프로필을 먼저 만든 뒤 실제 월드젠 밀도와 구조물 충돌을 비교한다.

### 추가 보스/차원 모드
26.2 호환성과 게임 톤을 확인한 뒤 한 번에 하나씩 추가한다. 숫자를 늘리는 것보다 각 모드 콘텐츠가 Survival Ascension의 진행 루프에서 실제 역할을 갖는지를 우선한다.

## 통합 순서
1. 외부 모드가 제공하는 레지스트리 ID, 태그, 엔티티/아이템 종류를 읽는다.
2. 외부 광물·통나무·작물에 해당 숙련 XP 규칙을 연결한다.
3. 외부 적/보스를 전투 숙련과 월드 승천 단계에 연결한다.
4. 외부 바이옴/차원을 원정 목적지 후보에 연결한다.
5. 외부 장비는 고유 기능을 보존하면서 어픽스 허용 여부를 선택한다.
6. 엔더 드래곤 이후 콘텐츠를 `종말 단계`에서 자연스럽게 노출한다.
7. 실제 클라이언트/신규 월드/장시간 플레이에서 충돌을 검사한 뒤 기본 팩 승격 여부를 정한다.

## 숙련 XP와 모드팩의 관계
외부 콘텐츠가 늘어나면 특정 숙련만 비정상적으로 빨라지거나 느려질 수 있으므로, 모든 숙련에 같은 raw XP 경제를 강제하지 않는다. 채굴처럼 행동 빈도가 높은 숙련은 작은 보정, 건축·기동처럼 실제 XP 기회가 적은 숙련은 큰 보정을 사용한다. 외부 광물/보스도 이 공통 숙련 보정 위에서 작동하게 해 모드가 늘어도 진행 속도 차이가 폭발하지 않게 한다.

## 사용자 경험
최종 테스트 때 사용자는 개별 의존성을 만지지 않는다.

`Modrinth App → 파일에서 가져오기 → Survival Ascension <버전>.mrpack 선택 → 플레이`

이 흐름을 정식 테스트 방식으로 삼는다.

## 아직 검증하지 않은 것
현재 계획/잠금 단계에서는 외부 모드를 한 인스턴스에서 실제 그래픽 클라이언트로 모두 실행했다고 주장하지 않는다. 첫 `.mrpack` 산출 후 별도로:
- 클라이언트 부팅
- 신규 월드 생성
- 오버월드/네더/엔드 월드젠
- 외부 던전/보스 진입
- 외부 장비 장착
- Survival Ascension 숙련/월드 승천 연동
을 실플레이로 확인한다.

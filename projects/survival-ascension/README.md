# Survival Ascension

Minecraft Java 26.2 / NeoForge 26.2.0.38-beta / Java 25.

Survival Ascension turns progression into larger physical actions, then scales enemies, world stages and shared infrastructure back against that growth.

## 0.18.0-alpha.1

### Endgame Ascension Nexus
After the Ender Dragon has pushed the server world into Stage 2 `Endgame / 종말`, players can collectively fund the final traversal project:
- 4 Nether Stars
- 64 Dragon's Breath
- 512 Obsidian
- 512 Amethyst Shards
- 64 Echo Shards

The project cannot accept materials before world ascension Stage 2. Funding remains server-authoritative and world-shared through the existing infrastructure SavedData.

Completion + Mobility Lv.90 upgrades the existing air dash from one use before landing to two uses before landing. Both uses still share the normal Mobility dash cooldown; landing resets the counter. The project does not grant flight or bypass the existing level progression.

### World progression
- Stage 0 Awakening: default.
- Wither kill -> Stage 1 Legendary.
- Ender Dragon kill -> Stage 2 Endgame.
- Stage increases elite frequency/rank odds and tactical warband size/frequency.
- M -> Infrastructure -> Status shows the canonical server stage.

### Current late-game action scale
- Mining: 9x9, Extract and 5x5x8 Tunnel.
- Woodcutting: up to 256 natural-tree logs with smart-tree protection and tick draining.
- Harvesting: 9x9 plus real-seed-cost replant.
- Combat: 8-target cleave plus 5.5-radius/12-target sprint shockwave.
- Construction: 9x9 planes plus 5x5x5 Volume.
- Mobility: dash, air dash, and after the Ascension Nexus two air dashes per airtime.
- Enemies: Elite I / Ascended II / Mythic III traits plus tactical Leader/Bruiser/Hunter/Support warbands, all scaled by world stage.

M main radial remains Skills / Mining / Construction / Equipment / Infrastructure / Guide / Close.

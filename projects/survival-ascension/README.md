# Survival Ascension

Minecraft Java 26.2 + NeoForge용 **대규모 성장형 서바이벌 모드**.

바닐라의 나무→돌→철→다이아→네더라이트 성장에서 장비가 강해져도 결국 한 블록씩 캐고 한 대씩 때리는 밋밋함을 줄이는 것이 목표다. 플레이할수록 캐릭터의 숫자만 커지는 것이 아니라, 한 번에 처리하는 작업 규모와 사용할 수 있는 능력 자체가 커진다.

## 0.1.0-alpha.1

첫 알파는 채굴만 완성한다.

| 채굴 레벨 | 채굴 범위 | 채굴속도 배율(약) |
|---:|:---:|---:|
| 0 | 1×1 | 1.00× |
| 10 | 3×3 | 1.34× |
| 30 | 5×5 | 2.26× |
| 60 | 7×7 | 4.24× |
| 100 | 7×7 | 8.00× |

- 곡괭이 채굴로 XP를 얻는다.
- 광석은 일반 돌보다 XP가 높다.
- 웅크리면서 캐면 레벨과 무관하게 1×1 정밀 채굴한다.
- 광역 채굴은 추가 블록마다 정상 플레이어 파괴 경로를 사용하므로 드랍·내구도·다른 모드의 파괴 이벤트를 최대한 보존한다.
- 블록 엔티티는 안전을 위해 광역 채굴에서 제외한다.

### 명령어

- `/ascension stats` — 현재 채굴 레벨, XP, 채굴 범위, 속도 배율 확인
- `/ascension mining setlevel <0~100>` — 관리자용 테스트 레벨 설정

## 장기 방향

채굴 다음에는 벌목 → 농사 → 전투 → 건축 → 이동으로 확장한다. 최종 목표는 초반 플레이어와 엔드게임 플레이어의 **작업 체급 자체가 다른 서바이벌**이다.

## 독립 구현

행동 기반 숙련과 단계별 능력 해금이라는 장르적 설계 원리를 참고하지만, Project MMO를 포함한 외부 모드의 소스·리소스·데이터를 복사하지 않는다. 이 프로젝트는 독립 구현이다.

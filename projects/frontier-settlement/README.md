# Frontier Settlement

Minecraft Java 26.2 / NeoForge 26.2 cooperative settlement-growth mod.

## Alpha.1 vertical slice

- one server-authoritative shared settlement per world
- settlement founding in the Overworld
- one physical shared barrel stockpile
- live categorized resource ledger: wood, stone, metal, food
- shared compact HUD synced to every connected player
- one persistent construction villager at founding
- `/frontier found`, `/frontier status`, `/frontier rescan` test commands

The final interaction model remains world-space building placement, automatic modest terrain preparation, worker construction, roads and connected outposts. Debug commands are temporary testing seams, not the target UX.

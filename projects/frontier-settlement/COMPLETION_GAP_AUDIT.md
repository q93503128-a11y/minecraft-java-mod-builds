# Frontier Settlement — v0.2 완성도 갭 감사

기준 문서: `ORIGINAL_DESIGN_v0.2.md`
현재 구현 기준: `0.1.0-alpha.33`

상태:
- `완료`: 원본 핵심 요구가 실제 구현됨
- `부분`: 기능은 있으나 원본 범위가 더 남음
- `미구현`: 아직 게임 기능으로 없음
- `외부`: companion이 콘텐츠를 공급하는 영역
- `후보검증`: 버전/코드는 고정했지만 전체 실런타임 묶음 검증이 남음

이 문서는 현재 코드에 맞춰 원본 범위를 줄이는 문서가 아니다. 핵심 `부분/미구현`이 남아 있는 동안 제품을 완성이라고 부르지 않는다.

## 7. 외부 콘텐츠 전략

원본 의도대로 Frontier는 모든 던전/몹/무기/바이옴을 직접 만들지 않고 검증된 외부 모드를 콘텐츠 공급원으로 사용한다.

### Alpha.31

- additive settlement material tags;
- `c:` 호환 재료 태그;
- expedition relic tag;
- 공동 저장소 실제 relic/external weapon 인식;
- Weapons Expanded namespace bridge;
- companion 없이도 부팅 가능한 soft integration.

### Alpha.32

- 시장이 expedition relic을 실제 소비;
- 공유 창고 자동 판매 금지;
- 전용 물리 배럴 opt-in;
- 실물 emerald payout;
- 방문 상인.

### Alpha.33

- Weapons Expanded 등 인식된 외부 무기를 **실제 게임 플레이 가치**로 연결;
- 작업장 전용 정비 배럴에 넣은 손상 외부 무기만 대상;
- 공동 창고의 무기는 자동 선택/이동하지 않음;
- 작업장 주민은 주거 여유 + 실제 식량 4를 사용해 유입;
- 주민은 실제 창고까지 걸어가 금속 1개를 추출·휴대·복귀;
- 금속 1개당 내구도 64 정비;
- 대기 무기가 사라지면 들고 있던 재료도 실제 창고까지 걸어서 반환;
- 작업장과 고급 제작소는 별개 계열 유지.

### 전체 companion 런타임

`COMPANION_LOCK.json`은 Terralith/Lithostitched, DnT, Repurposed Structures, Better Combat 및 의존 라이브러리, Weapons Expanded, Lootr, Sophisticated, Jade, Xaero를 고정한다.

## 10. 현재 결론

Alpha.33은 **10개 기능 건물 + 물리 건설/도로/전초/물류 + 시장 외부 유물 교역 + 작업장 외부 무기 정비**까지 확장했다.

하지만 원본 v0.2 기준으로 건설소, 작은 다리/계단, 수레 정거장, 감시탑, 병영, 고급 제작소, 수변/군사 전초, coarse unloaded simulation, 일부 UI와 전체 companion 런타임 검증이 남아 있다.

따라서 현재 상태는 **넓은 playable alpha**이며 완성본이라고 부르지 않는다.

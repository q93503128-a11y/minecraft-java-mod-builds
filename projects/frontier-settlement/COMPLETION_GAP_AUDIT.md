# Frontier Settlement — v0.2 완성도 갭 감사

기준 문서: `ORIGINAL_DESIGN_v0.2.md`
현재 구현 기준: `0.1.0-alpha.30`

상태 표기:
- `완료`: 현재 코드에 핵심 요구사항이 실제 구현됨
- `부분`: 일부 구현됐지만 원본 범위가 남음
- `미구현`: 원본 요구사항이 아직 실제 게임 기능으로 없음
- `외부`: Frontier 자체 기능이 아니라 선택적 companion 구성/호환 대상으로 관리

이 문서는 현재 구현에 맞춰 요구사항을 줄이는 용도가 아니다. `부분/미구현` 항목은 실제 완료 전까지 계속 남긴다.

## 13. Alpha.30 이후 완성 트랙

아래 순서는 원본 v0.2의 남은 범위를 닫기 위한 구현 순서다. 실플레이에서 치명적 회귀가 나오면 해당 수정이 우선한다.

1. **정본 복구 + companion 구성 확정**
   - 원본 v0.2 저장소 복원
   - 26.2 NeoForge 실제 companion 버전/의존성 확정
   - 호환 정책/라이선스 목록
2. **누락 건물 1차**
   - 작업장, 수레 정거장, 감시탑, 시장
   - 기존 B 팔레트 안에서 카테고리 확장, 새 핵심 키 추가 금지
3. **누락 건물 2차 / 후반**
   - 건설소, 병영, 고급 제작소
   - 실제 기능과 주민 역할 연결
4. **도로 지형 적응**
   - 계단
   - 작은 교량
   - 급경사 회피 강화
5. **전초 전문화 확장**
   - 해안/강 어업·교역
   - 위험 지역 군사 거점
6. **언로드 저빈도 시뮬레이션**
   - 물리 아이템 권위를 깨지 않는 범위의 생산/물류 coarse simulation
7. **외부 모드 선택적 통합**
   - Jade 최소 상태 provider
   - Xaero waypoint/위치 정보 연동 가능성
   - Terralith/DnT 지형·구조물 탐험 목표 연동
8. **UI 원본 회귀검사**
   - 건물 상태 패널
   - 건설 자재/진행
   - 측면 알림
9. **전체 실제 플레이 / 멀티 합격 기준 재검증**

이 트랙의 `미구현/부분` 핵심 항목이 남아 있는 동안 제품 상태를 `완성`이라고 부르지 않는다.

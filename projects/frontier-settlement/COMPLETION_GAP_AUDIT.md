# Frontier Settlement — v0.2 완성도 갭 감사

기준 문서: `ORIGINAL_DESIGN_v0.2.md`
현재 구현 기준: `0.1.0-alpha.32`

상태:
- `완료`: 원본의 핵심 요구가 현재 코드에 실제 구현됨
- `부분`: 실제 기능은 있으나 원본 범위가 더 남음
- `미구현`: 원본 요구가 아직 게임 기능으로 없음
- `외부`: Frontier 자체 재구현보다 companion이 콘텐츠를 공급하는 영역
- `후보검증`: 코드/버전은 고정했지만 전체 실런타임 묶음 검증이 아직 필요

이 문서는 현재 코드에 맞춰 원본 범위를 줄이는 문서가 아니다. 핵심 `부분/미구현`이 남아 있는 동안 제품을 완성이라고 부르지 않는다.

## 9. 외부 콘텐츠 전략

원본 의도와 마을키우기 기획의 핵심: Frontier가 모든 던전/몹/무기/바이옴을 직접 만들지 않고 검증된 외부 모드를 **콘텐츠 공급원**으로 사용한다.

### Alpha.31 완료

- additive settlement material tags;
- `c:` 호환 재료 태그;
- expedition relic tag;
- 공동 저장소의 실제 relic/external weapon 인식;
- Weapons Expanded namespace bridge;
- companion 없이도 Frontier 부팅 가능한 soft integration.

### Alpha.32 완료

- 시장이 `expedition_relics`를 실제 소비하는 첫 progression bridge;
- 공유 창고 자동 판매 금지;
- 시장 전용 물리 배럴에 플레이어가 넣은 것만 거래;
- 실물 emerald payout;
- tagged visiting merchant;
- output full 시 안전 정지/롤백.

### 전체 companion 런타임

`COMPANION_LOCK.json`에는 Terralith/Lithostitched, DnT, Repurposed Structures, Better Combat 및 의존 라이브러리, Weapons Expanded, Lootr, Sophisticated, Jade, Xaero를 고정했다.

상태: **후보검증** — 각 버전/의존성과 Frontier 단독 CI는 확인했지만 전부 함께 같은 26.2 인스턴스에서 실제 부팅/새 월드/멀티를 아직 끝내지 않았다.

| 외부 축 | Frontier 연결 상태 |
| --- | --- |
| Terralith | 부분 — 태그 기반 지형/전초 판정 보강 미완 |
| Dungeons and Taverns | 부분 — 획득한 relic의 시장 소비는 가능, 구조물 발견 자체 progression 미연결 |
| Repurposed Structures | 부분 — 탐험 콘텐츠 공급, 구조물 발견 progression 미연결 |
| Better Combat | 외부/후보검증 — Frontier 재구현 없음, 풀스택 회귀 필요 |
| Weapons Expanded | 부분 — 외부 무기 인식, 작업장/제작/경비 활용 미완 |
| Lootr | 외부/후보검증 — 멀티 던전 보상 역할, 풀스택 확인 필요 |
| Sophisticated Backpacks | 외부/후보검증 — 창고 오인 회귀 필요 |
| Jade | 미구현 연동 — Frontier provider 없음 |
| Xaero | 미구현 연동 — waypoint/API 연결 없음 |
| 추가 몬스터 | 후보 — baseline stack 안정 후 도입 |

## 13. 현재 우선순위

1. **Alpha.32 최종 문서 SHA CI까지 녹색으로 고정**.
2. `COMPANION_LOCK.json` 전체를 한 인스턴스에 설치해 fresh-world 실제 런타임/키 충돌/구조물 밀도/멀티 보상을 검사.
3. 누락 건물 1차 계속: **작업장 / 수레 정거장 / 감시탑**.
4. 외부 무기/희귀 아이템을 작업장·고급 제작에 실제 연결.
5. 도로 계단/작은 교량/급경사 처리.
6. 해안·강 어업/교역 전초 + 위험 지역 군사 거점.
7. 언로드 저빈도 시뮬레이션.
8. Jade 상태 provider / 건물 상태 패널 / 측면 알림.
9. 전체 서바이벌+멀티 합격 기준 재검증.

실플레이에서 치명적 회귀가 발견되면 위 breadth 순서보다 해당 근본 수정이 우선한다.

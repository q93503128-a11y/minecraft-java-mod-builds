# Arcane Circle: Ninefold Arcana 0.4.0-alpha.1

Minecraft Java 26.2 + NeoForge용 구중 마법학 전투 시스템이다. 현재 1~3써클, 숫자키 주문 슬롯, 최대 삼중 즉석 융합, 실전 숙련 각인, 지팡이 장비 효과를 구현한다.

## 조작

- `C`: 드래그 가능한 구중 마도서 열기
- `1`~`5`: 해당 주문 슬롯 즉시 시전
- `X`를 누른 채 `1`~`5`: 주문을 융합 대기열에 순서대로 추가
- `X` 놓기: 선택한 2~3개 주문을 융합해 시전
- 마도서에서 슬롯을 먼저 누르고 주문 문양을 누르면 장착
- 마도서 목록은 마우스 휠로 이동

## HUD와 상태 화면

- 화면 하단에 다섯 개의 정사각형 주문 슬롯을 표시한다.
- 각 슬롯은 번호, 주문 고유 룬, 이름과 남은 쿨타임을 표시한다.
- 쿨타임은 사각 슬롯의 외곽을 시계방향으로 감싸는 진행선과 초 단위 숫자로 보인다.
- X 융합 중에는 선택한 주문과 예상 결과가 슬롯 위에 표시된다.
- 인벤토리에는 써클, 마력, 회복량, 통찰, 현재 지팡이와 주요 보정치를 표시한다.

## 융합과 각인

성공한 실제 융합 시전만 숙련도를 올린다.

- 2써클 이중 융합: 4회
- 3써클 이중 융합: 7회
- 3써클 삼중 융합: 10회

숙련도를 모두 채운 결과 주문은 일반 주문으로 각인되어 1~5 슬롯에 직접 장착할 수 있다. 마도서의 `융합식` 탭에서 모든 조합식과 현재 숙련도를 확인할 수 있다. 재료 순서는 상관없지만 중복 재료 수는 정확히 맞아야 한다.

## 구현된 삼중 융합

- 마력탄 + 불씨 + 서리침 → 삼상 마력포
- 질풍보 + 소형 방벽 + 마력탄 → 폭풍 성벽
- 불씨 + 치유 + 중형 방벽 → 불사조 성역

기존 이중 융합식도 모두 유지한다.

## 지팡이

9종의 지팡이가 메인 손 또는 보조 손에서 마법 수치를 바꾼다.

- 견습 마도봉: 최대 마력·회복
- 홍염 지팡이: 화염 위력
- 빙하 지팡이: 서리 위력·범위
- 청풍 지팡이: 빠른 쿨다운·풍류 강화
- 수호 지팡이: 수호술 위력·최대 마력
- 생명의 지팡이: 치유·회복 강화
- 균열 지팡이: 공간술 범위
- 현자의 지팡이: 마력 효율·쿨다운
- 대마도사의 지팡이: 전반적인 고급 보정

첫 각성 시 견습 마도봉 하나가 지급되며, 모든 지팡이는 도구·유틸리티 창작 탭에서 확인할 수 있다.

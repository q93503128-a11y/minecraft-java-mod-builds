# Arcane Circle: Ninefold Arcana 0.5.0-alpha.1

Minecraft Java 26.2 + NeoForge용 구중 마법학 전투 시스템이다. 현재 1~3써클, 다섯 주문 슬롯, 최대 삼중 즉석 융합, 실전 숙련 각인, 영구 쿨타임 저장, 지팡이 장비와 생존 제작을 구현한다.

## 조작

- `C`: 반응형 구중 마도서 열기
- `1`~`5`: 해당 주문 슬롯 즉시 시전
- `X`를 누른 채 `1`~`5`: 주문을 융합 회로에 추가
- `X` 놓기: 선택한 2~3개 주문을 융합해 시전
- 마도서에서 슬롯을 먼저 누르고 주문 카드를 누르면 장착
- 마도서 상단 드래그: 창 위치 이동
- 마도서 목록에서 마우스 휠: 주문·융합식·지팡이 목록 이동

숫자 주문키 사용 뒤 바닐라 핫바 선택 위치를 복원한다. 메뉴를 열거나 접속이 끊기면 미완성 융합 회로를 취소하며, 회로는 10초 뒤 자동 만료된다.

## HUD와 마도서

- 화면 하단에 다섯 정사각형 주문 슬롯을 표시한다.
- 슬롯에는 번호, 학파별 고유 룬, 주문명과 남은 쿨타임이 표시된다.
- 쿨타임은 슬롯 외곽을 시계방향으로 감싸는 진행선과 초 단위 숫자로 보인다.
- 좁은 화면에서는 마력 막대를 슬롯 위로 옮겨 양옆 넘침을 방지한다.
- 융합 중에는 현재 재료, 완성 결과, 세 번째 주문 추가 가능 여부 또는 남은 후보 수를 표시한다.
- 인벤토리 상태 패널은 여유 공간에 따라 측면형과 상단 압축형을 자동 선택한다.
- 마도서는 `주문`, `융합식`, `지팡이`, `마력핵` 네 탭으로 구성된다.
- 잠긴 주문을 누르면 미각인 또는 써클 부족 이유를 바로 표시한다.

## 시전 안정성

- 공격 주문은 시야가 가리지 않은 유효 대상을 우선 선택한다.
- 팀원과 플레이어가 길들인 동물은 공격·범위 마법에서 제외한다.
- 불사조 성역은 아군 플레이어와 길들인 동물을 치유하고 적만 태운다.
- 이동 주문은 월드 경계, 액체, 바닥 지지와 머리 공간을 검사한 뒤 전이한다.
- 대상이나 안전 공간이 없으면 마력·쿨타임을 소모하지 않고 실패 연출도 출력하지 않는다.
- 쿨타임은 월드 저장 데이터에 기록되어 재접속이나 서버 재시작으로 초기화되지 않는다.

## 융합과 각인

성공한 실제 융합 시전만 숙련도를 올린다.

- 2써클 이중 융합: 4회
- 3써클 이중 융합: 7회
- 3써클 삼중 융합: 10회

숙련도를 모두 채운 결과 주문은 일반 주문으로 각인되어 1~5 슬롯에 직접 장착할 수 있다. 재료 순서는 상관없지만 같은 주문을 여러 번 요구하는 식에서는 개수까지 정확히 맞춘다. 잘못된 다음 재료는 기존 회로를 망가뜨리지 않고 거부된다.

### 삼중 융합

- 마력탄 + 불씨 + 서리침 → 삼상 마력포
- 질풍보 + 소형 방벽 + 마력탄 → 폭풍 성벽
- 불씨 + 치유 + 중형 방벽 → 불사조 성역

기존 이중 융합식도 모두 유지한다.

## 지팡이

지팡이는 주 손을 우선하며, 주 손에 없으면 보조 손의 효과가 적용된다. 각 지팡이는 서로 다른 32×32 전용 픽셀아트와 효과를 가진다.

- 견습 마도봉: 최초 1회 지급, 최대 마력·회복 강화
- 홍염 지팡이: 화염 위력 강화
- 빙하 지팡이: 서리 위력·범위 강화
- 청풍 지팡이: 연속 시전·이동술 강화
- 수호 지팡이: 방벽 위력·최대 마력 강화
- 생명의 지팡이: 치유·마력 회복 강화
- 균열 지팡이: 공간술 사거리·전이 보호막 강화
- 현자의 지팡이: 마력 효율·회로 냉각 강화
- 대마도사의 지팡이: 전반적인 최고위 보정

견습 마도봉을 제외한 8종은 생존 제작식이 있으며, 마도서의 `지팡이` 탭과 아이템 설명에서 재료를 확인할 수 있다. 최초 지급 여부는 마법사 프로필에 저장되므로 기존 월드에서도 한 번만 지급되고, 버리거나 제작 재료로 사용해도 다시 복제되지 않는다.

## 자동 검사

```bash
chmod +x gradlew
python3 tools/test_magic_contract.py
./gradlew --no-daemon --no-configuration-cache clean build
python3 tools/verify_jar.py build/libs/arcanecircle-0.5.0-alpha.1.jar
```

검사는 저장 마이그레이션, 입력, 네트워크, 융합, 아군 보호, 반응형 UI, 제작식, 모델 연결, 9개 텍스처의 PNG 형식·크기·중복과 JAR 누락을 확인한다.

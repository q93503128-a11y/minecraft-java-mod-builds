# Arcane Circle: Ninefold Arcana 0.6.0-alpha.1

Minecraft Java 26.2 + NeoForge용 구중 마법학 전투·성장 시스템이다. 이번 버전은 1~5써클, 누름-전개-해제 시전, 위치별 마법진, 주문서 학습, 사서 거래, 고위 지팡이 성장과 기존 저장 호환을 구현한다.

## 0.12.1-alpha.10

- 체력·피해를 `100 RPG HP = 바닐라 20 HP`로 통일
- 써클별 마도사 체력·주문 위력·숙련 보상을 기하급수화하고 즉시 반격 보장
- 영구 사망 세력 대표 4명, 플레이어 포함 세력 최강자 기록, 관계 상세 UI
- 고정 난이도 의뢰와 압축형 의뢰 UI
- 균열 황야·빙결 묘역·별먹는 심연 및 영구 토벌 마수 3종
- 4개 테마 장비 세트 12개와 성간 보행화 자유 비행
- 실제 효과 범위와 마법 기하 렌더 범위 공유, 학파별 투사체 형상 분리

## 조작

- `C`: 구중 마도서 열기
- `1`~`5` 누르기: 해당 주문의 마법진 전개 및 조준 유지
- `1`~`5` 놓기: 마법 발사 또는 효과 확정
- `X`를 누른 채 `1`~`5`: 주문을 2~3중 융합 회로에 추가
- `X` 놓기: 완성한 융합 주문 시전
- 마도서에서 슬롯 선택 후 주문 카드 선택: 장착
- 마도서 상단 드래그: 창 이동
- 마우스 휠: 목록 이동

마법 입력용 `1`~`5` 클릭은 바닐라 핫바 처리 전에 소모하므로 주문을 준비하거나 발사할 때 손에 든 아이템이 바뀌지 않는다.

## 마법진과 충전 시전

숫자키를 누른 순간에는 마력과 쿨타임을 소모하지 않는다. 서버가 주문 준비 상태를 저장하고 마법진을 유지하며, 숫자키를 놓았을 때 대상·사거리·안전 위치를 다시 검사한 뒤 실제 효과를 실행한다.

- 전방 투사체·광선: 플레이어 시선 앞 공중 마법진
- 이동술: 발밑 또는 조준 지면 마법진
- 방벽·신체 강화·치유: 신체와 발밑 회로
- 자기 중심 영역술: 시전자 지면 대형 마법진
- 지정 영역술: 조준한 지면 마법진
- 속박술: 대상 주변 결속 마법진

유지 한계는 12초이며, 사망·차원 이동·로그아웃·메뉴 진입 시 준비 중인 회로를 안전하게 해제한다.

## 1~5써클 주문

새 마법사 프로필은 익힌 주문이 없는 상태로 시작한다. 최초 한 번 지급되는 `초심자 마도서`를 읽으면 1써클 기초 주문 5종을 습득한다.

### 1써클 — 기초 회로

- 마력탄
- 불씨
- 서리침
- 질풍보
- 소형 방벽

### 2써클 — 모험 실전술

- 치유
- 단거리 전이
- 석화 피부
- 번개 갈래
- 마나 랜스

### 3써클 — 전장 제어술

- 중형 방벽
- 화염 파도
- 빙창
- 비전 감응
- 부유

### 4써클 — 전략 마법

- 유성 파편
- 블리자드
- 뇌전 감옥
- 광역 치유
- 공간문

### 5써클 — 영역·성채급 마법

- 업화 영역
- 절대영도
- 천공 폭풍
- 아이기스 성채
- 비전 소멸포

기존 10개 융합 주문도 유지된다. 현재 총 주문 수는 35개다.

## 주문서 습득과 가격

2~5써클 전승 주문은 각각의 주문서를 우클릭해 소모해야 영구 습득된다. 현재 써클보다 높은 책은 해독할 수 없으며 소모되지 않는다.

주문서는 제작하거나 사서에게 구매할 수 있다. 제작식은 마법 부여된 책, 주문별 촉매, 자수정·다이아몬드·메아리 조각·네더라이트·네더의 별 등 써클에 맞는 희귀 재료를 요구한다.

사서 거래의 에메랄드 환산 기준은 다음처럼 기하급수적으로 증가한다.

- 초심자 마도서: 12
- 2써클 주문서: 27
- 3써클 주문서: 72
- 4써클 주문서: 216 + 다이아몬드
- 5써클 주문서: 576 + 네더의 별

## HUD와 마도서

- 1~5 주문 슬롯의 최대 크기를 27픽셀로 줄였다.
- 주문 슬롯 전체를 하트·허기·핫바보다 위로 이동했다.
- 왼쪽 마력·써클·지팡이 상태 영역은 기존 크기를 유지한다.
- 준비 중인 슬롯은 금색 테두리와 `READY` 상태를 표시한다.
- 빈 슬롯은 명확한 빈 칸으로 표시한다.
- 마도서 툴팁은 습득 방식, 마법진 전개 위치, 효과, 위력, 사거리와 쿨타임을 보여준다.
- 마력핵 탭은 1~5써클 구현 상태를 반영한다.

## 지팡이 성장

후반 지팡이의 체급 차이를 크게 벌렸다.

- 견습 마도봉: 최대 마력 +25, 입문 보정
- 원소 지팡이: 주력 학파 위력 약 1.45~1.55배
- 수호·생명·균열 지팡이: 전문 학파 약 1.75~1.85배
- 현자의 지팡이: 최대 마력 +155, 소모 0.60배, 위력 1.52배, 쿨타임 0.56배
- 대마도사의 지팡이: 최대 마력 +280, 소모 0.46배, 위력 2.20배, 사거리 1.80배, 쿨타임 0.43배, 회복 2.15배

현자의 지팡이는 균열 지팡이·마법이 부여된 책·금 블록·다이아몬드 블록을 요구한다. 대마도사의 지팡이는 현자의 지팡이·네더의 별·메아리 조각·네더라이트 블록을 요구한다.

## 저장 호환과 안정성

- 기존 v0.5 주문, 슬롯, 융합 숙련도, 마력과 영구 쿨타임 유지
- 새 필드는 선택형 기본값으로 마이그레이션
- 아군 플레이어와 소유한 길들인 동물은 공격 주문에서 제외
- 이동술은 월드 경계, 액체, 바닥 지지와 머리 공간 검사
- 실패한 시전은 마력과 쿨타임을 소모하지 않음
- 쿨타임은 재접속·서버 재시작으로 초기화되지 않음

## 자동 검사

```bash
chmod +x gradlew
python3 tools/test_magic_contract.py
./gradlew --no-daemon --no-configuration-cache clean build
python3 tools/verify_jar.py build/libs/arcanecircle-0.6.0-alpha.1.jar
```

검사는 Java 25 컴파일, 1~5써클 주문 수, 충전 네트워크, 바닐라 핫바 차단 입력, 주문서 20종, 사서 거래 5단계, 제작식, 저장 마이그레이션, 지팡이 9종과 JAR 내부 구조를 확인한다.

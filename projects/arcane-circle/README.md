# Arcane Circle: Ninefold Arcana 0.3.0-alpha.1

Minecraft Java 26.2 + NeoForge용 구중 마법학 테스트 모드다. v0.3은 메뉴에서 결과 주문을 연구하는 구조를 폐기하고, 전투 직전에 고른 두 주문을 실제로 함께 시전해 새 마법을 만드는 방식으로 교체했다.

## 조작

- `C`: 성좌 마도서 열기
- `R`: 주력 회로 주문 단독 시전
- `G`: 주력 회로 + 직조 회로 즉석 융합 시전
- `Z / X`: 주력 주문 이전 / 다음
- `V / B`: 직조 주문 이전 / 다음
- 마도서에서 회로를 누른 뒤 주문 문양을 눌러 직접 선택

`F`는 바닐라 보조 손 교체 키와 충돌하므로 기본 융합 키를 `G`로 지정했다. 키 설정에서 바꿀 수 있다.

## 실전 융합과 각인

1. 주력·직조 회로에 서로 다른 주문을 선택한다.
2. 조합식이 존재하면 중앙 융합핵에 결과 주문이 표시된다.
3. `G`로 결과 주문을 즉시 시전한다. 별도의 연구 완료 버튼은 없다.
4. 성공한 실제 시전만 숙련도를 올린다.
5. 2써클 융합은 4회, 3써클 융합은 7회 성공하면 결과 주문이 영구 등록된다.
6. 등록된 결과 주문은 회로에 직접 놓고 `R`로 단독 시전할 수 있다.

## 새 마도서 UI

기존 평면 카드 대시보드를 삭제했다.

- **주문 성좌**: 두 원형 회로, 중앙 융합핵, 1~3써클 별자리 주문 문양
- **융합 각인**: 모든 결과 주문의 실전 숙련도를 방사형 각인으로 표시
- **마력핵**: 1~9중 동심 회로와 마력·통찰·써클 상태 표시

타 게임 UI 자산을 복제하지 않고, 고급 판타지 마도서·천구의·룬 회로의 시각 문법을 Minecraft 렌더링 프리미티브로 새로 구현했다.

## 구현된 융합식

- 마력탄 + 불씨 → 화염창
- 서리침 + 소형 방벽 → 빙결 사슬
- 질풍보 + 마력탄 → 풍인
- 화염창 + 불씨 → 화염구
- 빙결 사슬 + 서리침 → 서리 폭발
- 풍인 + 마력탄 → 연쇄 마력뢰
- 단거리 전이 + 질풍보 → 균열 도약

조합 순서는 상관없다.

# Arcane Circle: Ninefold Arcana 0.2.0-alpha.1

기존 바닥 마법진·촉매 조합 실험을 폐기하고 마력핵, 주문서, 융합 연구, 1~3써클 성장과 단축키 시전으로 다시 만든 테스트 모드다.

## 조작

- `C`: 마도서 UI
- `R`: 선택 주문 시전
- `Z / X`: 이전·다음 주문 슬롯
- 마도서의 주문 카드를 클릭: 현재 선택 슬롯에 장착
- 융합 연구 카드를 클릭: 선행 주문을 알고 있으면 결과 주문 습득

## 써클 규칙

- 1써클: 최대 마력 100, 초당 회복 2
- 2써클: 최대 마력 170, 초당 회복 4
- 3써클: 최대 마력 260, 초당 회복 6
- 시전 통찰 8에서 2써클, 24에서 3써클 개방
- 현재 써클보다 낮은 주문은 차이마다 마력 -10%, 쿨타임 -18%, 위력 +12%, 사거리 +10%

## 주문 습득

기초 마도서 주문과 일부 전승 주문은 처음부터 알려진다. 융합 주문만 조합 연구가 필요하다. 따라서 상위 써클 주문이 반드시 조합으로만 만들어지는 구조가 아니다.

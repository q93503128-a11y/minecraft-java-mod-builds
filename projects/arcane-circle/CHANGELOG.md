# Changelog

## 0.5.0-alpha.1 - 2026-08-01

### 오류 수정

- 쿨타임을 월드 저장 데이터로 이동해 재접속·서버 재시작 초기화 우회 제거
- 로그아웃, 사망 후 부활, 차원 이동, 서버 종료 시 남은 융합 대기열 정리
- 잘못된 융합 재료가 기존 대기열 전체를 망가뜨리던 문제 수정
- 대상이나 안전한 이동 위치가 없는 실패 주문에서 마법진·소리·마력·쿨타임이 먼저 처리되던 문제 수정
- 공격 주문에 시야 검사를 추가하고 팀원·길들인 동물 오폭 방지
- 불사조 성역이 아군을 공격할 수 있던 문제를 치유·적 공격 분리로 수정
- 전이 주문의 월드 경계, 액체, 머리 공간, 바닥 지지 검사 강화
- 구버전 슬롯에 알 수 없거나 배우지 않은 주문이 남는 저장 마이그레이션 문제 수정
- 숫자 주문키 사용 시 바닐라 핫바 슬롯이 함께 이동하는 현상을 선택 위치 복원으로 완화
- 메뉴 진입 중 남아 있던 X 융합 입력과 클릭 누적 제거
- 최초 지팡이 지급 여부를 마법사 프로필에 저장해 중복 지급 및 API 의존 제거

### 사용성·디자인

- 마도서를 주문·융합식·지팡이·마력핵 4탭 반응형 UI로 재구성
- 마도서 위치, 선택 슬롯, 탭별 스크롤 위치 유지
- 잠긴 주문 선택 시 미각인·써클 부족 사유 표시
- 작은 화면용 상단 마력 HUD와 압축 인벤토리 상태 패널 추가
- 융합 후보 수, 완성 결과, 세 번째 회로 확장 가능 여부 표시
- 학파별 룬과 실제 시전 마법진 문법 차별화
- 9개 지팡이에 서로 다른 32×32 전용 픽셀아트와 휴대형 모델 적용

### 구현 확장

- 부분 융합 재료로 완성 가능한 조합 후보를 계산하는 다중집합 검색 추가
- 융합 대기열 10초 자동 만료 추가
- 공간·바람·방벽·치유 지팡이 보정이 실제 이동 거리, 보호막, 회복에 반영되도록 수정
- 견습 마도봉 최초 1회 지급과 나머지 8종 생존 제작식 추가
- 9개 지팡이 제작 정보와 보정치를 마도서에서 확인 가능
- 저장·입력·네트워크·UI·시전·아군 보호·제작식·모델·텍스처·JAR을 검사하는 자동 감사 확대

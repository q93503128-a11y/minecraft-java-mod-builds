# Changelog

## 0.6.0-alpha.1 - 2026-08-01

### 시전 체계

- 숫자키 즉시 시전을 `누름 → 마법진 전개·조준 유지 → 놓기 → 발사` 구조로 전환
- 준비 단계에서는 마력과 쿨타임을 소모하지 않고, 해제 순간 대상과 안전 위치를 다시 검사
- 전방, 발밑, 신체, 시전자 지면, 조준 지면, 대상 결속의 6개 마법진 전개 위치 추가
- 전방 투사체와 광선은 시선에 수직인 공중 마법진에서 발사
- 이동기·결계·치유·자기 중심 영역·지정 영역·속박술의 전개 위치를 역할별로 분리
- 12초 유지 한계와 사망·차원 이동·로그아웃·메뉴 진입 취소 처리 추가

### 입력·HUD

- 클라이언트 Pre 틱에서 바닐라 1~5 핫바 클릭을 먼저 소모해 주문키와 아이템 전환 중복 제거
- 기존 선택 슬롯을 사후 복원하던 임시 방식을 삭제
- 주문 슬롯 최대 크기를 38에서 27픽셀로 축소
- 주문 슬롯 줄을 하트·허기·바닐라 핫바보다 위로 이동
- 왼쪽 마력·써클·지팡이 상태 영역은 기존 크기 유지
- 준비 중 슬롯의 금색 테두리와 READY 상태 표시 추가
- 빈 주문 슬롯 표시 및 빈 슬롯 저장·동기화 수정

### 1~5써클 마법 세계

- 직접 습득 주문 25개와 기존 융합 주문 10개로 총 35개 구현
- 2써클: 석화 피부, 번개 갈래, 마나 랜스 추가
- 3써클: 화염 파도, 빙창, 비전 감응, 부유 추가
- 4써클: 유성 파편, 블리자드, 뇌전 감옥, 광역 치유, 공간문 추가
- 5써클: 업화 영역, 절대영도, 천공 폭풍, 아이기스 성채, 비전 소멸포 추가
- 마력핵 최대 써클을 5로 확장하고 통찰 승급 기준·최대 마력·회복량 확장

### 주문서 성장

- 새 프로필은 익힌 주문과 장착 주문이 없는 상태로 시작
- 최초 한 번 지급되는 초심자 마도서로 1써클 기초 주문 5종 습득
- 2~5써클 전승 주문용 소모성 주문서 20종 추가
- 현재 써클보다 높은 주문서는 소모하지 않고 해독 실패 처리
- 주문서 습득과 빈 슬롯 자동 장착 상태를 월드 저장 데이터에 영구 보존
- 주문서 20종의 고가 생존 제작식 추가
- 사서 1~5레벨 주문서 거래 추가
- 에메랄드 환산 가격을 12 → 27 → 72 → 216 → 576으로 증가
- 4써클 거래에는 다이아몬드, 5써클 거래에는 네더의 별 추가 요구

### 지팡이 성장

- 모든 중후반 지팡이의 전문 학파 위력과 범용 보정을 상향
- 현자의 지팡이를 최대 마력 +155, 소모 0.60배, 위력 1.52배, 쿨타임 0.56배로 강화
- 대마도사의 지팡이를 최대 마력 +280, 소모 0.46배, 위력 2.20배, 사거리 1.80배, 쿨타임 0.43배, 회복 2.15배로 강화
- 현자의 지팡이 제작에 균열 지팡이와 다이아몬드 블록 요구
- 대마도사의 지팡이 제작에 네더라이트 블록 요구

### 저장·검사

- v0.5의 주문, 슬롯, 융합 숙련도, 마력, 지급 여부와 영구 쿨타임 호환 유지
- 신규 주문서 지급·학습 필드를 선택형 기본값으로 추가
- Java 25 컴파일, 충전 네트워크, 1~5써클 주문 수, 주문서 20종, 사서 거래 5단계, 제작식, HUD, 지팡이와 JAR 구조 검사를 자동화

## 0.5.0-alpha.1 - 2026-08-01

### 오류 수정

- 쿨타임을 월드 저장 데이터로 이동해 재접속·서버 재시작 초기화 우회 제거
- 로그아웃, 사망 후 부활, 차원 이동, 서버 종료 시 남은 융합 대기열 정리
- 잘못된 융합 재료가 기존 대기열 전체를 망가뜨리던 문제 수정
- 대상이나 안전한 이동 위치가 없는 실패 주문에서 마법진·소리·마력·쿨타임이 먼저 처리되던 문제 수정
- 공격 주문에 시야 검사를 추가하고 팀원·길들인 동물 오폭 방지
- 불사조 성역이 아군을 공격할 수 있던 문제를 치유·적 공격 분리로 수정
- 전이 주문의 월드 경계, 액체, 머리 공간, 바닥 지지 검사 강화
- 구버전 슬롯에 알 수 없거나 배우지 않은 주문이 남는 저장 마이그레이션 문제 수정
- 숫자 주문키 사용 시 바닐라 핫바 슬롯이 함께 이동하는 현상을 선택 위치 복원으로 완화
- 메뉴 진입 중 남아 있던 X 융합 입력과 클릭 누적 제거
- 최초 지팡이 지급 여부를 마법사 프로필에 저장해 중복 지급 및 API 의존 제거

### 사용성·디자인

- 마도서를 주문·융합식·지팡이·마력핵 4탭 반응형 UI로 재구성
- 마도서 위치, 선택 슬롯, 탭별 스크롤 위치 유지
- 잠긴 주문 선택 시 미각인·써클 부족 사유 표시
- 작은 화면용 상단 마력 HUD와 압축 인벤토리 상태 패널 추가
- 융합 후보 수, 완성 결과, 세 번째 회로 확장 가능 여부 표시
- 학파별 룬과 실제 시전 마법진 문법 차별화
- 9개 지팡이에 서로 다른 32×32 전용 픽셀아트와 휴대형 모델 적용

### 구현 확장

- 부분 융합 재료로 완성 가능한 조합 후보를 계산하는 다중집합 검색 추가
- 융합 대기열 10초 자동 만료 추가
- 공간·바람·방벽·치유 지팡이 보정이 실제 이동 거리, 보호막, 회복에 반영되도록 수정
- 견습 마도봉 최초 1회 지급과 나머지 8종 생존 제작식 추가
- 9개 지팡이 제작 정보와 보정치를 마도서에서 확인 가능
- 저장·입력·네트워크·UI·시전·아군 보호·제작식·모델·텍스처·JAR을 검사하는 자동 감사 확대

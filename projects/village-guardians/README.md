# Village Guardians — 마을지키기

마인크래프트 생존 월드의 한 마을을 실제 공동체로 운영하고 지키면서, 플레이어도 강력한 수호자로 성장하는 NeoForge JAR 모드다.

## 통치 코어

- 첫 접속자가 임시 촌장이 된다.
- 촌장은 한 명만 존재한다.
- 촌장 직책과 실무 역할은 별개다.
- 멀티플레이어는 다음 역할 중 하나를 선택한다.
  - `guard_captain` 경비대장
  - `builder` 건축가
  - `quartermaster` 보급관
  - `scout` 정찰병
  - `steward` 농업관
  - `medic` 의무관
- 마을 전체 시간 진행은 촌장이 안건을 발의하고 온라인 플레이어 과반수가 찬성해야 실행된다.
- 자연적인 바닐라 시간 흐름은 꺼진다.
- 다른 명령이나 모드가 일주기를 다시 켜도 서버가 주기적으로 마을 시간을 복구한다.
- 촌장, 역할, 마을 날짜와 시간 단계는 월드 저장 데이터에 영구 보존된다.

## 0.2 RPG 알파

- 적대 몬스터를 처치하면 RPG 경험치를 얻는다.
- 레벨과 경험치는 월드에 영구 저장된다.
- 최고 레벨은 우선 30이다.
- 레벨이 오를 때마다 가하는 피해가 증가하고 받는 피해가 감소한다.
- 3레벨 단위로 추가 최대 체력이 증가한다.
- 5레벨 단위로 공격과 방어 성장이 크게 뛰어오른다.
- 30레벨 기준 공격 약 6.23배, 받는 피해 28%, 추가 체력 36포인트를 목표로 한다.
- 각 역할은 `/vg skill`로 첫 액티브 스킬을 사용할 수 있다.
- 역할 스킬은 주변 12블록 안의 같은 차원 아군에게 적용되며 레벨에 따라 강해진다.

### 역할 스킬

- 경비대장 — **전장의 함성**: 힘과 저항 강화
- 건축가 — **긴급 방벽**: 강한 저항과 흡수 체력
- 보급관 — **전투 보급**: 즉시 회복, 재생, 흡수 체력
- 정찰병 — **질풍 정찰**: 이동 속도, 점프, 야간 시야
- 농업관 — **풍요의 기운**: 채굴 속도와 재생
- 의무관 — **구호의 빛**: 대량 회복, 재생, 흡수 체력

## 명령어

```text
/vg status
/vg role <role>
/vg skill
/vg rpg status
/vg rpg test_xp <1~5000>
/vg propose advance_time
/vg vote yes
/vg vote no
/vg mayor transfer <player>
```

- `/vg mayor transfer`는 현재 촌장만 사용할 수 있다.
- `/vg rpg test_xp`는 알파 테스트용이며 현재 촌장만 사용할 수 있다.

## 시간 규칙

월드 시간은 자동으로 흐르지 않는다.

```text
아침 → 낮 → 저녁 → 밤 → 다음 날 아침
```

`advance_time` 안건이 통과될 때만 다음 단계로 이동한다.

## 첫 테스트 순서

1. 월드에 접속하고 `/vg status`로 촌장과 시간 정지를 확인한다.
2. `/vg role guard_captain`처럼 역할을 선택한다.
3. `/vg skill`을 사용해 역할 스킬과 쿨타임을 확인한다.
4. 좀비 등 적대 몬스터를 처치하고 RPG XP가 오르는지 확인한다.
5. `/vg rpg status`로 성장 수치를 확인한다.
6. 촌장은 `/vg rpg test_xp 3000`으로 빠르게 고레벨 성장과 추가 체력을 확인한다.
7. 서버를 종료하고 다시 접속해 촌장, 역할, 날짜, 레벨과 XP가 보존되는지 확인한다.
8. 멀티에서는 스킬이 주변 아군에게 적용되고 투표가 온라인 과반수로 처리되는지 확인한다.

## 빌드

Java 25가 필요하다. 프로젝트의 부트스트랩 스크립트가 Gradle 9.2.1을 자동으로 내려받아 빌드한다.

Windows:

```bat
build.bat
```

Linux/macOS:

```bash
chmod +x build.sh
./build.sh
```

완성 JAR은 `build/libs/villageguardians-0.2.0-alpha.1.jar`로 생성될 예정이다. 실제 Gradle 빌드와 게임 로딩 검증이 끝나기 전에는 배포 완료로 간주하지 않는다.

## 현재 제한

- 투표 안건은 서버 재시작 시 취소된다. 통과된 결정과 마을·RPG 상태는 저장된다.
- 습격, 경비병, 방어 시설과 역할별 고유 작업은 다음 단계다.
- 전용 UI는 아직 넣지 않았다. 기능 구조가 굳은 뒤 임시 회색 메뉴가 아닌 완성형 디자인으로 추가한다.

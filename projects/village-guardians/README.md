# Village Guardians — 마을지키기

Minecraft Java 26.2에서 낮 동안 마을을 준비하고, 밤에는 실제 성문·성벽·포탑·시설을 지키는 NeoForge 공성 방어 RPG 모드다.

- Minecraft `26.2`
- NeoForge `26.2.0.37-beta` 이상 26.2.x
- Java `25`
- Gradle `9.2.1`
- 현재 소스 버전 `0.18.9-alpha.1`
- 목표 JAR `villageguardians-0.18.9-alpha.1.jar`

## 핵심 루프

낮 정비 → 장비·성장·시설·포탑·용병 준비 → 다음 밤 정찰 → 공성전 → 피해 복구·강화 → 다음 날짜로 진행한다.

날짜 상승은 적 HP와 숫자만 키우지 않는다. 초반 정면 약탈전에서 시작해 조직 전열, 공병·파쇄병 중심 본격 공성, 측면·후방 공격, 정예 병력, 복합 보스전으로 전쟁 양상이 바뀐다.

## 난이도와 멀티플레이

- 초반 솔로 완화 수치를 유지한다.
- 플레이어 사망 시 20초 부활 대기 동안 성문·성벽·시설은 정상 피해를 받는다.
- 전원이 부활 대기 중이라고 시설 피해가 30%로 줄어드는 보호 규칙은 없다.
- 적 수는 1명 `100%`, 2명 `130%`, 3명 `160%`, 4명 `190%`를 기준으로 스케일한다.
- 공격 방향 수는 플레이어 수가 아니라 날짜·웨이브·정찰 정보에 의해 결정된다.

## 성벽 Segment와 국소 돌파

0.18.9부터 성벽은 블록별 HP가 아니라 여러 방어 구역의 독립 HP로 관리된다.

- 북서 성벽
- 북문
- 북동 성벽
- 서쪽 방벽
- 동쪽 방벽
- 후방 서측 방벽
- 후방 동측 방벽

각 구역은 현재 HP, 최대 HP, 방어 등급, 강화 단계, 손상 상태를 가진다. HP가 내려가면 월드 외형도 균열·부분 손상으로 변하고, 0이 되면 마지막 공격 지점 중심에 5블록 폭의 국소 돌파구가 생긴다. 성벽 전체를 지우지 않으며 파괴·복원 모두 블록 아이템을 떨어뜨리지 않는다. 돌파 이후 측면 공격 AI는 해당 구멍을 새 진입 경로로 사용한다.

## 공격 방향과 정찰

전선은 날짜에 따라 단계적으로 열린다.

- 1~4일: 북문 정면 중심
- 5~7일: 소규모 북서·북동 별동대 가능
- 8~11일: 서·동 측면 공세 등장
- 12~15일: 정면 + 양측 복합 전선
- 16일 이후: 예고된 후방 별동대까지 포함한 다전선 총공세 가능

다음 밤 정찰 화면에는 주공, 별동대, 예상 병과·수량, 공성 병과, 정예, 보스 전투 구조, 전장 상황을 미리 표시한다. 야간 시작 직전에는 위험 방향에 연기·화염 신호도 표시한다. 기존 몬스터 상세 도감 화면은 유지한다.

## 적·정예·보스

기존 전열병·척후병·방패병·폭파병·사수·파쇄병·주술사·지원병·네크로맨서·포탑 사냥꾼·공성 야수와 보스 계열에 더해 0.18.9는 전투 행동 자체가 다른 정예 교리를 추가한다.

- 갈고리병: 측면 성벽 접근 후 내부 침투
- 화염 투척병: 근거리 범위 화상·마법 피해
- 침투 암살자: 살아 있는 플레이어를 빠르게 추격
- 역병술사: 독·약화 범위 방해
- 돌파 기병: 고속 돌격과 순간 강화

보스는 기존 HP 증폭만이 아니라 세 가지 전투 구조를 사용한다.

- 파성 거신: 성벽 Segment 직접 파쇄, 50% 이하 2페이즈 강화
- 사령 결속자: 주변 침공 병력 회복·보호 의식
- 검은 결투원수: 시설보다 플레이어를 추격하는 결투형 지휘관

## 직접 배치 포탑

기존 고정 성루는 요새 건축·관측 구조물로 남기고, 실전 화력은 플레이어가 직접 배치하는 포탑이 담당한다.

설치: 포탑 계열 선택 → 월드 바닥 우클릭으로 유효 위치 미리보기 → 같은 위치를 다시 우클릭해 확정.

서버가 다음 배치를 거부한다.

- 마을 방어구역 밖
- 주 통행로 차단
- 건물 출입구·운영 공간 차단
- 북문 전면 도배
- 다른 포탑과 8블록 미만 간격
- 단단한 바닥·2블록 높이 공간 미확보
- 전체 설치 한도 초과

포탑 10계열:

1. 중쇠뇌 — 단일 고화력
2. 연사 포탑 — 빠른 연사
3. 철갑 관통포 — 중장갑 대응
4. 화염 투사기 — 지속 화상
5. 서리 억제기 — 감속 제어
6. 연쇄 전격탑 — 다중 연쇄
7. 광역 투석포 — 범위 포격
8. 마법 억제탑 — 적 강화 효과 제거
9. 대공 발사대 — 고고도 목표 우선
10. 지원 봉화 — 주변 수호자 회복·저항

모든 포탑은 HP, 최대 HP, 레벨, 피해, 공격 주기, 사거리, 역할, 가동 상태를 가진다. 포탑 사냥꾼·폭파병·보스가 실제로 포탑을 공격하며 HP 0에서는 아이템 드롭 없이 잔해 상태가 된다. 회관에서 개별 수리·강화·철거와 손상 포탑 일괄 수리를 관리한다.

## 용병 배치

용병은 RTS식 세밀 조작 대신 전투 전 병과별 거점만 지정한다.

- 성문 전방
- 성 내부
- 성벽

병과별 허용 위치와 자동 전투 우선순위가 다르며, 전투 중 지나치게 거점에서 이탈하면 역할에 맞게 복귀한다.

## 장비·무기·세트

높은 등급과 강화의 범용 성능이 장비의 주력이다. 특정 공성 적만 상대하는 효과를 고등급 장비의 본체로 사용하지 않는다.

0.18.9 무기 계열 차이:

- 장검
- 대형 도끼
- 장창/투척창
- 전투 망치
- 장궁
- 석궁

2/3세트 장비:

- 성벽 수호자 — 범용 피해와 받는 피해 감소
- 밤사냥꾼 — 원거리 운용 중심 + 범용 생존 보정

세트 효과는 실제 전투 피해 계산 경로에 연결되어 있으며 장비 툴팁과 인벤토리 보조 패널이 같은 세트 상태를 표시한다. 좁은 GUI에서는 패널을 compact 형태로 줄이고, 읽을 수 있는 안전공간조차 없으면 바닐라 인벤토리와 겹치지 않도록 패널을 숨긴다. 장비 툴팁 정보는 유지된다.

## 회관 지휘 UI

공성 방어 지휘 화면에서 다음을 관리한다.

- 성벽 Segment 상태·수리·강화
- 새 포탑 배치 계열
- 설치 포탑 HP·레벨·위치·수리·강화·철거
- 손상 포탑 일괄 수리
- 다음 밤 정찰

새 포탑 선택 화면과 설치 포탑 관리 화면은 분리해 하나의 긴 목록에 억지로 합치지 않는다.

## 주요 명령어

```text
/vg status
/vg progression
/vg raid status
/vg village status
/vg skill
/vg rpg status
/vg propose advance_time
/vg vote yes
/vg vote no
```

대부분의 플레이 기능은 명령어보다 호출기, 인벤토리 상태 패널, 마을 회관과 기능 건물 단말을 통해 이용한다.

## 빌드와 검증

CI는 Java 25 + Gradle 9.2.1에서 기존 회귀 계약과 0.18.9 공성 계약을 먼저 실행하고, 이후 NeoForge `clean build`, `tools/verify_jar.py`, SHA-256 산출, JAR artifact 업로드를 수행한다.

주요 검증 범위:

- 초반 솔로 난이도와 1/2/3/4인 `100/130/160/190%` 적 수 스케일
- 전원 사망 시설 피해 보호 미적용
- 7개 성벽 Segment와 5블록 국소 돌파
- 날짜별 다방향 전선과 정찰
- 10개 포탑 계열, 설치 제한, HP/파괴/수리
- 3개 용병 배치 거점
- 5개 정예 교리와 3개 보스 전투 구조
- 장비 범용 성능, 무기 계열, 2/3세트 실제 전투 연결
- 인벤토리 Safe Area와 좁은 GUI 배율
- 구조물 파괴 아이템 드롭 억제
- 기존 상점·도감·확인창·production UI 라우팅 회귀

자세한 빌드 결과는 [`BUILD_AND_RUNTIME_REPORT.md`](BUILD_AND_RUNTIME_REPORT.md), 외부 자산 출처와 라이선스는 [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md)를 참고한다.

# Village Guardians — 마을지키기

Minecraft Java 26.2에서 낮 동안 마을을 준비하고, 밤에는 실제 성문·성벽·포탑·시설을 지키는 NeoForge 공성 방어 RPG 모드다.

- Minecraft `26.2`
- NeoForge `26.2.0.37-beta` 이상 26.2.x
- Java `25`
- Gradle `9.2.1`
- 현재 소스 버전 `0.18.46-alpha.1`
- 목표 JAR `villageguardians-0.18.46-alpha.1.jar`

## 100일 장기 캠페인 확장

- 정식 캠페인은 제100일 최종 대공성까지 이어지고, 101일 이후만 끝없는 전쟁으로 전환한다.
- 플레이어 최대 레벨은 Lv.100이며, 적 XP는 날짜별 목표 레벨의 실제 필요 XP와 함께 증가한다.
- 적의 날짜 기반 이동속도 폭증은 사용하지 않는다. 후반 난도는 새 웨이브 교리·공중/다전선·정예/보스 조합 중심으로 상승한다.
- 장비 전장 단계 I~X, 포탑 Lv.10, 방어 연구 Lv.20, 용병 Lv.100까지 성장한다.
- 다섯 역할은 Lv.30 1차, Lv.60 2차로 직선 전직한다. 각 단계마다 액티브 4개를 추가하며 기본/1차/2차 기술을 모두 계속 장착할 수 있다.
- 공용 전술 포인트는 별도 재화를 추가하지 않고 기존 트리를 사용한다. Lv.30까지 기존 획득량을 보존하고 이후에는 2레벨마다 1P를 얻는다.

## 핵심 루프

낮 정비 → 장비·성장·시설·포탑·용병 준비 → 다음 밤 정찰 → 공성전 → 피해 복구·강화 → 다음 날짜로 진행한다.

## 0.18.46 시설 강화 비교 확인창·작전표 폐지·파티 XP 속도 복구

- 회관 시설 강화의 최종 확인창이 범용 설명만 보여 주던 문제를 수정했다. 이제 **현재 단계/현재 효과 → 다음 단계/다음 효과 → 필요 공동 보급품**을 실행 직전에 직접 비교한다. 시설 수리도 현재 내구도 → 수리 후 내구도와 비용을 표시한다.
- `수호단 작전표` 종이는 인벤토리 버튼과 회관 지휘대가 이미 같은 기능을 제공해 관리 노동만 늘리므로 폐지했다. 새 로그인에서는 지급하지 않고, 기존 세이브에 남은 작전표와 구형 호출기도 자동 정리한다.
- 파티 공용 경험치 전환 때 넣었던 병과별 2~32 XP 표가 기존 처치 XP보다 약 10배 낮아 성장 속도가 급락했다. 파티 공유 방식은 유지하되 보상량은 **기존 처치 공식 `min(90, 7 + 적 최대체력×0.48) × 마을 보정 1.18`** 로 되돌렸다. 병영 XP 배율은 그 뒤 기존대로 적용되며, 플레이어·용병·포탑 중 누가 막타를 쳐도 밤 참가자 모두 같은 양을 받는다.

## 0.18.45 장비 전장 단계·기본 피해 성장, 파티 경험치 중복 제거

- 장비의 **등급(일반~전설)** 과 별개로 전장 단계 I~IV를 추가했다. 전장 단계는 무기 자체의 기본 피해층을 담당하고, 등급·강화는 기존처럼 배율 성장층을 담당한다. 따라서 초반에 운 좋게 얻은 영웅 장비가 후반 종결 장비가 되는 구조가 아니다.
- 습격 드롭 전장 단계는 1~4일 I, 5~9일 II, 10~14일 III, 15일 이후 IV로 상승한다. 근접 무기는 철→다이아→네더라이트의 바닐라 기본 공격력 상승에 더해 단계별 추가 기본 피해를 받고, 활·쇠뇌·삼지창도 같은 단계별 기본 원거리 피해 보정을 받아 후반에 실제 기초 화력이 오른다.
- 전장 단계 II/III/IV의 추가 기본 피해는 근접 +1.5/+3.0/+5.0, 원거리 +1.25/+2.5/+4.0이다. 이후 기존 레벨·직업·희귀도·강화·세트·유물 배율이 적용된다.
- 상점 장비도 입고 시점에 따라 I~IV 전장 단계를 갖는다. 기존 저장의 상점 장비는 상품 ID로 단계를 복원하고, 과거 일반 드롭은 아이템 재질을 기준으로 안전하게 추정한다.
- 합성은 이제 같은 아이템·전장 단계·등급·강화 단계끼리만 가능하며 결과가 전장 단계를 보존한다. 툴팁에 전장 단계와 추가 기본 피해를 직접 표시해 `영웅 결투 검`처럼 이름만으로 실제 세대를 알기 어려웠던 문제를 줄였다.
- 0.18.44에서 습격 적 처치 경험치를 밤 참가자 전원에게 동일 지급하도록 바꿨지만, 플레이어가 직접 막타를 치면 구형 개인 처치 XP가 한 번 더 들어가던 중복 경로가 남아 있었다. 이제 습격 적은 파티 공용 XP만 지급해 **플레이어·용병·포탑·지속 피해 중 누가 마무리해도 모든 참가자가 같은 XP**를 받는다. 개인 주화와 처치 발동 효과는 직접 처치자 보상으로 유지한다.

## 0.18.44 용병 외형·생존·어그로, 파티 처치 경험치, 포탑 사거리선·연구 비교

- 네 용병 병과의 바닐라 철골렘 외형을 숨기고 CC0 Quaternius RPG Character Pack의 Warrior/Rogue/Ranger/Cleric 실제 OBJ 형상을 각각 방벽 수호병/돌격 집행관/성루 명사수/전장 치유사 표현층으로 사용한다. AI·충돌·체력·저장은 기존 서버 권한 엔티티가 계속 소유한다.
- 용병은 병과별 기본 최대 체력·방어력·공격력·이동속도·밀림 저항을 갖고 장기 레벨과 용병 교리 연구의 생존 보정을 받는다. 신규/재도전 복원 용병은 새 최대 체력으로 완전 회복된 상태에서 시작한다.
- 일반 적의 자동 용병 어그로는 병과별 수용량을 가진다. 방벽 수호병이 가장 많은 적을 받아내고, 돌격병·명사수·치유사에게 전장이 전부 몰리는 것을 막는다. 명시적인 수호병 도발은 이 제한보다 우선한다.
- 습격 적 1기가 죽을 때 처치 주체와 관계없이 그 밤의 모든 참가자에게 같은 개인 성장 경험치를 준다. 플레이어, 용병, 포탑, 지속 피해가 마무리해도 파티 경험치가 누락되지 않는다.
- 포탑 설치 미리보기는 procedural mesh 원 외에 서버 동기화 파티클 원을 배치 모드 동안 반복 표시해 사거리선이 보이지 않던 환경에서도 실제 Lv.1 최대 사거리 경계를 읽을 수 있게 한다.
- 직업 성장 화면은 지속·위력·특수 세 갈래가 상호 배타적이지 않고 모두 함께 성장할 수 있음을 헤더에서 명시한다.
- 수호단 작전표 종이를 다시 지급한다. 종이를 우클릭하면 마을 지휘 화면이 열리고, 비어 있는 경우 두 번째 핫바 칸을 우선 사용한다.
- 마을 방어 연구 실행 결과 화면은 강화 직후 이전 단계, 현재 단계, 다음 단계와 다음 공동 보급품 비용을 함께 표시한다.

## 0.18.43 잔존 좀비 교착·클라이언트 유령 위치 수정

- 실제 플레이에서 `웨이브 2 · 오크 보병`이 꼬마 좀비 외형으로 굳어 움직이지 않고 공격 판정도 받지 않은 채 밤을 끝내지 못하는 증상을 재분석했다.
- 일반 오크 보병은 원래 성체 좀비여야 하지만, `finalizeSpawn`의 바닐라 랜덤 판정이 일부 일반 좀비를 아기/치킨 조키 상태로 바꿀 수 있었다. 이제 스폰 완료 뒤 외형을 다시 정규화해 **척후병·폭파병만 아기 좀비**, 일반 오크 보병은 항상 성체로 고정하고 바닐라 탑승 상태도 제거한다.
- 잔존 적 진행 감시는 마지막 웨이브에서만 실행하지 않는다. 어느 웨이브든 적이 2명 이하로 줄면 위치·자기 HP뿐 아니라 현재 목표의 HP 변화까지 감시해 12초 동안 실제 전투 진척이 없는 개체를 재정렬한다.
- 근접 적이 플레이어 바로 옆에 있다는 이유만으로 정상 전투라고 간주하던 예외를 제거했다. 가까이 있어도 12초 동안 이동·피해 교환이 전혀 없으면 교착으로 판정한다.
- 이미 월드에 존재하는 적의 복구 이동은 `snapTo`가 아니라 서버 추적 엔티티용 `teleportTo`를 사용한다. 서버 히트박스만 다른 곳으로 이동하고 클라이언트에는 공격 불가능한 유령 몸체가 남을 가능성을 차단한다.

## 0.18.42 포탑 사거리 미리보기 · 설명 명확화 · 폭파병 속도 미세 조정

- 포탑 설치 위치를 첫 우클릭으로 미리볼 때 현재 포탑 공학 연구가 반영된 **실제 Lv.1 최대 사거리**를 바닥의 고정 원형 경계로 3.5초간 표시한다. 중앙 배치 표식만 움직이고 외곽 사거리선은 고정해 판정 범위를 과장하지 않는다.
- 포탑 지휘 UI는 설치 한도가 `기본 2 + 성벽 단계 + 포탑 공학 연구`로 증가한다는 계산식을 직접 보여준다. 포탑 상세에는 현재/다음 단계의 연구 반영 피해·사거리·공격 주기, 정확한 철거 환급량, 적에게 실제로 피해를 받아 파괴될 수 있다는 설명을 표시한다.
- 코볼트 폭파병은 0.18.38 이전의 과도한 돌진 성능으로 돌아가지 않는 선에서 기본 이동속도를 `0.14 → 0.15`로 소폭 올렸다. 체력·공격력·시설 피해 배율의 완화 수치는 유지한다.
- 직업 성장의 지속/위력 가지는 각 단계가 주는 실제 누적 수치를 직접 적는다. 특수 가지도 `특수 등급 N/5`와 역할별로 무엇이 강화되는지, IV·V에서 생기는 재사용 감소를 명시해 모호한 “추가 증폭” 문구를 줄였다.
- 포탑·용병 수치 감사에서는 즉시 수치 너프가 필요한 확정 플레이 증거가 없어 임의 재조정을 하지 않았다. 포탑은 설치/강화 비용과 설치 한도, 용병은 정원/고용비/장기 레벨 성장으로 통제하며 다음 실플레이에서 실제 기여도를 보고 조정한다.

## 0.18.41 회관 포탑 지휘·실플레이 수명주기 복구

- 북문 레버에서 성문 개폐와 성벽/포탑 지휘를 겹쳐 처리하던 좌표·이벤트 충돌을 제거했다. 북문 레버는 성문 열기/닫기만 담당하고, 성벽 구역 및 포탑 배치·수리·강화·철거는 마을 회관 지휘대에서 관리한다.
- 회관 유지보수 화면 상단에 항상 보이는 `포탑 지휘`를 추가했다. 시설 목록을 먼저 선택할 필요 없이 새 포탑 계열, 설치 포탑 목록, 일괄 수리와 성벽 구역으로 바로 이동한다.
- 회관 화면 최대 크기를 620×320 논리 픽셀로 다시 낮추고 시설 행 높이, 목록 폭, 현재 효과/다음 강화 정보 구조를 압축했다. 중첩 검은 카드 대신 구분선 중심의 상세 구조를 사용한다.
- 재도전 스냅샷 복원 용병도 신규 고용과 같은 병영 바깥 훈련장 안전 위치에 생성한다. 복원 시 병영 중심에 다시 갇힐 수 있던 별도 경로를 제거했다.
- 낮에는 용병이 병영 바깥 집결장에서 대기하고, NIGHT 진입 즉시 실제 병과별 전투 거점으로 전개된다. 첫 웨이브 카운트다운 동안 `raid active=false`라는 이유로 다시 낮 집결지로 복귀하던 상태 경계를 수정했다.
- 성루 명사수는 계단 아래 집결점까지 도달한 뒤 장시간 경로 생성이 반복 실패할 때만 성벽 거점으로 제한 복구한다. 정상 경로 탐색은 유지하며 매 틱 순간이동하지 않는다.
- 마지막 원거리 적이 살아 있는 표적만 보유한 채 벽 뒤·사거리 밖에서 navigation 종료 상태로 멈추면 더 이상 정상 사격으로 오인하지 않고 최종 적 진행 복구 대상으로 판정한다.

## 0.18.40 실플레이 UI·용병 병영 탈출 수정

- 회관 유지보수 화면을 거의 전 화면을 덮던 940×500 최대 패널에서 **720×360 중심형 작업 패널**로 줄였다. 목록과 상세 영역의 비율도 다시 잡아 선택한 시설 정보가 화면 한가운데 모이고 불필요한 빈 공간이 줄어든다.
- 현재 효과/다음 강화는 단순 텍스트 덩어리 대신 같은 간격의 정보 카드로 묶었다. 다음 단계 효과와 실제 공동 보급 비용을 한 카드에 함께 표시해 하단 버튼 때문에 설명이 잘리거나 비용만 따로 떠 보이는 문제를 없앴다.
- 회관 버튼은 `수리 · 보급 N`, `강화 · 보급 N`처럼 사용하는 재화를 버튼 자체에서 바로 읽을 수 있게 했고, 시설 단계 표기도 `Lv.0 / 5` 대신 `0단계 / 5단계`로 정리했다.
- 용병 고용 위치를 병영 내부 중심이 아니라 **병영 출입구 바깥 훈련장/도로 쪽**으로 옮겼다. 철골렘 AI가 닫힌 다크오크 문을 열 수 없어 고용 직후 병영에 갇히던 원인을 제거한다.
- 기존 세이브에 이미 병영 내부에 갇혀 있는 용병도 낮 배치 틱에서 병영 내부임을 감지하면 바깥 집결 공간으로 한 번 꺼낸다. 이후 기존 병과별 전투 거점 이동 AI가 이어서 소유한다.

## 0.18.39 최종 잔존 적 정지·무적 상태 핫픽스

- 실플레이에서 마지막 적이 단순히 성벽 뒤에 고립된 것이 아니라 **서버상 살아 있으면서 이동하지 않고 피해도 받지 않는 비정상 전투 상태**가 확인됐다. 0.18.38의 거리/시야 기반 `잔존 적 유도` 판정은 원인 진단이 잘못된 임시 대응이므로 제거했다.
- 모든 활성 습격 적은 런타임에서 `NoAI`와 vanilla invulnerability를 허용하지 않는 전투 불변조건을 갖는다. 스폰 직후와 매 서버 틱에 비정상 플래그를 정리하고 즉시 정상 AI 라우팅으로 되돌린다.
- 최종 웨이브 1~2마리 복구는 더 이상 플레이어와의 거리나 LOS만 보고 순간이동하지 않는다. 실제 위치와 체력 변화가 12초 이상 없고, navigation이 종료된 상태에서 목표/시설에 정상 교전 중이지 않은 경우에만 **AI 진행 정지**로 판단해 북문 전선에서 다시 교전시킨다.
- 정상적으로 제자리에서 원거리 공격 중인 적, 시설에 붙어 실제 공성 중인 적은 복구 대상으로 잡지 않는다. 잔존 적 복구 메시지도 `고립`이 아니라 `전투 상태 복구`로 실제 원인을 표현한다.
- 비정상 상태 복구는 서버 로그에 UUID·엔티티 종류·NoAI/무적 플래그를 남겨 같은 증상이 재발하면 원인을 추적할 수 있게 했다.

## 0.18.38 2인 LAN 실플레이 후속 · 성벽 동선·용병·공동경제 안정화

- 남·동·서 성벽 계단을 포좌와 같은 ±34 라인에서 ±52 전용 접근 라인으로 옮겼다. 북측 ±25 계단, 8개 ±34 포좌, 성루 명사수 전투선이 서로 다른 공간을 사용한다.
- 성벽 몸체와 보강 패스가 같은 난간을 중복 생성하던 구조를 정리했다. 성벽 안쪽은 흉벽 리듬을 유지하고, 외곽 defender gallery는 한 줄의 연속 추락 방지 난간만 소유한다.
- 기존 0.18.37 월드는 새 지오메트리 마커로 한 번 자동 재건한다. 일반 마이그레이션은 새 게임 초기화를 호출하지 않으며, 이후 저장된 성벽 구역 HP·돌파 상태와 배치 포탑을 다시 투영한다.
- 초반 코볼트 폭파병의 체력·공격·이동 속도와 시설 피해 배율을 낮추고, 일반 날짜 속도 버프에서도 제외했다. 시설 압박 역할은 유지하되 초반에 혼자 방어선을 무시하고 터뜨리는 수치 압박을 줄였다.
- 성문 전방 용병은 밤 시작 전에 북문 밖 집결선으로 전개된다. 일반 습격 적은 가까운 전투 용병을 실제 공격 대상으로 삼을 수 있어 수호병과 돌격병이 방어선을 받아내고 교전한다.
- 시설·성벽·포탑·용병·마을 방어 연구처럼 파티 전체가 공유하는 투자는 공동 보급품을 사용한다. 개인 장비·직업 성장·소모품은 기존처럼 개인 수호 주화를 사용한다. 상점·보급소에서 수호 주화 25를 공동 보급품 50으로 전환할 수 있다.
- 낮에는 생존 중인 수호자의 허기와 포만도를 유지한다. 의무소의 낮 체력 회복과 단계별 버프는 기존 시설 효과로 따로 유지된다.
- 같은 밤 재도전은 전투 시작 스냅샷과 당시 인원수 기준을 유지하면서 획득한 개인 성장·전리품을 되돌리지 않는다. 같은 날 최대 3회까지 감소하는 공동 보급 지원을 제공해 실패 후 실제 강화 선택을 만들되 무한 파밍은 막는다.
- 밤 시작 참가자 UUID를 저장해 전투 종료 직전 접속이 끊겨도 해당 밤의 주화·경험치 보상이 누락되지 않게 했다. 진행 중 투표의 신규 접속·제안자 퇴장·중복 투표도 서버에서 정리하고, 짧은 간격의 동일 변경 패킷 재전송을 무시한다.
- 회관·방어 연구·성벽·포탑 화면은 현재 효과만이 아니라 다음 단계와 실제 사용 재화를 우선 표시하도록 상세 영역을 재배치했다.
- 수호자 **위압의 함성** 도발 범위를 크게 넓히고 도발을 습격 AI보다 상위의 짧은 서버 권한 상태로 바꿨다. 측·후방 공격 계획, 코볼트 폭파병 같은 시설 우선 병과, 포탑 사냥꾼도 도발 지속시간 동안 도발자를 추적한다.
- 수호병 용병의 자동 도발도 초반부터 넓은 전선 범위를 커버하도록 확대하고 같은 권한 도발을 사용한다. 일반 적이 용병을 무시하고 시설만 미는 현상을 줄였다.
- 플레이어가 쏜 화살·기술 투사체는 아군 용병과 충돌 처리를 취소해 그대로 통과하며, 플레이어/용병이 용병에게 주는 직접 피해도 서버에서 0으로 만든다. 용병이 아군을 잘못 표적으로 잡으면 다음 AI 갱신에서 즉시 해제한다.
- 마지막 웨이브에서 1~2마리 잔존 적이 벽·지형·경로 문제로 고립되면 35초 이후 북문 안쪽 전선으로 재유도한다. 최종 웨이브가 한 마리 때문에 영구 잠기는 경우를 막는다.
- 포탑은 기본 자동 설치물이 아니라 북문 성벽 지휘 레버에서 직접 건설하는 구조임을 첫 야간에 명시한다. 포탑이 0기면 `새 포탑 배치` 경로와 두 번 우클릭 확정 방식을 안내한다.

## 0.18.37 LAN 시간 진행 투표 교착 수정

- 2인 LAN에서 제안자의 자동 찬성 1표와 다른 플레이어의 반대 1표가 남아 영구적으로 `이미 진행 중인 안건이 있습니다.`가 뜨던 교착을 수정했다.
- 투표 부결은 단순 반대 과반이 아니라, 남은 미투표자가 전부 찬성해도 통과 과반에 도달할 수 없는 순간 확정한다. 2인은 한 명의 반대로 즉시 부결되며, 3~4인 이상에서도 수학적으로 불가능한 안건이 남지 않는다.
- 찬성/반대 버튼을 누른 플레이어의 투표창은 즉시 닫힌다. 통과 또는 부결이 확정되면 아직 투표창을 보고 있는 다른 플레이어의 창도 서버에서 닫는다.
- 진행 중인 정상 투표를 X로 닫았을 때는 다음 시간 진행 요청으로 현재 투표창을 다시 열 수 있다. 이미 확정된 안건은 남지 않는다.
- 플레이어 접속/퇴장에 따른 과반수 변화도 기존처럼 재평가하되, 새 불가능-통과 판정으로 교착 없이 정리한다.

## 0.18.36 실플레이 전장 가독성·회귀 재감사

- 성벽·건물 뒤에 가려진 **모든 활성 습격 적**이 다시 `vg_raid` 빨간 외곽선으로 표시된다. 눈앞에 직접 보이는 일반 적은 외곽선을 끄고, 보스는 시야 여부와 관계없이 항상 빨간 외곽선을 유지한다.
- 0.18.29에서 일반 적의 벽 너머 외곽선을 전술/공중 적으로 제한했던 규칙을 실플레이 피드백에 따라 되돌렸다. 성벽 방어 중 잔존 일반 적을 찾기 위해 벽 둘레를 반복 탐색하는 불필요한 시간을 없애는 것이 목적이다.
- 관전자와 다운 상태 플레이어는 적의 `보임` 판정에 참여하지 않는다. 실제 전투 가능한 플레이어에게 가려진 적의 외곽선이 다른 비전투 플레이어 때문에 꺼지지 않는다.
- 이름표 가시성은 기존 규칙을 유지한다. 일반 적 이름표를 상시 노출하지 않고, 보스·공중·전술 위협의 식별 계약도 그대로 보존한다.
- 전장 가독성 변경과 함께 AI 이동 소유권, 활성 적 UUID 명부, 웨이브/공중 경고, 회관·시설 권한, 포탑/성벽 정비, 용병 배치, HUD/modal 억제, 0.18.35 성벽 계단 동선 계약을 다시 회귀검사한다.

## 0.18.35 성벽 계단 상단 접속부 실플레이 수정

- 실플레이에서 성벽 계단이 중간부터 최고 높이의 착지 상판에 덮여 플레이어가 성벽 위로 올라갈 수 없는 물리 지오메트리 회귀를 수정했다.
- 원인은 9칸 계단이 `R-10~R-2`를 사용하면서 착지부가 `R-6~R-1`에서 시작해 마지막 5개 계단의 수평 좌표를 겹쳐 덮던 것이었다.
- 착지부는 이제 마지막 계단 바로 다음 칸인 `R-1`에서 시작하고 `R+2`까지 이어져 성벽 상부와 외곽 defender gallery에 연속적으로 연결된다.
- 계단 각 칸의 3블록 머리 공간과 5블록 폭 본체는 유지하며, 기존 북측 2개·남/동/서 각 2개 접근로 모두 같은 수정된 생성 함수를 사용한다.
- 새 마이그레이션 마커를 추가해 0.18.34 기존 월드도 한 번 자동 재투영하며, 이전 착지 상판 잔재를 제거한 뒤 올바른 계단/착지부를 다시 생성한다.
- 회귀검사는 계단과 착지부 수평 구간 비중첩, 최고 계단과 착지부의 높이 연속성, 3블록 머리 공간, 기존 월드 재생성 마커를 검증한다.

## 0.18.34 Codex 후처리 · 시설 소유권/서버 leaf 정합

- 회관은 시설 수리·강화 전용으로 유지하고, 용병 지휘는 병영, 성벽·포탑 지휘는 북문 성벽 지휘 레버가 단독 소유한다.
- 회관 시설 목록은 실행 가능한 `facility:*` 대신 표시 전용 `facility_card:*`를 사용하며 구식 `facility:`/`manage:` 직접 액션은 서버에서 거부한다.
- 성벽 지휘 레버를 실제 WALLS 현장 단말기로 라우팅하고 성벽 현장 UI에서 공성/포탑 지휘 화면에 정상 진입할 수 있게 복구한다.
- 용병 병과 화면·배치·퇴역과 포탑/성벽 변경 작업은 각 실제 시설 위치를 leaf 메서드에서 다시 검증한다.
- 낮에 포탑 배치 모드를 켜고 밤에 설치를 확정하던 시간차 우회를 막기 위해 두 번째 우클릭 확정 시점에도 정비 단계를 재검증한다.
- 직업 미배치 기술 안내는 옛 회관 안내를 제거하고 실제 직업 배치 위치인 기술 연구소를 가리킨다.

## 0.18.33 대규모 수동 코드 감사·정리

- 서버 변경 작업의 권한 검사를 `VillageMaintenanceRules`로 통합했다. 시설 강화·수리, 포탑 관리, 연구, 상점, 장비 강화, 용병 고용·퇴역은 실행 시점에 위치·시설 가동·낮 정비·게임오버 상태를 다시 확인한다.
- 모든 적을 매 틱 북문으로 덮어쓰던 `VillageGatePrioritySystem`을 제거했다. 북문 정면은 습격 시스템, 측·후방 외곽은 공격 계획 시스템, 공중 이동은 습격 시스템이 각각 단독 소유한다.
- 활성 적과 용병의 대규모 AABB 재검색을 authoritative UUID 명부 해석으로 교체했다. 체력 표시, 정예/보스, 용병 AI와 배치가 같은 저장 명부를 사용한다.
- 임의 강연대까지 가로채던 중복 회관 이벤트, 사용 경로가 사라진 공동 자금 시스템과 구식 회관/역할 UI, 중복 역할 기술 구현 및 호출되지 않는 보조 API를 물리적으로 제거했다.
- 새 게임 시 온라인 플레이어만 초기화되던 문제를 수정했다. 알려진 오프라인 플레이어는 영속 대기 마커를 소비하는 다음 접속 시 인벤토리·엔더 상자·스타터 태그까지 초기화한 뒤 새 키트를 받는다.
- 개인 기술 연구 진입점과 용병 퇴역 목록을 현행 시설 UI에 다시 연결했고, 파괴된 시설의 카탈로그 진입 및 원격 패킷 변조 경로를 차단했다.
- 큰 모달 UI는 바닐라 HUD 계층을 일관되게 숨기며, 회관은 유지보수 전용 화면이라는 0.18.33 계약을 보존한다.

## 0.18.33 실플레이 UI 가독성·성벽 전투공간 교정

- 마을 회관을 시설 유지보수 전용 화면으로 단순화했다. 회관에서는 건물 선택 후 **수리와 강화만** 실행하며, 대장간·연구소·병영·성벽 지휘 같은 시설 고유 기능과 직업 배치는 각 실제 시설에서 사용한다.

- 다음 밤 웨이브 브리핑은 헤더를 두 줄까지 표시하고 웨이브/병과 행 높이와 좌측 목록 폭을 키웠다. 적 도감 제목·역할·하단 안내도 실제 패널 폭으로 잘라 그리며, 4개 패널의 비율과 간격을 다시 계산해 핵심 예상 병과와 대응 정보를 먼저 읽을 수 있게 했다.
- 기존 5블록 두께 성벽의 1×1 관통 사격구를 폐기하고, 12블록 주기의 **3블록 폭 × 2블록 높이 사격구**로 교체했다. 하단 2블록은 그대로 막혀 있으므로 지상 적의 통로가 되지 않으면서 플레이어/원거리 수비수가 실제 시야와 투사체 각도를 확보한다.

## 0.18.32 성벽 계단 교통·성루 명사수 전투선 분리 안정화

- 0.18.31의 UUID 10슬롯 자체는 여러 명사수의 완전 중첩을 줄였지만, 최종 WALL 슬롯 5개씩이 북측 두 계단의 상부 착지 통로와 그대로 겹쳐 여러 명사수를 배치할수록 계단 출구를 물리적으로 막을 수 있었다.
- 계단 아래 집결점은 기존 `±25 / z=-62`를 유지해 실제 북측 계단으로 접근하게 하고, 계단을 오른 뒤의 최종 WALL 거점만 북벽 좌우 전투선으로 분리했다.
- 최종 거점은 북벽 `x=-56~-40` 및 `x=40~56`, `z=-74`에 4블록 간격으로 총 10개 배치된다. 두 북측 계단 착지부와 성벽 포좌 연결부를 모두 비워 플레이어·용병·포탑 정비 동선이 서로 막히지 않는다.
- 성루 명사수의 실제 사격은 기존처럼 물리 LOS와 공중 위협 우선순위를 사용하며, 사격 코드가 navigation을 소유하지 않는 기존 구조를 보존한다. 배치 시스템만 복귀/거점 이동을 소유한다.
- 새 회귀검사는 단순히 "10슬롯이 존재하는가"가 아니라 계산된 10개 좌표가 계단 착지 폭과 겹치지 않는지, 서로 충분히 분산되는지, 포좌 연결부와 안전거리를 갖는지까지 검증한다.

## 0.18.31 실플레이 직전 성벽 동선·성루 명사수 배치 안정화

- 북문 쪽 두 계단에만 의존하던 성벽 접근을 보완했다. 기존 북측 접근로는 보존하고 남·동·서 성벽에 각 2개씩 5블록 폭 계단과 상부 착지 공간을 추가해 측면/후방 포좌까지 성 내부에서 직접 올라갈 수 있다.
- 새 계단 위치의 안쪽 흉벽 난간도 실제 통로 폭만큼 열어 두므로 계단 꼭대기에서 난간에 막히지 않는다. 외곽 난간은 유지해 성벽 밖 추락 방지는 보존한다.
- `성루 명사수`의 기존 WALL 거점 좌표가 실제 성벽 보행면보다 한 블록 높고 성벽 안쪽 램프 쪽에 치우쳐 있던 문제를 수정했다. 이제 북측 실제 성벽 상부 중앙선에 서며 UUID 기반 10개 슬롯으로 여러 명이 한 좌표에 겹치지 않는다.
- 성루 명사수의 성벽 경로 탐색이 즉시 실패하면 곧바로 성 내부 배치로 후퇴시키지 않고, 해당 북측 계단 아래의 지상 집결점으로 먼저 이동한 뒤 다음 배치 틱에서 다시 성벽 상부 경로를 시도한다.
- 기존 월드는 새 마이그레이션 마커를 통해 성벽 계단·난간 개구부를 자동 투영한다. 이번 버전은 대규모 신규 콘텐츠보다 실제 플레이 테스트 직전 이동/배치 실패 가능성을 줄이는 안정화 패스다.

## 0.18.30 성벽 상부 전투 거점·포탑 포좌 정합

- 성벽 보행로가 실제 전투 지형이 되도록 북·남·동·서 각 2곳, 총 8개의 5×5 성벽 상부 포좌를 추가했다. 중앙 문양 블록과 U자 안전 난간으로 배치 위치를 읽을 수 있고, 기존 성벽 보행로와 3블록 폭으로 직접 연결된다.
- 기존 포탑 배치 검증은 마을 중심 반경을 지상 기준으로만 잘라 성벽 상부가 방어구역 밖으로 판정되던 문제를 수정했다. 지정된 성벽 포좌만 예외적으로 허용하며 일반 외벽·임의 고지대에는 설치할 수 없다.
- 지붕이나 임의 구조물 위에 3블록 공간만 있으면 포탑을 올릴 수 있던 고도 우회도 막았다. 일반 포탑은 평탄화된 마을 지면 ±2블록, 성벽 상부는 지정 포좌에서만 배치된다.
- 성벽 수리/재건 시에도 상부 포좌와 난간 연결부가 다시 투영되며, 기존 0.18.29 월드에는 새 마이그레이션 마커를 통해 자동 재건된다.
- 포탑 총구는 설치 기준점보다 2블록 이상 높게 계산되고 실제 블록 충돌 LOS를 사용하므로, 포좌 포탑은 성벽 뒤 지상 포탑과 달리 흉벽 위로 사격할 수 있으면서 벽을 관통하지 않는다.

## 0.18.29 복합 전장 가독성·공중 경고 정합

- 0.18.28에서 공중 병종별 실제 경고 시간이 12/18/24틱, 플레이어 타격 반경이 2.15/2.75/3.10블록으로 갈라졌는데 월드 경고 메시는 여전히 18틱·2.35블록 고정이던 판정/연출 불일치를 제거했다. 이제 경고 지속시간과 주 위험 원이 실제 회피 판정과 같은 값을 사용한다.
- 하늘 약탈귀·파성 망령·폭풍 사냥귀의 공중 경고를 서로 다른 색·마커 밀도·회전 언어로 분리했다. 시설 폭격 표식과 플레이어 급강하 표식도 같은 메시를 억지로 공유하지 않고 구조물 여부를 함께 인코딩한다.

- 시야 밖의 모든 일반 적을 벽 너머 발광시키던 전역 아웃라인을 폐기했다. 보스와 전술 위협만 가려졌을 때 강조되어 성벽 너머가 수십 개 실루엣으로 도배되지 않으면서도 반드시 찾아야 할 표적은 놓치지 않는다.

## 0.18.28 공중 병종·대공 방어 생태계

- 실제 비행 적을 하늘 약탈귀·파성 망령·폭풍 사냥귀 3교리로 분화했다. 7일차 기본 급습 이후 10일차부터 시설 폭격형, 13일차부터 고속 추격형이 섞이며 실제 스폰과 낮 정찰이 같은 결정 규칙을 사용한다.
- 파성 망령은 플레이어에게 쉽게 끌려가지 않고 내부 시설을 우선 폭격한다. 폭풍 사냥귀는 더 넓게 수호자를 탐색하고 짧은 경고·빠른 급강하·짧은 회복 주기로 압박하지만 1회 피해와 판정 반경은 작다.
- 지상 정예 교리 시스템이 비행 적에게 갈고리/암살/기병 이동 AI를 다시 덮어쓸 수 있던 0.18.27 잔여 소유권 충돌을 차단했다. 공중 이동은 끝까지 습격 시스템 하나가 소유한다.
- 대공 발사대와 성루 명사수 용병은 단순히 가장 가까운 비행 적을 함께 두드리는 대신 시설 폭격형 → 고속 추격형 → 일반 급습형의 위협 우선순위를 공유한다.
- 성루사수 플레이어의 조준 보정은 시야 원뿔 안 공중 적을 우선하며, 활 피해는 공중 적에게 18% 증가한다. 플레이어가 직접 대공 역할을 맡을 수 있게 했다.
- 광역 투석포는 이미 다른 투석포의 12틱 지연 포격이 예약된 군집에 큰 감점을 줘, 여러 포탑이 같은 빈 좌표에 연속 포격하는 지연 오버킬을 줄였다.
- 낮 정찰은 공중 적 총수뿐 아니라 세 공중 교리의 실제 예정 수량·역할을 따로 공개하며, 지상 정예 예상 수량에서도 공중 적을 제외한다.

## 0.18.27 공중 습격 전투 완성도·정찰 정합

- 공중 적의 플레이어 공격을 바닐라 Phantom 공격 AI에 맡기면서 모드가 동시에 이동 목표를 덮어쓰던 이중 소유권을 제거했다. 하늘 약탈귀는 모드가 직접 순항 → 경고 → 급강하 타격 → 상승 이탈을 제어한다.
- 급강하 타격은 경고 시점의 위치를 고정해 18틱 뒤 작은 반경에만 피해를 준다. 플레이어가 경고 원 밖으로 빠지면 피할 수 있고, 시설 공습도 같은 고정 지점 경고 후 피해가 들어간다.
- 공중 습격의 경고/충돌은 서버 동기화 절차 메시로 표시해 실제 판정 위치와 시각 위치를 공유한다.
- 낮 정찰은 실제 스폰 판정과 같은 `willSpawnFlying` 규칙을 사용해 웨이브별 하늘 약탈귀 수를 따로 공개한다. 지상 병과로 잘못 표시되던 정찰 오차를 제거했다.
- 성루 명사수 용병은 사거리 안에 공중 적이 있으면 지상 최근접 적보다 먼저 사격해 대공 발사대의 보조 대공 전력으로 기능한다.

## 0.18.26 공중 습격·포탑 역할 분화

- 7일차부터 실제 비행 적 `하늘 약탈귀`가 웨이브에 섞인다. 폭풍전선/사냥꾼 계열 웨이브에서는 출현 비율이 더 높고, 지상 전선 경로·북문 강제 AI에서 제외되어 성벽을 물리적으로 우회한다.
- 비행 적은 성 안의 플레이어를 우선 급습하고, 방어자가 없으면 성벽이 아니라 내부 시설 상공으로 이동해 제한된 주기의 공중 타격을 가한다. 성벽은 지상 공세를 강하게 지연시키지만 후반에는 대공 방어를 따로 준비해야 한다.
- 대공 발사대는 비행 적에 압도적인 타깃 우선순위와 1.65배 대공 피해를 가지며, 비행 표적이 없을 때만 지상 원거리·지원 적을 보조 사격한다.
- 나머지 포탑도 단순 최근접 사격에서 역할별 위협 점수 방식으로 바뀌었다. 중쇠뇌는 보스/중량 적, 연사포는 러셔/마무리, 관통포는 중장갑, 서리는 공병/고기동, 연쇄/투석은 군집, 억제탑은 버프·지원병을 우선한다.
- 마법 억제탑은 공격/재생뿐 아니라 속도·저항·흡수까지 제거해 적 지원병의 실제 강화 효과를 끊는다.

## 0.18.25 다전선 경로 소유권·돌파 후 침입 정합

- 후반 별동대가 측면/후방 전선에 배치돼도 매 틱 마지막에 `VillageGatePrioritySystem`이 모든 적을 북문으로 다시 끌어오던 충돌을 제거했다. 북문 우선 경로는 실제 `NORTH` 전선의 외부 적에게만 적용된다.
- 측면·후방 적은 성벽 밖에 있는 동안 `VillageAttackPlanSystem`이 이동 경로를 단독 소유한다. 일반 습격 AI와 탑 사냥꾼의 목표 선택이 먼저 북문·플레이어·포탑으로 방향을 바꿨다가 다시 되돌아오는 경로 싸움을 없앴다.
- 해당 구역이 돌파되면 별동대는 기존 전투 목표를 지우고 실제 돌파구 안쪽 접근점으로 진입한다. 내부에 들어온 뒤에는 북문이 멀쩡해도 이미 확보한 측면 진입권을 인정해 플레이어·포탑·가까운 내부 시설을 정상 공격한다.
- 갈고리/침투 등 다른 메커니즘으로 성 안에 먼저 들어온 적도 위치 자체를 내부 진입권으로 인정하므로 북문으로 되돌아 나가지 않는다.

## 0.18.24 방어 관리 권한·경제 정합

- 성벽·포탑의 수리·강화·철거·배치 선택은 UI를 어디서 열었는지가 아니라 서버가 액션 패킷을 받는 순간 다시 회관 지휘대 근접 여부를 검증한다. 화면을 연 뒤 멀리 이동하거나 임의 액션 패킷을 보내도 원격으로 주화와 방어 상태를 바꿀 수 없다.
- 포탑/성벽의 일반 관리 작업은 게임 오버 상태와 야간/습격 중에는 거부되며 낮 정비 시간에만 가능하다. 전투 중 사용하도록 만든 응급 포탑 수리 키트의 근거리 현장 수리는 이 제한에서 제외한다.
- 손상된 포탑을 강화할 때 새 최대 HP로 즉시 완전 회복되던 경제 우회가 제거됐다. 강화는 기존 손상 HP를 그대로 남긴 채 새 최대 HP만 늘려 수리 비용을 우회하지 못한다.
- 이전 릴리스 회귀 테스트가 현재 버전 문자열을 고정하지 않도록 0.18.23 테스트를 기능 계약으로 정리했고 README의 현재 버전/JAR 표기도 정본과 다시 맞췄다.

## 0.18.20 용병 명부·병영 경제 정합

- 병영의 기존 즉시 `마을 용병` 생성 경로를 폐기하고, 방벽 수호병·돌격 집행관·성루 명사수·전장 치유사 4병과를 한 명부에서 고용·확인·퇴역하는 구조로 통합했다.
- 용병 정원은 주변 AABB에 현재 보이는 철골렘 수가 아니라 SavedData의 병과 명부가 정본이다. 용병이 먼 곳이나 언로드 구역에 있어도 정원을 우회해 추가 고용할 수 없다.
- 병영 강화가 고용비를 올리던 역성장 수식을 제거했다. 병영 Lv.1 비용을 기준으로 이후 단계는 병과별 하한까지 완만하게 할인된다.
- 기존 월드의 이름 `마을 용병` 철골렘은 청크가 로드될 때 방벽 수호병 Lv.1로 1회 이관되어 새 레벨·연구·Presentation·세이브 구조에 편입된다.
- 낮 정비 시간에는 현재 로드된 용병을 개별 퇴역시킬 수 있다. 언로드된 엔티티를 UUID만 지워 고아 엔티티를 만드는 일을 막기 위해 퇴역은 실제 엔티티가 로드된 경우에만 허용하며 고용비는 환불하지 않는다.
- 병영 시설 관리 화면과 용병 명부 화면은 동일한 연구 포함 정원을 표시한다. `용병 교리` 정원 보너스가 시설 설명에서 빠지던 UI 오표기를 최종 수동 감사에서 수정했다.

## 0.18.19 후반 연구·용병 장기 성장

- 방어 연구는 기존 세이브 ID를 유지한 채 분야별 최대 Lv.10으로 확장된다. Lv.1~5의 기존 핵심 위력은 유지하고 Lv.6~10은 성장률이 완만한 숙련 구간으로 이어진다.
- 용병 교리는 피해뿐 아니라 치유, 처치 훈련 진척, 정원까지 장기 성장한다. 기존 Lv.1~5 정원 보너스는 감소하지 않으며 최대 연구에서는 추가 정원이 더 열린다.
- 포탑 공학은 피해 외에 실제 사거리와 최대 내구도도 올린다. 0.18.18 이전 풀피 포탑 세이브는 1회 이행 시 새 최대 내구도 기준으로 풀피를 유지하며, 이후 연구 강화도 현재 HP 비율을 보존한다.
- 전리품 군수학은 장비 드랍·판매 가치 외에 전투 소모품 가격과 현장 수리 효율에도 연결된다.
- 용병은 기존 Iron Golem 기반 판정·저장 구조를 유지하면서 병과별 지속형 절차 메시 실루엣을 가진다. 방벽 수호병/돌격 집행관/성루 명사수/전장 치유사가 Lv.20·40·60 구간에서 시각적으로 단계 강화된다.
- 0.18.18에서 추가된 장비별 장기 강화 상한, 전투 소모품, 성벽 사격구·전투 보행로, Lv.60 용병 성장 구조를 그대로 유지한다.

날짜 상승은 적 HP와 숫자만 키우지 않는다. 초반 정면 약탈전에서 시작해 조직 전열, 공병·파쇄병 중심 본격 공성, 측면·후방 공격, 정예 병력, 복합 보스전으로 전쟁 양상이 바뀐다.

## 난이도와 멀티플레이

- 초반 솔로 완화 수치를 유지한다.
- 플레이어 사망 시 20초 부활 대기 동안 성문·성벽·시설은 정상 피해를 받는다.
- 전원이 부활 대기 중이라고 시설 피해가 30%로 줄어드는 보호 규칙은 없다.
- 적 수는 1명 `100%`, 2명 `130%`, 3명 `160%`, 4명 `190%`를 기준으로 스케일한다.
- 공격 방향 수는 플레이어 수가 아니라 날짜·웨이브·정찰 정보에 의해 결정된다.

## 성벽 Segment와 국소 돌파

0.18.9부터 성벽은 블록별 HP가 아니라 여러 방어 구역의 독립 HP로 관리된다.

- 북서 성벽
- 북문
- 북동 성벽
- 서쪽 방벽
- 동쪽 방벽
- 후방 서측 방벽
- 후방 동측 방벽

각 구역은 현재 HP, 최대 HP, 방어 등급, 강화 단계, 손상 상태를 가진다. HP가 내려가면 월드 외형도 균열·부분 손상으로 변하고, 0이 되면 마지막 공격 지점 중심에 5블록 폭의 국소 돌파구가 생긴다. 성벽 전체를 지우지 않으며 파괴·복원 모두 블록 아이템을 떨어뜨리지 않는다. 돌파 이후 측면 공격 AI는 해당 구멍을 새 진입 경로로 사용한다.

## 공격 방향과 정찰

전선은 날짜에 따라 단계적으로 열린다.

- 1~4일: 북문 정면 중심
- 5~7일: 소규모 북서·북동 별동대 가능
- 8~11일: 서·동 측면 공세 등장
- 12~15일: 정면 + 양측 복합 전선
- 16일 이후: 예고된 후방 별동대까지 포함한 다전선 총공세 가능

다음 밤 정찰 화면에는 주공, 별동대, 예상 병과·수량, 공성 병과, 정예, 보스 전투 구조, 전장 상황을 미리 표시한다. 야간 시작 직전에는 위험 방향에 연기·화염 신호도 표시한다. 기존 몬스터 상세 도감 화면은 유지한다.

## 적·정예·보스

기존 전열병·척후병·방패병·폭파병·사수·파쇄병·주술사·지원병·네크로맨서·포탑 사냥꾼·공성 야수와 보스 계열에 더해 0.18.9는 전투 행동 자체가 다른 정예 교리를 추가한다.

- 갈고리병: 측면 성벽 접근 후 내부 침투
- 화염 투척병: 근거리 범위 화상·마법 피해
- 침투 암살자: 살아 있는 플레이어를 빠르게 추격
- 역병술사: 독·약화 범위 방해
- 돌파 기병: 고속 돌격과 순간 강화

보스는 기존 HP 증폭만이 아니라 세 가지 전투 구조를 사용한다.

- 파성 거신: 성벽 Segment 직접 파쇄, 50% 이하 2페이즈 강화
- 사령 결속자: 주변 침공 병력 회복·보호 의식
- 검은 결투원수: 시설보다 플레이어를 추격하는 결투형 지휘관

## 0.18.12 수동 품질 감사·전투 연출 정합화

실제 플레이 테스트가 어려운 기간을 이용해 자동 검사만으로는 놓치기 쉬운 런타임 경계와 전투 읽기 문제를 수동으로 재검사했다.

- 포탑 LOS 시작점이 포탑 자신의 실체 블록 내부에 있던 위험을 제거했다. 각 목표 방향으로 상단 캡 밖에 실제 muzzle을 만들고 그 위치에서 블록 충돌 LOS와 사격선을 계산한다.
- 대공 포탑은 후보 순서가 아니라 실제 가장 가까운 고고도 적을 우선하며, 연쇄 전격은 모든 빔이 포탑에서 뻗는 별모양이 아니라 첫 목표에서 다음 목표로 이어지는 실제 연쇄 경로를 그린다.
- 용병 지휘가 커스텀 이름 문자열을 다시 파싱하던 구조를 없애고 SavedData에서 복원된 병과 맵을 단일 정본으로 사용한다. 궁수·치유사는 랠리 복귀 중이 아닐 때 바닐라 철골렘의 근접 추격을 빠르게 억제한다.
- 파성 거신이 가장 흔한 정면 북문 공성에서 고유 행동을 포기하던 조기 return을 제거했다. 2페이즈는 설명대로 파쇄 주기가 45틱에서 30틱으로 빨라지고, 파쇄 직전 경고와 충격 피드백이 추가됐다.
- 사령 결속자의 의식, 검은 결투원수의 약화 베기, 갈고리병·화염 투척병·역병술사의 특수 행동에 발동 전 텔레그래프를 추가해 갑작스러운 판정보다 읽고 대응할 수 있는 전투로 바꿨다.
- 암살자·돌파 기병은 서버 플레이어 목록의 우연한 순서가 아니라 실제 가장 가까운 생존 수호자를 고른다.
- 보스 변이는 다운된 플레이어를 공격 후보에서 제외한다. 뇌광은 경고 시점의 고정된 지점을 저장하고 15틱 뒤 같은 지점에 떨어지므로 표시 밖으로 움직여 실제로 회피할 수 있다.
- 신규 `tools/test_v01812_quality_audit.py`가 위 계약을 고정하고, 0.18.8~0.18.11 회귀 계약과 함께 Java 25 clean build에서 검증된다.

## 장비·무기·세트

높은 등급과 강화의 범용 성능이 장비의 주력이다. 특정 공성 적만 상대하는 효과를 고등급 장비의 본체로 사용하지 않는다.

0.18.9 무기 계열 차이:

- 장검
- 대형 도끼
- 장창/투척창
- 전투 망치
- 장궁
- 석궁

2/3세트 장비:

- 성벽 수호자 — 범용 피해와 받는 피해 감소
- 밤사냥꾼 — 원거리 운용 중심 + 범용 생존 보정

세트 효과는 실제 전투 피해 계산 경로에 연결되어 있으며 장비 툴팁과 인벤토리 보조 패널이 같은 세트 상태를 표시한다. 좁은 GUI에서는 패널을 compact 형태로 줄이고, 읽을 수 있는 안전공간조차 없으면 바닐라 인벤토리와 겹치지 않도록 패널을 숨긴다. 장비 툴팁 정보는 유지된다.

## 0.18.10 추적 도탄 개편

궁수의 `추적 도탄`은 더 이상 첫 적 적중 뒤 주변 대상에게 한 프레임에 피해를 뿌리는 방식이 아니다.

- 최초 표적은 시야 중앙 전방 원뿔 안에서 선정한다.
- 발사 순간에도 실제 화살 진행 벡터에서 목표 방향으로 부드럽게 보간해 급격한 방향 전환을 줄였다.
- 비행 중 표적이 죽거나 사라지면 화살 진행 방향 전방에서 새 적을 재포착한다.
- 재포착은 화살과 대상 사이 블록 충돌 검사를 통과해야 하므로 벽 너머 적을 억지로 쫓지 않는다.
- 첫 적 적중 이후에는 이전 대상에서 가장 가까운 LOS 대상 순으로 실제 시간차 도탄한다.
- 한 도탄 연쇄에서 같은 적은 다시 선택하지 않는다.
- 기본 4회에서 특수 숙련에 따라 최대 8회까지 도탄하며, 연쇄 피해는 단계별로 완만하게 감소한다.
- 2차 도탄 피해도 플레이어 처치로 귀속되어 정상 XP·주화 보상을 받을 수 있다.
- 이미 계산된 1차 화살의 장비·직업·유물 배율은 2차 도탄에서 다시 곱하지 않으며 일반 궁수 패시브 도탄도 재귀 발동하지 않는다.

## 0.18.18 장기 성장·전투 보급·성벽 교전 패스

- 무료 `마을 배급 식량`을 하루 1회 기본 생존식량으로 통합하고, 역할이 겹치던 유료 `전투 건량` 판매는 제거했다.
- 보급소에 응급 붕대, 정화 약제, 전투 자극제, 수호 비약, 비전 촉진제, 응급 포탑 수리 키트를 추가했다. 날짜별 해금·종류별 재사용 대기시간·보급소 단계별 가격/묶음 보정이 적용된다.
- 대장간 장비 강화는 기존 +5 단일 상한을 폐지했다. 대장간 단계와 방어 일수가 장기 강화 한도를 열고 장검/망치 +30, 도끼 +28, 장창·비전봉 +26, 활 +25, 석궁 +24, 방패 +22, 방어구 +20의 계열별 최종 상한을 사용한다.
- +10 이후와 +20 이후 강화 효율은 완만해지며 강화 비용은 마스터워크 구간부터 가속 증가한다. Mace도 드랍/무기 스타일뿐 아니라 실제 등급 강화·피해 계산에 포함된다.
- 기술 연구소는 레벨마다 직업 기술 위력 +5%, 지속시간 +5%, 재사용 효율을 제공한다. 병영의 과도한 레벨당 -2초 쿨다운은 제거하고 병영은 경험치·용병 중심 시설로 되돌렸다.
- 일반 성벽에는 높은 1블록 사격구와 내부 발판을 배치해 적이 통과하지 못한 채 원거리 교전할 수 있고, 성벽 상단 바깥쪽에는 살짝 돌출된 전투 보행로와 투하구를 만들어 벽 바로 아래 적도 공격할 수 있게 했다.
- 용병 성장 상한을 Lv.5에서 Lv.60으로 확장했다. 처치 누적 요구량은 단계적으로 증가하고 피해·회복·사거리·제어 범위는 완만한 장기 곡선을 사용해 극후반에도 투자 가치가 남는다.

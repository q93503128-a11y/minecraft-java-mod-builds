# Village Guardians — 마을지키기

Minecraft Java 26.2에서 한 개의 요새 마을을 함께 성장시키고 야간 습격을 막는 NeoForge 협동 RPG 모드다.

- Minecraft `26.2`
- NeoForge `26.2.0.37-beta` 이상
- Java `25`
- 현재 소스 버전 `0.7.0-alpha.1`
- 목표 JAR `villageguardians-0.7.0-alpha.1.jar`

## 게임 구조

- 자연 시간은 멈춰 있으며 낮·밤 진행은 플레이어가 직접 결정한다.
- 모든 플레이어가 운영 UI, 빠른 신호, 역할, 시설 수리와 강화에 참여한다.
- 첫 접속자는 마을 중심을 정하기 위한 내부 소유자 값으로만 저장되며 별도 플레이 특권은 없다.
- 마을 반경은 96블록, 성벽 반경은 76블록이다.
- 중앙 광장에서 북문까지 폭 9블록의 전투 대로가 유지된다.
- 밤에는 북쪽 외곽에서 여러 웨이브가 접근한다.
- 가까운 플레이어가 있으면 적은 건물보다 플레이어를 우선 공격한다.
- 북문이 닫혔으면 성문을 공격하고, 실제로 열렸거나 파괴됐으면 통로로 진입한다.
- 시설이 공격받을 때만 상단 내구도 HUD가 잠시 나타난다.
- 벽에 가려진 습격 적은 붉은 윤곽선으로 표시된다.
- 시설이 파괴되면 완전히 사라지지 않고 잔해가 남으며, 수리 전까지 기능이 중단된다.

## 기능 건물

| 건물 | 역할 |
|---|---|
| 마을 회관 | 공동 운영, 빠른 신호, 시간 진행 |
| 병영·훈련장 | 훈련, 역할 능력 강화 |
| 대장간 | 개인 장비 강화 |
| 기술·마법 연구소 | 스킬·마법·특수능력 습득 |
| 상점·보급소 | 화살·식량 구매, 일일 빵 지급 |
| 의무소 | 치료, 웨이브 사이 회복 |
| 북문·성벽 | 적 진입 차단, 마을 방어력 제공 |

매일 기본 빵 3개가 지급되며 보급소 레벨마다 2개씩 증가한다.

## 성문과 성벽

- 북문은 틈이 없는 통짜 목제 성문과 보강틀로 구성된다.
- 북문 안쪽 레버를 눌러 모든 플레이어가 열고 닫을 수 있다.
- 성문이 파괴되면 레버는 작동하지 않는다.
- 북문 양쪽의 석재 계단이 성벽 위 통로에 직접 연결된다.
- 기존 석재 절단기 형태의 임시 조작 블록은 제거됐다.

## 건물 배치

0.7부터 건물은 중앙 광장을 향하도록 자동 회전한다.

1. 구조 NBT에서 실제 문 위치를 찾는다.
2. 네 방향을 가상 배치해 문이 중앙 쪽 외벽에 오는 회전을 선택한다.
3. 실제 문 바로 밖에 진입로를 연결한다.
4. 기능 단말과 읽을 수 있는 벽면 간판을 문 옆에 배치한다.
5. 외부 구조물의 기존 실내는 유지하며 임의 가구를 공중에 덧씌우지 않는다.

## UI

- 인벤토리 GUI는 어두운 공개 GUI 자산으로 교체된다.
- 인벤토리 옆에는 레벨, XP 진행바, 역할, 재화, 마을 상태가 보이는 소형 RPG 대시보드가 표시된다.
- 전체 운영 화면은 어두운 전술 패널, 얇은 청록 강조선, 일관된 버튼 계층과 스크롤 본문을 사용한다.
- 무지개색 버튼, 두꺼운 금색 프레임, 임시 회색 메뉴는 사용하지 않는다.
- 작은 창에서는 버튼을 한 열로 바꾸고 본문만 스크롤한다.

## 외부 공개 자산

0.7은 무료 공개 자산을 실제 런타임 JAR에 포함한다.

- **Default Dark Mode**: 인벤토리 GUI와 기본 버튼 자산
- **Towns and Towers**: 같은 건축 계열에서 선별한 회관, 병영, 대장간, 연구소, 상점, 의무소 구조 NBT

빌드 시 버전과 커밋을 고정해서 가져오며, 최종 JAR 검증기는 아래 항목이 하나라도 빠지면 실패한다.

- 외부 GUI PNG 3개
- 외부 건물 NBT 6개
- 자산 선택 기록
- 제3자 출처·라이선스 고지

자세한 내용은 [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md)에 기록한다.

## 성장과 역할

- 최고 레벨 30
- 적 처치와 습격 방어로 XP 획득
- 레벨에 따라 공격 피해, 피해 감소, 추가 최대 체력 증가
- 역할: 경비대장, 건축가, 보급관, 정찰병, 농업관, 의무관
- 역할 스킬은 주변 아군에게도 적용된다.
- 장비 강화와 능력 습득은 각 기능 건물에서 진행한다.

## 주요 명령어

```text
/vg status
/vg progression
/vg raid status
/vg village status
/vg role <role>
/vg skill
/vg rpg status
/vg propose advance_time
/vg vote yes
/vg vote no
```

대부분의 플레이 기능은 명령어보다 호출기, 인벤토리 상태 패널과 건물 단말을 통해 이용한다.

## 저장 호환

- 기존 `village_council`과 진행 데이터 저장 키를 유지한다.
- 0.7은 구조 세대 마커를 바꿨으므로 기존 테스트 월드 첫 접속 때 마을을 새 배치로 재건한다.
- 플레이어 레벨, XP, 역할, 주화, 시설 강화와 날짜는 유지한다.
- 마을 부지 안에서 직접 지은 블록은 재건 과정에서 덮어쓸 수 있으므로 테스트 월드 기준으로 사용한다.

## 검증 상태

- 0.6.0-alpha.1은 Java 25 `clean build`, 계약 테스트와 JAR 검증을 통과했다.
- 0.7.0-alpha.1 소스에는 외부 자산, 신규 UI, 자동 건물 회전, 성문 조작과 성벽 계단 수정이 반영됐다.
- 요새 배치 계약 테스트는 로컬 계산으로 통과했다.
- 현재 작업 환경에는 Java 25 Gradle 실행 환경이 없고 외부 다운로드도 차단되어 있어 0.7 JAR은 아직 생성하지 않았다.
- GitHub Actions는 자동 실행되지 않으며 `.build-trigger`를 명시적으로 갱신할 때만 실행된다.

# Village Guardians — 마을지키기

마인크래프트 생존 월드의 한 마을을 실제 공동체로 운영하고 지키면서, 플레이어도 강력한 수호자로 성장하는 NeoForge JAR 모드다.

## 통치 코어

- 첫 접속자가 임시 촌장이 된다.
- 촌장은 한 명만 존재한다.
- 촌장 직책과 실무 역할은 별개다.
- 멀티플레이어는 경비대장, 건축가, 보급관, 정찰병, 농업관, 의무관 중 하나를 맡는다.
- 마을 전체 시간 진행은 촌장이 안건을 발의하고 온라인 플레이어 과반수가 찬성해야 실행된다.
- 자연적인 바닐라 시간 흐름은 꺼진다.
- 촌장, 역할, 마을 날짜와 시간 단계는 월드 저장 데이터에 영구 보존된다.

## 마을 영역 기반

- 촌장이 오버월드에서 현재 위치를 마을 중심으로 지정한다.
- 중심 기준 반경 64블록을 공식 마을 영역으로 판정한다.
- 마을 중심은 서버를 종료해도 영구 저장된다.
- 마을 내부에서 적대 몬스터를 처치하면 RPG 경험치를 50% 더 받는다.
- `/vg status`에서 현재 마을 내부인지 외부인지 확인할 수 있다.

## 0.2 RPG 알파

- 적대 몬스터를 처치하면 RPG 경험치를 얻는다.
- 레벨과 경험치는 월드에 영구 저장된다.
- 최고 레벨은 우선 30이다.
- 레벨이 오를 때마다 가하는 피해가 증가하고 받는 피해가 감소한다.
- 3레벨 단위로 추가 최대 체력이 증가한다.
- 5레벨 단위로 공격과 방어 성장이 크게 뛰어오른다.
- 30레벨 기준 공격 약 6.23배, 받는 피해 28%, 추가 체력 36포인트다.
- 각 역할은 `/vg skill`로 첫 액티브 스킬을 사용한다.
- 역할 스킬은 주변 12블록 안의 같은 차원 아군에게 적용되며 레벨에 따라 강해진다.

### 역할 스킬

- 경비대장 — **전장의 함성**: 힘과 저항 강화
- 건축가 — **긴급 방벽**: 강한 저항과 흡수 체력
- 보급관 — **전투 보급**: 즉시 회복, 재생, 흡수 체력
- 정찰병 — **질풍 정찰**: 이동 속도, 점프, 야간 시야
- 농업관 — **풍요의 기운**: 채굴 속도와 재생
- 의무관 — **구호의 빛**: 대량 회복, 재생, 흡수 체력

## 명령어

```text
/vg status
/vg village status
/vg village set_center
/vg role <role>
/vg skill
/vg rpg status
/vg rpg test_xp <1~5000>
/vg propose advance_time
/vg vote yes
/vg vote no
/vg mayor transfer <player>
```

- `/vg village set_center`, `/vg mayor transfer`, `/vg rpg test_xp`는 현재 촌장만 사용할 수 있다.

## 시간 규칙

월드 시간은 자동으로 흐르지 않는다.

```text
아침 → 낮 → 저녁 → 밤 → 다음 날 아침
```

`advance_time` 안건이 통과될 때만 다음 단계로 이동한다.

## 첫 인게임 테스트 순서

1. 촌장이 원하는 마을 중앙에서 `/vg village set_center`를 사용한다.
2. `/vg village status`와 `/vg status`로 영역 판정을 확인한다.
3. `/vg role guard_captain`처럼 역할을 선택하고 `/vg skill`을 사용한다.
4. 마을 안팎에서 각각 적대 몬스터를 처치해 방어 XP 보너스를 비교한다.
5. `/vg rpg test_xp 3000`과 `/vg rpg status`로 고레벨 성장을 확인한다.
6. 서버 재접속 후 중심, 촌장, 역할, 날짜, 레벨과 XP가 보존되는지 확인한다.
7. 멀티에서 주변 아군 스킬과 온라인 과반수 투표를 확인한다.

## 빌드 상태

실행용 목표 파일은 `villageguardians-0.2.0-alpha.1.jar`다. 원격 Java 25 빌드 경로도 저장소에 추가했지만, 현재 작업 환경에서는 외부 빌드 결과를 회수하지 못했다. 실제 JAR 빌드와 게임 로딩 검증 전에는 배포 완료로 간주하지 않는다.

## 현재 제한

- 투표 안건은 서버 재시작 시 취소된다. 통과된 결정과 마을·RPG 상태는 저장된다.
- 실제 습격 웨이브, 경비병, 방어 시설과 역할별 고유 작업은 다음 단계다.
- 전용 UI는 아직 넣지 않았다. 기능 구조가 굳은 뒤 임시 회색 메뉴가 아닌 완성형 디자인으로 추가한다.

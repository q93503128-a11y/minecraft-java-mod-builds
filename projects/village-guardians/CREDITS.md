# Village Guardians architecture credits

## What is shipped in the mod

The current fortress is generated by original Java placement code in this repository. No third-party `.schem`, map, texture pack, or model file is redistributed in the JAR.

## Licensed visual references

The architecture pass studies the following openly licensed references for medieval proportions, timber framing, building roles, and furnished interiors:

- Quaternius — **Medieval Village Pack** (CC0). Used only as a broad low-poly medieval village design reference.
- BuildSchem — **Ultimate Medieval Village Church Survival Base** (CC BY 4.0). Used as a reference for stone/timber massing and functional interior zoning.
- BuildSchem — **Ultimate Medieval Manor Survival Base** (CC BY 4.0). Used as a reference for furnished manor composition and layered medieval silhouettes.

The current generated fortress is not a direct copy or conversion of those files. Future direct imports, if any, must preserve the original author attribution and license terms in this file and in release documentation.

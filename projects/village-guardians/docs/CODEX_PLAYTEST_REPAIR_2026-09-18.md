# Village Guardians — Codex 실플레이 결함 전수 수정 인계 (2026-09-18)

## 시작 조건

반드시 현재 원격 `main`을 git으로 최신화한 뒤 시작한다. `gh`는 사용하지 않는다.
프로젝트는 `projects/village-guardians/`이며 새 프로젝트가 아니다. 기존 시스템을 재설계하거나 기능을 삭제해서 통과시키지 않는다.

현재 ChatGPT 작업 기준 버전은 `0.18.40-alpha.1`이다. SHA는 인계 시점 관측값일 뿐이므로 Codex 시작 시 원격 main을 다시 확인한다.

## 이번 실플레이에서 확인된 핵심 증상

1. 회관 유지보수 UI가 실제 게임 화면에서 지나치게 크고 빈 공간이 많아 상용 게임 UI처럼 보이지 않았다.
2. 다음 단계/비용 정보가 화면 구조상 약하고 일부는 하단 액션과 경쟁해 읽기 나빴다.
3. 고용한 철골렘 기반 용병이 병영 내부에 생성되고 닫힌 문을 통과하지 못해 실제로 갇혔다.
4. 이전 테스트에서는 마지막 적이 이동도 하지 않고 피해도 받지 않는 비정상 전투 상태도 발견됐다. 0.18.39에서 NoAI/무적 플래그와 최종 적 진행 정지 복구를 추가했으므로 회귀시키지 않는다.
5. 사용자는 현재 실플레이에서 “문제가 아주 많다”고 판단했다. 위 두 화면만 땜질하고 끝내지 말고 전체 실제 플레이 흐름을 감사해야 한다.

## 0.18.40에서 이미 반영한 것

- 회관 화면 최대 크기 축소, 상세 카드 밀도 개선, 다음 강화와 공동 보급 비용 결합 표시.
- 수리/강화 버튼에 재화 종류 직접 표시.
- 시설 단계 문구 정리.
- 신규 용병을 병영 밖 훈련장/도로 쪽에 스폰.
- 기존 세이브에서 병영 내부에 남은 용병을 낮에 바깥으로 복구.
- 0.18.39의 frozen/invulnerable raid-enemy 복구 보존.

이 항목을 되돌리지 말고 실제 코드를 먼저 읽어서 부족한 부분을 더 고친다.

## Codex가 해야 할 일

### 1. UI/UX 전수 감사
실제 화면 기준으로 회관뿐 아니라 다음을 모두 확인한다.

- 회관 유지보수
- 시설별 메뉴
- 용병 지휘
- 성벽/포탑 지휘
- 다음 밤 정찰
- 상점/보급소
- 장비 강화/합성
- 직업/기술 연구
- 패배/재도전
- 전투 HUD

검은 반투명 큰 판 + 텍스트 나열로 끝내지 않는다. 현재 프로젝트의 가장 나은 화면과 기존 디자인 언어를 기준으로 일관성을 맞춘다.
텍스트 겹침, 잘림, 과도한 빈 공간, 의미 없는 대형 패널, 버튼과 설명의 경쟁, 재화/다음 단계 누락을 실제 safe area 계산으로 제거한다.

### 2. 용병 전체 lifecycle 감사
고용 → 낮 대기 → 밤 사전 배치 → 전투 → 추적/복귀 → 사망/저장 → 재접속 → 패배 후 재도전을 전부 추적한다.

특히:
- 닫힌 문/가구/벽 때문에 navigation이 영구 실패하지 않는지
- BASTION/STRIKER/RANGER/MEDIC 모두 실제 배치점에 도달 가능한지
- 성루 명사수가 계단/포좌와 충돌하지 않는지
- 용병이 적에게 실제 어그로 대상이 되고, 자신도 적을 공격하는지
- 플레이어 화살/스킬이 용병에게 피해/충돌하지 않는지
- 도발이 시설 우선 병과에도 실제 우선권을 갖는지
- 낮에 건물 안으로 다시 들어가 갇히는 경로가 없는지
- 기존 저장의 용병도 같은 규칙을 따르는지

### 3. 전투 흐름 전수 감사
활성 적 UUID 명부, AI routing ownership, side/rear assault, structure attacks, final-wave completion, NoAI/invulnerable 상태, health/death event를 따라간다.
한 마리 때문에 웨이브가 잠기는 경우를 “그냥 죽이기”로 숨기지 말고 실제 원인을 수정한다.

### 4. 실제 플레이용 테스트 편의
수정 후 사용자가 즉시 확인할 수 있도록 필요한 `/vg` 명령이나 재현 순서를 문서에 적는다.
자동 테스트가 실제 화면/AI 성공을 대신한다고 표현하지 않는다.

## 금지

- 기능 삭제/no-op/주석 처리로 회귀검사 통과
- 기존 저장 초기화
- 용병을 매 틱 무조건 teleport하는 식의 정상 AI 무력화
- 마지막 적을 일정 시간 후 그냥 삭제/즉사
- UI를 임시 placeholder 카드로 다시 덮기
- 실제 실행하지 않은 playtest를 PLAYTESTED라고 표시
- 사소한 수정마다 clean build 반복

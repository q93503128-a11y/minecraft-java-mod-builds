# Village Guardians — 직선형 전직 정본

상태: **IMPLEMENTED / PLAYTEST DEFERRED**. 전직은 기존 다섯 역할 ID 위에 레벨로 파생되는 성장 단계다. 별도 전직 재화나 분기 직업은 만들지 않는다.

## 고정 구조

- 역할 ID는 `VANGUARD / RANGER / ARCANIST / LUMINAR / WARDEN` 다섯 개를 유지한다.
- 계보는 **기본 직업 → Lv.30 1차 전직 → Lv.60 2차 전직** 한 줄이다.
- 전직 상태는 플레이어 레벨에서 계산하므로 기존 저장에 새 전직 필드를 강제로 추가하지 않는다.
- 액티브 장착 슬롯은 기존 2칸을 유지한다. 버튼이나 단축키를 늘리지 않는다.
- 각 단계는 액티브 기술 4개를 가진다. 한 역할은 최종적으로 **기본 4 + 1차 4 + 2차 4 = 12개**의 기술 풀을 가진다.
- 2차 전직 뒤에도 기본 기술과 1차 전직 기술은 사라지거나 금지되지 않는다. 습득한 12개 중 원하는 2개를 장착한다.
- 전직 시 역할 패시브도 강화된다. 단순 공격력 상승만이 아니라 각 역할의 핵심 기능인 흡혈·대공·마법 효율·회복/보호·탱킹을 강화한다.
- 전직 전용 재화는 없다. 기술 연구는 기존 수호 주화 경제를 사용한다.
- 공용 전술 포인트는 새 시스템을 추가하지 않고 기존 `VillageSkillTreeSystem`을 그대로 사용한다. 모든 레벨업마다 1P를 지급하고 기존 저비용 단계 규칙을 유지해 50개 전체 비용은 110P다. Lv.300의 299P로 모든 갈래를 완성할 수 있다. 한 갈래라도 10단계를 완성하면 남는 포인트를 `체력 단련(최대 체력 +0.25)` 또는 `공격 단련(기본 공격력 +0.1)`에 반복 투자한다. 반복 단련 횟수는 저장되며 과거 투자 포인트는 회수하지 않는다.

## 직업 성장 5단계 종착점

직업별 성장 트리는 기존 `지속 / 위력 / 특수` 3갈래 × 5단계를 유지한다. 새 메뉴나 새 재화를 추가하지 않는다. 단순 수치 상승만으로 끝나지 않도록 **특수 V**는 역할별 행동 변화가 생기는 종착점으로 취급한다.

- 선봉검사 계열: 근접 처치 시 주변 적에게 짧은 약화를 남겨 다음 돌파 대상을 만든다.
- 성루사수 계열: 신속 사격의 완성형이 주 화살 포함 7발 부채꼴로 확장된다.
- 비전술사 계열: 기술 시전 시 첫 비전 메아리가 확정되고 추가 메아리 확률은 별도로 남는다.
- 성휘사제 계열: 남는 치유량이 흡수 보호막으로 전환되어 체력이 찬 아군에게도 가치가 생긴다.
- 철벽수호자 계열: 거대 방패 태세와 대수호 진군 유지 중 주변 아군에게 피해 저항 오라를 제공한다.

## 직업 계보

| 역할 | 기본 | 1차 · Lv.30 | 2차 · Lv.60 | 정체성 |
| --- | --- | --- | --- | --- |
| VANGUARD | 선봉검사 | 전선검장 | 파성검성 | 근접 돌파, 다수전, 흡혈, 마무리 |
| RANGER | 성루사수 | 성루명사수 | 천공추적자 | 원거리, 고지, 대공, 추적·관통 |
| ARCANIST | 비전술사 | 전투원소술사 | 대비전술사 | 원소 광역, 지역 제어, 연쇄 시전 |
| LUMINAR | 성휘사제 | 전장성직자 | 대성휘사제 | 회복, 정화, 보호, 전투 복구 |
| WARDEN | 철벽수호자 | 성문수호장 | 불락수호장 | 도발, 전선 고정, 방벽, 진형 복구 |

## 액티브 기술 풀

### 선봉검사 → 전선검장 → 파성검성

기본: `회전 검무 / 전투 고양 / 검기 난무 / 천붕 강하`

1차: `전선 절개 / 피의 회오리 / 전투 깃발 / 파성 일격`

2차: `검성 연환 / 생명 절취 / 절대 돌파 / 천단참`

전직 패시브는 근접 화력과 체력, 흡혈을 강화하고 2차에서는 부상당한 적을 마무리하는 능력을 추가 강화한다.

### 성루사수 → 성루명사수 → 천공추적자

기본: `신속 삼연사 / 추적 도탄 / 천공 화살비 / 성멸 대궁`

1차: `매의 징표 / 분열 사격 / 대공 요격 / 폭우 사격`

2차: `별추적 화살 / 관통 성단 / 천공 봉쇄 / 유성 대궁`

전직 패시브는 원거리 화력과 공중 위협 대응을 강화한다. 공중 특화는 적의 이속을 억지로 올리는 방식이 아니라 표적 우선순위와 요격 능력으로 차별화한다.

### 비전술사 → 전투원소술사 → 대비전술사

기본: `홍염탄 / 빙결 지대 / 폭풍 회랑 / 천뢰 폭격`

1차: `용암핵 / 빙결 감옥 / 낙뢰 사슬 / 중력 폭풍`

2차: `태양핵 폭발 / 절대영도 / 천뢰 연쇄 / 붕괴 특이점`

전직 패시브는 기술 위력과 재사용 효율을 강화한다. 각 스킬은 화염 폭발, 빙결 제어, 낙뢰 지역 압박, 중력 집결이라는 서로 다른 역할을 유지한다.

### 성휘사제 → 전장성직자 → 대성휘사제

기본: `응급 성광 / 전군 정화 / 치유 성역 / 기적의 대성역`

1차: `수호의 빛 / 성역 정화 / 회생 파동 / 심판광`

2차: `천상의 방벽 / 회귀의 빛 / 부활 성가 / 최후의 기적`

전직 패시브는 치유량뿐 아니라 보호막, 피해 저항, 전투 복구 능력을 강화한다. 지원 직업이 회복 버튼만 반복하지 않도록 공격형 성광 기술도 포함한다.

### 철벽수호자 → 성문수호장 → 불락수호장

기본: `수호 돌진 / 위압의 함성 / 거대 방패 태세 / 대수호 진군`

1차: `성문 충격 / 강제 도전 / 수호 결계 / 철벽 파동`

2차: `불락 방벽 / 성채 돌진 / 절대 방진 / 성채 강림`

전직 패시브는 체력·피해 경감·수호 기술을 강화한다. 새 기술은 공성 적을 미친 속도로 추격하는 대신, 도발·밀치기·방벽·진형 복구로 전선을 통제한다.

## 저장·멀티플레이 계약

- 기존 `VillageRole` enum 순서와 역할 ID는 변경하지 않는다.
- 기존 기본 기술은 roleIndex 0~3을 그대로 유지한다.
- 1차 기술은 roleIndex 4~7, 2차 기술은 8~11에 append한다. 기존 기술 비트의 의미를 바꾸지 않는다.
- 서버가 레벨, 전직 단계, 기술 습득, 장착, 피해·치유 결과를 최종 결정한다.
- 전직 뒤 기존 장비·직업 트리·기술 습득·장착 상태를 초기화하지 않는다.
- 실제 클라이언트 플레이와 멀티플레이 체감 검증은 100일 캠페인 콘텐츠 확장 후 수행한다.

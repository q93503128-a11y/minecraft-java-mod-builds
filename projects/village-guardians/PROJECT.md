## 제품 정체성

단순 바닐라 마을 보호 모드가 아니라, 하나의 넓은 요새 마을을 운영하고 시설을 성장시키며 야간 공성을 막는 협동 RPG다.

## 현재 캠페인 범위

정식 수작업 캠페인 범위를 **제100일까지** 확장한다. 제100일은 최종 대공성이고, 101일 이후는 선택형 끝없는 전쟁으로 남긴다.

- 1~19일: 기존 변경 수비 → 공성 전쟁 → 저주 군단 → 균열 공세
- 20~29일: 검은 물결
- 30~39일: 천공 침공
- 40~49일: 사령 공성
- 50~59일: 철의 일식
- 60~69일: 폭풍 군단
- 70~79일: 심연 진군
- 80~89일: 멸망 공세
- 90~99일: 최후 전쟁
- 100일: 최종 대공성
- 101일 이후: 끝없는 전쟁

후반 난도는 날짜에 따라 모든 적에게 이동 속도·공격력을 폭증시키지 않는다. 공성 적과 보스는 읽고 대응할 수 있는 이동 속도를 유지하고, 새로운 웨이브 교리, 공중/다전선 압박, 정예·지원병 조합, 보스 수와 패턴으로 난도를 올린다.

플레이어는 Lv.300까지 성장한다. Lv.1~60은 기본 직업과 1·2차 전직을 완성하는 구간이고, Lv.61~300은 자주 레벨이 오르는 장기 숙련 구간이다. Day 20의 목표 Lv.30은 보존하며 이후에는 Day 100의 Lv.300을 향해 하루 평균 3~4레벨을 얻는다. Lv.100 이후 전투 수치 환산은 4레벨당 기존 1레벨만큼만 증가해 레벨 숫자만 3배로 늘리면서 공격력·스킬 수치까지 폭증하지 않게 한다. 전술 포인트는 모든 레벨업마다 1P를 지급하고, 공용 전술 트리의 기존 저비용 규칙을 유지해 50개 전체 노드 비용은 110P다. Lv.300의 299P로 다섯 갈래를 모두 완성할 수 있다. 한 갈래라도 10단계를 완성하면 남는 포인트를 체력 +1 또는 기본 공격력 +0.1의 반복 기초 단련에 계속 투자할 수 있다. 적 처치 XP와 방어 성공 XP는 해당 날짜의 목표 레벨 상승 폭과 실제 다음 레벨 요구 XP를 함께 반영한다. 장비 전장 단계는 I~X, 포탑은 Lv.10, 방어 연구는 Lv.20, 용병은 Lv.100까지 장기 성장한다.

## 직업 확장 방향

기본 직업 5개를 유지하고 분기 직업은 추가하지 않는다. 각 직업은 **Lv.30 1차 전직 → Lv.60 2차 전직**으로 직선 성장한다. 각 전직은 액티브 기술 4개와 역할 패시브 강화를 추가한다. 2차 전직 뒤에도 기본/1차 기술을 계속 장착할 수 있다. 상세 계약은 `docs/ROLE_ADVANCEMENT_PLAN.md`를 정본으로 사용한다.

## 절대 핵심 규칙

1. 촌장 전용 플레이 권한을 만들지 않는다. 모든 플레이어가 운영, 빠른 신호, 역할, 투표, 수리와 강화에 참여한다.
2. 첫 접속자 소유자 값은 마을 중심 초기화와 기존 저장 호환에만 사용한다.
3. 자연 일주기는 멈추고 시간 진행은 플레이어 결정으로만 처리한다.
4. 중앙 광장부터 북문까지 폭 9블록의 주 전투로에는 건물이나 장식물을 두지 않는다.
5. 기능 건물의 입구는 중앙 광장을 향해야 한다.
6. 구조 NBT의 실제 문 위치를 찾아 진입로, 간판과 기능 단말을 배치한다.
7. 임의 좌표에 가구를 덧씌워 공중 블록이나 외벽 충돌을 만들지 않는다.
8. 북문은 틈 없이 닫혀야 하며 플레이어가 내부 레버로 열고 닫을 수 있어야 한다.
9. 플레이어가 성벽 위로 직접 올라갈 수 있는 연결된 계단과 통로가 있어야 한다.
10. 적은 가까운 플레이어를 시설보다 우선 공격하고, 열린 성문으로 진입하며, 닫힌 성문과 시설을 실제 타격 동작으로 공격한다.
11. 시설 피해 HUD는 피해 직후에만 보이고 평상시 화면을 점유하지 않는다.
12. 시설 파괴 시 잔해를 남기고 수리하면 원형을 복구한다.
13. UI는 개발자용 회색 메뉴, 무지개 버튼과 두꺼운 장식 프레임을 사용하지 않는다.
14. 최종 배포물은 Java 25로 컴파일되고 내부 검증을 통과한 실행용 JAR이어야 한다.

## 외부 자산 정책

무료 공개라는 말만 믿고 무단 복사하지 않는다. 수정·비상업 재사용과 공유 조건이 명시된 자산만 고정 버전으로 사용한다.

- Default Dark Mode: 26.2 인벤토리·버튼 GUI
- Tiny Creatures: CC0 판타지 적 시각 참고 자료이며 바이너리를 번들하지 않는다.
- 건물은 자체 생성 구조만 사용하며 제3자 구조 NBT를 번들하지 않는다.
- 빌드 결과에는 번들된 자산의 출처, 고정 버전과 라이선스 고지를 포함한다.

## 기능 건물

- 마을 회관
- 병영·훈련장
- 대장간
- 기술·마법 연구소
- 상점·보급소
- 의무소
- 북문·성벽

각 건물은 내구도, 기능 중단, 잔해, 수리와 최대 5단계 강화 상태를 가진다.

## UI 규격

- 바닐라 인벤토리: 공개 어두운 GUI 자산 적용
- 인벤토리 보조 패널: 레벨, 실제 XP 진행바, 역할, 재화, 마을 상태
- 전투 HUD: 바닐라 하트 묶음 대신 실제 현재 체력/최대 체력을 표시하는 가로 체력바
- 전체 운영 UI: 어두운 슬레이트 배경, 얇은 청록 강조선, 제한된 위험/강화 색상
- 작은 화면: 1열 버튼, 본문 스크롤, 항상 보이는 닫기 버튼
- 모든 X 버튼은 해당 창을 즉시 닫는다.

## 빌드 검증 계약

최종 JAR 검증기는 다음을 필수 검사한다.

- NeoForge 메타데이터와 컴파일 클래스
- Village Guardians 자체 assets/data
- Default Dark Mode GUI PNG 3개
- 제3자 라이선스 고지
- 제3자 구조 NBT 부재
- 중복 ZIP 항목과 Java 소스 혼입 금지
- SHA-256 생성

GitHub Actions 워크플로는 자동 소스 커밋으로 실행하지 않는다. `.build-trigger` 파일을 명시적으로 갱신하거나 수동 실행할 때만 동작한다.

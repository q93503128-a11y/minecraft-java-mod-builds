## 제품 정체성

단순 바닐라 마을 보호 모드가 아니라, 하나의 넓은 요새 마을을 운영하고 시설을 성장시키며 야간 공성을 막는 협동 RPG다.

## 현재 캠페인 범위

정식 수작업 캠페인 범위를 **제100일까지** 확장한다. 제100일은 최종 대공성이고, 101일 이후는 선택형 끝없는 전쟁으로 남긴다.

- 1~19일: 기존 변경 수비 → 공성 전쟁 → 저주 군단 → 균열 공세
- 20~29일: 검은 물결
- 30~39일: 천공 침공
- 40~49일: 사령 공성
- 50~59일: 철의 일식
- 60~69일: 폭풍 군단
- 70~79일: 심연 진군
- 80~89일: 멸망 공세
- 90~99일: 최후 전쟁
- 100일: 최종 대공성. 7개 고정 교리 웨이브를 순서대로 진행하고, 4~7웨이브에는 역병 대주술사 → 철갑 전쟁군주 → 공성 거수 → 검은 성문기사가 한 명씩 출전하는 우두머리 연전으로 마무리한다.
- 101일 이후: 끝없는 전쟁

후반 난도는 날짜에 따라 모든 적에게 이동 속도·공격력을 폭증시키지 않는다. 적 전투 스탯은 특정 날짜/Tier에서 하드캡하지 않고 Day 100까지 완만하게 성장한 뒤 101일 이후 제곱근 꼬리 성장으로 계속 오른다. 공성 적과 보스는 읽고 대응할 수 있는 이동 속도를 유지하고, 새로운 웨이브 교리, 공중/다전선 압박, 정예·지원병 조합, 보스 수와 패턴으로 난도를 올린다.

후반 적 외형도 스탯과 이름만 바꾼 재탕으로 처리하지 않는다. 기존 좀비/스켈레톤/일리저 계열에 더해 동굴거미·늪지 스켈레톤·조글린·브리즈·마그마 큐브·좀비화 피글린을 실제 전투 아키타입으로 사용하고, 일부 역할은 동굴거미+늪 독궁병, 조글린+황금 약탈광, 후반 팬텀+아기 기수, 공성 거수+지휘 사수처럼 바닐라 엔티티를 조합해 첫눈에 다른 실루엣을 만든다. 늪 독궁병은 실제 Bogged의 독화살, 돌풍 교란병은 Breeze의 원거리 교란과 근접 충격파, 마그마 투사·조글린 파성수·황금 약탈광은 각 본체의 이동/근접 성격에 맞춘 압박 능력을 유지해 후반 일반 병종도 이름만 다른 좀비로 돌아가지 않는다. 정예 5종은 갈고리 이동, 투척 궤적, 예고 후 암살 돌진, 역병장, 기수 돌격 충격파를 각각 실제 판정과 맞추고, doctrine별 기수/장비 실루엣을 추가한다. 조합 기수는 별도 보상/XP 주체가 아니며 피격은 서버 권한 본체로 전달되고 본체 제거 시 함께 정리한다. 용병 6병과의 본체 외형은 자체 임시 모델 대신 `THIRD_PARTY_NOTICES.md`에 고정한 Quaternius RPG Character Pack의 CC0 Warrior/Rogue/Ranger/Cleric/Monk/Wizard OBJ를 실제 런타임 리소스로 사용한다.
보스 4종도 같은 원칙을 사용한다. 공성 거수는 Ravager+Pillager 지휘 사수, 철갑 전쟁군주는 Iron Golem급 전쟁 갑주+Vindicator 도끼 지휘관, 역병 대주술사는 Spider+Witch, 검은 성문기사는 Hoglin+Wither Skeleton 기수로 구분한다. 본체 엔티티가 바뀌어도 기존 보스별 체력·공격 기준과 Siege Doctrine/Aspect 패턴은 유지하며, 시각 기수는 같은 습격 팀에 묶어 아군 오인·중복 보상·흰색 외곽선 분리를 막는다.
네 보스의 고유 주기 능력도 같은 공용 원형 이펙트로 처리하지 않는다. 공성 거수는 12틱 전 지면 파쇄 경고 후 9.5블록 충격파, 철갑 전쟁군주는 18틱 전 지휘 표준/방사 경고 후 12블록 아군 강화, 역병 대주술사는 24틱 전 거미줄형 역병장 경고 후 11블록 독·회복, 검은 성문기사는 14틱 전 교차 검격 경고 후 10블록 암흑·흡혈을 발동한다. 경고 메시의 외곽선은 보스에 붙어 이동하며 실제 발동 반경과 일치하고, 발동 순간 시각 기수의 손 동작과 병과별 사운드를 함께 사용한다.
보스 수명주기 연출도 공유 burst 하나로 끝내지 않는다. 최초 발견 시 공성 거수는 지면 균열과 중량감, 전쟁군주는 군기와 지휘 관, 대주술사는 거미줄 개화, 성문기사는 기마 돌진선으로 등장한다. 50% 2페이즈에서는 기존 Siege Doctrine/Aspect 지속층을 유지하면서 각 아키타입 전용 변형 burst를 추가하고, 사망 시에는 보상/XP/상태 해제 전에 서버가 보스 타입을 읽어 전용 마무리 연출만 재생한 뒤 기존 정리 순서를 그대로 수행한다. 사망 연출에는 추가 피해나 보상 주체를 만들지 않는다.

장비 세트는 아이템 종류로 자동 분류하지 않고 각 게임 전용 장비가 명시적인 세트 ID를 가진다. 검·도끼·전투망치·수호창·활·쇠뇌·집중봉·방패·투구·흉갑·각반·장화 등 전투 장비는 모두 세트 소속을 가지며, 같은 바닐라 아이템이라도 드랍 출처나 고유 장비에 따라 다른 세트가 될 수 있다. 세트는 전선 집행자, 밤사냥꾼, 비전 공명, 여명 성약, 성벽 수호자의 5계열이며 2/3/4/5세트 보너스를 가진다. 5세트는 단순 소폭 수치가 아니라 전사의 처형 화력, 궁수의 장거리 집중사격, 비전술사의 고위력·재사용 압축, 성광술사의 대형 지원 효율, 수호자의 저체력 철벽처럼 역할 루프를 크게 강화하는 완성 보너스로 둔다. 기존 저장의 세트 ID 없는 장비는 기존 아이템 계열을 바탕으로 호환 세트를 결정하고, 새 상점 장비·습격 드랍·합성 결과는 세트 ID를 직접 보존한다.

플레이어는 Lv.300까지 성장한다. Lv.1~60은 기본 직업과 1·2차 전직을 완성하는 구간이고, Lv.61~300은 자주 레벨이 오르는 장기 숙련 구간이다. Day 20의 목표 Lv.30은 보존하며 이후에는 Day 100의 Lv.300을 향해 하루 평균 3~4레벨을 얻는다. Lv.100 이후 전투 수치 환산은 4레벨당 기존 1레벨만큼만 증가해 레벨 숫자만 3배로 늘리면서 공격력·스킬 수치까지 폭증하지 않게 한다. 전술 포인트는 모든 레벨업마다 1P를 지급하고, 공용 전술 트리의 기존 저비용 규칙을 유지해 50개 전체 노드 비용은 110P다. Lv.300의 299P로 다섯 갈래를 모두 완성할 수 있다. 한 갈래라도 10단계를 완성하면 남는 포인트를 최대 체력 +0.25 또는 공용 공격력 +0.1의 반복 기초 단련에 계속 투자할 수 있으며 반복 랭크 자체에는 별도 상한을 두지 않는다. 공용 공격력은 근접·활·역할 기술에 모두 연결하되 광역·다단히트·지속 피해는 hit budget 계수를 사용해 한 스킬에서 동일 보너스를 반복 합산하지 않는다. 적 처치 XP와 방어 성공 XP는 해당 날짜의 목표 레벨 상승 폭과 실제 다음 레벨 요구 XP를 함께 반영한다. 장비 전장 단계는 I~X이며 상점 고유 전투 장비는 72종으로 Day 100까지 촘촘히 해금한다. 포탑은 Lv.10, 방어 연구는 Lv.20, 용병은 Lv.100까지 장기 성장한다. 용병의 사거리·제어 범위·방어력은 중간 레벨에서 하드캡하지 않고 감쇠형 숙련 곡선으로 Lv.100까지 계속 오른다. 용병은 하루 방어전이 끝나 다음 낮이 되면 생존 개체의 체력을 전부 회복한다. 방벽 수호병은 실제 도발 교전 중 짧은 흡수 체력을 얻고, 돌격 집행관은 새 표적을 추적한 뒤 첫 근접타에 큰 개시 피해를 준다. 성루 명사수/전장 치유사에 더해 Day 25 결계 수도사는 아군에게 보호막·저항과 약화 정화를 제공하고, Day 45 비전 포격병은 체력이 높은 위협을 우선 겨냥해 범위 포격과 둔화를 건다. Day 101+에서 포탑 Lv.10+연구 Lv.20 또는 용병 Lv.100+연구 Lv.20을 달성한 방어 자산은 새 레벨/재화 없이 피해는 제곱근, 사거리·지원 범위는 로그 기반의 완만한 전쟁 적응을 받아 끝없는 전쟁에서도 역할을 잃지 않는다.

## 직업 확장 방향

기본 직업 5개를 유지하고 분기 직업은 추가하지 않는다. 각 직업은 **Lv.30 1차 전직 → Lv.60 2차 전직**으로 직선 성장한다. 각 전직은 액티브 기술 4개와 역할 패시브 강화를 추가한다. 2차 전직 뒤에도 기본/1차 기술을 계속 장착할 수 있다. Lv.90/150/210/270/300에는 새 재화나 세 번째 슬롯을 만들지 않고 기존 두 장착 기술을 교차 사용해 발동하는 `전투 숙련 I~V`가 열린다. 같은 전직 단계의 두 기술은 연계 효과가 강한 집중 조합, 서로 다른 단계는 연계 시간과 쿨다운 환급이 유리한 혼합 조합으로 작동해 Lv.60 이후에도 장착 선택과 전투 순서가 실제 플레이를 바꾼다. 상세 계약은 `docs/ROLE_ADVANCEMENT_PLAN.md`를 정본으로 사용한다.

## 절대 핵심 규칙

1. 촌장 전용 플레이 권한을 만들지 않는다. 모든 플레이어가 운영, 빠른 신호, 역할, 투표, 수리와 강화에 참여한다.
2. 첫 접속자 소유자 값은 마을 중심 초기화와 기존 저장 호환에만 사용한다.
3. 자연 일주기는 멈추고 시간 진행은 플레이어 결정으로만 처리한다.
4. 중앙 광장부터 북문까지 폭 9블록의 주 전투로에는 건물이나 장식물을 두지 않는다.
5. 기능 건물의 입구는 중앙 광장을 향해야 한다.
6. 구조 NBT의 실제 문 위치를 찾아 진입로, 간판과 기능 단말을 배치한다.
7. 임의 좌표에 가구를 덧씌워 공중 블록이나 외벽 충돌을 만들지 않는다.
8. 북문은 틈 없이 닫혀야 하며 플레이어가 내부 레버로 열고 닫을 수 있어야 한다.
9. 플레이어가 성벽 위로 직접 올라갈 수 있는 연결된 계단과 통로가 있어야 한다.
10. 적은 가까운 플레이어를 시설보다 우선 공격하고, 열린 성문으로 진입하며, 닫힌 성문과 시설을 실제 타격 동작으로 공격한다.
11. 시설 피해 HUD는 피해 직후에만 보이고 평상시 화면을 점유하지 않는다.
12. 시설 파괴 시 잔해를 남기고 수리하면 원형을 복구한다.
13. UI는 개발자용 회색 메뉴, 무지개 버튼과 두꺼운 장식 프레임을 사용하지 않는다.
14. 최종 배포물은 Java 25로 컴파일되고 내부 검증을 통과한 실행용 JAR이어야 한다.

## 외부 자산 정책

무료 공개라는 말만 믿고 무단 복사하지 않는다. 수정·비상업 재사용과 공유 조건이 명시된 자산만 고정 버전으로 사용한다.

- Default Dark Mode: 26.2 인벤토리·버튼 GUI
- Tiny Creatures: CC0 판타지 적 시각 참고 자료이며 바이너리를 번들하지 않는다.
- 건물은 자체 생성 구조만 사용하며 제3자 구조 NBT를 번들하지 않는다.
- 빌드 결과에는 번들된 자산의 출처, 고정 버전과 라이선스 고지를 포함한다.

## 기능 건물

- 마을 회관
- 병영·훈련장
- 대장간
- 기술·마법 연구소
- 상점·보급소
- 의무소
- 북문·성벽

각 건물은 내구도, 기능 중단, 잔해, 수리와 최대 10단계 강화 상태를 가진다. Lv.1~5는 핵심 기능을 빠르게 완성하는 전반 성장, Lv.6~10은 효율이 완만해지는 후반 전문화 구간으로 사용한다. 후반 단계는 Lv.6/7/8/9/10 순서로 Day 25/40/55/75/90에 열린다. 대장간·연구소·병영·보급소는 후반에도 수치와 경제 효율이 계속 성장하고, 의무소는 Lv.6~10에서 저항/신속/힘/재생/보호막을 차례로 II단계로 강화한다. 비의무소 시설의 정면 문장은 Lv.6/8/10에 철·금·광원 표식이 추가되어 성장 상태가 월드 외형에서도 읽힌다.

## UI 규격

- 바닐라 인벤토리: 공개 어두운 GUI 자산 적용
- 인벤토리 보조 패널: 레벨, 실제 XP 진행바, 역할, 재화, 마을 상태
- 전투 HUD: 바닐라 하트 묶음 대신 실제 현재 체력/최대 체력을 표시하는 가로 체력바. Absorption이 있으면 현재/최대 체력 표기를 유지한 채 `+추가 체력` 수치와 금색 보조 게이지를 함께 표시한다.
- 전체 운영 UI: 어두운 슬레이트 배경, 얇은 청록 강조선, 제한된 위험/강화 색상
- 작은 화면: 1열 버튼, 본문 스크롤, 항상 보이는 닫기 버튼
- 모든 X 버튼은 해당 창을 즉시 닫는다.

## 빌드 검증 계약

최종 JAR 검증기는 다음을 필수 검사한다.

- NeoForge 메타데이터와 컴파일 클래스
- Village Guardians 자체 assets/data
- Default Dark Mode GUI PNG 3개
- 제3자 라이선스 고지
- 제3자 구조 NBT 부재
- 중복 ZIP 항목과 Java 소스 혼입 금지
- SHA-256 생성

GitHub Actions 워크플로는 자동 소스 커밋으로 실행하지 않는다. `.build-trigger` 파일을 명시적으로 갱신하거나 수동 실행할 때만 동작한다.

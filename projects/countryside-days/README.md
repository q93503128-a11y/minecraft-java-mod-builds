# Countryside Days — 시골식당

폐기된 옛 프로젝트와 무관하게 2026-07-31부터 새로 시작한 Minecraft Java Edition용 NeoForge 힐링 생활 모드다.

## 정체성

이 게임은 식당 타이쿤이 아니다. 플레이어는 넓고 현실적인 시골 생활권에서 농사, 채집, 낚시, 동물 돌보기, 주민 관계, 배달, 집과 식당 꾸미기, 산책과 탐험을 자유롭게 즐긴다. 식당은 이 활동에서 얻은 재료와 주민 이야기가 모이는 중심 거점이다.

## 현재 단계

`0.1.0-alpha.2` 기반 구현 단계다.

현재 구현된 것:

- 공식 NeoForge 26.2 + Java 25 + ModDevGradle 프로젝트 골격
- 공식 Gradle 9.2.1 Wrapper
- `countrysidedays` 모드 진입점과 분리된 레지스트리
- 시골 주방 작업대 블록
- 들나물, 민물고기, 시골 전골, 요리 수첩
- 전용 크리에이티브 탭과 한국어·영어 번역
- 블록·아이템 모델과 조리 재료 태그
- 월드 공용 저장 데이터
  - 최초 식당 기준점
  - 작업대별 손질 진행 상태
  - 누적 완성 요리 수
- 첫 실제 조리 루프
  1. 주방 작업대에 들나물 사용
  2. 같은 작업대에 민물고기 사용
  3. 시골 전골 완성 및 누적 기록
- 빈손 작업대 상태 확인과 요리 수첩 정보 확인
- JAR 내부 검증 도구와 CI 실패 원인 기록
- Java 25 `clean build`, datagen, JAR 구조 검사 성공

아직 완료되지 않은 것:

- 시골 생활권 월드 생성과 시작 식당 건축물
- 자연 채집·낚시를 통한 실제 재료 획득
- 주민에게 요리를 제공하는 단계
- 주민 일정과 관계
- 환경 렌더링, 셰이더성 후처리, 환경음
- 전용 UI
- GameTest, 전용 서버, 실제 클라이언트 실행 검증

현재 JAR은 컴파일과 구조 검사를 통과한 개발 알파다. 실제 게임 실행 검증 전까지 정식 테스트 배포물로 보지 않는다.

## 개발 빌드

Java 25가 필요하다.

```bash
./gradlew clean build
python3 tools/verify_jar.py build/libs/countrysidedays-0.1.0-alpha.2.jar
```

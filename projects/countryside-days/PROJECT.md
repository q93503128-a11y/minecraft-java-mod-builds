- Mod version: `0.1.0-alpha.10`
- Minecraft: `26.2`
- Java: `25`

- 월드 조건: 새 `평지` 월드 권장
- 선택 외부 모드: e4mc 등 연결 보조 모드

## 프로젝트 정체성

식당만 반복 운영하는 타이쿤이 아니라, 집·농장·목장·장터·주민 관계와 요리가 이어지는 시골 생활 힐링 게임이다. 식당은 모든 생활 생산과 마을 경제가 만나는 중심 거점이다.

## alpha.10 핵심 변경

### 한국어 리소스 복구

- 손상된 `ko_kr.json`을 정상 UTF-8 JSON으로 전면 재작성
- HUD의 `OPEN`, `CLOSED`, `Rep`, `Ranch`와 목표 문구를 한국어로 표시
- CI와 JAR 검사기가 한국어·영어 파일을 직접 UTF-8 디코딩하고 JSON 파싱
- 양쪽 언어 키가 하나라도 다르면 빌드 실패

### 책 분리

- `시골식당 요리 수첩`: 세 요리법, 주문 보상과 조리 기록만 수록
- `시골생활 설명서`: 식당 영업, 농사, 목장, 장터, HUD, 주민 일정과 보호 규칙 수록
- 기존 플레이어도 `alpha.10` 최초 접속 시 두 권과 시작 지원품을 한 번 받음

### 주민 대폭 증원

기존 복순·한결·소미·도윤 외에 공용 주민 12명을 추가한다.

- 제빵사 미나
- 목수 우진
- 우편배달부 하람
- 어부 세진
- 정원사 나래
- 재봉사 유리
- 선생님 지호
- 요리사 다온
- 의원 수현
- 꽃집 주인 봄이
- 대장장이 건우
- 도서관지기 은채

각 플레이어 구획에는 별도로 다음 일꾼이 배정된다.

- 농장 일꾼 새봄
- 목장 일꾼 태호

### 생활 일정과 휴일

- 새벽: 집에서 준비
- 오전: 직업별 일터에서 근무
- 정오: 점심 휴식
- 오후: 다시 근무
- 해질녘: 광장·회관에서 교류
- 밤: 집으로 귀가
- 7일마다 하루는 마을 휴일
- 휴일에는 주민들이 광장과 회관에서 쉬고 상점이 닫힘

### 실제 농사 일

- 새 개인 농장은 경작지만 있고 작물은 하나도 심지 않은 상태로 시작
- 시작 지원: 밀 씨앗 24개, 당근 16개, 감자 16개
- 플레이어가 직접 심을 수 있음
- 농장 창고 배럴에 씨앗·당근·감자를 넣으면 일꾼이 빈 경작지에 실제로 심음
- 다 자란 밀·당근·감자를 수확하고 같은 배럴에 생산물을 보관
- 수확 뒤에는 같은 작물을 다시 심어 농사가 이어짐

### 실제 목장 일

- 기존 목장 생산물 수거 배럴과 별도로 보급 배럴 추가
- 보급 배럴에 건초 블록과 물 양동이를 넣으면 목장 일꾼이 실제 급이대와 물통을 채움
- 사용한 물 양동이는 빈 양동이로 반환
- 기존 월드에서도 보급 배럴이 없으면 접속 시 자동 설치
- 가축의 배고픔·급식·급수·번식·생산·굶주림 사망은 기존처럼 실제 자원을 사용

### 날짜별 변동 물가

- 농부 한결, 목장지기 소미, 회관지기 도윤의 구매가와 매입 조건이 게임 날짜마다 변동
- 동일 날짜와 상품에서는 항상 같은 가격이라 멀티플레이어에게 공정함
- 가격과 요구 수량은 기준값에서 제한된 범위만 변해 경제가 무너지지 않음
- 휴일에는 거래 불가

## 자동 검증

- 한국어·영어 UTF-8 JSON 파싱과 키 일치

- 목장 보급 배럴과 생산물 수거 배럴

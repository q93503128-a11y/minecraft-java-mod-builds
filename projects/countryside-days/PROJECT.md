## 프로젝트 선언

이 프로젝트는 식당 경영에만 묶이지 않는 시골 생활 힐링 게임이다. 플레이어가 넓은 시골에서 자기 집·농장·식당·목장을 돌보고, 주민과 관계를 맺으며 채집·낚시·요리·축산·장터 거래·꾸미기를 이어간다. 식당은 생활, 주민 관계와 마을 경제가 만나는 중심 거점이다.

## 절대 핵심 규칙

1. 최종 배포물은 실제 컴파일된 NeoForge 실행 JAR이다.
2. 길·건물·농장·목장·수로·표지판은 하나의 예약 좌표계를 사용하며 서로 침범하지 않는다.
3. 주인 없는 농장·목장·가축을 생성하지 않는다.
4. 멀티플레이어마다 겹치지 않는 독립 생활 구획을 지급한다.
5. 집·농장·식당·목장·가축·식당명·진행도는 플레이어 UUID에 귀속한다.
6. 다른 플레이어는 남의 건물·농작물·가축·조리대·상자·문·울타리 설비를 사용할 수 없다.
7. 마을회관·장터·주민 집·공공도로 등 공공 생활권은 파괴할 수 없다.
8. 건물은 실제 침대·문·창문·가구·조명·창고·작업 시설을 갖춘다.
9. HUD는 화면을 가리지 않으며 좌표 나열 대신 상대 방향 화살표와 거리로 길을 안내한다.
10. 빌드·데이터 로드·GameTest·서버·클라이언트 검증 전에는 완성이라고 부르지 않는다.

## 새 월드 생성 규칙

1. 모드와 NeoForge를 설치한 뒤 완전히 새 월드를 만든다.
2. 월드 유형은 반드시 `평지`를 선택한다.
3. 평지는 용암·동굴·적대몹·바닐라 나무 장식이 없는 전용 `rural_plains`를 사용한다.
4. 중앙 정착지 안전 반경에는 자연 강·연못·자동 농장·자동 목장·자동 도로를 생성하지 않는다.
5. 자연 강과 드문 나무는 정착 생활권 밖에서만 생성한다.
6. `alpha.7` 이하의 월드는 옛 표지판·창문·가구·목장 구조가 저장되어 있으므로 재사용하지 않는다.

## 0.1.0-alpha.8 구현 범위

### HUD와 길찾기

- 좌측 상단에는 현재 생활 목표만 표시
- 우측 상단에는 별도 마을 동전 상태 HUD 표시
- 집과 식당은 플레이어 시선 기준 `↑ ↗ → ↘ ↓ ↙ ← ↖` 화살표와 거리로 안내
- HUD의 원시 X/Z 좌표 표시 제거
- 멀티에서는 서버가 접속자 본인의 집·식당 위치만 전송

### 건물과 사유지

- 길가의 중복 생활 구획·농장·목장 표지판 제거
- 사유지 정문 울타리 바로 앞에 소유자 표지판 하나만 배치
- 식당 이름은 남쪽 출입구 외벽에 부착하고 외부를 향하도록 고정
- 소유자 표지판과 진입로까지 사유지 보호 범위에 포함
- 플레이어 집과 주민 집에 실제 침대, 문, 2×2 유리창, 상자, 화로, 작업대, 책장, 식탁과 조명 배치
- 상자·화로·의자·문·간판의 방향 상태를 명시
- 식당 의자를 탁자 안쪽을 향하도록 네 방향으로 배치
- 공중 간판 프레임과 지지 없는 오브젝트 사용 금지

### 살아 있는 주민과 손님

- 주민은 새벽 집 앞, 낮 일터, 오후 장터·회관, 밤 자기 집으로 이동
- 농부 한결·목장지기 소미·회관지기 도윤에게 실제 직업과 마을 동전 거래 목록 지정
- 손님은 영업시간에 식당 의자까지 걸어와 계단 상판 높이에 앉음
- 영업 종료 후 일어나 중앙 마을로 돌아감
- 다른 플레이어의 식당 손님에게 서빙할 수 없음

### 목장 생활

- 목장과 헛간에 실제 여닫이 울타리문 설치
- 소·양·닭을 플레이어 UUID에 귀속하고 사유 동물 이름과 상태 표시
- 다른 플레이어의 가축 상호작용과 공격 차단
- 주인은 젖 짜기·털 깎기·끈 사용 등 바닐라 상호작용 가능
- 가축 포만도는 날짜에 따라 감소
- 포만도가 낮아지면 건초 급이대로 이동해 목장 전체가 건초 한 블록을 실제 소모
- 이어서 물통으로 이동해 물 한 칸을 실제 소모
- 자원을 채우지 않으면 배고픔·굶주림 상태가 표시되고 끝내 사망
- 잘 먹은 같은 종의 성체 두 마리는 3일 주기로 자동 번식
- 종별 최대 개체 수를 제한해 무한 증식 방지

### 시장과 진행

- 농산물 장터: 씨앗, 당근, 감자, 건초, 물통, 꿀병, 그릇
- 목장 장터: 밀, 울타리문, 끈, 이름표, 가위
- 살림 장터: 화분, 랜턴, 액자, 그림, 책장, 카펫, 의자 재료
- 모든 시장 상품은 식당 손님에게서 번 마을 동전 사용
- 시골 전골 외에 `들나물 차`와 `농가 아침식사` 추가
- 시골생활 요리 수첩을 레시피·식당 진행·시장·목장 관리·인테리어·주민 일정 안내서로 확장

### 자동 검증

- 플레이어 UUID별 생활 구획·식당명·손님 보상 분리
- 실제 침대 두 블록과 침대 방향
- 2×2 유리창, 정문·농장·목장 울타리문
- 소유자 입간판과 남향 식당 벽 간판
- 안쪽을 향하는 의자 방향
- 목장 급이대 건초와 물통
- 새 음식 레시피 데이터와 아이템 모델
- 전용 서버, 가상 디스플레이 클라이언트와 JAR 구조

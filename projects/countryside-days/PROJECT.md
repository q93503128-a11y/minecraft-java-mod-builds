## 프로젝트 선언

이 프로젝트는 식당 경영에만 묶이지 않는 시골 생활 힐링 게임이다. 플레이어가 넓은 시골에서 살고, 자기 집·농장·식당·목장을 돌보며, 주민과 관계를 맺고 채집·낚시·요리·배달·꾸미기·탐험을 즐기게 한다. 식당은 생활과 주민 관계, 마을 경제가 만나는 중심 거점이다.

## 절대 핵심 규칙

1. 최종 배포물은 실제 컴파일된 NeoForge 실행 JAR이다.
2. 마을 배치는 하나의 예약 구획표를 사용하며 길·건물·농장·수로·표지판이 서로 침범할 수 없다.
3. 주인 없는 농장과 목장을 자동 생성하지 않는다.
4. 멀티플레이어마다 겹치지 않는 독립 생활 구획을 지급한다.
5. 각 생활 구획의 집·농장·식당·목장·진행도·식당명은 해당 플레이어 UUID에 귀속한다.
6. 다른 플레이어는 남의 농장·목장·조리대·상자·문·울타리 설비를 사용할 수 없다.
7. 마을회관·장터·주민 집·공공도로 등 공공 생활권은 파괴할 수 없다.
8. 건물은 실제 생활에 필요한 가구·조명·창고·작업 시설을 갖춘다.
9. UI는 기본 회색 화면을 피하고 목재·종이·천·식물 모티프의 따뜻한 디자인을 사용한다.
10. 빌드·데이터 로드·GameTest·서버·클라이언트 검증 전에는 완성이라고 부르지 않는다.

## 새 월드 생성 규칙

1. 모드와 NeoForge를 설치한 뒤 완전히 새 월드를 만든다.
2. 월드 유형은 반드시 `평지`를 선택한다.
3. 평지는 용암·동굴·적대몹·바닐라 나무 장식이 없는 전용 `rural_plains`를 사용한다.
4. 중앙 정착지 안전 반경에는 자연 강·연못·자동 농장·자동 목장·자동 도로를 생성하지 않는다.
5. 자연 강과 드문 나무는 정착 생활권 밖에서만 생성한다.
6. `alpha.6` 이하의 이미 생성된 월드에는 잘못된 도로·수로·시설 블록이 저장되어 있으므로 재사용하지 않는다.

## 0.1.0-alpha.7 구현 범위

- 중앙 공공마을과 플레이어 사유 생활 구획을 완전히 분리
- 공공마을: 마을회관, 장터, 복순·한결·소미·도윤의 개별 주택과 일터
- 주민 주택의 상자, 화로, 작업대, 책장, 화분, 침상 표현, 식탁, 창문과 다중 조명
- 플레이어별 독립 구획: 집, 식당, 울타리 농장, 울타리 목장, 헛간, 가마솥 급수대
- 최대 8방향 다중 링 방식으로 멀티플레이어 구획을 112블록 이상 이격 배정
- 예약 도로를 먼저 배치하고 시설을 나중에 지어 중첩과 파괴 방지
- 외부 연결도로는 공기·풀·꽃만 정리하며 건물과 농작물을 덮어쓰지 않음
- 공중 간판 프레임을 폐기하고 바닥 고정 단독 입간판 사용
- 반복 생성되던 주인 없는 밭·관개수로·외곽 도로 제거
- 중앙 ±560블록 건조 정착지 예약으로 뜬금없는 물 생성 방지
- 공공시설 전체 파괴 방지와 공공 창고 접근 보호
- 사유 구획 전체를 UUID 기준으로 보호하여 주인만 수확·건축·설비 사용 가능
- 각 플레이어 식당에 해당 플레이어 전용 손님 배정
- 식당 이름, 요리 수, 손님 수, 마을 동전 수를 플레이어별 독립 저장
- 서버가 접속자 본인의 집·식당 좌표만 클라이언트로 동기화
- HUD에 현재 목표, 보유 마을 동전, 집·식당 방향·거리·X/Z 좌표 표시

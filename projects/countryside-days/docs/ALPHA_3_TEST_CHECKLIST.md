# Countryside Days 0.1.0-alpha.3 수동 테스트

## 환경

- Minecraft Java 26.2
- NeoForge 26.2.0.38-beta
- Java 25
- 새 월드 권장

## 확인 순서

1. 새 월드에 처음 접속한다.
2. 주방 작업대, 요리 수첩, 낚싯대가 각각 한 번만 지급되는지 본다.
3. 주변 평지에 식당, 밭, 우물, 과수목, 마당이 함께 생성되는지 본다.
4. 벽, 지붕, 바닥, 물, 밭, 길이 서로 겹치거나 끊기지 않았는지 본다.
5. 화면 왼쪽 위 오늘 할 일 안내판이 보이는지 본다.
6. 풀이나 고사리를 부숴 들나물이 나오는지 본다.
7. 낚시로 민물고기가 추가 지급되는지 본다.
8. 작업대에 들나물을 사용한 뒤 민물고기를 사용해 전골을 만든다.
9. 복순 할머니에게 말을 걸어 안내 문구를 확인한다.
10. 전골을 든 채 민수에게 말을 걸어 마을 동전 4개와 경험치를 받는다.
11. 같은 날 다시 전골을 건네도 보상이 중복되지 않는지 본다.
12. 요리 수첩으로 조리 수, 손님 수, 마을 동전 수를 확인한다.
13. 월드를 나갔다 들어와도 거점과 진행 기록이 유지되는지 본다.
14. 두 명이 접속했을 때 각자 준비물을 받고 같은 식당 진행을 공유하는지 본다.

## 특히 기록할 문제

- 거점이 물, 절벽, 동굴, 나무, 기존 구조물과 겹침
- 건물 내부가 어둡거나 몬스터가 생김
- NPC가 벽이나 바닥에 끼임
- NPC 이름이나 대사가 보이지 않음
- HUD가 다른 UI와 겹치거나 너무 큼
- 아이템 모델이 검보라색 또는 누락 상태로 보임
- 작업대 재료가 소모되지 않거나 전골이 중복 생성됨
- 멀티에서 손님 보상이 여러 번 지급됨
- 재접속 후 진행 기록이 초기화됨

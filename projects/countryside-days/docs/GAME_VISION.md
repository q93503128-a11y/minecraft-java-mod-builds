# Countryside Days — Game Vision

## 한 문장 정의

아름답고 넓은 한국형 시골 생활권에서 천천히 살아가며, 직접 모은 재료와 사람들의 이야기가 식당으로 모이는 오픈월드 힐링 생활 게임.

## 플레이 감정

플레이어가 느껴야 하는 핵심 감정은 다음과 같다.

- 바쁘게 최적화하지 않아도 되는 여유
- 멀리 보이는 논과 산, 물길을 직접 걸어가는 공간감
- 날씨와 시간에 따라 같은 장소가 다르게 느껴지는 변화
- 주민이 단순 상점 NPC가 아니라 같은 동네 사람처럼 느껴지는 친밀감
- 내가 한 행동이 식당, 집, 마을 풍경에 남는 축적감

## 월드 범위

개발 대상은 시골 생활권 하나다. 시골 밖의 도시, 대륙, 국가 단위 콘텐츠는 만들지 않는다.

### 핵심 생활권

- 식당과 플레이어 주거
- 마을 중심길과 작은 상점가
- 넓은 논과 밭
- 과수원과 비닐하우스
- 축사와 목장
- 냇가, 둑길, 작은 다리
- 저수지 또는 강변 낚시터
- 대나무숲, 야산, 숲길
- 버스 정류장과 외곽 도로
- 오래된 빈집, 창고, 정자, 사당 같은 생활 흔적
- 계절 행사 공간

### 규모 원칙

- 장소를 한 화면에 몰아넣지 않는다.
- 식당에서 논, 냇가, 산길까지 실제 이동 시간이 느껴져야 한다.
- 빈 공간도 논두렁, 바람, 새소리, 전봇대, 농로, 배수로 같은 정보로 채운다.
- 단순히 맵을 크게 만들지 않고 목적지 사이의 풍경과 사건을 설계한다.
- 첫 알파는 약 2048×2048 블록의 집중 생활권을 목표로 하며, 구조가 안정되면 4096×4096 블록 이상으로 확장한다.

## 핵심 플레이 루프

1. 아침에 날씨, 주민 일정, 식당 예약과 재료 상태를 확인한다.
2. 농사, 채집, 낚시, 거래, 부탁, 배달, 탐험 중 원하는 활동을 고른다.
3. 얻은 재료와 이야기를 식당 또는 집으로 가져온다.
4. 손질과 조리, 메뉴 구성, 주민 대접을 통해 관계와 마을 경제를 변화시킨다.
5. 벌어들인 자원으로 식당, 집, 농장, 마을의 작은 공간을 개선한다.
6. 해질녘과 밤에는 정리, 산책, 주민 이벤트, 실내 생활을 즐긴다.

식당을 하루 쉬어도 게임이 막히지 않는다. 반대로 식당에 집중하면 농사와 주민 관계에서 얻은 것이 깊게 연결된다.

## 식당 시스템 방향

- 클릭 한 번으로 완성되는 메뉴가 아니라 재료 준비와 조리 과정이 월드 상호작용으로 보인다.
- 손질대, 화덕, 가마솥, 프라이팬, 칼, 도마, 냉장고, 저장고를 실제 작업 공간으로 만든다.
- 메뉴는 단순 등급표가 아니라 계절, 재료 신선도, 주민 취향, 날씨와 연결한다.
- 손님 수를 빠르게 처리하는 타이쿤보다 한 끼와 한 사람의 이야기를 중요하게 다룬다.
- 멀티에서는 채집, 조리, 서빙, 배달을 자연스럽게 나눌 수 있게 한다.

## 식당 밖 콘텐츠

- 논밭 관리와 계절 작물
- 산나물, 버섯, 열매, 약초 채집
- 민물낚시와 통발
- 닭, 오리, 염소, 소 등 소규모 동물 돌보기
- 자전거, 손수레, 경운기 또는 소형 트럭 같은 시골 이동 수단
- 주민 심부름과 배달
- 빈집 정리와 주거 꾸미기
- 사진, 도감, 산책 기록
- 장터, 마을잔치, 비 오는 날, 첫눈 같은 계절 사건
- 길 수리, 정자 복원, 꽃길 조성처럼 마을 풍경을 바꾸는 공동 작업

## 주민과 관계

- 주민은 시간대와 날씨에 따라 집, 밭, 가게, 정자, 냇가를 이동한다.
- 관계도는 숫자만 오르지 않고 대사, 도움, 식당 방문, 공동 작업, 개인 사건으로 표현한다.
- 모든 주민이 매일 같은 자리에 서 있지 않는다.
- 주민마다 좋아하는 음식뿐 아니라 생활 습관, 가족, 일, 걱정과 계절 일정이 있다.
- 멀티에서는 관계 진행과 중요한 선택을 월드 기준으로 동기화한다.

## 비주얼과 셰이더 방향

JAR 내부에서 안전하게 제공할 수 있는 렌더링과 리소스를 우선한다.

- 따뜻한 아침광과 긴 노을
- 낮은 채도의 자연색과 과도하지 않은 블룸
- 거리별 안개와 산 능선의 대기 원근
- 잔잔한 물 반사와 물가 안개
- 바람에 반응하는 풀, 작물, 나뭇잎
- 비 온 뒤 젖은 흙과 반짝이는 물웅덩이
- 창문과 처마 아래의 부드러운 그림자
- 밤의 가로등, 식당 창문, 벌레 소리, 반딧불
- 실내는 따뜻하고 외부는 푸른 밤빛이 느껴지는 대비

외부 셰이더 팩을 무단 포함하지 않는다. 내장 클라이언트 렌더링, 후처리, 안개, 입자, 텍스처, 사운드를 조합해 기본 상태에서도 분위기가 살아야 한다. 외부 셰이더와의 호환은 이후 별도 검증한다.

## UI 방향

- 목재 간판, 종이 메뉴, 천 라벨, 압화와 식물 문양을 모티프로 사용한다.
- 중요한 정보는 한 화면에 과밀하게 넣지 않는다.
- 식당 운영, 주민 관계, 지도, 도감은 각각 시각 언어를 구분한다.
- 작은 화면과 창 모드에서도 겹치거나 잘리지 않아야 한다.
- 닫기 버튼은 모든 창에서 즉시 동작한다.
- 개발자용 설명, 패치 노트, 임시 회색 버튼을 게임 화면에 노출하지 않는다.

## 기술 우선순위

1. Java 25 + NeoForge 26.2 기반 실제 JAR 빌드
2. 월드 저장과 멀티 동기화의 안정성
3. 시골 생활권 생성과 거점 배치
4. 재료·조리의 한 사이클
5. 주민 일정과 관계
6. 환경 연출과 전용 UI
7. 계절, 이동 수단, 마을 공동 작업 확장

## 하지 않을 것

- 시골 밖 도시를 억지로 확장하기
- 식당 숫자 경영 메뉴만 늘리기
- 수백 개 아이템을 먼저 추가하고 실제 쓰임을 뒤로 미루기
- 파티클만으로 고급 연출을 흉내 내기
- 재배포 권한이 없는 텍스처, 셰이더, 음악을 번들하기
- 빌드와 실행 검증 없이 완성이라고 주장하기

# 1. Canonical gameplay need

The R12 main-story climax already has a locked gameplay role:

```text
Central Anchor cascade begins
→ emergency regional partition is established
→ systemic guardian / crisis form activates
→ fight communicates Network Link / Cascade Line / Partition Window / Reconfiguration
→ immediate cascade is contained
→ only then does the player choose Restore / Release / Partition
```

Terradragon remains the optional R12 altar-summoned world boss and is **not** reused as the story guardian.

The unresolved gate is therefore not `what should the finale be?`. It is:

```text
which actual external model / rig / visual family can truthfully express the already-authored systemic guardian
→ what anatomy that model supports
→ which attacks/weak points/VFX/audio can then be locked without inventing presentation during coding
```

# 2. Final-guardian visual/anatomy acceptance profile

A final candidate must satisfy the following before `FINAL GUARDIAN MODEL = LOCKED`.

## 2.1 Silhouette

Required:

- immediately reads as an **ancient constructed guardian**, not ordinary wildlife, undead, a humanoid soldier or a generic stone golem;
- large enough to carry the launch finale without becoming an unreadable screen-filling blob;
- has 2–4 visually distinct functional zones that can communicate network state;
- can plausibly remain grounded in the fantasy setting while still looking more engineered/systemic than R03's Rock Golem role.

Preferred anatomy:

- central core / chest / lens / ring / protected control structure;
- independently readable arms/emitters/shoulder assemblies or equivalent attack origins;
- one or more external link nodes, plates, conduits or segment boundaries that can visibly open/close during Partition Window/Reconfiguration;
- locomotion that supports a heavy guardian rather than a nimble human duelist.

Rejected identity shortcuts:

- `large stone humanoid + glowing cracks` as the whole concept;
- skeleton/bone boss;
- animal-shaped mech whose animal gimmick dominates the Anchor identity;
- gun robot/cyberpunk security unit;
- cute mascot monster enlarged into a finale boss;
- generic floating cube/ring made from particles only.

## 2.2 Motion coverage

The accepted asset/rig must either include or cleanly support retargeting for at least:

- idle / active-idle;
- locomotion or authored reposition;
- 3+ materially different attack motions;
- stagger / hit reaction or readable interruption state;
- phase/reconfiguration transition;
- defeat / shutdown;
- one channel/cast/charge pose suitable for network mechanics.

A model with no usable rig can remain a visual reference but cannot close the source-bootstrap gate by itself.

## 2.3 Mechanics-to-anatomy mapping

The final model must let the existing mechanics become visible:

- **Network Link** — actual link origins/nodes on the body or arena device, not arbitrary beams from empty space;
- **Cascade Line** — a readable emitter, sweep origin or body alignment that truthfully forecasts the lane;
- **Partition Window** — plates/nodes/core exposure or a similarly visible vulnerable state;
- **Reconfiguration** — a real pose/segment/state change rather than recoloring the same idle mesh.

The final attack sheet is written **after** the model wins this test.

# 3. Candidate pass A — permissive / public-safe sources

## 3.1 Quaternius `Ultimate Monsters`

Authoritative source:

`https://quaternius.com/packs/ultimatemonsters.html`

Verified current page evidence on 2026-09-17:

- 50 models;
- fully animated;
- FBX / OBJ / Blend / glTF;
- page displays **CC0**;
- free personal/commercial use stated by the creator page.

Candidate subset inspected through current public indexes includes `Goleling`, `Goleling Evolved`, `Dragon`, `Dragon Evolved` and other stylized monster identities.

### Decision

`SOURCE FAMILY = VALID COMPARISON POOL`  
`DIRECT FINAL GUARDIAN = NOT ACCEPTED`

Reason:

- license/format/animation availability are excellent;
- the currently surfaced creature identities read as fantasy creatures/mascots rather than an ancient system guardian;
- promoting one only because it is CC0 would make the final boss presentation follow asset convenience instead of canon;
- `Goleling` also risks collapsing the finale back into a conventional golem identity after R03 already owns a Rock Golem role.

The pack remains useful if archive inspection reveals a substantially stronger construct-shaped model not visible in the current web evidence.

# 4. Candidate pass B — paid/local-only discovery candidates

These sources are **not accepted project assets**. They are recorded so a later acquisition decision is evidence-based instead of repeating the search.

## 4.1 N-Hance Studio `Stylized Magic Construct` — current strongest shape/animation lead

Fab listing:

`https://www.fab.com/listings/b86c16b7-fa0f-449f-9dfd-2ca4ef725982`

Observed listing evidence on 2026-09-17:

- designed for stylized fantasy games;
- tagged machine / magic / metal / fantasy / golem / animated;
- 5 unique creatures;
- 4 hand-painted skin variations;
- **37 animations**;
- modular components;
- IK Rig / Control Rig / retarget-oriented tooling;
- FBX plus converted glTF/GLB/USDZ availability;
- exact listed animations include idle, death, stun, dodge, four unarmed attacks, spell start/loop/end families, directional walk/run and swim motions;
- listing states no generative AI was used.

Current crawled Fab evidence does **not** expose a selected license/price-tier contract cleanly enough to record redistribution/use terms as verified project provenance.

### Decision

`TOP DISCOVERY CANDIDATE = NEEDS_EXTERNAL_CLIP / VERIFY / LOCAL_ONLY`

Why it is materially stronger than the generic golem/mech pool:

- its declared identity already combines **magic + machine + metal + fantasy** instead of requiring the project to reinterpret an unrelated creature;
- four attack motions plus spell/channel states can plausibly support Cascade/Link mechanics;
- modularity gives a better chance of creating visible partition/reconfiguration states without fabricating an unrelated second model;
- broad animation coverage reduces the risk of a final boss that moves like a placeholder.

Still required before any lock:

1. visually inspect all five creature variants in the listing/video;
2. verify which exact variant has a boss-scale silhouette and readable core/nodes;
3. inspect the actual Fab license tier/terms at acquisition;
4. confirm private-use/export/retarget/conversion rights and public-repo byte boundary;
5. acquire the chosen source and preserve receipt/source/version/license evidence;
6. inspect skeleton hierarchy and animation clips;
7. test Minecraft-scale silhouette, hitbox and camera distance;
8. reject if it looks like a normal humanoid caster despite the promising feature list.

This is the **first candidate in this pass worth an actual visual/acquisition review**, but it is not production-locked yet.

# 7. Composite/editable-base fallback contract

If no single external model meets the finale standard, a **coherent edited/composite base** is allowed, but it is not permission to improvise a boss from unrelated parts.

Allowed structure:

```text
one accepted primary animated construct body/rig
+ compatible external ring/core/conduit architectural pieces from one coherent fantasy-tech family
+ authored attachment/retarget/conversion work
→ one visually unified final model
```

Requirements:

- every source has provenance and compatible terms;
- one source family remains visually dominant;
- attachments are mechanically meaningful: core, partition plate, link node, emitter, not random decoration;
- Blockbench/Blender review occurs before combat attacks are anatomy-locked;
- actual Minecraft camera/hitbox/animation review occurs before `FINAL MODEL ACCEPTED`;
- the result cannot look like `robot + random magic ring` collage.

This fallback is preferable to accepting a visibly wrong stock boss merely to close the gate.

# Senbonzakura Bankai Showcase

문승준의 Minecraft Java 전투 연출 프로토타입.

## 목표

- Minecraft Java 26.2 / NeoForge 26.2.0.38-beta / Java 25에서 실제 실행되는 단일 참백도 전투 쇼케이스를 만든다.
- 첫 구현 범위는 참백도 `천본앵`과 만해 `천본앵경엄`의 발동 연출이다.
- 서버는 권위 있는 전투 판정과 상태만 담당하고, 수백 개의 칼날은 클라이언트 custom geometry로 렌더링한다.
- 수백~수천 개 엔티티나 바닐라 파티클 도배로 연출을 흉내 내지 않는다.

## 0.1.0-alpha.1 연출 시퀀스

1. 참백도 낙하
2. 지면 파문
3. 양측 거대 도열 상승
4. 거대 도열 붕괴
5. 은빛·분홍빛 미세 칼날 폭풍
6. 전방 집중 난도질
7. 최종 수렴과 소멸

## 구현 원칙

- 다른 프로젝트의 게임 코드나 리소스를 복제하지 않는다.
- 공격 판정과 시각 칼날 수를 분리한다.
- 시전자 주변 약 2.25블록은 칼날 안전영역으로 둔다.
- 알파 단계에서는 PvP를 건드리지 않고 적대/중립 Mob만 공격한다.
- 원작 이미지·텍스처·음원 파일을 포함하지 않는다. 아이템과 연출은 코드 및 Minecraft 기본 텍스처만으로 새로 구성한다.

## 권리 고지

비상업적 개인 테스트용 팬 프로토타입이다. BLEACH 및 관련 명칭·설정의 권리는 각 권리자에게 있으며, 이 저장소에는 원작의 이미지·음원·모델을 복제한 자산을 포함하지 않는다.

# Senbonzakura Showcase

이 프로젝트의 범위는 `참백도 · 천본앵`과 `만해 · 천본앵경엄` 하나뿐이다.

## 유지하는 것

- 참백도 아이템과 전용 모델.
- `B` 직접 만해 입력.
- 검 침잠, 지면 파문, 좌우 거대 검열 84자루, 붕괴 파편, 수천 장 칼날 해류.
- `BankaiFlowMath`를 공유하는 클라이언트 연출/서버 판정.
- 고빈도 다단히트와 시전자 안전영역.
- `ExternalShockwaveVfx`를 포함한 천본앵 전용 보조 연출.

## 제거 원칙

- 범용 스킬 프레임워크를 만들지 않는다.
- 천본앵과 무관한 독립 기술, 전용 키, 서버 서비스, 렌더러를 넣지 않는다.
- 제거된 기능의 죽은 코드나 언어 키를 남기지 않는다.

## 환경

- Minecraft Java 26.2
- NeoForge 26.2.0.38-beta
- Java 25
- Gradle 9.2.1

# Senbonzakura Bankai Showcase

문승준의 Minecraft Java `천본앵 / 천본앵경엄` 단독 전투 연출 프로토타입.

## 목표

- Minecraft Java 26.2 / NeoForge 26.2.0.38-beta / Java 25에서 실제 실행되는 단일 참백도 쇼케이스를 만든다.
- 참백도 `천본앵`과 만해 `천본앵경엄`의 발동/전개를 높은 체급의 3D 연출로 구현한다.
- 서버는 권위 있는 전투 판정과 상태만 담당하고, 수천 장의 칼날은 클라이언트 custom geometry로 렌더링한다.
- 바닐라 파티클 도배, 분홍 안개, 별도 속도선 벽으로 천본앵을 흉내 내지 않는다.

## 현재 연출 시퀀스

1. 참백도를 손높이에서 놓는다.
2. 검이 지면으로 떨어져 물처럼 아래로 잠긴다.
3. 지면 파문과 함께 주변 무대가 어두워진다.
4. 좌우 각각 42자루의 거대한 검열이 지중에서 솟는다.
5. 짧은 정적 뒤 거대 검열이 작은 칼날로 물질적으로 붕괴한다.
6. 붕괴 파편이 7개의 대형 칼날 군집으로 포획되어 하나의 살아 있는 폭풍을 만든다.
7. 군집은 공격 구간에서 크게 합류하고 가르며 지나가지만 고정된 목표 좌표에서 멈추지 않는다.
8. 시전자 주변 약 2.45블록 안전영역은 공격 판정에서 제외한다.

## 현재 렌더 체급

- 검열 붕괴 파편: 약 760장.
- 근거리 두께 있는 3D 칼날: 약 420장.
- 중거리 양면 칼날 면: 약 2,100장.
- 원거리 소형 칼날 면: 약 2,400장.
- 폭풍 본체 합계: 약 4,920장.
- 7개 macro current의 중심과 내부 칼날이 모두 시간 기반으로 계속 이동한다.

## 입력/기능 범위

- `참백도 · 천본앵`을 주손 또는 보조손에 들고 `B` 단독으로 만해를 발동한다.
- 우클릭으로 만해를 발동하지 않는다.
- 범용 8개 기술, 스킬 인벤토리, 10칸 로드아웃, `Shift + 숫자` 입력은 프로젝트 범위에서 제거한다.
- 천본앵 외의 별도 능력 프레임워크를 이 쇼케이스에 다시 얹지 않는다.

## 구현 원칙

- 공격 판정과 시각 칼날 수를 분리한다.
- 수천 개 실제 엔티티를 생성하지 않는다.
- 알파 단계에서는 PvP를 건드리지 않고 Mob만 공격하며, 시전자 소유 길들인 동물과 아군은 제외한다.
- 보이는 범위와 판정 범위가 지나치게 어긋나지 않도록 공격 시점을 연출 파동과 맞춘다.
- 외부 작품 영상/스크린샷은 타이밍·실루엣·공간 사용 참고로만 사용한다.
- 원작 이미지·음원·모델·텍스처 파일은 저장소/JAR에 포함하지 않는다.
- AI 생성 이미지를 기준 레퍼런스로 사용하지 않는다.

## 권리 고지

비상업적 개인 테스트용 팬 프로토타입이다. BLEACH 및 관련 명칭·설정의 권리는 각 권리자에게 있으며, 이 저장소에는 원작 자산을 복제해 포함하지 않는다.

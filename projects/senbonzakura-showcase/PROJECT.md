# Senbonzakura & Ability Showcase

문승준의 Minecraft Java 고연출 전투 스킬 프로토타입.

## 현재 범위

- 참백도 `천본앵` / 만해 `천본앵경엄`.
- 독립 쇼케이스 기술 8종: 천락, 공간절단, 흑일, 천검묘, 역천, 시간장례, 백뢰강림, 성창.
- Minecraft Java 26.2 / NeoForge 26.2.0.38-beta / Java 25.

## 천본앵 전투 원칙

- 시각 칼날은 수천 장의 client custom geometry로 렌더하며 실제 엔티티 수천 개를 생성하지 않는다.
- 거대 검열 84자루 → 붕괴 파편 약 760장 → 폭풍 본체 약 4,920장의 질량 전환을 유지한다.
- 7개 macro current와 4개 렌더 속도층이 실제로 지나가는 경로를 서버가 추적한다.
- 폭풍 활성 구간에는 매 틱 판정하며 여러 렌더층이 겹친 만큼 다단히트를 누적한다.
- 천본앵은 세 번의 큰 피해가 아니라 매우 많은 작은 참격이 연속으로 들어가는 기술로 취급한다.
- 시전자 주변 안전영역, 아군, 소유 길들인 동물은 공격에서 제외한다.

## 8개 독립 기술

각 기술은 단순 색 변경이 아니라 실루엣, 공간 사용, 속도 곡선과 공격 타이밍을 별도로 갖는다.

- `Z` 천락: 상공 균열과 초거대 검 낙하.
- `V` 공간절단: 전장을 가르는 지연 대각 절단.
- `G` 흑일: 성장/흡인/압축하는 구형 암흑체.
- `R` 천검묘: 48자루 거대 무기 전개.
- `H` 역천: 중력 반전과 동시 지면 충돌.
- `J` 시간장례: 시간 정지장과 축적 참격 동시 해방.
- `K` 백뢰강림: 입체 번개 본류와 분기.
- `O` 성창: 수렴환, 압축 발사체, 경로 후폭발.

## 구현 원칙

- 서버는 권위 있는 피해/상태 판정을 담당한다.
- 대형 연출은 client custom geometry 중심으로 구성한다.
- 바닐라 파티클 도배나 동일 효과의 색상 복제는 사용하지 않는다.
- 외부 작품의 원본 이미지·음원·모델·텍스처 파일은 저장소/JAR에 포함하지 않는다.
- Java 25 clean build와 JAR 검증을 통과하지 않은 산출물은 테스트용 정본으로 취급하지 않는다.

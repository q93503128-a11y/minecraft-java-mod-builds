## 0.1.0-alpha.12 — Dense Multi-Hit + Ability Return

### 천본앵

- 검 침잠 → 지면 파문 → 좌우 거대 검열 84자루 상승 → 약 760장 붕괴 파편 → 약 4,920장 칼날 폭풍 구조를 유지한다.
- 기존에는 서버 공격이 150/180/212틱의 세 순간에만 발생했다. alpha.12부터는 칼날 폭풍이 살아 있는 108~248틱 동안 매 틱 판정을 수행한다.
- 렌더러가 실제 사용하는 0.82 / 1.00 / 1.10 / 1.30 속도층을 서버도 모두 추적한다.
- 한 대상이 여러 칼날 층에 동시에 덮이면 한 틱에 최대 4회의 작은 참격을 받는다.
- 바닐라 피격 무적시간이 수십 개 칼날 접촉을 하나로 합치지 않도록 천본앵의 각 미세 참격 직전에 해당 피격 무적시간을 해제한다.
- 피해량은 개별 타격을 작게 유지하고, 위력은 높은 히트 수의 누적으로 만든다.
- 시전자 주변 안전영역과 아군/소유 길들인 동물 제외는 유지한다.

### 독립 쇼케이스 기술 8종

alpha.10의 Bankai-only 정리에서 빠졌던 8개 기술을 다시 실제 실행 경로에 연결한다. 단순 색변환 복제품이 아니라 각 기술마다 별개의 custom geometry와 전투 타이밍을 사용한다.

- 천락: 상공 균열, 초거대 검 낙하, 충격파/잔해
- 공간절단: 지연 대각 절단면, 공간층 분리, 파쇄
- 흑일: 구형 암흑체 성장, 흡인, 압축 폭발
- 천검묘: 48자루 거대 무기 상승/부유/낙하
- 역천: 범위 중력 반전과 동시 추락
- 시간장례: 시간장과 정지 참격, 동시 해방
- 백뢰강림: 암운층과 굵은 입체 번개 본류/분기
- 성창: 후방 수렴환, 압축, 성창 발사, 경로 후폭발

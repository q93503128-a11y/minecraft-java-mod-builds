# Senbonzakura Bankai Showcase

Minecraft Java 26.2 / NeoForge용 전투 연출 프로토타입.

## 조작

1. 크리에이티브 전투 탭에서 `참백도 · 천본앵` 획득.
2. 참백도를 주손 또는 보조손에 든다.
3. `B`로 `卍解 · 千本桜景厳` 발동.
4. 키는 Minecraft 조작 설정에서 변경 가능.

우클릭은 만해를 발동하지 않는다.

## 0.1.0-alpha.4 — Petal Storm Rebuild

`alpha.3`의 초반 의식 연출은 유지하고, 검열이 꽃잎 칼날로 바뀌는 과정과 이후 폭풍의 힘을 전면 강화했다.

- 거대 검열에 균열/발광 단계를 추가
- 거대 검 → 중간 크기 칼날 파편 → 미세 칼날의 2단 분해
- 분해 파편 약 320개
- 폭풍을 Flow / Core / Dust 3계층으로 분리
- Flow 430개 3D 칼날이 넓은 난류 해류를 형성
- Core 108개 고속 칼날이 긴 잔광과 순간 가속을 담당
- Dust 340개 미세 스트릭이 속도감과 밀도를 보강
- 공격 직전 압축 후 좌→우 / 우→좌 / 전방 수렴 공격에서 급가속
- 시전자 주변 안전영역 유지

## 성능 구조

보이는 대형 검과 칼날 조각은 클라이언트 custom geometry다. 실제 엔티티 수백 개를 생성하지 않는다.
서버는 만해 상태와 공격 판정만 처리한다.

CI 기준: Java 25 + Minecraft 26.2 + NeoForge 26.2.0.38-beta에서 clean build와 JAR 내용 검사를 통과해야 배포 가능으로 본다.

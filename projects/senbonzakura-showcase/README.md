# Senbonzakura Bankai Showcase

Minecraft Java 26.2 / NeoForge용 전투 연출 프로토타입.

## 조작

1. 크리에이티브 전투 탭에서 `참백도 · 천본앵` 획득.
2. 참백도를 주손 또는 보조손에 든다.
3. `Shift + B`로 `卍解 · 千本桜景厳` 발동.
4. 키는 Minecraft 조작 설정에서 변경 가능.

우클릭은 만해를 발동하지 않는다.

## 0.1.0-alpha.3 — Presentation Rebuild

`alpha.2`의 원형 칼날 폭풍 연출을 폐기하고 전면 재작성했다.

새 시퀀스:

- 손높이의 참백도를 놓아 지면으로 떨어뜨림
- 검이 물에 잠기듯 지면 아래로 사라짐
- 동심원 파문과 함께 주변 공간이 어두워짐
- 좌우에 시야 끝까지 이어지는 대형 도열이 지중에서 상승
- 짧은 정적 후 대형 도열이 물질적으로 붕괴
- 분홍 파티클이 아니라 작은 3D 칼날 조각으로 거대한 좌우 칼날 해류 형성
- 좌→우, 우→좌, 양측 전방 수렴의 세 차례 대형 공격 파동
- 시전자 주변 안전영역 유지

## 성능 구조

보이는 대형 검과 칼날 조각은 클라이언트 custom geometry다. 실제 엔티티 수백 개를 생성하지 않는다.
서버는 만해 상태와 세 번의 공격 판정만 처리한다.

CI 기준: Java 25 + Minecraft 26.2 + NeoForge 26.2.0.38-beta에서 clean build와 JAR 내용 검사를 통과해야 배포 가능으로 본다.

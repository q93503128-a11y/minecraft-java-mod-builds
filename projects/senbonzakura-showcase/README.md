# Senbonzakura Bankai Showcase

Minecraft Java 26.2용 전투 연출 프로토타입이다.

## 테스트

1. NeoForge 26.2.0.38-beta 환경에 빌드 JAR을 넣는다.
2. 크리에이티브 전투 탭에서 `참백도 · 천본앵`을 획득한다.
3. 검을 들고 우클릭하면 만해가 발동한다.
4. 기본 전개 시간은 10초, 재사용 대기시간은 30초다.

## 0.1.0-alpha.1

- 실제 장비 가능한 참백도 아이템
- 참백도 낙하 및 지면 파문
- 양측의 거대 검열 상승
- 거대 검열이 미세 칼날 군집으로 전환되는 연출
- 클라이언트 전용 수백 개 3D blade shard
- 시전자 주변 안전영역
- 서버 권위 Mob 광역 난도질 판정
- 최종 집중 일격

연출은 파티클 수를 늘리는 방식이 아니라 custom world geometry를 사용한다.

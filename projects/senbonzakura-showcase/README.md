# Senbonzakura Bankai Showcase

Minecraft Java 26.2 / NeoForge용 전투 연출 프로토타입.

## 조작

1. 크리에이티브 전투 탭에서 `참백도 · 천본앵` 획득.
2. 참백도를 주손 또는 보조손에 든다.
3. **`B` 단독**으로 `卍解 · 千本桜景厳` 발동.
4. 키는 Minecraft 조작 설정에서 변경 가능.

우클릭은 만해를 발동하지 않는다. `alpha.5`에서는 키바인드 내부 ID를 새로 등록해 이전 버전의 `Shift+B` 설정이 `options.txt`에서 승계되지 않도록 했다.

## 0.1.0-alpha.5 — Petal-only Natural Storm

`alpha.4`에서 속도감을 위해 사용했던 선형 잔광/벽 스트릭을 제거하고, 움직이는 표현을 모두 실제 3D 꽃잎 칼날로 통일했다.

- 검열 분해 파편 480개
- Flow 꽃잎 820개
- Core 꽃잎 220개
- Dust 꽃잎 620개
- 폭풍 구간 총 약 1,660개 꽃잎 칼날 + 분해 파편
- 모든 Core/Dust 속도선과 벽 형태 glow streak 제거
- Dust 계층도 선이 아니라 작은 3D 칼날로 변경
- 기존 `fract` 반복 이동 제거
- 연속 사인/코사인 기반 흐름장으로 자연스러운 곡선 운동
- 각 꽃잎의 실제 다음 위치를 이용해 회전 방향을 계산
- 일부 꽃잎만 공격 파동으로 이탈하고 나머지는 계속 폭풍 흐름 유지
- 좌→우 / 우→좌 / 전방 수렴의 순간 가속은 유지
- 초반 검 낙하 / 지면 침잠 / 거대 검열 상승 연출 유지

## 성능 구조

보이는 대형 검과 칼날 조각은 클라이언트 custom geometry다. 실제 엔티티 수백~수천 개를 생성하지 않는다.
서버는 만해 상태와 공격 판정만 처리한다.

CI 기준: Java 25 + Minecraft 26.2 + NeoForge 26.2.0.38-beta에서 clean build와 JAR 내용 검사를 통과해야 배포 가능으로 본다.

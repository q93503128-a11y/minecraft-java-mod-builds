# Senbonzakura Bankai Showcase

Minecraft Java 26.2 / NeoForge용 `참백도 · 천본앵` 단독 전투 연출 프로토타입.

## 조작

1. 크리에이티브 전투 탭에서 `참백도 · 천본앵`을 획득한다.
2. 주손 또는 보조손에 천본앵을 든다.
3. **`B` 단독**으로 `만해 · 천본앵경엄`을 발동한다.
4. 우클릭, 스킬 인벤토리, `Shift + 숫자` 슬롯 입력은 사용하지 않는다.

## 0.1.0-alpha.10 — Bankai-only Cleanup

`alpha.8~alpha.9`에서 시험했던 범용 전투 기술/스킬 인벤토리 구조를 전부 제거하고 천본앵 하나에 다시 집중한다.

- 8개 범용 쇼케이스 기술 제거.
- 스킬 인벤토리 및 10칸 로드아웃 UI 제거.
- 일반 기술 키바인드와 네트워크 요청 경로 제거.
- `B` 단독 천본앵 발동만 유지.
- `alpha.7`의 밀집 군집형 칼날 해류 연출 유지.
- 7개의 대형 칼날 군집이 서로 합류/분리하면서 계속 흐르는 구조 유지.
- 폭풍 본체 약 4,920장(근거리 420 + 중거리 2,100 + 원거리 2,400), 검열 붕괴 약 760장 구조 유지.
- 고정 목표점으로 꽃잎이 몰렸다 멈추는 이동 구조는 사용하지 않는다.

## 연출 기준

초반 전개는 `검을 놓음 → 지면 침잠 → 파문/암전 → 좌우 거대 검열 상승 → 동시 붕괴 → 거대한 칼날 해류` 순서로 읽히도록 구성한다. 꽃잎은 단순 분홍 파티클 안개가 아니라 가까이에서는 작은 칼날, 멀리에서는 꽃잎처럼 읽히는 custom geometry를 사용한다.

BLEACH TV 애니메이션과 Bandai Namco `BLEACH Rebirth of Souls`의 쿠치키 뱌쿠야 공식 영상/화면은 동작, 타이밍, 공간 구성의 **참고 자료로만** 본다. 원작 이미지·음원·모델·텍스처 파일은 프로젝트에 포함하지 않는다. AI 생성 이미지를 연출 참고 자산으로 사용하지 않는다.

## 환경

- Minecraft Java 26.2
- NeoForge 26.2.0.38-beta
- Java 25
- Gradle 9.2.1

CI에서 Java 25 clean build, 필수 Bankai 클래스/리소스 존재 확인, 폐기한 범용 능력/UI 클래스 부재 확인을 모두 통과해야 테스트 JAR로 인정한다.

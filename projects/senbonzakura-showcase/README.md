# Senbonzakura Bankai Showcase

Minecraft Java 26.2 / NeoForge용 `참백도 · 천본앵` 단독 전투 연출 프로토타입.

## 조작

1. 크리에이티브 전투 탭에서 `참백도 · 천본앵`을 획득한다.
2. 주손 또는 보조손에 천본앵을 든다.
3. **`B` 단독**으로 `만해 · 천본앵경엄`을 발동한다.
4. 우클릭, 스킬 인벤토리, `Shift + 숫자` 슬롯 입력은 사용하지 않는다.

## 0.1.0-alpha.11 — Blade River Alignment

`alpha.10`의 Bankai-only 구조를 유지하면서, 화면에서 보이는 칼날 흐름과 실제 서버 전투 판정을 같은 수학으로 묶고 남아 있던 원형 궤도 성격을 제거한다.

- 클라이언트/서버 공용 `BankaiFlowMath` 추가.
- 7개 macro current의 중심 이동을 원형 `orbit` 계산에서 비대칭 칼날 강 구조로 전면 교체.
- 좌측 3개 해류의 1차 횡단 → 우측 3개 해류의 2차 횡단 → 7개 전부의 전방 대수렴 순서로 공격 실루엣 구성.
- 폭풍 본체 약 4,920장(근거리 420 + 중거리 2,100 + 원거리 2,400), 검열 붕괴 약 760장 체급 유지.
- 서버 공격을 플레이어 현재 위치 중심의 원형 범위 판정에서 제거하고, 실제 7개 해류가 최근 지나간 sweep corridor를 기준으로 판정.
- 시전 후 플레이어가 이동해도 판정 원점은 최초 만해 전개 지점과 일치.
- 다른 차원의 플레이어에게 start 패킷을 보내던 전역 broadcast를 제거하고 시전 차원으로 제한.
- 참백도 툴팁에 남아 있던 `Shift + B` 표기를 실제 입력인 `B`로 수정.
- 참백도 아이템 모델을 더 가는 도신, 암색 사각 츠바, 금색 장식, 보라색 손잡이 계열로 재구성.

## 연출 기준

초반 전개는 `검을 놓음 → 지면 침잠 → 파문/암전 → 좌우 거대 검열 상승 → 동시 붕괴 → 거대한 칼날 해류` 순서로 읽히도록 구성한다. 꽃잎은 단순 분홍 파티클 안개가 아니라 가까이에서는 작은 칼날, 멀리에서는 꽃잎처럼 읽히는 custom geometry를 사용한다.

칼날 해류는 시전자를 중심으로 원을 도는 장식물이 아니다. 좌우 검열에서 태어난 큰 질량이 서로 다른 타이밍과 방향으로 전장을 가르고, 마지막에는 넓은 전방 강으로 합쳐졌다 다시 분리되어야 한다. 서버 판정 역시 이 macro current의 이동을 직접 샘플링한다.

BLEACH TV 애니메이션과 Bandai Namco `BLEACH Rebirth of Souls`의 쿠치키 뱌쿠야 공식 영상/화면은 동작, 타이밍, 공간 구성의 **참고 자료로만** 본다. 원작 이미지·음원·모델·텍스처 파일은 프로젝트에 포함하지 않는다. AI 생성 이미지를 연출 참고 자산으로 사용하지 않는다.

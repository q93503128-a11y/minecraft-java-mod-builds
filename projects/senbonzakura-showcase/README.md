# Senbonzakura Showcase

Minecraft Java 26.2 / NeoForge용 `천본앵` 단일 쇼케이스 모드.

## 조작

- `B` — 만해 · 천본앵경엄 (`참백도 · 천본앵`을 주손/보조손에 든 상태)

모든 범용/독립 스킬은 제거했다. 이 프로젝트는 이제 천본앵과 그 만해 연출·판정만 유지한다.

## 현재 구현

- 검 침잠 → 지면 파문 → 좌우 거대 검열 84자루 상승 → 붕괴 파편 약 760장 → 약 4,920장 칼날 폭풍.
- 7개 macro current와 렌더 속도층을 서버 판정에서도 추적.
- 칼날 폭풍 활성 구간에는 고빈도 다단히트 판정을 수행.
- 시전자 주변 안전영역, 아군, 소유 길들인 동물은 공격 제외.
- 대형 연출은 client custom geometry 중심이며 바닐라 파티클 도배를 사용하지 않는다.

## 환경

- Minecraft Java 26.2
- NeoForge 26.2.0.38-beta
- Java 25
- Gradle 9.2.1

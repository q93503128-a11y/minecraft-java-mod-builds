# Senbonzakura Bankai Showcase

Minecraft Java 26.2 / NeoForge용 전투 연출 프로토타입.

## 조작

1. 크리에이티브 전투 탭에서 `참백도 · 천본앵` 획득.
2. 참백도를 주손 또는 보조손에 든다.
3. **`B` 단독**으로 `卍解 · 千本桜景厳` 발동.
4. 키는 Minecraft 조작 설정에서 변경 가능.

우클릭은 만해를 발동하지 않는다. `alpha.5`부터 새 키바인드 ID를 사용해 이전 `Shift+B` 설정을 승계하지 않는다.

## 0.1.0-alpha.7 — Clustered Blade Torrent

`alpha.6`의 연속 유동장은 유지하면서, 꽃잎이 너무 흩어져 보이던 문제를 고쳤다.

- 꽃잎 폭풍을 7개의 대형 칼날 군집으로 재구성
- 군집마다 수백 장이 내부에서 계속 흐르고 회전
- 공격 구간에는 왼쪽 3군집 / 오른쪽 3군집이 각각 큰 해류로 합쳐졌다가 다시 분리
- 마지막 구간은 한 점 수렴 대신 폭을 유지한 전방 칼날 강으로 변형
- 가까운 꽃잎은 선 없는 3D 칼날, 중·원거리는 경량 양면 칼날 면으로 분리
- 폭풍 본체 약 4,920장(근거리 420 + 중거리 2,100 + 원거리 2,400)
- 검열 분해 단계 약 760장 추가
- 기존 geometry budget 병목을 피하도록 렌더 구조를 계층화
- 어떤 꽃잎도 고정된 목표점/end 좌표를 사용하지 않음
- 군집 중심과 내부 꽃잎 모두 시간 기반으로 계속 이동
- 초반 검 낙하 / 지면 침잠 / 거대 검열 상승 연출 유지

## 성능 구조

보이는 대형 검과 칼날 조각은 클라이언트 custom geometry다. 실제 엔티티 수천 개를 생성하지 않는다.
근거리 칼날에만 두께 있는 3D 형상을 쓰고, 중·원거리 군집은 선이 없는 경량 양면 칼날 면으로 처리한다.
서버는 만해 상태와 공격 판정만 처리한다.

CI 기준: Java 25 + Minecraft 26.2 + NeoForge 26.2.0.38-beta에서 clean build와 JAR 내용 검사를 통과해야 배포 가능으로 본다.

# Senbonzakura & Ability Showcase

Minecraft Java 26.2 / NeoForge용 고연출 전투 기술 프로토타입.

## 조작

- `B` — 만해 · 천본앵경엄 (참백도 · 천본앵을 손에 든 상태)
- `Z` — 천락 · Skyfall
- `V` — 공간절단 · World Divide
- `G` — 흑일 · Black Sun
- `R` — 천검묘 · Grave of Swords
- `H` — 역천 · Gravity Reversal
- `J` — 시간장례 · Last Second
- `K` — 백뢰강림 · Heaven's Judgment
- `O` — 성창 · Stellar Lance

신규 8개 기술은 천본앵 아이템 없이 바로 테스트 가능하다. 모든 키는 Minecraft 조작 설정에서 변경할 수 있다.

## 0.1.0-alpha.8 — Eight Ability Showcase

천본앵 `alpha.7`의 밀집 군집형 꽃잎 폭풍은 유지하면서, 서로 연출 문법이 겹치지 않는 8개 기술을 추가했다.

- 천락: 상공 균열 → 초거대 검 노출 → 낙하 → 지면 충격파/부유 잔해
- 공간절단: 지연된 대각 절단면 → 공간층 분리 → 후발 파쇄
- 흑일: 실제 구형 암흑체 성장 → 주변 칼날 흡입 궤도 → 점압축 폭발
- 천검묘: 전장에 48자루 거대 무기 상승 → 부유 → 분산 낙하
- 역천: 범위 내 잔해/적 부유 → 중력 반전 해제 → 동시 지면 충돌
- 시간장례: 반투명 시간장 → 정지된 다중 참격 → 시간 재개와 동시 판정
- 백뢰강림: 상공 암운층 → 굵은 입체 번개 본류/분기 → 지면 전격파
- 성창: 후방 대형 수렴환 → 에너지 초압축 → 소형 성창 발사 → 경로 후폭발

## 설계 원칙

- 기술마다 실루엣, 공간 사용, 속도 곡선, 정적 구간을 다르게 한다.
- 단순 색 변경이나 동일한 파티클 복제는 금지한다.
- 큰 기술은 실제 custom geometry를 중심으로 구성하고, 피해 판정은 서버에서 분리한다.
- 천본앵 꽃잎은 별도 선/레이저 효과 없이 칼날 형상 자체로 밀도와 흐름을 표현한다.

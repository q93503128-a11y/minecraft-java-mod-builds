# Changelog

## 0.1.0-alpha.3 — 2026-08-12

- `alpha.2`의 원형/공전형 칼날 폭풍 프레젠테이션 폐기.
- 만해 연출 전체를 의식형 시퀀스로 재작성.
- 참백도 낙하 높이를 손높이 기준으로 수정하고 지면 침잠 연출 강화.
- 로컬 암전 무대와 다중 지면 파문 추가.
- 좌우 각각 42자루의 대형 검열을 긴 원근 구도로 배치.
- 대형 검열의 물질적 분해 전환 단계 추가.
- 520개의 클라이언트 3D 미세 칼날을 좌우 해류 형태로 재배치.
- 공전 운동 제거, 좌우 횡단 및 전방 수렴 3단 공격으로 교체.
- 공격 판정을 시각 파동 타이밍에 맞춰 3회로 정리.
- 전개 시간을 13초로 조정.
- 만해 전용키는 `Shift + B` 유지, 우클릭 발동 금지.

## 0.1.0-alpha.2 — 2026-08-12

- 전용 `Shift + B` 만해 키 추가.
- Java 25 / NeoForge 26.2 빌드 오류 수정.

## 0.1.0-alpha.1 — 2026-08-12

- 최초 독립 프로젝트 생성.
- 참백도 `천본앵` 아이템 추가.
- 만해 `천본앵경엄` 1차 전개 시퀀스 구현.
- 서버 판정과 클라이언트 대량 칼날 렌더를 분리.

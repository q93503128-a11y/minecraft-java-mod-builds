# Changelog

## 0.1.0-alpha.11 — 2026-08-14

- 클라이언트 렌더와 서버 공격 판정이 함께 사용하는 `BankaiFlowMath` 추가.
- 7개 macro current의 중심에서 남아 있던 원형 `orbit` 이동을 제거하고 비대칭 칼날 강 이동으로 교체.
- 좌측 3군집 횡단, 우측 3군집 역방향 횡단, 7군집 전방 대수렴의 3단 전투 흐름으로 재구성.
- 서버 공격을 플레이어 현재 위치 중심 원형 AABB 전체 타격에서, 실제 해류 중심의 최근 sweep corridor 교차 판정으로 변경.
- 시전자가 의식 단계 이후 이동하더라도 공격 판정은 최초 전개 원점을 유지하도록 수정.
- Bankai start 패킷을 전 서버 broadcast하던 문제를 수정하여 시전 차원 플레이어에게만 전달.
- stop 패킷은 차원 이동/로그아웃 시 stale client state 정리를 위해 전역 clear 방식 유지.
- 참백도 툴팁의 오래된 `Shift + B` 표기를 실제 `B` 단독 입력으로 수정.
- 참백도 모델을 가는 도신, 암색 사각 츠바, 금색 장식, 보라색 손잡이 중심으로 재구성.
- 네트워크 프로토콜을 `senbonzakura-showcase-v7`으로 갱신.
- CI에 alpha.11 source audit, 공용 flow math 클래스/JAR 리소스 검증 추가.

## 0.1.0-alpha.10 — 2026-08-14

- `alpha.8`에서 추가했던 범용 8개 쇼케이스 기술 전부 제거.
- `alpha.9`에서 추가했던 스킬 인벤토리, 10칸 로드아웃, 일반 기술 키바인드 전부 제거.
- 일반 능력 서버 서비스/클라이언트 렌더/네트워크 요청 경로 제거.
- 천본앵을 든 상태의 `B` 단독 만해 입력만 유지.
- 네트워크 프로토콜을 Bankai-only 구조에 맞춰 `senbonzakura-showcase-v6`으로 갱신.
- `alpha.7`의 7군집 밀집 칼날 해류와 약 4,920장 폭풍 + 약 760장 검열 붕괴 구조 유지.
- 원작 자산을 포함하지 않고 공식 영상/화면은 연출 참고로만 사용한다는 범위를 문서에 명시.
- CI에서 폐기한 범용 능력/UI 클래스가 JAR에 남아 있으면 실패하도록 검증 강화.

## 0.1.0-alpha.3 — 2026-08-12

- `alpha.2`의 원형/공전형 칼날 폭풍 프레젠테이션 폐기.
- 만해 연출 전체를 의식형 시퀀스로 재작성.
- 참백도 낙하 높이를 손높이 기준으로 수정하고 지면 침잠 연출 강화.
- 로컬 암전 무대와 다중 지면 파문 추가.
- 좌우 각각 42자루의 대형 검열을 긴 원근 구도로 배치.
- 대형 검열의 물질적 분해 전환 단계 추가.
- 520개의 클라이언트 3D 미세 칼날을 좌우 해류 형태로 재배치.
- 공전 운동 제거, 좌우 횡단 및 전방 수렴 3단 공격으로 교체.
- 공격 판정을 시각 파동 타이밍에 맞춰 3회로 정리.
- 전개 시간을 13초로 조정.
- 당시 만해 전용키는 `Shift + B` 사용.

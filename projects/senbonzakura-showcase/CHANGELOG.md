# Changelog

## 0.1.0-alpha.12 — 2026-08-14

- 천본앵 서버 공격을 3회 단발 판정에서 108~248틱 연속 다단히트 판정으로 전환.
- 클라이언트가 사용하는 0.82 / 1.00 / 1.10 / 1.30 네 가지 칼날 해류 속도층을 서버 판정에도 동일 적용.
- 한 대상이 여러 칼날 층에 겹치면 한 틱에 최대 4회 미세 참격을 받도록 밀도 기반 접촉 판정 추가.
- 천본앵 미세 참격이 바닐라 피격 무적시간에 합쳐지지 않도록 각 접촉 직전 무적시간을 초기화.
- 공격 반경을 시각적 원거리 칼날층에 맞게 확장하되 원형 묻지마 타격은 사용하지 않고 실제 해류 sweep corridor만 판정.
- alpha.10 Bankai-only 정리 때 빠졌던 8개 독립 쇼케이스 기술을 다시 활성화.
- 천락 / 공간절단 / 흑일 / 천검묘 / 역천 / 시간장례 / 백뢰강림 / 성창의 서버 서비스, 전용 키, custom geometry 렌더 경로 복구.
- Bankai와 8개 기술을 같은 네트워크 payload에서 분기 처리하도록 프로토콜 v8로 갱신.
- 기존 외부 충격파 보조 렌더를 실제 클라이언트 이벤트에 연결.
- CI를 alpha.12 기준으로 갱신하고 Bankai 다단히트 및 8개 능력 클래스의 source/JAR 포함 여부를 검증.

## 0.1.0-alpha.11 — 2026-08-14

- 클라이언트 렌더와 서버 공격 판정이 함께 사용하는 `BankaiFlowMath` 추가.
- 7개 macro current의 원형 이동을 비대칭 칼날 강 이동으로 교체.
- 서버 공격을 실제 해류의 sweep corridor 기준으로 변경.
- 참백도 툴팁의 오래된 `Shift + B` 표기를 실제 `B` 입력으로 수정.

## 0.1.0-alpha.10 — 2026-08-14

- 범용 쇼케이스 기술과 스킬 UI를 제거하고 천본앵 Bankai-only 구조로 정리.

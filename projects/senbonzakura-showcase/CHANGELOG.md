# Changelog

## 0.1.0-alpha.13 — 2026-08-14

- 프로젝트 범위를 다시 천본앵 단일 쇼케이스로 고정.
- 천본앵과 무관한 독립 기술 코드, 키 바인딩, 서버 서비스, custom geometry 렌더러를 전부 삭제.
- 메인 초기화, 네트워크, 클라이언트 이벤트, 언어 파일에서 제거 기능의 연결과 문자열을 삭제.
- 천본앵의 고빈도 다단히트, 7개 macro current, 4개 렌더 속도층 판정은 유지.
- 프로토콜을 Bankai-only `v9`로 갱신.
- CI가 제거된 범용 기술 클래스의 재유입을 실패 처리하도록 강화.

## 0.1.0-alpha.11 — 2026-08-14

- 클라이언트 렌더와 서버 공격 판정이 함께 사용하는 `BankaiFlowMath` 추가.
- 7개 macro current를 비대칭 칼날 강 이동으로 정렬.
- 서버 공격을 실제 해류의 sweep corridor 기준으로 변경.
- 참백도 툴팁의 입력 표기를 실제 `B` 키와 일치시킴.

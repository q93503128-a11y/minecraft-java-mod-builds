# Riftfrontier — Third-Party Assets Ledger

외부 자산을 실제 프로젝트에 넣기 전에 이 문서에 기록한다.

현재 등록된 bundled third-party asset: **없음**.

## 기록 형식

| Asset | Author | Source | License / usage note | Immutable source/revision | Modified | Used in |
|---|---|---|---|---|---|---|
| _none_ | - | - | - | - | - | - |

## 규칙

1. 공개 저장소에 넣는 자산은 재배포 권한을 확인한다.
2. 가능하면 원본 URL뿐 아니라 release/version/commit/hash 등 변경되지 않는 기준점을 남긴다.
3. 수정 여부와 실제 사용 위치를 기록한다.
4. 개인 로컬 테스트만 허용되는 자산은 저장소에 커밋하지 않고 별도 overlay로 취급한다.
5. 유료 자산 우회 다운로드, DRM 우회, 접근 제한 회피를 하지 않는다.
6. 공개 배포 전 전체 목록을 다시 검수한다.

# 《이능 직업 서바이벌》 RPG XP 구현 체크포인트 (2026-11-17)

## 구현 방향
- 기존 SavedData 직업별 레벨·SP·진행 XP에 P30 시험 요구식을 연결. Lv1 SP0, 레벨당 3SP, Lv301 900SP.
- 바닐라 레벨·인챈트/수선 XP는 건드리지 않는다. 새 재화·관리 메뉴를 만들지 않는다.
- XP 원천: 적 처치, 광석·원목 파괴, 첫 제작 아이템, 발전과제, 차원·생물군계 발견, 지배/인형/기생술사 고유 첫 성취.
- 지배 몹·인형·기생 숙주가 처치한 몹은 활성 소유 직업의 경험치로 인정한다. PvP·자기 소유 개체 처치 XP는 제외한다.
- 일반 사냥·채집·농장에는 시간당 XP 상한이 없다. 동일 위치 2분 이내 반복 채굴만 미지급, 최근 위치 기록은 플레이어당 2048개로 제한한다.
- 첫 제작·탐험·직업 성취는 플레이어 UUID 전체에 1회 귀속한다. 기존 schemaVersion4 저장은 비어 있는 최초 보상 기록으로 로드하고 schemaVersion5로 저장한다.

## 미검증 및 후속
- P30의 Lv300 요구량 713,125 XP는 계산 목표이며, 30시간 성장 성공이 아니다.
- 외부 모드 이벤트 취소·모드 몹 처치·실제 숙주 전투·재접속/멀티 성능을 확인해야 한다.
- 결계·계약·군체가 구현되면 전용 성공 보상을 같은 API에 연결한다.
- 탐험의 기본 보상은 생물군계·차원·발전과제이며, 별도의 구조물 감지기는 아직 없다.
- 기존 스킬트리 효과·직업 자동 스탯 수식을 임의로 대체하지 않는다. 이후 직업별 연결 상태를 별도 검사한다.
- 모델·UI·애니메이션은 기존 분담대로 Codex 담당.
- CI 검증 상태는 커밋 이후 결과로 따로 기록한다.

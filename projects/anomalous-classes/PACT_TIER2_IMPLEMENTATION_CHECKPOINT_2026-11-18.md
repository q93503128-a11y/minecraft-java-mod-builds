# 계약술사 제2위계 — 서버 권능·제단·전리품 구현 체크포인트 (2026-11-18)

- 정본: `classes/PACT_16_COMBAT_DESIGN_BASELINE_V3.md`, `classes/PACT_TIER_1_2_DESIGN.md`, `classes/PACT_ALTARS_EXPLORATION.md`, `PACT_ALTAR_WORLDGEN_FREQUENCY_V2.md`, `classes/PACT_SOFTCAP_MULTICONTRACT_POLICY_V1.md`.

- 16종 상대 ID/위계는 전부 보존하지만 **1위계 4종과 2위계 4종만** 서버에서 계약/기술 사용 가능. **3·4위계 8종은 제물·시련·권능·제단 구현 전 잠금 유지**. 데이터에서 신분만 존재하는 고위계 계약을 소모 없이 열지 않는다.

## 2위계 획득 및 생존 루프

- 자연 생성 기능성 제단 4종: **카르다 폭풍의 뿔탑 / 네르아 침몰한 해류당 / 셰로 눈 없는 관측대 / 하스텔 폐쇄된 계산당**. 중앙 핵 우클릭에서 계약술사만 제물·가호·금기·위약금이 적힌 서명 확인을 받을 수 있음. 다른 직업은 계약 불가 안내만 받고 **모든 직업이 일반 상자 열람 가능**.
- **실제 제단 근접·차원·코어 종류를 서버에서 확인**하고 계약서 최종 승인 순간 다시 검사. 임의 `/pact contact karda` 같은 명령은 이 제단 제약을 우회하지 못함. 제단 발견만으로 자동 아이템·HP 소비 없음. 다른 위치 이동/파괴/변조·이전 승인 60초 만료/타인 서명·전투 상태 변경은 소비 전 차단.
- 제단 4종의 자연 생성은 **오버월드 새 청크**에 한정. 40청크(640블록) 격자당 시도 1건을 공유하고, 지역 내 후보 중심은 이웃 영역 간 최소 15청크 간격이 나도록 계산. 바이옴/해저 지형/표면 기울기 부적합이면 생성 실패 가능. 모든 16종이 각각 40/15로 생성되는 오류 방지. **현재 4종만 이 배치 후보를 사용하므로 16종 합산 최종 분포는 미완성**.
- 물 관련 네르아만 해양 바닥, 다른 3종은 육지 후보. 각 구조물은 테마 블록·계약 핵·전 직업용 일회 생성 상자. 해양 제단에는 호흡용 마그마 수류 후보를 포함. **건축 디테일·시각적 크기·성역 입구 연출은 아직 상용 품질로 확정하지 않음**. 현재 기능성 9블록 안팎 원형 흔적/제단이며 원래 기획의 2위계 22~36블록 대형 외형은 Codex 시각/월드 작업에서 더 제작해야 한다.
- 새 월드젠 코드는 이미 생성된 청크에 구조물을 강제로 삽입하지 않음; 기존 플레이어 집/농장 덮어쓰는 접속 시 변조 없음. 핵은 일반 서바이벌로 파괴되지 않아 단일 제단이 영구 소실되지 않음.
- 현 서버 시험 제물(실제 검증 전 기본값): 카르다 구리24+자수정8; 네르아 프리즈머린16; 셰로 엔더 진주4; 하스텔 금4+에메랄드8. 제물·해약 비용과 스킬 쿨타임은 카탈로그 데이터에 분리. **다중 계약 1/2/4/8배, 최고 동일 가호 100%+그 외 50%** 그대로 유지. 매시간/접속 시 정기 유지비 없음.

## 전투 및 성장

- **카르다:** 폭풍 도약(서버 충돌·길찾기·착지 가능 여부 검사, 수평 최대8/상향 최대5)과 천둥 강타(기본16HP, 도약 직후 +25%); 조건부 유효 착지 충격·짧은 이동 가호·다음 무기타 전하 추가타. 지면에서 곧바로 강타 사용 가능.
- **네르아:** 해류 장악(12블록 당기기/6HP)과 심해 압력(9블록 내 목표 주변2.5블록·16HP, 수중 +20%). 수중 호흡 가호는 **첫 기술 사용 전부터** 적용. 물결 추가타/짧은 피해 방호/수중 유효 전투 회복, 육상에서 기본 기술 사용 가능.
- **셰로:** 관측의 응징(14블록 14HP) 직접 기술; 실제 적의 위협 표적 관측 경고·실제 투사체 근접 빗나감 뒤 3초 강화 +35%·교전 무기 공격 강화. 미지원 외부 공격의 미래 발생 시점을 아는 것처럼 위장하는 예고는 넣지 않음. 회피 조건 실패해도 주력 기술 사용 가능.
- **하스텔:** 선불 청구(4블록15HP, 6초간 받는 피해20% 감소) → 서버에 **채무 12 추가**(누적24 상한), 이후 실제 유효 적에게 피해를 준 사건만 35% 상환(초당 최대5) → 완납 시 한정 보너스 타격. 자기 최초 청구 타격은 새 채무를 상환하지 못함. 채무는 계정/재접속/사망 후 유지, 시간 경과로 부채 증가 없음. 미상환 시 정식 해약 불가.

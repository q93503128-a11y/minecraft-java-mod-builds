# 계약술사 16제단 — 부서진 포탈급 밀도와 물 관련 장소만 수중 생성 v2

> **2026-11-08 사용자 최신 방향:** 제단이 지나치게 드물지 않아야 하므로 오버월드에서 **부서진 네더 포탈(Ruined Portal) 정도의 발견 빈도**가 좋다. **물 관련 존재가 아니면 물속에 생성하지 않는다.** 기존 [16제단 건축·테마/위계/일반 전리품](./classes/PACT_ALTARS_EXPLORATION.md)과 [1위계의 제단 없이 입문](./classes/PACT_TIER_1_2_DESIGN.md)을 보존한다. 이 문서는 **첫 세계생성 시험을 위한 밀도·배치 디자인 기본안**이지 실제 월드젠 구현/시드 실측 아님.

## 1. 무엇을 '부서진 포탈만큼 많다'고 계산하나

- **16종 제단을 전부 합한 생성 시도 총량**을 바닐라 오버월드 부서진 포탈에 준하는 수준으로 시험한다. **16종 각각이 포탈만큼 생성되는 것이 절대 아니다**. 각 종류에 단독 spacing40 세트를 만들면 유적이 최대 16배 늘고 기존 던전·지형을 압도할 수 있다.
- 첫 후보 **같은 월드젠 지역 규모**: `spacing=40 chunks, separation=15 chunks`인 집합적인 16제단 후보군. **서로 다른 salt / 구조물 타입별 유효 바이옴·지형 선택**. 이는 Minecraft Wiki의 [월드젠 구조물 간격](https://minecraft.wiki/w/World_generation)과 **1.21.1 데이터팩을 추출했다는 [구조물 알고리즘 비교 자료](https://github.com/dannysmith/mc-bluemap-structures/blob/main/docs/structure-algorithm.md)**의 Ruined Portal OW **40/15**에 따른 **검수용 기본값**.
- 실제 Minecraft 구조물 배치에서 spacing은 **모든 후보가 반드시 생성된다는 보증이 아니다**. 산·숲·바다·기반 지형/외부 구조물과 충돌하거나 바이옴 부적격이면 탈락한다. 현존 월드젠에 맞는 **유효 후보를 먼저 찾고 위계·종류를 고르는 방식**을 검토하며, 거짓 보장이나 무한 재시도/기존 건축 파괴를 만들지 않는다.
- **입문 1위계는 제단 없이도 체결 가능**: 제단의 흔적/전 직업 보물 때문에 탐험하게 하는 것이지, 1위계의 주력 스킬을 초반 수백 청크 탐색에 봉쇄하는 것이 아니다.
- **첫 위계 분배 후보**: 1위계 **40%**, 2위계 **30%**, 3위계 **20%**, 4위계 **10%**를 **입지 적합 후보 중 선택**(현재 비율은 사용자 수치 확정이 아닌 첫 모드팩 시드 시험값). 고위계 제단이 '너무 희귀해 특정 서버에서 한 번도 안 나온다'는 결과이면 4위계 쪽 가중치를 조정. 제단이 자주 생성되어도 **최초 4위계 체결 비용·제물/서약/시련은 별도 고급 목표**이므로 저렴하게 계약되는 것과 혼동 금지.

## 2. 물속과 지면의 경계 — 현재 16종 지역 테마 보존

| 판정 | 포함/제외 | 적용 |
|---|---|---|
| **수중 제단 허용(테마 일치)** | **네르아 — 침몰한 해류당** | 바다 얕은 곳/연안·일부 해저. 숨 쉴 공기주머니/접근 가능한 핵/원본 월드 해류 탐험 보존. 바닷속 아닌 해안에도 일부 가능 |
| **그 외 15종은 수중 생성 금지** | 이사엘·벨칸·우르겐·리드나·카르다·셰로·하스텔·칠익의 재판관·메르자드·타론·아르켄·나하르·라키엘·오르마스·비아르 | 해당 테마의 땅/동굴/산/숲에 배치. **바다/호수/강 바닥·침수된 유적/공기방 강제 생성 안 함** |
| **강변·호숫가·습지 지면** | 물을 직접 주제로 삼지 않은 제단도 **마른 실제 지면 위에 설치**되고 핵·진입로/보물 등 실사용 공간이 침수되지 않으면 후보 | '습지 바이옴이라서 허용'이 아니라 실제 수면/발판·마른 통로·바닐라 워터로깅/강변 경사와 부딪히는지 검수 |
| **침수될 위험/지형 손상** | 대부분 **배치 포기 또는 같은 후보 영역 내 안전 위치로 짧게 조정** | 기존 구조물 위·절벽 공중부양·숲 통째 파괴·바다 막는 인공 댐/엄청난 흙 평탄화·강제 청크 로딩 금지 |

- 산/숲/평원 제단은 해당 모티브에 맞는 바이옴 후보를 **2~3개씩** 고려한다. 이형/거석의 거대한 구조물은 별도의 **지형 높이/기반지지·반경** 조건 검증. 단일 외부 모드 희귀 바이옴에 완전히 의존하지 않는다.
- 수중 관련 제단이 하나뿐이라는 기준은 **현재 16종 기획에서 해양을 명확히 테마로 삼는 유일한 네르아**를 확인한 결과. 향후 존재가 더 생기거나 배경 변경 사용자 결정이 있으면 목록을 다시 검수한다.

## 3. 흔하지만 재미없는 복붙 건축은 금지

- 총생성 빈도만 높이되 **위계·종류별 조형·크기**는 원래 16개 제단 디자인의 핵심을 그대로 보존한다. 1위계 12~20블록/2위계22~36/3위계36~56/4위계50~85블록 등은 **실제 월드젠/모델 제작 전 크기 후보**이며 4위계 85블록 지형 강제 절삭 명령으로 구현하지 않음.
- **모든 직업이 보상 상자를 열 수 있음**. 계약 핵의 체결·관계·심화는 계약술사만. **같은 제단 핵은 다른 플레이어도 자기 제물로 계약할 수 있음**, 일반 상자 내용은 기본 월드 공유 1회. 스킬트리 무료 초기화/직업 변경·제단 재방문으로 재료 무한 복제 금지.
- 새로 생성하는 청크에서만 정상 구조물을 만들어, **이미 존재하는 월드/플레이어 건축물에 뒤늦게 제단을 덮어쓰지 않는다.** 새 월드 시드/바이옴/적합 지형으로 획득 가능성 시험. 외부 YUNG·Cataclysm·Born in Chaos 구조물과의 실제 충돌/거리·보상 중복을 검사.
- 고위 4위계 제단을 발견해도 **계약할 재료/시련/금기**가 남으며, 그 위계가 강한 것은 고비용 정당한 보상. 반복 유지비 없음, 2·3계약 제물 2배·4배 등 보존.

## 4. 실제 검사할 지표 (아직 측정 전)

1. 동일 월드 시드의 여러 표본에서 **오버월드 4k×4k/8k×8k 영역** 각각의 바닐라 부서진 포탈 vs 16제단 **모든 종류 총 발견 횟수**/유효 배치 실패율/근처 랜드마크 충돌율 비교.
2. 첫 플레이 1h·6.5h·17h·30h 정상 탐험 중 실제 제단 조우수, 4위계까지 도달 가능성, 모든 직업 공용 상자 보상/반복 수급 위험 비교.
3. 네르아 제외 **수중 생성 0건**, 해저 네르아는 핵/공기·안전한 입출입 가능; 지형절삭/물 가림·마을/거점/자연 던전 침범 0건 지향.
4. 16종의 **실제 편중**(예: 산 제단이 계속 실패해 한 종을 전혀 못 보는 문제) 측정 후 **지형 적합 타입 재추첨**·가중치·대체 바이옴 범위 재조정. 밀도를 위해 미설계 바다 제단 15종을 억지로 수몰시키지 않음.
5. 멀티 2/4/8인에서 제단 핵 다중 사용자, 계약 별도 원자 제물 소모·서약, 상자/원본 월드 상태, 로딩 중복·서버 TPS.

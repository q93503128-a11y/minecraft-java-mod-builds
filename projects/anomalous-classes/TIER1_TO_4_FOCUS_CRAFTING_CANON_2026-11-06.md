# 《이능 직업 서바이벌》 1~4등급 전용 장비 6직업 제작법 정리 v1

> **2026-11-06 사용자 요청:** "1~4등급 정리 ㄱㄱ. 메아리 조각은 ㄴㄴ."
> **설계 정본 작업 기준**: 사용자 확정 조건인 **1~4등급 메아리 조각 요구 0개**를 충족하고, 원래 6직업 기획의 1~3등급 18개 후보는 보존, 이형(4등급)에서 메아리 조각을 요구하던 네 직업의 재료만 대체한다. 이번에 정리한 정확한 재료 개수는 승인 대기 없이 작업용 **레시피 설계 기준**으로 채택하며, 과거 사용자가 각 수량을 직접 하나씩 확정했다고 주장하지 않는다. **실제 Minecraft 레시피 JSON·JAR·플레이/멀티 검증 전**.

## 1. 변경 범위

- 직업별 장비 **1계열 / 규격(1)→변조(2)→변칙(3)→이형(4)→불가해(5)**. 각 단계 일반 **바닐라 제작대 3×3**에서 제작. 2~5등급은 직전 등급 장비 1개를 재료로 소비한 결과 장비 1개가 산출. 별도 직업 장비 제작대/업그레이드 화폐 없음.
- 사용자가 직접 제외한 **메아리 조각**은 **1~4등급 24개 레시피 모두 0개**. **네더의 별**도 이 24개 레시피에 필요 없다. 이미 사용자가 확정한 **불가해(5등급) 6직업 재료와 +40% 등의 성능은 바꾸지 않는다**. [불가해 재료 정본](./TIER5_FOCUS_6CLASS_CRAFTING_PROPOSAL_V1.md).
- 정신 지배자, 결계술사, 계약술사, 군체술사의 **이형 4개 레시피만 변경**했다. 그 외 20개 레시피의 재료/개수는 기존 파일과 동일. 4등급 재료의 교체는 희귀 소재 과밀 문제 해결 목적이며 다른 시스템/직업 성능을 약화하지 않는다.
- **구현용 제작 방식 권장: shapeless crafting(무형 조합)**. 같은 아이템이 2개 필요한 경우 재료 1개씩 **각 칸에 배치**한다. 바닐라 crafting_shapeless의 재료 목록은 1~9개이므로 아래 총 칸 수로 검산했다. 정확한 레시피 JSON/아이템 ID 네임스페이스/해금 조건은 구현 전 기술 검증. UI/레시피북·JEI가 실제로 표시될지 테스트 전.
- 일반 인벤토리 2×2에서 2등급 이상 일부 조합이 잘못 조합되지 않도록 제작대 3×3 사용을 기준으로 한다. 각 직업의 1등급도 재료가 5~9개이므로 3×3 작업대 필요.

## 3. 수량·진행·자원 겹침 감사

- **재료 칸 수 검사:** 총 24개 모두 3×3의 9칸 이하. 1등급·2등급·3등급·4등급에서 각각 6개 레시피 확인. 가장 큰 정신 지배자 1~4등급 중 9칸짜리 레시피 포함, 인형술사 변칙도 9칸 사용. **9칸보다 많은 수량을 하나의 재료 칸에 쌓아 쓰는 비바닐라 제작 요구 없음**.
- **메아리 조각 0 / 네더의 별 0 (1~4등급 24개 전부)**. 이미 확정된 5등급 6종에도 메아리 조각/네더의 별 **필수 없음**. 따라서 1~5등급 직업 장비의 **기본 제작 경로만 보면 이 두 자원 요구 0**. 계약술사의 **4위계 최초 계약 제물/고급 현현 후보**는 직업 장비와 별개이며 변경하지 않는다.
- **성장 난이도 계단:** 규격은 구리·실·자수정/기초 생물 소재 → 변조는 철·레드스톤 → 변칙은 금·흑요석·자수정/네더 접근 → 이형은 다이아몬드와 각 직업 고급 소재 → 불가해는 기존 확정된 직업별 종결 소재. 1~3등급은 기존 숫자를 보존하기 위해 일률적인 비용 인상/강제 던전·보스/차원 해금 조건을 추가하지 않았다.
- **멀티 2/4/8인:** 8명이 모든 6직업 장비를 1~5등급까지 각자 제작한다는 극단적 사례도 이 두 소재의 **직업 장비 제작 요구량**은 0. 단, 다이아몬드·자수정·프리즈머린·가스트 눈물·불사의 토템 등 다른 재료의 실제 경제 부담은 게임 플레이로 검증 전.
- **불가해 레시피의 경제적 방향 유지:** 5등급 정신 조율기에는 우는 흑요석/자수정 블록, 인형 조종틀에는 다이아몬드 블록/기계, 공생 핵에는 황금 사과/가스트 눈물, 결계에는 엔드 수정/프리즈머린, 계약에는 불사의 토템 또는 바다의 심장, 군체에는 벌집/프리즈머린. 기존 확정 수량 변경 없음.
- **특수 주의:** *책과 깃펜* 2개는 한 칸에 여러 개 쌓는 방식이 아니라 **2칸에 1개씩 배치**, 원본 내부 데이터(사용자가 작성한 내용)가 우발적으로 장비 결과로 복사되지 않도록 처리. 실제 Minecraft 1.21.1 recipe/ingredient 매칭과 아이템 사용성은 구현 시 확인. *꿀 블록*은 벌꿀 병으로 제작 가능하므로 고대 도시 파밍의 대체 강제 구조물 요구가 되지 않음.
- **게임성 미검증:** 마을 주민 거래·농장·상자/외부 모드 레시피 변화로 자원 수급이 불균형할 수 있다. 특히 정신 지배자 변칙의 에메랄드 4와 엔더 진주 2, 이형의 엔더의 눈 2는 강제 네더 여정이 얼마나 부담인지 실제 비교. 계약술사 이형의 책과 깃펜이 너무 쉬운 경우에는 단순히 메아리 조각을 되돌리는 대신 위험/게임 플레이 목표를 다른 방식으로 추가 검토한다.
- **확인해야 할 것:** 레시피 충돌/미발견 재료 안내, 재료 소모 단일 트랜잭션, 직업 변경·아이템 드롭/회수, 5등급 제작까지 이어지는 이전 등급 보유, 기존 영구 강화 데이터를 가진 장비의 승급 시 처리(그런 데이터가 있다면). 출력 아이템 중복/기본 장비 보너스 중첩 방지.
- **원본/최신 경계:** 이전 파일의 1~4등급 **'후보' 표현은 이 파일의 2026-11-06 설계 정리로 업데이트**하되, 전투 밸런스·획득 속도 테스트 이전의 작업 수치라는 점을 유지. 새로운 사용자가 1~3등급 수치까지 일일이 재승인했다고 주장하지 않는다.

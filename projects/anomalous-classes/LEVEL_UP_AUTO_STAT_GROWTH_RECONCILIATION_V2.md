## 2. 1P + 빠른 레벨업이 초래하는 '같은 플레이 시간에 과도한 자동 스탯' 문제

한 플레이어가 똑같은 플레이 시간 동안 **느린 레벨업 시나리오에서 3P씩 99레벨업(Lv100 진입)** 하면 누적 SP는 `99×3=297P`.
그 시간이 비슷한 **빠른 레벨업 시나리오에서 1P씩 297레벨업(Lv298 진입)** 하도록 XP 보상을 조정하면 누적 SP는 `297×1=297P`.

**같은 297SP를 얻는다고 해서 동일 전투력은 아니다.** 기존 자동 스탯 공식을 새 레벨 `L=298`에 그대로 적용하면:
- 정신 지배자 최대 HP `20+0.12×297=55.64` (기존 Lv100 `31.88`),
- 인형술사 본체 HP `20+0.06×297=37.82` (기존 Lv100 `25.94`),
- 결계술사 본체 HP `20+0.045×297=33.365` (기존 Lv100 `24.455`).
- 인형 기본 전개 수·정신 지배 기본 슬롯/군체 비행 등의 **레벨 기반 비연속 해금 시점도 3배 가까이 앞당겨짐**. 패시브 297P와 레벨 보너스 둘 다 확보하므로 소환물·결계/보스전 스케일이 흔들림.

**사용자 승인 없이 3P를 과거 정본이라고 되살리는 게 아니라**, P=3 배율을 하나의 **수학적 비교 예시**로만 사용한다.

## 3. 권장 해결 구조(후보): 빠른 레벨링이더라도 '실제 획득 SP/시간'과 '자동 파워/시간'을 따로 조율

**A. 먼저 측정 가능한 목표를 정한다:**
- 정상 서바이벌(처음 30~60분), 동굴/기본 외부 몹, 중반 던전, 실제 보스/멀티 각각의 **시간당 레벨업 횟수**, **시간당 스킬 투자**, **시간당 실제 자동 전투력 성장**을 별도로 측정.
- **첫 5~10랭크 돌파에 걸리는 시간**과 첫날 기본 능력+도구/방패/식량 확보 편의가 더 중요. 목표 실시간·몬스터당 RPG XP는 실제 선정된 보스/스폰 환경 전까지 제안치에 머무름.
- 1P이므로 빠른 레벨업이 필요하다는 사용자 조건은 **검증 게이트**, 단 극단적인 Lv1000 도달 속도를 빠르게 하라는 뜻은 아니다.

**B. 스탯 자동 성장 속도 보정(가상 비교):**
- 일반식 `OldStat(L)=base+f(L-1)`의 **새 1P 고속 레벨 후보**를 `NewStat(L)=base+f((L-1)/k)`처럼 평가한다. 여기서 `k`는 **같은 플레이시간에 몇 배 빨리 레벨업하는지 비교해 얻는 테스트 계수(예: 3)**이며, **별도 육성 레벨·두 번째 XP·HUD 게이지가 아님**.
- 단 **직업 고유의 기초값, 실제 BD/숙주, 계약 제물·관계, 이미 만든 인형 부품·매개체, 현재 군체 소실 N**에 이 공통 수식을 억지로 적용하지 않는다. **레벨 때문에 자동 추가되는 성장분**을 재보정할 때만 예시로 사용한다.
- 고유 성장이 너무 일찍 약해지는 경우 `k`를 스탯별/클래스별 개별 튜닝하거나 (1) 초반 유효 기본값 강화, (2) 5~10랭크 돌파 체감, (3) 장비 획득/특정 생물군 특성의 선택 가치 조정 순으로 해결. **새 스탯/재화/지속 관리 클릭 추가 금지**.

**k=3을 가정한 본체 HP 예시(기존 기획 수식 자체는 수정하지 않음):**

| 직업 | 기존 가상식 Lv100 본체HP | 기존 가상식 그대로 빠른 Lv298 HP | **1P 빠른 레벨 가정** `L=298`, 자동 레벨 상승분만 `÷3` | 비교 결과 |
|---|---:|---:|---:|---|
| 정신 지배자 | 31.88 | 55.64 | **31.88** | 원래 느린 성장에서 동일 SP/시간을 얻던 시점과 기본 HP 비슷 |
| 인형술사 | 25.94 | 37.82 | **25.94** | 인형 모델·장비 스탯 중복 보정 방지 |
| 결계술사 | 24.455 | 33.365 | **24.455** | 결계 방벽도 `√L` 보정의 입력을 함께 재보정 검토 |

**중요:** `k=3`은 **기존 3P/level을 확정 전제로 만든 새로운 최종 공식이 아니다.** 실제 게임에서 1P 방식의 레벨/시간이 얼마나 빠를지·우리 의도한 전투 파워 곡선/몬스터 위협이 어느 수준인지 확인할 때 쓰는 **파워 동등성 비교 도구**다. 기존 HP·군체 수·레벨 구간을 한꺼번에 무조건 `÷3` 해버리면 **동영상으로 보는 레벨업은 빠른데 스탯이 너무 안 오르는 '무의미한 레벨업'**이 될 수 있으므로 기초성능/아이템+패시브 돌파를 함께 확인한다.

**C. 비연속 해금·개체 수 보정도 별도 취급:**
- 정신 지배자 `BaseSlots`, 인형 `BaseActive`, 군체 `Nmax`, 비행 가능 시기, 결계 `다중 전개` 패시브는 `레벨 자동 해금`과 `패시브 랭크 해금` 여부를 **각각 분리**. 사용자 본래 선택/장비 등급에서 생기는 소환체 +1을 임의 삭제하거나 줄이지 않는다.
- 같은 시간에 레벨을 빨리 올리면 레벨 게이트도 더 빨리 넘는다. `원래 Lv25 후보였다 → 새 Lv73로 확정` 같은 즉흥 전수 변경 금지. **실제 획득 시간/비행 손맛·클래스 공정성과 서버 FPS/TPS를 비교해 필요할 때 개별 결정**.
- 비행/지배/숙주/결계의 **기본 재미에 필수적인 능력**을 높은 레벨로 미루지 않는다. 기생 BD와 계약 위계/제단 같은 **사용자 고유 해금 조건**을 XP/레벨로 강제 대체하지 않는다.

**D. 초반 체감과 액티브:**
- 본체 HP `+0.04`씩 오르는 식은 수치상 성장하나 한 레벨마다 **반 하트도 보이지 않음**. 그렇다고 기계적으로 스탯 보상을 표시하거나 XP popup을 과장하지 않는다. 실제 HP는 내부 소수로 누적, **Lv5/10 등 의미 있는 랭크 돌파와 클래스 효과**가 체감되도록 조절.
- 직업 기본 능력은 여전히 Lv1/랭크0부터 사용 가능. **스킬 포인트를 모아야 처음 군체가 생기거나 결계를 펼치거나 숙주에 기생하는 식의 입문 제한을 추가하지 않음**.

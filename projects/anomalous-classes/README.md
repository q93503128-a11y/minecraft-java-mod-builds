# 이능 직업 서바이벌

Minecraft Java 1.21.1 / NeoForge 21.1.244 모드. 현재 구현 범위는 6직업 선택·변경 화면, 서버 권위 선택 요청, 직업별 저장 프로필이다.

## 조작

- 처음 월드에 들어오면 직업을 고른다. 최초 선택 중에는 화면을 닫을 수 없다.
- `M` 키로 프로필을 열고, `직업 관리` 화면의 `직업 변경` 버튼으로 직업 선택 화면을 연다. `M` 키는 설정에서 변경할 수 있다. `/class` 명령도 기존대로 사용할 수 있다.
- `M` 키로 현재 직업 프로필을 연다. 키는 Minecraft 설정에서 다시 지정할 수 있다.
- 좌우 방향키, 화면 화살표, 직업 아이콘, 마우스 휠로 둘러본다.
- 변경은 최근 플레이어가 피해를 주거나 받은 뒤 8초 동안 잠긴다. 이 시간은 D11에서 테스트 후보로 둔 기본값이다.
- 직업마다 레벨·XP·SP·영구 데이터 칸을 따로 저장한다. 바닐라 경험치와 인벤토리는 건드리지 않는다.

## 프로필·스킬 트리

- 프로필은 저장된 직업 레벨·경험치·SP와 서버 플레이어의 현재 바닐라 능력치(최대 체력, 공격력, 이동 속도, 방어력)를 보여준다.
- 프로필에서 `스킬 트리`와 `직업 관리`로 이동한다. 직업 관리는 공통 프레임만 있으며, 상세 직업 기능은 아직 없다.
- 스킬 랭크와 SP 투자는 서버가 처리하고 직업별로 저장한다. 한 랭크, 다음 돌파, 보유 SP 내 최대 투자와 비전투 중 무료 초기화를 지원한다.
- 스킬의 설명·랭크·비용은 표시되지만 전투 효과는 아직 연결되지 않았다. RPG 경험치 획득 경로와 진행 곡선도 아직 없으므로 프로필은 저장 경험치만 표시한다.
- 레벨·SP 흐름을 검증할 때는 권한 레벨 2 이상으로 `/class test grant-levels <amount>`를 사용한다. 일반 플레이어에게 임의 XP 보상은 추가하지 않았다.

## 현재 구현 경계

6직업의 전투 능력과 성장 이벤트는 아직 구현되지 않았다. 따라서 선택 화면은 가짜 스킬·피해·보상을 표시하지 않는다. 새 월드와 기존 월드 모두 오버월드의 `SavedData`에 UUID별 직업 상태를 저장하며, 이 모드는 바닐라 월드 데이터를 별도로 수정하지 않는다.

## 개발

Java 21과 Gradle Wrapper를 사용한다.

```powershell
./gradlew.bat clean build
./gradlew.bat runClient
```

산출물은 `build/libs/anomalous-classes-0.1.0-alpha.1.jar`에 생성된다.

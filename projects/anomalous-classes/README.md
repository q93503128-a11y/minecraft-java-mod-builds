# 이능 직업 서바이벌

Minecraft Java 1.21.1 / NeoForge 21.1.244 모드. 6직업 선택·변경, M 키 프로필, 서버 저장 성장과 대형 스킬트리 UI를 포함한다.

## 조작

- 처음 월드에 들어오면 직업을 고른다. 최초 선택 중에는 화면을 닫을 수 없다.
- `M` 키로 프로필을, `J` 키로 스킬트리를, `U` 키로 직업 관리를 연다. 각 키는 Minecraft 설정에서 변경할 수 있다. 직업 관리 화면은 프로필·스킬트리·직업 변경 및 매개체 화면으로 연결된다.
- `/class` 명령도 기존대로 사용할 수 있다.
- 좌우 방향키, 화면 화살표, 직업 아이콘, 마우스 휠로 둘러본다.
- 변경은 최근 플레이어가 피해를 주거나 받은 뒤 8초 동안 잠긴다. 이 시간은 D11에서 테스트 후보로 둔 기본값이다.
- 직업마다 레벨·XP·SP·영구 데이터 칸을 따로 저장한다. 바닐라 경험치와 인벤토리는 건드리지 않는다.

## 프로필·스킬 트리

- 프로필은 저장된 직업 레벨·경험치·SP와 서버 플레이어의 현재 바닐라 능력치(최대 체력, 공격력, 이동 속도, 방어력)를 보여준다.
- 프로필에서 `스킬 트리`와 `직업 관리`로 이동한다. 직업 관리의 `매개체` 화면에는 현재 직업의 실제 3×3 제작법을 표시하고, 보유한 매개체를 서버 저장 전용 슬롯에 장착·해제할 수 있다.
- 스킬 트리는 직업별 대형 분기 지도다. 드래그로 이동하고 휠로 확대·축소하며, 노드에 마우스를 올리면 이름·효과·비용·경로 조건을 확인한다.
- 6직업 지도에는 581개 구매 노드가 있으며 각 트리의 전체 가격은 900SP다. 주요 노드는 기존 패시브의 랭크 구간을 기록하고, 소형 노드는 최대 체력·방어력·이동 속도·공격력을 실제 플레이어 속성에 반영한다.
- 노드 구매·경로 조건·SP 차감·무료 전체 초기화는 서버가 결정한다. 초기화는 비전투 중에만 가능하며, 직업별 투자 상태를 따로 저장한다.
- 기존 랭크 데이터는 완성된 구간을 새 노드로 옮기고, 미완성 구간에 쓴 SP를 반환한다. 이관은 6직업 상태를 검증한 다음 한 번만 저장하며, 경험치·레벨·영구 데이터는 유지한다.
- 기존 주요 패시브의 전투 판정은 현재 코드에 연결되어 있지 않다. 이번 변경은 구간 해금 기록을 보존하지만 그 전투 효과가 이미 적용된 것처럼 표시하지 않는다. RPG 경험치 획득 경로와 진행 곡선도 확정되지 않아 프로필에는 저장 경험치만 표시한다.
- RPG XP는 바닐라 경험치와 분리된다. 적 처치(소유한 지배체·인형·숙주 포함), 광석/원목 채집, 최초 제작품, 첫 생물군계·차원 발견, 발전 과제, 직업별 새로운 소유 성취로 획득한다. 동일 위치 단기 반복 채굴과 최초 보상 재수령만 제한한다.
- P30 XP 곡선은 약 30시간 Lv300 목표의 **시험값**이며, 활동별 지급량은 플레이타임을 실제 측정해 조정해야 한다. 레벨업마다 3SP 지급, Lv301에서 누적 900SP. 일반 레벨업은 서버에서 저장하며, `/class test grant-levels <amount>`는 관리자 테스트 전용으로 유지한다.

## 현재 구현 경계

직업별 전투 능력과 성장 이벤트, 매개체의 직업별 전투 효과, 여섯 직업의 개별 관리 기능은 아직 연결되지 않았다. 매개체 슬롯은 저장·장착 기능이며 아직 전투 보너스를 적용하지 않는다. 화면은 구현되지 않은 효과를 실제 적용 중인 것처럼 표시하지 않는다. 새 월드와 기존 월드 모두 오버월드의 `SavedData`에 UUID별 직업 상태를 저장하며, 이 모드는 바닐라 월드 데이터를 별도로 수정하지 않는다.

## 직업 매개체

- 직업 관리 화면에서 현재 직업의 5등급 매개체 제작법을 3×3으로 확인할 수 있다. 6직업 30개 제작법은 화면과 서버가 같은 정본 데이터를 사용한다.
- 현재 직업 매개체를 보유 중이면 전용 슬롯에 서버 권위로 장착·해제할 수 있으며, 슬롯은 재접속 후에도 저장된다. 슬롯은 아직 직업별 전투 효과를 적용하지 않는다.
- 1등급 매개체는 각 직업 제작법으로 만들며, 2~5등급은 중앙 칸에 직전 등급 매개체를 넣어 승급한다. 계약술사 불가해 등급은 불사의 토템 또는 바다의 심장을 받는다.

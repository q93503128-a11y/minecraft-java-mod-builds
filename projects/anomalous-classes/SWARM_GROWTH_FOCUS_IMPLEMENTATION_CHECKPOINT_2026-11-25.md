## 기존 성장 체계 유지

- 현재 그래프 스킬트리 및 공통 직업별 900SP 구조를 변경하지 않음. 각 major 단계의 기존 old_rank_to(10·15·20·30)를 읽어 9개 군체 고유 효과를 적용. MINOR는 현재 프로젝트의 공용 스탯만 부여.
- 날카로운 턱: 일반 군체 공격 계수에 1랭크당 +0.6%, 최대 +18%.
- 급습 전술: 급습 공격 계수에 +0.6%/랭크, 20랭크부터 급습 접근 속도 추가 보정(시험).
- 희생 본능: 소모 공격 계수에 +0.6%/랭크, 30랭크부터 사용 직후 짧은 연계 공격 간격 개선. 소모된 개체는 복구하지 않음.
- 단단한 갑피: 모든 역할 군체 유효 내구 +0.6%/랭크.
- 탄도 감각: 실제 접근 중인 적 투사체를 예측하고 물리 엄호 노드를 재배치; 이동 +0.8%/랭크, 15랭크부터 접근 감지 반경 확장. 임의 자동 탄환 삭제/범위 밖 무적 없음.
- 호위 진형: 엄호대에만 내구 +0.5%/랭크. 10랭크부터 역할 재배치 처리량 +1.
- 자연 분열: 자연 재증식 틱 간격을 40 / (1 + 0.012 × 랭크)에 맞춰 단축. 직접 +N 버튼 추가 없음.
- 재결집: 전술 전환 처리량과 실제 재결집 노드 이동 +0.7%/랭크. 먼 곳 즉시 이동 없음.
- 무리 추적: 공격대 경로 탐색 이동 속도 +0.8%/랭크. 비행 속도에도 작은 +0.3%/랭크 연계. 기본 48블록 표적 사거리 확대 없음.

## 군체 핵과 손실 처리

- 기존 실제 직업 매개체 슬롯의 장착 상태를 서버에서 참조. 인벤토리 보유·다른 직업 매개체·다중 보유로는 군체 강화 없음.
- 공격과 내구에 규격 5%, 변조 10%, 변칙 15%, 이형 20%, 불가해 **40%**. 개체 공격 기반 일반 공격, 급습 및 소모 피해 각각에 보정 단 1회 적용. 플레이어 무기 피해·본체 HP/방어·비행 지속 게이지 추가 없음.
- 방어계수는 (1 + 공통 갑피 + 호위 진형(엄호군만) + 장비 보너스)로 합산해 실제 공격을 받은 군체 역할에 적용. 비행대의 갑피/장비 강화는 적용하되 호위 전용 방어는 받지 않음.
- `SwarmSavedData.State.applyDamage`: 개체당 유효 손실 임계까지 실제 피해가 누적되면 마릿수를 감소. 약한 피격으로 무조건 1개체 사망하지 않음. 4개 역할의 `pending_*` 값을 NBT에 별도 저장하며 구 저장 데이터에서는 0으로 시작. 해당 역할의 마지막 개체가 이동하면 남은 부상도 함께 전달. 다시 장착하거나 전술을 바꿔도 기존 누적 피해를 통째로 무료 제거하지 않음.
- 군체 합산 수량 `alive = attack + guard + lift + regroup`, 동일 사건의 단일 비용 계산, 급습·희생 쿨타임·전투 대상 서버 검증은 기존 구현 유지.

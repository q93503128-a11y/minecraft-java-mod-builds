### 구현/정산
- \`pact_deepening_tier4_v1.json\`에서 4인 각 1·2차 성취 이벤트, 횟수, 일반/고급 아이템 제물 및 \`elite_min_health\` 수치를 선언. 최종 데이터는 Java \`PactDeepeningService\` 로더를 통해 읽으며 의식마다 소모하는 초희귀 입문 아이템은 배제.
- 1·2·3위계 12종에서 4위계 추가로 **16종 심화**. Stage마다 서로 다른 \`event\`를 허용하여 1차 콤보와 2차 강적/생태 시련이 같은 증명 클릭이 되지 않도록 한다. 기존 하위 위계는 원래 단일 event를 두 stage에 상속해 동작 보존. NBT \`Bond.deepening/progress\`, 확인 대기/재료 결제/재전송 거부/승급 후 이전 진행도 초기화 경로는 공통 서버 구현 재사용.
- \`PactTierFourCombatService\`의 실제 공격·피격·피해·사망 이벤트와 연결. 강적 2차는 **플레이어의 실제 처치 출처** + 죽기 전 해당 계약 전투기의 적법한 유효타로 남긴 12초 표식 + 해당 적의 기준 최대HP가 모두 필요. 그냥 강적을 한 번 때리는 것으로 승급되지 않으며, 자가 소환체/지배/기생체, 아군, 기존 최초 계약 수호자 시련 몹은 제외. 표식은 TTL/최대 64개로 관리하며 세션 종료 때 사라지고 영구 시련 진행도만 저장. 치명타로 즉시 사망한 적은 **타격 전 유효성 검사**를 통과했으면 처치 이벤트에서 표식을 확인할 수 있도록 처리.
- 비아르의 실제 회복 성공은 플레이어가 기존 첫 뿌리로 적대 몹을 공격했을 때의 표식, 그 뒤 유효 타격과 유효 자기 치유가 모두 있을 때만 인정. 2차 바이옴 증명은 현재 서버 생물군계 registry ID를 기록; 클라이언트·명령어 문자열에서 받지 않는다. 같은 바이옴 다시 가서 체력 0.5만 채워서는 증명 증가 없음. 구형 월드의 비아르 저장에 신규 NBT 필드가 없어도 안전 로딩하며, 계약 해약·재서명에서 바이옴 증거 초기화.
- 4위계 가호 증가분에만 1.00/1.08/1.20배. 각 계약 고유 액티브가 \`PactCombatService.power\`를 통해 단독으로 배율을 한 번 적용. 기본 HP/기초 공격력 무단 중첩 금지. 다른 위계 1/1.12/1.25, 1/1.10/1.22, 1/1.08/1.18 유지. 특정 4위계 현현/확률 도입은 **없음**.

- 술식탄은 서버 소유 Snowball 충돌 시 마법 피해를 주는 임시 기하학/투사체 구현(전용 모델은 Codex 담당). 순간 방벽은 전방 3초/내구20, 증폭은 시전 시 활성 자기 결계 전부 5초간 +35%, 신규 결계에 소급되지 않음.
- R 첫 입력 미리보기 상태 시작·둘째 입력 설치, Z 종류·X 크기, G 마지막 설치 설정 즉시 설치. 임시 키 C=술식탄, V=순간 방벽, B=증폭, H=조준 결계 해제. R/G 재시전은 서버 쿨타임과 동시 수 검사 동일하게 거침.
- 소유자 UUID·서버 유효 범위·시전 당시 스탯·유형별 재사용 대기·동작은 서버 권위. 재사용 대기/최근 성공 설정은 서버 SavedData, 활성 결계는 전직/사망/차원 이동/서버 종료 시 모두 정리.
- 결계 설치만 반복해서는 RPG XP를 얻지 못한다. 압축 결계 첫 실제 적중, 방어 결계 첫 실제 피해 방호, 격리 결계 첫 실제 경계 차단, 술식탄 첫 유효 적중, 순간 방벽 첫 피해 방호에 대해서만 플레이어 전체 1회 성취 XP를 지급한다.

## 2026-11-06 **D09 최신 사용자 조작 정정** — R 표적/범위·결계 Z/X/G

**직업별 키는 완전 공통이 아니다.** 인형/군체 R은 무료 표적 지정, 인형 실 견인은 별도 액티브. 결계는 **R 현재 유형·크기 범위 전개, Z 종류 변경, X 크기 변경, G 마지막 성공한 결계 설정 즉시 재시전**을 사용자 새 방향으로 채택했다. G 홀드/Shift+G·강제 N 키·공통 6액티브 강제는 이전 잘못된 배치이므로 폐기. 결계 R/G는 모두 기존 쿨다운·설치 한도·서버 판정 준수. 세부 보조 기술 키/관리 키·순환 순서·크기 숫자는 검증 전 후보. [최신 D09 v2](./D09_DIRECT_SKILL_KEYBIND_AND_CLASS_COMMANDS_V1.md) / [결정 장부](./PLANNING_DECISION_REGISTER_V1.md). **기존 6직업 스킬/장비/경제·중력/공명 보류·D10 대기 상태 보존**.

## 게임 목표

기존 마인크래프트 서바이벌(채굴, 건축, 탐험, 전투, 제작)에 독특한 **이능 직업 8종**의 성장과 스킬 사용을 결합한다. 전사/궁수처럼 무기만 달라지는 직업 대신, 직업마다 실제 플레이가 달라지는 능력을 중심에 둔다.

진행은 익숙한 RPG 방식으로 유지한다: 공통 경험치 → 레벨업 → 스킬 포인트 → 직업별 스킬 해금·강화. 레벨업 때 자동 증가하는 능력치의 구성 및 증가량은 직업별로 다르게 설계한다. 별도 조작과 관리 메뉴는 최소화한다.

## 선택된 직업 (8종)

1. **정신 지배자** — 정신력을 사용해 적대 몬스터·중립 생물·주민·철 골렘·동물 및 외부 모드 보스 등 다양한 생명체의 지배를 시도한다. 강할수록 지배 난도가 매우 높고, 유지 중에도 정신력이 지속 소모된다. 플레이어 지배 가능 여부는 미결정.
2. **인형술사** — 재료로 마리오네트를 제작·강화·분해하고 **조종틀과 인형을 잇는 실**로 자동 운용한다. 후반에는 3기 이상 다수 운용 가능. 무쿨타임 표적 지정 명령, 같은 팀 플레이어·소환물과 인형 간 양방향 오폭 방지가 핵심 규칙.
3. **기생술사** — **인간형으로 돌아다닐 수 있지만 숙주가 없으면 전투력이 매우 약하다.** 돼지 같은 생물에 실제로 기생해 숙주 몸으로 생활·직접 전투하면서 **생체 데이터를 성장형 능력치로 영구 축적**한다. 더 강한 생물에게는 **최소 생체 데이터 요구치를 충족해야만 기생 시도 가능**하며, 요구치 충족 후에도 저항/성공 여부를 판정한다. 다른 종으로 옮겨도 데이터·종별 숙련 보존. 숙주는 동시에 1기 직접 조종. **숙주가 죽으면 허약한 인간형으로 튀어나오며 기본적으로 일정 시간 재기생 불가, 패시브 투자로 즉시 재기생 시도 가능한 횟수 확대**. [현행 기생술사 v7](./classes/PARASITE_MORPHER.md), [생체 데이터 성장·기생 요구치](./classes/PARASITE_BIODATA_GROWTH.md), [숙주 사망·긴급 재기생](./classes/PARASITE_HOST_DEATH_AND_TRANSFER.md). 이전 3기관 장착형은 [옛 초안](./classes/PARASITE_MORPHER_V1_ARCHIVE.md)으로만 보존.
4. **결계술사** — **범위를 지정해 종류별 결계를 독립 설치하는 공간 마법사**. 핵심 결계는 **방어 / 내부 압축 공격 / 격리**이며, **술식탄·순간 방벽·결계 증폭 같은 보조 주문**도 사용하는 8직업 중 가장 일반 마법사에 가까운 직업. [v4 상향 통합 기획](./classes/BARRIER_CASTER.md)은 사용자 제시 방향을 반영했고, 동시 설치 수·범위·시간·시전 비용·기술명은 검증 전 제안.
5. **계약술사** — **초월적 존재와 계약해 그 존재의 권능을 사용하는 다중 계약·제물 직업**. 천사·악마·고대신·거인족·크툴루 같은 이형 존재는 예시. **상대별로 제물 종류·금기·능력**, 약한 계약자에서 상위 존재로 진출, **이중계약·파기·조항 위반을 추가 제물로 대납하는 위험한 선택**을 사용자 새 방향으로 채택. 상대별 능력은 직업 안의 전문화처럼 구분. [v2 방향 정본](./classes/PACT_CASTER.md). 구체 제물 재료·비용/존재 목록·동시 계약 수·기술·수치 미확정.
6. **군체술사** — 작은 생물 군단을 빠르게 증식하고 전투 중 소모한다. 소모가 지나치게 빨라 군단 형성이 불가능해서도, 초반부터 무제한 폭증해서도 안 된다. 개별 지휘/관리 강제하지 않는다. [1차 상세 기획 후보 — 군집 증식·소모·재보충·서버 군집형 성능 설계](./classes/SWARM_CASTER.md). **새로운 스킬/매개체/수량 수치는 승인 전 제안**이다.
7. **중력술사** — 중력장·끌어당기기·부양·낙하/압축 공격.
8. **공명술사** — 진동·충격파·공명 표식·연쇄 공명 공격.

시간 간섭자, 그림자술사, 거울술사, 공간술사 등 기존에 제안되었으나 채택되지 않은 직업은 확정 목록에 넣지 않는다.

## 확정된 정신 지배 방향

- 보스뿐 아니라 **비적대적 생명체(주민, 철 골렘, 동물 등)**도 지배 가능 대상으로 설정한다. 대상의 우호도·몬스터 종류·보스 등급만으로 면역을 두지 않는다. 플레이어 지배는 아직 확정되지 않았다. 외부 모드별 AI/전투 기믹·주민 거래 및 마을 역할 호환은 별도 검증한다.
- 강함, 저항, 체력 등의 요소로 지배 난도를 결정한다. 난도는 매우 높아질 수 있으나 성공 가능성을 무조건 0으로 만들지 않는다.
- 지배 시도뿐 아니라 **지배 상태 유지에도 정신력**을 소모한다.
- **레벨이 오를수록 동시 지배 가능한 최대 마릿수가 천천히 증가**하도록 설계한다. 여러 개체를 동시에 지배할 때 추가 유지 정신력 부담도 발생하며, 패시브로 효율 개선 가능. 고정 레벨 상한은 없다. 수치 공식은 `classes/SKILL_TREE.md`에 제안 단계로 정리했다.
- 성장 후 약한 잡몹의 유지 소모는 극히 작거나 0이 될 수 있다. 강력한 보스 유지 비용은 후반에도 체감되도록 설계한다.
- 소유자는 **지배한 몬스터를 바라보고**, 자신 및 다른 플레이어가 해당 몬스터를 공격할 수 있는지 **개체별 ON/OFF** 토글할 수 있다. 신규 지배 대상에 적용할 기본값도 플레이어 설정에서 ON 또는 OFF로 선택한다.
- 공격 허용 ON은 지배한 몬스터를 공격해 CC처럼 활용할 수 있게 한다. 보호 OFF는 플레이어발 피해를 막는 규칙이지 모든 적/환경 피해로부터 무적이 되는 기능이 아니다.
- PvP, 투사체/광역 스킬 피해, 소유권, 멀티플레이, 지배 해제·재접속·보상 악용 등은 서버 최종 권한으로 세부화한다.
- 복잡한 몬스터별 명령·편성·지휘 UI는 현 단계에서 도입하지 않는다.
- **지배한 말**은 지배에 성공한 뒤 일반적인 길들이기 거부 없이 안장 없이 탑승·조종할 수 있도록 한다. 일반적인 정신 지배 성공 난도까지 무조건 100%가 되는 것은 아니다. 해제 시 원래 길들이기/장비 상태를 되돌리는 방향이다.
- 지배 대상의 **동행/대기/해제**는 복잡한 명령 없이 구현하는 것이 유력한 설계안이며, **지배 도감(종류별 수집 기록)**은 선택적으로 추가 검토한다. 실제 개체의 무한 보관/복제 시스템은 확정하지 않았다.
- **정신 과부하**는 지배한 대상의 정신을 과부하시켜 잠시 전투력을 강화하는 능력이다. 적에게 피해를 주는 정신 공격으로 변경하지 않는다.
- **강제 장악**은 별도 액티브 스킬에서 제외한다.
- 주변 생명체의 움직임과 행동을 잠시 정지시키는 **광역 정신 CC**를 추가하는 방향이다. 스킬명은 기존 '정신 정지장' 대신 **'의식 봉쇄'를 추천하는 가칭**으로 검토한다. 적대/비적대 생명체를 모두 대상으로 하고, 플레이어/PvP 규칙·시전자 제외 여부·지속시간·외부 AI 호환성은 상세 설계에서 검토한다.

**공통 직업 매개체 슬롯 확정 방향:** [직업 매개체 장착·손 연출](./CLASS_FOCUS_SLOT.md) — 8직업 공통 슬롯 하나에 장착, 주손·왼손 자유. 실제 UI/장비 API 구현은 기술 스택 선정 후.

## 성장 및 장비 방향

- 직업별 레벨업 능력치 증가량/비중은 서로 다르다. 구체 수치는 후속 밸런스 설계에서 확정한다.
- **레벨 상한은 두지 않는다.** 계속 경험치를 얻어 레벨을 올리고 능력치가 성장할 수 있어야 한다. 레벨이 높을수록 다음 레벨까지 필요한 경험치는 증가시킬 수 있다. 구체 곡선/수치 폭주 방지는 후속 밸런스 과제이다.
- 공통 레벨/스킬 포인트와 직업별 스킬 트리를 사용한다. 기존 1~50레벨 가정은 폐기한다. 액티브/패시브 개별 해금 단계에는 한계를 둘 수 있어도 캐릭터의 레벨과 능력치 성장 자체를 끝내지 않는다.
- 기본 전투와 바닐라 생존을 유지한다. 바닐라 장비를 사용할 수 있도록 한다.
- **직업 장비는 핵심 능력의 효율을 확실하게 올리는 강화 수단**이다. 장비 없이도 직업 핵심 능력을 사용 가능해야 한다.
- 정신 지배자의 유지 효율/회복, 군체술사의 증식/군단 유지, 결계술사의 결계 효율 등 **직업별 체감 성능** 중심. 정확한 수치·슬롯 수·제작/획득 방식은 미확정.
- 장비 등급명은 **규격 → 변조 → 변칙 → 이형 → 불가해** 5단계(A안)로 확정했다. 세부 성능, 등급별 색/획득 분포는 추후 결정한다.

## 2026-11-05 군체술사 6차 — 군체 관리/실시간 전술 변경

- **사용자 지시:** 군체술사의 **군체 관리 패널을 단축키로 열 수 있어야** 하고, **전투 중 빠르게 전술 설정·변경**할 수 있어야 함. [군체 관리 패널·전술 퀵 휠·서버 명령/비행 연계](./classes/SWARM_COMMAND_PANEL_AND_QUICK_SETTINGS_V6.md).
- **7차 최신 사용자 확정:** 기존 제안한 **'자동 / 공격 우선 / 균형 / 엄호 우선' 고정 전술 폐기**. 플레이어가 **전술 이름을 자유롭게 짓고 공격·엄호 비율을 전부 직접 설정**하여 저장·변경·삭제, **퀵 메뉴에서도 직접 수정/즉시 적용**할 수 있음. 짧게 누름=관리 패널/길게 누름=사용자 전술 퀵 휠은 입력 후보이며 **G 키·홀드 시간·슬롯 수는 미확정**.
- 명령은 즉시 적용을 요청하고 **실제 군체의 재배치에는 이동 시간 필요**. 비행 중엔 최소 운반 군체 확보·시야/아군 투사체/실제 적 피격·안전 하강 유지. **별도 관리 노동/3개 상시 게이지/수동 개별 생물 지휘는 추가하지 않음**. 중력·공명 기획 보류 유지.

## 2026-11-05 군체술사 7차 — 커스텀 전술의 실제 전투/비행 통합

- [**군체술사 플레이어 직접 설정 전술과 실제 공격·엄호·비행·원거리 피해·자연 증식의 통합 규칙**](./classes/SWARM_TACTICAL_COMBAT_INTEGRATION_V7.md). 6차의 고정 이름/비율 프리셋 폐기 유지, **사용자가 전술 이름과 공격%·엄호%를 직접 설정·저장해 퀵 메뉴에서 호출하고 그 자리에서 수정**.
- **공격100%·엄호0%를 선택하면 숨은 방어 보너스 없음**, **공격0%·엄호100%면 무료 급습/소모 공격대 생성 없음**. 비행 운반 군체만 안전 최소 수량을 우선 예약하고 나머지 비율을 적용, `공격N+엄호N+비행N+재결집N=실제 군체N`.
- 군체 전술 변경·피격·군체 소모/자연 증식은 서버 권한으로 일관되게 처리하며, 큰 거리 이동·화살 방어·안전 하강은 실제 위치/시간/수량이 뒷받침되어야 한다. **군집 엄호 액티브는 폐기되어 전술 100:0을 덮어쓰지 않는다**. 현재는 기획 통합만 완료, 실제 Minecraft 플레이/빌드 검증 없음. 중력/공명 두 직업 보류 유지.

## 2026-11-05 군체술사 8차 — 엄호는 별도 액티브가 아닌 전술

- **사용자 확정:** `군집 엄호`는 스킬에서 **완전히 제외**. 유저가 직접 이름·공격:엄호 비율을 정하는 전술로 **지속 운용**, 엄호 액티브 슬롯/쿨타임/지속시간/추가 버프 없음. **액티브 공격은 `군집 급습`·`군체 소모` 2종**으로 정리하고 원격 표적 지정은 무료 기본 명령. 제3액티브를 억지로 채우지 않는다.
- 공격100%/엄호0%면 공격 전담, 엄호대 없음. 엄호 전담이면 공격대 전용 기술 사용할 개체 없음. 비행대 예약·실피격·자연 증식/실제 이동 규칙은 유지. [군체 정본](./classes/SWARM_CASTER.md), [전술과 실전 통합](./classes/SWARM_TACTICAL_COMBAT_INTEGRATION_V7.md).
- **기존 하위 문서의 `군집 엄호 액티브(후보)` 표현은 역사적 제안이며 채택되지 않는다.** 중력·공명 상세 기획 보류 유지.

## 2026-11-05 군체술사 9차 — 군체 외형·생물 애니메이션과 렌더·전투 판정

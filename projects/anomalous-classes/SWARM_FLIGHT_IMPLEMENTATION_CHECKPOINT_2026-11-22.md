# 군체술사 비행 — 서버 운반대 구현 체크포인트

2026-11-22. 현재는 6직업 핵심 기능 개발 단계이며 사용자 실게임 테스트는 통합 단계 이후에만 수행한다.

- 비행은 별도 탈것·마나 없이 실제 totalAlive = attack + guard + lift + regroup 한 자원을 사용한다.
- H 기존 키맵을 직업별로 분기: 군체 비행 토글, 결계 결계 해제 기존 기능 보존. 별도 중복 H 키 등록 금지.
- Lv25 이상, 최소 N24에서 시작해 Lv100에는 운반군 30개체를 예약하는 시험 수치. 비행 상태와 군체 수량은 서버가 최종 승인한다.
- 가까운 재결집·엄호·공격군에서 10틱당 최대 2마리로 운반대 편성. 멀리 간 공격대는 실제 이동한 후에만 편입한다.
- 운반군이 물리 proxy로 생긴 후 vanilla mayfly/flying permission을 서버가 부여한다. 클라이언트 입력은 바닐라 WASD/Space/Shift, 이탈/충돌/속도는 서버 및 바닐라 이동 구조를 활용한다.
- 운반대에 실제 피격이 누적되어 수량이 감소할 수 있다. 지원 수 부족 시 짧은 재배치 유예 후 비행 권한을 회수하고 단방향 감속 하강한다.
- 비행 중 X 소모기는 공격대 인원만 비용으로 지불하고 운반군/엄호군을 침범하지 않는다.
- 비행 이탈·직업 전환·차원 이동·재접속에서도 날 수 있는 허가를 영구 유지하지 않으며, 운반수량 복귀/서버 N 보존을 처리한다.
- 제삼자 다른 비행 모드/창작모드/겉날개와 동시 지원은 제한한다.
- 실제 운반군 리깅/애니메이션, HUD, 전술휠/관리 UI는 Codex 디자인 단계로 유지한다.
- 외부 안티치트/엘리트라/서버 지연/멀티플레이의 실제 이동 일치성은 미검증이다.

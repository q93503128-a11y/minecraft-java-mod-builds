## 2. 서버 처리 불변조건

1. 전투가 아닐 때만 변경 가능. 전직 전용 시설/새 화폐·정기 비용 없음. **전투 중 스킬 트리 무료 초기화도 불가**하며, [3SP 및 무료 초기화](./SP_3_PER_LEVEL_AND_FREE_RESET_V2.md)를 동시에 적용.
2. 서버는 전환 요청 시 `상태 검증 → 기존 공격/주문·실체 회수/해제 예비 상태 확보 → 원직업 이능 종료 → 새 직업 단일 활성 → 저장 확정`을 원자적으로 처리. 동시 타격·사망·로그아웃·크래시·차원 이동 시 절반만 완료되는 일이 없도록 재시도/롤백.
3. 원본 몹/숙주/인형은 **원래 실제 `UUID`와 손상·HP 상태**를 보존하고 가짜 재소환·원가 복제 금지. 전개 인형은 안전한 **이미 있던 등록/회수 시스템**으로만 보관, 인벤토리가 가득 찼다고 버리거나 무한 전용 창고를 새로 만드는 일 금지.
4. **인간형으로 탈출할 안전한 위치가 없다면** 변경을 일단 거절하고 해결 이유를 보여준다. 용암·공허·벽 관통·원거리 무료 텔레포트 금지.
5. **미로드 청크의 지배 대상**은 청크 강제 로딩 없이 해당 원본 UUID에 해제 예약을 서버 저장하고 다시 로드될 때 원본 AI 복원. 클라가 변경 전 직업의 옛 상태를 계속 사용하지 못하도록 epoch/버전 판정.
6. **재전직은 쿨타임·피해·소모재·기생 긴급 재기생 충전·군체 N를 무료로 초기화하지 않음**. 기존 계약 채무도 계속 보존/정상 정산.

## 3. 정신력 고갈/외부 AI 원복 — 위임받은 자율 세부안

- 정신력이 0에 가까워 실제 현재 재생량으로 유지비를 감당하지 못하면 **일반·낮은 위협도의 몹부터**, 동일 위협군은 *유지 효율이 나쁜 몹·최근 지배한 몹부터* 안전하게 지배 해제. 가능한 한 귀하게 얻은 높은 위협도/보스 개체를 마지막까지 지킨다. **실제로 유지불가하면 강한 개체도 해제**; 무료 영구 보존 없음. 새 '해제 우선순위' 전용 UI는 추가하지 않음.
- 지배한 몹은 원래 AI/팀·직업/길들이기·안장/거래 등 정상 상태로 복귀. 보스의 외부 phase·arena·특수 스킬은 **원본 모드가 유지·복구할 수 있는 어댑터**에서만 안전하게 다룸. 확인되지 않은 외부 보스는 지원한다고 거짓 약속하거나 원본 보스 전체를 영구 면역으로 처리하지 않음.
- 지배 후 해제·재장악을 반복해 **원래 엔티티 한 번의 XP·전리품·보스 클리어를 여러 번 지급하지 않음**. 실제 외부 모드 몬스터 각각의 AI/상태 변경/저장 동작은 코드/실전 별도 검증.

# 《이능 직업 서바이벌》 RPG 성장 템포 — 약 30시간의 혼합 서바이벌 v1

> 날짜: 2026-11-05. **D04 사용자 확정:** "30시간 정도? 너무 빡빡하게 사냥만 30시간 말고." 목표는 **한 직업을 일반적으로 육성하며 탐험·채굴·제작·건축·전투·직업 고유 활동을 섞는 약 30시간의 유효 서바이벌 플레이로 Lv300 종결급에 진입**하는 경험이다. **30시간 연속 사냥·던전/보스 반복 파밍은 필요조건이 아니다.** 정확한 XP 공식/보상량·구간별 시간/클래스 간 편차는 *게임에서 검증할 설계 후보*이지 사용자에게 추가 확정받은 값이 아니다.

## 1. 승인된 목표와 기존 정본의 경계

- 무제한 RPG 레벨 유지, **Lv300은 이미 종결급**이다. Lv301이 종결급을 여는 최초 레벨이 아님. 1레벨마다 해당 직업에 **1SP 지급**. 바닐라 XP/레벨·수선·인챈트는 완전 별개.
- 플레이어의 **활성 직업 하나**를 약 30시간 일반적으로 육성하는 목표. 직업 변경이 가능하되 **비활성 직업 XP/SP가 자동 상승하거나 한 직업의 누적 30시간을 다른 직업에 복제하는 정책이 아니다**. 같은 월드의 이미 확보한 재료·거점·탐험 기록에 대한 보상의 공정성과 다른 직업을 새로 키우는 부담은 아래 검증 항목으로 둔다.
- **유효 플레이**에는 생존 준비(나무·광물·도구/장비·기초 거점), 생물군계와 구조물 탐험, 실제 적 전투/던전, 직업 고유 행동(지배·인형 제작/운용·기생/BD·결계·계약·군체) 등이 포함된다. 매분 공격/킬을 요구하지 않는다.
- 생존/건축으로만 반복해서 경험치 자동 생성, 제자리 AFK, 자동 농장, 같은 저비용 레시피 무한 왕복, 같은 위치의 블록 설치/철거 반복, 소환물 자체 처치 등은 성장의 주력 루프가 아니며 중복 지급을 방지한다.
- '약 30시간'은 각자 즐기는 방식에 따른 **목표 중심값**이지 30:00:00 정각에 자동 레벨300/경험치 보정·부스트를 부여하거나 30시간에 도달하면 더 이상 성장하지 않는 시스템이 아니다.

## 2. XP 보상 설계 — 정상 서바이벌을 벌주지 않기

| 활동 | RPG XP를 주는 설계 원칙 | 남용 방지/상충 사항 |
| --- | --- | --- |
| 자연스러운 탐험 | 새로운 생물군계·구조물·실제 탐험 달성(예: 고유 던전 최초 탐색 및 재방문 중 유효 위험 극복) | 청크 출입 반복/로그인·로그아웃/직업 변경으로 '최초 발견' 재지급 금지 |
| 생존·자원 수급 | 유의미한 광물/위험 지역 채굴·장비 발전·첫 정상적인 제작 성취에 기여 | 흙/돌 수백 블록 채굴만으로 XP 무한 수급, 설치→회수 루프/대량 자동 채굴은 기본 성장 경로에서 제외 |
| 제작·건축 | 실제 생존 진전(거점 확장·필요 설비 확보, 직업 부품/매개체 및 진척도에 관계되는 제작)으로 한정하여 적정 보상 | 모든 제작 버튼 클릭·장식 블록 1개 배치 때마다 XP 지급하지 않음. **건축 시간을 '무보상'으로 만들지 않도록** 탐험/재료/생존 성취 XP와 자연스럽게 연결; 구조물 자체의 주관적 '품질 점수' 강제 평가 X |
| 위협 대응·전투 | 일반 적·강화 적·던전/보스에 대해 위험과 실제 기여에 비례한 가변 XP. 인형/지배체/숙주/결계/권능/군체가 정상 참여하면 주인 직업 XP 인정 | 직접 막타 강요, 특정 강력 몬스터 반복 소환·자동 처리 독점, 소환물마다 처치 한 번씩 중복 계산 금지 |
| 직업 고유 플레이 | 실제 의미 있는 능력 사용 및 직업별 발전: 새로운 유형의 지배·합법적 인형 제작/개조·숙주/종별 성취·결계 활용·계약/제단의 실질 진행·군체 전술/비행 성취 | 공통 XP를 **직업 전용 BD/계약 관계/군체 수 N과 혼동하지 않음**; 자원 소모 없이 버튼 반복 사용만으로 레벨링 금지 |

**중요:** 위 표는 지급 가능한 사건의 설계 범위이지, 모든 제작/조작에 반드시 별도 RPG XP를 붙인다는 뜻은 아니다. 콘텐츠의 '처음 1회 보상'과 '재방문해도 의미가 있는 반복 보상'을 적절히 조합해 기존 Minecraft 자유도를 해치지 않는다.

## 3. 역산할 시간·레벨 성장 설계

- **사용자 승인 목표:** 여러 활동을 섞은 약 30시간 → Lv300 도달, 그때 이미 직업별 전체 전력이 종결급.
- **내부 시험 기준 후보** (미승인, 실게임 검증 전): Lv25 약 0.5~1.5시간, Lv100 약 5~8시간, Lv200 약 14~20시간, Lv300 약 30시간. 구간 목표는 실제 '첫 밤·주요 도구 진척·첫 던전·전용 매개체 제작' 등과 함께 재조정하며 과도한 초기 알림 연타 금지.
- 다음 레벨 필요 XP 및 행동별 지급량은 **각 플레이 시나리오의 시간당 RPG XP**를 기준으로 역산한다. '레벨별 XP 공식만 보고 30시간 걸린다'고 선언하지 않으며, 실제 아이템 수급·탐험·피격/사망·직업별 전투 역할에 따라 시뮬레이션해야 함.
- **시험할 최소 루트:** (A) 일반 생존 위주(건축/채굴/탐험+자연 교전), (B) 탐험·던전 비중 높음, (C) 제작·직업 운영 비중 높음, (D) 전투 위주. 어느 한 루트만 지나치게 좋은 XP를 주는지/전투를 안 하면 레벨이 전혀 안 오르는지 확인.
- 동일 월드 내 둘째 직업 전환은 이미 탐험한 장소/소유 자원을 사용할 수 있지만 **직업별 XP/레벨/SP 독립**이므로 초보 직업 성장 전체를 자동 완료시키지 않는다. 최초 탐험·일회성 퀘스트성 진행의 **플레이어/월드 귀속 vs 직업 귀속**을 분리해 재플레이 막힘과 재지급 악용을 동시에 해결할 것.
- **타 직업 대비 비교:** 정신 지배체 처치, 인형이 대신 싸운 처치, 기생 숙주 전투, 결계 공격, 계약 권능, 군체 공격 모두 정상 XP 소유자 배분. 서로 다른 직업이 'Lv300까지 반드시 같은 30.0시간'이 되도록 똑같은 보상으로 바꾸지 않고 큰 부당 격차만 조정.
- 상한 없는 레벨의 Lv301 이후에도 성장 가능, 30시간 달성 이후 경험치/XP 종료 강제 금지. **Lv1 초기 포인트, 액티브 SP 비용, 패시브 완료 후 SP 사용**은 D03 관련 후속 미확정으로 유지한다.

## 5. 기존 문서와의 우선순위

- 최신 플레이시간 **약 30h 혼합 생존**은 [RPG_XP_LEVEL_SKILLPOINTS_BALANCE_V1.md](./RPG_XP_LEVEL_SKILLPOINTS_BALANCE_V1.md) 내 시간 미정 언급보다 우선.
- 기존 XP 요구 곡선 A/B/C, 적별 XP 테이블, 레벨 자동 HP/정신력/인형 공격/결계 배율, 군체 소형 실체 및 기생 BD 경로 등은 **임의로 삭제·고정/재설계하지 않는다**. 목표 시간과 함께 시뮬레이션해 **조정 후보와 근거**를 추후 제시.
- 최종 경험치 공식/XP 지급량/각 직업의 30시간 기준 파워, 초반 시간 범위는 **아직 PLAYTEST-PENDING**. 사용자 확정은 '30시간 정도, 사냥만 강제하지 않음'뿐이다.

# 이능 직업 — 공통 매개체 장비 착용·손 연출 설계 v1

> 2026-11-04 / **PROPOSAL, USER REVIEW PENDING.** 사용자는 정신 지배자/인형술사/기생술사의 직업 장비를 반드시 손에 들지, 또는 **왼손(보조 손)**에 들어도 되는지 질문했다. 현재 정신 지배자 문서에서는 공통 장비 슬롯을 미확정 제안, 인형술사 문서는 손에 상시 들 필요 없다고 명시, 기생술사 공생 핵 문서는 착용 슬롯 세부 정책이 미정이다. **아래 공통 슬롯 선택은 사용자가 최종 승인하기 전까지 추천안**이다.

## 1. 추천: 직업 매개체 장착 슬롯 1개(양손 자유)

- Minecraft 기본 **주손·보조 손(왼손)**과 별도로 **'직업 매개체' 슬롯 하나**를 인벤토리에 둔다. 장비 1개만 실제 활성. 직업별 장비 계열은 1종/5등급 **규격→변조→변칙→이형→불가해** 유지.
- **정신 지배자 → 정신 조율기**, **인형술사 → 마리오네트 조종틀**, **기생술사 → 공생 핵**이 같은 공통 매개체 슬롯을 사용한다. 각 아이템의 기존 5등급 수치/기능을 변경하지 않는다. 직업과 다른 종류는 장착 불가(또는 비활성), 우회·중복 장착 방지.
- 주손에 무기/곡괭이, **보조 손에 방패·횃불·불사의 토템 등 바닐라 아이템을 유지**할 수 있다. 직업을 사용하려면 항상 손을 비우거나, 직업 장비 때문에 방패/토템을 포기해야 하는 상황을 피한다.
- **손에 '보여주는' 것은 별개**다. 지배 스킬 시 잠깐 정신 조율기를 꺼내 들고 정신 이펙트 연출; 인형 타겟 지정 시 십자 조종틀이 손에 보이며 실을 당기는 모션; 기생술사는 공생 핵의 빛이 손/몸에서 반짝이는 짧은 연출. 실제 인벤토리 아이템이 주손·보조 손으로 이동하지 않으며 **현재 무기·방패 사용/채굴을 강제로 중단하지 않는다**.
- '왼손에 직접 들기'가 멋있어 보인다면 **선택적 수동 전시**는 허용하되, 이 경우 기본 바닐라 보조 손 슬롯이 실제로 점유되어 방패·토템·횃불과 경쟁한다. 별도 매개체 슬롯과 왼손에 같은 장비를 동시에 넣어 효과를 중복 적용하지 않는다.
- 단지 가방 안에 넣어 두기만 하면 장비 효과가 자동 활성화되는 방식은 피한다. **별도 슬롯에 장착**해야 강화 효력 발생. 슬롯이 비어 있어도 **모든 직업의 기본 능력**은 사용 가능.
- 실제 구현은 목표 Minecraft 버전/로더 선정 시 커스텀 Inventory slot, 관련 아이템 UI/저장·네트워크/호환 API 중 가장 안정적인 방법으로 결정한다. **Trinkets/Curios 등 특정 로더의 장신구 API를 의무로 정하지 않는다**.

## 2. 직업별 계약

| 직업 | 매개체 한 계열 | 사용 중 보이는 표현 | 장착 효과 위치 |
|---|---|---|---|
| **정신 지배자** | 정신 조율기 | 주문 시 짧은 조율기/이펙트 연출 | 서버가 정한 정신력/지배 효율(기존 미확정 스탯 계약) |
| **인형술사** | 십자형 마리오네트 조종틀 | 명령 시 십자 틀을 잡아 당기는 모션/인형 연결 실 | 동시 전개 +1~+5기 및 인형 공격/HP 보너스만 |
| **기생술사** | 공생 핵 | 인간형 가슴/옷/손의 낮은 강도 발광, 숙주 진입 시 생체 빛 | 실제 **기생 숙주 HP/공격력 보너스 +5~+25% 후보**, 인간형 강화는 없음 |

## 3. Minecraft 보조 손을 항상 사용하면 생기는 문제

- Vanilla Minecraft Java 보조 손은 **방패·토템·횃불·일부 투사체/도구**를 넣는 단일 슬롯이다. 오른쪽 클릭 등 상호작용 우선순위가 주손 상태에 영향을 받는다. 직업 매개체 아이템을 왼손에 강제하면 필수 바닐라 선택지와 충돌한다.
- 특히 **기생술사**가 돼지/거미/워든처럼 전혀 다른 몸으로 들어갈 때, '인간형 왼손에 들었던 아이템이 없는 손에도 물리적으로 들려야 한다'는 연출·히트박스 문제까지 생긴다. **공생 핵은 장착 상태만 플레이어에게 귀속**하고 숙주 모델에 따라 짧은 표시를 띄우는 편이 자연스럽다.
- 반대로 별도 슬롯 UI도 별도의 인벤토리 공간이므로 **8개 직업마다 슬롯을 하나씩 늘리지 말고 공통 1개만** 제공. 바닐라 인벤토리와 통합된 작은 장비 위치 하나면 된다.

## 4. 서버/저장/UI 규칙

- 서버 플레이어 UUID에 **한 개 활성 매개체 슬롯** 저장. 실제 장비 아이템 ID/등급·유효 직업·제작 소유권 확인, 복제·중복 장착/재로그/죽음·차원 이동 검증.
- 장비 해제·버리기/교체 시 효과는 즉시 해제. 최대 체력 변화는 **체력 비율 보존**으로 무료 힐을 방지. 인형 전개 슬롯 초과 시 인형 개체를 삭제하지 말고 [조종틀](./classes/MARIONETTE_CONTROL_BAR.md)의 안전 회수 정책을 적용.
- 죽었을 때 매개체 장비를 어떻게 떨구는지는 서버 게임룰/일반 아이템/공용 사망 인벤토리 규칙에 따라 처리. 직업 레벨/BD/종족 기술 영구 기억은 장비와 무관하게 저장되어야 함.
- Codex UI 작업은 인벤토리에 작은 **'직업 매개체' 슬롯**을 1개 추가하고, 손/캐릭터 모델 연출과 활성 장비를 구분한다. 최종 디자인은 실제 Minecraft 화면에서 검수. 기존 직업 액티브 입력과 왼손 아이템의 오른쪽 클릭을 충돌시키지 않는다.

# 군체술사 — 원격 표적·군집 급습·군체 소모 서버 전투 연계

2026-11-22. 이전 1차 체크포인트 `SWARM_IMPLEMENTATION_CHECKPOINT_2026-11-22.md`에 이어지는 두 번째 전투 코드 단위. 기존 NeoForge 1.21.1 / Java 21 및 서버 군체 노드 구조 유지.

## 구현

- R: **서버 시선·실제 블록 충돌 기반** 최대 48블록(문서의 미확정 시험값) 유효 Monster 우선 표적. 없는 곳 조준 시 명시적 대상 해제. 아군·정신지배된 몹·타 차원·언로드 개체·벽 뒤·사거리 초과 제외.
- 표적은 서버 메모리에서 UUID로 관리하며, 사망/실종/사거리 이탈·전직·재접속·차원 전환 시 해제. 서버 권위라 네트워크 메시지는 action ID만 전달. 다른 직업의 R 입력 경로/동작 유지.
- Z: **군집 급습**. 실제 공격 노드가 있을 때 서버가 대상 지정·8초 시험 쿨다운을 확인하고 6초 이내에 경로를 따라 접근. 물리 노드가 실제 적에게 1.8블록 안으로 접근하고 시야가 연결된 경우에만 최대 3명 타격. 텔레포트·원거리 즉시 피해 없음. 접근에 실패한 시전은 만료되며 쿨다운 유지(시험 규칙).
- X: **군체 소모**. 현재 실제 공격대의 25% 올림(시험값, 최저 1)을 소모. 공격 노드가 표적 3블록 이내이고 직접 시야를 확보해 **실제 적에게 유효 피해를 성공시킨 경우에만** 공격대 수·총 N을 정확히 한 번 감산, 12초 시험 쿨다운. 엄호·재결집·운반 인원은 건드리지 않음.
- 두 액티브 모두 공격 0%/실제 공격대0이면 사용 불가. 재접속과 저장 후에도 쿨다운은 서버 SavedData의 다음 준비 게임 tick으로 보존. 다른 직업의 패킷은 서버에서 모두 거부.
- 기존 레벨/전술/스킬트리, 군체 실피격과 자연 재증식 보존. 단순 표적 지정은 쿨다운과 소모 없음.
- 기존 `verifySwarmRules`를 `check`에 포함: 0/100 전술, 총수 보존, 희생 비용 계산, 쿨다운 반복/독립성 등 검증.

## 구현 경계

- 현재 타깃·기술은 기존 Monster 기준으로만 적용. 모든 외부 몹/보스의 특수 AI 경로가 검증되었다는 의미가 아님.
- **피격 모델·충돌 샘플 렌더 외형은 Codex가 정식 디자인 작업에서 변경할 대상.** 전용 군체 전투 애니메이션·피해 피드백·VFX·사운드와 정식 군체 관리 패널/전술 퀵휠, 비행, 고유 패시브/매개체 효과는 이 단계에 포함하지 않음.
- 48블록, 8초/12초, 25% 희생과 공격 위력/범위는 최종 밸런스 확정치 아님. 실제 PvP/멀티 및 눈으로 보이는 공격범위-서버 판정 적합성 미검증.
- **실제 게임에서 AI가 군체 노드를 물고 화살로 타격하는지 확인하지 않았으므로**, 이전 G1/G2를 통과했다고 간주하지 않음. 코드 빌드 통과도 게임 완성 판정이 아님.

## 플레이테스트

1. `/class`로 군체술사 선택, `/swarm tactic save 100 돌격`, 지상에서 공격대 편성까지 잠시 확인.
2. `/summon minecraft:zombie ~9 ~ ~`, 좀비를 바라보고 **R**로 먼 표적 지정. 공격대가 실제 길을 따라 접근할 때까지 기다림.
3. 충분히 가까워진 후 **Z**로 급습. 이미 가까우면 바로 타격, 멀면 이동 후 타격. 벽 너머/먼 곳 원격 즉시피해가 있으면 실패.
4. 공격대가 접근한 상태로 **X** 군체 소모. 유효한 타격일 때에만 총 N 감소 및 자연 재증식 확인. 직후 연타해 중복 희생되지 않는지 확인.
5. `/swarm tactic save 0 생존`으로 공격 0·엄호 100 전술 전환 후 Z/X 입력. 공격대가 0인 시점에는 공격 금지. R은 무료 표적만 지정해 둬야 함.
6. 사망·재접속·차원 이동 후 대상·예약 급습 소멸과 기본 성장·쿨다운 보존, 아군 몹 비공격 확인.

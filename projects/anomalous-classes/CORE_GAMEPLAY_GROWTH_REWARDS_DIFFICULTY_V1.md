## 0. 현행 사용자 결정 vs 이번 신규 제안

### 기존 사용자 승인 방향 — 그대로 보존

- **마인크래프트 기존 서바이벌을 유지**: 채굴·건축·탐험·제작·전투. 8개 이능 직업의 차별화된 전투/이동/제작/생존 능력을 결합한다.
- **공통 RPG 경험치 → 레벨 → 스킬 포인트 → 직업별 스킬·능력치**, 상한 없는 캐릭터 레벨. 직업별 자동 스탯 성장과 패시브 투자, 주손/보조손 별도 **직업 매개체 슬롯 1개**, `규격→변조→변칙→이형→불가해` 5등급. 직업 기본 능력은 매개체 장비를 얻기 전에도 사용 가능.
- 현재 **정신 지배자·인형술사·기생술사·결계술사·계약술사·군체술사**의 세부 설계가 존재. 각 직업의 구별된 자원/강점/성장 규칙은 **직업별 최신 정본** 우선. 공통 루프를 편의 때문에 통째로 같은 유형의 스킬/소환수로 바꾸지 않음.
- **외부 모드**는 보스·몬스터·던전·스폰/전리품·편의성/소규모 장비 개선 등 **우리 게임을 보조하는 역할**. 별도 레벨·직업·스탯/스킬트리·대규모 자체 장비 단계·별도 RPG 자산/재화/강제 퀘스트 같은 **경쟁하는 성장축** 기본 도입 금지.
- **JEI**는 같은 모드팩에 들어 있어도 다른 플레이어가 원하면 **Ctrl+O로 JEI 아이템 목록/검색 UI를 숨길 수 있음**(JEI 모드 자체를 비활성화/언로드하는 것은 아님). 제작법 R/사용처 U 기능과 구별. 사용자는 JEI 유지 희망, 다른 플레이어에게 UI를 강요하지 않음. 바닐라 레시피북 버튼 숨김 여부는 **별도 개인 취향 설정**.
- 최상위 보스를 지배/기생 등 클래스 능력에서 '보스라서 무조건 면역'으로 처리하지 않는다. 다만 고난도 성공 판정/유지·저항, 고유 기믹·AI/안정성/소유권을 해치지 않도록 실제 API·보스별 동작 검증이 필요하다.

### 신규 통합 **제안** (미승인·정량 수치 미확정)

- **일반 생존을 위한 초반 여유** + **던전·특수 적·보스가 주는 고난도 선택형 목표** + **그 적이 실제로 주는 기존 재료·RPG XP/직업별 성장 기회**를 연결한다.
- **새로운 공용 토큰/뱃지/일일퀘스트/장비 강화 재화는 만들지 않는다.** 이미 있는 Minecraft 아이템/XP와 기존 클래스별 고유 자원·재료/숙련·신뢰·군체 N을 활용한다.
- **강제 레벨별 지역 접근 제한/보스 필수 순서**보다는 '적 패턴/스폰 위험/재료 및 준비도'가 난도를 구성하도록 한다. 특정 구조물/몬스터 모드는 선택 단계이며 세부 실제 스폰 레벨/위치/드롭 확정하지 않는다.

## 1. 한 바퀴가 분명한 서바이벌 RPG 루프

`바닐라 생존·탐험·채집 → 실제 위협 조우 → 직업 능력으로 전투·이동/보호/제작 선택 → 기존 아이템 드롭/공통 RPG 경험치 + 직업별 고유 보상 → 레벨업/스킬/매개체 성장 → 더 다양한 위험과 선택형 보스·던전 → 다시 생존·탐험`.

**상태별 플레이 판정**

| 시기 | 플레이어가 보통 하는 일 | 실제 위험·목표 | 누적되는 성장/보상 | 허용하면 안 되는 문제 |
|---|---|---|---|---|
| **처음 생존** | 직업 선택 후 채굴, 음식·기본 도구, 가까운 동물/적·기초 능력 익힘 | 밤·동굴 기본 몹, 희귀 특수 적을 선택적으로 조우 | 낮은 단계 RPG 레벨, 익숙한 마크 재료, 클래스 기본 능력 숙련 | 시작 능력 없이 필수 재료나 특정 생물군계를 찾아다니며 생존 실패, 첫날 강화 적 떼 |
| **초반 성장** | 기본 클래스 스킬과 장비 제작, 탐험·기초 던전 | 일부 Mutant/Born in Chaos/바닐라 엘리트 적 후보, 낮은 밀도 | 바닐라 재료·스킬포인트·초기 매개체, 직업 고유 성장(인형·BD·계약 등) | 일반 채굴·건축이 불가능할 정도의 무차별 공격, 무조건 전용 던전 입장 |
| **중반 다양화** | 술식/동료/숙주/군체·계약을 키우고 던전·미니보스 도전 | YUNG 던전·Graveyard·Mutant·선별된 Born in Chaos | 직업별 유의미한 도구·재료/드롭, RPG 레벨/스킬·매개체 상위 제작 후보 | 모든 클래스가 같은 스탯 장비만 파밍, 던전 한 종류 반복이 유일한 최적 경로 |
| **강적/보스전** | 패턴 확인, 준비, 보스 전투·재도전·멀티 협동 | Cataclysm/Mowzie's 등 **버전/호환성 검증 후** 선택 채택 | 유효 XP·전리품·선택적인 상위 제작/강화 경로, 지배·기생 도전 등 실제 능력 사용처 | 보스 패턴을 상태이상/지배/결계로 무한 잠금, 보스 무적을 우회한 무료 드롭 |
| **후반/장기 성장** | 기존 직업의 차이를 극대화하며 원하는 탐험/건축/보스/협동 지속 | 강한 적+여러 패턴, 멀티 위협·서버 부하 | 레벨·자동 능력치 지속 성장, 전문화 폭/장비 효율 체감 | 무제한 레벨이라 엔티티 수/체력·적 XP가 폭주, 영구 농장으로 레벨 무한 증가 |

이 표는 **고정 스테이지·레벨 컷/정량 플레이타임이 아님**. 기존 월드의 풍경과 자유로운 마크 진행을 유지하면서 위협·보상의 점진적 다양성을 제안하는 기획 구조다.

## 2. 공통 XP / 바닐라 XP / HUD의 관계 — 중요한 미결 사안

### 2.1 지켜야 하는 것

- **공통 RPG 레벨**은 모든 클래스에서 같은 게임 주도 성장축. 레벨 상한 없음, 스킬 포인트·클래스별 자동 성장, 레벨 이후의 포인트 처리 정책 필요.
- **바닐라 경험치·인챈트 시스템**은 기존 마크의 중요한 보상/인챈트 소비 루프. 그냥 제거하거나 전용 클래스 레벨로 임의 덮어써서는 안 된다.
- **멀티 플레이어 Locator Bar**가 경험치 바 안/위에 표시될 수 있고, **JEI**는 개별 클라이언트에서 숨김. 따라서 UI에 RPG XP 게이지/바닐라 XP/멀티 위치/스킬 자원 3~4개가 서로 겹치는 방식 금지.

### 2.2 제안: 성장 권한은 하나, 바닐라 인챈트는 유지 (확정 아님)

- 게임 고유 **RPG XP·레벨**을 서버 상태로 관리(이 게임 유일한 공통 RPG 직업 성장), 바닐라 XP는 **원래 인챈트·수선/바닐라 레시피 쓰임을 보존**한다. 두 XP 상태를 혼동하지 않도록 RPG 레벨 표시와 바닐라 XP 바는 UI에서 구분. '외부 RPG XP 시스템 하나 더'를 설치하지 않는다.
- **동일 처치/행동으로 두 XP를 획득하는 방식**은 '각각 다른 목적'인 제안일 뿐 아직 확정하지 않는다. 또 다른 XP를 끝없이 지급하면 이중 보상 악용이 되므로 이벤트 중복/루트 간 경제·인챈트 영향 검증.
- **레벨업 보상 후보:** 레벨마다 클래스 기본 능력치 자동 성장, 스킬포인트 1개 같은 단순 방식부터 시험. 1레벨당 정확히 몇 포인트, 누적 랭크 총합 270/285/290/300 등과의 일치, 최종 레벨 이후 포인트 처리 방식은 미결. **스킬 랭크 총합을 같게 만든다는 이유로 모두 300랭크 강제 금지**.
- **XP 주체:** 플레이어 본체 공격뿐 아니라 자신이 합법적으로 소유한 인형/지배체/군체, 기생 중 숙주 몸, 결계의 유효 타격/계약 권능이 만든 전투 보상도 **주인 플레이어의 공통 XP 대상 후보**. '본체가 마지막 공격을 해야 XP'라는 제한으로 소환형 직업을 불리하게 만들지 않음.
- **XP 획득 기준을 서버에서 한 번만 집계**: 같은 몬스터가 여러 소환체에 맞거나 여러 플레이어가 피해를 줬더라도 중복 지급/농장 폭증 방지. 팀원 분배는 기여/근접·협동/소유권 모델을 별도 검증. 멀티에서 '막타 스틸'도 피하되 참여하지 않은 AFK 부캐에게 무제한 원격 XP를 주지 않는다.
- **XP 출처 우선순위 후보**: 위협 있는 적의 정상 처치/전투, 던전·보스 실질 극복에 의미 있는 보상. 채굴/제작은 이미 재료 보상이 있으므로 **모든 블록 채굴에 무한 RPG XP를 부여하지 않는다**. 선택적인 최초 탐험 발견/유의미한 제작 성취 XP는 더 이상 반복 노가다가 되지 않을 때만 고려.
- **보스 반복/소환 악용**: 최초 유효 격파의 추가 보상 가능성은 시험안; 반복 보스가 전부 무보상이면 재전투 동기 사라짐. 리스폰 보스/명령 소환·스폰 알/피해 농장/지배 후 처치/소유 소환물 무한 처치로 XP·드롭을 무한 생산하는 것은 제한. 서버 설정/전투 상태 검증.

### 2.3 선택 전 비교 질문

| 결정 | 제안 기본값 | 검증할 대안/문제 |
|---|---|---|
| RPG XP와 바닐라 XP의 분리 | **게임 자체 RPG 레벨 상태 + 바닐라 XP 유지** | RPG XP를 바닐라 XP와 연동하면 인챈트 소비가 직업 성장 손실이 되는지, 멀티 XP 바와 충돌하는지 |
| 공통 스킬포인트 | **레벨업당 일관된 기본 지급** | 초반 기술 부족·장기 270랭크의 클릭 노동과 고레벨 잉여 포인트 |
| 난이도에 따른 보상 | **강한 적에게 의미 있는 더 높은 보상** | 단순 체력 비례 XP로 고HP 치즈/농장·서버 오버플로/무조건 DPS 직업 우대 |
| 협동 XP | **서버 귀속·참여 기여 인정**, 막타 독식 방지 | 팀/파티, 실제 거리, 보스 차원·사망, XP 부캐·다중 소환물 악용 |
| 죽음/재접속 | **영구 획득한 직업 레벨/고유 성장 손실 금지 방향** | 장비·바닐라 XP·현재 소환/군체·숙주 상태는 기존 개별 정책과 바닐라 gamerule 존중 |

## 3. 전리품/제작·장비: 보상은 기존 플레이 루프에 연결

**새 공용 보스 토큰·강화 주화·자체 고급 재료 10종을 일단 추가하지 않는다.**

| 얻는 것 | 어디서? | 기존 소비·영향 |
|---|---|---|
| **바닐라 재료/기존 모드 재료** | 채굴·채집·전투·거래·던전 상자 | 무기/방어구/생활 도구·인형 제작 부품, 일부 매개체 제작, 계약 상대가 요구하는 다양한 **기존 자원 제물** |
| **공통 RPG XP** | 유효한 위협의 전투·선택형 의미 있는 탐험/성취 후보 | 공통 레벨→직업별 자동 스탯/스킬포인트→직업 스킬 강화 |
| **바닐라 XP** | 원래 정상 획득 경로 | 기존 인챈트·수선. 추가 RPG 성장 시스템이 아님 |
| **직업 고유 축(기존)** | 지배 성공/유지·인형 제작/수리·기생 활동에 따른 BD/종숙련·결계 운용·계약 제물/관계·군체 N의 자연 증식 | 개별 정본이 정한 **전투·이동·생존의 의사결정**, 일반적인 '보스 코인'과 구분 |
| **상위 보스/던전 드롭** | 희귀 강적·고유 구조물, 실제 모드 출처/난도 조건 | **상위 매개체/희귀 인형 특화·특정 계약 제물 후보**, 대신 필수 재료는 보통 최소 2개 획득 경로 확보. 적이 다양해져도 '하나의 보스를 매일 100번 반복' 강요 금지 |

- **외부 장비를 그대로 추가**하는 경우 그 갑옷/무기가 바닐라 및 우리 매개체 성장과 비교해 어떤 가치인지 검증한다. Cataclysm 등에서 나오는 강력한 무기·방어구를 자동으로 전부 삭제하거나 속성만 뽑아 별도 등급 시스템을 추가하지 않는다.
- **장비 5등급**은 기존 직업 매개체 한 계열에 적용. 모두가 보스 드롭만으로 한 단계씩 진화하도록 강제할 필요 없음: 바닐라 자원 승급과 고급 탐험 보상이 어울리는 조합을 **직업별 기존 재료 정책에서** 조정.
- 이미 **제물**이라는 직업 고유 소비 자원이 있는 계약술사에게 '제물은 금지된 추가 통화'라고 새로 부정하지 않는다. **계약 상대별 기존 아이템·행위·관계 비용**을 유지하고 공통 화폐로 축소하지 않는다.
- **인형술사 부품 3요소**나 **기생술사 BD/종별 숙련**을 '성장축이 중복되므로 폐기'하지 않는다. 사용자가 승인한 **직업별 개성을 주는 고유 성장 방식**과, 금지하는 **외부 RPG 모드의 독자적 경쟁 성장축**은 다르다.

## 4. 여섯 직업에서 같은 적/보상이 다르게 재미있어지는 이유

| 직업 | 즉시 쓰는 시작 능력/전력 | 중반~후반 위협이 주는 과제 | 보상과 실제 직업별 성장 연결 | 플레이 막힘 방지 |
|---|---|---|---|---|
| **정신 지배자** | 정신 침투·기본 대상 지배, 장기 유지 정신력. 지배 동료는 기본 따라오며 스스로 전투 | 높은 저항·광역/정신력 부담·특수 보스 AI. 보스 고유 패턴과 지배해제 안전성 | 강한 적 자체가 지배 가능한 **전력 선택**이 될 수 있음 + 공통 XP, 정신력·유지 효율 성장 | 초반 약한 대상부터 활용, 보스 절대 면역 X. 높은 지배 난도와 보스 기믹/제어 어댑터 미확정 유지 |

| **군체술사** | 시작부터 작은 살아 있는 군체, 무료 원격 표적, 공격 액티브 급습/소모, **상시 엄호는 플레이어 직접 정의 전술** | 다수/광역 적의 실제 군체 사망, 보스 장기전 증식·소모·엄호/비행 분담 | 공통 XP·군체 개체 공격/내구·자연 증식과 최대N 레벨 성장, 매개체 강화; 보스 전투에서 군체 선택 | N=0에서도 시간/유효 전투로 자연 증식, 수량 버튼 +N 없음, 숨은 자동/공격우선 프리셋 금지, 본체 생물 크기 약 **0.2블록** |

**기본 규칙:** 소환체/정신 지배체/기생 숙주/군체/계약 권능으로 실제 적을 쓰러뜨려도 소유자 전투 기여가 정상 집계되어야 한다. 플레이어 본체의 무기 마지막 타격만을 보상 조건으로 만들지 않는다. 적이 강해졌다고 일부 직업이 일반 마크 채굴·방패/도구·건축을 아예 못하는 설계도 피한다.

## 5. 외부 모드 난이도는 어떻게 배치하는가

### 5.1 목적별 현재 후보(**고정 포함 목록 아님**)

| 외부 후보 | 목적 | 난이도·보상 통합 방식 |
|---|---|---|
| **바닐라 적** | 일상 생존 위협과 기본 XP/드롭 | 마을/집·광산/건축을 시작할 수 있을 정도로 기본 위협 유지, 외부 강적에 완전히 교체당하지 않음 |

### 5.2 난이도 곡선 원칙

- **초반**: 외부 몹을 처음부터 모든 바이옴/밤에 대량 투입하지 않는다. Minecraft 원래 적을 상대하면서 직업의 '기본 재미'와 XP·재료 루프가 돌아가야 한다.
- **중반**: 던전 내부·특정 구조물/지형/상황에서 새로운 패턴·넓은 공격·변이 적을 조우하는 **선택적인 높은 위험/더 의미 있는 보상**. 엄호/지배/기생/결계 등 각 직업이 보스전에서 다른 대응책을 고민한다.
- **후반**: 강력 보스가 주는 광역·돌진/속성·페이즈 패턴과 성장한 직업 능력을 경쟁. 이미 있는 보스 피해 구조를 지배/정신정지/결계/군체 실체 계산이 우회하지 않도록 **보스별 어댑터·진영/AI 복원** 확인.
- **멀티**: 전투 참여 인원에 따른 보스 난도 보정은 검토 가능하지만 **비참여 높은 레벨 1인이 근처에 있다는 이유만으로 모든 야생 좀비 HP 폭증** 금지. 협동 장비·군체·인형으로 서버 부하가 늘수록 스폰 개체수도 자동 곱하는 단순 설계 금지.
- 적의 실제 강함/생존력/원거리/방패 대응/차단·CC 저항과 보상이 같은 구간에서 **일관되게 증가**해야 한다. 주간 미션/배틀패스/독립 난도 포인트 같은 신규 성장축 X.

### 5.3 데이터 계약 제안 (코딩 전 공통 명세)

- 몹/구조물 프로필 후보: `entityTypeId`, `sourceModId`, `encounterRole` (ordinary/elite/boss), `spawnContext`, `rewardProfile`, `xpAttributionPolicy`, `combatCompatibility`.
- `combatCompatibility`의 검사 항목: **정신 지배**(성공/해제 후 AI/페이즈 복원), **기생 숙주**(몸 조종·모델·고유 공격), **인형의 표적/아군 판정**, **결계의 투사체·영역 공격/보스 특수 기믹**, **계약 권능의 팀/조항·보상**, **군체 실체 위치/탄도/광역 피격**, PvP/멀티/차원/저장.
- 위 값은 **실제 모드가 이를 제공한다는 주장이나 고정 구현 스키마가 아님**. 연구/QA 매트릭스를 서버 설정/전투 어댑터로 바꿀 때 쓰기 위한 정보 설계안.
- **모드팩에 후보를 많이 넣는 것 자체가 목표가 아니다**. `재미 기여 / 보상 기여 / 기술 호환 / FPS·TPS / 관리 부담 / 법적 사용 조건 / 대안`을 기준으로 남기거나 제외한다.

## 6. 비정상 루프와 막힘을 먼저 차단

1. **소환물 스폰·사망 XP 무한**: 플레이어 인형/군체/지배체·계약으로 만든 존재를 적으로 사칭해 반복 죽이거나, 고정 농장/마을 주민/농장 거래를 매 tick 카운트해 RPG XP가 폭증하는 경우. 소유자·유효 위협·처치 ID/보상 상한을 서버에서 검증.
2. **레벨/스탯 수치 폭주**: 상한 없는 레벨은 확정이나 스탯 곱이 무한히 커져 체력/피해/군체수/보스HP·직업 저장이 오버플로하는 것은 실패. 유효 강화량 합성/상한 또는 체감 감소·표현 범위는 수치 실험 뒤 결정.
3. **출발 지형 소프트락**: 기생술사의 돼지·대체 동물, 계약술사의 낮은 위계 제단·제물, 인형술사의 재료·실처럼 입문 핵심 요소가 특정 드문 지형에만 존재해서 직업 전투를 시작 못 하는 문제 금지.
4. **외부 보스 우회/막힘**: 무제한 결계 격리·지배/CC/숙주 기술로 보스 페이즈 멈춤, 특별한 약점 무시, 보스 상태 복원이 깨지면 재도전/다른 월드 저장에 악영향. '보스는 절대 면역' 대신 **실제 보스별 높은 저항/비용·타깃/페이즈 어댑터**를 검증해야 함.
5. **가짜 보상**: 특별 드롭이 기존 장비/전투에서 아무 쓸모도 없거나, 모든 상급 드롭을 새 통화로 환전만 하는 루프 금지. '특별 적과 싸운 이유'가 장비/직업 능력 변화로 보여야 한다.
6. **잦은 UI 관리 노동**: 수십 개 능력치·전술/장비/종별 숙련 정보를 계속 누르도록 강요 금지. 자주 바꾸는 설정은 빠른 메뉴; 성장 화면은 필요 시 열기. JEI 노출은 사용자/클라이언트별 취향, 멀티 위치 표시·동적 조명은 외부 QOL 후보.
7. **다른 모드 성장축 침투**: 외부 보스/던전 모드가 별도 스킬포인트/레벨/직업·전투 재화/반복 점수판을 추가한다면 기능 제거 가능 여부를 검토, 기본 채택 보류. 단 **우리 직업 자체의 고유 데이터(기생 BD/계약 제물/인형 부품 등)는 제거 대상이 아님**.

## 7. 기획 단계에서 해볼 검수(게임 클라이언트 플레이테스트와 구분)

**동일 장면을 6직업에 대입:**
1. 처음 나무·음식/도구·첫 밤 준비, **능력의 핵심 행동에 곧 접근 가능**한가?
2. 갑옷·방패/곡괭이/횃불을 들고 살아가는 동안 직업 능력이 **실제 행동 선택**을 만드는가?
3. 바닐라 스켈레톤/좀비/거미/철 골렘/주민, 선택한 외부 특수몹 1종/작은 던전, 강한 보스 1종에 **각 직업 행동·피격·보상·소유권**을 설명할 수 있는가?
4. 중반 자원 하나를 얻은 후 **어떤 장비/스킬/숙주/계약/인형/군체**가 변하는지 확인 가능한가?

### 통과 조건(정량 수치 없음)

- 여섯 직업 모두 **첫날부터 능력을 사용**할 수 있고, 일반 서바이벌과의 접점이 있다.

- 강적을 상대하는 이유가 **전투 준비/보상·재료·스킬 투자** 중 최소 하나로 연결되고, 일반 바닐라 몬스터를 완전히 쓸모없게 만들지 않는다.
- 새 공용 재화/중첩 RPG 시스템 없이도 충분한 선택과 성장감을 제공한다.
- 구상한 내용 중 **미확정 수치/로더/외부 모드 채택은 명확히 표시**한다.

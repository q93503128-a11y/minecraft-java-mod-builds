# 《이능 직업 서바이벌》 직업 변경·직업별 저장 생명주기 v1

> 작성: 2026-11-05. **D01 사용자 확정:** 직업별 독립 성장 저장, 이전 직업 복귀 가능. **D02 사용자 확정(A): 비전투 중 어디서나 변경 가능.** 이 문서는 지금까지의 확정 의도와, 그것을 구현할 때 필요한 **설계상 안전 규칙/미승인 수치 후보**를 명시한다. 기획 단계이므로 코드·클라이언트·멀티 검증 완료 주장이 아니다.

## 1. 사용자 승인된 핵심 동작

- **한 플레이어는 현재 직업 하나만 활성화**하며 기존 월드에서 다른 직업으로 변경할 수 있다. 다른 직업의 RPG 레벨·XP·SP·스킬/패시브·고유 영구 성장 기록은 **직업별 별도 저장**한다.
- 새 직업을 선택하면 그 직업 고유 성장은 처음부터 진행하며, 이미 육성한 직업으로 복귀하면 저장된 레벨·획득 능력·고유 기록을 그대로 불러온다. 별도 새 월드를 만들 필요가 없다.
- **비전투 중이라면 세계 어디에서든 변경할 수 있다.** 마을, 제단, 제작대, 특별 구조물이나 별도의 전용 시설 방문을 **직업 변경의 필수 조건으로 요구하지 않는다.**
- **전투 중에는 변경할 수 없다.** 즉시 다른 직업의 고위 권능·방어·회복·소환 능력을 이어 쓰는 다중 직업 전투는 기본 플레이가 아니다.
- 바닐라 인벤토리·HP/허기·경험치/수선/인챈트·월드 건축/탐험 진행은 직업 전환 보상이나 별도 직업 레벨로 복제하지 않는다. 직업 전용 매개체 슬롯은 **유효한 현재 직업 장비만 효과가 켜진다**.
- **다른 직업의 고유 자원/계약/숙련/부하를 지우지 않는다.** 전환 시 실체가 있는 개체의 행동/소유권/아이템 보존 정책은 아래 안전 처리에서 다룬다.

## 2. 비전투 판정 — 구현 안전 명세

다음은 사용자 선택 A가 성립하도록 하는 **설계 기본값**이며, 숫자는 미승인 시험값이다.

1. 서버가 현재 플레이어의 **직접 공격/기술 사용·적법한 전투 피해 수신, 그 플레이어가 소유한 소환체·지배체/계약 권능·현재 숙주의 유효 전투 참여**를 기록한다. 해당 교전이 진행되는 동안 변경 불가.
2. 공격 대상에게 유효한 피해/CC를 가하는 중, 자신이나 직업 개체가 적의 공격을 계속 받는 중, 위험한 채널링/투사체/지속 피해가 처리 중이면 변경 불가. 단순히 적대 몬스터가 근처에 존재한다는 이유만으로 **영원히 변경 금지하지 않는다**.
3. 전투 종료는 위험한 행동/피격이 멈춘 뒤 짧은 **전투 해제 유예 시간**을 지나 확인한다. 예: *마지막 유효 전투 이벤트 이후 8초*는 **조정 가능한 후보**, 사용자 확정된 수치가 아니다. 추적 중 적이 근처에 있다고 무조건 영구 봉쇄하지 않으며, 소환체가 세계 먼 곳에서 교전 중인 경우 현재 전환 가능성은 서버가 관련 상태를 안전하게 정리할 수 있는지 검증한다.
4. 변경 메뉴 요청 자체는 실패해도 재화/XP/HP를 소비하지 않는다. 전투 중이면 **현재 전투에서 벗어난 후 변경 가능** 정도의 짧은 피드백. 바닐라 키와 경합하지 않는 변경 명령/GUI 진입 키는 **공통 조작 정책 결정 후** 지정한다.

## 3. 변경 과정의 원자성 — 제안된 안전 동작

1. 서버가 새 직업의 유효성·전투 상태·현재 직업과 동일 여부를 판단한다. 불가면 아무 상태도 변경하지 않는다.
2. 허용되면 전환 전에 **현재 직업의 레벨·XP·SP/패시브·쿨타임·소유 개체 ID·BD·전술·제물/서약·장비 효과 등을 정확히 저장**한다. 전환 대상 직업의 영구 데이터는 별도 존재한다.
3. 현재 직업의 공격 권능/채널링/지속 버프를 **안전하게 비활성화**하고, 관련 엔티티를 삭제하거나 복제하지 않는다. 소환체·숙주·결계/군체 등의 기존 정체성/사망·소모 기록/내부 타이머를 전환으로 무료 회복·리셋하지 않는다. 특정 실체를 어디에 남기고 어떻게 회수하는지는 직업별 어댑터 설계에서 확정한다.
4. 전환 대상 직업의 별도 저장을 읽고 **오직 해당 직업의 패시브/기술/매개체 보너스만 활성화**한다. 동일한 한 플레이어 UUID에서 두 직업 피해·회복·보너스가 동시에 유효해지지 않게 한다.
5. 전환 중 서버 종료·네트워크 지연·청크 언로드·사망·장비 이동이 발생하면 **직업 유효성/소유권 정본**을 통해 이전/목표 직업 중 하나로 안전 복구한다. 중간 상태에서 스킬 누락/개체 복제/부하 영구 소멸/BD 초기화/계약 부채 면제 금지.
6. 저장 스키마의 제안: `playerUUID → selectedClassId + classProgress[classId]{rpgLevel,rpgXp,sp,skills,passives,uniqueGrowth,ownershipRecords,version}`. 바닐라 인벤토리·월드데이터 별도, 실제 저장 API·직업별 엔티티 직렬화는 게임 코드 설계에서 결정.

## 4. 직업별 상태 경계 — **영구 기록 보존 확정, 비활성 실체 동작은 기술 설계**

| 직업 | 변경 후 반드시 보존할 것 | 전환 과정의 제안된 안전 규칙 |
| --- | --- | --- |
| 정신 지배자 | 과거 지배 개체 소유·상태, 레벨·패시브, 정신 자원과 개체 UUID | 지배 대상이 남아 있는 경우 공격 명령/정신력 유지의 비활성화와 원본 AI 복원을 무작정 동일시하지 않음. 직업을 되돌릴 때 유실 없이 회복할 수 있는 저장·휴면 정책 필요 |
| 인형술사 | 제작한 인형 ID·부품·크기·파손/HP·강화·등록 정보 | 가동 인형이 타 직업에서 싸우지 않게 안전 회수·휴면 처리. 소환/회수/저장 이벤트 중복으로 무료 재료 복사/HP 회복 금지 |
| 기생술사 | 영구 BD·종별 숙련100·배운 기술·현재 숙주 상태/식별자 | 현재 숙주 플레이어 조종권을 떠날 때 원본 몹/AI/팀/HP의 생존·소유 일관성을 보장. **정상 직업 전환을 숙주 사망 이벤트로 취급하지 않아 무료 사망 드롭/재기생 충전을 만들지 않는다** |

| 계약술사 | 계약 상대·심화·관계·금기·위약금·미상환 채무 | 직업 전환은 **계약 파기나 부채 면제 행위가 아님**. 비활성 중 권능 중단/서약 연속성 판정은 서약별 규칙으로 정리해야 하며, 자동 소멸 금지 |
| 군체술사 | 군체 현재 N·Nmax/생존 손실·사용자 제작 전술·기술/매개체 성장 | 비활성 상태에서 군체가 계속 방어하거나 비행하지 않도록 정지/휴면, N 유지/재증식/재활성화 시 서버 수량이 복제되지 않게 처리 |

**모든 직업에 대해:** 비활성 상태의 자연 재생, 타이머 진행, 남겨둔 실체의 실제 월드 존재 여부, 월드가 플레이어 없이 진행될 때의 정책은 추후 직업 생명주기 통합 설계의 세부 결정 사항이다. 사용자 승인 없이 '무제한 무료 유지' 또는 '전환 즉시 영구 상실'로 확정하지 않는다.

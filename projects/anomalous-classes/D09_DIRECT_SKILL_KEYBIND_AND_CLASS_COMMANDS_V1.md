# 《이능 직업 서바이벌》 D09 — 직업별 핵심 조작·직접 시전·키 충돌 계약 v4

> **2026-11-06 사용자 최신 결정 우선:** 액티브는 별도 단축키로 직접 발동하는 A안 유지. `R`은 인형/군체 **무료 표적 지정**, 결계는 **현재 설정 결계의 범위 전개**에 사용. `실 견인`은 표적 지정이 아닌 인형 재배치 액티브. 결계는 **`Z` 종류 변경, `X` 범위 변경, `G` 최근 사용 결계 설정 즉시 재시전**. `G` 홀드/탭 구분과 `Shift+G`는 **최신 사용성 피드백에 따라 기본 조작에서 폐기**. 직업별 물리 키 기능은 서로 다르며 불필요한 공통 명령을 강제하지 않는다.
>
> **승인 경계:** 위 방향·결계 네 핵심 동작·인형/군체 R 표적은 사용자 발언에 직접 근거. 다른 직업의 키 문자, 바뀐 보조 스킬키, 관리키 `M`, 군체 전술 휠 입력 방식, 순환 순서/반경, 최초 기본값 등은 **구현 전 조작 설계 후보**. 기존 확정된 능력·비용·수치·동시 설치/소유권/스킬 수는 전부 그대로. DESIGN ONLY / NOT IMPLEMENTED / NOT PLAYTESTED / MULTIPLAYER NOT TESTED.

## D09 v4 — 기생술사 V 모드 + 숫자 1~0 계승 기술 (사용자 직접 지정, 2026-11-06)

**사용자 최신 결정:** 전투 도중 계승 액티브를 휠에서 고르는 방식은 사용하지 않는다. 기생술사의 **`V`를 계승 기술 입력 모드 ON/OFF 토글**로 쓰고, **모드 ON에서는 키보드 `1,2,3,4,5,6,7,8,9,0`을 각각 계승 수동 기술 1~10의 직접 시전**에 사용한다. OFF에서는 바닐라 `1~9` 핫바 선택 복원. `0`은 바닐라의 10번째 핫바 칸이 아니므로 OFF에서 기존 역할 없음(사용자의 다른 모드 키 충돌 확인 필요).

- ON에서 숫자키 입력은 **핫바 선택 변경 패킷을 보내지 않고 계승 기술만** 발동한다. 현재 들고 있는 무기/도구·오프핸드 유지. 바닐라 마우스 휠을 통한 핫바 선택은 계속 가능하게 두는 **추천안**(사용자가 휠로 계승 기술을 고르라는 뜻이 아님). OFF에서 단축키 작동도 원래대로. 화면 HUD는 `계승 모드 ON/OFF`와 1~0에 지정된 실제 배운 수동 기술/쿨다운을 명확하게 보여준다.
- **`V`에 기존 '계승 직접기 즐겨찾기' 배정 금지**, `G`에 있던 선택 휠은 전투 중 기본 액티브 실행 방식에서 철회. `Z/X/C` 공통 기생 액티브 `침투 고정/생체 수복/본능 각성`은 계속 별개 직접 키 사용. `R` 숙주 이탈/전이는 앞서 논의 중인 조작 후보이며 이번 `V` 변경이 이를 확정하지 않는다.
- **기생 종족 숙련 100 이후 계승한 모든 지원 능력은 계속 무제한 보유**한다. 10개는 현재 한 페이지의 **즉시 시전 물리키 수**지 전체 계승/해금/영구 보유 상한이 아니다. 11개 이상의 직접 발동형이 생기면 별도 페이지/키 재배치 기능이 필요하다. **페이지 전환 물리키·전투 중 전환 UX는 아직 결정하지 않는다.** `M` 정보 메뉴에서 기술 목록과 배치 확인·설정은 통합 메뉴 방향 후보로 검토한다.
- **자동 계승 능력은 V 모드와 무관하게 항상 정상 동작**: 거미 벽 타기/가디언 수중 적응/낙하 완화는 환경형, 엔더맨 투사체 회피는 반응형. 크리퍼 폭발/가디언 광선/엔더맨 수동 순간이동/워든 충격 기술은 지원되는 경우 1~0에 배정 가능한 직접 기술. 현재 숙주 원래 선천 능력, 종족별 기술 조건·스킬/공통 공격 후딜은 보존.
- **입력 안전:** 채팅/GUI·포커스 손실·죽음·차원 이동·직업 변경·로그아웃/재로그에서 숫자키가 눌린 채 남거나 `V`를 바꾼 순간 원치 않는 기술·아이템 전환/이중 발동이 발생하지 않게 한다. 새 접속 시 V를 OFF로 시작하는 것은 **UX 추천값(미승인)**. 계승 기술은 서버의 숙주 상태·해금·현재 종의 원래 능력·쿨다운·대상·팀/피해/소유권 최종 검사 통과 시에만 실행.
- 이 조건은 과거 D09 v3의 **'바닐라 1~9 항상 보호', '기생 V 즐겨찾기 / G 휠'** 설명보다 우선한다. 숫자키 사용 모드는 **기생술사의 V ON이라는 명시 상태에서만** 핫바 키를 대체하므로 다른 직업/일반 플레이를 변경하지 않는다.

**계약술사 조사로 확인된 현 정본:** 1~4위계별 4상대 = **16 계약 상대 초안**, 각 기본 권능 2개 = 총 **32권능 초안**. 다만 32개가 전부 수동 액티브는 아님(예고/표식 축적/조건형 방어 등 자동/상태형 포함), **세부 발동 분류/권능 키가 미확정**. 사용자 확정된 동시 계약 3개 이상과 여러 유효 권능을 유지하면서 별도의 계약술사 입력설계를 검토할 것. 계승 V모드를 계약술사에 자동 복제하지 않는다.

## D09 v3 최신 결정 및 검토 — 2026-11-06

**이 섹션이 이하 v2의 조작 설명보다 우선한다.** 아래 v2의 R 즉시 설치·선택 결계 1기 증폭·H 군체 비행 등의 충돌 부분은 역사적 초기안이다.

**사용자 명시 방향**
- 결계술사: **R 1회 = 조준 위치에 반투명 3D 결계 미리보기**(아직 설치·쿨타임 소모 없음). 미리보기 중 **Z = 결계 종류**, **X = 크기** 변경. **R 2회 = 현재 반투명 위치·종류·크기로 실제 결계 설치**. 설치 실패/취소는 비용·최근 사용 설정 변경 없음.
- 결계술사 **G = 최근 실제 설치에 성공한 종류+크기의 결계를 현재 조준 위치에 즉시 설치**. 이는 미리보기 2단계를 생략할 뿐 별도 무료 시전이 아니고 기존 종류별 쿨다운/동시 설치 한도/3D 범위/서버 검사를 정상 적용. 편집 중인 Z/X 값은 G로 덮어쓰지 않음. 최초 성공 이전 G는 사용 불가.
- **결계 증폭은 선택한 결계 하나가 아니라 시전 순간 이미 설치되어 활성 상태인 자신의 모든 결계에 적용**한다. 방어/압축/격리 고유 효과는 그대로. 타인의 결계·이미 소멸한 결계·미로드 다른 차원·이후 새로 설치한 결계·순간 방벽은 대상 아님. 동일 증폭의 반복 중첩/지난 압축 타격 소급 금지. **기존 한 개 대상 +35%/5초/24초 시험값은 전체 적용 기준으로 아직 밸런스 미검증**이며 임의로 이미 재조정됐다고 주장하지 않는다.
- 인형술사/군체술사 **R은 유효 적 무료 무쿨 표적 지정**, 인형 **실 견인은 Z 액티브 후보**로 독립 유지. 공통 물리키 강제 배치, G 길게 누름·Shift+G·N 강제는 폐기 유지.

**사용자 제안·질문 단계(최종 승인이라고 기록하지 않음)**
- **M 공통 메뉴**: 부하 없이 혼자 다닐 때도 프로필/현재 직업/직업별 레벨·XP·스킬포인트·스킬트리·능력치·장비·정보를 볼 수 있고, 지배체/인형/숙주·BD/결계/계약/군체 등의 소유 시스템을 **같은 메뉴의 직업별 탭**에서 관리. 직업 변경은 기존대로 비전투 중 어디서나 가능.
- 군체술사의 **H는 군체 관리 바로가기 제안**. 별도 중복 메뉴가 아니라 M>군체 관리로 바로 진입. **기존 H=비행 전환 키 후보와 충돌하므로 비행 시작/종료 키는 재배정 미정.** G 빠른 사용자 전술 휠은 단독키 즉시 진입 후보, 관리 화면에 G 공통 배정 금지.
- 기생술사 **R을 숙주에서 자발적으로 나오는 키로 사용 제안**. 인간형에서는 기존 R 기생 시도 후보. 원래 기획의 살아있는 숙주→다른 숙주 직접 기생 이전도 보존: 유효한 다음 숙주를 바라보며 R이면 이전 시도, 별도 대상 없는 R은 취소 가능한 안전한 자발적 이탈 시전으로 분기하는 방안 **미확정**. 숙주 사망 전용 재기생 제한을 자발적 이탈에 강제로 적용하지 않고 위험 중 순간 무적 이탈 불허.
- **결계 수동 해제 기능은 필수 유지**, 그러나 별도 해제키는 사용자 질문으로 아직 미정. 제안: M에서 현재 결계 선택 후 해제, 플레이테스트에서 빠른 해제가 꼭 필요하면 H를 자기 조준 결계 한 개 해제용 선택키로 검토. 해제로 이전 시전 비용/쿨타임이 환급되지 않음.
- 결계 R 미리보기 중 Esc 취소, 상태별 HUD, 미리보기 중 G의 상세 처리·초기 크기/유형·직업별 H/M 배치는 아직 시험/세부 결정 대상.

**6직업 보존:** 정신 침투·정신 과부하(지배체 버프), 인형 3액티브, 기생 3공통 액티브와 숙련100 영구 계승(환경형 자동/공격형 수동), 결계 독립 3종+보조 3종, 계약 동시 3개 이상과 유효 권능 전체, 군체 급습/소모 2액티브와 사용자 전술/상시 엄호 모두 유지.

**검증 상태:** 이 문서는 기획만 수정하며 코드·JAR·클라 키 충돌·멀티플레이는 미검증.

## 1. 키 배치 철학

- **직업별 조작이 우선**이다. 같은 `R`이 모두 같은 시스템을 뜻하지 않는다. 겨냥·지정/전개가 핵심인 직업에 가까운 `R`을 배정하고, 보조 기술·모드 변경·일상 명령은 직업 필요에 맞춰 별도로 배정한다.
- **A안 = 능력을 실제로 직접 사용할 수 있음**이다. 한 공용 액티브 1~6 테이블을 억지로 모든 직업에 적용하는 뜻이 아니다. `N` 등 먼 키를 기본적으로 강제하지 않는다.
- **액티브 vs 기본 명령:** 인형/군체 표적 변경은 무료·무쿨타임 기본 명령. 인형 실 견인/응급 접합/연계 구동은 독립 액티브. 군체 급습/소모만 공격 액티브. 정신 침투·기생은 기존 대상 집중·저항·소유권 규칙을 유지한다.
- 각 직업의 물리 키와 단축 슬롯은 **옵션 → 조작키에서 변경** 가능해야 한다. 서버는 사용한 **안정적 능력 ID/현재 직업/대상**을 확인하고 과거 바인딩 변경으로 다른 능력이 실행되지 않게 한다.
- `WASD`/`Space`/`Shift`/`Ctrl`/`E`/`Q`/`F`/`1~9`/마우스 좌우 클릭/마우스 휠 등 바닐라 생존 조작을 강제로 대체하지 않는다. 전용 매개체 슬롯은 손의 방패·토템·무기와 경쟁하지 않는다.
- **관리·전술 화면**을 열려고 `G`를 누르고 기다리거나 `Shift+G`를 누르게 만들지 않는다. 짧게/길게를 구분해야 하는 신규 게임플레이 조작 자체를 기본 정책에서 폐기한다. 필요한 UI는 독립 키 한 번으로 열어야 하며 키 배치 예외를 강제로 통일하지 않는다.

- 표의 사용자 명시 행은 **동작 방향의 승인**이다. 다른 칸들의 물리키는 **아직 사용자 확정이 아니다**. `R` 표적 지정을 인형 견인/군체 급습으로 오해하거나 결계술사 `R`을 단순 결계 선택으로 되돌리지 않는다.
- `M`은 필요 시 직업 관리·소유물/계약 장부/군체 전체 패널을 여는 **먼 키 후보**다. `G`는 결계의 반복 시전이므로 결계술사 관리창 키가 될 수 없다. `H`는 군체 비행처럼 별도 직접 기능이 필요한 직업의 **선택적 후보**. `N`, `Shift+G`, `G` 길게는 기본 필수 조작이 아니다.
- 계약술사는 동시 계약 3개 이상/유효 권능 전체를 보존하고, 기생술사는 숙련 100으로 영구 계승한 종족 능력 전부를 보존한다. **단축키 수는 능력 보유/해금 상한이 아니다.** 휠/전체 목록의 직접 발동도 제공. 비활성·미해금 키는 다른 능력을 대신 발동시키지 않는다.
- 정신 지배자의 `강제 장악` 독립 액티브, 군체의 `급속 증식` 및 `군집 엄호` 액티브는 폐기 상태 유지. **의식 봉쇄** 및 다른 일부 액티브/수치는 이전 설계의 승인 대기 후보라는 지위를 바꾸지 않는다.

## 3. 결계술사 — 배치 편집과 즉시 재시전의 완전한 구분 (사용자 명시)

### 3.1 직접 동작과 기억

| 키 | 정확한 의미 | 서버 자원/인스턴스 변화 |
|---|---|---|
| `Z` | **현재 결계 종류**를 방어 → 압축 → 격리 → 방어로 순환(**순환 순서 후보**). HUD에서 현재 종류 표시 | 종류 변경만으로는 결계 소환/기존 인스턴스 교체·삭제/쿨다운 소비 없음 |
| `X` | **현재 결계 범위**를 소형 → 중형 → 대형 → 소형으로 순환(**순환 순서 후보**). 기존 반경 3/5/7블록은 전투 기획의 미확정 숫자 | 설정만 변경. 즉시 설치·재료 사용 없음 |
| `R` | **현재 선택한 (종류, 크기)**의 결계를 십자선이 가리키는 유효 위치에 원거리 전개 | 해당 타입 쿨다운·최대 개수·위치·거리·서버 조건을 만족한 경우 정확히 한 개 설치 |
| `G` | **마지막으로 시전에 성공한 (종류, 크기)**를 꺼내 현재 조준 위치에 **즉시 전개**. `Z/X`로 바꿔 놓은 작업 중 설정은 덮지 않음 | `R`과 **똑같은 서버 검증·쿨타임·동시 설치 한도·피해/내구** 적용. 성공 시에만 최근 성공 기록 갱신 |
| `C` / `V` / `B` | 보조 주문 술식탄 / 순간 방벽 / 결계 증폭 (현재 **추천 초기 배치**) | 각 기존 스킬 조건/쿨다운 적용. 결계 증폭은 조준한 현재 소유 결계 또는 관리 화면에서 선택한 1개에만 |
| `M` | 설치된 결계 목록/소유 결계 선택·안전 해제 기능에 접근 (**후보**) | 기존 설치 결계를 무료 회수해 새 쿨다운 없이 재사용하는 행동이 아님 |

**최근 사용 설정**은 '최근에 **성공적으로 설치된 결계의 유형+크기**'만 기록한다. `Z/X`를 눌러 아직 설치하지 않은 값, 실패한 시전, 시전 도중 취소한 값, 단순 선택·증폭 스킬, 마지막 설치 좌표는 덮어쓰지 않는다. `G`는 **예전 좌표에 재설치하는 것이 아니라 현재 조준 위치를 사용한다**. 첫 성공 시전 이전에는 `G`로 임의 기본 결계를 설치하지 않고 '최근 사용한 결계가 없습니다'를 알린다. 마지막 성공 이후 `G`를 다시 성공적으로 사용하면 같은 설정으로 반복 시전 가능하되 각 시전 비용/쿨다운을 정상 적용한다.

- `Z/X` **현재 편집값**과 `G` **최근 성공 값**은 서로 다른 두 상태다. `R` 시전 성공 시 최근 값 갱신. `G` 실패 시 최근 값·편집값 모두 유지. **결계 하나만 전개할 수 있는 모드 교체**는 금지하며 기존대로 방어/압축/격리 각각 독립 월드 인스턴스 유지.
- 예시: **중형 격리**를 `R`로 설치 성공 → `Z/X`로 **대형 압축**을 미리 준비 → `G` 누르면 **중형 격리**가 현재 조준 위치에 설치 시도 → `R` 누르면 여전히 선택 중인 **대형 압축**이 설치 시도. 각 종류별 재사용 대기 중이면 그 입력은 실패하며 재사용 대기를 우회하지 않는다.
- 설치 전 십자선 위치에 **현재 설정 기준 미리보기**를 간결하게 보여주고 바닐라 채굴·전투·우클릭 조작을 막지 않는다. 조작은 `R/G` 눌러 직접 시전을 요청하는 방식이며, 이전 D09 v1의 `Z/X/C` 결계 개별 직접 시전·`R` 결계 선택·`G` 길게·`H` 즉시 해제는 **오래된 설계로 폐기**한다.
- 크기 변경은 실제 범위 및 효과 밀도를 바꾸는 선택이므로 기존 결계 크기 보정(작을수록 집중·넓을수록 커버리지), 원거리 시전 거리·실제 3D 시각/히트박스, 사용 가능한 크기/패시브 제약 모두 유지. 단순 UI 크기 변경이 아니다.
- **마지막 성공 설정의 저장 정책(사망·재접속·직업 전환)**은 서버가 기술 유효성을 최종 판정하도록 하고, 직업 저장 기록에 이전 성공 설정이 유효하게 남으면 보존하는 것을 작업용 후보로 둔다. 로그아웃으로 쿨타임/지속시간·기존 결계 인스턴스가 리셋되는 악용은 금지. 저장이 불명확할 때 설정을 꾸며 즉시 시전하지 않는다.
- 동일 `R/G` 입력의 네트워크 재전송·중복 keydown·서버 응답 지연으로 결계가 복제되면 안 된다. 동일 사건 1회만 결계 전개. 시전 실패는 자원·기존 결계 수·마지막 성공 설정 변경 없이 짧게 사유 표시.

### 3.2 결계 성능·기획 보존

- 방어 결계: 외부 위험/투사체를 실제 경계 내구로 막음. 압축 결계: 범위 내부 적에게 예고 후 압축 피해. 격리 결계: 경계 통과를 내구/저항/시간으로 제한.
- 각 결계는 **독립적으로 설치·유지**된다. 방어+압축+격리 또는 같은 종류의 여러 인스턴스가 가능하되 중첩 악용 방지. 기본 동시 3개·패시브 최대 5개, 반경 3/5/7 등은 **기존 미검증 수치 초안**이다.
- **술식탄/순간 방벽/결계 증폭**은 삭제하지 않고 단지 `C/V/B` 초기 배치 후보로 이동. 선택한 살아 있는 결계 1개 증폭/안전 해제와 설치된 결계 관리가 가능해야 한다.
- `G`는 새 종류/추가 결계 슬롯/빠른 무료 소환 능력을 주지 않는다. 기존 `R`과 동일한 설치 액션의 '최근 세팅 바로쓰기' 입력일 뿐이다.

## 4. 다른 직업: 지휘·지정 액션과 액티브 분리

### 인형술사

- `R`은 바라본 유효 적으로 인형 군단의 **우선 표적 ID만 변경**한다. 무료/무쿨. 공격 쿨타임 초기화, 무료 돌진 피해, 순간이동, 팀/주민 오폭 금지.
- **`Z` 실 견인**은 현재 자신의 **인형 한 기를 안전 경로를 따라 끌어오는** 재배치 액티브(자체 쿨다운). 표적 지정과 완전히 다른 기술. `X` 응급 접합은 실제 재료로 한 기 수리. `C` 연계 구동은 전개한 유효 인형 전체에 잠깐 스탯 버프. 세 스킬의 이전 수치·시전 대상/비용 후보 보존.
- 인형 전개/회수, 동행·대기, 인형제작대 수리/분해는 관리·기본 기능으로 계속 지원. 이 기능들을 무리하게 `R` 또는 새로운 액티브 슬롯으로 합치지 않는다. 회수의 전투 중 피해 무효/쿨타임 리셋 금지.

### 군체술사

- `R` 원격 무료 표적 지정(공격대의 현재 목표 ID만). `Z` 군집 급습과 `X` 군체 소모는 별도 공격 액티브. **`군집 엄호`는 액티브가 아니라 사용자 이름·비율 직접 설정 상시 전술**, 더 많은 스킬을 채우려고 재도입 금지.
- `G`는 **사용자 저장 전술의 빠른 휠**을 단일 입력으로 즉시 열기(**제안**). 휠에서 빠른 선택·비율 직접 수정/일시 적용/저장 기능은 기존 확정대로 유지. 전체 군체 관리창은 별도의 관리 키 후보 `M` 사용 가능. 비행은 별도 `H` **후보**, 이동/승하강·운반군 보호 그대로. 유저가 지정한 0:100/100:0 비율을 자동 고정 전술로 치환하지 않는다.
- 기본 군체 자동 동행·자연 증식·피격 손실·원격 이동·비행대 보호와 공격/엄호 실제 인원 분리는 이전 정본 유지.

### 정신 지배자·기생술사·계약술사

- **정신 지배자:** 직접 `R` 조준 침투와 기존 5액티브(정신 침투/정신 충격/자해 암시/정신 과부하/의식 봉쇄) 연결은 **입력 후보**. 정신 과부하는 내 지배체 강화이며 적 직접 공격 스킬 아님. 자체 `G` 개체 관리·동행/대기/플레이어 피해 허용 설정·지배 해제/전체 관리 경로 유지. 다른 플레이어 직접 지배나 이전 폐기 `강제 장악` 추가 금지.
- **기생술사:** `R` 대상 기생 집중은 **입력 후보**(기본 능력, 공통 액티브 아님); `Z/X/C`는 침투 고정/생체 수복/본능 각성 후보. 현재 숙주 선천 능력 및 숙련 100 뒤 모든 종족 계승, 환경형 자동·조건형 방어 자동·직접 기술 퀵 접근을 유지. 인간형 공격 금지/BD 조건/숙주 사망 후 재기생 제한 그대로.
- **계약술사:** R에 임의 표적 지정/새 액티브를 만들지 않는다. 존재마다 실제 권능 내용이 다른 만큼 **지정한 능력을 직접 시전할 슬롯**을 설정하되 구체 `R` 기능은 후속 입력 검토. 동시 계약 3개 이상/각 존재별 금기·가호 중복 50%/정기 제물 유지비 없음 그대로. 현현·체결·파기는 중요한 비용/조항 확인 및 서버 확정 이후에만 실행. 5/6개 키로 권능 보유 상한을 만들지 않는다.

## 5. 키 충돌·실전 사용성·서버 안전

1. **모드팩 실제 충돌은 미확인.** `R/Z/X/C/V/B/G/M/H`는 편의 중심 초안이며 사용자 클라이언트 `options.txt`와 설치 모드 키 바인딩을 읽고 같은 게임 컨텍스트의 단축/조합 충돌 경고 및 재설정을 검증해야 한다. 외부 모드의 키 설정을 자동으로 빼앗지 않는다. `C/X`는 크리에이티브 툴바 저장/로드와 조합 충돌 시험.
2. 채팅·인벤토리·제작대·계약서·스킬트리·옵션 등 UI가 열려 있을 때 게임플레이용 `R/Z/X/G`가 시전/종류 변경/표적 지정으로 작동하지 않는다. 전술/권능 휠 내부 입력은 그 UI가 명시적으로 처리.
3. `G` 짧게/길게 0.2초 구분과 `Shift+G` 같은 숨은 조합을 기본 조작에서 **완전히 제거**. 각 직업의 G는 한 번 누르면 분명한 동작이 발생해야 하며 결계술사의 G는 **최근 설정 시전**, 관리 화면이 아니다.
4. 재바인딩·직업 변경·사망·차원 이동·포커스 손실·재접속 시 이전 홀드/범위 미리보기/잠재 입력/서버 응답이 다음 직업의 키로 재발동하지 않는다. 현재 선택 결계·최근 사용 설정·계약 권능/기생 계승 즐겨찾기 저장 시 클래스 ID를 구분한다.
5. 타깃/결계 위치/자원·쿨타임/소유권·팀·PvP/원격 지시·군체 개체 수·숙주 데이터·제물 거래 등은 **서버만 최종 변경**. 요청 ID와 행동 종류로 연타·지연 패킷·같은 틱 중복 발동을 방어.
6. **게임 HUD**: 직업별로 실제 배정된 입력과 현재 컨텍스트만 보이며, 결계술사는 종류·크기·시전 가능한 상태·최근 성공 조합을 HUD에서 구분한다. 무관한 빈 슬롯/버튼을 상시 노출하지 않는다. 실제 아트/배치·투명 패널 남발 여부는 별도 시안 검수.
7. **실플레이 재현 필수:** 이동/점프/방패/채굴하면서 인형·군체 R 표적 지정, 인형 Z 견인 단일 인형 실제 경로 확인. 결계 R·G 교차 시전, Z/X 상태 유지, 중형 격리 성공 후 대형 압축 준비 중 G 반복, 첫 G 없음/쿨다운/3개 최대/해제/재접속, 결계 증폭 대상 선택, 멀티 지연/타인 결계 대상 무단 조작 금지.
8. 입력 퀄리티는 기획 문서 검토만으로 검증되지 않는다. 클라이언트 화면·실제 플레이타임·모드팩 키 충돌·멀티/서버 판정·FPS/TPS 확인 전 완료라 하지 않는다.

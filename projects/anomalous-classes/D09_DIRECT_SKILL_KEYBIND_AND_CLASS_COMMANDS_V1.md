# 《이능 직업 서바이벌》 D09 — 직업 능력 조작·키 충돌 계약 v1

> **승인 경계 (2026-11-06):** 사용자 확정은 **A안: 액티브 스킬을 전용 직접 단축키로 시전하고, 기본 명령/관리와 분리**하는 원칙이다. 아래의 개별 키 문자·보조키·휠 제스처·단축 슬롯 수·시전 예외는 **설계 기본안 / 플레이테스트 전**, 사용자 각각의 별도 확정이 아니다. **DESIGN ONLY / CODE NOT IMPLEMENTED / NOT PLAYTESTED / MULTIPLAYER NOT TESTED.**
>
> 대상: 현재 상세 기획한 6직업(정신 지배자·인형술사·기생술사·결계술사·계약술사·군체술사). 7·8번째 직업 중력술사·공명술사는 삭제/사전 확정하지 않는다. 이 문서는 기존 액티브·기본 명령·패시브의 실제 권한/비용/유효 범위를 **변경하지 않고 입력만 연결**한다.

## 1. 최상위 입력 불변조건 (사용자 A안 확정)

1. 전투 액티브는 선택 후 마우스로 또 발동하는 공용 핫바 전환이나 `Alt+1~6` 강제가 아니라 **각 스킬 슬롯의 직접 키를 누르면 해당 능력의 시전 절차가 시작**된다. 조준·지속 집중·범위 미리보기 등 실제 기술 의미에 필요한 예외만 둔다.
2. **기본 명령은 액티브 슬롯/쿨타임/재화를 차지하지 않는다.** 인형·군체의 무쿨 우선 표적, 기생의 기본 침투, 종족 환경 능력, 지배체 관리, 결계 선택·해제, 군체 전술·비행이 해당한다. 명령 요청 연타를 막는 기술적 전송 제한은 게임 쿨타임이 아니다.
3. 바닐라 생존의 좌클릭 공격/파괴, 우클릭 사용·배치·방패, `1~9` 핫바, 휠 핫바, `WASD`, `Space`, `Shift`, `Ctrl`, `E`, `Q`, `F`, `T`, `Tab`은 강제로 변경하지 않는다. **별도 직업 매개체 슬롯**은 기존 주손/보조손을 점유하지 않는다.
4. 모든 단축키는 **설정 → 조작키**에서 바꿀 수 있어야 한다. 직업 변경 시 각 직업의 능력·단축 배치는 해당 직업 고유 저장 기록에서 복구하되, 전용 키의 물리적 바인딩은 클라이언트 설정으로 일관되게 유지한다.
5. 실제 효과의 최종 판정은 서버: 직업·해금·소유권·대상·PvP/팀·비용·재료·쿨다운·지속 행동 상태. 클라 키 입력이 서버 게임 상태를 자동 확정하지 않는다.

## 2. 공통 직접 키 6개 + 기본 명령 3개 (권장 초기값, 변경 가능)

| 입력 ID | 초기 키 | 설명 | 게임 내 규칙 |
|---|---|---|---|
| ability.1 | `Z` | 액티브 1 | 현재 직업의 슬롯 ID에 귀속된 기술, 입력 순간 조준에 따라 판정 |
| ability.2 | `X` | 액티브 2 | 동일 |
| ability.3 | `C` | 액티브 3 | 동일 |

| ability.5 | `B` | 액티브 5 | 동일 |
| ability.6 | `N` | 액티브 6 | 동일 |
| basic.command | `R` | 맥락에 맞는 무료 기본 명령 | 명령을 보유하지 않는 직업에서는 효과 없음/다른 능력 임의 추가 금지 |
| class.manage | `G` 짧게 | 현재 직업 관리·상태 화면 | 바라보는 자신의 개체/대상을 우선하여 맥락을 정할 수 있음 |
| class.quick | `G` 길게 | 빠른 명령/전술/권능·특성 선택 휠 | 서버 변경이 필요하면 실제 확정 동작 한 번에만 요청 |

- **`G` 단/장 누름**은 하나의 물리 키로 판정한다. keydown에 관리창을 바로 열지 않고 keyup으로 짧게 누름을 확정; 길게 누름 임계는 **0.20~0.25초 시험 후보**, 홀드 시 미리보기, 선택 후 놓으면 확정, `Esc` 또는 무선택 해제 시 취소. 채팅/GUI 진입·직업 변경·죽음 시 이전 키 홀드 상태를 반드시 취소한다.
- 단/장 키를 구분하기 어려운 사용자에게는 **관리창/빠른 휠 개별 재바인딩**을 제공한다. `Shift+G` 같은 조합은 선택적 컨텍스트 보조키이며 필수 조작이나 기존 `Shift` 웅크리기 대체가 아니다.
- 6개 단축 슬롯은 **한 번에 즉시 키로 접근하는 기본 영역**이지 총 배운 기술·계약·종족 특성·장착 제한 6개라는 뜻이 아니다. 남은 직접 발동형은 퀵휠/전체 목록에서 사용하고 필요 시 기존 6키에 다시 지정한다. 기생의 모든 영구 계승 특성 및 계약술사의 유효 다중 권능은 삭제/봉인/추가 해금 조건 없이 유지한다.
- 발동형 액티브가 없는 슬롯은 `미지정`으로 두어 키 눌림이 아이템·자원·쿨타임을 소비하지 않는다. 스킬 순서·키 슬롯 변경은 이름이 아니라 **안정적인 능력 ID**를 저장해 지연된 응답/직업 전환으로 다른 능력이 실행되지 않게 한다.

- 특정 기술을 아직 해금하지 않았거나 대상이 없으면 슬롯은 조건에 맞게 비활성 표시하되 다른 기술을 암묵적으로 대신 발동시키지 않는다.

### 4.1 정신 지배자

- `Z` 정신 침투는 **길게 누르는 집중** 후보: 유효 목표·거리/시야·정신력을 서버가 판정, 키 해제/대상 소실은 중단 처리. 성공 전에는 장악 소유권을 확정하지 않는다.
- `G`로 바라본 자신의 지배체를 관리할 때 개체 동행/대기·공격 허용 ON/OFF·해제·상태를 보존한다. 대상이 없으면 **전체 관리 화면**. 서버 PvP 설정이 OFF일 때 해로운 플레이어 피해를 전부 억제한다. 타인의 지배체를 관리할 수 없다.
- 지배체 사망/주인 사망/언로드 시 기존 상태·저장·재기생 등 **각 정본의 생명주기 정책**을 변경하지 않는다.

### 4.2 인형술사

- 무료 표적 지정은 이동·공격 AI의 우선 대상을 바꾸는 것이지 즉시 타격·원거리 순간이동·공격 타이머 리셋이 아니다.
- `Z` 실 견인은 실제 안전 경로/지형·크기·충돌을 검사, `X` 응급 접합은 **기존 소재 원자 소모**, `C` 연계 구동은 현재 전개 인형 전체에 단일 버프. 기존 인형제작대·3m 모델·부품/손상 저장과 상호작용을 그대로 둔다.
- 위험한 인형 회수는 긴 입력·선택 확인 등으로 실수 방지; 순간 회수로 전투 피해를 무효화하지 않는다.

### 4.3 기생술사

- 기본 `R` 침투는 **액티브 3종과 별도**이며 영구 BD 소비/스킬 슬롯 요구가 없다. 침투 성공 후 실제 숙주 모델/카메라/조작으로 이동하고 숙주 1기만 직접 조종한다.
- **현재 숙주의 선천 행동**과 **숙련도 100 달성 뒤 다른 숙주에서도 영구 계승된 기술**을 모두 유지한다. 벽 타기·수중 적응 등 환경형은 자동, 투사체 회피 등 조건형은 서버 자동, 수동 공격/순간이동만 직접 발동형으로 `V/B/N/H` 또는 퀵휠에서 선택한다.
- 퀵 슬롯 수가 **계승 기술 개수 제한이 되어서는 안 된다.** 사용 가능한 모든 수동 계승 능력에 휠 접근을 남긴다. 인간형에서 금지된 계승 공격, 사망 후 재기생 잠금, BD 미달·저항·외부 엔티티 어댑터의 제약을 우회하지 않는다.
- 자발적 숙주 이탈/교체는 의도 확인·안전 시전이 필요하며 `R` 입력 하나로 전투 중 숙주를 즉시 버리는 행동을 만들지 않는다.

### 4.4 결계술사

- 결계 직접키를 누른 동안 **시전 대상 위치/범위 미리보기**, 유효한 상태에서 **키를 떼어 설치/발동**하는 조작을 우선 시험한다. 짧게 누르면 빠르게, 길게 누르면 조준 후 시전. `Esc`·GUI 전환·대상 불가로 취소; 자원/쿨다운은 서버 유효 시전 확정 때만 처리.
- `Z/X/C` 결계 각각 독립 유지·수명·동시 설치 한도를 보존. `V/B/N`은 본래 보조 주문. `R` 선택 뒤 `N` 증폭은 선택한 **자기 결계 한 개**만; 대상 없으면 조용히 오사용하지 않도록 안내.
- `H` 결계 해제는 불필요한 아군 보호 손실을 막는 적절한 확인/짧은 누름 방지 동작을 사용. 해제 후 재설치에 새 비용/쿨다운이 적용되는 기존 규칙 보존.

### 4.5 계약술사

- 슬롯 `Z/X/C/V/B/N`은 **계약 번호에 고정되지 않은 사용자 지정 권능 ID 바로가기**다. 계약이 3개를 넘더라도 유효한 계약·권능 수를 축소하지 않으며 매핑하지 않은 권능은 `G` 휠/장부에서 사용 가능.
- 계약서를 새로 체결/심화/파기하거나 고가 현현에 제물을 지불하는 행위는 **확인 화면과 서버 원자 소모**가 반드시 필요하다. 일반 권능은 직접키 한 번으로 발동 가능하되 권능 자체가 원래 요구하는 대상·대가를 유지한다.
- 다중 계약 제물 소프트캡, 최강 가호 100% + 나머지 가호 50% 규칙, 정기 제물 유지비 없음, 존재별 금기/관계 등 이미 확정된 계약 경제 규칙 보존. 단축키로 계약을 임의 재정렬하여 저가 비용을 반복 적용하면 안 된다.

### 4.6 군체술사

- `R`은 타깃 등록만 수행; 손실/소환/무료 피해가 발생하지 않음. `Z` 급습은 **현재 공격대가 이동한 실제 위치**에서, `X` 소모는 **가용 공격대 일부**에서만 소비. 엄호/운반 군체를 몰래 끌어와 지불하지 않는다.
- `G` 짧게 관리/길게 퀵휠은 이전 **사용자 이름 지정/비율 자유 설정/빠른 편집** 정본을 그대로 사용. 고정 `자동·공격 우선·균형·엄호 우선` 프리셋을 재도입하지 않는다. 비행 중에도 휠 사용과 실제 재배치가 가능하되 순간 화살 차단/군체 텔레포트 금지.
- `H` 비행은 충분한 운반 군체를 먼저 실제 예약하고 물리적 상승·하강. 전투/비행 중 수량 부족 시 안전하게 하강하고 부활/재접속/차원 변경으로 중복 생성하지 않는다.

## 5. 키 충돌·입력 상태와 UI/UX 정책

1. **바닐라 보호:** 생존 `E` 인벤토리, `F` 오프핸드 교체, `Q` 드롭, `1~9` 핫바, 좌우 클릭, 휠·`Shift`·`Ctrl`을 덮어쓰지 않는다. 기본 `C`/`X`는 크리에이티브 저장·로드 툴바 조합에도 쓰이므로 **특히 크리에이티브 테스트**를 한다.
2. **모드팩 충돌:** 현재 외부 모드팩의 실제 `options.txt` / 모드별 키 바인드·인게임 설정은 이번 문서 작업에서 검수되지 않았다. 어떤 외부 모드 키도 임의 변경하거나 입력을 가로채지 않는다. 설정 화면에서 동일 키/수정키/맥락이 겹치면 명확히 경고하고 해당 바인딩으로 이동할 수 있게 한다. 기본 `Z/X/C/V/B/N/R/G/H`는 확정된 무충돌 세트라고 주장하지 않는다.
3. **맥락:** 게임 플레이 중에만 전투 키 동작, 채팅·상자·제작대·스킬 트리·설정·계약서·다른 GUI가 열리면 기본 게임 조작 이벤트로 스킬을 발동하지 않는다. 키 단·장 누름은 클라에서 상태 관리하되, 게임 상태의 실제 변경은 서버. 키 충돌이 있을 때 두 스킬/바닐라 행동이 동시에 실행되어서는 안 된다.
4. **입력 수명:** 키를 누른 채 창 포커스가 사라지거나 ESC·사망·차원 이동·직업 변경·서버 연결 해제가 발생하면 채널링·미리보기·퀵휠·예약된 발동을 취소, 키를 다시 누르기 전까지 복구되지 않는다. 실수로 자동 시전하거나 재료를 소모하면 실패.
5. **실전 조작:** 짧은 키다운/키업, 길게 눌러 범위 미리보기, 홀드 주문의 이탈/피격 중단, 빠른 반복 입력/중복 네트워크 응답을 구분한다. 본래 자동 패시브/AI 기능은 버튼을 누르지 않아도 계속 동작한다.
6. **HUD 시안 조건:** 실제 해금된 액티브 슬롯/직접키/쿨다운/비용/전제만 간결하게 표시. 무료 기본 명령은 액티브로 위장하지 않고, `G`/관리 화면 도움말에 표시. 타깃 부족·BD 미달·전개 슬롯 부족·엄호 0%·실제 군체 이동 중 등은 **짧고 이해 가능한 플레이어용 피드백**을 준다. 시각 디자인(폰트·색·위치·아트)은 시안 단계에서 별도 검수.
7. **설정 영속화:** 플레이어별 키 재바인딩, 직업별 슬롯-능력 ID 매핑, 계약/계승 휠 즐겨찾기, 사용자 군체 전술을 각 역할에 맞는 소유권과 수명으로 저장; 월드/서버 변경에도 바인딩과 상태가 혼동되지 않는다. 전투 중에 키 설정을 바꾸거나 직업을 교체하면 이전 입력/예약을 무효화한다.
8. **권한·중복 방지:** 서버는 요청 번호/발동 ID 및 현재 직업 ID와 대상 ID로 중복 요청·지연 응답을 판별. 최종 자원/손상·전개·피해·현현·계약·군체 수량은 서버에서 한 번만 갱신. PvP 서버 설정 OFF/아군/타 소유 객체 위반을 키·휠로 우회하지 못한다.

## 6. 구현/테스트 게이트

- **대상 기술 기능 보존:** 정신 지배자 5후보·인형 3후보·기생 3후보+모든 계승·결계 6후보·계약 자유 권능·군체 공격2개의 직접 바인딩. *기술이 후보였다는 기존 상태 유지*.
- **바닐라 충돌:** 평상시 채굴·건축·보조손 방패·아이템 드롭·스크롤·전투, 크리에이티브 `C/X` 조합, 채팅·인벤토리/제작대·JEI 창 입력 시 스킬/기본 명령 오발동 없음.
- **타 모드:** 실제 설치된 모드팩의 키 충돌 목록 생성, 사용자 재바인딩 후 재검사. 게임 내 테스트 없이 “충돌 없음” 판정 금지.
- **수명/멀티:** 다른 플레이어·유실 개체·언로드·차원 이동·창 포커스·사망·같은 틱 중복·반복 키·핑 지연/응답 역전·오프라인 상태, 정신 침투·기생·군체 비행 취소/재접속 시 자원·체력·N·소유권 무결성.
- **플레이 감각:** 단축키 6개가 손에 닿는지, 결계 정확 시전이 빠른지, `G` 탭/홀드 오인식 여부, 높은 계약 수/여러 계승 기술에서도 휠이 전투를 지나치게 방해하지 않는지, 1인칭 군체/인형 HUD 가림을 실측. 불편하면 기존 능력 삭제가 아니라 키 재배치·인터랙션 보완.
- **버전:** 현재 외부 모드팩 확인본은 **Minecraft 1.21.1 / NeoForge 21.1.244 / Java 21**. 기술 구현 시 [NeoForge 1.21.1 Key Mappings 문서](https://docs.neoforged.net/docs/1.21.1/misc/keymappings/)의 클라이언트 `RegisterKeyMappingsEvent`, 게임 중/GUI 컨텍스트, `KeyModifier` 등 적합성을 확인. 이것은 구현 방향 검증일 뿐 현 시점 코드 존재 증명이 아니다.
- **검증 상태:** USER CONFIRMED = A안 입력 선택. DESIGN PROPOSAL = 위 키·동작 매핑. CODE REVIEWED = 기획서 대조만(모드 소스 구현 검수 아님). NOT IMPLEMENTED, NOT BUILT, NOT PLAYTESTED, MULTIPLAYER NOT TESTED.

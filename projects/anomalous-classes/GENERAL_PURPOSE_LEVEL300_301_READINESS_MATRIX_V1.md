# 《이능 직업 서바이벌》 Lv300~301 범용 전력 산술·실플레이 준비 매트릭스 v1

> 2026-11-05 / 6직업 상세 기획은 유지, 중력술사·공명술사 보류, 숫자는 **전부 미승인 시험식**이다.
> **최신 설계 원칙:** [범용 전력 중심·자연스러운 상성 허용 v3](./GENERAL_PURPOSE_ENDGAME_BALANCE_POLICY_V3.md).
> 이번 문서는 [Lv300 상세 수치 역산](./LEVEL_300_SIX_CLASS_ENDGAME_BALANCE_BENCHMARK_V1.md)의 후보식을 **정해진 레벨에 정확히 대입**하고, 범용 밸런스에 필요한 **게임 안에서 실제로 가동되는 전체 전력**의 누락을 기록한다. 특정 보스별 수치 평준화는 하지 않는다.

## 1. 기준과 계산 한계

- 공통 레벨 L=100/200/300/301, x=L−1, s=√L−1. RPG XP와 바닐라 XP 분리, 캐릭터 레벨 상한 없음.
- 비교 조건: 동일 레벨, 동일 단계의 바닐라 방어구·무기, 해당 직업에 실제로 구할 수 있는 동급 매개체; **고위 숙주·BD·계약·인형 제작 재료·지배체 확보는 레벨만으로 주지 않는다**. 캐릭터별 보유 장비 및 준비 비용을 별도 기재한다.
- 기본 HP는 **실제 방어력·회피·엄호·결계 내구·숙주 HP·가호·부활·원본 보스%HP 피해를 포함하지 않는다.** DPS는 실제 게임에 구현된 AI/시전/피격 확인 전 확정 불가.
- 레벨301은 1SP/레벨·1레벨0SP인 **미확정 지급 가정에서 누적300SP를 편의상 비교**하는 값. 레벨300부터 이미 종결급이어야 한다. 스킬 해금에 SP가 쓰인다면 패시브300랭크 전부를 Lv301까지 얻지 못할 수도 있다.

### Lv300→301을 무리하게 강력한 돌파로 만들지 않는다

본체 기본 HP 변화는 대략 정신 +0.14, 인형 +0.07, 인간형 기생 +0.04, 결계 +0.07, 계약 +0.08, 군체 +0.10HP에 불과하다. **1레벨 차이 자체는 작은 변화**이며 SP/랭크 투자도 실제 효율에 비례하도록 설계한다. '301부터 종결급'이 아니라 '300에서 종결급, 301은 산술상 완성 비교가 편한 레벨'이다.

## 5. 실제 구현 전 해결해야 하는 최소 불확실성

1. **RPG 1SP/레벨 + 빠른 XP 공급**은 여전히 추천/미확정. Lv100/200/300 도달 플레이 시간 및 액티브 SP 비용 결정 전 '풀 패시브+풀 액티브'를 동시에 가정 금지.
2. **기생 숙주**의 외부 모드 entity AI/animation/input 지원, **정신 지배** 후 원본 Boss AI/Phase, **인형** 자율 AI/파손, **군체** 서버 N 보존과 소수 Proxy 타격은 설계 기술 게이트. 전투 데이터와 호환 API 없이 실제 결과를 꾸미지 않는다.
3. **결계 레벨 위력 ×3.95**는 원래 시안 대비 큰 변화이므로 클래스별 교전이 아니라 **범용 일반 적 단일/다수**에서 사용감 확인 후 승인 판단. 자동 확정 금지.
4. **강력한 기생 숙주/4위계 계약/불가해 매개체/고급 제작 인형/고위 지배체 확보 시간**은 나중에 실게임에서 실제 획득 가능성을 측정한다. 총 레벨만으로 자동 지급 금지.
5. 외부 모드팩 **전용 서버 부팅 성공은 직업 모드의 구동 성공을 뜻하지 않는다**. 이 프로젝트에 아직 게임 본체 source/Mod ID가 없음. 설치 도구·런타임 QA 및 게임 구현 계획은 별도 기록.

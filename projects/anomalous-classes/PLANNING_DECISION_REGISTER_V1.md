## A. 이미 정해져 있으며 변경하지 않는 상위 요구

- 마인크래프트 본래 서바이벌과 바닐라 XP(인챈트/수선)는 유지. **별도 RPG XP**로 무제한 캐릭터 레벨/직업별 자동 성장/스킬 포인트 운영.
- **Lv300은 이미 종결급**, Lv301은 미확정 1SP 모델의 계산 편의일 뿐 필수 첫 종결 레벨이 아님. 각 직업의 **본체+고유 능력+실사용 부하/숙주/결계/계약/군체 전력**을 평가.
- 직업 고유 특색과 자연스러운 성능·상성 차이 허용; 특수 보스마다 동일 승률·DPS로 강제 평준화하지 않음.
- 8직업 목록을 유지, 현재 **6직업 상세 기획 집중**. 중력/공명의 상세 보류는 삭제를 뜻하지 않음.
- 외부 9개 기능 모드+6개 라이브러리, Minecraft 1.21.1 / NeoForge 21.1.244 / Java 21 **모드팩 최소 서버 부팅 검증 완료**. 이능 직업 게임 본체·클라·실전·멀티플레이는 아직 검증 전.
- 현재 6직업의 확정 메커니즘을 줄이거나 구형 초안으로 되돌리지 않는다. 기존 스킬 랭크·매개체·제단/제물·BD·제작·군체 실체/전술은 보존하며 미확정 계수는 보완한다.

## C. 사용자의 개별 결정을 기다리지 않고 자율 처리할 것

1. 클래스 6종의 기초 능력·액티브·패시브·장비·자원·해금/돌파를 **정본 1개씩**으로 일관되게 통합(기존 확정 기능 삭제 금지).
2. 검증 전 숫자는 '제안'으로 유지하며 계산 검증과 범용 적 1기/6기/서바이벌 하루의 **전체 전력 및 비용/실사용 편차** 비교. 보스별 강제 평준화 금지.
3. 입력이 확정되면 화면이 표시할 필수 상태/실패 메시지/선택 실수 방지·단축키 변경 규칙을 **기능 명세로 자동 도출**. 색상/레이아웃/모델 최종 선택은 시안 단계.
4. 서버 권한 소유권·팀 피해·중복 XP/아이템·사망/재접속·오프라인/언로드·데이터 복구·장비 착탈 상태 전이를 공통 규칙과 직업별 예외로 정리.
5. 외부 모드의 지원되지 않은 숙주 기술·보스 AI·결계 판정·군체 피격은 가능하다고 가정하지 않고 실패/제약 안내와 **실제 기술검증 게이트** 제시. 핵심 직업 판타지를 임의 축소하지 않음.
6. XP·BD·제물·수리·전리품 루프의 무한 생산·손실·소프트락 반례, Lv1/25/100/200/300/301 및 레벨 무한 성장의 정수 오버플로/실제 클라·멀티 테스트 기준 검토.
7. 현재 프로젝트에 남은 '로더 미선정', '구형 3액티브', '이전 XP 미확정' 등 역사 기록과 현재 정본이 혼동되지 않도록 **승인/후보/폐기 상태 표**를 제공하고 이전 내용을 안전하게 보존.
8. 통합 기획 완료 후에만 **시안**(직업 선택→스킬 트리→실플레이 HUD→고유 능력/관리/모델) 제작. 과거 HTML이나 실패한 생성 이미지는 디자인 승인본으로 취급하지 않음.

## D01 회의 안건 — 직업 변경 허용 여부 (미결정)

- **A. 세계/캐릭터마다 최초 선택 직업 고정**: 직업 정체성 뚜렷, 직업 갈아타기 악용 적지만 실수·취향 변화에 불편. 서버 관리자의 테스트/복구 명령은 일반 플레이 규칙과 별개.
- **B. 조건부 변경 허용, 직업별 성장/소유 상태 분리 보존**: 동일 월드에서 다른 직업을 즐기되 고레벨 즉시 갈아타기/부하 중복 소환을 막는 별도 상태 관리 필요. 실제 비용·쿨다운은 후속 선택.
- **C. 자유 변경, RPG 레벨 공용 유지**: 진입 장벽 낮지만 한 직업의 성장만으로 다른 직업 종결 전력을 즉시 활용할 수 있어 직업 고유 BD/제단/인형 경제와 결합할 때 불균형 발생. 직업별 고유 축은 자동 지급하지 않음.

**현재 A/B/C 모두 미선택**. 사용자가 답한 뒤 관련 규칙을 통합하되, 확인받지 않은 손실·강제 리셋·권한 정책을 멋대로 정하지 않는다.

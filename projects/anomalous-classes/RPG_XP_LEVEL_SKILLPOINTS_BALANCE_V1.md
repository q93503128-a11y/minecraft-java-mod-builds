## 1. 확정: 경험치는 완전히 다른 사용처

| 항목 | 용도/귀속 | 금지되는 동작 |
|---|---|---|
| **Minecraft 바닐라 XP/경험치 바** | 인챈트·수선 등 **기존 Minecraft의 원래 획득·소비 규칙** | 이능 스킬 포인트 구매/직업 레벨업으로 바닐라 XP 소모, RPG 레벨 업으로 바닐라 XP 임의 변환·강제 지급, 인챈트 때문에 RPG 레벨 손실 |
| **게임 고유 RPG XP/직업 캐릭터 레벨** | 서버 소유자 상태의 **공통 무제한 레벨**, 레벨 상승 시 직업별 기본 능력치와 스킬 포인트 지급 | 바닐라 인챈트 XP로 직접 환전, 수선으로 소모, 외부 RPG 모드의 별도 XP·레벨/스킬트리 추가 |
| **기존 고유 직업 진행** | 기생의 **BD/종별 숙련**, 계약의 관계·제물/심화, 인형 재료/부품·군체의 실체 수량처럼 이미 정한 **각 직업의 의미 있는 고유 상태** | 별도 공통 XP 화폐로 억지 통합/폐기, 바닐라 XP처럼 자동 인챈트 소모, 외부 모드 새 성장 시스템으로 대체 |

- 원래 몬스터가 주는 **바닐라 XP 오브/인챈트 경험치**는 원래 경로로 처리; 별도의 서버 RPG XP는 **적법한 활동/처치의 단일 사건을 평가해 지급**한다. 동일한 처치가 원래의 바닐라 보상과 RPG 성장에 각각 기여할 수는 있지만, **한 풀에서 빼서 다른 풀로 옮기는 환율은 없다**.
- **두 경험치의 수급 루프·보상량은 각각 독립 튜닝**, 동시에 얻는 것이 자동으로 똑같은 숫자를 받는다는 뜻이 아니다. `In Control!` 등 외부 모드의 '경험치 조절' 기능이 바닐라 오브를 건드리는지/기타 처치 보상을 건드리는지 확인하고, **우리 RPG 보상을 중복 발급하지 않는다**.
- HUD: 바닐라 XP 바/레벨 숫자는 원래 의미를 유지. **멀티 Locator Bar (경험치 바 표식)**와 충돌하지 않도록 **RPG 레벨은 별도 간결 표시/성장 화면**으로. 사용자별 **JEI Ctrl+O** 표시/숨김 개인 선택 유지.
- XP 지급/레벨/포인트/저장은 **서버 권위**, 소환체·지배체·숙주·결계·군체 등 플레이어를 대신해 피해를 준 시스템도 올바르게 소유자에게 기여를 귀속. 동료가 막타를 뺏었다고 0 XP가 되는 협동 불공정과 AFK 원격 XP 농장 두 가지 모두 방지.

## 2. 레벨 상한 없음 + 기술 랭크는 유한: 별개 문제

- **캐릭터 레벨 상한 없음**: 레벨이 계속 오르면 최소한 해당 직업의 자동 기본 성장도 계속 가능해야 한다. XP 요구치가 지나치게 커져 사실상 몇 년간 1레벨도 못 올리는 구조는 체감상 상한으로 작동하므로 금지.
- **일반 패시브/액티브의 유한 랭크**는 유지될 수 있다. 모든 패시브를 완성했더라도 레벨이 계속 오르는 것을 막지 않는다.
- **현재 미승인 스킬 트리 초안 총량 비교**:
  - 정신 지배자 **270패시브**(+ 다른 액티브 해금 4포인트 가상 시 **총 274**)
  - 인형술사 **290패시브**(액티브 해금 포인트 별도 정책 미정)
  - 기생술사 **285패시브**(액티브 해금 포인트 별도 정책 미정)
  - 결계술사 **300패시브**(기본 결계·보조술은 포인트 0에서도 사용)
  - 계약술사 **270패시브**, 군체술사 **270패시브**(기본 기술·엄호 전술/원격 표적은 포인트 요구하지 않음)
- 총 랭크 숫자가 다르므로 **동일 레벨에 6직업이 완벽히 같은 랭크 수/전투력을 가져야 할 필요는 없다**. 하지만 기생이 285, 결계가300이라서 스킬포인트를 더 주는 식으로 공통 지급 규칙을 혼동시키지는 않는다. 실제 유효성·해금/반복 클릭 부담을 비교.

**P1 조건부 추천 이유:** 사용자 의견대로 **레벨업 속도를 충분히 빠르게 설정한다는 조건에서** 새 재화·보너스 지급 구간 없이 스킬 선택이 꾸준히 이어진다. 초반 능력은 랭크0부터 쓸 수 있어 포인트가 없어도 재미가 가능. 과거 '3포인트 확정'은 **현재 이 프로젝트 정본과 확인한 대화 기록에서 확인되지 않았음**(다른 프로젝트의 규칙을 자동 가져오지 않음). **중요: 특정 액티브에 실제 1포인트 해금 비용을 정한 적은 없으므로 표의 'Lv271에 전체 완료'는 패시브만 구매한다는 비교용**. 액티브 비용·전직 변경/회수·스킬 초기화·포인트 지급이 끝나는 조건은 미결.

**패시브 완료 뒤 포인트 정책은 사용자 미결정:**
- **A. 소수 반복 숙련에 계속 투자** (정신 지배자의 기존 SKILL_TREE.md에서 추천했던 안): 레벨을 올릴 때마다 클릭·보너스 계속 제공, 장기 성장 체감 가능하지만 **무한 수치 곱/유지비 음수/영구 CC/소환물 무제한** 위험. 별도 새 UI/재화는 만들지 않음.
- **B. 더 이상 투자할 비반복 노드가 없으면 포인트 지급을 멈추고 자동 직업 스탯 성장만 계속**: 가장 단순, 무한 미사용 포인트 쌓임/의미 없는 클릭 방지. **이 문서의 구현 용이성 추천**이지만 **기존 정신 지배자 A 추천을 사용자 승인 없이 폐기·덮어쓰지 않음**.
- 남은 랭크가 적고 한번에 1레벨보다 큰 상승/경험치 보상이 들어와도 서버는 **실제 유효 스킬 구매량 이내에서** 잉여 포인트 누락/중복 지급·무한 표시 문제를 피할 것. 이 정책을 정하기 전까지 저장 데이터 모델을 포인트 영구 초과 제한으로 강제하지 않는다.
- 270~300회 클릭 요구가 부담이면 UI에서 **기존 노드에 1·5·10랭크 연속 투자/긴 클릭 같은 빠른 입력**을 검토하되 서버가 포인트/효과/해금 이벤트를 원자 검증. 신규 '전문화 서브시스템'을 만들 이유는 없음.

## 2.1 최신 사용자 의견 — '3P였나? 1P라도 빠른 레벨업이면 괜찮다' (2026-11-05)

- **기록 확인:** 현재 `anomalous-classes` 프로젝트의 확정된 레벨업당 **3SP** 원문은 확인되지 않았다. 앞서 만든 **1SP/레벨은 추천 비교안**이며 사용자 승인으로 확정된 사실이 아니었다.
- **이번 사용자 조건부 허용:** **레벨업당 1SP도 괜찮지만 그럴 경우 레벨업 속도는 꽤 빨라야 한다**. 무거운 270~300랭크를 1P/레벨 기준으로 설계하면 끝까지 투자 가능한 레벨은 **패시브만 약 Lv271~301**(시작 Lv1 0P, 기타 포인트 지출·부가 지급·선행조건 제외). **3P/레벨**이라면 패시브만 약 Lv91~101. 단 스킬 랭크 총량 자체도 미검증 시안.
- **현 추천 방향은 `1SP + 초반/중반 빠른 레벨업`**, 그러나 정확한 XP 요구 함수/레벨업당 XP 보상·SP 지급값을 **최종 확정하지 않는다**. 유저가 과거의 3P 규칙에 더 큰 가치를 둔다면 3P와 느린 레벨 속도를 같은 **'실제 획득 SP/플레이 시간'** 기준으로 비교할 수 있다.
- **성장 속도의 기준:** `획득 SP/시간 = 레벨업 수/시간 × 레벨당 SP`. 동일하게 시간당 12포인트를 목표로 할 경우 1P는 시간당 12레벨, 3P는 시간당 4레벨. 이것은 **비교 예시일 뿐 실제 목표치는 아님**.
- **중요한 2차 효과:** 1P/레벨 방식에서 레벨을 자주 올리면 **레벨당 자동 증가하는 체력/지배력/인형 HP/결계 효율/군체 최대수도 더 빠르게 증가**한다. 단순히 XP 보상만 3배 늘리면 전체 PvE 밸런스가 붕괴할 수 있으므로 **같은 플레이 시간/장비/모드 보스** 기준으로 자동 성장 공식과 몬스터 위험을 함께 검토한다. 무제한 레벨 정체성·직업 간 상이한 성장 곡선은 유지.
- **초반 체감 검사:** 스킬 패시브 5/10랭크 돌파를 얻기까지 걸리는 실시간, 첫 밤/철 장비/첫 외부 던전·보스 경험, Lv25/Lv100/Lv300의 실제 플레이시간 및 레벨별 UI 알림 빈도 측정. XP 보상을 확정하기 전 **첫날 자주 레벨업하는 것이 실제로 재미를 늘리는지** 문서 시뮬레이션과 게임 플레이로 판단한다.

## 3. XP 곡선 3개 수치 시안 — 단위는 가상, 실제 플레이타임 목표 아님

`L >= 1` 정수, `x=L-1`일 때 `XP_to_next(L)`은 **레벨 L에서 L+1로 넘어가려면 필요한 RPG XP**. 바닐라 경험치 레벨 곡선과 별개이며 세 식 모두 **미승인 예시**.

- **A 선형 증가 (빠른 장기 성장):** `ceil(70 + 16x)`
- **B 완만한 초선형 (1차 추천):** `ceil(70 + 16x + 1.5*x^(3/2))`
- **C 강한 후반 증가:** `ceil(70 + 16x + 0.16*x^2)`

| 현 레벨 L | A 다음레벨 필요 XP | B 다음레벨 필요 XP | C 다음레벨 필요 XP |
|---:|---:|---:|---:|
| **1** | 70 | 70 | 70 |
| **25** | 454 | 631 | 547 |
| **100** | 1,654 | 3,132 | 3,223 |
| **300** | 4,854 | 12,610 | 19,159 |
| **500** | 8,054 | 24,775 | 47,895 |
| **1,000** | 16,054 | 63,418 | 175,735 |

**누적 XP(레벨1에서 레벨 25/100/500 진입 시까지; 정확한 정수 올림 합계)**:
- A: Lv25 **6,096**, Lv100 **84,546**, Lv500 **2,022,946**
- B: Lv25 **7,713**, Lv100 **142,369**, Lv500 **5,352,205**
- C: Lv25 **6,797**, Lv100 **135,553**, Lv500 **8,629,990**

**해석:**
- 같은 레벨 보상률이라면 A는 빠른 후반 레벨링, C는 높은 레벨 진입 부담 급상승, B는 그 중간. 단 **상위 몹·보스가 주는 RPG XP를 얼마나 올리는지 미정**이므로 숫자만으로 'Lv500까지 50시간' 같은 주장은 불가능.
- **B는 최초 비교 후보일 뿐**, 1/25/100/500 레벨을 실제로 몇 시간에 달성할지/직업별 경험치 수급 차이/소환물 공동 기여/외부 보스 반복 위험을 시험하고 선택한다. **1P/레벨을 선택한다면 레벨업 속도를 이 문서의 A/B/C 비교만으로 보장할 수 없다**. 실제 몹·던전·보스 RPG XP 획득량과 다음 레벨 필요 XP를 함께 결정해, 초반 짧은 간격의 레벨업과 중후반 의미 있는 성장 속도를 시험해야 한다.

## 4. 자동 능력치: 기존 6직업이 같은 사람이 되어서는 안 됨

**현재 과거 개별 문서의 가상 수식을 지우지 않고, 실제 차이가 어느 정도인지 비교한다.** 인형술사의 매개체 버프, 기생술사 숙주 기본 스탯/BD, 정신 지배자의 유지 정신력, 계약술사 4위계 가호, 군체 N은 전부 서로 다른 성장 원천이다. **공통 스탯 하나로 치환하지 않음.**

### 기존 개별 문서에 실제로 있던 HP 성장 가상식(동일 공통 규칙으로 미승인)

| 클래스 | 기존 문서 시험 수식 | Lv1 | Lv25 | Lv100 | Lv500 |
|---|---|---:|---:|---:|---:|
| 정신 지배자 | `HP=20+0.12*(L-1)` | 20.00 | 22.88 | 31.88 | 79.88 |
| 인형술사 | `HP=20+0.06*(L-1)` | 20.00 | 21.44 | 25.94 | 49.94 |
| 결계술사 | `HP=20+0.045*(L-1)` | 20.00 | 21.08 | 24.455 | 42.455 |

**발견:** 현재 시험 수식만 따르면 Lv500 정신 지배자 본체 HP가 결계술사의 **약 1.88배**다. 이것이 판타지/실제 전투상 의도적인 강점인지는 승인되지 않았다. '정신 지배자는 원래 지배체가 핵심이고 결계술사는 직접 결계로 방어' 같은 독자성이 있으므로, 이 격차를 정본으로 자동 확정하거나 수식을 임의로 동일하게 만들지 말고 **동일 장비/외부 보스에서 TTK·피격·유지비/장비 합성·협동 기여를 검토**해야 한다.

### 다른 직업의 성장 합성 규칙(개별 정본 우선)

- **정신 지배자:** 레벨→최대 정신력/정신력 회복/유지비·동시 지배 한도, 높은 위협 보스의 개별 유지 난도는 성장 후에도 의미 있게. 단순 본체 HP만 높다고 전투 우위 단정 금지.
- **인형술사:** 레벨→자체 HP + 실제 인형 HP/공격 강화, **이미 제작한 인형의 소재·크기·스킬·조종틀 효과를 중복 곱하지 않는다**. 기본 공격속도는 자동 레벨업 대상이 아니고 인형 구성 선택의 가치 보존.
- **기생술사:** 공통 레벨/BD/종별 숙련/숙주 기본 HP·능력/패시브·공생 핵을 각각 한 번 합성. **미기생 인간형의 약한 정체성**을 고레벨에서도 유지. 모든 클래스에 적용하는 본체 HP 식을 기생에게 강제로 적용하지 않음.
- **결계술사:** 본체 HP는 가상식이 있지만 결계 실제 방호/압축/격리·다중 설치/시전은 별개. 기존 `BarrierPowerFactor(L)=1+0.025*(sqrt(L)-1)` 후보로 Lv1 1.000 / Lv25 1.100 / Lv100 1.225 / Lv500 약 1.534. 보스 광역/돌진/방벽 파괴 실제 판정이 체감 전투력을 결정.
- **계약술사:** `기본 본체 스탯→상위 존재 가호→관계/심화→이중계약 높은 가호100%+낮은 가호50%→패시브→매개체`를 확정된 우선순위/기존 문서 범위에서 각각 한 번씩; **Lv500의 +스탯/가호 복제·무한 직접 피해** 방지. 계약 상대별 차이를 공식 하나로 제거하지 않음.
- **군체술사:** 총 N/현재 실제 역할 분할·최대 Nmax(레벨 자동 성장), 생물당 공격/내구·자연 증식과 스킬/군체 핵의 보정; **엄호는 상시 직접 설정한 전술, 액티브는 급습/소모**, 개체 길이 약 0.2블록. 수량과 개체 질적 강화는 **직업 고유 성장**으로 유지.
- 모든 직업은 레벨 무제한과 스탯 오버플로 보호를 갖되 **공격력/내구/투사체 상호작용, 실활동 소환물 수 및 TPS**는 실제 기술 게이트를 통과해야 한다.

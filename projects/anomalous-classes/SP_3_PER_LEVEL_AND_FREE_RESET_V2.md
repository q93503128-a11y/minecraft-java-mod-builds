## 2. 비용 커브 (세부 랭크 가격은 설계 기본안, 아직 실플레이 전)

- 각 노드 랭크 **1~8은 랭크당 1SP**, **9~16은 2SP**, **17~24는 3SP**를 기본으로 삼는다. 25 이상은 기본 4SP이되 실제 큰 분기·핵심 돌파에 중요도에 따른 추가 비용을 붙인다.
- 원래 270~300랭크의 차이로 생기는 비용 차이는 **17랭크 이후에만** 작은 정수 프리미엄으로 균등 배분해, 직업별 총합을 정확히 900SP로 맞춘다. 높은 랭크가 이전보다 싸지는 **역전 비용**은 없음. 가장 기본적인 노드 첫 랭크는 항상 1SP.
- 비용 중요도 `impact=1` 일반 편의/입문, `2` 실전 전문화, `3` 핵심·대형 돌파(인형 추가 슬롯/결계 추가 전개/기생 위기 생존/군체 주력 성능 등). **이 중요도는 새 패시브 능력이나 선행 레벨 하드게이트가 아니라 비용 모델 전용 메타데이터**다.
- 최종 개별 랭크당 비용은 JSON의 `classes[].nodes[].rank_costs`를 **유일 데이터 원본**으로 읽는다. UI가 가격을 동적으로 추측/자체 산출하지 않는다. 같은 랭크 강화라도 랭크·핵심 노드 별로 고정 가격을 보여주고, '다음 투자' 시 서버가 현행 가격/잔여 SP/상한 검증.
- 임의 새 선행 스킬/랭크 잠금·기존 액티브 구매 SP/직업 전체 스킬 모듈은 추가하지 않는다. **기본 직업 주력 기술은 처음부터 가능**, 기존 계약 체결/BD100/숙주 종 숙련/인형 실재/시련·매개체 제작 등은 별개의 **원래 정상 성장**으로 접근. 계약16상대 고유 자동패시브48개는 계약 보상, SP트리 노드가 아님.
- SP는 해당 직업의 영구 레벨에 연결. 바닐라 XP와 분리, 직업 교체 시 다른 직업에 옮겨 쓰기 불가. Lv301 이후 **3SP/레벨 계속 지급**(무제한 레벨 성장 결정 보존)하지만 **모든 유한 트리를 완료했다면 여분 SP로 보관**. 새 끝없는 반복 노드/새 재화/레벨 스탯 무한 폭주를 억지로 만들지 않는다. UI는 모두 완료 상태를 보여주고 추가 클릭을 요구하지 않음.

## 3. 초기화는 완전 무료 + 전투 중만 잠금

- **비전투 중 세계 어디에서든** 현재 활성 직업 패시브 트리의 투자 랭크를 전부 0으로 돌리고 **소비 SP 전량 환불**. XP·레벨·자동 기본 스탯/숙주 BD·종 숙련·계약/가호·제물/관계·인형 부품/재료·군체 실제 N/전술 등의 **영구 비SP 상태는 변경·초기화하지 않는다**. 다른 직업의 SP/투자에는 영향 없음.
- 일부 투자를 취소하고 싶을 때도 전체 초기화가 무료이므로 1개씩 환불 강요하지 않는다. **서버에서 전량 롤백/전량 재계산**으로 잔여 SP를 원자적으로 갱신. 초기화를 게임 내 신규 제물/화폐로 판매하지 않는다.
- **전투 중 스킬트리 초기화 불가**, 교전이 끝나면 바로 가능(전투 판정 D02와 공용). 실시간 전투에서 순간적으로 최대 HP/방어·동시 인형 슬롯/결계 설치수/기생 사망 전이 충전/계약의 피해상한을 바꿔 무료 치유·피해 취소·슬롯 복제·리스크 회피하는 문제를 차단. 서버는 UI 탭 전환 중에도 유효 전투 상태를 재판정.
- 스탯 상한 변화로 생명력이 오를 때 **비율 보존·상한 클램프**하고, SP 초기화만으로 잃은 개체가 살아나거나 실제 사용한 자원/재료/쿨다운/보스 패턴이 초기화되지 않음. 투자 제거로 동시 유지 수가 줄면 **실제 초과 개체를 죽이거나 재료로 만들지 않고** 안전한 일반 회수/휴면·시간상태 정책에 따라 직업별 정리. 안전한 정리 실패 시 변경을 거절하여 소유 기록 유실을 피함.
- 사용자 투자 노동 완화: 900SP를 1개씩 900번 클릭하게 하지 않음. 노드 당 **'한 랭크/다음 돌파까지/최대 투자 가능'**를 UI 작업 흐름으로 검토. 한 번의 서버 원자 처리가 여러 랭크를 적용할 때 투자 합산 SP 정확히 검사.
- 초기화를 무료로 제공한다는 뜻은 **현재 진행 중인 계약 시련/거래·전리품·종 숙련/BD·원본 몹 AI·자원 채무를 모두 지운다는 뜻이 아님**.

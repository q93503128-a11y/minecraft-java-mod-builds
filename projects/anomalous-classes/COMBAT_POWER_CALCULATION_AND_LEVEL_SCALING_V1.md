## 1. 계산의 공통 정의

- `L` = **현재 활성 직업**의 RPG 레벨, 정수 L≥1, 상한 없음. `x=L-1`, `s=√L-1`. 바닐라 경험치/마법부여 레벨과 분리. 직업을 바꾸면 **그 직업의** 경험치·스킬랭크·자동 성장 값을 쓴다.
- `HP`는 Minecraft 체력 단위, 하트 1칸=2HP. 각 기술의 표기 HP는 **실제 피해 처리 전의 공격 원시값**. 적 방어·피해 면역/캡/위상/피격 판정·조준/이동 실패는 그대로 적용한다.
- 계산의 기본 단계: `직업 상태/계약·숙주·인형·결계/군체 실제 존재 확인 → 기술/엔티티 원래 기본값 → 해당 직업의 레벨 보정 1회 → 해당 기술에 실제로 투자한 패시브 보정 1회 → 현재 1개 매개체 등급 보정 1회 → 해당 계약/재료/시련의 고유 보정 1회 → 서버 이벤트 대상·방어·사거리·중복 판정 → 실제 피해/회복/자원 지불`.
- **`물리 무기 보너스`와 `이능 권능 피해`는 별도 계열**. 소환된 인형/지배체의 원본 공격을 다시 `계약술사 권능`으로 처리하거나, 바닐라 무기 전체 공격에 권능 ×성장계수를 무작정 중첩하지 않는다.
- 한 매개체는 전용 슬롯에서 **등급 한 개**만 활성. 규격~이형 효과는 기존 후보값 유지, 불가해 수치는 2026-11-06 확정값 사용. 모든 직업의 최고 등급을 똑같은 '스탯 전체 ×1.4'로 처리하면 오류.
- `방어/회복/치명 보호`는 원시 공격 피해와 다른 **effect tag**로 계산하며, 상시 %감경·지속시간·쿨다운·희귀 제물·CC는 단순 권능 공격 성장 배율이 자동으로 확대/감소시키지 않는다.
- 반사/추가 피해·자동 패시브가 새 유효 공격 이벤트를 재귀적으로 발생시켜 **동일 사건 무한 트리거**하지 못하게 `sourceEventId`, `ownerId`, `effectFamily`, `targetId`를 서버에서 관리. '한 타격 중복 적용 없음'은 PvP와 외부 보스 원본 위상에 모두 적용.

## 3. 계약술사 `PactPower(L)` 세부 시뮬레이션 명세

### 3.1 레벨 배율과 정확한 적용 대상

```text
x = L - 1
s = sqrt(L) - 1

PactPower(L) = 1.0 + 0.005*x + 0.020*s       // 이번 작업 신규 시험안
RankDirect(r) = 1.0 + 0.005*r                 // 권능 응축 기존 후보, 0<=r<=30
FocusDirect(g) = [1.00,1.05,1.10,1.15,1.20,1.40][g]  // 0:없음, 5:불가해
RawActiveDamage =
    DataBaseHp
  * PactPower(L)
  * RankDirect(rank)
  * FocusDirect(equippedGrade)
  * EffectiveContractPowerFactor   // 계약별 관계·심화/조항의 해당 효과, 중복 없이 한 번

RawPassiveExtraDamage =
    PassiveBaseHp
  * PactPower(L)
  * PassiveOwnConditionalBonus     // 실제 명시된 조건이 충족될 때만
// 고유 패시브 직접 추가타에는 '액티브 전용' 권능 응축/증표 위력은 곱하지 않는다.
// 패시브가 다시 패시브를 부르지 못하고, 내부재사용은 계약/기술/대상별 서버 소유.
```

- **전체 권능에 일괄 x2.821 금지**: 직접 권능/고유 자동 패시브에서 **실제 HP로 표시된 공격형 피해(`DIRECT_DAMAGE`, `PASSIVE_DAMAGE`)**에만 `PactPower(L)` 적용. 짧은 범위 상태이상/이동/위치 이동/탐험/적 경고/계약 금기/패시브 발동 조건은 레벨에 따라 무조건 확대되지 않음.
- **직접 고정량 방호/흡수 한도(`FLAT_SHIELD_CAP`, `ABSORB_HP`)**는 **`PactPower(L)` 1회로 체급 유지**. 예: 이사엘 `수호의 빛` 첫 피해 35% 경감의 **최대 10HP 상한**은 Lv300에 28.21HP까지 증가(비율35%는 그대로); 오르마스 `대륙의 피부` 기본 흡수 55HP는 Lv300 **155.18HP**(장비·추가 가호 전). **% 감경 자체·지속시간·중첩 금지·쿨타임은 확대되지 않음**.
- **%회복·%흡혈·HP비례 비용·단발 구원(`PERCENT_HEAL`, `PERCENT_LIFESTEAL`, `HP_SACRIFICE`, `FATE_SAVE`)**은 기존의 실제 HP·단위시간/시전 상한에 따라 계산. `PactPower`나 증표+40%를 %회복률에 추가로 곱하여 무한 회복/공짜 대가를 만들지 않음. 라키엘의 구원은 불사의 토템 우선, 금 블록2개 초기 비용, 180초 내부재사용 기본안 보존.
- **패시브형 %방어/이동/넉백 저항(`DAMAGE_REDUCTION`, `MOVE_BONUS`, `KNOCKBACK`), 상태이상 시간/광역 CC, 특별 현현**은 이 레벨 피해 배율의 적용 대상이 아님. 레벨에 따른 생존 강화는 *상시 본체 HP 증가·가호 및 실제 방어 특성*이 담당.
- **추가 HP 여파가 전체 무기 공격 가호에 다시 증폭되지는 않는다.** 본체 실제 무기 공격의 바닐라 공격 쿨다운/물리 피해 계산 뒤 계약이 제공하는 **직접 공격 가호 증가분만** 결합, 직업 액티브 피해 계산과 분리.
- 계약 2개 이상에서도 `PactPower`를 현재 레벨 기준으로 한 번만 구하고 **개별 권능마다 한 번만** 적용한다. 기존 가호 증감/심화는 스탯별 계약별 관계를 반영한 뒤 가장 큰 증가분100%+나머지50%를 합성, 육신각인·무력동화·증표를 *그 증가분*에 한 번 적용. **고유 권능 자체를 50%로 깎지 않음**.
- 일반 액티브의 원래 재사용 대기는 `BaseCooldown*(1-0.003*술식순환랭크)` (최대9% 단축) 후보. 원래 현현·위약금·특별 구원/채무기한은 기존 예외 유지. 레벨 300이라고 쿨타임이 자동 0이 되지 않음.

**Lv300 × 불가해 +40% × 권능 응축30랭크 (+15%) 시의 이론 단일 직접기 원시값**: 이사엘 낙인 `7×2.8214×1.40×1.15≈31.80HP`, 3위계 판결 `28×…≈127.19HP`, 오르마스 분쇄 `60×…≈272.55HP`. **관계·심화 추가/적방어·원본 보스 피해상한/명중·범위는 제외**. 이 숫자에 무기 가호+120%나 동일 `Focus` +40%를 한 번 더 곱하면 오류.

### 3.3 일반 단독 계약 vs 복수 계약의 경계

- 이사엘·우르겐 등 1위계도 Lv300에 `PactPower`로 직접 권능이 성장해 **처음 계약이 완전히 무용해지지 않는다**. 다만 동일 전문 분야 4위계의 기본 권능 6~7배+본체 가호 격차/현현·전투 범위가 명확히 더 강함.
- 2/3위계 계약의 접근은 **정상 획득·시련·장비·심화**를 통해 확보. Lv300=4위계 필수 획득/3중계약 필수도 아니지만 **Lv300 정상 플레이어가 실제 가진 2/3위계로도 종결급 전투가 가능한지**는 실게임 측정 게이트.
- 4위계 3중은 세 번째 계약 `기본 소모 제물×4` 등 지수 비용·별도 제단/시련·금기/위약금이 있으므로 기본 30시간 진행 가정에서 제외. 어렵게 획득한 매우 높은 전력은 정상 보상이며, 능력 수치만 보고 계약 개수 하드캡·추가 제물 유지비 신설 금지.

## 4. 군체술사 레벨 1~500 연속 보간(기존 마일스톤을 잇는 신규 시뮬레이션안)

기존 문서의 `Lv1=16기, Lv25=48기, Lv100=80기, Lv300=112기, Lv500=128기` 후보 및 전병력 풀공격 기본 DPS `Lv1≈5, Lv25≈10, Lv100≈22, Lv300=44, Lv500≈62HP/s`를 **성장 관측용 앵커**로 사용한다. 이는 모든 고급 장비 자동 지급/주인 무한 무료 방어의 근거가 아니다.

```text
anchors = [
    (L:1,   Nmax:16,  fullAttackBaseDps:5),
    (L:25,  Nmax:48,  fullAttackBaseDps:10),
    (L:100, Nmax:80,  fullAttackBaseDps:22),
    (L:300, Nmax:112, fullAttackBaseDps:44),
    (L:500, Nmax:128, fullAttackBaseDps:62)
]
1<=L<=500: adjacent anchors를 구간 선형 보간
Nmax(L)=floor(interpolated Nmax); 공격Dps는 보간 실수 유지
L>500: Nmax(L)=128+floor(2*(sqrt(L)-sqrt(500)))   // 증가하지만 물리 AI N개는 아님
L>500: fullAttackBaseDps(L)=62+0.09*(L-500)         // 무한 레벨의 질적 성장

validN = attackN+guardN+liftN+regroupN  // alive N와 같음
NominalAttackDps =
    fullAttackBaseDps(L)
  * sqrt(attackN / max(1, Nmax(L)))
  * (1 + 0.006*날카로운턱랭크)
  * FocusSwarmAttackFactor(grade)
effectiveDps = NominalAttackDps * observedParticipationHitFactor  // 관측값! 기본 100% 단정 금지
```

- 공격0이면 공격 DPS0. 엄호·운반에 예약한 개체가 공격에도 참여한 것으로 세지 않는다. 전술 분담 UI의 사용자 저장 비율을 무단 수정/이탈하지 않는다.
- Lv300 **N=112 전원 공격**·날카로운 턱30랭크+18%·불가해 공격+40%인 경우 `44×1.18×1.40=72.688HP/s`는 **100% 도달/유효 공격 가정의 명목값**. 공격84·엄호28이면 약 `62.95`, 공격52·엄호28·비행32면 약 `49.53HP/s` 명목값. 실제 군체 소실·재증식·공격 참여 시간/자연 지형은 별도.
- 원래 `급습/소모` 두 액티브, 자동 증식·사용자 전술의 상시 엄호, 개체 소실·비행 안전하강은 변경 없음. `fullAttackBaseDps`는 **수치 모델의 결과**로서 몬스터 스폰/타격 쿨타임과 중복 곱해 `N × DPS`를 또 하지 않는다.
- 서버 물리 액터 수/타격 proxy 및 TPS는 실제 테스트로 결정. 극고레벨 N의 수치가 무한히 성장한다는 이유로 무한 개별 AI를 소환하지 않는다.

## 5. 6직업 비교 시 '실제 준비 비용'을 포함한 계산 규칙

- **정신 지배:** `Pmax, regen, T별 유지비, 보유수, 실제 각 몹의 유효 공격 참여율` 모두 집계. 지배체의 원본 전투 피해가 약속된 만큼 나오지 않으면 단순 본체 피해 ×공통배율로 덮지 않는다. 기본 저T 몹은 고레벨에 거의 유지비0이 가능.
- **인형:** `최대 전개 슬롯`은 실제 소지·전개·생존·타격 인형수와 다름. `전투 DPS=Σ(현재 전개 살아 있는 인형 i의 실제 적중 기반 유효 HP 감소/sec) + 플레이어 기여`. 제작/수리 재료 및 회수 후 복귀 시간도 기록. 이론 6기 모두 100% 딜로 "너프 필요" 결론 금지.
- **기생:** 숙주1기 원본 스탯·고유 공격×레벨 성장×BD×종별 숙련×투자 패시브×장비(불가해 숙주 공격/HP만 +40%)를 한 번씩 합성. 기본 약한 인간형 유지. 원본 보스 특수기/기동 어댑터 지원 성공 전 '자유롭게 조종 가능'이라고 전력 산술에 포함 금지.
- **결계:** 압축 피해는 실제 타격된 **각 파동**만 집계. 같은 적에 겹친 압축을 동시 폭발처럼 중복 계산 금지. 전체 자기 결계 대상 증폭은 사용자 승인 방향으로, **시전 당시 유효한 모든 자기 결계에 1회** 적용. 새로운 강한 레벨 위력×3.95를 실제 최종값으로 처리하지 않는다.
- **계약:** 1계약 초반부터 가호+유용한 직접기+고유 자동 패시브, 2~3위계 정상 획득/희귀 4위계 별도. 복수 계약의 가호/권능·심화·금기·제물 비용을 버리지 않는다. 모든 액티브를 동시에 사용할 수 있는 조건/쿨타임·입력/캐릭터 상태도 실측.
- **군체:** 공격·엄호·비행·재집결이 같은 N을 공유. 무료 일시 엄호/공격 자동 할당 X. 실제 전투 후 소실량과 자연 증식 회복시간을 고려해야 명목 군체 DPS를 실효로 환산 가능.

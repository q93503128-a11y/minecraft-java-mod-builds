# 《이능 직업 서바이벌》 PvP 서버 설정 연동 및 소유권 판정 v1

> 2026-11-06 사용자 결정 D06: "PvP는 A안. 서버 PvP 설정을 따르도록 하자." 본 문서는 설계 명세이며 실제 코딩·런타임/멀티 테스트는 수행하지 않았다.

## 1. 확정된 게임 규칙

- 서버의 실효 PvP 허용 상태를 이능 공격·방어·일반 해로운 상태효과에도 적용한다.
- PvP가 꺼진 서버: 플레이어 사이의 직접/간접 이능 피해, 밀치기·속박·기절·상태이상 등 해로운 효과는 적용하지 않는다. 몬스터 대상 PvE 공격, 자기 방어/버프는 정상 작동한다.
- PvP가 켜진 서버: 서로 적대 관계인 플레이어 사이에는 유효한 이능 공격과 일반 CC를 허용한다. 단, 팀/보호구역/소유자 관계 및 기존 인형의 아군 쌍방 오폭 차단을 적용한다.
- 인형·지배 생명체·기생 숙주·군체·결계·계약 권능 등 플레이어가 소유한 효과도 동일한 서버 PvP 판정을 따른다.
- **PvP 허용이 다른 플레이어를 정신 지배하거나 기생하여 카메라·이동·입력·인벤토리·채팅 제어권을 빼앗는 기능까지 허용한다는 뜻은 아니다.** 이 기능은 이번 결정의 범위 밖이며 현재 허용된 대상/기능으로 구현하지 않는다.
- 기본 바닐라 PvP 설정을 존중하며 새 이능 PvP 서버 설정은 필수로 추가하지 않는다.

## 2. 서버 권위 세부 정책 — 구현 명세

1. 피해 사건에서 최종 소유자 플레이어, 직접 행위자, 투사체·폭발·지속 피해의 원천, 대상, 현재 소유권/팀 관계, 서버 PvP 상태를 함께 판정한다. 클라이언트의 PvP 가능 여부 주장은 신뢰하지 않는다.
2. 근접, 투사체, 광역/폭발, 지속피해, 반사 피해, 유해 상태효과, 강제 이동/경직 등 모든 간접 피해 경로를 같은 정책으로 검사한다. 직업 스킬의 PvP 피해만 막고 소환체의 별도 공격으로 우회하는 일 금지.
3. 플레이어와 적 몬스터가 같은 공격 범위에 있을 때 PvP=false인 경우 **플레이어만 가해 효과를 차단**하고 몬스터는 정상 공격할 수 있다.
4. PvP=true라도 같은 팀 우호 인형/플레이어/소환물 및 타인 소유 몬스터의 허용 여부를 기존 [ALLY_RELATIONS.md](./ALLY_RELATIONS.md)·개별 피해 토글·서버 보호 규칙에 따라 판정한다. 다른 플레이어 소유 길들인 몹 전부 공격 가능이라고 자동 해석하지 않는다.
5. 관계 변경, 서버 PvP 설정 변경, 지연탄·지속장판, 로그인/로그아웃 뒤 공격 등에서 **실제 효과 적용 시점의 서버 권한**을 검사한다. 유효한 피해가 아닌 차단 이벤트는 PvP 기여·RPG XP·계약 조항 위반을 허위 발생시키지 않는다.
6. 서버 DamageSource나 외부 모드 스킬을 완전히 분석하지 못하면 이미 처리 가능하다고 주장하지 않는다. 별도 어댑터와 실제 멀티 테스트가 필요한 구현 경계로 표시한다.

## 3. 검증할 사례 — 현재 테스트 미실행

| 상황 | 설계상 기대 결과 |
| --- | --- |
| PvP=false, 폭발·결계·군체가 적 플레이어와 몹 동시 피격 | 몹 정상 피해, 플레이어 유해 피해·CC 차단 |
| PvP=false, 소유 인형/지배체/기생 숙주가 다른 플레이어 공격 | 플레이어 피해·해로운 효과 차단 |
| PvP=false, 공격 반사·자가 보호 기술 | 자가 보호는 작동, 다른 플레이어 반사 피해는 차단 |
| PvP=true, 적대 플레이어 vs 이능 공격/일반 CC | 다른 권한 규칙 통과 시 사용 가능 |
| PvP=true, 같은 팀 인형/플레이어 | 기존 아군 판정/우호적 피해 차단 유지 |
| PvP=true, 타 플레이어 자체를 지배/기생하려는 입력 | 이번 PvP 승인만으로 허용되지 않음 |
| 팀 변경/서버 설정 변경/소유자 오프라인/지연형 투사체 | 실제 서버 판정과 원래 소유권으로 처리, 무효 XP·이중 피해 없음 |

기존 확정 범위는 유지한다. PvP 전용 계수, 플레이어 대상으로 허용할 강한 제어 효과의 세부 한계, 외부 모드 호환은 후속 기술 테스트/밸런스 영역이다. 다음 사용자 결정은 [결정 장부](./PLANNING_DECISION_REGISTER_V1.md)의 D07 계약술사 동시 활성 계약 수다.

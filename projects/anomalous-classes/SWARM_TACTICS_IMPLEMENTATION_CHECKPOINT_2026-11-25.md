# 군체술사 — 서버 전술 저장·빠른 전환 구현 체크포인트

2026-11-25. 본 프로젝트는 Minecraft Java 1.21.1 / NeoForge 21.1.244 / Java 21, 브랜치 main의 기존 6직업 게임이다. 이번 작업은 군체 전술 통합 기능의 서버 처리와 사용 가능한 초기 조작 화면이며, **6직업 통합 플레이테스트는 아직 진행하지 않는다**.

## 1. 구현 상태

- 저장된 모든 전술은 **사용자가 직접 만든 데이터**다. 개발자 제공 기본 전술, 숨은 균형 전술, 강제 군체 분담 비율 없음. 저장되지 않은 상태에서는 기본 N·재결집·생존 동작은 기존처럼 유지한다.
- 기존 String->percent 저장 포맷을 UUID(id)·이름·공격Percent(0–100)·화면 순서로 점진적으로 마이그레이션한다. 구형 NBT의 이름/비율/활성 전술을 불러와 다음 저장부터 UUID를 기록한다. SaveData version=3.
- 서버 권위 작업: CREATE, UPDATE/RENAME, SELECT, DELETE, MOVE, TEMPORARY, RESTORE. 플레이어당 최대 8개, 이름 1~24글자(공백만/제어문자 금지), 공격% 0~100. 전술 ID로 삭제/수정하여 동일한 표시 이름도 서로 다른 전술로 보존.
- 전술 수정마다 `tacticRevision`을 증가시키고 요청 버전이 다르면 거부하고 서버 최신 스냅샷 반환. 신뢰하지 않는 패킷의 임의 전술ID, 범위 밖 비율, 다른 직업 플레이어 요청은 서버에서 거부.
- 일시 적용은 현재 공격 목표 비율만 변경하며 저장 전술의 내용은 덮어쓰지 않는다. 복원은 선택 저장 전술의 비율로 되돌린다. 세션 종료 시 일시 값은 지운다.
- 목표 공격/엄호 분담은 기존 `SwarmSavedData.State.advance()`가 비행대 `lift`와 재결집 중인 군체를 제외해 계산하고, 기존 물리 역할 이동 예산을 거쳐 적용한다. 군체 N/유효 피격·급습·군체 소모 계산은 변경하지 않는다.

## 2. UI/입력 통합

- **U**: 기존 공통 직업 관리키를 누르면 군체술사만 새 전술 관리 화면을 연다. M → 프로필 → 직업 관리 경로도 동일한 화면으로 이어진다.
- **G**: 기존 결계술사 반복 입력 키를 군체술사에 한해서 **빠른 전술 화면** 호출로 재사용한다. 별도 중복 G 바인딩 없음; 결계술사·계약술사의 기존 G 기능은 유지.
- **H**: 앞선 군체 비행 토글 그대로, 이번 변경에서 사용하지 않음.
- 두 화면은 별도 전술 시스템이 아니며 모두 동일한 서버 스냅샷과 액션 프로토콜 사용. 전술 목록에서 이름/공격 비율 표시, 저장·비율 수정·삭제·순서 재배치·일시 적용/복원 지원. 퀵 화면 목록은 클릭한 저장 전술을 서버에서 승인받은 후 닫힌다.
- UI는 프로젝트 기존 `MenuUi` 텍스처/버튼과 한글·영어 문구를 재사용. AI가 새 시각 규칙을 임의로 늘리지 않음.

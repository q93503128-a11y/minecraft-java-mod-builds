# 군체술사: 첫 실제 충돌 기반 서버 구현 체크포인트

2026-11-22 / 범위: G1·G2를 실제로 시험할 수 있는 첫 서버 구현 수직 슬라이스. 현재 프로젝트의 NeoForge 1.21.1 + Java 21 유지. 타 직업과 기존 성장 체계/저장 호환성을 변경하지 않는다.

## 이번 코드

- SwarmSavedData: 서버 소유자별 N, 공격·엄호·비행·재집결 보존식. 최초 이름 지정 전술 0개, 사용자 직접 이름·공격 비율 0~100 저장·선택·삭제. 전술 8개 상한.
- SwarmRules: 문서의 레벨1/25/100/500 후보 개체 수(16/48/80/128), 초당 자동 회복 후보, 피격 손실, 역할 분배. **수치는 실플레이 미확정 조정값**.
- SwarmNodeEntity: 각 역할에 최대 1개 **실제 살아있는 server collision proxy**만 만들고 별도 조직체 N은 엔티티 N개와 분리. 노드 noSave, 서버 재접속에서 영속 개체 복제 없음. 기존 몹의 실제 타격/화살을 맞으면 그 역할의 논리 N 감소.
- 좀비·스켈레톤의 실제 공격 target goal을, 소유자 가까이에 있고 유효한 군체 노드에 한해서 추가. 일반 몹 전부·외부 모드 적·보스의 AI를 지원한다고 주장하지 않음.
- 기본 군체 추적·사용자 설정 전술에 따른 공격·엄호·재결집 노드. 기본 전술을 저장/주입하지 않는다. 공격 0%는 공격 노드를 만들지 않고, 엄호 0%는 엄호 노드를 만들지 않는다.
- 주인 및 주인 소유 인형·정신지배 개체·길들인 동물·아군 공격은 차단하도록 필터. Swarm 공격으로 처치한 적도 기존 RPG XP 소유자 판정에 통합.
- Codex가 교체할 비최종 모델 대신, **충돌 위치를 게임 안에서 확인하기 위한 바닐라 소형 생물 샘플 렌더만** 등록. UI/3D 모델/애니메이션/VFX/사운드의 최종 디자인은 본 구현에 포함되지 않는다.
- 초기 사용 입출력은 `/swarm` 및 `/swarm tactic save <attackPercent> <name>`, `/swarm tactic select <name>`, `/swarm tactic delete <name>`, `/swarm tactic list`로 테스트 가능하게 하며, 완성된 군체 관리 GUI가 아니다.

## 아직 구현하지 않은 것

- 원격 표적 지정, 군집 급습·군체 소모 액티브, 실제 대규모 개체 단위 렌더/죽음 모션, 비행·비행대 분담·통제 착륙, 군체 기술트리 효과·매개체 능력, 즉시 목표/실제 물리 재배치 정밀 동기화, 게임 내 전술 관리·퀵휠 UI.
- 실제 Minecraft 좀비 AI 타격/스켈레톤 화살 목표·충돌 및 아군 화살 통과 여부는 **코드만으로 통과 판정 불가**. 전술 비율 변경 중 먼 공격대의 복귀는 아직 cluster proxy 이동 모델 수준이므로 G3/G7 전체 통과 아님.
- 클라이언트/멀티플레이 FPS·TPS·조작감 미측정. 확인 후 확장.

## 최초 실제 테스트 순서

1. 새/기존 월드에서 `/class`로 군체술사 선택. `/swarm`으로 기본 16/16, 전술 미설정 확인.
2. `/swarm tactic save 0 생존` 실행 후 수 초에 걸쳐 재집결군→엄호군 역할 전환 확인. `/summon minecraft:zombie ~3 ~ ~` 호출해 실제 군집 대상을 공격하는지 확인.
3. `/summon minecraft:skeleton ~6 ~ ~` 호출하고 유효 화살이 군집 실체와 충돌해 수량 감소하는지 확인. 회피한 화살은 플레이어가 정상적으로 맞아야 함.
4. `/swarm tactic save 100 돌격` 실행, 엄호군 0인지와 공격대가 좀비를 실제 공격하는지 확인.
5. 공격 개체 수가 줄어들 때 /swarm에 표시되는 N이 감소하고 자연히 회복되는지, 재접속·직업 변경에서 복제가 없는지 확인.

- **결계술사**: 방어·압축·격리 3종과 술식탄/순간 방벽/증폭 등의 서버 기능. 3D 전개 미리보기/본격 이펙트는 Codex 시각 단계 보류.

- **군체술사**: 실체 충돌 기반 공격·엄호·비행 역할 N 보존, 급습·군체 소모, 스킬트리 주요 랭크/5등급 매개체, 이름·비율 직접 제작하는 8개 전술/U 관리/G 퀵화면. [군체 전술 체크포인트](./SWARM_TACTICS_IMPLEMENTATION_CHECKPOINT_2026-11-25.md). 현재 G 화면은 전투 중 이동 유지형 논블로킹 휠이 아니라 일반 Screen.

5. *핵심 기능이 실제 부족하면* 같은 채팅에서 의미 있는 단위로 구현하고 위험에 맞춰 코드/검사/빌드 수행. 기능 삭제·no-op·가짜 빌드·CI 반복 금지. 미확정 수치/조건은 임의 정본화하지 않는다.
6. 6직업의 핵심 구현·감사가 모두 끝난 뒤 **사용자 통합 Minecraft 플레이테스트를 한 번에** 실시. 결과 수정 후 **Codex 정식 모델/애니메이션/VFX/사운드/핵심 UI 시각 디자인**. 지금은 사용자에게 개별 JAR 플레이테스트 요청 금지.
7. 검증 상태는 코드 리뷰/자동 TESTED/BUILD VERIFIED/JAR PRODUCED/CLIENT PLAYTESTED/MULTIPLAYER TESTED를 실제 실행에 맞춰 구분.

# 이능 직업 서바이벌 - 매개체 고정 배치 제작법 및 관리 UI 설계

2026-11-12 사용자 결정: 6직업 매개체 5개 등급, 총 30종의 제작법을 재료 위치가 의미 있는 Shaped Recipe로 변경한다. 직업 관리 UI에 실제 제작대와 같은 3×3 제작법을 표시한다.

## 우선순위와 정본

- 재료 및 소모 개수: TIER1_TO_4_FOCUS_CRAFTING_CANON_2026-11-06.md 와 TIER5_FOCUS_6CLASS_CRAFTING_PROPOSAL_V1.md를 변경하지 않는다.
- 과거 두 문서의 shapeless 권고는 사용자 결정에 따라 shaped로 대체한다. 각 단계는 일반 제작대 3×3에서 제작한다.
- 아래 배치는 위 사용자 결정에 맞춘 30종의 구체적인 패턴 제안이다. 개별 칸의 디자인을 사용자가 각각 승인한 것은 아니다.
- 등급: 규격 / 변조 / 변칙 / 이형 / 불가해. 2~5등급은 이전 단계 매개체 1개를 소비하고 그 아이템은 가운데 칸 O에 놓는다.
- A, B, C, D, E: 오른쪽 범례의 아이템. 글자 1개는 재료 1개를 사용하는 슬롯 1개다. 점(.)은 빈 슬롯. 세 줄을 위 / 가운데 / 아래 순서로 읽는다.
- 5등급 계약 증표의 A에는 불사의 토템이나 바다의 심장 중 하나를 놓는다. 두 대체안을 모두 구현하고 제물 경제를 바꾸지 않는다.
- 기존의 등급 효과, 장착 슬롯 수, 결과 아이템 수량을 바꾸지 않는다.

## 직업 관리의 매개체 열람 UX

- 메뉴에서 해당 직업의 5개 등급을 전환하며 각 등급의 효과, 완성 아이템과 원재료를 확인한다.
- 실제 제작대와 똑같은 3×3 슬롯을 그린다. 각 재료 칸에는 실제 Minecraft 아이템 아이콘을 표시하고, 마우스를 올리면 아이템 이름 및 전체 필요 수량을 보여준다.
- 오른쪽에 화살표와 결과 슬롯, 결과 아이템 이름·등급·효과를 표시한다. 2~5등급의 중앙 슬롯에는 이전 단계 매개체 아이콘을 그린다.
- 계약술사 불가해의 토템/바다의 심장은 두 조합을 전환하거나 둘 중 하나를 선택하여 보여준다.
- 실제 제작법 JSON과 메뉴가 불일치하지 않도록 동일 제작 데이터에서 UI를 그리거나 자동 일치 검증을 실시한다. 조합법은 게임 내 제작대에 실제로 등록되기 전까지 플레이 가능한 기능으로 표시하지 않는다.
- 메뉴에서 즉시 제작하거나 무료 업그레이드하지 않는다. 장비 제작 및 재료 소비는 바닐라 제작대에서 서버 권위로 처리한다.

- 위 30개 패턴을 재료표와 문자 빈도로 대조한 결과 재료 종류, 소모 개수, 9칸 제한에서 30/30 통과.

# 6직업 대형 스킬트리 — 정적 디자인·동작 검토

**검토 방식:** 소스, 승인된 12장 ZIP, 실제 리소스 파일, 데이터 좌표, 자동 정적 검사와 Java 런타임 fixture를 검토했다. CUA/Minecraft 화면 조작은 사용하지 않았다.

## 승인 시안과 비교

ZIP의 구현 가이드와 직업별 `전체맵`·`확대_플레이뷰` 12장을 모두 확인했다. 화면 전체를 PNG로 붙이지 않고 배경, 아이콘, 노드 상태 프레임, 실시간 선·글자·정보 카드를 분리했다.

| 직업 | 승인 시안의 시각 방향 | 적용한 분리 아트 |
|---|---|---|
| 계약술사 | 제단, 계약 인장, 육화와 권능 | 붉은 계약 제단 배경, 인장·검·서약서 아이콘 |
| 정신 지배자 | 심연, 정신 파동, 의식 공간 | 보랏빛 의식 관측소 배경, 눈·정신 파동 아이콘 |
| 인형술사 | 공방, 톱니, 실과 인형 | 황동 공방 배경, 인형·기어·실 아이콘 |
| 기생술사 | 숙주 침투, 생체 조직, 신경 연결 | 생체 조직 연구실 배경, 침투·숙주 연결 아이콘 |
| 결계술사 | 룬, 겹친 결계, 압축·격리 공간 | 청색 룬 석조 결계 배경, 방벽·봉인 아이콘 |
| 군체술사 | 벌집, 군락 연결, 번식·엄호 | 호박색 벌집 동굴 배경, 군집·알·엄호 아이콘 |

공통 HUD는 좌상단 프로필 복귀와 직업명, 우상단 보유·사용 SP와 초기화로 제한했다. 중앙을 지도에 내주기 위해 큰 제목판, 계열 탭, 고정 설명 패널, 줌 버튼, 조작 설명은 제거했다. 승인된 노드 프레임 아틀라스의 잠김·구매 가능·선택·보유 상태를 사용하고, 주요 노드의 기존 돌파는 금색 프레임과 구간 표시로 구분한다. 지도의 연결은 실제 JSON 그래프 좌표에 따라 부드러운 곡선으로 그리고, 구매 경로가 열리면 같은 선을 강조한다.

노드는 런타임에 생성되는 구매 데이터와 아이콘으로 표시한다. 소형 스탯 아이콘 4종은 공유하며, 기존 패시브별 아이콘은 6개 아틀라스에서 개별 256×256 PNG로 잘라 사용한다. 노드 아이콘·배경은 코드 도형으로 대체하지 않았다.

## 월드 저장과 이관

- 레거시 랭크 배열과 신규 `purchasedNodes`·`skillTreeVersion`을 서로 다른 NBT 필드로 보존한다.
- 6개 직업 변환을 메모리에서 전부 검증한 뒤 한 번에 저장한다. 랭크 배열이 잘못됐거나 알 수 없는 노드가 있으면 버전 표식을 쓰지 않고 전체 이관을 거부한다.
- 완성한 기존 단계는 소형 노드와 해당 주요 노드로 변환한다. 마지막 미완성 단계의 레거시 랭크 비용은 남은 SP에 환급한다. 이관 전후 `보유 SP + 이미 사용한 SP`가 같은지 확인한다.
- 단계가 변환되면 재접속/재시작 시 재이관하지 않는다. 레벨, 경험치, 영구 데이터는 기존 값으로 유지한다.
- 구매·SP 차감·경로 조건은 서버가 최종 판정한다. 무료 초기화는 전투 잠금 확인 후 해당 직업의 구매 노드 가격을 모두 반환한다.
- 소형 속성 modifier는 같은 고유 ID로 제거 후 다시 적용해 직업 전환·초기화·재접속에서 누적되지 않게 했다. 최대 체력 변화 때 현재 체력 비율을 유지한다.

기존 패시브의 미구현 전투 효과가 실제로 발동되는지는 이 변경의 완료 기준에 포함하지 않았고 구현됐다고 주장하지 않는다.

## 좌표·텍스트·상태 검토

- GUI Scale 2·3·4와 16:9·16:10·4:3 조합의 9개 Minecraft 논리 화면 크기를 정적으로 계산했다.
- 화면 좌표 변환, 월드 좌표 역변환, 클릭 판정이 같은 확대율·카메라 중심을 사용한다. 클릭을 놓을 때까지 드래그 임계값을 확인해 드래그를 구매로 처리하지 않는다.
- 휠은 포인터 아래 월드 지점을 기준으로 확대·축소한다. 카메라 이동은 데이터 그래프 바깥으로 벗어나지 않게 제한한다. 리사이즈 시 월드 중심과 확대율을 보존한다.
- 화면 밖 노드·선은 캐시된 좌표의 viewport 범위로 걸러낸다. 그래프는 최대 108 구매 노드로 제한되어 매 프레임 전체 데이터와 클릭 위젯을 다시 구성하지 않는다.
- 호버 카드는 `Font.split`으로 실제 클라이언트 폰트 너비에 맞춰 줄바꿈하고, 화면 가장자리·높이에 맞게 폭과 줄 수를 제한한다. 한국어·영어 키와 버튼 폭은 정적 검사했다.
- 스킬 화면은 `renderBackground()`를 한 번 호출하고 `super.render()`를 호출하지 않아 배경을 중복 블러 처리하지 않는다. 배경 아트가 월드 배경 위에 한 번 표시된다.

## 2. 액티브 스킬 3종 후보

| 기술 | 목표 | 지속/재사용 (후보) | 전제 |
|---|---|---|---|
| **침투 고정** | 다음 기생 시도에서 집중 유지가 좀 더 쉬워지도록 준비 | 준비 유효 8초 / 재사용 40초 | 인간형 또는 숙주 상태, 유효 기생 대상 필요 |
| **생체 수복** | 현재 숙주의 실제 체력을 천천히 복구 | 회복 5초 / 재사용 45초 | 살아 있는 숙주에 기생 중, HP 결손 |
| **본능 각성** | 현재 숙주의 근접 위험을 감수하며 기동·화력 강화 | 지속 6초 / 재사용 35초 | 살아 있는 숙주에 기생 중 |

### 침투 고정

- 사용 후 **8초 이내 시작하는 적법한 다음 침투**에만 집중 완화 적용. 침투 중 짧은 타격/시야 끊김이 발생했을 때 **잃는 침투 진행도 25% 감소** 후보. **기생 최소 BD, 현재 사망 후 재기생 제한, 현재 숙주 소유권, 지원 여부는 그대로**.
- 침투를 준비했다고 바로 생물 조종권을 빼앗지 않는다. 기존 [침투 판정](./PARASITE_BIODATA_ACQUISITION_AND_INTRUSION.md)의 정상 시야/거리·대상 이동/저항·침투 시간 진행 필요.
- 기존 침투 집중에 **조건부 안전성**을 더하는 기술이지 '긴급 재기생 충전'을 무단 획득하거나 60초 기생 제한을 무시하는 능력이 아니다.
- 준비 이후 8초 내에 합법적인 침투 자체를 시작하지 못했다면 효과는 소멸. BD/권한 미달로 시작 자체가 불가한 대상만 있으면 시전 안내에서 불가 사유를 표시. 실제 소모·쿨타임 정책은 사용성 테스트 전 조정.
- 사망한 숙주를 살리는 기술 아님. 사용자 입력 연타와 프로세스 전환으로 버프 중첩 불가; 침투 1회 확정 시 적용 소진.

### 생체 수복

- **현재 기생한 숙주 1기**의 결손 HP를 **5초에 걸쳐 회복**. 사망한 숙주, 인간형, 다른 플레이어, 지배체·인형, 과거 종별 숙주에게 사용 불가.
- 기본 총 회복 후보: `heal = min(0.25 × HostMaxHp, 4 + 0.5 × sqrt(BD))`. 예: 작은 돼지는 대략 최대 체력의 25% 이하, 매우 큰 체력을 가진 보스급 숙주는 BD가 아무리 높아도 즉시 체력 25% 풀회복하는 것이 아니라 절대 회복량이 제한됨. 실제 소재나 별도 생체 연료를 소모하지 않고 **45초 쿨타임**으로 제한.
- 적의 충분한 피해를 받거나 숙주를 떠나면 **남은 회복을 중단**하며 이미 실제로 회복된 HP만 유지. [자가 수복 패시브](./PARASITE_SKILL_TREE.md) 20랭크 후보는 **소규모 피격 1회를 버티고 회복을 이어 가는** 돌파로 설계; HP 무적/사망 회피 아님.
- 체력 100%일 때 시전하면 성공하지 않도록 하고 쿨타임/시전 상태를 소비하지 않는다. 최대 HP 변경·숙주 교체 시 기존 HP 비율과 수복 진행 상태를 서버가 일관 처리.
- **허약한 인간형의 취약성 유지**: 인간형으로 튀어나왔을 때 이 스킬로 8→20HP를 채우거나 재기생 제한 중 자동 생존하는 기능으로 확장하지 않음.

### 본능 각성

- 현재 조종 중인 **숙주 1기**를 6초간 강화: **공격 피해 +15%, 이동속도 +15% 후보**, 대신 **적에게 받는 피해 +15%** 후보. 재사용 35초. 버프 상태에서 전투를 유지하면 강하지만 잘못 쓰면 숙주 사망→인간형 배출·재기생 제한으로 이어지는 위험.
- **공격속도·공격 간격·기생 가능 대상 수·BD 자체·침투 저항·재기생 충전 횟수에는 변화 없음**. 같은 숙주에게 중복 재사용하여 누적하지 않음.
- 신속한 도주/적 접근·짧은 화력 선택을 모두 지원하지만 폭주+자가 수복을 겹쳤다고 무적이 되지 않음. 바닐라 포션·외부 모드 피해·환경 위험과 결합한 실제 방어/받는 피해 계산은 서버 정본으로 검증.
- 인형술사 '연계 구동'이 소환체 전부를 강화하는 것과 달리, **기생술사는 직접 조종하는 현재 숙주 자신만** 강화하고 **피해를 더 받는 위험**을 명확히 가짐.
- 숙주를 바꾸거나 죽으면 버프는 종료. 새 숙주에 버프가 무료 이전되거나 이전 숙주를 무한 강화하지 않는다. 재사용 대기 타이머는 그대로 보존.

## 3. 패시브와 액티브 상호작용

- **침투 정밀화(30랭크)**는 기본 침투 시간 감소, **침투 저항(25)**은 도중 피격 위험 완화, **침투 고정(액티브)**은 짧은 기간 중단 페널티만 제한. 3개 효과를 각각 한 번 계산하며 최소 BD/침투 진입 가능 여부는 어떤 효과로도 달라지지 않음.
- **생체 해석**은 BD 획득 효율만 증가. BD 자체가 마나처럼 기술을 사용할 때 감소하지 않음.
- **종별 융화**는 해당 종 숙련 획득 효율 상승. 종별 숙련 단계 10/30/60/100 및 현재 종 기준 적용은 그대로.
- **조직 강화/공격 적응/신체 운용**은 기본 숙주 HP/전투/이동 강화. 본능 각성은 6초간 피해/이속의 **단 한 번 별도 배율**. 자기 몸을 여러 번 복제해서 버프를 무한 중첩하는 기능 아님.
- **생존 전이**는 숙주 사망 후 재기생 제한을 우회하는 충전 0~3회 및 제한 시간 단축에만 관여. **침투 고정이 이 충전을 생성/복원하거나 쿨타임을 무시할 수 없다**.
- **자가 수복**은 생체 수복 회복량·피격 허용 범위·쿨타임에만 영향; **인간 의태**는 숙주 없이 인간형에 배출됐을 때 약한 상태/조작을 조금 보완, 숙주 상태에서의 전반 전투력 상승은 별도.

## 4. 대상별 종 고유 행동과 액티브 차이

| 숙주 | 숙주 자체의 기본/고유 행동 후보 | 액티브와의 관계 |
|---|---|---|
| 돼지 | 일반 이동·짧은 기생체 돌진 후보 | 돌진은 돼지로 살기 위한 기본 종 능력. 본능 각성 중 위험 감수 강화 |
| 좀비 | 실제 근접 공격·낮은 기동성, 햇빛 약점 보존 | 각성으로 빠르게 접근 가능하지만 낮 전투 위험은 남음 |
| 거미 | 벽면 이동·근접 공격 | 침투 고정의 타깃 접근 지원과 무관, 평소 벽면 이동 가능 |
| 슬라임 | 실제 크기·점프·충돌, 분열 시 개체/기생체 분리 안전성 | 생체 수복은 현재 본체만 회복, 분열체 복제/회복 불가 |
| 가디언 | 실제 수중 이동·조준 광선(지원 어댑터 필요) | 원거리 피해·이동속도 보너스는 서버 실제 능력과 계산 |
| 워든 | 직접 근접·감지·충격파 능력의 구현된 부분만 | 높은 BD 요구치/침투 저항 필요. 각성으로 월드 보스 제약 우회 불가 |

- 종별 고유 행동은 **실제 Minecraft 버전·로더에서 구현·검증한 동작만 사용 가능**. 종마다 별도 5~10개 버튼·새 직업 마나를 추가하지 않는다.
- 갑옷/도구가 없는 돼지 등도 기존 생존 채집/제작 입력은 보조 촉수 시스템으로 가능하도록 검토, 종 특성 때문에 바닐라 생존이 멈추지 않음.
- 정상 스킬 사용/기생 시도는 같은 플레이어 UUID의 단일 서버 권한으로 확인, 숙주 교체 시 이전 숙주 버프/공격 상태를 제대로 되돌린다.

## 5. UI/멀티플레이/성능 검증 계약

- **기본 입력**: 기생 시도, 숙주 해제/전환, 현재 종 고유 기술, **종족 기억 기술 선택/사용**. **액티브 3개**: 침투 고정/생체 수복/본능 각성. 모든 키는 재바인딩 가능, 화면에 미기생 인간형에서 사용할 수 없는 스킬을 적절히 흐리게 표시.
- HUD: 현재 숙주 종/HP, BD(현재/대상 요구), 침투 집중 진행도, 사망 후 재기생 제한시간, 생존 전이 0~3충전, 액티브 3종 쿨타임, **선택된 계승 종족 기술의 재사용 대기**. [종족 기억](./PARASITE_TRAIT_INHERITANCE.md)은 한 능력 휠로 모든 습득 기술에 접근하며 **종마다 별개 전투 액티브 슬롯/키를 무한 추가하지 않는다**. **새 기생 부하 바/유지 연료 금지**.
- 무단 외부 몬스터 AI 제어, 침투 도중 플레이어 인벤토리 중복, 주인 사망 후 남은 숙주, 스킬 타이머 재로그 초기화, 다른 플레이어 숙주 탈취, 본능 각성 중 사망/재기생 즉시 악용, 동일 HP 회복의 중복 적용, 명령 패킷 스팸 등을 검증.
- 시각: 인형술사/정신 지배자와 구분되는 **플레이어의 살아 있는 숙주 몸** 카메라/모션/사운드. 액티브가 숫자만 튀는 별도 색상 오라로 끝나지 않도록 몸의 짧은 반응·움직임/타격 피드백 연출. 최종 UI 디자인 Codex 담당; 서버 스탯/권한/BD/침투/피해는 모드 코드가 결정.
- **전투/성장 테스트는 미수행**. 실제 에뮬레이션/AI/서버 모델과 렌더 구현 기술은 MC 버전·로더 선정 이후 결정.

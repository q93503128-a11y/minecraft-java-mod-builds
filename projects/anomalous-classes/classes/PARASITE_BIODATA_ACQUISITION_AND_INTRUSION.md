## 1. 단 하나의 영구 BD 수치 — 얻지만 소비하지 않는다

- **BD는 별도의 돈/상점/스킬 마나가 아니다.** 플레이어 기생술사 데이터에 쌓이는 성장형 스탯. 사망, 인간형 복귀, 종 변경, 로그아웃으로 감소하지 않는다.
- **BD가 올라가면** (1) 기생 가능 대상의 최소치 통과 여부가 달라지고 (2) 현재 숙주 최대 HP·공격력 등 실제 능력이 기존 성장식에 따라 완만하게 상승한다. 기생 시 `requiredBioData`를 **소비하지 않는다**.
- 공용 XP/레벨/스킬포인트와 연결하되, 같은 행동을 기계적으로 두 번 세어 과도한 스탯 보너스가 중첩되는지 검증한다. **BD는 직업 전용 성장 지표 한 개**이며 별도 생체 조각/연료/재화 없음.
- **인간형으로 생존 행동 가능하지만 BD의 주력 획득은 실제 숙주 기생 활동**. 숙주 없는 인간형에서도 공용 Minecraft 생존은 정상 작동한다. 일반 채굴·건축만으로 '숙주에 기생하지 않아도 최고 BD'를 얻는 방향은 피한다.

## 2. 획득 이벤트와 1차 수치 후보

| 활동 | 첫 BD 후보 | 유효 조건과 반복 방지 | 초반 돼지에서의 가치 |
|---|---:|---|---|
| 숙주로 정상 활동 **4분 누적** | **+4 BD** | 실제 게임 활동을 기록하는 구간만 누적. 정지·자동입력·같은 경로 무한 왕복은 유효 활동으로 취급하지 않음 | 최약체 숙주로도 차근차근 성장 |
| **새 생물군계 최초 방문** | **+12 BD** | 플레이어별 월드/차원 + biome ID 기준 한 번. 인간형 혼자 탐험한 장소를 나중에 같은 숙주로 첫 탐험처럼 반복 보상하지 않도록 완료 기록 공유 | 위험한 전투 없이 탐험 성장 |
| **생존 목표 최초 달성** | **+12~30 BD** | 공용 생존 활동의 의미 있는 milestone ID를 플레이어별 한 번만 인정. 예: 숙주 상태의 첫 도구 발전, 식량 기반 확보, 지하 심부에서 무사 복귀. 단순 제작·설치 연타는 무보상 | 바닐라 생존 루프와 연결 |
| **실질적 적대 전투 참여·승리** | **+3~60 BD** | 원래 적 위협도, 숙주 자신이 실제 위험을 부담한 비율, 유효 피해/위험/최종 승리 판정. 소유한 자동 소환물·트랩만으로 완전 자동 처치 시 0 또는 대폭 하향 | 후반 강한 숙주에서 빠른 성장 |
| **강력 적/보스 최초 격파** | **높은 별도 후보 보상** | 플레이어 기생 기여, 서버상 대상 고유 진행 이벤트 기반 1회. 보스 소환 반복/월드 데이터 초기화 악용 방지 | 후기 성장 목표 |

**위 4분은 아무 활동 없이 기생한 상태로 오래 있어도 수치가 올라가는 '접속 시간 보상'이 아니다.** 실제 숙주의 이동·지형 이용·유효 채집/전투·탐험 등 서버 이벤트를 통해 '활동이 인정되는 시간'을 집계하는 후보이며, 이동 거리만으로 인정하면 AFK 매크로 악용 가능하므로 서로 다른 합법 이벤트/행동 증거와 함께 계산한다.

- 세계 탐험 기록은 **생물군계 ID만** 영원히 수집하는 것을 강요하지 않는다. 다른 차원의 같은 biome, 모드 추가 biome은 월드/차원 식별 기준에 따라 보상을 검증한다. 같은 구역/종류의 반복 입장 보상은 금지.
- 전투 BD는 원본 적 위협도+기여율을 보고 데이터 테이블에서 산정한다. **같은 종의 연속 처치 보상은 점차 감소**, 플레이어가 위험을 실제로 감수한 새로운 강적/환경에서 회복 가능. 평범한 스포너 무한 처치가 최상위 최적 해법이면 실패.
- **돼지 한 종만 고집해도 BD를 끝까지 얻는 경로는 열려 있어야 한다.** 동물을 바꾸는 것이 반드시 특정 종 도감 100개 채우기 같은 해금 조건이 되어서는 안 된다. 약한 숙주에서 위험도가 높은 전투를 억지로 강제하지 않으면서 탐험·생존 보상이 유의미해야 한다.
- '보스 격파'가 본래 숙주의 몸을 유지한 상태로 직접 기생 활동 중 이루어지지 않은 경우 기여 검증 기준을 충족하지 못하면 BD 보너스를 지급하지 않는다. 파티 공동 킬에 대해 동일 보스 보상이 무제한 복제되지 않도록 개인별 최초/공헌 기록 분리.
- 기생한 지 얼마 안 됐다는 이유로 종별 확정 보상을 즉시 중복 부여하지 않는다. 본체 사망/재접속/멀티 시 숙주 변경으로 활동 구간·최초 방문·마일스톤을 초기화하지 않는다.

### 2.1 초반 비교 시나리오(테스트 전 가정)

돼지 숙주로 **유효 활동 40분(4 BD × 10회 = 40 BD)** + **새로운 biome 3곳(12×3=36 BD)** + **서로 다른 생존 목표 2개(12×2=24 BD)** → **100 BD**.

- 기존 [BD 최소 요구량](./PARASITE_BIODATA_GROWTH.md)의 **좀비 100 BD**에 진입 가능한 가상 상황. 실제 생물군계 분포·숙주 채집/전투/생존 난도에서 40분을 달성 가능하다고 검증한 것은 아니다.
- 시작 돼지→소(20 BD)→좀비(100)→거미(160)→가디언(600)→워든(5000)의 **최소치 표는 이미 정한 검증 전 예시를 그대로 재사용**한다.
- **BD 5000까지의 진도**는 초기 활동 보상만으로는 지나치게 오래 걸릴 수 있다. 새로운 위협·고난도 숙주/보스 전투의 BD 수익이 올라가는지, **보스 최초 승리 + 큰 BD**와 다수 동작의 경제 보상을 테스트하며 조정. 상위 적 처치 보상 증가를 실측 없이 확정하지 않는다.

## 3. 종별 숙련도: BD와 다른 기능, 별도 화폐는 아님

- **공용 BD**는 모든 종에 적용되는 가장 큰 성장형 스탯이며 강한 숙주에 들어가기 위한 **하드 게이트**.
- **종별 숙련도**는 사용했던 종의 실제 운용 경험을 저장하는 **조작 숙련 + 완전 숙련에 따른 다른 숙주로의 능력 계승 조건**이다. 예: 돼지 숙련, 거미 숙련, 가디언 숙련. **100까지 완전히 숙련하면 해당 종의 지원된 선천 능력을 다른 종 숙주에서도 영구 사용 가능**해진다. BD 최소 기생 요구치를 **절대 무시하거나 낮춰 주는 대체 수단은 아니다**. 세부는 [능력 전승 v2](./PARASITE_TRAIT_INHERITANCE.md) 참조.
- 처음 그 종으로 기생하는 즉시 species mastery 기록을 생성. 같은 종 다른 개체로 옮기거나 인간형→숙주→인간형을 반복해도 진행도는 동일 species ID에 합산해 유지한다.
- **개선된 초안(사용자 승인 방향):** 종별 숙련 점수 **0~100**을 **해당 숙주로 얻은 유효 BD**뿐 아니라 **그 종의 고유 행동·탐험/생존 성취**에서도 얻는다. 기존 **유효 BD 10당 숙련 +1점**은 기본 경로 후보로 유지하고, 실제 종 고유 행동을 익혔음을 나타내는 **종별 최초 성취 보너스**를 추가해 완전 숙련까지 1,000 BD 노가다를 필수로 만들지 않는다. 세부 보너스량·도달 시간은 미검증. 10·30·60·100점에서 체감 개선:
  - 10: 해당 종 조작 반응/전환 안정 약간 개선
  - 30: 해당 종의 **고유 이동** 사용성 증가(예: 거미 벽면 제어, 돼지 돌진 회복)
  - 60: 해당 종 고유 기술의 실행 안정성/선후딜 개선(실제 판정·공속 상한 검증)
  - **100: 완전 숙련으로 해당 종의 지원된 고유 능력들을 모든 다른 숙주에 영구 계승 해금**. 작은 생존/전투 보정(최대 HP +5% 이내 후보)과 외형/사운드 피드백도 보조로 검토. **현재 종 원래 능력은 숙련 0부터 가능**
- 숙련 점수를 벌려고 이미 받은 BD를 **소비하지 않는다**. 다른 종으로 기생해도 과거 종 숙련은 그대로 저장되고 **그 종 숙련 100에서 해금한 종족 고유 능력은 다른 숙주에 계속 계승**된다. 다만 원래 종의 **체력/공격 같은 종별 기본 스탯 보너스를 다른 종에 무한 중복 적용하지 않는다**. 여러 종의 환경형 능력은 실제 환경 조건/중복 그룹 기준으로만 작동한다.
- 낮은 숙주가 영원히 무가치해지지 않도록 종 고유 기술에서 실제 차별점을 제공하고, 높은 숙주도 처음 들어가면 그 종 조작 숙련은 0부터 시작해 성장 보람이 있다.
- **3개 별도 랭크·화폐·재료를 새로 만드는 설계는 하지 않는다.** UI에는 해당 종의 숙련 진행도와 **100 완전 숙련 시 타 숙주 계승이 열림**을 보여준다. 계정 내 2명의 기생술사/멀티 플레이어가 서로 숙련도를 공유하지 않는다.

### 3.1 종별 고유 행동·탐험 성취로 숙련을 추가 획득 (사용자 동의 방향)

- **본체가 실제 숙주였던 종에만 해당 종 숙련 부여**. 돼지에 기생할 때 거미 벽 타기를 계승 사용해도 거미 종 숙련이 새로 오르지 않고, 돼지의 조작·생존 숙련이 오른다. 같은 생물을 다시 점유하거나 로그아웃해도 최초 성취를 재획득 불가.
- **첫 유효 고유 행동**: 해당 종의 고유 이동/공격/생존 기술을 실제 환경에서 의미 있게 사용해 성공하면 **숙련 +8 후보**. 예: 거미로 수직 지형을 올라 실제 새로운 높이에 도달, 가디언으로 수중 표적 공격 성공, 돼지로 위험에서 실제 도주. 막힌 벽을 제자리에서 반복 누르는 것은 인정하지 않음.
- **환경별 숙주 탐험 성취**: 해당 종으로 유효 탐험/첫 위험 지역 이동 완료 시 **숙련 +6~10 후보**. 단 biome 여러 개 입장만으로 무한 획득 불가; '첫 지하 진입/안전 귀환'처럼 미리 등록된 숙주별 유효 환경 목표를 제한적으로 지급.
- **해당 종 생존·전투 실적**: 숙주의 신체 약점을 실제로 극복한 전투/생존 사건·장시간 유효 생존을 달성하면 **숙련 +8~15 후보**. 돼지 등 비전투 숙주는 채굴·탐험/탈출·식량 확보·수중 생존처럼 **전투 없는 대체 과제** 제공.
- **숙주 개체/환경·목표 ID별 최초 보상**은 서버에서 원자적으로 기록하며, 자동 농장/AFK/제자리 이동/동일 이벤트 반복으로 재지급하지 않는다. 모든 숙주에 등록된 과제와 종별 콘텐츠 난도 차이를 검증. 신규 화폐·클릭 제작·종 도감 수집 강제 없음.
- **100 완전 숙련**은 [종족 능력 계승](./PARASITE_TRAIT_INHERITANCE.md)의 **다른 숙주에서도 해당 종의 모든 지원 고유 기술을 영구 사용하는 조건**. 따라서 보너스량은 입문 돼지·거미·크리퍼·보스별로 실제 사용시간과 해금 체감을 보고 조정. 100달성 시간이 지루하다면 단순 BD 지급 계수를 높이는 대신 **고유 기술을 실제 배워 가는 숙주 경험**을 보강하는 쪽을 우선.
- 정산 필드 후보: `perSpeciesMastery`, `perSpeciesMilestoneIds`, `speciesEffectiveBdAccumulator`, `masteredSpeciesIds`, `masteryVersion`; 모두 서버 권위로 지급/저장. **일회성 성취가 실제로 한 번만 지급되면**, 해당 종 최초 방문/전투의 BD 보상과 숙련 보너스를 같이 주는 것은 가능(서로 다른 스탯이므로 중복 지급 버그와 구분).

## 4. 기생 허용과 성공을 분리하는 4단계 판정

- 사망한 숙주에서 인간형으로 나온 경우 **기본 재기생 금지 상태**가 먼저 적용된다. 예외적으로 [생존 전이 패시브/긴급 재기생 충전](./PARASITE_HOST_DEATH_AND_TRANSFER.md)이 있으면 해당 금지만 한 번 우회할 수 있지만, **최소 BD·대상 소유권·집중 침투·저항 단계는 여전히 필수**다. 정상 숙주 간 직접 전환 및 자발적 이탈은 사망 전용 규칙과 구분한다.

1. **대상 유효성/권한 검사**: 현재 플레이어가 직접 조종할 수 있는 살아있는 서버 entity인지, 타인 소유·이미 기생 중·보호 구역·동일 팀/비동의 PvP 대상·미지원 모드 보스가 아닌지 확인. 이 상태가 안 되면 BD가 높아도 불가.
2. **생체 데이터 최소치 검사**: `BD >= requiredBioData(targetType)`가 아니면 시도 불가. 대상 현재 HP 1 또는 약화 상태라도 요구량을 낮추지 않음. 기존 예시 돼지/닭/양 0, 소 20, 좀비 100, 거미 160, 가디언 600, 워든 5000 후보 유지.
3. **저항/침투 단계**: BD 요건 충족한 뒤 대상 생물의 저항을 이겨야 실제 기생 성공. 초기 추천: **무한 확률 재시도 대신 보이는 집중 침투(progress)을 진행하는 방식**. 충분히 가깝고 유효한 시선/대상 범위 안에서 숙주의 저항/위험/기생자의 성장에 따라 몇 초간 침투를 유지. 맞거나 시야가 끊기면 진행이 중단/후퇴할 수 있으며 목표의 위험한 움직임이 실제 도전이 된다. 조건 충족 후 성공했다면 전환이 원자적으로 이루어짐.
4. **원본 숙주 제어권 이전**: 성공 시 서버가 오직 한 명의 기생술사에게 entity UUID 점유를 확정하고 기존 AI·팀/소유·체력·종별 기술을 보존. 이전 숙주를 해제하되 트랜잭션 실패 시 현재 숙주가 사라지지 않음.

### 저항/침투 시간 후보

| 대상 | BD 최소치(기존 초안) | 유지 침투 시간 후보 | 설명 |
|---|---:|---:|---|
| 돼지·닭·양 | 0 | 약 1.5초 | 입문 숙주로 거절 스트레스 적게 |
| 소 | 20 | 약 2.5초 | 초급 |
| 좀비 | 100 | 약 4초 | 전투 중 시야/거리 확보 필요 |
| 거미 | 160 | 약 5초 | 높은 기동 때문에 침투 어려움 |
| 가디언 | 600 | 약 8초 | 수중 환경·원거리 반격 위험 |
| 워든 | 5000 | 약 16초 | 가까운 거리에서 압도적 위험, 준비/도전 필요 |

- 위 시간/범위/저항은 **검증 전 제안**이며 적의 실제 공격 주기/AI·외부 전투 라이브러리에 맞춰 조정. **BD 최소치 이상만 충족하면 난도 0/즉시 성공인 것은 아님**.
- 높은 BD는 같은 종의 침투 시간을 **최대 30% 정도까지 완화하는 후보**이지만 0초 순간 점유는 불가. 단, 입문 돼지는 번거로움을 줄일 수 있게 별도 짧은 처리 허용.
- 상대 HP가 낮으면 침투 중 저항/위험을 **일부 줄일 수 있으나 BD 요구치에는 영향 없음**. 보스 HP 1을 만들었다고 무조건 성공하지 않음.
- **저항 = 꼭 확률 추첨만을 뜻하지 않는다.** 높은 BD가 필수치에 도달한 뒤에도 목표에 붙어 살아남고 집중을 유지해야 성공한다. 연속 실패 확률 뽑기보다 **플레이어가 통제 가능한 기술적 과제**를 우선.
- 강력 몹을 울타리에 가둔 뒤 무위험 침투하는 전술이 언제나 가장 강한 해법이 되지 않도록, 실제 위협 상황/특수 패턴·거리·충돌·보스 환경 조건을 검증한다. 다만 플레이어가 준비한 유효 제어/전술까지 억지로 무효화하지는 않는다.
- 실패 시 **현재 숙주가 즉시 죽거나 영구적으로 소멸하지 않는다**. 집중 중단 시 진행도가 적당히 후퇴/다음 시도 대기(예: 5초 후보)를 검토해 연타 악용 금지. 숙주 변경 완료 뒤에는 회복/쿨타임/피해·아이템을 복제/초기화하지 않는다.

## 5. UX·서버·데이터 구조

- 최소 정보만: **현재 BD**, 조준 대상 **필요 BD**, **현재 기생 가능/부족/제어 불가**, 침투 중 진행 상태, **현재 종 숙련**. 종별 도감 메뉴/별도 BD 인벤토리·추가 재화는 불필요.
- **중요: '필요 BD'는 소비량이 아니다.** BD 100으로 좀비에 성공해도 이후 BD는 100 이상을 유지. 대상 HP가 줄어도 조준 UI의 필요 BD 숫자는 불변.
- 원본 숙주 엔티티의 공격/이동·애니메이션과 직접 조종의 서버 실제 판정은 일치해야 함. 외부 몬스터의 미구현 특수 능력은 기생 성공 후 자동 플레이 가능인 것처럼 보이지 않게 지원 상태를 정확히 설명.
- 서버 저장: `bioDataValue`, `perSpeciesMastery`와 점수 나머지, `discoveredBiomeIds`, `awardedMilestoneIds`, `activityWindow/eligibleSeconds`, `combatRewardHistory`, `currentHostUuid/currentHostTypeId`, `hostClaimOwnerUuid`, `intrusionProgress/lastAttemptTime`, `version`.
- 월드에 장기 저장해야 할 기록만 영속화하고 매 tick 전체 스캔 대신 **기존 게임 이벤트**(이동, 피해, 킬, biome 변경, 채굴 성공, 생존 목표 완료) 중심으로 집계. 매 tick 전체 몹 순회 금지.
- 네트워크 패킷은 **기생 시도 목표 ID와 조작 입력**만 전달하고 BD/저항/숙련/획득량/성공 여부는 서버가 계산. 오프라인·차원 변경·월드 리로드에서 침투 progress를 부당하게 이어 붙이지 않음.
- 몹 사망/전리품과 기생 교체가 같은 틱에 실행될 때 중복 개체, XP/BD 두 번 지급, 플레이어 UUID 소유권 꼬임을 방지. 파티 기여/동일 적 중복 지급을 서버 이벤트 ID로 dedup.
- 실제 Minecraft 버전/로더는 **아직 미선정**. 바닐라/모드 API 호환성은 구현 전에 확인. 기존 공용 직업 5등급 장비/무제한 레벨/스킬 포인트는 유지.

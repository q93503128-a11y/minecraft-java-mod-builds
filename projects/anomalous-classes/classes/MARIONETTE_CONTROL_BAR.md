## 1. 조종틀 하나로 두 가지 효과만

| 현재 장착 등급 | 동시 전개 슬롯 보너스 | 인형 공격력 상승 후보 | 인형 최대 체력 상승 후보 |
|---|---:|---:|---:|
| 조종틀 없음 | +0기 | +0% | +0% |
| **규격** | **+1기** | +5% | +5% |
| **변조** | **+2기** | +10% | +10% |
| **변칙** | **+3기** | +15% | +15% |
| **이형** | **+4기** | +20% | +20% |
| **불가해** | **+5기** | **+40%** | **+40%** |

- 조종틀 효과는 **현재 장착한 한 개 장비의 등급에 따라 결정**한다. 예: 변칙 +3기는 규격(+1)·변조(+2)를 더해 +6기가 되는 것이 **아니다**.
- 동시 조종 수 증가: 규격에서 +1, **승급할 때마다 +1**, 불가해에서 +5. 인형의 레벨 기반 기본 전개 수와 **여분의 실 패시브 +1/10랭크**는 기존대로 합산.
- 인형 스탯 증가: **소유자의 모든 전개 인형**의 공격 피해/최대 HP에 등급별 가산 비율을 하나의 장비 계수로 적용. 칼날·투사기·방패 반격 포함. 방패의 방어 성공 판정·구동핵·골격·크기별 고유 기믹은 변경하지 않음.
- 규격~이형의 공격력/HP 5%p 단계는 **기존 미검증 시안**이다. 불가해는 **공격력·HP +40%, 추가 전개 +5기(사용자 확정)**로 별도 강화한다. 실제 전투 밸런스 테스트는 아직 수행 전이다. 사용자가 요청하지 않은 공속·이속·사거리·명령 지연·연결 안정/특수 행동 보너스는 **없음**.
- 조종틀을 착용하지 않아도 인형 제작·전개·자동 공격·무료 무쿨타임 표적 지정 가능. 본 장비는 **강화 수단**이지 직업 해금 필수 아이템이 아니다.
- 장비 효과와 인형 자체의 부품/크기/패시브 능력치가 결합할 때 **같은 공격/HP 배율을 두 번 세지 않는다**. 인형 HP가 바뀌면 **현재 HP 비율을 유지**해 장비 교체로 즉시 치유 악용을 방지.
- 장비 제거/강등으로 동시 전개 수가 감소해 초과 상태가 되더라도 **이미 만든 인형을 삭제·사망·복제하지 않는다**. 우선 신규 전개를 제한하고 초과 인형의 안전한 회수·동작 정책을 별도 정한다.

### 공식 연동

`GearBonus(g) = g` (미장착 g=0, 규격 g=1, 변조=2, 변칙=3, 이형=4, 불가해=5)

`MaxActive(L,r,g) = BaseActive(L) + floor(r/10) + GearBonus(g)`

`GearStatFactor(g) = (g === 5 ? 1.40 : 1 + 0.05*g)` (공격력/최대 HP 각각; g=0~4는 기존 시안, g=5는 사용자 확정 보정)

`AttackWithGear = AttackWithoutGear × GearStatFactor(g)`

`MaxHpWithGear = MaxHpWithoutGear × GearStatFactor(g)`

- L은 직업 레벨(상한 없음), r은 `여분의 실` 패시브 랭크(0~30). 기본 전개 슬롯의 실제 레벨별 수치는 [PUPPET_SKILL_TREE.md](./PUPPET_SKILL_TREE.md) 참조.
- 조종틀 자체 때문에 실 렌더링 거리, 명령 시전 거리, 타겟 변경 속도나 AI 전술 행동이 바뀌는 일 없음.

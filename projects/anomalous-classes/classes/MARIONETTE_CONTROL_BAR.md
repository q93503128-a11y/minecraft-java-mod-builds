# 마리오네트 조종틀 — 5등급 장비 설계 v1

> 2026-11-04 / **USER-CONFIRMED:** 실로 연결된 마리오네트를 조종하는 **십자형 나무 조종대(마리오네트 컨트롤 바)** 형태, 직업 장비 한 계열, 공통 5등급 **규격→변조→변칙→이형→불가해**. **NAME/RECIPE/NUMERIC EFFECTS/UPGRADE COSTS = PROPOSALS**, NOT TESTED. 직업 장비가 없어도 기본 인형 제작·전개·자동 전투·표적 지정 가능.

## 조종틀을 사용하는 이유

- 부품/재료의 역할은 **인형 자체의 전투 방식·크기·HP·무장**이다.
- 패시브의 역할은 **제작 효율·제어 동작·새 행동·무제한 레벨과 함께 커지는 전개 수**다.
- 조종틀의 역할은 **실 조종 연결, 목표 전환의 정확한 전달, 실 장력 안정과 다수 인형 반응**이다.
- 따라서 최고 장비만 착용하면 3m 인형의 몸체가 무료로 커지거나 인형 재료·수리 재료가 복제되도록 하지 않는다.
- 개체별 실 2~4가닥의 근접 표현은 클라이언트 경량 렌더링; 보이는 실의 길이가 곧 서버 명령·청크 로딩 거리인 것은 아니다.

## 1. 5개 등급의 성능과 외형 차이 (초기 제안)

| 등급 | 조종틀 모양 | 표적 변경 반응 지연 감소 | 추가 유효 명령 거리 | 특수 조종 기능 |
|---|---|---:|---:|---|
| **규격** | 소박한 목제 십자대와 묶인 실 | -4% | +0 | 기본 연결 안정 |
| **변조** | 구리 연결점과 철 보강, 이중 실 고리 | -8% | +1블록 | 좁은 지형에서 동행 재시도 조금 개선 |
| **변칙** | 자수정 결속점과 분리 실 고리 | -12% | +2블록 | 인형별 역할에 맞춘 명령 전달 조금 더 정확 |
| **이형** | 금속 접합·굴곡 십자대와 긴장 조절 장치 | -16% | +4블록 | 여러 인형이 한 위치에 겹치지 않도록 분산 |
| **불가해** | 형태는 여전히 십자 조종대, 비물리적인 빛의 실 효과 | -20% | +6블록 | **동시 전개 +1기 후보**, 여러 인형의 명령 지연 간섭 완화 |

- 표의 수치는 조종틀 간 단계별 **교체 적용**이지 이전 등급 보너스를 누적 합산하는 뜻이 아니다.
- 패시브 연결 강도·반응 동조와는 별도 **곱 보정**. 실제 명령 전환 대기시간의 하한과 공격 타이머는 전투 테스트 후 결정한다.
- **규격** 장비를 얻기 전에도 완전 기본 조종 가능. 명령 지연 감소를 위한 UI 수치 표시가 필수는 아니며 실제 조작감 우선.
- 불가해의 전개 +1은 전체 `MaxActive(L,r,g)` 계산에서 단 한 번 더하는 효과. 높은 레벨까지 무제한으로 같은 조종틀을 중복 착용하여 슬롯 폭증하는 기능은 아님.
- 장비 교체 후 허용 전개 슬롯이 기존 수보다 낮아지는 경우 **이미 전개된 인형을 죽이거나 삭제·복제하지 않는다**. 초과 수에는 신규 전개를 허용하지 않고 안전한 회수/정렬 정책을 추후 결정.

## 2. 제작·승급 재료 후보

**모든 승급은 직전 조종틀 1개를 요구**하며, 서버의 인형제작대에서 진행하도록 제안. 바닐라 재료로 시작하고 상위 등급은 탐험·고난도 전투를 활용한다. 추가 전용 화폐를 만들지 않는다.

| 만들 장비 | 직전 조종틀 | 추가 재료 예시 | 획득 의도 |
|---|---|---|---|
| **규격** | 없음 | 막대기×2, 실×2, 구리 주괴×1 | 초기 벌목·거미 사냥·채광 |
| **변조** | 규격×1 | 철 주괴×2, 레드스톤×2, 실×2 | 동굴 채광 및 기본 인형 개선 |
| **변칙** | 변조×1 | 자수정 조각×4, 금 주괴×2, 청금석×2 | 정동·광질·탐험 선택 |
| **이형** | 변칙×1 | 다이아몬드×2, 흑요석×2, 슬라임볼×2 | 고강도 광물·탐험·슬라임 수급 |
| **불가해** | 이형×1 | 다이아몬드×2 + **네더의 별×1** 또는 **메아리 조각×4** | 강적 도전 또는 고난도 구조물 탐험의 대체 경로 후보 |

- **불가해 촉매 대체 경로**는 제작법을 각각 별도 데이터 레시피로 제공하는 후보이며 실제 희귀도 동등성을 보장한 것이 아니다. 네더/엔더 강제 진입 정책이나 서버 모드팩 확정 전 수치 검증 필요.
- 가상의 '상위 인형 에너지석', '결속 화폐' 등 별도 파밍 재화를 추가하지 않는다.
- 이전 조종틀을 투입하면 같은 장비가 다음 등급으로 전환된다. 강화 클릭 반복/패킷 재전송으로 양쪽 등급의 조종틀을 동시에 생성하지 않는다.
- 조종틀은 **플레이어 직업 장비 슬롯 하나의 계열**이고, 인형제작대 자체/인형 부품 3종은 직업 착용 장비로 세지 않는다.
- 장비의 소유자·등급·현재 장착 상태를 서버가 최종 확정하며, 기존 정본에서 보조 장비 슬롯이 미결정이므로 착용 위치/단축키는 추후 정한다.

## 3. 완성도를 위한 연출·UX 조건

- 규격/변조/변칙/이형/불가해의 모양이 모두 **실제 마리오네트 십자형 조종대**로 인식되어야 함. 마지막 등급만 지팡이나 마법책으로 바뀌지 않는다.
- 직접 조종 바를 장시간 손에 들고 있어야만 인형이 공격하도록 강제하지 않는다. 표적 지정·연계 기술 시 **손동작 + 실 당김 + 인형 관절 응답**의 짧은 애니메이션을 제공한다.
- 최고급의 실 VFX/사운드는 실제 거리별 LOD, TPS, 멀티 환경에서 검증. 실을 엔티티 수십 개로 소환하지 않는다.
- 등급 승급 전 UI에는 소모될 실제 재료와 **얻을 편의/전개 성능**을 정확히 표시. 실패/취소 시 재료 미소비. 승급 레시피가 없으면 진입이 완전히 막히지 않도록 기본 직업 능력 유지.
- Codex는 최종 UI/아이콘/모델 외형 구현을 맡지만, 조종틀 등급/재료/전개 수/효과 계산은 공용 서버 게임 모델에서 제공한다.
- 장비의 디자인 참고: **전통적인 marionette control bar / cross controller** 실루엣. 실제 외부 아이템 모델·텍스처 사용은 라이선스 확인 후.

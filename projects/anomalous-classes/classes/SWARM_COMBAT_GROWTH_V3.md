# 군체술사 — 3차 전투 피격·자연 증식·개체 강화·외형 설계

> 2026-11-05 / **기획 문서이며 코드/빌드/플레이테스트 없음.** [군체술사 정본](./SWARM_CASTER.md)과 [공용 아군 판정](../ALLY_RELATIONS.md), [공통 매개체 슬롯](../CLASS_FOCUS_SLOT.md)을 함께 본다. 사용자의 최신 의견을 기존 1·2차 설계보다 우선. **사용자 확정한 사항과 이번 추천 후보 구분 필수.**

## 1. 이번 사용자 발언의 해석과 결정 경계

### 확정 또는 강하게 선호한 방향
- **중력술사·공명술사는 보류**, 지금 군체술사까지만 집중 진행. 두 직업의 8직업 목록 자체는 삭제하지 않는다.
- **원격 표적 지정**, 작은 개체가 실제 적과 교전하고 증식·소모하는 군체는 유지.
- 사용자는 `스킬로 수량 늘리는 건 별로일지도`라고 피드백. **버튼을 눌러 군체 수량을 회복하는 액티브 스킬 `급속 증식`은 현재 제안에서 제외**하는 것을 추천하며, 사용자 의도를 강제로 모든 형태의 수량 증가 금지로 과장하지 않는다.
- 사용자가 `적이 군체 때려서 죽이는 거지?`라고 질문: **예 — 적의 유효한 공격이 군체를 때리면 실제로 개체 수가 감소하고, 그 손실이 화면에 생물 사망/이탈로 표현되어야 한다**는 방향을 적용한다. 단 지금은 코드가 없어 엔티티 충돌/적 AI 호환 구현을 완료한 것은 아니다.

### 새 추천안 — 아직 최종 수치/기술 미확정
- **최대 군체 수는 레벨 자동 성장 위주**. 패시브를 찍어야 최대 마릿수 증가하는 구조는 현재 우선 추천에서 내린다. 영구 전투 포인트는 개체 공격력·개체 생존력·군집 운용(연계·모아치기)의 실질적 변화에 쓰는 방향.
- **현재 수량은 플레이어가 버튼으로 충전하는 자원이 아니라** 적이 군집을 공격해 줄어들고, 시간이 흐르거나 유효한 전투를 수행하면서 **자연스럽게 재증식**하는 전투 자원.
- **개체 강화는 군집에 소속된 모든 개체의 공통 스탯/행동 개선**으로 추천. 하나하나 강화/장비/육성/먹이 주기 UI는 만들지 않음.
- 능력 버튼 수는 반드시 3개를 채울 의무 없음. 기존 `급속 증식`의 자리는 **군집 엄호**(손실을 감수하고 플레이어를 지키는 전략)처럼 실제 전투에서 유용한 기술 후보로 검토하거나, 테스트 결과 필요 없다면 2액티브로 유지한다.

## 2. 제안하는 전투 자원과 스탯 구분

| 표시/내부 | 전투·성장 의미 | 증가/감소 | 화면 표현 |
|---|---|---|---|
| **현재 군체 수 N** | 전투 중 군단 전력, 소모 스킬 비용, 실제 타격받아 줄어드는 개체 | 적 타격·자발 소모 시 ↓, 자동 번식/전투 회복 시 ↑ | HUD `N / Nmax`, 군집 밀도/사망 애니메이션 |
| **최대 군체 수 Nmax** | 현재 개체의 상한, 점진적 군단 성장 | 캐릭터 레벨 자동 성장 위주 | 스탯 메뉴·HUD 분모 |
| **개체 공격력** | 같은 숫자여도 더 치명적인 군집 공격 | 직업 레벨/패시브/매개체 | 물어뜯는 타격·전투 피드백/소형 생물 형태 성장 |
| **개체 생존력** | 개체 소실에 필요한 유효 피해를 늘려 적의 광역 공격을 견딤 | 레벨/패시브 | 갑피/충격받은 생물·실제 수량 감소 |
| **번식/재결집 효율** | 시간/전투 수행으로 잃은 N을 자동 회복 | 레벨 자동 성장과 제한된 패시브 후보(수량을 *즉시* 주는 버튼 아님) | 죽은 개체 대신 작은 생물이 나타나는 연출 |

- **별도 게이지/화폐 금지:** 수량은 일반 아이템·별도 '군체 에너지'·개체별 아이템 수로 변환하지 않는다.
- 무제한 캐릭터 레벨이 군체 수만 무한대가 되는 결과를 피하기 위해 서버 물리체 수와 논리 수량을 분리. 일정 성장 구간 이후에는 개체의 **질적 능력치·증식 효율/공격 특성**도 계속 성장한다. 논리 수량의 최종 상한/등급은 실측 전 미확정.
- **초반 16, 중반 48, 후반 128** 등 이전 후보는 설계용 지표일 뿐 레벨별 확정 숫자 아님. 레벨을 올리는 과정과 보스의 유효 공격 피해량에 맞춰 조정.

## 3. 적에게 맞는 군체: 죽음이 실제 전투 규칙이 되는 방식

### 3.1 플레이어가 보는 동작

1. 플레이어가 **멀리 있는 적을 원격 표적 지정**한다. 군체는 실제로 그쪽으로 이동해 적을 둘러싼다. 플레이어는 무기를 쓸 수 있고 개체별 지정 필요 없음.
2. 적이 군체를 향해 **근접·투사체·범위 공격**을 하면, 유효 범위에 들어온 군집이 공격을 받아 일부 개체가 쓰러지거나 흩어진다.
3. 예를 들어 `80/100`이던 군체가 적에게 크게 맞고 `72/100`이 되면, **논리 수량 -8**과 함께 적절한 수의 작은 생물이 쓰러져 사라지는 화면 연출. 예시 수치이며 피해별 손실 공식 확정 아님.
4. 수량이 줄면 자연스럽게 지속 공격 압박이나 소모 기술의 잠재 위력이 낮아진다. **군단 전체가 0까지 가도 영구 손실은 없으며** 주인 가까이서 조금씩 되살아난다.
5. **개체 생존력 강화** 시 같은 적의 공격에 더 적은 개체가 죽는다. **공격력 강화** 시 같은 72마리라도 적에게 주는 유효 피해가 증가. 눈에 보이는 효과는 타격·갑피·크기/소리 피드백으로 반영.

### 3.2 서버 실현성 원칙

- **개별 생물당 실제 LivingEntity/독립 AI/개별 HP/UUID를 무조건 두지 않는다.** 군집 중심 위치·도달 경로·논리 `N,Nmax`과 **타격 가능한 1개 또는 소수의 군집 hitbox/피해 proxy**로 처리하는 구현 후보. 개체별 사망은 렌더링·서버 수량 차이를 동기화하여 표현.
- 적이 군집을 **공격 대상으로 인식하고 타격**할 수 있어야 한다. 바닐라 적이 자동으로 모든 종류의 proxy를 공격하는 것은 보장하지 않으므로 **표준 몬스터의 공격 타깃/피해 이벤트 적응**이 구현 과제. 외부 AI 몬스터는 지원된 모드/API에 한해 안정적으로 대응하며 무조건 호환 주장 X.
- 개별 군체를 적이 한 마리씩 추적하지 않고, **진짜로 공격 가능한 군단 위치**에 유효 공격이 닿으면 서버에서 피해를 산정한다. 원거리 화살/광역/근접은 적법한 충돌·장애물·아군 필터를 통과한 경우에만 적용. 화면에서 군체가 없는 지점을 때렸는데 군단이 죽는 부정확한 일 금지.
- **스탯 내부:** 일부 누적된 유효 피해를 개체 손실로 변환하는 `군체 내구력/소실 저항` 내부 모델 후보. 개체별 HP바는 없고 타격받을 때 실제 수량이 감소. 무의미한 0손실 연타/소수 피해를 영구 무효화하지 않도록 소수 피해 누적 처리. 개체 생존력은 '적 한 번의 타격으로 잃는 N'을 줄여 주는 역할.
- **광역 공격**은 한 군집 안의 여러 개체가 맞았다는 이유로 서버가 피해를 논리 수량만큼 여러 번 호출하지 않는다. 유효 교차 부피·군집 밀도·타격 종류를 반영한 적절한 1회 손실로 계산. 강한 보스 기술이면 한 번에 다수 손실 가능하되 항상 전멸 또는 반대로 무적이 되는 문제를 실전 수치로 조정.
- **일반 공격받는 생명체와의 균형:** 군단이 자동으로 모든 적의 피해를 다 흡수해서 주인이 무적이 되어선 안 됨. 적은 군체를 공격할 수도 주인을 공격할 수도 있으며 타깃 우선·AI 어그로·PvP는 보통 몬스터와 공용 파티 규칙을 존중.
- 피해 원천과 소유자를 검증해 **자기 군체/동료 군체/아군 인형·지배체/팀원**의 우호 피해 금지. 적 진영이 군체를 직접 공격하는 것은 정상.
- **시야/수량 동기화:** 16마리처럼 적을 때리면 개체 수 변화가 알아볼 수 있는 수량은 가능한 한 개별 사망과 일치하게 연출. 128개 논리 수량을 모두 물리체 128개로 유지하지는 않더라도 밀도 변화·죽는 개체의 수·HUD가 납득되게 연동.
- 군집 N=0이면 적의 타깃 목록에서 무효한 잔여 proxy가 공격을 계속 흡수하지 않고, 주인의 기본 종자/재결집 시스템만 남아 전투 중 자동 복구. 소유자 사망/재접속/차원 이동 때 불사 유령 군집·중복 개체 생성 금지.

## 4. 증식은 별도 액티브가 아니라 기본 능력

- **회복 3경로 제안:** (1) 비전투 상태에서 자동 보충, (2) 전투 중 기본 보충, (3) 적에게 유효 공격·처치 시 조건부 추가 보충. **버튼을 눌러 수량을 찍어내지 않는다.**
- 전투 중 재생이 멈추면 강적에게 일방적으로 소멸당할 수 있으므로, **처치가 없더라도 보스와 싸우는 동안 일정한 수량 복구는 계속**되도록 한다.
- N이 적을수록 증식이 더 느려져 끝없는 절망 순환에 들어가지 않도록 **바닥 보호용 최소 회복**을 제공. 0에서 완전 무력 상태로 고착 X.
- 공격·방어 성장의 한 측면으로 증식 효율을 일부 늘릴 수 있어도, **그냥 +N개를 즉시 얻는 액티브 스킬/패시브 랭크**는 현재 추천에서 제외. 스킬 포인트가 중요한 전투 품질을 바꾸도록 한다.
- 의도적으로 군단을 희생하는 기술은 매 시전 제물을 내는 대신 **현재 N을 진짜 비용으로 소비**한다. 비용은 실제로 전력 저하/생물 사망 연출을 남기고 시간이 지나야 돌아온다.

## 5. 액티브 구성의 정리 (구체 기술은 미승인)

| 조작 | 역할 | 군체 수량에 미치는 영향 |
|---|---|---|
| **기본 원격 표적 지정** | 적을 지정하면 군단이 따라가 집중 공격, 전투 중 무료 재지정 가능 | 0 |
| **군집 급습** | 자주 쓰는 공격적 돌진/휩쓸기, 범위·피해 판정 명확 | 기본적으로 직접 수량 소모 0 |
| **군체 소모** | 일부 군체를 희생해 강한 순간 일격, 지속 화력을 줄이는 위험한 선택 | 실제 현재 N 감소 |
| **군집 엄호** (**기존 급속 증식의 대체 후보**) | 군단 일부가 주인 곁으로 돌아와 짧게 공격을 막거나 적에게 반격, 방어하면 군체가 희생될 수 있음 | 발동 시 무료 또는 제한, 유효 적 피격 시 **N 감소**, 무조건 완전 무적 아님 |

- **급속 증식(즉시 수량 +15~25%) 액티브는 비채택 추천:** 기존 1차 3액티브 초안에 적힌 `급속 증식`은 더 이상 최신 제안 아님. 단순 수량 +N/쿨타임 뒤 반복 클릭은 재미/조작 대비 가치가 낮을 수 있다.
- **군집 엄호**도 3번째 버튼이 무조건 필요하다는 뜻 아님. 플레이테스트에서 서바이벌·보스 대응에 충분한 의미가 없으면 **2액티브와 원격 표적 기본기**로 유지하는 편이 낫다.
- 군집 엄호는 결계술사의 **고정된 방어 결계 설치**와 달리 **움직이는 실제 군체가 자신을 희생해 주인을 잠시 엄호하는 전투 선택**이다. 단 일반 적 타깃이 이미 주인을 향한다면 군체 전부가 공격을 못 하며 완전 방어가 되어서는 안 된다.
- 스킬이 너무 많아 메뉴만 늘거나 최종적으로 '소모기→증식기'를 의무적으로 반복하는 지루한 정해진 콤보가 되는 것 방지.

## 6. 시각 외형 첫 후보 — 진짜 생물 무리처럼

- **초기 외형 기준:** 작은 몸체·빠른 다리/턱·마디가 분명한 `절지/벌레형 이능 생물` **한 계열**을 추천한다. 얇은 파티클 구름·검은 모래 효과처럼 보이지 않게 **머리/몸통/움직이는 다리·아가미/작은 날개 등 구체적인 생물 실루엣**이 있어야 한다. 정식 모델·종류는 사용자 미승인.
- **평상시:** 플레이어 곁의 낮은 위치나 주변 공간을 작은 무리가 이동하되 채굴 중 시야를 막지 않음; 먼 사람에게 다리/날개마다 개별 엔티티 동기화 금지.

- **증식:** 주인 근처/군체 중심에 아주 작은 개체가 나타나 군집에 합류하며 수량 보충. 메뉴·부화대/매번 인벤토리 클릭/실제 번식 AI 추가 강제 X.
- **질적 강화:** 개체 공격력 업그레이드 후 턱·공격 모션/충격감을, 개체 생존력 업그레이드 후 갑피·피격 반응을 조금 강화. **모델/텍스처 변형은 공통 매개체 등급과 혼동하지 않고 실제 시각 검수 전 세부 미확정.**

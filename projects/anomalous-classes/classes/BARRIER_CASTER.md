# 결계술사 — 결계 배치·방호/구속/공격·공간 장악 1차 기획

> 2026-11-04 / **DESIGN PROPOSAL — 사용자 검토 전.** [PROJECT.md](../PROJECT.md)의 확정 직업 정체성은 **"방어·공격·구속 및 공간 장악 결계를 사용한다"**이다. 다음 3운용 방식·기본 결계 1개·수치·조작·장비는 새 제안이며 확정된 기술 구현/플레이테스트가 아니다. **이 직업의 이름, 별도 직업 목록, 공용 성장과 5등급 규칙은 변경하지 않는다.**

## 1. 독립적인 직업 역할

**결계술사 = 위치·경계선과 시간을 설계해 적의 접근을 제한하고, 보호한 공간을 공격 기회로 전환하는 직접 전투형 지역 제어 직업.**

| 직업 | 핵심 차별화 |
|---|---|
| 정신 지배자 | 몬스터 여러 기의 AI와 행동을 지배 |
| 인형술사 | 수제 인형을 여러 기 운용하는 자동 전투 |
| 기생술사 | 현재 숙주 1기를 직접 조종하며 생물 기술을 계승 |
| **결계술사** | **몬스터를 소유하지 않고, 내가 만든 결계의 경계와 위치를 통해 전장의 흐름을 바꿈** |
| 중력술사 | 엔티티에 중력을 가해 끌고 띄우고 낙하시킴(결계가 적을 한 곳으로 지속 흡인하는 직업이 아님) |
| 공명술사 | 진동·표식·연쇄 충격 효과로 피해를 만듦(결계의 트리거 공격과 별개) |

- **재료 제작/소환 군단/새 장비 대량 관리**를 본업으로 만들지 않는다. Minecraft 일반 무기/채굴·건축·인벤토리 사용 가능.
- 결계는 **플레이어가 월드 내 일정한 위치에 세우는 임시 공간 규칙**이지 무적·기지 전체 영구 보호권·무한 월드 클레임이 아니다.
- 높은 레벨과 강력한 보스가 와도 **적을 영원히 가두거나 모든 공격을 막는 무한 요새**가 되면 안 된다. 한편, 보스에게 통째로 무효라면 후반 성장도 의미 없어지므로 부분 저항/내구 소모로 표현.

## 2. 하나의 결계 시스템, 세 운용 모드

공통 '결계 생성'의 **영역·경계·지속시간·내구** 구조를 공유하고, **어떤 결과를 얻느냐**만 모드로 고른다. 3개의 전혀 다른 물리 엔진이나 10개의 관리 슬롯을 만들지 않는다.

| 결계 형태 | 핵심 행동 | 처음 사용하는 상황 | 약점·대가 |
|---|---|---|---|
| **방호 결계** | 경계로 들어오는 적의 투사체와 위험한 접근 공격을 **결계 내구도에서 일부 받아냄**. 아군은 통과/행동 가능 | 좁은 동굴에서 회복, 주민·동료를 지키기 | 계속 공격받으면 내구가 부서짐. 영역 밖의 적에게는 별도 피해 없음 |
| **구속 결계** | 적이 경계를 밟거나 넘을 때 **짧게 감속·이동 제약**. 제대로 위치를 잡아야 전투에서 의미 있음 | 돌진 몹 막기, 이동 방향 차단, 후퇴 확보 | 적을 영원히 가둬두지 못함. 보스는 효과 시간이 단축됨 |
| **반격 결계** | 적이 경계를 넘거나 결계를 공격할 때 **제한된 반격 피해**·짧은 밀침을 발생 | 근접 적이 몰려오는 좁은 입구, 예측 배치 | 경계에 접근하지 않는 원거리 적에게는 무의미. 연속 트리거 남용 방지 |

### 공통 구조

- **기본 동시 활성 결계 1개** 후보. 역할을 전환하려면 모드를 고른 뒤 결계를 새로 설치한다. **스킬 트리로 최대 2~3개까지 늘리는 안**은 후속 검토(기본 1기만으로 답답한지/성능을 실제 테스트). 무제한 레벨이라고 영역 개수가 자동 수십 개로 폭증하지 않는다.
- 초기 결계는 **바닥 위치를 지정해 세우는 경계가 명확한 원형 영역** 후보(예: 반경 **3.5블록**, 지속 **14초**, 설치 **12초 재사용**). 경계 외형은 얇은 발광선·조형화된 문양/면으로 표현하고, **실제 효과 범위와 화면상의 경계가 일치**해야 함.
- **결계 내구도**는 방호할 때 받아낸 피해로 소모하는 **월드에 놓인 결계 자체의 체력**이다. 새 직업 전용 마나바/현금/희귀 연료를 추가하는 게 아니라 결계를 활용할 수 있는 한계를 나타낸다. 구속·반격 결계도 공통 지속시간/트리거 횟수 상한을 공유. 기본 결계 몸체를 파괴·만료하면 자동 사라짐.
- 사용자의 주손·보조 손·[직업 매개체 공통 1슬롯](../CLASS_FOCUS_SLOT.md)을 보존. 결계는 직업 장비 없이도 사용 가능하며, 직업 장비는 나중에 결계 내구·반경/스킬 피해 등 **직관적 효율 향상**을 제공할 수 있음.
- **결계 위치는 플레이어의 조작 선택**이므로 설치 후 부동. 설치/모드 전환/만료를 아무 때나 반복해 상태 이상 중첩·쿨타임 초기화하는 버그 방지. 결계 만료 전에 새 배치를 할지/철거를 할지는 기본 안전성 검증 후 결정.
- 기본 이동·일반 무기 공격/아이템/채광/건축은 정상 사용. 결계는 실제 블록을 영구 대체하지 않고, 지형 파괴·분해·청크로드·월드 소유권 변경을 수행하지 않는다.

## 3. 기본 행동과 액티브 후보 (기술 수 최소화)

| 행동/기술 | 입력과 효과 | 왜 필요한가 |
|---|---|---|
| **운용 모드 선택** (기본 조작) | 방호/구속/반격 중 선택 | 결계 3개를 별개의 스킬바로 늘리지 않음 |
| **결계 설치** (기본 스킬) | 조준한 위치에 선택한 모드 결계 전개 | 방어·CC·반격을 동일한 규칙으로 사용 |
| **결계 회수/해제** (기본 조작) | 소유 결계를 조기 해제 | 잘못 설치한 결계를 지울 수 있음. **해제했다고 재사용대기 무료 초기화 불가** |
| **경계 압축** (액티브 후보) | 현재 존재하는 결계의 **남은 내구/지속시간 일부를 희생해 경계 안쪽에 짧은 파동과 적 넉백** | '지키다가 반격'이라는 전략을 만들어냄 |
| **결계 증폭** (액티브 후보) | 짧게 현재 결계의 방호량·구속·반격 효과를 강화, 대신 결계 내구 소모 가속 | 위급한 순간 결계 유지와 폭발적 강화 사이에 선택 |
| **즉시 방벽** (액티브 후보) | 목표 방향에 아주 짧은 일회용 얇은 방어면 전개(지속 2초 수준) | 월드에 설치한 결계 밖에서 돌발 투사체를 받아내는 숙련형 방어 |

- **수치 후보**: 경계 압축 재사용 **20초** / 증폭 **30초** / 즉시 방벽 **24초**. 시전 조건·내구/시간 비례 계수와 빠른 방벽의 성공 판정은 플레이테스트 후 조정.
- **방호와 구속을 단순히 같은 둔화로 만들지 않는다**. 방호는 서버가 실제로 공격/투사체가 경계를 통과하는가를 판정해야 하고, 구속은 타깃의 이동/행동을 실제로 짧게 제한해야 한다.
- **경계 압축은 언제든 무료 광역 데미지를 주는 별도 무기**가 아니라, 남아 있는 결계 자원을 소비하는 종료 기술. 결계가 없으면 발동 불가. 이 기술과 반격 결계의 피해는 다른 보스 피해 규칙을 따른다.
- **즉시 방벽은 완전 무적/일정 시간 자동 방어**가 아니라 타이밍·방향을 요구하며 한정된 투사체/공격을 막는다. 외부 몹의 모든 보스 공격과 광역기를 무조건 소거하지 않는다.
- 잘못 배치했을 때는 무료 재설치 연타 대신 **보이는 결과/실패 사유 안내 + 기본 회수 가능**으로 조작 스트레스를 줄인다.

## 4. 실제 서바이벌과 만나는 플레이 예시

**초반 동굴:** 좀비가 통로를 통해 접근하면 구속 결계를 좁은 입구에 두고, 뒤로 물러나며 바닐라 무기로 싸운다. 스켈레톤 투사체가 위험한 통로에서는 방호 모드로 바꿔 짧게 엄폐한다. 설치가 빗나가면 공격을 무조건 멈추는 것이 아니라 평소 채광/도구/이동으로 대처 가능.

**중반 주민 구출:** 주민을 보호하려는 길목에 방호 결계를 둔다. 아군 주민·소유 인형·동맹 유저는 통과/행동에 제약을 덜 받고, 적의 접근/투사체만 내구도에서 소모되며 보호된다. 플레이어가 실제로 모든 세력을 안전하게 통과시킨다는 뜻은 아니며 **아군/중립/적대는 [ALLY_RELATIONS.md](../ALLY_RELATIONS.md) 공용 서버 판정**을 따른다.

**후반 보스전:** 보스 돌진 경로를 읽고 구속 결계를 깔면 일부 이동 제약, 공격 경로에 방호 결계를 놓으면 일부 피해 흡수, 보스가 결계를 때렸을 때 반격 모드로 전환할 유인이 생김. 보스에게 영구 봉쇄는 불가능하고, 시야/정확한 배치/기다린 타이밍이 강함의 원천.

## 5. 장기 성장·스킬 트리 방향 (별도 상세 예정)

- 공통 RPG **레벨 상한 없음**, 경험치·스킬 포인트·직업 장비 5등급 **규격→변조→변칙→이형→불가해** 유지. 결계술사는 '배치/내구/공간 제어/반격' 효율과 정교한 사용 능력이 증가해야 하며 물리 근접 공격만 단순 곱셈하는 직업이 아님.
- 패시브 3계열 제안: **형성(결계 반경·강도·지속)** / **경계(구속·방호 규칙과 반응)** / **역전(반격·압축·배치 적응)**. 아직 노드 수/총 랭크 확정하지 않음.
- **시각적 방어 벽이 실제 적 화살/돌진을 막는지**가 플레이어에게 중요. 보스·모드 피해 어댑터를 검증하지 않고 '모든 공격 방어'로 표시 금지.
- 고레벨이 되면 결계 수가 아니라 **다른 지역을 맡기거나 압축·방어를 동시에 운용하는 선택**이 늘어나야 한다. 동시에 존재하는 결계 수는 예산/성능을 고려해 제한하고, 레벨 성장에 따른 기본 HP/공격 보정은 차기 정본에서 구체화.

## 6. 멀티플레이·몹 AI·보호구역·성능

- 각 결계는 **시전자 서버 UUID·팀·형태·위치·반경·내구·수명·타격/트리거 당 재사용 제한**을 갖고 서버가 확정. 다른 플레이어가 결계를 손쉽게 훔쳐/삭제/무한 복제할 수 없어야 함.
- 실제 적의 근접 접근·투사체가 결계를 만날 때 적절한 **경계 충돌/방어 이벤트**를 발생시키며, **시전자/아군 통과·아군 투사체의 일방향 공격**은 권한과 기하 판정에 맞춰야 함. 중립 몹·주민은 기본적으로 적대 몬스터처럼 강제 공격하지 않음.
- 결계가 길을 막아 적·주민·몬스터 AI의 경로탐색을 영구 고장내지 않게 일시적 공간 충돌/경로 차단 최적화 필요. **직접 block setBlock 대량 배치/매 tick 전역 몬스터 반복 검색/대형 Display Entity 남발**을 기본 구현으로 선택하지 않는다.
- 서버/월드 재시작·차원 이동·소유자 사망·청크 언로드 후 영구 보호결계가 남거나 플레이어를 가두지 않게 수명과 소유 상태 동기화. 파티, 정신 지배체/인형, 기생 숙주와 공용 피해/피아 식별을 그대로 사용.
- 피해 타입/광선/보스 음파·마법·폭발은 vanilla projectile과 다른 판정을 가질 수 있어 실제 MC 버전/다른 모드와 연결 시 지원 범위를 명시. 보호구역/블록 파괴/포털·엔더드래곤·워든 충돌을 우회하지 않는다.
- 결계 VFX는 얇고 알아볼 수 있는 실제 공간 표식·면·파열 때의 애니메이션/사운드가 핵심. AI 임의 색 사각형·무의미한 반복 오라로 마무리하지 않는다. 최종 UI/텍스처/모션은 외부 레퍼런스 기반 Codex와 함께 검수한다.

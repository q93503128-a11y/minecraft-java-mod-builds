## 1. 성능·입력 계약

1. **1계약 전투 완결**: 계약 직후 본체 가호가 상시 정상 적용되고, 대표 직접 권능은 유효 적을 바라보거나 시전자 기준으로 눌렀을 때 **별도 선행 조건 없이 본효과**를 낸다. 서브 액티브는 방호/위치·기동/타이밍·폭딜 등 주력과 구별되는 실제 선택이어야 한다.
2. **가호 / 고유 패시브 / 액티브 / 현현 분리**: 본체 HP·공격·이동의 기본 가호를 고유 패시브 1개로 억지 집계하지 않는다. 패시브는 별도 키 없이 상시 또는 평타 적중·권능 사용·피격 등 **자주 겪는 사건**에 반응한다. 한 존재당 **2~3개 차별화된 고유 패시브를 목표로 검토**하지만 단순 수치 복제·과도한 조건이면 줄인다. 숫자를 채우기 위한 버튼이나 노드 금지.
3. **연계는 추가 보상**: 낙인 중첩/방어 성공/실제 회피/먼저 특정 권능 시전/특정 방향 공격은 부가 강화에 쓰되, 그 전에도 주력 액티브의 원래 피해·방어·기동 성능은 정상이어야 한다. 공통 기본 효과를 만들기 위해 새 자원바·반복 클릭·매번 제물 구매 금지.
4. **조건과 강도 분리**: 1위계 기본 역할은 이미 강해야 하고, 2/3/4위계는 동일 전문 분야에서 가호뿐 아니라 실제 전투 범위/강도·위기 대응·이펙트에서도 상위. **4위계의 초희귀 비용을 핑계로 평소 권능의 쿨다운/조건을 과도하게 악화시키지 않는다.**
5. **기존 위험 보존**: 벨칸의 현재 HP 희생, 하스텔의 실제 채무, 계약자별 금기/조항·관계, 제물/현현 비용은 정체성이다. 제거하거나 무료 무적·무료 계약 해약으로 우회하지 않는다. 하지만 **평타·보통 권능마다 비싼 제물/신규 유지 게이지**를 요구하지 않는다.
6. **다중 계약은 선택**: 평소 초중반 1계약/가끔 2계약을 시험 단위로 쓴다. 3개 이상 유지 가능, 새 n번째 계약 체결 제물은 1/2/4/8/16배, **정기 유지비 없음**, 동일 스탯 최강 가호 100%·각 나머지 50% 원칙 유지. 고유 패시브와 권능은 임의로 50% 약화/삭제하지 않는다.
7. **권능 입력은 조작키를 점유할 필요가 있을 때만**: 1계약 1~2개 직접 시전이 기본 예측이며, 자동 축적/수동 실행 준비는 별도 버튼으로 중복 등록하지 않음. 계약술사의 키/슬롯 수·R 역할은 아직 D09 후보. M 프로필·계약 관리도 사용자 검토 중인 공통 메뉴이며 전투 중 매번 열게 하지 않는다.

## 2. 제1위계 — 시작 계약 하나만으로 서바이벌 전투

### 이사엘 — 서광의 전령 / 보호·심판

- **상시 가호**: [기존 상향 후보](./PACT_TIER_1_2_DESIGN.md) 최대 HP +25%·평시 직접 공격 +15%; 낙인 대상 추가 심판 피해 +20%는 **별도 미검증 시험값**, 무한 곱셈 금지.
- **직접 권능**: `서광의 낙인`은 보통 적을 조준해 즉시 표식과 **첫 타격 자체의 효과**를 낸다. 표식 쌓아야만 첫 피해가 들어가는 구조 금지. `수호의 빛`은 자신/적법한 아군에게 즉시 의미 있는 피해 경감을 준다. 보호 성공 뒤의 반격은 **추가 보너스**이지 보호 자체의 선행 조건이 아니다.
- **고유 패시브 후보**: **서광 잔향**(유효 적을 평소 때려도 약한 빛의 후속 타격이 자연스럽게 발생; 낙인 적이면 더 효과적), **수호의 기색**(자신이 실제 위협을 받을 때 짧은 방어 보조, 상시 무적·수호의 빛 대체 아님), **심판의 호응**(보호한 뒤 반격하면 추가 빛 공격, 성공 못 해도 정상 낙인/수호 위력 유지).
- **30초 전투 예시**: 낙인으로 교전 → 무기/빛 추가타격 → 위험 시 수호의 빛 → 평타/재낙인. 보호 대상 주민/골렘이 없어도 혼자 충분히 강한 시작 계약.

### 벨칸 — 재의 거래인 / 화염·위험 근접

- **상시 가호**: 기존 근접 공격 +30%, 화염 권능 효율 +20% 상향 **시험값** 보존.
- **직접 권능**: `재화의 일격`은 현재 HP 일부를 **유효한 1회 시전 비용**으로 지불해 곧바로 강력한 화염 일격을 사용. 사전 잔불 3회 적중·낮은 HP 강제 조건 없이 기본 화력이 강해야 한다. 최대 HP 영구 손실·매 사용 희귀 아이템 제물은 요구하지 않는다.
- **고유 패시브 후보**: **잔불 각인**(보통 근접 공격에도 적에게 화염 잔흔을 남김), 기존 **붉은 갈망**(근접 교전/HP 위험에 따라 화력과 *제한된* 회복이 자동 발생하도록 하는 후보; 직접 발동 버프를 보존하는 대안도 승인 전 비교), **재의 피막**(불에 휘말린 교전에서 자연스러운 화염 저항·짧은 생존 보조).
- **30초 전투 예시**: 강화된 평타로 싸움 → 적에게 유의미한 화염 일격 → 갈망/재의 보호로 버팀 → HP 여유 계산. 피를 많이 잃어야만 강해지는 강제 저체력 운영이 아니라, **위험하면 더 큰 보상이 붙는 강한 기본 근접**.

### 우르겐 — 산맥의 자손 / 육중한 근접·채굴

- **상시 가호**: 기존 HP +40%, 근접 공격 +25%, 채굴 +15%, 넉백 저항 상향 **시험값** 유지.
- **직접 권능**: `거인의 주먹`은 적에게 선행 조건 없이 강한 근거리 타격. `지반 파쇄`는 원래 전방 광역 충격/짧은 밀침을 **단독으로도** 사용. 주먹→파쇄는 큰 보너스 연계일 뿐 정상 파쇄에 필수 아님.
- **고유 패시브 후보**: **대지의 버팀**(평소 지상 이동·근접 중 넉백/타격 흔들림 완화, 기본 가호 넉백 저항과 중복 수치를 두 번 곱하지 않음), **강격의 여운**(평타/주먹이 실제 유효 적에 맞을 때 한정 압박 반응), **지반 감각**(채굴/험한 지형에서 낙하·충돌 안정 보조; 신규 광석 탐지/광물 생성 아님).
- **30초 전투 예시**: 적 접근 견딤 → 주먹 또는 광역 파쇄를 상황에 맞춰 사용 → 무기 타격으로 밀어냄. 채굴 중에도 유효한 편의 가호가 자연스럽게 작동.

### 리드나 — 길 잃은 별 / 기동·기습

- **상시 가호**: 기존 이동 +15%, 직접 공격 +15%, 도약/회피 후 기습 +25% **시험값** 유지.
- **직접 권능**: `성간 도약`은 벽·충돌·청크/보호구역을 서버 검증하여 짧은 거리로 **즉시 안전 이동**. `별빛 궤적`은 도약을 먼저 하지 않아도 유의미한 기본 원거리/경로 타격, 도약 직후면 더 강해지는 구조.
- **고유 패시브 후보**: **안전한 여명**(일반 도약·낙하 피해를 완화하여 탐험에 편의), **별의 잔영**(성간 도약 직후 짧은 피격 부담 완화; 완전 무적 프레임 강제 아님), **선회 감각**(상대에게 위치를 바꾸며 싸울 때 무기 공격의 적중/추적 사용감 향상; 뒤를 잡아야만 정상 피해가 나는 것 아님).
- **30초 전투 예시**: 일반 무기로도 전투 유효 → 도약으로 유리한 위치 → 별빛 궤적으로 마무리/견제 → 재배치. 좁은 동굴에서도 최소 유효 사거리로 사용 가능해야 한다.

- **현현**은 평상시 액티브 수에 포함하지 않는다. 사용자 대가·사전 조건·확률적 출현(해당 존재만)과 특수 모델·이펙트는 보존하되, 현현을 사용하지 않아도 이미 강력.

## 6. 공통 270랭크 패시브 트리와 계약별 패시브의 관계

- 기존 공통 **육화·권능·교섭 9노드 ×30랭크 = 270랭크**는 일단 그대로 보존. 1SP/레벨, Lv300 약30시간 목표/종결급 성장, 레벨 무제한과 각 직업 고유 성장 원칙을 건드리지 않음.
- 계약별 고유 패시브는 **처음 해당 계약을 체결하면 바로 제공**한다. 공통 스킬포인트를 또 지불해야 해당 계약의 패시브 기능이 열리도록 하지 않는다. 공통 트리는 그 기반 위에서 성장 폭·연계 선택을 강화하는 역할.
- 1계약 기준 **무력 동화/육신 각인/위기 저항/권능 응축/무장 직조/술식 순환**은 즉시 의미 있고, **관계 공명**은 관계 성장 이후, **심화 내재화**는 심화 이후, **이중 조율**은 실제 두 개 이상의 계약 후에 의미 생김. 레벨1 플레이를 이 세 노드로 유도하는 메뉴/추천 UX 금지.
- 기존 v1의 '공통 3개 노드×10랭크 추가하여 300랭크'는 계속 **미승인 후보**. 이번 작업의 목표는 직업 체감 개선이지 총 노드를 늘리는 것이 아니다. 신규 고유 패시브를 전부 30랭크 상수 증가 스킬로 전환하거나 후반 SP 노가다 유발 금지.
- 한 플레이어가 여러 계약을 가진 뒤 같은 종류 패시브가 겹쳐도 **기본 가호 100%/50% 스탯 규칙과 고유 효과를 분리**한다. 중복 한 공격 사건에서 3~5개 동일 피해 루프 무한 재귀 금지. 불필요한 전역 '1계약만 발동' 제한도 금지: 각 계약이 가진 고유 전투 가치는 실제로 누릴 수 있어야 한다.

## 7. 빠른 구현 판단·테스트 계약

### A. 사용성

- 버튼 사용 자체의 전제는 적법한 표적·거리·시야·충돌·해당 계약을 실제 체결했음·기존 쿨/명시 비용 등. **표식 N개/완벽 회피/스킬 순서/유적 방문/비가 옴 등**은 '기본 효과를 강제로 사용 불가'로 표시하면 실패.
- 적 1명/3명/원거리 적/보스/좁은 동굴/야외/물 밖을 차례로 상정해서 기본 기술이 유효한가, 버튼 선택의 이유가 다른가, 패시브가 실제로 자주 터지고 이해되는가를 확인.
- 패시브는 명확한 짧은 VFX/적중 피드백으로 보이되 HUD에 3~5개 실시간 게이지·중복 점멸 남발 금지. 지나치게 자주 발동한 동일 효과는 시각만 합쳐서 읽기 쉽게 하고 실제 서버 피해·회복이 실체와 일치해야 함.

### B. 밸런스 경계

- 기준: **1계약 플레이어가 같은 레벨·비슷한 장비의 다른 직업보다 약하다는 이유로 더 많은 계약을 강요받지 않는가?** 강한 분야와 약한 분야는 특색으로 남겨도 되지만 '항상 도구 공격만 해야 한다'면 미완성.
- 비교 대상: 결계술사 독립 압축/방어/격리+보조, 인형 3액티브+본체와 인형 실제 DPS, 군체 자동 행동/급습·소모, 정신 지배체, 기생 실제 숙주와 계승. HP/공격 %만 단순 합산해서 강하다고 판단하지 않음.
- 지표: 1계약 일반 몹 TTK, 3몹 전투시간/피해, 스켈레톤 원거리 생존/거리 접근, 보스전 지속 DPS·실제 피격·한 번의 기술 적중률·불필요한 입력 수. 시험값을 실측했다고 주장하지 않음.
- **기존 1·2위계 상향 G.6 후보와 3·4위계 기존 시험값**을 잠정 비교 기준으로 쓰되 새 수치·쿨다운을 임의 승인하지 않음.
- 외부 몹 API 미지원 기능은 보수적으로 기본 유효 공격/피해 대처를 남기고, 지원되지 않는 필살기·완벽한 AI 사전예측을 허위 구현하지 않는다.

### C. 소유권과 저장

- 캐릭터가 가진 계약 ID/활성 권능·고유 패시브/관계·제물·심화가 서버 최종 상태. 계약 파기/금기/직업 변경·죽음/재접속·멀티 중 같은 패시브를 중복 설치/사라진 계약 버프 잔류/공짜 회복이나 무한 적중 루프가 없어야 함.
- 한 번 누른 권능은 명확한 서버 승인/거부가 있어야 하고, 피격이든 공격이든 패시브는 사건을 한 번만 처리. 플레이어에게 개발자 상태·밸런스 실험 명칭 표시 금지.
- 시전 패킷/조준 대상/타인 소유/보호구역·PvP 허용·월드 지형 파괴 설정과 원본 바닐라 무기/방패/도구 사용 보존.

# 군체술사 — 공격·엄호·번식 270랭크 공통 패시브 시안

> **최신 8차 정정 (2026-11-05):** `군집 엄호`는 **액티브 기술이 아닌 전술 설정의 상시 엄호 역할**이다. 플레이어가 직접 이름 지어 저장한 전술의 엄호 비율로 자동 수행되고 별도 버튼/쿨타임/지속시간/무료 버프가 없다. 주력 액티브는 현재 **군집 급습·군체 소모** 두 종. 이전 3번째 엄호 액티브 후보·효과는 채택하지 않음.


> 2026-11-05 / **DESIGN PROPOSAL · NEW NUMBERS UNAPPROVED/UNTESTED.** [군체 정본](./SWARM_CASTER.md) / [피격·자연 증식](./SWARM_COMBAT_GROWTH_V3.md) / [공격/엄호 동시 분담](./SWARM_SPLIT_FRONTLINE_V4.md) / [5등급 군체 핵](./SWARM_FOCUS.md). 사용자 방향: 큰 군체는 공격·엄호 동시 분리, 엄호 군체가 화살·원거리 공격을 맞아 개체를 잃고 시야를 방해하지 않음; 소모/재증식·원격 표적·무제한 레벨·개체 공통 성장 보존. 중력술사/공명술사 상세 보류.

## 1. 설계 원칙

- **자동 레벨 성장:** 최대 군체 수(논리 `Nmax`)와 기초 개체 공격·생존력, 성장 곡선은 캐릭터 레벨에 따라 자동 개선하는 방향. **'최대 수량 패시브'로만 군단을 커지게 하지 않는다**. 무제한 레벨→무한 물리 AI 소환은 금지.
- **스킬 포인트:** 수량 N을 버튼으로 즉시 +N 늘리지 않으며, 군체 하나하나에게 XP·장비·성장 트리를 주지 않는다. **군단 전체의 개체당 질적 강화, 엄호 위치/투사체 대응, 급습·희생 공격 효율, 시간에 따른 자연 재증식**을 강화.
- **역할 분담 자체는 기본 기능:** 충분한 N에서 공격대와 엄호대가 자동 분리·동시 활동. 별도 고위 패시브 투자·특정 고등급 매개체가 필요하지 않음. 원격 표적 지정도 무쿨타임/무소모 기본 명령.
- 기본 자연 증식·원격 표적과 **군집 엄호 전술(상시 행동)**은 기본 기능이고, **군집 급습·군체 소모**는 액티브 기술이다. 군집 엄호를 별도 액티브/쿨타임으로 두지 않는다. 패시브는 자체 효과를 **전투 손맛·수량 유지·선택**에서 보강하고 불필요한 새 단축키/강화 화면을 만들지 않는다.
- 270랭크는 타 직업 정신 지배자 270/기생 285/인형 290/결계 300 등 기존 **미검증 성장 규모를 참고한 숫자**이다. 사용자가 새로 확정한 것이 아니며 실제 전투/레벨당 스킬 포인트 지급 속도를 먼저 비교해야 함.

## 3.1 5차 비행의 스킬 트리 연계 (2026-11-05)

[군체 탑승 비행·공격/엄호/운반 분리·전투 밸런스 시험](./SWARM_FLIGHT_AND_COMBAT_BALANCE_V5.md) 참조.

- **비행 자체는 스킬 포인트로 구매하는 신규 노드가 아니다.** 캐릭터 레벨에 따른 충분한 군체 수·개체의 운반력으로 진짜 호버링/상하좌우 이동을 얻는 신규 후보. 이전 사용자가 승인한 무제한 레벨 성장·자연 증식은 유지.
- **9패시브와 270랭크는 그대로.** 새로 4번째 계열이나 270랭크 초과 신설하지 않고 기존 `무리 추적`의 **집단 기동 개선**을 비행 반응/가속 일부에도 연동할 수 있는 후보. **조작이 불편하거나 시야가 가리는 문제는 스킬 포인트 0에서도 발생하지 않아야 한다.**
- `단단한 갑피`는 비행 중 실제 피격된 **운반 군체**의 내구에도 정상 적용한다. 탄도 감각은 우호 판정·실제 탄도와 일치하는 엄호를 돕지만 **화살을 무료 삭제하지 않는다**.
- 공격대·엄호대·운반대를 별도 육성하거나 별도 3개 게이지를 추가하지 않는다. 한 개의 현재/최대 N을 유효한 역할에 분담하고, 실제 손실은 N에서 차감한다.
- 비행의 레벨별 해금 시점·속도·추락 보호·공격 손실 보정은 전부 **시험안**. 추후 실제 실전 테스트 전 수치 확정 금지.

## 4. 자동 레벨 성장 (공식·수치 미확정)

| 항목 | 장기 성장 방향 | 중점 |
|---|---|---|
| **플레이어 최대 HP** | 기본 20HP 시작을 다른 직업과 비교, 실제 자동 증가 계수는 아직 미정 | 플레이어 개인도 순식간에 쓰러지는 약한 조종수만 남지 않게 |
| **논리 군체 최대 Nmax** | 플레이어 레벨에 맞춰 상향·구간 성장(1위 계열과 무관) | 서버 물리 개체 1:1 복제 금지, 개체수가 늘어날수록 병력 규모 체감 |
| **개체 기본 공격** | 레벨 무제한 성장 | 마릿수만 늘리는 방식의 고레벨 한계 보완 |
| **개체 기본 내구** | 레벨 무제한 성장 | 강한 적이 한 방에 군체 전체를 전멸시키는 문제 방지 |
| **기본 재증식** | 캐릭터 레벨·실전 수량 상한에 맞춰 적정 보충 | 사용자가 버튼·먹이를 반복해서 누르지 않아도 복귀 |

- 실제 계산 순서 후보: `baseMaxCount(level)`, `currentCount <= Nmax` → `baseUnitAttack(level)` / `baseUnitDurability(level)` → 공통 공격/엄호 패시브 합산 → 현재 군집 분할 역할/소모 수량 → [매개체](./SWARM_FOCUS.md)의 개체 공격·내구 추가 보정(한 번) → 서버 전투·피격·재증식 이벤트. 숫자 폭주/계산 순서를 실제 모드 소스로 테스트 전 확정하지 않음.
- **기본 Nmax가 레벨에 비례하여 물리 엔티티 N개를 소환할 수 있는 권한**을 뜻하지 않는다. 군집 논리 수량과 클라이언트 생물 렌더링 밀도 별개.
- 목표 테스트: 레벨 1/25/100/500, 군체 N=0/저수량/80/100% 및 보스+다수 적+동시 플레이어, 투사체 피격의 단일 손실·원격 급습+엄호 동시 사용·시야/FPS/TPS.

## 5. 구현·비주얼 경계

- 공격대/엄호대 각각 위치/표적/수량을 가진 **소수의 유효 군집 단위**로 서버가 통제. 화면에서는 동물형 작은 생물 다수가 공격·엄호 중 개체들이 죽고 다시 나타나는 애니메이션이 있어야 한다.
- **화살/삼지창**은 실제 궤적과 엄호 충돌체 교차 시에만 개체 내구를 잃고 투사체를 멈추는 방법으로. **폭발/레이저/외부 몹 공격**까지 무조건 자동 차단한다는 약속 X. 본인/동료 화살 차단 금지.
- 시야 방해를 '장비나 스킬 투자하면 서서히 고쳐지는 약점'으로 만들지 않는다. 모델은 평상시 조준 중앙을 비우고 소형 생물의 각도를 적절히 조정, 1인칭/3인칭 시각 QA.
- 인형술사와 다르게 작은 개체마다 서로 다른 무기/부품/레벨을 주지 않는다. 계약술사와 다르게 희귀 제물을 매번 소모하지 않고, 정신 지배자와 다르게 기존 몹의 AI를 탈취하지 않는다.

## 1. 평가 단위 변경: '전 계약자의 총 32개'가 아니라 '내가 맺은 1개'

- 기획 후보 계약자 16명×기본 권능 2개 = 32권능은 **월드에 등장 가능한 후보의 전체 합계**일 뿐, 한 플레이어가 즉시 쓸 수 있는 액티브 수가 아니다.
- 기본 평가는 **1계약**, 추가로 **2계약** 비교. 3개 이상은 지원하되 평범한 초중반 전투 밸런스의 필수 전제로 삼지 않는다. 두 번째 계약의 첫 계약 대비 제물 2배/세 번째 4배 소프트캡, 가호의 같은 스탯 최대 100%+나머지 각 50%, **정기 유지비 없음** 유지.
- **계약의 구성 후보:** (a) 이미 있는 직접 전투 가호/본체 성장, (b) **전투 행동에 의미 있는 서로 다른 고유 패시브 2~3종**, (c) **직접 사용하는 1~2개 내외의 주력/보조 권능**. 특수 존재는 적합한 형태로 달라도 된다. 이것은 **추천 틀**이지 모든 존재에 정확히 2액티브·3패시브를 강제하는 숫자 규칙이 아니다.
- **기본 가호 vs 고유 패시브:** 최대 HP +N%, 공격력 +N%는 '기본 가호'이지 3종 패시브로 중복 집계하지 않는다. 고유 패시브는 해당 계약이 **전투 방법/판단을 바꾸는 별도의 조건·반응·연계**를 뜻한다. 계약술사 공통 패시브 트리는 별도로 존재한다.
- **발동 분류:** 직접 발동 권능 = 별도 눌러야 유의미한 선택(타이밍/목표/위치/비용); 조건형 권능 = 조건이 성립하면 자동 발동하거나 상태가 쌓이는 효과; 상시 가호 = 기본 능력치 강화; **현현** = 일부 존재만 가진 별도 고비용 특별 사건. **액티브/가호/조건형/현현을 더해서 '스킬이 많다'고 주장하지 않는다.**
- **완성 요건:** 한 계약자가 (1) 일반 적과 싸우는 실제 반복 루프, (2) 강적/보스의 위치·타이밍·방어를 바꾸는 선택, (3) 기존 채굴·무기·방패와 자연스럽게 연결되는 보상, (4) 연계 실패/적 이동/성공 판정이 분명해야 한다. 단순 버프 + 긴 쿨 1타만 제공하면 재작업.

- **직접 권능 ① 거인의 주먹:** 근접 목표 한 기 또는 짧은 전방 구역에 강한 충격. 가장 자주 사용 가능한 기본 계약 권능이어야 함.
- **직접 권능 ② 지반 파쇄:** 전방 부채꼴로 실제 맞은 적 여럿을 약하게 밀치고 짧게 자세를 흐트러뜨리는 공격. 보스 강제 기절/무한 경직 금지.
- **고유 패시브 A '굳건한 발' 후보:** 지면에 서서 유효 적의 공격을 견딜 때 넉백 복구/이동 안정성을 제공. 뛰면서 모든 원거리 공격 회피나 무적 불가.
- **고유 패시브 B '균열 포착' 후보:** 거인의 주먹에 맞아 실제로 자세가 흔들린 적에게 지반 파쇄가 후속으로 들어가면 추가한정 압박/경직 보너스. 같은 틱 반복 타격으로 무한 중첩 금지.
- **고유 패시브 C '파쇄 여운' 후보:** 지반 파쇄로 여러 적의 접근을 막는 데 성공하면 짧은 다음 근접 타격 기회/안정성이 생김. 타격 수가 많을수록 무제한 방어가 쌓이지 않도록 한 교전당 제한.
- **기본 루프:** 가호로 버티며 접근 → 거인의 주먹 → 흔들린 목표에 지반 파쇄 → 일반 무기 타격/후퇴. 채굴 중 기본 가호 효익 유지.
- **심화:** 주먹→파쇄 타이밍/범위/보스 단기 저항 대응을 개선. 세 번째 공격 버튼 불필요.

### 2.4 리드나 — 길 잃은 별: 안전 도약·각도 만들기·기습 타격

- **본체 가호:** 기존 상향 시험안 이동 +15%, 평시 공격 +15%, 도약/회피 직후 기습 추가 +25% **미검증** 유지. 기본 이동만 빠른 계약이 되지 않도록 직접 공격 연결.
- **직접 권능 ① 성간 도약:** 짧은 안전 위치 이동, 벽 관통/언로드/적 몸 안 겹침 금지. 맵 이동에도 유용하되 전투 기동이 주력.
- **직접 권능 ② 별빛 궤적:** 도약 후 열린 각도/표적을 활용한 직접 타격. 도약 없이도 약한 기본 타격은 가능하되 연계가 확실히 강해야 함.
- **고유 패시브 A '잔영 포착' 후보:** 성공한 도약 후 짧은 창에 첫 유효 무기/궤적 공격의 타이밍/적중 효율 향상. 회피 성공 시 다음 공격에 더 좋은 효과를 주되 동일 공격을 여러 번 복제하지 않음.
- **고유 패시브 B '위험 감각' 후보:** 도약 후 안전한 착지·낙하 피해 대응을 소폭 돕고 다른 이동이 이어질 수 있게 함. 안전하지 않은 좌표로 강제 생존/공허 구출·무료 장거리 탈출 없음.
- **고유 패시브 C '선회 공격' 후보:** 도약으로 적의 앞쪽/측면을 실제 바꾼 후 첫 타격은 목표의 방향에 따라 다르게 반응. 대상을 바라보지 않은 몹에 무조건 크리티컬을 부여하지 않음.
- **기본 루프:** 적 공격 방향 확인 → 성간 도약으로 위치 바꿈 → 잔영 창에 별빛 궤적 → 일반 무기 공격/재배치. 비행·대규모 공간 장악은 다른 직업 범위 침범 안 함.
- **심화:** 더 안정적인 착지·도약과 기습 공격의 연계를 강화, 위치 이동 횟수 무한 중첩 금지.

## 3. 제2위계 4종 — 1계약 플레이가 먼저인 역할 보강 (상세 후보)

## 4. 제3·4위계 8종: 기존 권능을 수동 두 개로 일괄 세지 않기 (분류 시안)

## 5. 계약술사 공통 패시브: 기존 9노드 보존, '1계약'에서 의미 있는 성장 확대

- 현재 [PACT_SKILL_TREE.md](./PACT_SKILL_TREE.md)의 **육화 3·권능 3·교섭 3 = 총 9노드×30랭크 = 270랭크 후보**는 삭제하지 않는다.
- 문제점: **교섭의 이중 조율**은 계약 1개일 때 효과 0이고, **심화 내재화**는 심화 전 효과 0이며, 관계 공명도 50 이상 관계를 올리기 전까지 효율이 거의 없어 1계약 초반에서 3노드가 즉각 무의미해질 수 있다.
- **수정 방향(후보):** 기존 노드 수/각 랭크를 즉시 늘리기보다 (1) 1계약 초반에서도 쓸만한 육화·권능 투자 경로를 명확히 표시, (2) 관계/심화는 해금 후 큰 수익을 주되 첫 전투에서 모두 선택하지 않게, (3) 여러 계약을 맺을 때만 발동하는 `이중 조율`은 **이중계약 전용 후기 선택**으로 명확히 안내, (4) 고유 패시브와 공통 스탯 패시브를 UI에 따로 표시.
- **추가 노드 3개 후보(별도 승인 전):** 육화 `계약 육체화`(10랭크: 자기 계약의 고유 패시브 실전 트리거 효율 향상, 기존 기본 가호 중복 강화 아님), 권능 `전투 응답`(10랭크: *같은 계약 안에서* 고유 패시브 조건이 실제로 성립한 뒤 다음 직접 권능의 반응/유효 타격 효율 개선, 이중 조율과 구분), 교섭 `서약 완수`(10랭크: **계약 1개만 있어도** 해당 존재의 실제 의무/관계 회복 유효 사건에서 조금 더 나은 관계 수익, 자동 농장/무고한 행위 조작 금지).
- 기존 9×30에 3×10을 추가하면 **300랭크 후보**가 되지만, **현재 270랭크가 자동으로 300랭크로 바뀐 것은 아니다**. 이 후보가 기존 노드와 실제 기능 중복이라면 랭크/노드 증가 대신 기존 9개 노드의 효과를 개선한다. Lv300 약 30시간/1SP 레벨업은 그대로이며 Lv300 전 스킬 트리 완전 해금 강제 조건 없음.
- 새 스킬포인트를 주는 별도 재화를 만들거나 특정 계약만 강화 가능한 공통 노드로 변질시키지 않는다. 계약을 파기/교체해도 공통 패시브 투자 기록은 계속 유지한다.

## 6. 키보드 조작: 기술 수를 부풀리기보다 유효 수동 권능만 바로 발동

- 계약 1개 기본 시 실제 직접 액티브는 보통 1~2종, 2계약 시 조건에 따라 대략 2~4종. 버튼 수를 채우려고 패시브/표식 충전/관계 유지/현현을 일반 공격 액티브처럼 HUD에 표시하지 않는다.
- **권능 직접키 `Z/X/C/V/B` 등은 D09 미확정 후보**. 기술/조건 분류가 정해진 뒤 해당 계약의 직접 발동 권능만 빠른 슬롯에 자동 제안/플레이어 변경 가능하게 배치한다. 항상 누르는 플레이 기능과 전투 입력의 수를 줄이는 것이 우선.
- `R`은 계약술사에서 아직 배정되지 않았다. 계승술사 `V`/숫자키 모드를 계약술사에 무단 복제하지 않는다. `M` 계약서·상세 가호·서약·금기·상태·기술 정보 확인은 공통 메뉴 제안이며 전투 중 수시 클릭 필수 UI로 만들지 않는다.
- 두 계약의 액티브를 번갈아 쓸 수 있으나 각 계약의 **고유 조건/금기/시전비용/쿨타임이 독립**되고 2계약의 가호 50% 합산이 직접 액티브 효과를 자동 절반으로 줄이는 규칙이 아님.
- 4위계 일부 현현의 희귀 제물/확인·조건부 개입은 별도 명시 UX를 유지. 싼 1위계 액티브처럼 무조건 바로 사출하는 숨은 단축키 배정 금지.

## 7. 검증 및 미결정

1. **1계약 테스트 4개:** 이사엘 표식/보호 연계, 벨칸 HP 위험/근접, 우르겐 충격/근접, 리드나 도약/기습. 각자 동굴 좀비 1·3·6마리, 스켈레톤 활, 보스 계열, 채굴/건축 중 전환을 실제 게임에서 검증해야 한다. 목표는 **직접 눌러야 할 스킬 개수나 수치가 아니라 플레이의 선택과 성능**.
2. **무계약/첫 계약 직후/1차 심화/2차 심화/2계약/3계약/고위 계약** 각 상태에서 가호·고유 패시브·공통 패시브·매개체·관계가 한 번씩만 적용되는지 확인.
3. 가호의 HP·공격·피해 보정과 기존 사용 가능한 권능의 **DPS/실제 공격 범위·CC/피격·생존**을 다른 직업의 동 레벨·비슷한 장비와 비교. 수치만 보면 강해 보여도 기본 한 계약의 실전 재미가 약하면 실패.
4. 서로 다른 계약 고유 패시브가 중복 획득됐을 때 스탯 무한 곱셈·농장/0피해 이벤트·아군을 때려 충전·PvP 서버 설정 우회 금지. 수동과 자동 전투 피해는 서버/소유권/계약 ID로 원자 판정.
5. **승인 전 남은 것:** 고유 패시브 명칭·정확한 효과 및 수치, 기존 '붉은 갈망/예조/채무 상환'의 자동 분류 최종 선택, 공통 3노드 추가 여부, 정확한 액티브 키, 초반 실제 전투 수치, 3·4위계 고유 패시브 확장.

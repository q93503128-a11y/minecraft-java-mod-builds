## 1. 한 계열, 두 스탯만 강화

**공생 핵은 '숙주 자체의 공격력·최대 HP'를 높이는 장비다.** 인형술사의 조종틀 보너스를 그대로 복사한 아이템은 아니지만 '등급이 높아질수록 단순하고 명료하게 강해지는 것'을 우선한다.

| 등급 | 현재 숙주 최대 HP 보너스 | 현재 숙주 직접 공격·계승 공격 피해 보너스 |
|---|---:|---:|
| 없음 | +0% | +0% |
| **규격** | **+5%** | **+5%** |
| **변조** | **+10%** | **+10%** |
| **변칙** | **+15%** | **+15%** |
| **이형** | **+20%** | **+20%** |
| **불가해** | **+40%** | **+40%** |

- **현재 한 개의 장비 등급만** 적용하며 낮은 등급 보너스를 별도로 누적하지 않는다. 공격 보너스는 서버가 계산한 현재 숙주 원래 공격/계승 폭발·특수 공격의 **실제 피해에 한 번만** 적용한다.
- 장비는 **숙주 안에 있을 때만** 스탯을 강화. 미기생 인간형에 숙주용 체력/공격 +40%를 똑같이 줘 허약한 인간형이라는 핵심 약점 제거 금지.
- **BD(생체 데이터) 최소 기생 요구치를 낮추거나 우회하지 않는다.** BD는 영구 성장 스탯. 장비 등급이 높다고 워든 기생 자격을 조기 획득하지 못한다.
- **특성 학습·기생 가능 BD·숙련 100 계승·재사용 대기·생존 전이 0~3충전·숙주 조종권·침투 시간에는 효과를 추가하지 않는다.** 장비 없이도 해금된 모든 종족 능력 사용 가능. [공통 매개체 슬롯](../CLASS_FOCUS_SLOT.md) 착용은 사용자 확정 방향이며 구현 UI·장비 API는 미정이다.
- 최대 HP 보정이 바뀔 때 현재 HP/최대 HP 비율을 유지해 **장착/해제/업그레이드 반복만으로 무료 회복**하거나 숙주 사망을 막는 악용을 방지한다. 죽은 숙주에 장비를 착용해 무료 부활 불가.
- 공용 레벨·BD·종별 숙련·패시브에 의한 스탯 강화는 각각 **한 번만** 곱/더함. 고레벨 극단적인 값은 서버 타입/클램프/실전 밸런스 검증.
- 장비 없어도 돼지 기생·생체 데이터 성장·거미/크리퍼 등 숙주 특성 습득·다른 숙주에서 전승 사용·자발적 이탈 가능.

## 2. 제작/승급 경로 — 다른 재화·제작대 추가 없음

바닐라 **제작대 3×3** 레시피로 장비 1개를 만들고, **바로 이전 등급의 공생 핵을 재료로 사용해 1단계 승급**하는 후보. **모든 표는 제작 슬롯 9개 이내로 구성 가능한 예시 입력 재료 목록**이며 특정 형태 배치는 나중에 데이터 레시피로 정의. 새로운 '기생제작대', 생체 조각 전용 화폐, 희귀 몹 20종 수집 조건을 만들지 않는다.

| 제작 결과 | 필요한 직전 장비 | 나머지 바닐라 재료 후보 |
|---|---|---|
| **규격 공생 핵** | 없음 | 구리 주괴×2, 실×2, 뼈×1, 썩은 살점×1 |
| **변조 공생 핵** | 규격×1 | 철 주괴×3, 레드스톤×2, 거미 눈×1 |
| **변칙 공생 핵** | 변조×1 | 금 주괴×2, 자수정 조각×3, 청금석×2 |
| **이형 공생 핵** | 변칙×1 | 다이아몬드×2, 흑요석×2, 블레이즈 가루×1, 발효된 거미 눈×1 |
| **불가해 공생 핵** | 이형×1 | 다이아몬드×2 + 네더의 별×1 **또는** 메아리 조각×4 + 네더라이트 파편×1 |

- 실제 희귀도 비교, 네더/고난도 구조물 대체 경로, 다른 직업 장비 진행 시점과 비용은 **검증 전**. 사용자 요청에 따라 숫자/제작 경로를 바꿀 수 있다.
- 해당 등급 장비가 여러 개 있다 해도 **장착 한 개만 유효**; 두 장비를 사용해 스탯/기생 허용치를 중복 적용하지 않는다.
- 장비 승급은 재료와 기존 핵을 원자적으로 소비하고 새 핵 한 개를 생성. 마우스 더블클릭/패킷 연타/리스폰·이사 과정에서 기존 등급과 새 등급이 함께 생성되지 않아야 함.
- 장비에 달라붙은 사용자의 레벨/원본 숙주/기생 기억 데이터를 저장하지 않는다. 모든 영구 BD·특성 기억·종별 숙련은 **플레이어 UUID**에 저장. 장비를 버렸을 때 성장 데이터가 사라지지 않음.

## 3. 아트·UX 경계

- **공생 핵**은 몸에 지니는 작고 특이한 유기질 핵의 이미지 후보. 무리한 생체 혐오/고어 묘사 없이 규격~불가해까지 재질·미세 발광·형태 복잡도만 발전. 다섯 등급이어도 같은 장비 계열로 인식 가능.
- 인간형에서 착용하면 증표가 보일 수 있지만 **스탯은 실제 숙주에 기생한 경우에만 적용**. 돼지처럼 손이 없는 숙주에서도 장비를 억지로 쥐게 하지 않고, 플레이어의 한 개 매개체 슬롯에서 효과를 계산한다(슬롯 확정·실제 구현 전).
- 툴팁은 **현재 숙주 HP +N%, 숙주 공격 피해 +N%** 두 항목만 보여준다. 'BD 요구치 -N%', '기생 기술 슬롯 +N', '워든 강제 기생' 등의 미구현 효과를 넣지 않는다.
- 최종 UI·아이콘·모델 작업은 Codex 담당. 실제 HP/데미지·승급 원가·장착/소유권·특성 학습 여부는 서버 권위에서 읽고 검증.

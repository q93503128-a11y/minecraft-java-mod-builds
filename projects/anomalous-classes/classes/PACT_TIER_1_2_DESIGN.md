# 계약술사 — 1·2위계 계약 정밀 설계 및 제단 월드 정책 (3차 기획 초안)

## A. 이번 대화에서 사용자가 새로 확정/강조한 방향

1. 계약술사는 플레이어 본인이 권능을 사용해 직접 강해지는 직업이다. 따라서 **대부분의 계약에 직접적인 플레이어 능력치 증가가 사실상 필수**다. 각 존재의 종류·성격별로 실제로 강화하는 스탯은 다를 수 있다.
2. **4위계는 같은 유형의 1위계보다 압도적으로 우수**해야 한다. 높은 위계와 훨씬 큰 계약/강화 제물 비용, 조항·위험에 걸맞은 강한 보상을 준다. 같은 분야에서 주력 성능을 동급으로 맞추지 않는다. 이전 문서의 '1위계가 후반에도 쓸모 있다'는 원칙은 **낮은 비용, 초기 접근성, 이중계약 보조 역할, 별도 유틸리티**에 국한하여 해석하고 동일 분야 4위계의 압도적 우위를 훼손하지 않는다.
3. **제단은 이전에 제안한 대형 성역·지하 의식실·거석·불가해 유적 같은 시각 완성도**를 추구하며, 이 수준을 목표로 1·2위계부터 구체화한다. 단 해당 이미지 자체는 참고(reference)이고 사용 라이선스·실제 건축/모델은 별도.
4. **'계약술사 플레이어가 존재할 때만 제단이 생성되도록 할지'는 사용자가 검토를 요청한 질문이다. 결론은 아직 확정하지 않는다.** 기술·멀티플레이 관점의 추천은 B절에 적는다.
5. 사용자는 **1·2위계 상세 기획을 진행**하도록 요청했다. 아래의 권능명·가호 수치·제물 수량·계약 조항 세부는 **검토 전 신규 제안**이다.

## B. 제단 월드 생성: 직업과 관계없이 생성 + 직업별 기능 분리 추천 (미확정)

- **추천:** 제단의 건축 구조물은 월드 생성 때 항상 고정적인 규칙으로 생성하고, 계약술사가 접근하면 의식 핵·시각 효과·계약 UI가 활성화된다. 다른 직업은 발견/세계관 정보를 얻을 수 있으나 계약 체결 권한 없음. 제단 건축 전체를 각 플레이어에게 따로 표시/숨기지는 않는다.
- 이유: Minecraft Java 월드젠은 chunk generation 중 시드·구조물 세트·바이옴 등에 따라 구조물을 결정한다. 직업 선택 전 생성한 청크에는 나중에 구조물이 자동 생기지 않는다. 플레이어의 직업이 바뀌면 이후 생성하는 지형에 구조물 빈도가 달라져 월드가 불연속적이 된다. 멀티플레이에서 계약술사 유무는 서버 공통으로 바뀔 수 있으므로 퍼플레이어 조건의 세계 구조물 생성은 의미가 불명확하다.
- 대안인 **직업 해금 후 이미 생성된 청크에 제단을 뒤늦게 삽입**하는 경우에는 플레이어 건축·지형 파괴/복구, 보호 구역, 청크 부하, 동시 서버 상태·월드 저장·중복 배치 및 기존 세이브 충돌을 처리해야 한다. 처음부터 채택하지 않는 편이 낫다.
- 필요 시 설정으로 **월드별 제단 생성 켜기/끄기**는 별도의 선택지로 만들 수 있다. 직업별 런타임 구조물 수를 결정하는 것과는 다르다.
- 제단 밀도/바이옴/구조물 크기·멀티 동기화·외부 월드젠 모드와의 실제 호환성·성능은 아직 측정되지 않았다.
- 구조물은 건축 블록/템플릿 위주, 애니메이션이 필요한 핵·특수 조형·현현에만 모델/VFX 사용 후보. 평상시 ticking entity 남발 금지. UI에는 **존재·가호·기술·제물과 소모 시점·금기·파기 위약금·이중계약 충돌**을 보여준다.
- 제1위계는 제단이 없어도 계약 가능해야 한다는 기존 방향을 유지하되, 그 접촉 UI/재료 형식은 미정. 제2위계 제단은 월드에 존재해도 모두가 계약 가능할 필요는 없다. 공용 제단과 개인 계약 상태를 분리한다.
- 근거 확인: [Minecraft Wiki 구조물/청크 월드 생성](https://minecraft.wiki/w/World_generation), [Structure definition](https://minecraft.wiki/w/Structure_definition). 정확한 버전/로더가 선정되면 공식 API를 재검증한다.

## C. 계약술사 스탯·위계 성장 공통 계약

### C.1 직접 전투 가호가 기본

- 대부분의 계약은 체결 즉시 **플레이어 본인의 유효 능력치를 바꾸는 기본 가호**(최대 HP, 직접 피해, 권능 피해, 이동/공격 속도, 방어·넉백 저항 등)를 준다. 단순 스킬 2개 추가가 아니다.
- 전투 전문 계약은 최소 하나의 주력 스탯 증가를 보장하는 방향. 탐험형도 이동·기습 피해·생존 스탯 등 유효 전투 보정을 함께 검토한다.
- 공통 레벨의 직업별 자동 성장, 스킬 포인트 투자는 독립적으로 유지. 계약 가호는 **성장의 대체재가 아니라 추가 축**이다. 스킬 포인트=계약 권능을 다루는 숙련, 제물 강화=계약 상대가 허용하는 권능의 규모라는 분담 후보.
- 고위는 체결 시 기본 가호부터 강하게, 강화될수록 더 큰 효과와 전용 권능을 준다. **동일 직업 레벨/장비/조건에서 같은 분야의 4위계는 최대 강화된 1위계보다 주력 전투·효율·기술 규모에서 명확히 우수**하게 설계한다. 다만 비교 지표와 최종 계수는 플레이테스트 전 미정.
- 타 직업과 비교 시 계약술사도 본체가 직접 싸우는 메커니즘을 보존한다. 계약 주인 소환체가 항시 자동전투하는 것을 기본 루프로 삼지 않는다.

### C.2 능력치 및 수치 폭주 위험

- **수치 시안(미확정):** 1위계 주력 스탯 보정 약 +8~18% 또는 최대 HP +2~4, 2위계 주력 보정 약 +15~30% 또는 최대 HP +4~6 등. 스탯마다 측정 단위가 다르고, 이는 절대 공통 규칙이 아니다. 공격 속도/이동/넉백은 별도 제한 검토. 기본 HP 기준은 Vanilla 20HP(하트 10개), 실제 공용 성장과 상호작용 재계산 필요.
- 고위 4위계의 전투 기여도를 1위계와 강하게 구별하되 단순히 모든 피해 계수를 4~5배 곱해 무한 레벨/외부 보스 콘텐츠를 무너뜨리지 않는다. 공격력·특수 권능·지속/범위·위기 대응을 함께 비교한다.
- 이중계약 시 **중복 가호의 단순 합산/곱셈 폭주를 피하고**, 같은 스탯 중복에는 더 높은 하나를 완전히 반영하고 다른 쪽 중복 기여는 감쇠하는 후보를 검토. 다른 종류의 스탯 보너스와 고유 기술은 가능한 한 정상 작동하도록 한다. 감쇠 비율/동시 계약 최대 수/주계약 지정은 **미정**, 자동 확정하지 않는다.
- 피격 전/후 HP 비율, 다른 모드 Attribute modifier와의 상호작용, 서버 소유권·직업 변경·장비 탈착·세계 재접속·죽음 중 보정 갱신은 구현 전 검증.

### C.3 제물로 심화

- 최초 계약 → 추가 제물 심화 I → 추가 심화 II/특수 돌파 등은 **구조 예시**이지 단계 수 확정이 아님. 강화는 단순 수치뿐 아니라 **권능의 행동 변화**를 제공한다.
- 매 공격에 물질 제물을 요구하지 않는다. 최초/심화/대형 권능·현현/면책/파기의 중요한 선택에 제물을 배분. 일부 악마의 HP 사용은 고유한 위험형 전투 루프라 예외 가능.

## D. 제1위계 4종 상세 후보

### D.1 이사엘 — 서광의 전령 (천사 / 보호·심판)

- **가호 후보:** 최대 HP +4, 표식 적 대상 신성/직접 공격 기여 +12%. 팀에게 자동 보호를 무조건 상시 무제한 제공하지 않는다.
- **기본 권능:** `서광의 낙인`: 적 1기를 빛으로 표식하여 공격을 집중하고, 표식 대상에 권능 추가 타격. `수호의 빛`: 자신 또는 유효 아군에게 다음 위험한 타격의 피해를 일시 경감. 표식은 정신 지배나 결계 설치와 구별.
- **연계:** 낙인 표적에게 접근 → 무기/권능으로 피해 → 타이밍에 맞춰 수호권능 → 재표식. 이사엘 본인이 실제로 맞서 싸우는 루프.
- **계약 제물 후보:** 금괴 2개와 성실한 보호 행동/대체 가능한 간단한 입문 자격. 입문 단계부터 주민 찾기를 필수로 강요하면 탐험 운에 묶이므로 대체 루트 필요.
- **관계·금기:** 주민·철 골렘 등 *무고한 존재의 부당한 처치* 시 신앙 감소→가호 점진적 약화→심각한 위반 시 일부 권능 봉인. 정당방위, 간접 원인·아군 소유권, 우발적 피해는 명시적으로 판정. 악마와의 양립 여부는 계약 조항에 따라 결정(천사의 악마 계약 금지 예시는 존재별).
- **심화:** 표식 연계 효과 강화, 피해 경감 활용성과 조건 변화. 신앙 회복은 일반 플레이의 보호/조항 이행으로 가능해야 하며 무한 무비용 신앙 노가다 방지.
- **파기:** 선불·헌신형으로 중간 수준 위약금 후보. 현현 필수 없음.

### D.2 벨칸 — 재의 거래인 (악마 / 리스크 근접 화염)

- **가호 후보:** 본체 근접 공격력 +16%, 화염 권능 피해 +10% (중복 배율 적용은 계산 시 검토).
- **기본 권능:** `재화의 일격`: 일정 체력을 사용해 불붙은 일격(발동 시 최소 생존 HP·불사 토템/PvP와의 경계 검토). `붉은 갈망`: 치열한 근접 교전에서 일시적 화력 상승, 유효 적 타격/처치로 제한된 회복 후보.
- **연계:** HP 여유 확인 → HP와 화력을 맞교환 → 밀착 연속 타격 → 위험을 벗어나 회복. 자동농장/무적 적 표적의 무제한 회복 불가.
- **계약 제물 후보:** 금괴 1개 + 체력 지불. **최초 제물은 낮지만 파기 위약금 매우 높음**. 같은 시점에 신뢰할 수 있는 정확한 위약금/대체 대가 UI 필수.
- **금기:** 약속한 거래 조건을 회피하거나 빚/파기 대가를 우회할 때 계약상 제재. 천사 계열 계약과 충돌 가능.
- **심화:** 화염 확산·연속 타격의 전투 성능 강화, 하지만 HP 대가가 완전히 사라져 무위험 메타가 되지 않도록 함.
- **현현:** 없음 후보. 가호·본체 기술에 집중.

### D.3 우르겐 — 산맥의 자손 (거인 / 근접·생존·채굴)

- **가호 후보:** 최대 HP +4, 근접 피해 +12%, 넉백 저항 +20%, 채굴 속도 +10%. 실제 스탯 동시 지급 폭은 타 직업과 비교 후 조정.
- **기본 권능:** `거인의 주먹`: 전방 단일/좁은 범위 강타. `지반 파쇄`: 짧은 부채꼴 충격파로 여러 적을 밀거나 경직. 일반 결계 배치/무한 지형 파괴와 구분.
- **연계:** 무기/곡괭이 사용을 포기하지 않고 탐험·채굴 → 전방 충격파로 위험을 열고 근접 마무리.
- **제물 후보:** 철괴 8개 + 돌 32개.
- **금기:** 맹세한 정면 승부·약속/명예를 훼손하는 행동에 제재 후보. 은신 자체를 일률적으로 처벌하는 식의 귀찮은 강제 조건은 피한다.
- **심화:** 넉백/경직 및 채굴·육체 강화. 채굴 레벨 제한을 우회하지 않는 것이 기본.
- **현현:** 없음 후보. 제4위계 거인 `오르마스`의 주력 채굴/대지/물리 성능은 최대 심화 우르겐보다 압도적으로 뛰어나야 한다.

### D.4 리드나 — 길 잃은 별 (이형 / 이동·기습·탐험)

- **가호 후보:** 이동 속도 +10%, 도약/회피 직후 유효 공격 기여 +12%. 항상 똑같은 공격력 증가는 아니라도 본체 전투에 효용이 필요.
- **기본 권능:** `성간 도약`: 짧은 거리의 위치 이동(안전 좌표·충돌/청크 로딩 검사). `별빛 궤적`: 도약/기습 이후 지정 적 타격, 직접 전투 가능. 타 직업의 중력장·공간 이동 메커니즘과 중복 여부 검토.
- **연계:** 적 공격 범위 이탈 → 각도 확보 → 기습 타격 → 탐험 이동.

## E. 제2위계 4종 상세 후보

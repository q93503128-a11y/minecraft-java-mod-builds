## 1. 숙주의 죽음과 플레이어의 죽음은 다르다

1. 실제 숙주가 죽으면 **숙주 개체는 한 번만 사망/제거**되고, 기생술사 플레이어는 그 부근에 **원래 인간형 의태**로 튀어나온다. 별도 벌레/인간 복제 엔티티를 지속 생성하지 않는다.
2. 인간형 상태는 채굴·제작·인벤토리 조작 가능하나 **전투력이 매우 약하다**. 기존 인간형 기본 최대 HP 8·피해 40%는 잠정 수치. 숙주 사망 직후 인간형 HP는 기본 최대치의 **75% 후보**(예: HP 6/8); 풀피 자동 회복 악용 금지.
3. **숙주의 사망 자체는 플레이어 사망 화면을 띄우지 않는다.** 이후 인간형까지 실제 피해로 죽으면 정상 Minecraft 플레이어 사망/리스폰/아이템 규칙 적용. **영구 생체 데이터(BD), 종별 숙련, 직업 레벨은 양쪽 상황 모두 보존**.
4. 탈출 장소는 숙주 사망 위치 근처에서 인간형이 들어갈 **실제 공간**을 찾는다. 기존 숙주를 살리거나 먼 안전지대로 무료 텔레포트하지 않으며, 용암·공허·폭발/협소 공간에서는 탈출 뒤 다시 죽을 수 있다. 숙주를 죽인 **동일 피해 이벤트를 인간형에게 중복 청구하지 않는다**.
5. 타인의 숙주/보스/동료/길들인 몹 소유권, 원본 숙주 엔티티 UUID·AI·드롭, 카메라, 전리품·인벤토리 보존을 서버에서 판정. 기생/사망 이중 트리거로 복제 금지.

## 2. 사망 후 재기생 제한

- **기본 후보: 마지막 숙주 사망 시점부터 60초 동안 기생 불가**. 인간형의 일반 생존/도주/채굴·제작은 가능하다.
- 살아 있는 숙주에서 **자발적으로 이탈하거나 정상 숙주 간 직접 교체**하는 경우에는 이 *사망 전용 제한*을 기본적으로 적용하지 않는다. 단, 서버가 이미 사망을 확정했다면 전투 중 수동 이탈로 속여 우회할 수 없다. 일반 전환의 안전/노출 조건은 별도 검증.
- 제한 시간은 재접속/차원 변경/리스폰으로 초기화되지 않으며, 제한 중 긴급 재기생으로 새 숙주를 얻었는데 그 숙주도 죽었다면 **마지막 사망을 기준으로 다시 시작**한다.
- 제한이 있더라도 충전형 긴급 재기생 패시브가 있다면 아래 조건대로 예외를 허용한다. 스킬 포인트/생체 데이터로 제한 시간을 매번 구매하는 추가 재화는 만들지 않는다.

## 3. 스킬 트리 제안 — '생존 전이' (0~30랭크)

| 패시브 랭크 | 보유할 수 있는 긴급 재기생 충전 |
|---:|---:|
| 0~9 | **0회** |
| 10~19 | **1회** |
| 20~29 | **2회** |
| 30 | **3회** |

- 기본 효과 후보: 랭크당 재기생 금지시간 0.5초 감소(최대 15초). 즉 랭크0은 60초, 랭크30은 45초. 10/20/30 돌파에서 긴급 횟수 증가. **기생술사 전체 스킬 트리는 아직 설계 전**이므로 이것은 전용 노드 *후보*이지 확정된 랭크 총량이 아니다.
- 긴급 충전 **1개로 사망 후 재기생 제한을 1회 우회**할 수 있다. **생체 데이터 최소 요구치, 해당 생물/보스 침투 집중·저항, 소유권/PvP/호환 조건은 모두 그대로 유지**. 즉 '바로 기생 가능'은 **즉시 정상적인 기생 시도 가능**이지 모든 대상에 자동 성공하는 스킬이 아님.
- **충전 회복 후보는 실제 활동 240초마다 1회**, 최대치 초과 불가. 오프라인 시간/사망/숙주 이탈/스킬 초기화로 무료 완충하지 않는다. 최초 해금 때 충전 지급 여부는 **한 번만** 처리하고 스킬 리셋 악용 불가.
- **충전은 유효한 새 숙주 점유가 성공적으로 확정되는 순간 1회 소비**. 타깃 불일치/침투 실패/방해·서버 취소에는 차감 없음. 입력 중복 전송에도 동시 소비/2개 숙주 점유가 발생하지 않아야 한다.
- 일반 기생 키를 사용하고 별도의 긴급 전이 조작키는 강제하지 않는다. 충전이 있다면 UI가 '긴급 재기생 1/2/3회' 표시.

## 5. 서버 상태·UI·검증 계약

- 후보 상태: `HUMAN_FREE`, `INFILTRATING`, `HOST_ACTIVE`, `TRANSFER_PENDING`, `HUMAN_DEATH_LOCKOUT`, `PLAYER_DEAD`. 성공한 직접 전환은 기존 숙주 AI 복구+새 숙주 제어를 하나의 트랜잭션으로 확정. 실패 시 기존 숙주 보존. 실제 숙주 사망은 **원래 숙주 복구/재생성 금지**.
- `hostDeathLockoutEnd`, `emergencyCharges`, `emergencyChargeRegenProgress`, `survivalTransferRank`, `hostUuid`, `hostControlSessionId`, `lastHostDeathEventId` 등은 플레이어/서버 귀속. 타이머와 충전은 차원·청크·재접속/리로그 중 보존.
- HUD는 필요할 때만 **'기생 불능 00:42' / '긴급 재기생 1회'**와 목표 BD·침투 진행도를 표시. 전투용 가짜 자원 바·긴급 버튼을 새로 늘리지 않는다. 실제 사망 시 인형·지배체와 피해/팀 판정 충돌 금지.
- 테스트: 반복 숙주 사망·탈출 안전 위치·같은 피해의 2회 적용·원본 사망 드롭 1회/인벤토리 유지·기생 시도 0/1/2/3충전·데이터 부족 워든/저항 단계 우회 금지·랭크 재설정/재접속 복제 방지·멀티 동시 점유/보스 사망 순서. **아직 미실행**.

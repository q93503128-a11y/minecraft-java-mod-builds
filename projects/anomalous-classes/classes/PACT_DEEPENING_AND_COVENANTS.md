## 1. 사용자가 이 대화에서 재승인한 이전 방향

- [1·2위계 기획 G.6](./PACT_TIER_1_2_DESIGN.md)의 **상향 퍼센트 수치를 후속 비교용 기준안으로 채택**한다. **최종 확정 공격력/체력/쿨타임이 아닌 PLAYTEST-PENDING BASELINE**이다. `최대 HP +4` 같은 초기 수치는 구현 기준에서 우선하지 않는다.
- 계약술사는 본체가 싸우며 **대부분의 계약에서 직접 능력치 가호를 제공**한다. 4위계는 비슷한 분야의 1위계보다 **압도적인 주력 성능 우위**가 있어야 한다. 위계는 4단계, 장비는 별도의 5등급.
- 다양한 제물·금기·위약금·면책·이중계약, 강력하지만 일부 존재만 현현, 제1위계 제단 없는 입문과 중위 이상 제단 활용 등 기존 계약 방향은 유지한다.
- **이번 문서의 두 번 심화, 제물 레시피·조건, 신앙 구간, 이중계약 잠정 2계약(미승인), 보너스 감쇠 50%(2026-11-05 사용자 변경 승인), 구체 위약금, UI 문구/전투 수치**는 이번에 새로 만든 추천 후보이며 사용자가 아직 일일이 확정하지 않았다.

## 2. 핵심 결정 규칙: 의미 있는 두 번의 심화 (신규 제안)

**최초 계약(기본 가호 + 고유 권능) → 1차 심화(가호 증가 + 현재 권능 보완) → 2차 심화(권능 동작 변화·연계 해금)**을 공통 UI의 기본 표현으로 삼는 후보. 세 번 이상 반복적으로 제물을 클릭하는 관리 노동 대신 두 번의 분명한 전환으로 보상을 체감한다. 계약 종류에 따라 강화 구조를 다르게 할 수 있으므로 **모든 존재·모든 위계의 정확한 심화 횟수를 확정하지 않는다.**

- 심화는 제물 소비와 조건 이행 뒤 서버가 확정한다. **한 계약의 심화가 다른 계약으로 복제되거나 이전되지 않는다**. 파기 후 해당 계약의 재체결 정책은 경제/악용 검토 전 미확정이다.
- 1차: 계약 가호의 본체 스탯을 적정량 강화하고 기존 기술 사용감을 개선(예: 범위·연계, 응답성). 2차: 고유 기술의 행동·상호작용 자체가 개선되며 가호는 따라 성장.
- **배율 시험값 후보:** 심화가 강화하는 *가호의 증가분*만 깊이에 따라 `depthBonusFactor = 1 / 1.15 / 1.25`로 적용(최초/1차/2차), 기초 플레이어 스탯 자체에는 곱하지 않음. 이는 예제용이지 모든 스탯·기술에 무조건 적용하는 확정 공식이 아니다.
- 예시: 우르겐의 초기 최대HP 가호 +40%는 1차에 +46%, 2차에 +50%가 되는 **가상 계산**. 실제 2차 심화의 가치는 가호 수치뿐 아니라 주먹→지반 충격파 연계에 있음.
- 신앙/관계 상태에 따른 효율은 **해당 계약의 가호와 권능**에만 적용한다. 관계와 심화 양쪽에서 같은 보너스를 이중 계산하지 않도록 적용 순서를 명시한다.
- 공통 무제한 캐릭터 레벨/직업 자동 스탯 성장과 기존 스킬 포인트·매개체 5등급은 보존. 스킬 포인트=계약술사 자신의 능력 사용 숙련, 추가 제물=특정 존재에게 빌리는 힘의 규모라는 역할 구분을 추천한다.

## 5. 신앙심 50 기본 및 관계/위반 엔진 (확정 방향 + 상세 후보)

- **사용자 승인:** 신앙/신뢰가 필요한 계약은 초기 **50**으로 계약. **50 초과면 강해지고 50 미만이면 약해진다**. 다른 악마·거인·고대신의 계약에 모두 신앙 자원을 강제하지 않는다.
- **시험 효율식**: `F ∈ [0,100]`, `FaithFactor(F) = 0.60 + 0.008F`. F=0→0.6, 50→1.0, 100→1.4. 신앙이 기본 스탯 자체를 줄이거나 늘리지 않고 **해당 계약의 가호 증가분과 기술 위력/기능**에 관여. 이 공식의 단위·최대값·개별 스킬 적용 범위는 미확정.
- **구간별 질적 변화 후보:** F≥70 낙인의 지속/보호 연계 강화, F≥90 강한 심판/방호 연계 허용, F<30 일부 가호 약화·강한 기술 사용 제한 후보. 구간은 신앙 50에서 출발해 정상적인 서바이벌 플레이로 도달 가능해야 하며 숨겨진 반복 행동 노가다는 피한다.
- **신앙 증가 사건:** 실제 주민·철 골렘 보호/습격 방어/계약 의무 이행/특별 성역 보존 등. **신앙 감소 사건:** 무고한 주민/철 골렘 등의 부당 살해, 명시적 서약 금지 위반 등.
- **사건 기반 정산:** 같은 NPC/방어 사건을 짧은 주기로 반복해 점수를 복제하지 않는다. 반복 구조행위/가짜 공격/자기 소유 엔티티의 처치 파밍을 차단. 서버 DamageSource·공격 원인·사용자/동료 소유권·적대 상태·PvP 관계 검토. 잘못된 인과 관계를 억지로 확정하지 않는다.
- 관계 상태는 **현재 값 + 왜 변했는지 짧은 이유 + 다음 목표**만 화면에 표시. 시스템 카드를 매번 확인하거나 매일 제단에 기도하도록 강제하지 않는다. 일반 전투 중 작은 HUD 이펙트나 이벤트 알림만.
- 이사엘 같은 천사와 악마의 이중계약 금기를 **일회 충돌 사건 + 해결되지 않은 갈등 상태**로 취급한다. 1틱마다 신앙을 끝없이 깎지 않는다.

## 6. 위약금·위반·면책 (신규 상세 후보)

### 6.1 상태와 선택

1. **정상 이행 중**: 가호/권능/심화 정상 사용.
2. **경고/갈등 발생**: 예를 들어 천사의 금기와 악마 계약이 충돌. 사전에 계약 내용을 읽을 수 있으며, 서버가 새로운 충돌 사건을 기록. 아직 실수로 인해 즉시 영구 파기/캐릭터 무력화되지 않게 한다.
3. **정식 면책·재협상**: 해당 존재가 예외를 받아들이는 계약이라면 **명시된 추가 제물과 조건**으로 허락. 모든 존재·금기에 만능 면책을 제공하지 않는다. 이미 발생한 무고한 살해를 돈으로 무한 취소할 수 없게 함.
4. **자발적 정식 해약**: 예고된 위약금 지불 후 계약 종료. 계약으로 받은 가호·기술·해당 활성 관계 효과 제거. 이전에 지급한 계약 체결·심화 제물은 자동 환불하지 않는다.
5. **강행 파기/중대한 위반**: 예고된 권능 약화/기술 봉인·유한한 제재와 미정산 채무가 남음. **죽음·재로그·차원 이동으로 무료 면책되지 않음**. 장기적으로 해결 가능한 제물/의식 루트는 필요.
6. **회복/결산**: 위반의 성격에 맞는 행동 또는 제물/유예 기한 등으로 정상화. 제재의 최악과 복구 경로를 계약 전에 알 수 있어야 함.

### 6.2 비용 구조 후보

| 계약 종류 | 체결 시 | 심화 시 | 정식 파기 시 | 중대한 위반 시 |
|---|---|---|---|---|
| **이사엘** (헌신형) | 작은 금/성역 제물, 관계 50 출발 | 희귀 소재+서약 이행 | 중간 수준 보상/절차 | 신앙 하락→권능 약화, 회복 가능한 의무 |
| **벨칸** (저선불·고위약금형) | 작은 금 + **현재 HP** 일회 희생 | 화염 소재/추가 HP·조건 | 최초 선불보다 훨씬 무거운 제물, **정확한 요구량 사전 명시** | 관계 없이 계약 빚·제한된 악영향, 강행 파기만으로 무료 면책 불가 |
| **우르겐** (재료/맹세형) | 철·석재 | 더 큰 광물/특별 도전 | 비교적 예상 가능한 광물 비용 | 실제 맹세 위반에 따른 강화 감소·회복 의식 |
| **리드나** (탐험형) | 청금석+탐험 조건 | 희귀 광물+새로운 탐험 | 희귀 소재/특정 장소 의식 | 금지된 유적 훼손 시 이동 권능 약화 |
| **카르다** (전투/현현형) | 중간~높은 폭풍 제물 | 희귀 폭풍 소재/실전 성취 | 상당한 의식 재료 | 거인 맹세 위반에 따른 충격 권능 감소 |
| **네르아** (해양형) | 해양 제물/해저 자격 | 더 큰 해양 재료/해양 의식 | 수중 성역에서 종료/재료 | 성역 훼손에 따른 수중 가호 약화 |
| **셰로** (관측형) | 엔더/관측 자격 | 추가 기록/탐험 | 특별 관측 의식 | 금기 관측/위반 시 정밀 권능 잠시 봉인 |
| **하스텔** (채무형) | 재물+의무 수락 | 상환 이력/재료 | 미상환 채무 **정산 후** 계약 해지 | 부채 이행 실패 시 추가 채무·단기 불이익; 자동농장 대출/상환 루프 방지 |

- 비용은 각기 실제 Minecraft의 아이템·HP·성취·장소·행동 등과 연결한다. **새 범용 '계약 코인'을 만들지 않는다.**
- **현재 HP 희생**은 일반 회복 가능하고, 기본적으로 영구 최대 HP 손실 아님. 단 고위의 **최대 HP 임시 봉인**은 조건부/복구 가능한 별도 조항 후보.
- 예: 벨칸 저선불 `금괴 1 + 현재HP 일부`, 정식 해약 `금괴 16 + 화염 소재`처럼 차등을 비교할 수 있음. **16개는 실제 최종 요구량이 아니라 위약금이 선불보다 확실히 높다는 시험 예시**. 위험한 계약일수록 정식 파기 조건과 강행 파기 결과를 반드시 계약 전 표시한다.
- **지불 불능의 출구:** 정식 해약이 불가능할 때도 강행 파기로 능력을 포기하고 추후 정산하는 선택이나, 제단에서 빚을 낮추는 유한한 의식을 검토. 돈을 못 냈다고 영구적으로 키 입력/일반 서바이벌 전체를 봉쇄하지 않는다.
- 불가해한 페널티라는 연출은 가능하되, **어떤 행동을 해야 회복되는지**는 플레이어에게 제시한다.

## 7. 이중계약·가호 중복 (기존 허용 방향 + 수치 후보)

- 사용자는 **이중계약 가능**, 이종 계약의 금기 충돌·면책·파기 의무를 이미 수용했다. **구현 초기 최대 동시 2계약**은 기능/밸런스 검증용 후보일 뿐 확정 슬롯 상한이 아니다.
- 각 계약의 **가호와 기술은 별개**, 중복 스탯을 그대로 곱하면 고레벨·4위계·매개체와 중첩 폭주 가능. 중복 피해/회복/치명 피격 구제를 2회 이상 처리하지 않도록 우선 순위/쿨타임 정의 필요.
- **스탯별 임시 합성 공식(검증 전):** 계약들에서 실제 관계/심화가 반영된 **같은 스탯의 가호 증가분**을 `b_high + 0.50 × b_low`로 합산. 각 스탯마다 높은 쪽이 다를 수 있음. 예: 우르겐 근접 +25%와 벨칸 근접 +30%이면 `30% + 0.50×25% = +42.5%`. 곱셈 `1.25×1.30`으로 무조건 +62.5%가 되지 않게 함. **0.50은 사용자 변경 승인된 비율이며, 실제 가호 크기와 최대 동시 계약 수 2는 여전히 잠정치**.
- 단일 계약의 가호가 심화/신앙에 따라 변하면 해당 계약의 유효 가호 증가분을 먼저 계산하고 **마지막에만 중복 가호 감쇠**를 적용. 가호 없는 항목은 감쇠 없이 해당 계약의 실제 보너스 반영. 모든 고유 액티브를 무조건 50%로 약화시키지 않는다.
- 여러 기술을 조합하는 즐거움을 남긴다: 우르겐 지상 타격 + 카르다 공중 낙뢰, 리드나 도약 + 셰로 예조 반격. 기술 자체는 각 계약 조건에 따라 사용 가능하지만 발동 판정/애니메이션/피해의 동시 중복은 서버에서 검증.
- **금기 충돌 사례**: 이사엘 계약이 악마 계약을 금지한다면 벨칸 계약 시 **사전 경고**→(a) 조건에 맞고 존재가 허락하면 큰 제물로 임시 면책, (b) 금기를 강행하고 신앙 하락/갈등 상태 감수, (c) 한쪽 정식 해약. 모든 충돌을 무조건 체결 거부하지 않는다.
- 면책을 받은 계약이 강한 이중계약 권능을 가져도 **제4위계와 제1위계의 동일 분야 주력 성능 격차**를 무력화하지 않아야 함. 낮은 위계 동시계약의 이중이득과 위약금/면책 비용의 상충을 플레이테스트로 비교.

### 7.1 6차 사용자 변경 승인 — 관계 이름과 이중계약

- **모든 존재에게 신앙심에 대응하는 '계약 관계 수치'가 있지만 존재마다 표시 명칭과 가치관, 상승/감소 사건, 권능에 미치는 구체 양상이 다르다.** 보편적인 역할은 관계가 좋아지면 해당 존재의 가호/권능이 강해지고, 나빠지면 약해지는 것. 이름만 교체한 동일 퀘스트 반복은 피한다.
- 1·2위계 **명칭 후보**: 이사엘 **신앙심**, 벨칸 **거래 만족도**, 우르겐 **명예**, 리드나 **별의 공명**, 카르다 **투지**, 네르아 **심해의 친화**, 셰로 **관측 일치도**, 하스텔 **신용**. 상위 위계도 개별 정의. 명칭은 아직 최종 사용자 승인 전.
- **50은 관계 수치 출발값을 전 존재에 통일하는 추천안**. 기존 천사의 신앙심 50은 사용자 승인. 모든 관계가 반드시 똑같은 세부 공식과 임계 구간을 갖는다는 뜻은 아님. 하스텔의 **신용**은 관계 수치이고 **채무**는 별도 납입 의무. 신용이 높아도 빚은 없어지지 않음.
- 이중계약 같은 스탯 약한 가호 반영률을 **35%에서 50%로 변경 승인**. 관계/심화가 반영된 계약별 보너스 두 개를 비교해 높은 것 100% + 낮은 것 50%. **각 스탯별로 비교**. 예시 +30%/+25%→+42.5%. 계약 자체 최대치·개별 수치·연계 패시브 수치는 아직 조정 중.
- [공통 패시브](./PACT_SKILL_TREE.md)와 [계약 증표](./PACT_FOCUS.md)의 추가 보정은 이중계약 합성 뒤 *증가분*에만 한 번 적용하고 HP·공격력/계약 스킬을 무조건 여러 번 곱하지 않는다.

### 7.2 6차 승인 — 계약 한 번 클릭으로 체결되지 않음

- **제단 핵 상호작용/하위 계약 접촉 → 계약 목록·상세 계약서 → '계약 진행' → 별도의 최종 계약 확인 → 서버 확정**. 단순 목록 클릭/계약 대상 선택/계약서 보기/처음 '계약 진행' 누르기만으로 재료 소모·HP 희생·관계 변화·계약 확정 금지.
- 최종 확인에는 **얻는 가호·권능·필요 제물(현재HP 포함)·소비 시점·금기·위반 페널티·정식 파기 위약금·이중계약 충돌 및 상대 관계 변화**를 명확히 표시. 고위약금·갈등 계약은 별도 주의 문구를 강조. 확인은 필요하지만 체크박스 여러 개/장문 반복 동의로 실제 조작을 방해하지 않는다.
- '체결'은 명확하게 구분된 두 번째 실제 승인 행동에서만 요청한다. 취소·닫기·이동·서버 응답 실패 시 소모 없음. 서버는 최종 승인 때 **조건/소유권/인벤토리/계약 상태/직업/제물·HP·위약금 조건**을 다시 계산, 미리보기와 다르면 체결하지 말고 갱신 확인을 요구.
- 결제와 계약 상태는 **원자적으로 commit**되고 동일 요청의 중복 패킷/더블 클릭/네트워크 재전송을 한 번만 처리. 사용자와 제단이 여러 명에게 동시에 열려도 한 플레이어의 제물을 중복 소비하지 않는다.
- 파기/강행 파기/면책/심화처럼 되돌리기 어렵거나 큰 자원을 쓰는 경우도 적절한 별도 확인을 제공. **일반 제단 상자 열기·계약서 읽기·정보 확인에는 불필요한 이중 확인 없음**.

## 8. 최소 화면 흐름 (사용자용, 개발 내부 문구 없음)

계약 핵과 상호작용 → **계약 대상/가호/기술 요약** → **필요 제물/보유 재료** → **주의해야 할 금기 및 이중계약 충돌** → **해약 위약금·위반 결과** → 최종 승인.

체결 후 같은 화면에서 해당 계약에 대해 `심화`, `조항 확인`, `면책 요청`, `계약 종료` 중 실제 가능한 행동만 표시한다. 필요한 UI만 맥락적으로 보이고 매번 거대한 메뉴를 반복하지 않는다.

**플레이어 문구 예시 (문구 자체는 후보):**
- `제단은 계약술사만 사용할 수 있습니다.`
- `이사엘의 가호 — 신앙 76/100`
- `계약 심화: 금괴 ×4 / 성역의 증명 완료`
- `주의: 이사엘의 서약은 벨칸과의 계약을 금합니다.`
- `위반을 감수하거나, 제물을 바쳐 예외를 요청할 수 있습니다.`
- `해약 시 필요한 제물: 금괴 ×16, 화염 제물 1종`
- `계약 종료 후 기존 제물과 심화는 반환되지 않습니다.`

- 문구는 개발자·로그/TODO/내부 작업 상태로 표시하지 않는다. 정확한 조건·확률·소비/반환 시점을 표시한다.
- 플레이어가 제단을 방문해야만 신앙 정보를 볼 수 있는 것은 아님. **현재 계약 관리와 권능 설명은 어디서든 가능**하고 실제 제물 바치기/의식에 제단 또는 적절한 계약 접촉 방법을 사용한다.
- 일반 플레이어도 얻는 제단 상자 보상·전리품과 핵 계약의 권한 상태는 완전히 분리.

## 9. 서버·멀티·저장·밸런스 검증 (미실행)

- 서버 소유 데이터: `playerUUID`, `contractEntityId`, `rank`, `deepeningStage`, `relationshipState`, `faithIfApplicable`, `breachRecords`, `debtOrDueCondition`, `waivers`, `severanceState`, `version`. 실제 직업 계약 슬롯 구조/스키마는 미정.
- **원자 처리:** 최초 체결·심화·해약·면책에서 제물 확인→정확한 1회 소비→상태 확정이 실패 시 롤백 가능해야 한다. 중복 패킷·동시 두 플레이어 상호작용·인벤토리 변경 대응.
- 위약금/미상환 채무는 사망·재로그·차원 이동으로 지워지지 않고, 기존에 받은 가호가 장비 탈착/직업 변경으로 유령처럼 남지 않는다. 사망 전투 피해와 체력 제물의 이벤트 순서 명확히.
- HP가 모자랄 때 HP 제물은 계약/스킬 비용 지불 실패 또는 명시적 다른 경로. 일반적인 최초 계약은 무조건 자신을 살해하는 숨은 함정이 되어선 안 됨.
- 신앙 사건과 타 플레이어/아군 몹/자신의 소환물에 대한 책임 귀속, PvP/우발 피격/정당방위 처리와 자동 보상 파밍 차단. `ALLY_RELATIONS.md` 기준.
- **HP 가호 변경 시 체력 비율 보존**, 무료 회복/죽음 방지/불사의 토템 중복 적용 금지. 월드에서 누적된 보너스를 복구 불가능하게 잃거나 계약 0개로 전환했는데 HP가 음수가 되는 버그 방지.
- 플레이 테스트 비교: 동일 레벨/장비/표적/제물 투자 시 계약 최초→심화1→심화2의 **12~30초 실제 유효 피해, 생존 HP, 조작 부담, 이동 효율**, 1→2→3→4위계 성장, 고위 체급의 명확한 상향, 신앙 0·50·100, 정식 해약과 강행 파기, 신앙 충돌, 멀티플레이 전리품 분배.
- UI·모델·사운드와 제단은 실제 Minecraft 화면 테스트가 필요하며, 이 문서는 구현 완료를 주장하지 않는다.

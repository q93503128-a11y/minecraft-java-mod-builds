## 1. 핵심 결정 — 배운 특성은 계속 보유, 다른 숙주에서도 모두 사용

- 기생술사는 **한 번에 살아 있는 숙주 딱 1기**만 직접 조종하며, 다른 종을 연구해 얻은 **종족 특성/능력 기억**은 기생체 본체의 **영구 저장 기록**이 된다.
- 새로운 숙주로 이동하더라도 과거에 배운 **거미 벽 타기·크리퍼 폭발 등 모든 특성을 접근할 수 있다**. 별도의 '특성 장착 3칸' 같은 강제 로드아웃 한도를 만들지 않는다.
- **미기생 인간형은 약해야 한다**. 강력한 공격·기동/방호 종족 특성은 **실제 숙주에 기생해 있을 때만** 쓸 수 있다. 인간형의 생존/기본 장비/채광 조작을 막지는 않는다.
- 특정 종에서 자연스럽게 제공되는 **원래 능력(선천)**은 해당 종에 들어가는 즉시 기본으로 사용 가능. 예: 거미 숙주라면 기본 벽 이동, 크리퍼 숙주라면 원래 신체를 소모하는 폭발 특성.
- **다른 종에서도 그 종의 능력을 계승 사용**하려면 단순 기생 1초·메뉴 클릭이 아니라, **해당 숙주로 실질적으로 능력을 발휘하거나 종 고유의 생존 행동을 달성**해 생체 기억을 해독한다(최소 한 번의 유효 행동 후보). 세부 종별 규칙은 data-driven. **새로운 도감 화폐·장비/슬롯·반복 재료 소비가 아니라 활동 이벤트로 해금**.
- 기억 해금 후에는 기생술사 영구 데이터에 귀속. 같은 종 숙주 재기생, 숙주 사망, 인간형 전환, 다른 숙주·차원·재접속 시 잃지 않는다. 종별 숙련 10/30/60/100 단계는 **이미 익힌 특성의 효율/사용감**을 개선하는 보너스 후보이며 계승 해금 조건에 각종 100랭크 강제하지 않는다.
- 모든 생물의 AI·모드 기술을 자동으로 추출/복제하는 것은 구현 불가에 가까우므로, **지원 종/고유 특성은 실제 검증된 abilityDefinition/컨트롤 어댑터를 등록**한다. 지원 미완료 종은 기본 숙주 조종만 되고 전승 가능한 고유 기술은 '미지원'으로 표시. 일부 보스의 특성이 없다고 임의 판타지 능력을 자동 생성하지 않는다.

## 2. '모두 사용'의 의미와 밸런스 규칙

**소유 제한 없음 / 동시 효과·순간 화력에는 자연스러운 한계.**

1. **영구 능력 목록 제한 없음**: 얻은 기억은 모두 선택 가능하고, 종이 다르다는 이유로 목록에서 빠지지 않음. 메뉴에서 마음대로 '모드를 갈아끼우는 제작 노동'을 반복하지 않음.
2. **현재 숙주 원본 기능은 더 우수**: 거미가 직접 벽을 타는 것은 거의 끊기지 않는 선천 이동. 다른 종이 '계승 거미 이동'을 쓰면 **제한시간/재사용 대기** 등으로 약해짐. 크리퍼 본체 자폭은 원본처럼 숙주 사망의 큰 위험; 타 종에 계승한 '제어된 생체 폭발'은 **더 작고 약한 폭발 + 자기 피해/쿨타임**으로 비자살 선택. 이렇게 원래 숙주종의 고유 강점을 유지.
3. **패시브형은 환경 조건에서만 작동**: 수중 호흡·낙하 완화 등 물/낙하에만 적용. 스탯형 +HP, +공격을 몬스터 100종에서 가져와 무한 합산하는 **항상 켜지는 숫자 스택**은 허용하지 않는다. 실제 효과는 생체 데이터·현재 숙주 기본 능력·공생 패시브·장비로 결정.
4. **공격형 능력은 개별 재사용 대기와 공격형 공용 후딜**: 예: 획득한 크리퍼 폭발 후 30초 개별 재사용, 공격형 계승 기술은 **공용 약 3초 동작 간격**(초안)을 갖는다. 기술이 20개여도 20발을 한 틱에 동시 발사하지 못한다. 이동/탐험 능력은 공격형과 별도 처리하며 전투 공격형 후딜 때문에 기본 이동·바닐라 공격을 막지 않는다.
5. **큰 보스 기술은 별도 높은 BD 요구치의 생물에 실제 기생 성공한 다음 학습**할 수 있는 후반 목표. 상위 스킬의 배율·발동 시간·공용 후딜은 보스 원본보다 낮거나 조정한다. 단일 숙주이므로 유의미하게 강할 수 있지만 **정신 지배자·인형술사 복수 전투 유닛 합계 DPS와 실전 위험을 비교**해야 한다.
6. **실제 조작/지형/피격/서버 권한 준수**: 거미 벽 타기는 벽에 실제 접촉해야 하며 공중 부양·블록 관통이 아니다. 크리퍼 폭발은 실제 거리/방어/팀 판정의 광역 피해. 보호 지역/설정상 블록 파괴 제한을 넘어 그리핑을 강제하지 않는다.
7. BD는 이 계승 기술들을 사용할 때 **소비되지 않는다**. 신규 '생체 에너지/변이 부하' 자원 바도 만들지 않는다.

- **크리퍼 자폭/계승 폭발 구분이 핵심**: 원래 크리퍼 숙주 자폭을 고른다면 해당 숙주가 죽을 수 있으므로 [사망/긴급 전이](./PARASITE_HOST_DEATH_AND_TRANSFER.md) 그대로 적용. 계승 폭발은 생체 폭발 연출과 실제 판정이 일치하되 **자해 위험과 자체 쿨타임**이 있다. 블록 피해/보호구역/PvP는 게임룰·서버 설정에 따르고, **계승 폭발은 기본적으로 지형 파괴 없는 전투기**를 제안.
- **원본 거미의 능력을 배운 돼지가 벽을 타는 것**은 실제 모델 애니메이션/지형 판정 지원 필요. 단순 포션 효과·파티클만 뿌려서 벽을 타는 것처럼 연출하는 가짜 구현 금지.
- 가디언처럼 한 종에서 둘 이상의 서로 다른 고유 능력이 있다면 각 능력은 별도의 **abilityId**로 구분·획득할 수 있다. '한 종에 무조건 1개' 제한이 아니라 의미 있는 지원 능력을 실제로 사용 가능하게 함.
- 원래 숙주 태생 자체의 환경 취약(좀비 햇빛/가디언 물 밖 등)은 다른 생물로 옮겨도 무조건 따라오는 영구 저주로 만들지 않는다. 현재 숙주 본래의 단점과 계승 기술 자체의 비용/조건만 적용.
- 사망한 숙주의 **블록 파괴·경험치/아이템 드롭과 계승 특성 해금이 중복 트리거**되지 않도록 서버 유효 활동 이벤트로 한 번만 보상.

## 4. UI: 전부 소유하고 빠르게 선택

- **현재 숙주의 원래 기술**은 기본 종별 조작 버튼에 맵핑. **계승 기술**은 하나의 **능력 선택 휠/목록**에서 모두 사용 가능. 현재 전투용 기술은 최근 사용/즐겨찾기로 바로 누를 수 있도록 하고 **편의 단축 3칸 후보는 장착 한도가 아님**. 목록에서 어떤 능력도 영구 잠기지 않는다.
- 키 바인딩을 종 수만큼 늘리지 않는다. 휠로 고르고 공통 실행 키를 눌러 사용. 멀티플레이에서 휠을 열었다고 게임 전체를 멈추게 하지 않는다. HUD는 현재 선택 기술·개별 쿨타임·공용 공격형 후딜만 필요시 표시.
- **기생 시도/이탈, 본체 스킬 3종(침투 고정·생체 수복·본능 각성)과 계승 기술은 별개**. 이 세 고유 스킬을 빼앗거나 숙주 수 제한을 늘리지 않는다.
- 지원되지 않는 능력의 획득 여부와 불가 사유/조건을 정확하게 표시. 생체 데이터가 부족하면 그 종부터 기생할 수 없으므로 초기부터 후반 능력이 공짜로 열리지 않는다.

## 5. 종별 데이터 구조·모드 호환·서버 검증

- 능력 정의 `abilityId`, `sourceEntityTypeIds`, `learnCriteria` (유효 행동 조건), `nativeBehaviorId`, `inheritedBehaviorId`, `nativeModifiers`, `inheritedModifiers`, `sharedCooldownGroup`, `ownCooldownTicks`, `renderVariantId`, `statusSafetyFlags`, `worldGriefPolicy`. **소유한 모든 기술을 데이터로 반복 등록**하며 하드코딩한 종별 난이도와 UI 목록을 분리.
- 플레이어 저장 `learnedTraitAbilityIds`, `perSpeciesMastery`, `bioDataValue`, `traitCooldownEndTicks`, `sharedAttackTraitCooldownEndTick`, `currentHostEntityUuid`, `traitMemoryVersion`. **숙주 사망·재접속·차원 전환으로 기술 쿨타임/습득 기록 초기화 불가**.
- 서버는 사용 가능한 실제 숙주/종 지원·BD·해금·고유 능력 타입·시전자/팀·공용/개별 쿨타임·거리/충돌/피해·리스크를 검증. 바닐라 모드/타 모드 보스/서버 PvP/보호구역 권한과 호환 검증 전에는 구현됐다고 주장하지 않는다.
- **처음부터 모든 능력이 지원되는 것은 아니다.** 실제 구현 계획의 초기 범위는 돼지 이동/기초, 거미 벽타기, 크리퍼 폭발, 슬라임 도약, 가디언 수중 능력·광선처럼 플레이 경험이 뚜렷한 5종 내외부터 검증. 지원종 목록은 어댑터 및 플레이 테스트로 계속 확장.
- 고레벨에서 플레이어 1기 체력/공격이 올라가도 **단일 숙주**이며, 숙주가 죽으면 인간형 배출·재기생 제한. '모든 특성 사용'을 이유로 소환체 수나 영구 무적/BD 하드 게이트를 뚫지 않음.

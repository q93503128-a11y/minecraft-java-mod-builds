# 기생술사 — 숙주 능력 완전 숙련·영구 계승·자동 능력 운영 v2

> 2026-11-04. **사용자 새 결정:** 벽 타기 같은 사소한 능력에 강제 쿨타임을 넣지 않는다. **해당 종을 완전히 숙련해야(종별 숙련도 100) 다른 종 숙주에서 그 능력을 사용할 수 있다.** 배운 능력은 모두 보유하고 모든 숙주에서 접근 가능. 전투 액티브 수가 늘어나는 문제는 **상시형/반응형/직접 발동형**으로 분리해 해결한다. 구체 수치/외부 몹 구현 지원 범위는 검증 전 초안.
>
> 기준: [기생술사](./PARASITE_MORPHER.md), [종별 숙련·BD 획득](./PARASITE_BIODATA_ACQUISITION_AND_INTRUSION.md), [285랭크 패시브](./PARASITE_SKILL_TREE.md), [3개 공통 액티브](./PARASITE_ACTIVES.md), [숙주 사망](./PARASITE_HOST_DEATH_AND_TRANSFER.md). 이전 v1의 **해당 종으로 고유 능력을 한 번 쓰면 타 종 계승 허용**, **계승 거미 벽 타기 8초/재사용 12초** 제안은 **철회**한다.

## 1. 종별 숙련도 100이 다른 숙주로 능력을 전승하는 조건

1. **현재 몸의 선천 능력:** 거미가 숙주일 때 벽 타기, 크리퍼일 때 폭발, 엔더맨일 때 투사체 회피처럼 **그 종 원래 기술은 숙련도 0에서도 사용 가능**. 바닐라/외부 몹 특수 기술은 실제 구현된 조작 어댑터에만 적용.
2. **실제 종별 숙련:** 해당 종 몸으로 이동·전투·생존·종 고유 기술 사용 등 실제 플레이를 통해 **종별 숙련도 0~100**을 올린다. 원본 [BD 및 숙련 획득 문서](./PARASITE_BIODATA_ACQUISITION_AND_INTRUSION.md)의 **해당 종에서 얻은 유효 BD 10당 +1 숙련** 후보 유지. 숙련 100 도달 시간이 지나치게 길지 않은지 플레이테스트로 측정. 별도 종 전용 업적(실제 활동·첫 성공) 보너스는 후속 검토; 장시간 AFK/자동 농장으로 숙련 100 도달 금지.
3. **완전 숙련(100):** 해당 종에 등록된 **지원 능력들이 다른 종 숙주에서도 영구 사용 가능**해지는 계승 해금. 해당 종이 숙주로 있는 동안은 100이 아니어도 선천 기술을 계속 쓸 수 있다.
4. **영구 보유:** 새 숙주로 이전/인간형 복귀·사망/재접속/스킬 포인트 재배분 뒤에도 **해금 기록 유지**. 다른 종 숙주마다 거미 벽 타기를 다시 100까지 숙련할 필요는 없다. 각 종의 숙련은 개별로 저장.
5. **배운 능력 전부 접근:** 종족 능력 **강제 장착 슬롯 수 제한 없음**. 단축 슬롯/선택 휠은 편의용. 강한 능력은 액티브 자체의 사용 조건/정상 공격 후딜·타격 판정/별도 재사용 대기로 조절.
6. **기생하지 않은 인간형**은 허약하며 강력한 계승 능력 자동 적용/공격 발동을 하지 못한다. BD는 소모하는 스킬 자원이 아니고 최소 숙주 기생 자격을 계속 결정.

## 2. 세 가지 능력 조작 유형

| 유형 | 예시 | 작동과 밸런스 |
|---|---|---|
| **환경형·지속 패시브** | 거미 벽 타기, 가디언 수중 적응, 낙하 완화 | 벽 접촉/잠수/낙하 등 조건에서 **즉시·지속 작동, 인위적인 초 단위 쿨타임 없음**. 입력은 이동·점프·웅크리기 등 바닐라 조작과 결합. 서로 다른 모델의 충돌 크기·애니메이션 제약은 현실적으로 유지 |
| **조건형 자동 방어** | 엔더맨 투사체 자동회피, 거북형 밀림 저항 | 해당 사건이 있을 때 서버가 자동 판정. 모든 공격 100% 회피·조건 없는 전방위 무적은 안 됨. 동일 공격의 다중 투사체 등은 중복 발동/위치 악용 방지 |
| **직접 발동 액티브** | 크리퍼 폭발, 가디언 광선, 엔더맨 수동 순간이동, 워든 충격파 | 배운 목록에서 골라 실행. 각 능력의 시전/판정·재사용대기, 공격형 능력들 사이 공통 **약 3초 후딜 후보**로 기술 수가 많아져도 순간 폭딜 무한 연계 금지. 기본 검/곡괭이 조작·이동은 막지 않음 |

- '패시브'는 **직업 스킬 포인트를 쓰는 285랭크 패시브 트리와 다른, 100 숙련으로 물려받은 종 특성**을 가리킨다. 관련 UI와 데이터 필드를 섞지 않는다.
- **환경형 능력은 똑같은 이동 기능을 여러 번 획득해도 물리 상태에서 한 번만 계산**하고, 거미 벽 이동과 다른 벽 이동이 중복 발동해서 수직 속도가 두 배가 되지 않도록 기능 그룹 내 우선순위 적용.
- **전투방어·고정 스탯형** 특성들을 100종 수집해 +HP/+공격력/무적을 무한 중첩하는 것은 허용하지 않는다. 직업 본체 전투 스탯은 현재 숙주/BD/종별 숙련/패시브/공생 핵으로 결정. 종족 방어는 조건부/중복 방지.
- 이동 중 **큰 몸체(워든 등)**가 벽을 타더라도 실제 히트박스/머리·통로 충돌 제약 유지. 화면에서 벽 타기 연출이 보이는 것과 실제 서버 수직 이동 일치. 블록 관통·비행으로 속이지 않음.
- 현재 숙주의 선천 능력과 다른 숙주의 계승 능력이 중복될 때는 **선천형을 우선**하고 두 개의 동일 효과를 중첩하지 않는다. 생물종 자체의 강점을 보존하되, **완전 숙련으로 열린 환경형 계승 기능에 의미 없는 지속시간 제한·쿨타임을 다시 넣지 않는다**.

## 3. 종족별 예시 (초안)

| 종 | 선천 능력 (해당 숙주에서 즉시) | **그 종 숙련 100 이후** 다른 숙주에서도 계승 사용 | 사용 방식/한계 |
|---|---|---|---|
| 거미 | 벽 접촉 시 벽 이동 | 다른 종 숙주도 **지속 벽 타기** | **쿨타임 없음**, 벽 접촉·중력·실제 몸체 충돌 필요 |
| 크리퍼 | 원래 폭발 행동(자폭한다면 숙주 사망) | 다른 몸에서 **제어형 생체 폭발** | 공격 액티브, 예: 30초 쿨타임·숙주 최대 HP 12% 자해·지형파괴 기본 없음(후보). 자폭으로 원래 크리퍼 숙주가 죽으면 인간형 배출/재기생 제한 |
| 슬라임 | 현재 종의 탄성/도약 | 다른 몸에서도 **자연 도약·낙하 완화** | 기본 점프/중력·착지 같은 실제 움직임의 제약. 단순 점프를 위해 별도 14초 쿨타임을 부여하지 않음; 극단적인 고출력 도약 별도 공격형 기술은 후속 검토 |
| 가디언 | 수중 적응·원거리 집중 광선 | 수중 호흡/이동 + 조준 광선 | **수중 적응은 상시 조건형**, 광선은 액티브 재사용 대기(예: 24초 후보) |
| 엔더맨 | 원래 순간이동과 투사체 회피 | **조건부 자동회피(반응형)** + 수동 단거리 순간이동 | 자동회피는 안전 지면이 있을 때 **유효 투사체 공격마다 약 35% 성공률 후보**, 동일 공격을 이용한 무한 위치 변경 차단. 수동 순간이동은 별도 28초 쿨타임 후보. 워든 음파 등 일반 투사체 아닌 공격은 제외 |
| 워든 | 실제 조종 가능한 근접/진동/음파 기술 | 조정된 고유 충격 기술 | 위협도/B​​D 요구치가 매우 높은 후기 콘텐츠, 기술은 실제 지원 어댑터 필요. 원본 보스 강제 면역·지형 관통을 자동 복제하지 않음 |

- 엔더맨의 **바닐라 투사체 회피**는 원래 종의 기능을 참조한다. 다른 숙주에게 계승된 35% 자동회피는 **우리 게임의 신규 밸런스 제안**이지 바닐라 수치가 아니다.
- 자동회피는 대상의 피격 예상 위치/유효한 투사체·공격 소유권/안전한 순간이동 목적지를 서버가 검사한다. 같은 공격/한 틱 멀티샷 중복·무조건 무적·월드 경계/차원/보호구역 우회 금지. 자동회피가 불가능한 공간이면 정상 피해 가능.
- 크리퍼의 원본 사망 시 인간형 배출·BD/인벤토리 보존·기생 금지와 [생존 전이](./PARASITE_HOST_DEATH_AND_TRANSFER.md) 충전 예외는 **폭발 방식이 달라도 일관 적용**.
- 외부 몬스터는 지원하는 실제 entityType/abilityId와 제어 어댑터만 계승 대상으로 표시. **종별 숙련 100을 달성했다고 미구현 스킬이 자동 생성되는 것은 아님**.

## 4. 액티브가 30개가 되더라도 같은 방식으로 조작

- 능력 수 1~5: 기본 HUD에 최근 사용/현재 선택 액티브만 보여준다. 학습 종이 늘어도 HUD 카드나 새 조작키를 종 개수대로 추가하지 않는다.
- **공통 능력 선택 휠**: 계승 **직접 발동 능력만** 모아 열기/선택/사용. 방어 자동형·지속 능력은 휠을 거치지 않음.
- 휠의 분류는 **공격/이동/지원**, 최근 사용·즐겨찾기·검색/스크롤을 활용. 화면상 단축 3칸 등은 장착 제한이 아니고 **조작 편의용**, 숙주 본래 고유 기술 키·기생 시도·공통 액티브 3종과 혼동하지 않는다.
- 휠을 연 뒤 **선택과 사용은 별개**로 조작 가능. 조작 방식은 키 재바인딩·GUI Scale/와이드 화면/멀티 시 게임 중단 없는 상태를 검토. 휠에서 스킬을 선택하는 동안 서버는 이미 허용/불가 및 쿨타임 정보를 제공.
- **스킬 재사용 대기는 능력을 선택한 탓에 초기화되지 않는다**. 종 교체, 스킬바 변경, 장비 착탈로 쿨타임 우회 금지. 종족 고유 기술과 계승 기술이 동일 공격을 공유할 때 서버가 발동 중복 방지.
- 미기생 인간형은 같은 휠을 열어 배운 종 특성을 볼 수는 있어도 강력한 종 기술 사용 불가. 배운 기술과 숙주 자체 원천 능력의 상태가 분명히 구분돼야 한다.

## 5. 영구 해금·숙련 경제·세이브

- 현재 DB 항목 `perSpeciesMastery` (0~100)가 **타 종 계승 해금의 유일한 기본 조건**이며, `learnedTraitAbilityIds` 또는 동등한 해금 기록은 **100 달성 시 서버에서 등록된 해당 종의 지원 abilityIds를 원자적으로 추가**하는 형태가 적절. 미래에 신규 능력이 지원되면 이미 숙련 100 종에 대한 추가 등록/마이그레이션 정책 필요.
- 기존 [종별 숙련 문서](./PARASITE_BIODATA_ACQUISITION_AND_INTRUSION.md)의 10/30/60/100 단계는 10/30/60에서 **현재 숙주에게만 적용되는 조작 개선**, **100에서 타 숙주 계승 해금**으로 구별한다. 100 이전에 다른 숙주가 배운 능력을 쓰지 못하며, 기존 v1의 '한 번 직접 사용하면 계승'은 폐기.
- 숙주가 아닌 상태/종 변경/사망·리스폰/재접속에서 종 숙련값과 계승 등록은 유지. 스킬 트리 '종별 융화'는 숙련 획득 효율을 높여 **완전 숙련 100까지의 과정**을 돕지만, 최소 BD를 우회하거나 스킬 투자만으로 즉시 종족 특성을 배움으로 처리하지 않는다.
- 초반/후반 종별 숙련 100까지 **실제 소요시간**을 측정해 숫자/보상을 조정한다. 유효 활동 BD 10당 숙련1만으로 너무 오래 걸린다면 종별 고유 행동·탐험/전투 성취에서 **종별 숙련 보너스 1회 획득**을 도입하는 방안 검토. 단순 AFK·제자리 벽 오르기·자동 농장에서 무한 숙련 수급 금지.
- 숙련 100을 여러 종 달성해도 **능력 획득 수 제한 없음**. 단일 숙주라는 직업 특성을 유지하면서 실제 액티브 발동 비용/공용 공격 후딜만으로 과다 화력 방지. 신규 스킬 슬롯/재화·유지 먹이 비용 금지.

## 6. 검증해야 할 실제 체감

1. 거미 숙련 99일 때 다른 몸에서 벽 못 타고 **100이면 정상 상시 벽 타기**가 되는가? 거미 본체에서는 숙련 0부터 벽 타기가 가능한가?
2. 돼지+거미 벽 타기/가디언 수중 적응을 함께 배운 뒤 **둘 다 쿨타임 없이 환경 조건에서 작동**하는가?
3. 엔더맨 숙련 100 후 다른 숙주가 자동회피를 할 때 공용/개별 공격 판정·안전 목적지·PvP 환경에서 무적/순간이동 악용이 없는가?

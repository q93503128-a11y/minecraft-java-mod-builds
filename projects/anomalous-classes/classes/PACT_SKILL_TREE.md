## 1. 근본 설계

- **존재별 고유 권능·스킬·신앙/명예/관계 상태는 특정 계약 데이터에 속함.** 계약 상대를 교체해도 **계약술사 개인의 공통 패시브 투자와 캐릭터 레벨은 그대로** 남는다.
- 계약을 맺거나 기본 기술을 사용하는 기능, 스킬 키 설정, 확인/취소, 계약서 미리보기, 안전 좌표 점검, 재료·위약금 표시는 **패시브 랭크 0부터 이용 가능**하다. UI 편의를 스킬 포인트로 팔지 않는다.
- 기본 가호/권능/제물 강화/관계 수치/매개체를 중복 적용하지 않는다. 다른 직업의 270~300랭크 후보를 참고하되 개별 스킬의 필요성을 우선한다.
- **새로 제안하는 규모:** 3계열 9노드 × 각 30랭크 = **270랭크**. 랭크 수/효율은 다른 직업의 미검증 패시브(정신 지배자 270, 기생술사 285, 결계술사 300 등)를 참고한 첫 초안이며 최종 승인이 아니다. 반복 노가다 목표 자체로 수를 늘리지 않는다.

### 2.1 효과 범위의 예시

- 같은 스탯의 두 계약 가호는 **각 계약의 신뢰·심화 보정을 개별 계산**한 뒤 `stronger + 0.50*weaker`로 합성한다. **50%는 사용자 변경 승인**, 강/약 계약 판단은 *해당 스탯*별로 한다.
- 그다음 육신 각인/무력 동화의 **해당 스탯 증가분 개선을 한 번** 적용한다. 최종 기본 캐릭터 HP·무기 공격 전체에 같은 +15%를 별도 곱하지 않는다.
- 예: 같은 근접 스탯에 벨칸 +30%, 우르겐 +25%이고 다른 보정이 없으면 **+42.5%**, 무력 동화 30랭크가 '+42.5%의 15%'를 더하면 **+48.875%**. 실제 공식이 아닌 단위/중복 계산 시험 예시이다.
- 관계 공명 30랭크와 `FaithFactor(F)=0.60+0.008F` 시험식을 가정하면 신앙 100의 관계 보너스는 기준 대비 +40%, 관계 공명으로 그 *초과 +40%*의 15%를 개선해 +46%가 되는 것(기본 캐릭터 전체 ×1.46 아님). 신앙 30의 불이익은 자동 면제하지 않는다.
- 심화 내재화는 최초 계약 원래 가호를 반복 증폭하는 노드가 아니라 **추가 제물에 의해 생긴 새로운 증가량**에만 적용한다. 타 노드/장비와 결합해 같은 증가량을 두 번 의미 없이 계산하지 않을 것.

## 3. 랭크 돌파 후보 (스킬 버튼/필수 UX 추가 금지)

- **무장 직조** 10랭크: 계약 권능 사용 직후 무기 타격 연계 입력의 허용창을 소폭 넓힘. 20랭크: 연계 성공 시 계약의 **기존 고유 표식·화염·충격·별빛**에 적절한 피드백 강화. 실제 피해는 노드 효율 범위 안에서만 조정. 30랭크: 하나의 실제 교전에서 연계 직후 공격 편의 보완; 공짜 타격/쿨다운 초기화 금지.
- **위기 저항** 20랭크: 한 번의 경미한 넉백 뒤 자세 회복 보조 후보. 계속 맞아도 무적으로 버티는 조건 없음.
- **이중 조율** 10/20/30랭크: 서로 다른 계약 액티브를 교대로 사용했을 때 연계 판정의 허용 시간이 조금 개선. 존재별 고유 스킬을 잠그지 않고, 충돌하는 계약 조항·가호의 50% 규칙·현현 비용을 무시할 수 없음.
- 나머지는 랭크당 강화를 중심으로 운영하고, 시험 결과 실제 손맛을 개선할 돌파만 추가. 모든 노드에 같은 형태의 10/20/30 강제 돌파 목록을 만들지 않는다.

## 4. 관계 수치와 스킬 트리의 경계

- 공통 트리는 **관계 수치를 대체하지 않는다**. 예: 천사는 신앙심, 거인은 명예, 악마는 거래 만족도/신용, 이형 존재는 별의 공명/관측 일치도 등 각기 다른 계약 데이터·금기·상승 사건을 보유한다.
- 관계 50 시작, 높아지면 강해지고 낮아지면 약해지는 역할은 공통. 값 범위·관계 보정 공식 등은 후속 확정. **악마의 실제 미상환 채무는 관계 수치와 별도로 저장**하며 높아진 신용으로 빚이 소멸하지 않음.
- 관계 공명은 정당한 행동으로 이미 올린 관계 상태의 긍정 보상만 개선한다. 신앙·명예를 돈으로 매 순간 마음대로 구매하거나 위반 기록을 삭제하는 버튼은 제공하지 않는다.
- 신앙 반복 획득·몹 포획 후 타격 자동농장 등으로 관계를 빠르게 무한 올리지 못하게 이벤트 귀속/반복 제한 서버 판정.

## 5. 장비와 비교 및 테스트

- 전용 [계약 증표 장비 후보](./PACT_FOCUS.md)의 5등급 가호/권능 효율은 공통 매개체 슬롯 1개에서만 적용. 패시브가 장비 등급을 우회하거나 서브장비 슬롯을 늘리지 않는다.
- `기본 캐릭터 레벨 스탯 → 각 계약 가호/심화/관계 반영 → 스탯별 이중계약 50% → 공통 패시브의 해당 증가분 보정 → 매개체의 해당 증가분 보정 → 실제 무기/스킬 공격 및 방어 계산` 순서 후보. 정확한 법적/게임 적용 순서, 영구 최대 HP 봉인과 특수 피해/힐/방어는 별도 검증.
- 다른 직업과 비교: 결계술사는 초반 압축 총 26HP/중형 방어 내구64HP, 인형술사는 별도 전투 개체, 기생술사는 숙주의 원래 전투 능력과 BD 축적, 정신 지배자는 실제 지배체 전력. 계약술사는 **본체 강화 + 직접 무기·권능 교전**을 비교하고 한 번의 이론적 퍼센트 합산만으로 우위 판정하지 않는다.
- 테스트 전 확인: 계약 변경 후 공통 랭크 보존, 계약 없음일 때 실체 없는 가호 금지, 강행 파기 시 패시브가 위약금을 우회하지 않는지, 최대 HP 변동 시 현재 비율 유지, 이중계약 50% 정확히 적용, 보스/모드 공격 속성·PvP·사망/재접속, 게임 내 효과명/설명과 실제 수치 일치.

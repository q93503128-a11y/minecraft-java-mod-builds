## 1. 공통 시전·수치 정의

- **모든 피해 수치는 Minecraft HP(하트 1칸=2HP)**이고, 아래 수치는 **같은 레벨/장비에서 비교할 초기 데이터 값**이다. 실제 레벨·직업 성장과의 통합을 위한 권능 공격력 공통 배율 `PactAbilityPower(L)`은 프로젝트의 실제 자동 성장과 맞춰 서버에서 **한 번만** 적용해야 한다. 레벨별 공통 공격 공식이 아직 확정되지 않았으므로 여기에서 임의의 `Lv300 ×N`을 만들어 중복 곱하지 않는다. `Lv1, PactAbilityPower(1)=1`의 공격 참고치이며 3·4위계 획득 적정 레벨은 아직 정하지 않았다.
- **본체 무기 공격 가호, 권능 공격 가호, 패시브 보너스와 장비 버프는 유형별로 한 번씩만 적용**한다. 기존 가호 표기는 원래 1~4위계 문서의 **미검증 초기 비교 수치**를 그대로 가져온 것으로, 새 숫자 강제 승인으로 둔갑시키지 않는다. HP 가호는 기본 최대HP 증가분을 계산하고 착탈 시 공짜 치유 불가.
- **직접 기술은 선행 표식·완벽 회피·특정 날씨·특수 바이옴·다른 계약 없이 사용**. 실전 동작 중 보호구역·사거리·쿨다운·적법 타깃·해당 계약 유효성·월드/차원·개별 HP 비용은 정상 검사. 조건형 콤보 성공은 추가 보상이지 기본 위력을 잠그는 관문이 아니다.
- **대상과 영역**은 서버가 실제 위치·충돌·시야/보호를 검증한다. 광역 기술의 타격 수는 공격당 표기 범위 내 적법 대상 **1회씩**(중복 엔티티/파트 판정으로 여러 번 맞지 않게). PvP는 서버 원래 설정, 같은 팀/소유 동료/주민 보호 조항을 보존한다. 시전 이펙트와 실제 판정 일치, 화면 흔들림·모션/사운드는 사용자 설정으로 줄일 수 있다.
- **패시브**는 별도 발동키·매일 출석·반복 제물 없이 계약 체결과 함께 사용. 같은 피해 사건에서 자신이 낸 패시브의 추가 피해는 **다른 공격형 패시브를 다시 트리거하지 못함**. 대상별 내부 재사용, 틱당 최대 1회, 실제 적에게 유효 피해를 준 경우에만 유효 공격 이벤트 발생. 여러 계약일 때 상시 속성 보너스는 기존 *최강 증가분100% + 그 외 각 50%*로 계산하고, 계약 고유 기능은 임의 절반으로 삭제/비활성화하지 않는다. 중복 동일 효과는 최종 한 번, 중첩 대신 효과 시간이 갱신된다.
- **일반 시전 비용**은 기본 쿨다운뿐. 벨칸의 기존 위험 HP 지불, 하스텔의 채무 등 원래 계약 고유 비용은 보존. 제물을 평타/보통 액티브마다 내지 않는다. 선택적 현현은 원래 희귀 재료·사전 고지·최종 확인을 그대로 사용하며 여기의 일반 Z/X 전투 스킬과 혼동 금지.
- **반복 시전 안전**: 시작 시 유효하지 않으면 비용/쿨다운 없음. 유효 시전이 실제로 시작된 뒤 적이 회피해 피해가 0이 되었다면 정상 쿨다운 적용(모든 빗나감 무료화 금지). 클라에서 이펙트만 나왔는데 서버가 거부하면 허위 성공 표시 금지.
- **기존 9노드×30랭크=270랭크 공통 패시브는 보존**. 아래 추가된 계약 고유 패시브는 **SP를 별도로 구매하지 않고 계약 체결과 동시에 획득**. 여러 계약을 억지로 체결해 1인 직업을 완성시키지 않는다.

## 2. 기본 조작 선택 (계약술사 한정, 테스트 전 수정 가능)

| 조작 | 기본 기능 | 설명 |
|---|---|---|
| `Z`, `X` | 첫 번째 활성 계약의 **직접 기술 1·2** | 첫 계약 1스킬이면 X는 빈 키. 조건형/패시브를 X로 억지 배치하지 않음 |
| `C`, `V` | 두 번째 활성 계약의 **직접 기술 1·2** | 두 번째 계약 없으면 비움. 계약 순서/즐겨찾기 커스텀 변경 허용 |
| `B`, `G` | 세 번째 활성 계약의 **직접 기술 1·2** | 세 번째 계약이 없으면 비움. 하나만 직접기면 다른 키 비움 |
| `R` | **추가 권능 페이지 다음으로 이동** | 직접 액티브가 6개 이하이면 아무 역할 없음. 4개 이상 계약 등 7번째 직접기가 생길 때만 활성. **전투 선택 휠/길게 누르기 금지** |
| `M` | 공통 프로필·계약 정보/권능 배치 | 전체 계약·가호/위약금·관계·심화·패시브 정보. M 통합 메뉴는 사용자 제안이므로 프로젝트 공통 UI 최종 구성과 충돌하면 그 결정을 따름 |

- 위 계약술사 전용 기본키는 **이번 설계에서 선택한 구현 출발값**이고 전체 직업의 `R/Z/X/C/V/B/G` 의미를 바꾸지 않는다. 특히 **기생술사 V-계승 숫자 모드와 별도**, 계약술사는 바닐라 1~9 핫바를 빼앗지 않는다.
- **단축키 등록은 안정적 기술 ID 기준**: 1·2·3번째 계약에 대해 순서대로 Z/X, C/V, B/G를 기본 제안하되, 앞선 계약에 직접기가 하나만 있어서 빈 자리가 있다면 **4번째 이상 계약의 직접기는 그 빈 키에 우선 배정**한다. 총 6개 칸이 실제로 다 찼을 때만 추가 페이지를 만들어 **R로 다음 6칸 페이지를 즉시 바꾼다**. 새로운 계약 추가·해약·관계 봉인이 있을 때 이미 플레이어가 직접 지정한 단축키 위치는 조용히 재배열하지 않는다. 신규 기술만 빈 키에 자동 채우고, 충돌/빈자리 부족은 M 배치창의 명확한 상태로 표시한다. 일반 1~2계약 전투에 R 전환이 필요 없으며 **단축키 수=보유 기술 수 상한이 아님**. 포커스 손실·차원 이동·직업 변경·재접속 시 안전한 1페이지로 돌아가고 물리키는 리바인딩 가능.
- 계약 파기/일시 봉인 시 슬롯은 **다른 계약 기술로 조용히 대체 시전하지 않고**, HUD에 비활성 표시 후 명시적 재배치. 미해금·자동·조건형 권능은 직접 단축키에 나타나지 않는다.
- 현현은 별도 **M > 계약 > 현현**의 비용 확인·최종 확정 UI를 쓰는 기본안. 실전 전용 H 등 별도 키는 굳이 만들지 않는다. 특별 비용을 몰래 소비하는 즉시 단축키 없음. 궁극 시전의 전투 사용성은 인게임 검증 후 개선한다.

## 3. 16개 계약자의 상세 개별 기본값

기록 형식: **위계 / 상시 본체 가호 (기존 미검증 시험안) / 실제 눌러서 쓰는 기술 / 자동 고유 패시브 3개 / 한 계약 전투 루프**. 기술에 표시한 재사용은 기술별 별도이며 버프 시간·타격 피해·회복량은 독립 값이다.

| **검은 별의 재림** / `Z` | 전방 최대 18블록·반경 5블록 | 범위 타격 65HP | 14초 | 흑성 기록 없어도 사용 가능. 최근 자기 유효 피해 사건 기록이 있으면 +25% 추가 별 타격, 기록 1개 소모 |

**고유 패시브 (자동, 기본 가호와 별개)**

1. **흑성의 인과** — 자신이 실제 발생시킨 적법 피해 사건을 20초간 하나 자동 기록(최대 1개). 과거 원시 피해량·체력비례 원킬을 그대로 재실행하지 않음
2. **잔광의 반격** — 유효 직접 무기 공격 때 6HP 별빛 여파, 4초 내부재사용
3. **사건 감각** — 강력한 근접/원거리 피격 후 4초간 다음 일반 피해 20% 경감, 16초 내부재사용

**일반 전투:** 별 기록 없이 큰 별 타격→일반 공격으로 흑성 기록→다음 재림 추가 피해. 고가 현현은 별개의 특별 사건.


### 4위계 · 라키엘 — 초월 신성 검술+자동 단발 구원

**본체 가호:** 최대 HP +135%, 직접 공격 +85% (기존 4위계 시험값).

**직접 액티브**

| 기술 / 기본 슬롯 | 목표 | 즉시 효과(초기값) | 재사용 | 실패·보너스 규칙 |
|---|---|---|---|---|
| **첫 서약의 검** / `Z` | 전방 최대 9블록·너비 5블록 | 적 각각 52HP + 주변 적법 적 한 명 10HP 신성 후속타 | 8초 | 보호 성공/아군 존재와 무관하게 바로 발동. 본체 기본 타격도 매우 강력 |

**고유 패시브 (자동, 기본 가호와 별개)**

1. **운명의 거부** — 자신을 기본 보호 대상으로 등록(동료 보호는 M에서 명시적 변경). **치명 타격 때 금 블록 2개를 서버에서 단 한 번 소비**, 180초 내부재사용이 가능하면 사망 1회 저지하고 최대HP의 20%로 회복(최소 1HP). **바닐라 불사의 토템을 먼저 판정하고, 토템이 발동하지 않을 때만 이 권능이 작동**. 자원이 없거나 대기 중이면 사용 불가를 상태 UI에 표시. 다른 차원·재접속/중복 사망사건으로 이중 소비·공짜 구원 금지. 이 금 블록 비용은 수치 시험 초기값이고 특별 현현 제물과 별개
2. **서약의 빛** — 평소 자신 근접 적중 때 추가 6HP 신성 타격, 4초 내부재사용
3. **불굴의 서약** — 실제 피격 시 3초 동안 받는 피해 15% 경감, 16초 내부재사용

**일반 전투:** 평소에는 강력한 신성 검과 무기 타격만으로 압도적. 운명의 거부는 별도 대가 있는 희귀 구원.


### 4위계 · 오르마스 — 대지형 근접 최상위·광역 지면 타격

**본체 가호:** 최대 HP +160%, 근접 +120%, 채굴 속도 +55% (기존 4위계 시험값).

**직접 액티브**

| 기술 / 기본 슬롯 | 목표 | 즉시 효과(초기값) | 재사용 | 실패·보너스 규칙 |
|---|---|---|---|---|
| **대륙의 피부** / `Z` | 자기 자신 | 피해 흡수 55HP + 근접 공격 +20%, 10초 | 22초 | 결계가 아닌 시전자 귀속 보호. 대륙 분쇄의 선행 조건 아님 |
| **대륙 분쇄** / `X` | 전방 8블록·반경 6블록 | 적법 대상 각각 60HP + 약한 타격 반응 | 13초 | 석갑 없어도 강력. 세이브/상자/건물 영구 파괴 없음, 서버 범위·시각 일치 |

**고유 패시브 (자동, 기본 가호와 별개)**

1. **대지의 중력** — 상시 넉백 저항 55%(기본 속성과 중복 계산 시 최종값 1회)
2. **산맥 여진** — 유효 근접 타격 때 주변 다른 적법 적 최대 2명에 8HP 충격, 5초 내부재사용
3. **지각의 숨결** — 낙하 피해 55% 감소·채굴 도중 피격 넉백 소폭 추가 완화. 기본 채굴 가호와 별도 물리 효과

**일반 전투:** 본체 평타만으로 강하고 분쇄를 단독으로 쓸 수 있음. 피부는 위험할 때 생존 강화.


### 4위계 · 비아르 — 강한 뿌리 광역 제압과 실제 전투 회복

**본체 가호:** 최대 HP +140%, 직접 공격 +85%, 본체 회복 가호 (기존 4위계 시험값).

**직접 액티브**

| 기술 / 기본 슬롯 | 목표 | 즉시 효과(초기값) | 재사용 | 실패·보너스 규칙 |
|---|---|---|---|---|
| **첫 뿌리** / `Z` | 전방 11블록·반경 4블록 | 적 각각 54HP + 일반 적 이동 느려짐 1.5초 | 11초 | 숲/물/식물 블록 없어도 정상. 보스에는 큰 피해 유지·속박 완화 |

**고유 패시브 (자동, 기본 가호와 별개)**

1. **생명의 역류** — 자신이 적법 적에게 실제 준 직접·권능 피해의 12%를 회복(5초당 최대 7HP), 자가 피해·무적 허수아비 피해 제외
2. **원시 회복** — 실제 유효 피해를 입힌 교전 중 5초마다 추가 1HP 회복, 피해를 안 입었으면 무효
3. **싹의 반격** — 적법 적에게 피격받을 때 공격자에게 뿌리 7HP 반격, 10초 내부재사용. 자신/아군 자해로 발동 금지

**일반 전투:** 첫 뿌리만으로 큰 광역 피해→기본 공격과 뿌리 연계에서 자동으로 회복. 특수 생물군계 필요 없음.

## 4. 전투 밸런스·위계 간 규칙

- **강한 기본값:** 1위계 일반 직접 공격 7~12HP/6~14초, 2위계 14~16HP/7~16초, 3위계 25~30HP/8~20초, 4위계 52~65HP/8~22초 등이 **데이터 초기값**이다. 이것만 보면 4위계가 압도적으로 강하지만 실제 4위계 획득 시점·외부 몬스터 HP·레벨 계수가 미정이므로 **출시 조정 확정값 아님**. 고위의 유틸/광역/구원은 숫자만이 아닌 질적 차별.
- **선행 콤보 보너스는 기본 피해의 대략 0~35%**에 한정해 첫 시전도 의미가 있게 한다. 표식·기록·선행 도약 없을 때 막힌 액티브가 있으면 실패. 보스/플레이어의 CC는 제한해도 **피해 자체를 단순 0으로 만들지 않는다**.
- **비슷한 분야 위계 비교**: 우르겐 ↔ 타론 ↔ 오르마스는 중갑·광역 타격에서, 벨칸 ↔ 메르자드는 화염에서, 이사엘 ↔ 칠익 ↔ 라키엘은 신성 공격·보호에서 높은 위계가 확연히 강함. 리드나 기동과 나하르 인과는 모티브만 연관되므로 단순 같은 타격으로 평준화하지 않는다.
- **HP 비용/회복 상호작용:** 벨칸이 지불한 HP는 타 계약 흡혈·회복이 무조건 즉시 전액 반환시키지 않게 실제 유효 적 피해·단위시간 회복 상한을 둔다. 하스텔 채무는 HP와 별도 서버 상태; 정기적 시간 압박/오프라인 자동 누적 금지. 비아르 회복/이사엘 보호 등은 아군 공짜 적중·가짜 적/허수아비로 무한 발동 금지.
- **가호와 패시브를 중복 세지 않음:** 명시된 수중 호흡, 원래 근접/채굴 가호, 기본 넉백 저항과 개별 자동 효과가 같은 Attribute를 2회 더하지 않게 최종 수치 계산에 고유 그룹을 둔다. 내부 재사용·서버 타격ID·계약ID로 멀티 동시 시전의 중복 이벤트/반사-반사 재귀 방지.
- **심화는 기본기를 제거하지 않는다.** 1차는 사거리/사용감/가호를 강화, 2차는 기존 패시브-액티브 연계를 강화하는 방식이 우선. 고정 2회 심화는 옛 기획에서 후보였으므로 **모든 계약에 무조건 단계 수 2로 확정하지 않음**. 관계와 권능 성장, 제물/위약금/서약 보존.
- **현현은 일반 스킬 카탈로그에 포함하지 않음.** 3/4위계의 특별 제물·성향·확률적 개입·고유 모델/사운드·현현 실패 비용은 기존 정본 유지; 성능을 일반 기술로 축소하지 않는다.
- **시점 불변조건**: 계약 없음/첫 체결/1계약 심화/2계약/3계약/계약 파기·봉인/다른 직업으로 교체/사망·재접속·멀티에서 자신의 권능·고유 패시브/가호/재사용/채무가 서버 스냅샷과 일치. 공짜 아이템/체력 리필·성장 소실 금지.

## 5. 구현 및 실플레이 검증 대상

| 검사 | 시나리오 | 정상 기준 |
|---|---|---|
| 1계약 입문 | 이사엘·벨칸·우르겐·리드나 각각 낮은 단계/기본 장비로 좀비·스켈레톤·작은 무리 | 기본 주력 기술은 선행 조건 없이 발동, 1계약으로 생존·처치 가능; 무기 전투도 매끄러움 |
| 사거리/레이캐스트 | 벽, 물, 좁은 동굴, 열린 공간, 조준 대상 없음 | 대상 없는 순간 무적/벽 관통 금지. 자기 시전 방어는 타깃 없을 때 정상 동작 |
| 패시브 중첩 | 지속 평타·1초 다중 히트·한 공격 다수 개체·파티 PvP/농장 허수아비 | 패시브 자체가 패시브를 무한 호출하지 않음. 눈에 띄는 자동 보상, 서버 한도 준수 |
| 계약 2~5개 | 권능 단축 페이지 전환 / 존재별 금기·제물/가호 중첩 | 전부 접근 가능한 직접 기술, 각 권능 중복 시전/등록 오류 없음, 가호 100%+각 50%, 신규 체결 1/2/4/8/16배 |
| 고위 계약 | 3·4위계 기본 권능 단독 + 보너스 조건 충족 + 특별 현현 | 4위계는 같은 분야 1위계 최대 심화보다 실전 주력 우위, 현현 없더라도 충분히 강력 |
| 상태 수명 | 사망·로그아웃·직업 변경·재접속·추가 계약 해지 | 가호 잔류·공짜 회복/쿨 회피·채무 손실·무한 현현/누락 금지 |
| 성능/화면 | 다인 멀티, 스킬 다중 히트, 큰 VFX, FPS/TPS | 서버 권한 피해 일치, 클라이언트 납득 가능한 피드백; 메모리/틱 부하 실제 측정 |

**검증 단계:** 작성·기존 문서 대조 수준 **DESIGN REVIEWED**. 모드 코드 없음, COMPILATION NOT RUN, JAR NOT PRODUCED, CLIENT NOT PLAYTESTED, MULTIPLAYER NOT TESTED. 피해·쿨다운·패시브 발동 빈도는 **수치 실험 전 조정 가능한 기본값**. 구현 시 `data-driven`으로 분리하고, 자료 변경이면 코드 빌드 반복 대신 게임 화면/플레이 확인을 우선.

## 1. 가칭 '군체 핵'의 역할

- **하나의 군체가 가진 개체 공격력과 개체 생존력**을 강화하는 **작고 살아 있는 중심 매개체**다. 전투 중 공격대·엄호대로 분리해도 같은 군체를 하나의 핵이 통솔한다.
- **군체 증식은 자동 기본 특성**, 장비 없이도 자연스럽게 일어난다. **원격 표적, 공격대·엄호대 동시 운용, 적 투사체의 실제 엄호 피격·개체 희생, 기본 급습·소모 기술**을 고등급 장비로 잠그지 않는다.
- 매개체의 주 효과를 **① 유효 개체 공격 성능 ② 유효 개체 내구**의 **딱 두 가지**로 제한하는 것을 추천한다. 최대 군체 수/엄호 비율/표적 사거리/개별 AI 수/증식 버튼/전용 화폐 등 쓸데없는 옵션 추가 X.
- 플레이어 무기 피해·본체 체력/방어구·일반 바닐라 공격은 매개체 보너스 대상 아님. 다만 개체 공격 기반의 군집 급습/군체 소모 피해가 합당하게 성장하는 것은 허용하되 같은 보너스를 두 번 곱하지 않는다.

## 2. 5등급 효율 후보 (타 직업 5등급의 미검증 보너스 체급 참고)

| 장착 상태 | **군체 개체 공격** | **군체 개체 소실 내구** |
| --- | ---: | ---: |
| 장비 없음 | +0% | +0% |
| **규격 군체 핵** | +5% | +5% |
| **변조 군체 핵** | +10% | +10% |
| **변칙 군체 핵** | +15% | +15% |
| **이형 군체 핵** | +20% | +20% |
| **불가해 군체 핵** | +25% | +25% |

- **단일 장착:** 실제 공통 직업 매개체 슬롯의 1개 아이템 등급만 서버가 적용. 5개 소유·인벤토리 내 보관/단순 손 전시만으로 중복 적용하지 않는다.
- **개체 공격 예시:** 기본 개체 유효 공격 지표 10(가상)→불가해 장착 12.5(가상), 이 값이 실제 적에게 가는 피해와 군집 기술에 적법한 **한 번의 증가**로 반영. `N×개체 위력`의 단순 무한 곱셈을 최종 공식으로 선언하지 않는다.
- **내구 예시:** 기본 개체가 `10 유효 피해`에 해당하는 손실 임계(가상)→불가해 +25% 내구면 `12.5`(가상)로 올라 같은 화살 한 발에 소멸하는 개체 수를 줄일 수 있음. 실제 탄체 피해·군집 밀도·누적 손실 분수 처리 방식은 미결정.
- 공격/엄호대에 동일 장비 기준을 사용하되 *같은 개체*가 두 번 장비 보너스를 받지 않는다. 엄호단 소실 내구는 공통 갑피/호위 패시브와 합산 후 장비를 한 번 적용. **'피해 차단 성공=무료 보상' 없음.**
- 소유자 사망/차원 이동/재접속/장비 교체 시 이미 받은 유효 피해·남은 군체 N·재배치 상태를 **임의 최대치로 무료 회복/복제하지 않는다**. 내구 보너스 교체는 개체별 HP 저장 대신 집단 손실 잔여 피해분을 안전하게 재계산/비율 유지.

## 3. 바닐라 기반 제작·승급 재료 후보 (수치 미확정)

새로운 전용 '군체 코인'이나 별도 제단 필수 제작을 피하고, 가능한 한 바닐라 제작대 3×3에서 직전 단계 핵 1개 + 소재로 승급한다. **재료 수는 서로 다른 제작칸에 하나씩 배치 가능한 슬롯 개수**로 표기하였고, 정확한 shaped/shapeless recipe JSON은 실제 버전·로더 선정 후 결정.

| 제작 결과 | 직전 등급 | 추가 소재 방향(시험) | 사용 슬롯 수 |
| --- | --- | --- | ---: |
| **규격** | 없음 | 구리 주괴×2, 실×2, 슬라임볼×1, 자수정 조각×1 | **6** |
| **변조** | 규격×1 | 철 주괴×2, 레드스톤 가루×2, 슬라임볼×2 | **7** |
| **변칙** | 변조×1 | 금 주괴×2, 흑요석×2, 자수정 조각×2, 엔더 진주×1 | **8** |
| **이형** | 변칙×1 | 다이아몬드×2, 메아리 조각×2, 프리즈머린 조각×2 | **7** |
| **불가해** | 이형×1 | 네더의 별×1, 네더라이트 파편×2, 메아리 조각×2, 자수정 조각×2 | **8** |

- **제작 가능성/게임 경제 검증 필요:** 슬라임볼/메아리 조각 등의 특정 구조/바이옴/차원 의존과 다른 직업 최고 등급 제물의 형평성. 정확한 재료 수량은 최종 확정 전. 너무 많은 희귀 재료로 재미가 떨어지면 같은 난도의 대체 재료/획득처를 검토하고, 꼭 특별한 물품을 새로 5개 추가하지 않는다.
- 초반 규격 핵 제작이 없더라도 군체 직업은 **입문 군단/원격 타깃/공격/엄호/재증식 가능**. 장비는 본체의 성장감을 높이는 보너스.
- 직전 매개체 하나를 정확히 소비하고 새 장비 하나를 반환. 인벤토리 이동 중복 요청/클라이언트 레시피 재접속/사망 등으로 복제 방지.

## 4. 3D 모델·애니메이션·시야 안전

### 4.1 오브젝트 방향 (가칭 모델 레퍼런스, 실제 자산 없음)

- 크리스털과 생물학적 갑피가 섞인 **손바닥 크기 타원형 핵** 안에서 작은 빛과 생물의 맥동이 일어나는 형태. **기생술사의 공생 핵과 실루엣/질감이 충분히 달라야** 한다. 기생 공생 핵은 숙주 본체 귀속, 군체 핵은 여러 생물을 잇는 '군단의 둥지' 모티브.
- **규격/변조**: 거친 금속틀과 얇은 벌집/갑피 문양. **변칙**: 내부에 살아 있는 다층 격자와 작은 부유 조각. **이형**: 핵 일부가 작은 생물형 부속으로 분열해 주변을 회전. **불가해**: 금속/갑피의 반투명 깊이와 규칙적인 맥동/아주 작은 복수 생물 그림자; 과도한 glow/gradient/렌더 오버드로우 금지.
- 손에 항상 들고 있어야 하는 것이 아니라 **직업 매개체 슬롯 장착→시전/원격 명령 순간만 짧게 손 위에 현현**. 이후 두 손의 곡괭이/방패/토템은 그대로. 시각 손 연출과 실제 item slot 위치는 분리.
- 개체 공격력 강화가 실제 작은 생물에게 더 강한 턱·가시·공격 피드백을, 개체 생존력 강화가 갑피·충격 반응을 주는 방향 검토. 외형 변형은 **노드/매개체 성장의 부수 시각 피드백**, 반드시 270종 별도 모델을 만들어야 한다는 뜻 아님.

### 4.2 시야·성능 기준

- **가장 높은 등급에서도** 군체 엄호대가 플레이어 1인칭 카메라 중앙을 계속 막지 않음. 장비의 화려한 핵·부유 개체/지속 파티클이 게임을 가리는 상황 금지.
- **급습대/엄호대 생물**을 분명하게 구분해 공격대는 적 주위, 엄호대는 플레이어 측/하단에 보이되 높은 밀도일수록 클라이언트 LOD/근접 페이드/그룹 렌더를 사용. 원래 논리 N/피격판정과 시각 수량의 일관성을 유지.
- GeckoLib 등 애니메이션 자산 활용은 실제 Minecraft 버전/로더·API·최적화 검사 후 결정. 참고: https://modrinth.com/mod/Geckolib (MIT 등 최신 라이선스/버전은 적용 시 재검증). 기존 Minecraft 자산의 저작권을 모르는 상태에서 무단 베이스 이용 X.
- 사운드: 작은 발걸음/턱/갑피/분열 소리 **특히 공격 중 피격·방어 성공**에 짧고 듣기 편한 피드백. 100개체 각각 매틱 별도 오디오 생성 금지. 원격 공격의 개체 일부 소멸이 정확하게 전투 HUD의 수량 손실과 동기화.

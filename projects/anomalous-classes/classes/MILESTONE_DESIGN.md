## 2. 설계 계약

- 총 10개 패시브, **270랭크**(20~40랭크/노드) 후보를 유지. 일반 랭크의 효과는 낮지만 **첫 10랭크 이내의 실전 변화**가 있어야 한다.
- '돌파'는 같은 노드에 투자한 랭크의 이정표(예: 10/20/30/40)에서 **자동 발동하는 영구 보너스**다. 별도 포인트/재화/버튼/전직을 추가하지 않는다.
- 최대 랭크가 같은 패시브라도 단순 능력치만 복사·붙여넣기 하지 않는다. 장악 / 결속 / 간섭의 기능을 구분한다.
- 원래의 **개별 지배 유지비 `U(T,L)`**, 장악 진행률, `MaxControlled(L,r)`, `GroupCost(N,q)` 시안을 기반으로 설계하되, 조건부 돌파 수치는 곱 보정으로 적용하고 0 이하 유지비나 정신력 생성은 방지한다.
- 강적·보스의 지배/CC를 막는 대상 분류별 영구 면역, 최대 지배 시간, 레벨 상한은 새로 만들지 않는다.
- 지배한 몹은 각자의 원래 생태/전투 방식에 맞게 행동한다. 패시브로 주민에게 임의의 공격 기능을 새로 부여하지 않는다.
- 외부 모드 AI 특수 기믹을 기본 API만으로 구현했다고 가정하지 않고, 지원 가능한 상태/입력/이벤트별 어댑터로 검증한다.
- 플레이어 직접 지배/PvP 참여는 미정. 현재는 몬스터/비플레이어 생명체 중심으로 설계.

## 3. 패시브 10종의 세부 돌파 보상 초안

아래 랭크/수치들은 전부 **가상 초기 밸런스**다. 달성한 돌파 효과는 누적 적용하되, 동일 종류의 속도/비용 보정은 계산 순서를 고정해야 한다.

### A. 장악 — 강한 개체 확보

**1. 심층 침투 (최대 30랭크)**

- 일반: 랭크당 정신 침투 장악 속도 **+1% 가산**, 랭크30이면 +30%.
- **10랭크 — 초입 집중:** 정신 침투 시작 후 최초 1.5초 동안 장악 속도 추가 +12%. 길들이기/CC 이후 지배를 열 때 즉시 체감.
- **20랭크 — 약점 포착:** 체력 50% 이하인 대상에 대해 장악 속도 추가 +10%. 기존 체력 감소 보정과 곱 적용하고, 필수 체력 임계값은 만들지 않음.
- **30랭크 — 종결 압박:** 장악도 80% 이상일 때 남은 장악 구간 속도 추가 +15%. 보스/비적대 개체 모두 동일 규칙.
- 밸런스: 평균 장악 속도 증가 중첩을 확인. 무한 레벨 고레벨의 극단적인 초고속 지배는 인게임 검수.

**2. 저항 관통 (최대 30랭크)**

- 일반: 정신 침투의 **유효 위협도만 랭크당 -0.5%**, 최대 -15%. 실제 몬스터 공격력/유지비는 변경 안 함.
- **10랭크 — 저항 균열:** 강적의 정신 침투 속도 추가 +5% × `min(1,T/160)`.
- **20랭크 — 저항 해석:** 추가 +7% × `min(1,T/160)`.
- **30랭크 — 저항 붕괴:** 추가 +8% × `min(1,T/160)`.
- T=160 이상에서 총 +20%까지(각 돌파 합산). 일반 잡몹도 약간 효과가 있지만 강력한 개체에서 효율이 더 커짐. 적 분류에 따른 보스 전용 허용/금지 규칙이 아님.

**3. 지배 안정화 (최대 20랭크)**

- 일반: 집중이 끊긴 후 장악도 감소 속도 랭크당 -2%, 최대 -40%.
- **10랭크 — 정신 고정:** 18초에 한 번, 집중 중 최초의 공격 피격 1회로 집중이 강제로 끊기지 않음(피해 자체는 정상).
- **20랭크 — 잔류 연결:** 일시적으로 시야를 잃거나 사정거리를 벗어나 집중이 끊겼을 때 **1.2초 이내 같은 대상으로 재시도**하면 기존 장악도의 일부를 유지. 부하/쿨타임은 정상 적용; 청크 언로드/로그아웃 중에는 연결을 지속할 수 없음.
- 의도: 지배 중 반격에 대처할 기회를 주되, 영원히 장악도를 저장·축적하여 보스를 공짜로 포획하는 오류는 막는다.

### B. 결속 — 더 오래, 더 많이, 더 안전하게

**4. 정신 결속 (최대 40랭크)**

- 일반: 개체별 정신력 유지비 랭크당 -0.65%, 최대 -26%, 장비와 곱 보정.
- **10랭크 — 안정된 휴식:** 지배자와 대상 모두 최근 5초간 피해를 주고받지 않은 경우, 해당 개체 유지비 추가 -8%. 전투 시작 시 즉시 해제.
- **20랭크 — 정착 결속:** **대기** 모드의 개체는 개별 유지비 추가 -12%. 공격 중이나 이동 중인 경우는 적용하지 않음.
- **30랭크 — 위기 안정:** 정신력이 15% 아래로 떨어지면 3초간 총 지배 유지비 -20% (재사용 대기 45초). 정신력 고갈을 완전히 막지는 못함.
- **40랭크 — 핵심 결속:** 현재 보유 대상 중 **위협도 T가 가장 높은 개체 1마리**의 개별 유지비 추가 -10%. 별도 선호 몬스터 지정 UI 없이 자동 계산.
- 전역 유지비 할인, 대기 할인, 장비 할인, 특수 1개 할인은 개별적으로 곱 적용. 대상의 원래 저항/포획 비용은 변경하지 않음.

**5. 다중 결속 (최대 30랭크)**

- 일반: 랭크당 최대 정신력 +0.5% 후보. **매 5랭크마다 동시 지배 가능 수 +1**.
- **5/10/15/20/25/30랭크 — 결속 확장:** 해당 단계마다 **마릿수 +1**, 총 +6.
- 기본 슬롯 자체는 `3 + floor(sqrt((L-1)/8))`로 무제한 레벨에 따라 천천히 증가. 수용 마릿수 상한을 넘어서 새로운 개체를 획득하려면 기존 개체 하나를 해제해야 한다는 안은 별도 검토.
- 기존 동행/대기/해제, 공격 허용 토글 외에 군단 지휘 시스템은 새로 만들지 않음.

**6. 분산 동조 (최대 30랭크)**

- 일반: 다중 결속 추가 정신력 유지비 랭크당 -1%, 최대 -30%.
- **10랭크 — 표적 공유:** 지배자가 직접 때린 대상에 대해 주변 전투형 지배체 최대 2마리가 3초간 우선 공격(사거리/원래 AI·평화 설정 준수).
- **20랭크 — 위협 전파:** 주인이 공격받으면 주변 전투형 지배체 1마리가 공격자를 우선 견제. 3초간 자동 반응, 8초 내부 쿨타임.
- **30랭크 — 합동 압박:** 서로 다른 지배체 3마리가 4초 안에 동일 적을 공격하면 다음 아군 타격에 +8% 피해(대상별 6초 쿨타임).
- 이것은 **기존 지배체의 협공 행동**이며, 개체를 새로 생성하거나 미니언 숫자를 무한 증가시키는 군체술사 시스템과 구별한다.

### C. 간섭 — 지배 없이도 싸울 수 있는 정신 전투

**7. 충격 잔향 (최대 20랭크)**

- 일반: 정신 충격에 맞은 대상은 4초간 정신 침투 장악 속도 보너스, 랭크당 +0.8% (최대 +16%).
- **10랭크 — 끊기지 않는 침투:** 정신 충격을 사용해도 진행 중인 대상의 장악도가 초기화되지 않고, 짧은 연계 유예를 얻음. 정신 충격의 정신력 비용/쿨타임은 유지.
- **20랭크 — 연쇄 암시:** 정신 충격이 적중한 대상에게 4초 안에 자해 암시를 사용하면, 자해 암시 정신 저항 판정을 소폭 유리하게 보정 (+10% 상당의 시도 효율).
- 보스에게 자동 확정 자해/지배를 주지 않으며, 공격성과 관계없는 생명체에 적용되는 안전·호환 정책은 별도 정의.

**8. 암시 심화 (최대 25랭크)**

- 일반: 자해 암시로 유발되는 유효 자기 피해 랭크당 +1%, 최대 +25%.
- **10랭크 — 정신 혼란:** 자해 암시 성공 후 대상의 주인 공격력을 2초간 -10% (대상의 전투 능력을 영구 약화하지 않음).
- **20랭크 — 노출된 의식:** 자해가 실제로 적중하면 해당 개체의 장악도에 **최대 2.5%** 기여. 적중이 취소/무효면 추가 장악도 없음. 동일 사용 한 번에 한 번만 적용.
- **25랭크 — 열린 균열:** 자해 성공 이후 4초간 해당 대상 정신 침투 속도 추가 +12%. 이전 20랭크 효과와 연계되나, 자체적으로 보스 영구 봉쇄를 만들지 않음.
- 종별 자기 공격/애니메이션을 그대로 사용할 수 있는지는 외부 모드별 검증. 지원되지 않는 공격은 정직하게 대체 반응을 정의해야 함.

**9. 과부하 지속 (최대 25랭크)**

- 일반: 정신 과부하의 **지배 대상 강화 지속시간** 랭크당 +0.12초, 총 +3초. 기본 8초(이전 미확정 초안).
- **10랭크 — 신경 가속:** 정신 과부하 대상의 공격 속도 +10% (단일 대상).
- **20랭크 — 몰아붙이기:** 강화된 대상이 체력 50% 이하라면 공격력 추가 +15%를 얻지만, 유지 비용 페널티가 다소 상승하는 안(+10%p, 미확정).
- **25랭크 — 잔향 전파:** 강화 대상 주변 8블록 안에 다른 지배체가 있을 때 **최대 2마리**에게 원래 정신 과부하 강화량의 25%를 분배. 이 경우 유지비 추가 부담이 있음. 주변 대상이 없다면 본래 강화 대상의 효과만 적용한다.
- 보스/외부 몬스터의 고유 특수공격을 삭제·무시하지 않으며 같은 효과의 재귀 중첩은 금지. 강력한 한 마리를 중점 강화하는 정체성을 유지한다. (Last Epoch Dread Shade의 강화 대상·대가·범위 선택에서 원칙만 차용)

**10. 봉쇄 확장 (최대 20랭크)**

- 일반: 의식 봉쇄(가칭) 반경 랭크당 +0.12블록, 총 +2.4블록.
- **10랭크 — 잔류 마비:** 정지가 풀린 비플레이어 생명체는 1.5초간 이동속도 -20%. 보스도 절대 면역을 새로 도입하지 않으나, 별도 저항 계산으로 적용 시간을 줄일 수 있음.
- **20랭크 — 열린 정신:** 의식 봉쇄에 적중한 대상에 대한 첫 정신 침투는 2초간 장악 속도 +10%. 연속 CC 영구화 대신 **CC→지배 전환** 보상.
- 다른 플레이어/PvP 적용 여부는 아직 결정되지 않았다. 시전자/지배 중 아군을 제외할지도 미정이며, 미확정 결정을 패시브 특성으로 몰래 고정하지 않는다.

## 4. 중복/오용/밸런스 검토

- **정신 결속**은 개별 유지비, **분산 동조**는 다중 소모, **다중 결속**은 마릿수에 영향을 준다. 서로 역할이 다르다.
- **심층 침투**는 장악 속도, **저항 관통**은 높은 T의 효율, **안정화**는 피격과 집중 중단 대처다.
- **충격 잔향/암시 심화/봉쇄 확장**은 서로 다른 액티브에 투자하며, 최종 효과를 합성할 때 최대 1회 사용/대상별 내부 쿨타임 등을 검토한다.
- **과부하 지속**의 단일 대상 버프와 작은 범위 전파는 '기생술사'·'인형술사'의 제작/진화 및 군체술사의 증식 게임 루프를 복제하지 않는다.
- **강한 지배체의 장기 유지**는 정신력 최대치·회복량·개체별 소모·그룹 소모 전부 반영해야 한다. 랭크 총합을 높였다고 실제 유지 시간이 자동으로 적절해지는 것은 아니다.
- CC 연쇄에 대한 **저항 누적/CC 효과 감쇠**를 검토하되 보스 정지의 절대 불가 규칙을 신설하지 않는다.
- 모든 스킬 효과는 서버가 최종 판정. 외부 모드의 AI 스킬 발동을 강제·복제하기 위해 무리한 반사/핵심 AI 코드 침습을 기본 조건으로 삼지 않는다.

## 5. 스킬 트리 UI 및 투자 경험

- 랭크 270개를 **270개의 별도 버튼**으로 만들지 말고, **패시브 10개에 현재/최대 랭크와 돌파 눈금**을 표시한다.

## 1. 장비 효과는 두 가지만: 경계 내구 + 결계 공격 위력

| 매개체 등급 | 방어/격리 결계·순간 방벽 **경계 내구** | **압축 결계 피해** |
|---|---:|---:|
| 장비 없음 | +0% | +0% |
| **규격** | **+5%** | **+5%** |
| **변조** | **+10%** | **+10%** |
| **변칙** | **+15%** | **+15%** |
| **이형** | **+20%** | **+20%** |
| **불가해** | **+40%** | **+40%** |

- **5등급 중 장착한 최고 한 개만** 효과를 낸다. 현재 결계 종류별로 한 번만 적용; 등급별 장비 5개를 여러 개 챙겨 다니며 5/10/15/20/40%를 모두 합산하지 않는다.
- 장비가 **결계 반경·동시 배치 개수·지속시간·설치 거리·술식탄/기본 무기 데미지·개별 주문 쿨타임·압축 타격 횟수·격리 보스 면역 관통**을 추가로 강화하지 않는다. 이러한 조정은 기본 결계·패시브·실제 종별 보스 저항 계약에서 다룬다.
- 기초 방어/압축/격리 결계와 술식탄·순간 방벽·증폭 주문은 **매개체를 착용하지 않아도 사용 가능**. 등급 장비 때문에 클래스 자체가 사용 불가가 되지 않는다.
- 이미 설치된 결계에 장비를 착탈해 **내구 최대값을 늘리고 현재 HP를 즉시 풀로 채우는 무한 회복 악용** 방지. 장비 교체 시 이미 설치된 결계의 실시간 스탯 재계산 정책은 **현재 내구/최대 내구 비율 보존** 또는 설치 시 장비 스냅샷 중 하나를 서버 정본으로 선택(구현 전 결정 필요); 원칙은 무료 내구 회복·압축 타격 소급 재계산 금지.
- **장비 승급 시 소유 결계가 소멸하거나 쿨타임 초기화되지 않는다**. 마법사형 외형과 실전 스킬 위력은 연결하되 강제 마나/연료/스킬 슬롯을 추가하지 않는다.
- 레벨 무제한의 기본 성장/패시브/장비 보너스는 각기 1회만 적용. PvP·보스/외부 마법 저항·소유권을 무시하지 않는다.

## 2. 바닐라 재료 중심 5단계 제작·승급 예시

제작대 3×3 기준, **직전 단계의 매개체 하나를 재료로 사용**해 다음 단계로 승급하는 후보. 기본부터 신규 결계 제작대/마법가루 화폐/특성 도감을 필수로 만들지 않는다. 각 레시피는 9칸 이내 수량(아이템 슬롯 단위)으로 구현 가능한 예시이며 패턴은 실제 데이터 레시피 구현 때 결정.

| 제작 결과 | 필요한 직전 장비 | 추가 마인크래프트 재료 후보 | 총 입력 칸 |
|---|---|---|---:|
| **규격 결계 매개체** | 없음 | 구리 주괴×2, 유리×2, 자수정 조각×2, 레드스톤×1 | **7** |
| **변조 결계 매개체** | 규격×1 | 철 주괴×3, 청금석×2, 자수정 조각×2 | **8** |
| **변칙 결계 매개체** | 변조×1 | 금 주괴×2, 흑요석×2, 발광석 가루×2 | **7** |
| **이형 결계 매개체** | 변칙×1 | 다이아몬드×2, 엔더 진주×2, 메아리 조각×2 | **7** |
| **불가해 결계 매개체** | 이형×1 | 엔드 수정×1, 우는 흑요석×2, 자수정 블록×2, 프리즈머린 수정×2 | **8** |

- 최종 등급의 네더의 별/네더라이트 파편/메아리 조각 재료는 엔드게임까지 진입한 뒤의 고급 도전 후보이므로 **다른 직업 매개체 재료/목표 진행 속도와 반드시 비교**. 사용자가 특정 차원을 필수로 가고 싶지 않은 경우에는 별도 유효 대체 제작 경로를 만들 수 있으나 현재 다른 프로젝트의 요구를 가져와 강제하지 않는다.
- 승급 성공 시 직전 매개체는 **1개 소모**되고 새 등급 한 개만 생성. 재료 부족/패킷 중복/가방 이동/사망·클라이언트 렌더 중복 클릭으로 아이템 생성/복제 금지.
- 장비 등급은 아이템 정본 데이터로 인식. 다른 직업 장비를 착용하거나 같은 슬롯을 클라이언트에서 중복 표시해 버프 중복 적용 불가. 사용자 직업을 변경하더라도 인벤토리 아이템 자체는 사라지지 않고, 직업 매개체 슬롯에서는 해당 직업에 맞는 효과만 적용.
- 사용자가 Minecraft 일반 생존 채굴·건축/제작을 하면서 자연스럽게 재료를 얻는 경로가 중심. 매 전투마다 실/마법 재화를 소비해 결계 사용을 연장하는 유지비 구조 추가 금지.

## 3. 아이템 외형과 화면 표현

- **공통 실루엣**: 손바닥만 한 중심 핵 위에 2~3개의 기하학적 원형 링이 겹치는 **작은 술식 기구** 후보. 5등급에서도 기본 형태는 일관되고 소재·문양 밀도·움직임·소리로 격을 드러낸다.
- **평상시**: 매개체 슬롯에 장착돼 있어도 두 손을 항상 차지하지 않는다. 필요할 때 몸/허리/책 허리에 축약된 장식으로 표시하는 후보.
- **시전 순간**: 손짓과 시선 방향에 매개체/술식 링이 짧게 나타나고, 목표 좌표에 3차원 예고 경계가 펼쳐진다. **방어(견고한 둥근 면)/압축(안으로 조이는 수축 링)/격리(경계 접촉 시 충돌 파문)**은 서로 다르게 읽혀야 한다.
- **장비 툴팁**: `결계 경계 내구 +N%`, `압축 결계 피해 +N%` 두 줄만 우선. 존재하지 않는 '기생 성공률', '마나 자동회복', '공격 스킬 슬롯 증가' 등 옵션 금지.
- 최종 모델/텍스처/사운드/UI는 외부 검증된 아트 자산 레퍼런스와 Codex 시안 검수로 결정. Unity·Roblox·다른 모드 프로젝트의 UI 파일을 무단 혼합하지 않는다.

# 계약술사 제4위계 — 희귀 제물 최초 체결, 심화는 존재별 시련·재료·성취의 조합

> 2026-11-06 사용자 결정 확정. 사용자: "ㅇㅇ 그러자. 4위계 계약 심화는 퀘스트 같은 거 시련 위주가 좋겠네, 300개의 존재 죽이기나 보스급 목 따기나 업적이나. 근데 꼭 퀘스트 위주일 필요는 없음."
> **확정된 방향**과 아래 **미검증 개별 콘텐츠 예시**를 구분한다. 기획만 반영한 상태이며 코딩, 게임 플레이, 멀티플레이는 테스트하지 않았다.

## 1. 사용자 확정 기준

1. **제4위계 최초 계약 시의 희귀 제물**과 **이후 같은 계약의 심화**를 분리한다. 네더의 별·메아리 조각처럼 얻기 어려운 고급 재료를 최초 체결의 의미 있는 대가로 사용할 수 있지만, **같은 계약의 매 심화에서 같은 극희귀 재료를 반복 필수로 요구하지 않는다.** 제4위계 4개 존재의 정확한 최초 제물/수량/대체품은 기존 [3·4위계 기획](./PACT_TIER_3_4_DESIGN.md)의 **후보이며 최종 확정이 아니다**.
2. 제4위계 심화는 **퀘스트처럼 분명한 시련·성취·업적·강적/보스급 적 격파 등 실제 플레이로 해내는 목표를 중심**에 두되, **모든 심화를 퀘스트만으로 구성하지 않는다**. 일반/고급 재료 추가 봉납, 관계·서약 이행, 특수 의식, 전투·탐험/보호의 실제 증명도 존재별로 혼합한다.
3. 사용자 예시인 **'300개의 존재 처치', '보스급 목 따기', '업적 달성'은 가능한 시련의 종류**이며, **300마리 고정 전원 필수/보스급 처치 전원 필수/특정 업적 전원 필수**로 확정하지 않는다. 정량 목표, 보스 목록, 성취 조건, 심화 단계 수와 난도는 게임 밸런스·기존 플레이시간(혼합 서바이벌 Lv300 약30시간) 검증 후 결정한다.
4. 정기 **계약 유지비 없음**, 최초/다중 계약 체결에만 별도의 1·2·4·8배 제물 소프트캡 적용. 심화·위약금·금기 위반 대납·선택형 현현은 다른 사건이다. **심화 과제를 새 계약의 제물 배수로 무조건 곱하지 않는다**.
5. 심화의 보상은 기존 제4위계 각 존재의 능력 방향/고유 권능을 **실제로 발전**시켜야 한다. 허울뿐인 수치 +1%나 성취 보상 없는 반복 처치는 금지. 기본 계약의 평소 가호·전투 권능은 심화 완료 전에도 강력하고 사용 가능해야 한다.

## 2. 존재별 심화 설계 방향 — 확정 방향을 구현하기 위한 후보, 개별 조건 미확정

| --- | --- | --- | --- | --- |
| **나하르** — 흑성/인과 | 실제 위협에서 공격 사건을 기록하고 재현 | 서로 다른 강적의 **유효 공격을 분석해 승리**, 특수 유적 관측/전투 시련, 조건부 강적 격파 | 기록 의식·유적 단서·상대적으로 수급 가능한 기록/광물 소재. **메아리 조각 8개를 매 심화 재청구하지 않음** | 인과 기록 안정화→기록 선택·역습/광역 연계 |

| **오르마스** — 거인/대지 | 강대한 적에 맞선 직접 전투/방어 | **보스급 존재 1회 유효 격파** 또는 동급 거석 전투 시련, 산악 유적의 강적 극복 | 거석 의식·광물/광석 소재, 이미 체결에 쓴 네더라이트 고액 원가 그대로 재청구 금지 | 석질 생존·근접 위력 향상→대륙 분쇄/충격 연계 |
| **비아르** — 생명/원시림 | 생명 보호와 실전 생존 | 서로 다른 생물군계의 유효 생존 성취, 보호/복구 시련, 강적 전투 중 특정 생명 수호 | 희귀하지만 재생 가능한 생태 소재·의식/실제 탐험. 허위 번식·보호 농장 금지 | 재생/뿌리 제압 개선→공격과 방호/회복 연계 |

- **300마리 처치형**을 일부 전투 성향 존재에 넣는 것은 가능하지만, 모든 무해 생물을 무차별 처치하도록 권장하지 않는다. 적법한 적대/유효 위협·기여를 세고, 농장·소환물 자기 처치·스포너 제자리 사냥으로 수치만 올리는 것을 성장 핵심으로 삼지 않는다. 직접 막타 강요 없이 계약술사 본체/합법적 권능 기여를 인정한다.
- **보스급 처치형**은 외부 모드 1개의 특정 보스 또는 월드에 단 한 번만 등장하는 개체가 절대 필수가 되어 막히지 않게, 의미 있게 비교 가능한 고난도 상대/의식·시련 대안을 둔다. 같은 보스를 여러 번 죽이는 고정 반복 과제는 피한다.
- **업적형**은 Minecraft 발전 과제나 모드 자체의 사건/성취를 사용할 수 있지만, 기존에 이미 달성한 업적을 다시 수행하라는 요구로 만들지 않는다. 기록 데이터가 없으면 사전 안내, 대체 활동 또는 기존 발전 과제 검증으로 소프트락을 방지한다. 타 직업일 때 달성한 월드/계정 공통 성취와 해당 계약 뒤 수행할 별도 성취를 정확히 구분한다.
- 각 존재에 반드시 동일한 1차=300마리, 2차=보스 1마리 같은 공식 양식을 부여하지 않는다. 1~2차 심화는 기존 설계의 **기본 후보**이며 모든 존재의 최종 심화 횟수는 아직 미승인이다.

## 3. 실제 플레이와 구현 품질 경계

- 시련 진행상황은 **이미 존재하는 계약서/계약 관리 UI**에서 목표·현재량·달성/실패 이유·심화 후 기술 변화를 보여주는 쪽으로 설계한다. 무조건 새 퀘스트 재화·별도 일일퀘스트 메뉴·10개 체크박스·주기적 로그인 보상을 추가하지 않는다.
- 계약 체결/심화는 서버가 유효한 대상·출처·소유자·아군/PvP 관계와 성취 이벤트를 검증해 일회성 기록, 인벤토리 제물 **최종 확인 후 원자 소비**. UI 요청·더블클릭·서버 재시작/사망·직업 전환으로 업적/킬 카운터·심화·제물 복제 금지.
- 기본/심화 기술은 사용자에게 계속 쓸모가 있고, 4위계는 같은 역할의 1위계 최대 심화보다 확실한 주력 체급 우위를 지닌다. 추가 심화가 무한 장벽/희소재료 재파밍/너무 많은 관리 노동이 되어서는 안 된다.
- **아직 승인되지 않은 것:** 네더의 별/메아리 조각의 *정확한 최초 계약 제물 개수*, 상위 4개 존재의 최종 채택명·시련 세트·실제 300킬 수량·어떤 보스군/업적이 인정되는지, 심화별 구체 아이템·현현 사용 비용과 리스크·세부 보상 계수. 정식 레시피/연출/UI/게임 코드 미구현.
- 최초 계약의 재료는 해당 존재의 **새 계약을 맺을 때** 한 번 지불한다는 뜻이며, 다중 계약 슬롯 제물 배수와 해약 후 재체결의 기존 규칙을 폐기하는 **캐릭터 생애 1회 무료 권리**가 아니다.

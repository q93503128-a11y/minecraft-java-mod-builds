# 기생술사 — 인간형 의태·실숙주 기생·생체 데이터 성장 (v3 정본)

> **2026-11-04 / DIRECTION CONFIRMED, DETAILS PROPOSED.** 사용자 결정 방향은 **인간형 모습으로 자유롭게 활동 가능하되 미기생 상태는 매우 허약**, **실제 생물에 기생해 그 몸으로 살아간다**, **기생하며 생체 데이터를 얻어 영구적으로 강해진다**, **다른 종으로 옮겨가도 성장 유지**, **돼지 같은 약한 생물에서 시작 가능**, **생체 데이터가 부족하면 강한 생물에게 기생 불가**다. 아래 세부 메커니즘은 검토용 기획이며 아직 코딩·밸런스·플레이테스트로 검증하지 않았다.
>

## 1. 판타지·다른 직업과의 차이

**기생술사 = 평소에는 허약한 인간형 의태로 돌아다닐 수 있고, 살아 있는 숙주 한 몸 안에 들어가 그 종의 신체·이동·공격 방식을 직접 사용하면서 영구 생체 데이터를 성장시키는 직업.**

| 직업 | 소유하거나 제어하는 몸 | 플레이어의 실제 전투 |
|---|---|---|
| 정신 지배자 | 정신력을 지불해 여러 몬스터의 존재·행동을 유지·지휘 | 플레이어는 별도로 남고, 여러 지배체는 자동 AI |
| 인형술사 | 자원으로 만든 복수의 마리오네트 | 인형들이 자동 AI로 전투하고 플레이어는 표적 지시 |
| **기생술사** | **지금 들어가 있는 숙주 1기** | **플레이어가 숙주의 눈·이동·공격·능력을 직접 조작**; 숙주 밖에 별도의 자동 전투 부하를 생성하지 않음 |
| 군체술사 | 작은 생물 다수가 증식·소모 | 군체 자체의 숫자와 소모가 핵심 |

- 정신 지배자의 '동행/대기/집단 조종'과 달리 기생술사는 **한 번에 하나의 숙주 몸으로 플레이**한다. 강한 숙주는 확보하기 어려우나 원본 종의 움직임/능력·특성을 적극 활용한다.
- 기생체 레벨/생체 데이터는 숙주가 아니라 **플레이어 소유의 영구 저장 상태**에 붙는다. 숙주를 옮겨도 성장과 해금 기록이 유지된다. **생체 데이터는 소모하는 재화가 아닌 누적 성장형 스탯이며, 강한 숙주를 점유하기 위한 최소 자격 기준**도 된다.
- **[인간형 상태/생체 데이터/숙주 최소 요구치 상세 설계](./PARASITE_BIODATA_GROWTH.md)**가 현행 세부 정본이다. 인간형 기본 체력 8/공격 40% 후보, 숙주별 최소 BD, BD에 따른 HP·공격 성장 예시 등 구체 수치는 아직 밸런스 제안.
- 초반의 **돼지 플레이가 실제로 가능한** 방향을 정본으로 삼는다. 이후 계속 돼지로 성장하거나 좀비·거미·다른 종으로 갈아탈 수 있다. 특정 종으로 갈아타야 레벨이 오르는 숨은 강제가 있어선 안 된다.
- 가상 연출은 **마인크래프트 세계에 맞는 생체 이질감·몸 내부의 기생체 감각** 중심. 잔혹한 유혈·장기 적출 표현은 필수 시스템이 아니다.

## 2. 핵심 플레이 루프

**허약한 인간형으로 시작 → 가까운 생물(대표: 돼지)에 기생 → 숙주로 생존·채집·탐험·전투 → 영구 생체 데이터 축적 → 더 강한 숙주의 최소 BD 요구치를 충족 → 기생 시도·저항 판정 → 다른 종으로 이동해도 성장 유지 → 계속 성장.**

- 초기 단계는 무력한 돼지를 '한동안 조종해야 하는 벌칙'이 아니라 **기생체가 약한 몸으로 어떻게 살아남고 성장하는지 보여주는 입문 단계**. 돼지의 기동·방어·기생형 돌진 등 작은 장점을 줄 수 있다.
- **입문 숙주 제공 방식 후보:** 직업 선택 후 짧은 안전한 기간에 가까운 돼지를 찾게 하거나, 돼지가 드문 지형에서는 기본 입문 숙주를 접근 가능한 곳에 마련한다. 돼지 없으면 다른 동물도 진입 가능한 대체 경로. 첫 분 이내 소프트락/환경 RNG로 실패하지 않도록 설계.
- **재료 채집·제작/인벤토리 기본 Minecraft 생존은 계속 가능**해야 한다. 돼지·거미 등 손이 없는 숙주일 때 도구 사용·상자·작업대 상호작용을 완전히 막는 대신, 기생체가 짧게 **보조 촉수를 전개해 블록 채굴·제작·아이템 조작**한다는 연출/조작 후보. 플레이어의 실제 인벤토리는 숙주와 함께 사라지지 않고 공통으로 유지된다. 이 능력의 실제 범위는 플레이테스트로 조절한다.
- 돼지로 농사·건축·광산을 거쳐 성장할 수 있고, 이후 좀비의 근접 전투/거미의 벽 타기/가디언의 수중 공격 등 각 종의 특성 때문에 숙주 교체 자체가 새로운 플레이 선택이 된다.

## 3. 실제 기생의 흐름 — 획득/조종/탈출/교체

1. **접근·기생 시도:** 플레이어는 현재 숙주에서 새 대상에 기생을 시도하거나, **허약한 인간형**에서 기생한다. 우선 서버가 **현재 영구 생체 데이터(BD) ≥ 대상의 최소 요구 BD**인지 검사한다. 부족하면 **시도 자체가 불가능**하다. 요구치를 충족해야 실제 저항/성공 판정 단계에 들어갈 수 있다. 대상이 살아 있고 가까운지, 이미 점유 중인지, PvP/소유권 조건이 맞는지도 확인.
2. **기생 성공:** 대상의 **기존 월드 개체 ID를 유지**하며 실제 몹의 모델·히트박스·이동/공격 특징을 사용. 플레이어 카메라·입력은 현재 숙주 몸을 중심으로 작동. 해당 숙주의 자율 AI는 충돌하지 않도록 제어 상태로 전환하고, 원래 AI·팀·거래·장비·체력 등의 정보를 보존한다. 소유자 플레이어의 논리적 본체/인벤토리는 서버에서 단일 권위로 연결.
3. **생활·전투:** 새 숙주를 직접 조종하고 실제 자원 수급/탐험/적 처치로 생체 데이터 획득. 숙주의 종별 고유 이동/공격 능력은 지원되는 범위에서 직접 조작.
4. **이탈/다른 종 이전:** 준비된 조건의 새 대상에 기생을 시도한다. 기생이 성공한 후에만 이전 숙주의 제어를 해제하며, 원본 생물이 죽지 않았다면 원래 AI로 복귀. 실패했다면 현재 숙주를 즉시 잃지 않도록 한다. 숙주를 벗어나 기생체 상태로 나오는 수동 이탈은 지원 후보이며 전투 중 남발 악용을 검토.
5. **숙주 사망:** 기생체가 죽었다는 뜻과 구분. **허약한 인간형 상태로 긴급 이탈**하는 생존 기회를 주는 방향을 추천한다. 안전한 공간이 없거나 최종 사망 조건이면 정상 사망/리스폰. 영구 생체 데이터는 보존하고 죽음/아이템 손실은 서버 공통 규칙과 연결. **독립 벌레 엔티티를 중복 생성하지 않고, 무한 무적·즉시 자동 새 숙주/보스 육체 복제 금지**.

- **고정 숫자 미확정:** 기생 시도 성공 확률·이탈 시 재사용 대기·사망 후 탈출 창·미기생 기생체 HP/속도.
- **다른 플레이어는 현 단계 자동 기생 대상에 넣지 않는다.** 플레이어 조종권 빼앗기·채팅/인벤토리 탈취·PvP 제어권 충돌은 별도 사용자 의사와 보안 정책이 필요한 문제. 주민·다른 플레이어 소유 길들인 몹·마을 중요 몹과의 상호작용은 별도 권한 검사.
- **강한 보스·외부 모드 몬스터**는 난도가 매우 높을 수 있지만 생물 범주 자체라는 이유만으로 자동 영구 면역화하지 않는 검토 방향. 다만 무조건 성공하거나 원본 외부 모드 AI·보스 페이즈가 항상 플레이어 조종 가능한 것은 아님. 종별 제어·특수공격 어댑터 구현 상태를 표시.

## 4. 공용 생체 데이터 + 종별 생체 데이터 — 숙주 이전에도 성장 보존

**모든 기생 활동의 보상은 '숙주가 아닌 기생체 플레이어'에게 귀속.**

| 성장 단위 | 저장 주체 | 얻는 활동 | 의미 |
|---|---|---|---|
| **공용 생체 데이터** | 플레이어 기생체 | 숙주 상태에서 일반 생존/전투/탐험 등 **실제 유효 행동** | 모든 숙주에 적용되는 지속적인 최대 HP·공격·기생 안정성 성장(공용 레벨 및 패시브와 중복 적용 검증) |
| **종별 숙련 데이터** | 플레이어 × EntityType | 그 종에서 실제로 이동·활동·능력 사용·전투 | 예: 돼지 기생 숙련, 거미 기생 숙련. 해당 종의 고유 기능을 더 잘 쓰도록 강화 |
| **종 최초 획득 기록** | 플레이어 | 그 종의 숙주로 실제 일정 시간 활동/기본 목표 달성 | 처음 다른 종을 시도했을 때 선택지가 열리는 보상. 다른 종을 반드시 수집해야 기생체 레벨이 오르는 것은 아님 |

- 공용 경험치/직업 스킬포인트는 기존 프로젝트에서 제공하는 방향 그대로 유지. 생체 데이터를 **거대한 별도 통화·수집용 아이템**으로 만들지 말고 서버 내 성장 지표로 구현. 표시는 간단히 공용 기생 숙련도와 현재 숙주/종별 진행도로 통합하는 것이 좋다.
- **AFK 수급 금지**: 서 있기만 해도 틱당 영구 데이터가 오르면 돼지 우리/몹 감금으로 무한 성장한다. **실제 이동·유효 채광·전투 기여·탐험·생존 목표/위험 처리 등**으로 보상하고 동일 행동·동일 개체의 비정상 반복은 획득량이 빠르게 감소하도록 한다.
- 특정 종 1개(돼지)를 끝까지 육성해도 장기 성장 경로가 열려 있어야 한다. 다른 종 사용은 **다른 신체 기믹과 새 숙주 가능성/숙련**을 제공해 자연스럽게 유도하고, 억지로 100종 수집하기 전에는 강한 보스에게 기생할 수 없도록 고정하지 않는다.
- **유효 신체 능력 = 현재 숙주의 원본 생체 능력 × 기생체의 공통 성장 × 이 숙주 종별 숙련 × 유효 능력/장비 보정**이라는 구성 원칙. 수치·곱 순서 미확정; 저체력 돼지가 고레벨에도 무의미해지지 않되, 처음 기생한 워든도 아무 제약 없이 최종 능력을 모두 사용하는 상황은 피한다.
- **기생 자격은 생체 데이터 최소치에 의해 우선 결정된다.** `currentBD < requiredBD(target)`이면 시도 불가. 요구치는 대상 **원래 종별 위협도·기초 능력과 보스 특성**을 기준으로 하며 현재 HP를 1로 만들었다고 최소 요구 BD가 낮아지지 않는다. BD 요건 달성 후에만 대상의 저항·현재 상태·기생 숙련에 따른 실제 성공 판정을 수행한다. 자세한 규칙과 임시 값은 [PARASITE_BIODATA_GROWTH.md](./PARASITE_BIODATA_GROWTH.md)에 기록. 지원하지 않는 외부 보스의 미구현 조작은 성공이라고 표시하지 않는다.
- 타 종으로 옮겨도 **공용 데이터/모든 종별 숙련 기록·스킬 트리·아이템/경험치/직업 레벨**이 사라지지 않는다. 돼지→좀비→거미→돼지로 돌아왔을 때 이전 돼지 숙련도도 살아 있어야 한다.

## 5. 숙주 종류별 초기 플레이 예시 (콘텐츠 후보)

| 숙주 | 기생 직후 경험 | 성장한 기생체가 활용할 장점 | 초기 대가/위험 |
|---|---|---|---|
| 돼지 | 기본 생존·빠른 도주·보조 촉수로 일반 생존 조작 | 장기적으로 높은 기본 체력/돌진/생존력을 추가 육성 가능 | 기본 공격 빈약, 몹과 정면 전투 위험 |
| 소/양 | 지상 생존·지속 전투/이동 | 큰 체격의 밀치기·방어적 선택 | 빠른 추격/기동 불리 |
| 닭 | 높이 차·낙하 대응과 탐색 | 작은 몸체/낙하 제어의 가치 | 낮은 내구력·타격 |
| 좀비 | 기본 근접 전투 | 기생체 성장과 결합한 전면 압박 | 햇빛 연소·지상 탐험 위험 |

## 6. 스킬/장비/과거 제안의 처리

- **기생(숙주 침투)**, **숙주 해제/전환**, **숙주의 기본 이동·공격**은 직업의 필수 기본 행동. 모든 생물을 새로운 액티브 버튼 하나씩으로 나누지 않는다.
- 직업 액티브는 숙주의 고유 능력 + 기생체 자체 능력 중 **최소 필수 조작**으로 설계. 예시 후보:
  - **침투 강화:** 강력 숙주 기생 시도에 짧은 집중/적법 판정을 보정(미확정).
  - **생체 과부하:** 현재 숙주 한 몸의 능력치를 단시간 강화(정신 지배자의 과부하와 역할 겹침 검증 필요).
  - **숙주 탈피:** 안전하게 현재 몸에서 빠져나오거나 아주 짧게 위기 탈출하는 기능(마나/무적 연타 방지).
  - **종 고유 능력:** 돼지 돌진/거미 벽 타기/좀비 강타/가디언 광선 등 실제 숙주의 행동을 맵핑. 원래 몬스터별 기초 공격을 복사한 별도 '만능 버튼'으로 만들지 않는다.
- 이전 1차안의 **공격·기동·방호 3기관 슬롯, 기생 부하 0~100, 4종 액티브(기생 침식/변이 분출/탈피/자가 재생)**는 현재 정본 **필수 시스템에서 제외하고 보류**. 실제 숙주 교체/직접 조작 경험을 먼저 검증한 뒤 도움이 되는 일부만 재설계할 수 있다.

## 7. 삶의 주체, 저장·사망·멀티플레이

- 숙주는 바닐라/외부 모드에서 **원래 존재하던 월드 엔티티 1기**를 사용. 같은 생물을 '기생 숙주'와 원본 몬스터로 중복 생성하거나 정상 AI·체력·드롭을 임의 지우지 않는다.

# 군체술사 — 공격대·엄호대 동시 운용, 투사체 실피격, 시야 보전 (4차)

> 2026-11-05 / **DESIGN ONLY · USER DIRECTION + UNAPPROVED DETAIL.** [군체술사 기본](./SWARM_CASTER.md) / [3차 실피격·자연 증식](./SWARM_COMBAT_GROWTH_V3.md) / [공통 우호 판정](../ALLY_RELATIONS.md) / [직업 매개체 슬롯](../CLASS_FOCUS_SLOT.md). 두 상세 미진행 직업 **중력술사·공명술사는 보류 유지**.

## 1. 이번 사용자 방향 (정본 우선)

- **군체 규모가 커지면** 군체를 **공격대와 엄호대**로 나누어 **급습과 엄호를 동시에 수행**할 수 있어야 함. 한 직업이 100마리를 독립 컨트롤하도록 만드는 것은 금지. 공격대가 표적을 공격하는 동안 엄호대는 시전자를 보호.
- **시야를 가리면 안 됨**: 1인칭·3인칭 조준점 및 카메라/바닐라 채굴·건축·전투를 침범하지 않아야 함. 큰 군단일수록 모델/이펙트가 화면을 가득 덮을 위험을 검증.
- **투사체를 대신 맞아 군체가 죽을 수 있음**: 화살 등 진짜 적의 원거리 공격을 군체가 실제로 가로막으면 개체 손실 발생. 장식용 파티클 대신 실피해/군체 수량/사망 연출 연결.
- **기본 원격 표적 지정**, 수량의 전투 자원성·자연 증식, 개체의 공동 공격/생존 성장, 수량 +N 버튼 스킬 지양은 보존.
- 이번 문서의 **분리 시작 개체수 24, 기본 공격/엄호 비율 75:25, 스킬 지속시간·쿨타임·물리 proxy 구현 선택**은 **새로운 권장 시험안**, 이번 사용자 발언만으로 확정되지 않음.

## 2. 플레이 화면에서 일어나는 일

1. 플레이어 곁에 작은 생물들이 따라다니다가 적을 **원격 표적 지정**하면 **공격대**가 실제로 목표까지 이동해 포위·기본 공격/군집 급습을 수행한다.
2. 군체가 충분히 많으면 일부는 **엄호대**로 남아 플레이어 주변 측면·하단을 따라다니고 적의 접근/화살에 반응. 공격대는 계속 원격 전투. 별도 작은 생물마다 타깃 지정·초당 수동 배치 필요 없음.
3. **군집 엄호 액티브(후보)**를 쓰면 짧은 시간 엄호대가 더 넓은 각도로 방어하고 공격대 일부가 지원할 수 있지만, **군단이 충분하면 남은 공격대는 공격/급습을 계속함**. 군체 전체를 강제로 플레이어 발앞에 고정하지 않는다.
4. 적이 엄호대를 때리면 **실제 논리 개체 수가 감소**해 화면에 생물 사망/튕김/흩어짐이 나타나고, 방어가 약해짐. 기본 자연 증식으로 시간이 흐르면 회복; 수량 충전 버튼 없음.
5. 군체가 크게 손실되면 서버는 **기본 생존/재집결 모드**로 돌아가며, 완전히 무력화되지 않지만 엄호 또는 공격을 동시에 충분히 수행하지 못할 수 있음. 저수량의 자동 우선순위/보호 행동은 실전 테스트 후 조정.

## 3. 한 가지 수량 N을 두 역할이 나누어 사용

**수량 불변 조건:** `totalAlive = attackCount + guardCount + regroupCount`; 어떤 논리 개체도 동시에 공격수와 방어수 2명으로 계산되지 않는다. `totalAlive ≤ maxCount`.

| 상태 | 행동 | 수량 예시(시험) |
|---|---|---|
| 낮은 군체수(예: N < 24) | 평소에는 한 무리가 공격, 엄호 사용 중이면 일부 방어로 전환. 저수량에도 급습·방어 스킬 사용 가능하나 고효율 동시 수행은 제한 | N=16, 필요 시 공격 10/엄호 6처럼 선택적 분할도 가능. **한쪽을 무조건 0으로 만들지 않는 것을 우선 검토** |
| 충분히 성장한 군체(예: N ≥ 24) | 기본 **공격대 + 엄호대 자동 분할**. 사용자는 원격 표적만 지정하면 나머지 자동 행동 | N=80: 공격 60 / 엄호 20 |
| `군집 엄호` 활성 중 | 공격대 일부가 잠시 엄호대에 합류해 방어 효과 강화하되 공격대가 남으면 원거리 급습 계속 | N=80: 공격 40 / 엄호 40 후보 |
| 적 공격으로 엄호대 손실 | `totalAlive` 실제 감소. 잠시 공격대를 엄호에 재배치할 수 있지만 **즉시 무한 재할당으로 무료 피해 흡수 금지** | N=80→74: 재분배 대기/우선순위 조건 후 변경 |
| `군체 소모` 사용 | **공격대에서만** 수량 비용 우선 차감, 주인 보호를 위한 마지막 엄호대까지 자동으로 희생하지 않음 | 공격대 60에서 일부 소모, 엄호대20 그대로 |

- 실제 역할 비율은 별도 항상 켜진 슬라이더/세부 편성·관리 화면을 만들지 않고 **규칙 기반 자동 배분**. 사용자의 수동 정밀 조작은 원격 표적 지정·급습·필요 시 엄호 액티브 정도.
- 저수량에서는 버프가 완전히 꺼져 실전에서 재미없어지지 않게, 기본 방어 반응 또는 스킬 사용 시 유한한 교대/부분 엄호 가능. 정확한 발동 임계값은 시험.
- 분리는 독립적으로 성장/제작한 **두 종류의 생물**을 요구하지 않음. **하나의 군체**가 여러 위치에서 역할만 수행.
- 공격대와 엄호대는 서로 다른 **실제 세계 좌표와 유효 피격 가능 범위**를 가져야 한다. 서버 논리·멀티는 단일 소유자 군체 데이터에 각 역할의 중심/손실을 기록; 시각 개체는 위치를 따라가며 그 수량의 생물을 표현.
- `군체 소모`로 공격대를 다 쓰면 엄호대가 남더라도 자동 공격 화력은 낮아진다. 수량을 소비할지 안전하게 남길지 **실제 선택**이 되게 함.
- 소모와 적의 광역 공격이 같은 tick에 오면 서버의 **단일 권위 수량 변경/중복 데미지 방지** 로직이 각 수량을 한 번만 소비하게 할 것.

## 4. 적의 원거리 공격을 대신 맞아 죽는 시스템

### 4.1 플레이 경험

- 스켈레톤의 **화살**이 플레이어에게 향할 때 엄호대가 실제 탄도에 있는 보호 위치를 차지하면 화살이 군체를 맞힌다. 그만큼 군체 숫자/방어 내구가 줄어들고, 피격된 생물이 떨어져 사라지며 작은 타격 효과가 들림.
- **방패처럼 언제든 100% 차단되는 무형 장막은 아님**. 공격 궤적과 엄호대의 위치/반응 시간·현재 숫자/공동 생존력에 따라 뚫릴 수 있음. 엄호대를 갉아먹는 화살과 주인을 노리는 적의 공격이 동시에 들어올 수 있음.
- **근접**: 엄호대가 실제로 지키는 쪽에서 적에게 맞으면 수량 감소. **광역**: 실제 영향 범위·속성에 따라 여러 생물을 잃을 수 있음.
- **삼지창/화살**과 같은 단일 탄체는 첫 유효 교차 대상으로 소멸/충돌 처리하며 **한 발이 동일 엄호대와 플레이어에게 이중 피해**를 입히지 않음. 예외 탄체의 관통/반사/회수는 종류별 처리.
- **화염구/폭발·구름형 투사체**는 투사체를 가로챌 때 폭발/광역 효과를 지우는 무상 전체 취소가 아니라 **폭발 원점과 범위를 실제로 계산**, 플레이어가 폭발 안에 있으면 피해 받을 수 있음.
- **레이저/파동/마법 장판 등 비표준 외부 공격**은 연속 광선/지역 판정이 다르므로 지원 가능한 어댑터에서만 엄호 적용. 못 하는 것을 100% 보호라고 설명하지 않음.

### 4.2 기술 실현성 경계

- 바닐라 일반 투사체는 이동구간 `raycast`로 **블록/엔티티 중 가까운 첫 교차**를 결정. 따라서 추천 구현은 **실제 존재하는 소수의 유효 엄호 충돌 체적/피격 proxy** 또는 해당 투사체 hit 검사에 대한 서버 측 간섭을 목표 버전/로더의 API와 충돌하지 않게 설계. **큰 보이지 않는 플레이어 전체 무적 판정 구체를 만들지 말 것**. 참고: https://minecraft.wiki/w/Thrown , https://docs.fabricmc.net/develop/entities/projectiles (후자는 Fabric 문서일 뿐 로더 고정 의미 X).
- 엄호가 **화살 발사 후 뒤늦게 시간 역행하여 즉시 순간이동**한 것으로 보이지 않게, 플레이어 주변 전·측면에 시각 군체가 먼저 분포해 있고 공격 접근 시 작은 반응 애니메이션/이동만 추가. 인터셉트 범위와 실제 서버 collision이 시각적으로 일치해야 함.
- 투사체에 유효 충돌하면 서버에서 `projectileId/impactId`에 대한 보호 처리 1회, 군체 유효피해 1회, 플레이어의 동일 피격 사건 여부/방패·토템/다른 피해 변환을 중복 적용하지 않음.
- 타 플레이어가 발사한 화살과 본인/동료 투사체는 **공용 소유권·팀·PvP 권한**으로 분리. **본인·아군이 발사한 화살을 소모 없이 엄호가 흡수하여 건축/활/쇠뇌를 방해하는 일이 없어야 함**.
- 엄호 군단이 모든 몹을 강제로 도발해 플레이어가 영구 무적되는 문제는 방지. 적 타깃 선택은 각 AI의 동작과 소환물 공격 가능/불가를 존중하며, 엄호가 실제로 닿는 피해만 차감. 몹의 공격 타깃 어댑터와 피격 proxy 적법성은 **런타임 테스트 전 미확정**.
- 성공한 보호의 숫자/위치/방어 개체 소실을 클라이언트에 정확히 동기화. 끊임없는 projectile 전체 엔티티 스캔이 아니라 **근접·활성 군체 주변의 실제 투사체 이동/피격 사건 기반 처리**.

## 5. 시야와 기본 플레이 보존

- **카메라 앞 조준점 중심에는 큰 생물 모델/날개/표시/반투명 검은 막을 두지 않는다.** 평시 엄호대는 플레이어 **옆·발치·하단 및 카메라 뒤**를 중심으로 움직인다.
- 화면 중간(특히 1인칭)에서 이동/채굴/검 조준/활 궤적이 보이게 중앙 시선용 **방해 최소 영역**을 유지. 위험한 투사체가 올 때만 일부가 전면으로 짧게 움직일 수 있으며, 그 순간에도 작은 모델과 분산·낮은 불투명도/이펙트를 활용해 과도한 가림을 억제.
- **카메라 클리핑/3인칭 거리/3인칭 어깨 시점/수중 시야/웅크림/좁은 동굴/엘리트라** 상태에서 생물이 거대한 화면 장애물이 되지 않도록 근접 생물 **클라이언트의 로컬 표시 축소/페이드/모델 수 제한**. **렌더링 페이드가 서버 충돌 상호작용과 다른 의미의 무적을 만들어선 안 됨**.
- 공격대가 원거리 표적까지 이동 중에는 몸을 항상 사용자의 바로 앞에 두지 않는다. 충돌체들이 사용자 캐릭터 이동/자신의 화살 발사를 막지 않고, 공용 매개체 슬롯 덕분에 양손 자유 유지.
- HUD는 **군체 현재/최대수량 하나 + 작은 엄호 상태/목표 표식 정도**, 무리 편성 숫자/광역 카드를 항상 표시하지 않음. 장비/스킬 상세에서 공격·엄호 효과 확인 가능.

## 6. 이번 요청과 연결되는 새 스킬 트리/5등급 매개체

- [스킬 트리 1차](./SWARM_SKILL_TREE.md): 공격 성능·엄호 개체 생존력/탄도 피격·자연 증식·원격 표적 편의의 **단일 군단에 적용되는 공통 패시브**. 별도 엄호대/공격대 영구 개체 육성 없음. **동시 분리 자체는 레벨/수량 충족 시 기본 가능**하며 반드시 고급 패시브를 찍어야만 해금하는 장벽이 아님.
- [군체 핵 5등급](./SWARM_FOCUS.md): 공통 직업 매개체 슬롯 1개에 장착. **군단의 직접 공격력·개체 내구** 두 가지 강화 중심, 최대 마릿수/분리 가능 여부/원격 표적 거리/시야 문제를 장비 보너스로 해결하지 않음. 기본 능력은 무장비에서도 정상 사용.
- 군집 엄호 자체는 **특별한 타이밍에 희생과 방어를 강화하는 스킬**이며, 군체가 성장했을 때 공격대/엄호대가 나누어 행동하는 **기본 AI 상태**를 대체하지 않음.

## 6.1 5차 비행 확장 (2026-11-05)

이 문서의 공격대+엄호대 **2역할 배분은 지상 기본 상태**이다. 사용자 비행 아이디어의 후속 [**군체 비행/전투 밸런스 5차**](./SWARM_FLIGHT_AND_COMBAT_BALANCE_V5.md)에서는 **공격대+엄호대+비행대(+재결집)**로 확대. 역할 총합은 실제 N과 같으며 두 역할에 동일 개체를 중복 집계하지 않는다.

- 비행 중에도 실제 원격 공격과 화살 방어가 가능하지만 **날기 위해 배정한 개체는 공격/엄호 화력에 동시에 집계하지 않는다**. 사용자가 비행 중 공격 스킬을 사용했다는 이유로 운반군을 자동 희생시키지 않는 게 기본 추천.
- 엄호군과 운반군 모두 적의 화살·유효 피해를 받고 사망할 수 있다. 군체 부족 시 **안전한 감속 하강** 후보를 마련하고, 공중 무적/임의 개체 즉시 충전 금지.
- 엄호/비행 군단을 플레이어 발밑과 옆에 위치시켜 **조준점·1인칭 시야·건축/채굴/활 공격을 보존**. 구체 분담 비율·비행 해금/속도는 유효 실전 테스트 전 미정.
- [스킬 트리](./SWARM_SKILL_TREE.md)의 9노드·270랭크, [5등급 군체 핵](./SWARM_FOCUS.md)의 두 스탯은 확대하지 않고 재사용하는 방향.

## 6.2 6차 최신 조작 요청 — 빠른 편성

사용자는 전투 중 즉시 바꿀 수 있는 **군체 관리 단축키+빠른 설정**을 추가 요청했다. [관리 패널·전술 퀵 휠 상세](./SWARM_COMMAND_PANEL_AND_QUICK_SETTINGS_V6.md) 참고.

- 이전 '항상 켜진 슬라이더/편성 관리 요구하지 않음'은 **기본 자동 배분/빠른 프리셋을 추천**한다는 의미로 유지하되, **선택적인 사용자 공격:엄호 비중 조절을 관리창에 허용**한다. 수동 설정은 필수 아님.
- 빠른 전술 변경은 서버의 목표 배분을 즉시 바꾸지만 **공격대가 실제 위치/거리/경로에 따른 재배치 시간 없이 플레이어에게 순간이동해 무료 방어하는 현상**은 허용하지 않는다.
- 비행 상태에서는 안전한 운반 역할 최소분을 먼저 확보하고 나머지를 공격/엄호에 배분. 전술을 바꾸는 것 자체는 비행 모드 On/Off나 급속 증식 스킬이 아니다.

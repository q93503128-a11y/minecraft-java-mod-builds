# 인형술사 — 재료 수급·제작·강화·분해 경제 설계 1차

> Status: **DESIGN PROPOSAL / USER REVIEW PENDING / NOT IMPLEMENTED.** 2026-11-04. 사용자가 정한 핵심 방향: 인형술사의 플레이는 **재료 수급과 인형 제작·강화·분해**를 중요하게 다루며, 마리오네트 조종틀의 실로 인형을 연결해 자동 운용한다. 본 문서의 **재료 개수, 세부 제작식, 강화·분해 반환율과 골격별 수치**는 사용자가 승인한 확정값이 아닌 검토용 초안이다.

## 1. 목적과 경계

- 바닐라 생존의 **벌목·광질·탐험·전투**가 인형의 부품·성능 발전으로 직접 이어져야 한다.
- 시작 인형은 오버월드 자원으로 제작 가능해야 한다. 첫 인형을 만들기 위해 보스나 특정 차원 진입을 강제하지 않는다.
- 자원을 모으는 이유는 **구체적인 새로운 전투 선택**(예: 중장 방어형/경량 근접형/투사형)을 얻기 위함이다. 서로 다른 새 화폐·제작대·무의미한 중간 합성 단계를 늘리지 않는다.
- 부품으로 제작한 **실 연결형 마리오네트**는 정신 지배자의 야생 몹 장악과 다르다. 후반 3기 초과 동시 운용을 원하지만, 군체술사의 무제한 증식과는 구별한다.
- 바닐라 자원의 기본 획득처는 실제 Minecraft 버전이 선정될 때 확인한다. 아래 외부 모드 및 Minecraft 위키를 원칙/재료 확인에 참고하되, 지원 버전이나 외부 모드 의존성을 고정하지 않는다.
- 기존 전용 플레이어 장비는 십자형 조종틀 **한 계열, 규격→변조→변칙→이형→불가해 5등급**을 유지한다. 인형 부품의 소재/역할 단계는 **직업 장비 등급과 별개**이며, 인형용 공식 5등급 시스템을 추가했다고 간주하지 않는다.

- [Modular Golems](https://modrinth.com/mod/modular-golems): 금속 부품별 성능이 달라지고 업그레이드 슬롯으로 능력을 바꾸는 구성. **소재가 역할과 연결되는 설계**만 참고한다. 해당 모드의 코드·아이템·자산은 무단 복사하지 않는다.
- [Tinkers' Construct 스타일 부품 설계 (독립 Bedrock 위키의 예)](https://tinkersbedrock.wiki.gg/wiki/Tools): 제작 재료→부품→완성 도구의 구조. 단, 용해로/주조틀 등 복잡한 제조 인프라는 이 직업에 들여오지 않는다.
- [Minecraft Wiki String](https://minecraft.wiki/w/Tripwire): 실은 재생 가능한 바닐라 재료로 거미 등을 통해 얻는다. 실은 **조립에 쓰는 재료**이지, 인형을 운용하는 동안 지속 소비하는 유지 연료가 아니다.
- [Minecraft Wiki Cobweb](https://minecraft.wiki/w/Cobweb): 거미줄 등 구조물 탐험으로도 실의 획득 경로를 마련할 수 있다. 새 Minecraft 버전에서 정확한 아이템 획득 방식은 구현 전 다시 검증한다.
- **인형 재료 회수는 이 게임의 자체 설계안**이며, 외부 모드가 동일한 확률/공식을 쓴다는 의미가 아니다.

## 3. 재료 수급 루트 (소재 수 = 별도 재화 수가 아님)

| 단계 | 주요 자원 | 기본 획득 활동 | 인형에 반영되는 선택 |
|---|---|---|---|
| 첫 인형 | 판자·막대기·실·구리·소량 철/레드스톤 | 벌목, 거미 전투, 초기 동굴 탐험 | 경량 골격/초급 무장/기본 구동핵 |
| 초중반 | 철·부싯돌·레드스톤·가죽·돌 | 동굴·밤 전투·채집 | 중장/균형 골격, 방패·투사형, 기본 강화 |
| 중반 | 슬라임볼·금·청금석·자수정 | 늪/동굴/자수정 정동/광질 등 | 관절 충격 흡수, 안정·출력형 핵, 특수 반응 |
| 후반 | 다이아몬드·흑요석·네더 석영 등 | 깊은 채광, 선택적 차원 탐험 | 고강도 부품, 원거리 특수 동작, 보스 대응 |
| 최상위 선택 강화 | 희귀 탐험 보상/보스 전리품 | 강한 지역·보스 | 기존 인형의 특수 행동 개선, 강제 필수 재료로 만들지 않을 후보 |

- 자원군별 **최소 2개의 실용 획득 경로**를 검토한다(광물/전리품/거래/재활용 등). 특정 생물군계가 없는 월드, 하드 모드, 멀티플레이에서 진행이 막히지 않도록 한다.
- 모든 부품이 매번 네더·엔더·고대 도시에서 재료를 요구하지 않게 한다. 탐험으로 얻는 고급 선택지와 기본 성장 경로를 구분한다.
- 외부 모드 적 처치/구조물에서 재료를 얻는 콘텐츠를 추가하더라도, 실제 설치된 외부 모드가 없을 때 기본 성장 루프가 중단되어서는 안 된다.
- **전투에서 자동으로 재료가 무한 생성되는 방식은 피한다.** 평범한 바닐라 전리품과 직접 수급을 기본으로 하고, 선택적 드롭 보정은 서버 성능·경제 시뮬레이션 후 결정한다.

## 4. 부품 3종과 재질 특성 (역할을 잠그는 '강제 티어'가 아님)

| 구성 | 선택 예시 | 전투상 실질 역할 | 외형·애니메이션 변화 |
|---|---|---|---|
| 골격 | 경량 | 낮은 HP 대신 빠른 접근, 회피/짧은 돌격 | 가는 팔다리, 빠른 관절 전환 |
| 골격 | 균형 | 범용 HP·속도·안정적인 공방 | 중간 실루엣, 전투 장치 강조 |
| 골격 | 중장 | 높은 HP·넉백 저항, 느린 이동 | 두꺼운 관절·중량 타격 |
| 행동 장치 | 칼날 | 가까운 거리에서 지속 압박 | 팔/칼날 관절의 절단·찌르기 모션 |
| 행동 장치 | 투사기 | 거리를 두고 원거리 견제 | 팔에서 사출/장전 모션, 투사체 판정 |
| 행동 장치 | 방패 | 주인/동료 앞에서 막고 반격 | 실제 막는 위치와 피격 판정 정합 |
| 구동핵 | 신속 | 이동·표적 반응 우선 | 끊어 당기는 빠른 조종 실 연출 |
| 구동핵 | 안정 | 방어·자세/연결 보호 우선 | 관절 흔들림 감소, 중심 유지 |
| 구동핵 | 출력 | 순간 화력 우선, 방어/효율에 대가 | 실의 강한 장력, 큰 타격 반동 |

예시 프로필: `경량+칼날+신속`=추격형, `중장+방패+안정`=주인 보호형, `균형+투사기+출력`=후열 화력형. 27종을 27개의 독립 모델/AI로 만들지 않고 기본 골격 모델+부품 표시+공유 애니메이션 변형으로 재사용한다.

### 소재와 역할의 관계

- 경량 골격도 금속을 보강할 수 있고, 중장 골격도 관절을 개선할 수 있다. 목재→철→다이아몬드가 모두 동일한 공격력을 더하는 **단일 수직 상위 티어만**이 되지 않도록 구성한다.
- 구리 = 반응 관절/연결점, 철 = 구조 강도·방호, 슬라임 = 충격 흡수, 금/레드스톤 = 빠른 구동, 청금석·자수정 = 안정/정밀 제어, 다이아몬드 = 고강도 고가 보강이라는 **자체 설계 역할**을 부여한다(바닐라 아이템 고유 효과라는 의미 아님).
- 소재별 속성·공격 보정 수치는 **기본 인형/외부 적 전투 검수 전 미확정**이다. 원거리 무장이 자동 공격하도록 설계하되 기본 사격에 화살을 매 발 소비하도록 강제하지 않는다(전개 후 다수 인형의 탄약 보급 노동 방지).

## 5. 초기 실제 제작 레시피 초안 (개수는 미확정)

### 첫 인형 = 3부품 + 연결용 실

각 부품은 일반 3×3 작업대에서 제작하고, 완성 인형은 **부품 3종 + 실×2**를 묶어 조립한다(다른 별도 인형 제작대 설치 요구를 기본 규칙으로 만들지 않는다).

| 제작 항목 | 제안 재료 (각 입력 합계는 9슬롯 이하) | 결과 |
|---|---|---|
| 초급 경량 골격 | 목재 판자×4, 막대기×2, 실×2, 구리 주괴×1 | 경량 골격 1 |
| 초급 칼날 장치 | 철 조각×4, 막대기×2, 부싯돌×1 | 칼날 장치 1 |
| 기본 구동핵 | 레드스톤 가루×1, 구리 주괴×2, 유리×1 | 기본 구동핵 1 (기본 전투 운용; 고급 구동핵 방향 선택 전) |
| 조립 | 골격×1, 행동 장치×1, 구동핵×1, 실×2 | 완성 마리오네트 1 |

첫 인형의 **최초 원재료 합계**: 판자×4 + 막대기×4 + 실×4 + 구리 주괴×3 + 철 조각×4 + 부싯돌×1 + 레드스톤×1 + 유리×1. 다양한 원재료가 필요하나 모두 오버월드 경로로 수급 가능. 실제 플레이에서 첫 인형까지 시간이 너무 길면 전투/동굴 루프에 맞춰 수량을 줄인다.

- 위 표는 **shapeless/recipe JSON로 실제 바로 구현 가능함을 검증한 최종 레시피는 아니다**. 부품 NBT/Data Components, 장착·성장 상태를 보존하려면 아이템 조립 방식과 저장 스키마를 별도 설계해야 한다.
- 초기 기본 구동핵 1종과 후속 `신속/안정/출력`의 **세 갈래 상위 구동핵**을 구분해, 첫 인형에 3종 고급 핵 제작을 강제하지 않는다. 27개 특화 조합 및 기본 스탯/동작의 별도 계산은 [PUPPET_COMBAT_MATRIX.md](./PUPPET_COMBAT_MATRIX.md)를 참고한다. 기본 구동핵은 특화 전 중립 상태이므로 27조합의 3핵 계산에는 포함하지 않는다.
- 구리·실 수급에 동굴 운과 야간 스폰 운이 과도하게 작용하지 않는지 검수. 실 수급 대안은 거미줄·기존 바닐라 전리품 활용.

## 6. 중후반 강화를 위한 제작 방식

기존 제작 3부품을 전부 버리고 새 인형을 만드는 대신, **같은 마리오네트 개체 ID의 부품을 교체/강화**한다.

| 강화 방향 | 재료 사용 예시 | 얻는 행동 변화 |
|---|---|---|
| 골격 보강 | 기존 골격 + 철/다이아몬드 | 특정 공격/넉백 저항과 HP 증가, 중량에 따른 이동 대가 |
| 관절 유연화 | 기존 골격 + 구리/슬라임볼 | 회피/회전/낙하 충격 완화 |
| 공격 모듈 변경 | 칼날 장치 ↔ 투사기 ↔ 방패 장치 | 기본 공격 패턴과 위치 선정 자체가 변경 |
| 구동핵 특화 | 기본 핵 + 레드스톤·금 / 청금석·자수정 등 | 신속/안정/출력 중 선택, 각각 장단점 |
| 특수 대응 강화 | 기존 부품 + 어려운 지역 희귀 자원 | 충격 흡수/일시적인 보호막/관통 등, 전투에 필요성 입증 후 |

- 부품을 **교체**하면 이전 부품이 그대로 돌아와 보관/다른 인형에 재사용 가능(손상 상태 보존). 이 행위는 '부품을 재료로 파괴'하는 것과 다른 작업이며, 무료 자원 복제 루트가 아니다.
- 이미 만들어진 인형은 강화 과정에서 **정체성/고유 ID, 명칭, 소유자, 원래 손상도**를 유지한다. 부품 장착 재선택으로 체력/쿨타임을 전부 회복하거나 전투 중 HP를 즉시 만회하면 안 된다.
- 재료를 추가해 소재를 보강하는 **영구 강화**는 실제 소모된 소재를 기록한다. 강화를 한 번 더 시도해도 과거 지불한 재료보다 많은 아이템을 생산하지 못하게 한다.
- 특수 소재는 모두를 강제 획득시키기보다 **전투 방식의 선택지**를 제공하는 방향. 초반 인형도 계속 보강하여 후반까지 사용할 수 있어야 한다.

## 7. 수리, 파손, 분해 — 플레이어가 이해하기 쉬운 2가지 선택

**수리와 분해는 같은 재료 풀을 공유하되, 매 tick 연료 소모나 반복 수리 버튼 노가다는 만들지 않는다.**

### A. 인형/부품 교체 또는 회수

- 인형을 안전하게 회수한 뒤 부품을 교체하면 **교체된 기존 부품을 아이템 그대로 보존**. 부품별 손상도·강화 상태도 유지. 새 조립을 위한 최소 소모재(실 등)는 소요될 수 있으나 과정마다 별도 마법 재화를 요구하지 않는다.
- 인형이 HP 0으로 파손되어 재료 회수 가능한 상태라면 수리/분해를 선택한다. 파손 후 자동 즉시 무료 재소환 금지.

### B. 인형을 원재료로 **분해** (사용자 결정: 기능 필수 / 반환율 미확정)

- 분해는 인형(또는 부품)을 **파괴하고 과거 실제 소비된 원재료의 일부를 되돌리는 선택지**다. 완성 인형과 부품을 동시에 남기지 않는다.
- **반환율 1차 제안**: 손상 없이 정상 분해한 일반 구조재의 각 종류별 `floor(0.75 × 유효투입량)`; **파손 인형은 0.45배** 후보. 다이아몬드처럼 개수 1의 고가 재료가 무조건 0으로 사라지지 않도록, **미파손 상태에서 핵심 촉매 1개를 부품 형태로 완전 회수**하는 예외안을 검토한다. 숫자·촉매 분류는 미확정.
- 서로 다른 인형을 제작·분해할 때 **원자재 회수량은 결코 그 인형을 만들고 강화하는 데 실제 투입된 재료량을 넘을 수 없다**. 자연 드롭·프리 재료·퀘스트 보상 등 원가 기록 없는 산출물은 별도 정의.
- **보강된 부품의 유효투입량 ledger**를 서버가 추적한다. 같은 철 주괴를 '기본 부품'과 '강화 부품' 양쪽에서 각각 환불해 주는 이중 계산을 금지한다.
- UI는 분해를 누르기 전에 **예상 반환 아이템 수량/영구 소멸하는 부품**을 분명하게 보여줘야 한다. 분해는 확인 절차가 필요하다.
- 분해로 반환된 재료는 일반 바닐라 아이템으로 사용 가능해야 한다. '재활용 파편' 같은 별도 화폐를 굳이 추가하지 않는다.

### 구체 예시 (미파손 초급 경량 골격만 분해하는 가정)

- 투입: 판자×4 + 막대기×2 + 실×2 + 구리 주괴×1
- 일반 재료 75% 내림 환불(가정): 판자×3 + 막대기×1 + 실×1 + 구리 주괴×0
- 구리 주괴×1처럼 작은 수량이 너무 손해로 체감되면 고가 소재 보존/반환 단위를 플레이테스트에서 조정한다. **실제 제작/분해 기능을 구현하거나 플레이테스트한 결과가 아님**.
- 같은 인형에서 받은 원재료를 다시 새 부품으로 만들 때 재료량이 늘어나면 실패. **직업 패시브 '소재 활용'도 무에서 재료 생성하지 않는다**.

### 수리

- 피해를 입은 부품은 원래 구성 소재 일부로 수리한다. 수리 자원 요구량은 손상률, 부품 기초 제작 원가, 인형술사의 관련 패시브 효과를 반영하되 무료 무한 치유를 피한다.
- '응급 접합' 스킬은 전투 중 일시 복구로서 준비된 소재 소량 또는 제한된 자기 소모 자원을 사용하도록 검토한다. 장비·투자 수준에 따라 수리 수량이 너무 많이 요구되는지 검수.
- 분해 소재와 수리 소재의 사용처가 달라질 수 있도록, 즉각적 이득은 **수리해서 계속 사용**, 큰 구조 변경은 **분해 후 새 모델 제작**으로 나눠 선택을 만든다.

## 8. 경제 밸런스와 성장 설계

- 장기 레벨 성장은 제한 없지만, 스킬/장비의 상승으로 제작·수리·소재 회수율이 개선되어도 **재료 반환이 투입량을 초과하지 않도록** 한다.
- 동시 인형 개체 증가 = **초기 제작 재료 + 개별 수리/강화 비용** 증가. 정신 지배자의 지속 정신력 유지와 달리 인형술사는 **지속적인 별도 연료/MP 유지 세금은 기본적으로 없음**. 대신 손상과 제작 투자에 따른 비용이 핵심.
- 후반 다수 운용을 위해 일괄 수리·일괄 전개 등 반복 노동을 줄이는 UX를 추후 검토한다. 이 작업이 새 정비 메뉴 6종을 추가해야 한다는 뜻은 아니다.
- 자원 수급/분해율을 최적화하면 인형술사만 바닐라 경제를 무한 증식할 위험이 있으므로, **제작→강화→해체→재제작**, 서로 다른 재료 바꿈, 월드 저장/로그아웃/사망의 수량 보존을 테스트해야 한다.
- 인형 중복·복제 방지, 레시피/소재 스탯/분해율/동시 운용 수는 **서버의 data-driven 설정**으로 분리하고, 핵심 조립 변경 시 JAR 수정 없이 콘텐츠 조정할 수 있도록 설계한다.

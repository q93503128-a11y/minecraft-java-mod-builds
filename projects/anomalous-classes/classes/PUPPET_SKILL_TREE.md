## 동시 전개 한도 후보

`BaseActive(L)=1+floor(sqrt((L-1)/24))`
`MaxActive(L,r,g)=BaseActive(L)+floor(r/10)+GearBonus(g)`

L=무제한 직업 레벨, r=여분의 실(0~30). **GearBonus(g)=g**로, 미장착 0 / 규격 +1 / 변조 +2 / 변칙 +3 / 이형 +4 / 불가해 +5기. 이는 사용자가 결정한 **조종틀 등급당 +1기**의 직접 반영이다. 기본 전개 수 Lv1 1기, Lv25 2기, Lv50 2기, Lv100 3기, Lv250 4기, Lv500 5기, Lv1000 7기. 여분의 실을 끝까지 투자하면 추가 3기. 예: Lv100 + 여분의 실 30랭크 + 불가해 조종틀 = **11기**(이론치; 획득 가능 레벨·TPS 미검증). 3m 인형도 1슬롯, 보관 아이템은 미점유, 전개 중 언로드는 슬롯 점유. 지속 연료나 정신력 유지비 없음. 서버 성능 테스트 전 수치 확정하지 않는다.

## 계약

재료와 크기는 부품 성능, 패시브는 제작·자동행동·전투 숙련, 조종틀은 **동시 전개 슬롯 증가 및 인형의 공격력·최대 체력 증가만** 담당한다. 조종틀의 명령 범위·반응/연결 특수 강화는 철회했다. 현재 스탯 증가량은 등급당 +5%씩(규격 +5%~불가해 +25%) 밸런스 후보이며 세부는 [MARIONETTE_CONTROL_BAR.md](./MARIONETTE_CONTROL_BAR.md) 참고. 해체·축소 환급은 실제 소비된 원가를 넘지 않으며 보상 중복 금지. 표적 지정 연타로 공격 쿨타임 초기화 불가, 아군 피해 차단은 투자 없이 기본 제공. 랭크 완료 이후에도 레벨 상승/기본 스탯 성장은 계속하고 이후 포인트 사용은 추후 결정. 최종 UI는 Codex가 구현하며 데이터·피해·아이템 판정은 서버 권위.

# 계약술사 — 전용 매개체 '계약 증표' 5등급 설계 초안

> **2026-11-06 D07 최신 사용자 확정(이 문서의 예전 '2계약 최대/검증 후보'보다 우선):** **3개 이상 동시 계약 허용**(2개 하드캡 없음). 새로운 n번째 활성 계약의 **소모 가능한 체결 제물**은 그 존재의 기본 제물 대비 **2^(n−1)배**: 첫 1배·둘째 2배·셋째 4배·넷째 8배·다섯째 16배. **같은 능력치의 가장 큰 가호 증가분 100% + 다른 각 계약의 동종 가호 증가분 50%**를 합산한다(각 고유 권능/금기·채무 자동 절반 아님). 기존 관계·심화·정식 계약서 확인·원자 소비/위약금·고위계 우위 보존. **정확한 제물 수량·권능 쿨·실게임 밸런스는 미검증.** 상세 정본: [3개 이상 동시 계약 소프트캡](./PACT_SOFTCAP_MULTICONTRACT_POLICY_V1.md).


> 2026-11-05 / **DESIGN PROPOSAL.** 공통 확정 규칙: [직업 매개체 슬롯](../CLASS_FOCUS_SLOT.md) 1개, 주손/보조 손 자유, 장비 없는 계약·기본 권능 가능, 등급은 **규격→변조→변칙→이형→불가해**. 기존 문서 `계약 증표`는 가칭이다. 아이템 제작식/가호 계수/자산은 플레이테스트·실제 화면·로더 호환 검증 전.

## 1. 무엇을 강화하는가?

- 계약 증표는 **계약 상대가 제공하는 플레이어 스탯 가호의 증가분**과 **계약에서 빌린 일반 액티브 권능의 위력** 두 가지에 집중한다. 별도 계약 슬롯, 제단 원격 이용, 계약 조건 면제, 관계 수치 획득 가속, 위약금 할인, 현현 자동 발동을 제공하지 않는다.
- 전용 매개체 슬롯 하나에 현재 장착한 계약 증표 1개만 활성. **한 장비가 현재 모든 유효 계약에 동일 원칙으로 적용**되고 두 계약 때문에 장비 효과를 두 번 적용하지 않는다.
- 대상 스탯과 권능의 계산 순서: 개별 관계/심화 → 같은 스탯 이중계약 `강한 가호+약한 가호 50%` → 공통 패시브의 해당 증가분 → 증표 가호 효율을 한 번 적용. 추가 공격 옵션은 권능 직접 효과에 한 번만 반영하고 무기 공격을 무조건 중복 강화하지 않는다.
- 일반 현현은 **특별한 제물과 조건을 동반한 궁극급 사건**이므로 매개체의 '일반 권능 위력' 보너스를 전부 무조건 적용하지 않는다. 적용 여부와 한계는 개별 존재 설계에 명시할 것.
- 계약이 금기를 위반해 봉인되거나 해약되면 장비로 그 계약의 보너스를 복구할 수 없다. 장비를 바꿔 채무·위약금·신앙 감소를 지울 수 없다.

## 2. 장비 5등급 효능 (전부 시험값)

| 등급 | 계약이 제공하는 스탯 가호 **증가분 효율** | 일반 권능 직접 효과·피해 |
|---|---:|---:|
| 무장비 | +0% | +0% |
| **규격** | +5% | +5% |
| **변조** | +10% | +10% |
| **변칙** | +15% | +15% |
| **이형** | +20% | +20% |
| **불가해** | +25% | +25% |

**예:** 우르겐 기본 가호 +40% 최대 HP와 규격 증표를 사용하면, 무조건 전체 최대 HP ×1.05를 추가하는 것이 아니라 **계약이 제공한 +40%의 증가분만 1.05배 → +42%**로 보정하는 시험안이다. 심화/관계/패시브/이중계약 후에는 그 최종 유효 증가분에 한 번만 적용. HP 변경은 현 체력 비율 유지. 수치·합성은 구현 및 타 직업 비교 전 미확정.

## 3. Minecraft 생존 재료로 만드는 제작·승급 (시험 레시피)

기본 제작대 3×3 안에서 직전 등급 증표 1개 + 새 재료들로 승급. 각 줄의 아이템은 제작 칸 수 제한을 만족하는 **재료 후보**이며 패턴·정확한 개수/희귀도/대체 레시피는 아직 미정.

| 제작 등급 | 직전 증표 | 추가 재료 후보 |
|---|---|---|
| 규격 | 없음 | 종이×1, 구리 주괴×2, 자수정 조각×2, 실×1 |
| 변조 | 규격×1 | 철 주괴×2, 청금석×2, 레드스톤×2 |
| 변칙 | 변조×1 | 금 주괴×2, 흑요석×2, 자수정 조각×2 |
| 이형 | 변칙×1 | 다이아몬드×2, 엔더 진주×2, 메아리 조각×2 |
| 불가해 | 이형×1 | 네더의 별×1, 네더라이트 파편×2, 메아리 조각×2, 자수정 조각×2 |

- 등급을 올리면 **직전 아이템을 한 개 소비**. 재료·계약 제물 경제가 경쟁하므로 같은 광물의 중복 요구가 지나치지 않도록 테스트. 최고 등급 제작은 같은 게임 내 타 직업 장비의 희귀도와 비교. 신규 전용 제작 화폐/테이블/매 계약마다 별도 증표를 강제하지 않는다.
- 아이템 자체를 5개 쌓아서 5번 스탯을 적용하는 행동, 직업 변경/사망/인벤토리 이동/일시 손 전시 등으로 증표를 복제하거나 무료 HP 회복·쿨타임 초기화 금지.
- 별도 제단 없이도 입문 계약 가능하며, 전용 증표를 제작하기 전에도 모든 기본 계약 기능 이용 가능.

## 4. 외형·모델·시각 품질 목표 (참고 방향, 자산 제작 전)

- **가칭 '계약 증표'**: 손바닥 정도의 금속/석질 인장에 작게 접힌 계약서/각인이 떠오르는 형태. 모든 계약 상대에게 재사용되는 **중립적인 단일 실루엣**을 기본으로 하고, 활성 계약에 따라 문자·재질 반사·발광 색/문양이 달라질 수 있다. 2계약이라도 아이템 하나를 '반으로 쪼개는' 식의 복잡한 관리 UI를 강제하지 않는다.
- **규격/변조**: 단순 금속·새겨진 원, 적은 수의 각인. **변칙**: 공중에 떠오르는 작고 독특한 인장 파편. **이형**: 금속 주변 비정상적인 문양과 특수 실루엣. **불가해**: 읽을 수 없는 문양·규칙적인 위치 변형과 짧은 효과(과도한 번쩍임 방지).
- 장비는 공통 전용 슬롯에 보관되고 **계약을 호출하거나 권능 시전 중에만 손 위에 짧게 나타나는 연출**을 검토한다. 주손 무기/곡괭이와 왼손 방패/토템을 억지로 교체하지 않는다. 천사계면 정돈된 성광, 악마계면 불길한 붉은 서명, 거인이면 금속/석재 울림처럼 각 계약 특성에 맞춘 반응.
- 실제 게임 모델·텍스처·애니메이션·사운드에는 외부 검증 자산 또는 제작한 3D 자산을 사용한다. 완성 판단은 마인크래프트 화면에서 실루엣/가독성/손연출/프레임/서버 부하를 검수한 뒤. **현재 3D 모델·VFX·음향/코드 없음**.

## 5. UI·검증

- 툴팁은 **'계약 가호 효율 +N%', '일반 권능 효율 +N%'** 두 줄 중심. 이는 계약 기본 공격력 +N% 자체와 다름을 설명해야 한다. 해당 계약 기술 종류와 무관한 옵션을 임의 추가하지 않는다.
- 장비 레벨과 계약 **4위계**는 서로 다른 개념이며, **장비 5등급을 제4위계 접근 필수 허가**로 강제하지 않는다. 강력한 상위 존재는 제단·제물·조건이 주 진입 장벽이다.
- 서버는 계약 대상 UUID/계약 ID/관계·심화·실제 매개체 등급을 검증하고, 관계 회복/금기 패널티를 장비 효과 때문에 우회하지 않도록 한다. 높아진 최종 HP와 현재 HP의 비율 보존·재로그 후 적용, PvP/외부 Attribute 중복 합성 확인.

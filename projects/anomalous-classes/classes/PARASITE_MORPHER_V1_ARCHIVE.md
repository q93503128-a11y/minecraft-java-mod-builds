# 기생술사 — 생체 특성 흡수·본체 변이 1차 기획

> 2026-11-04 / **DESIGN PROPOSAL / USER REVIEW PENDING / NOT IMPLEMENTED.** 기존 [PROJECT.md](../PROJECT.md)에서 사용자와 합의한 직업 정의는 **“생물의 특성을 흡수하고 신체 변형에 활용한다”**이다. 아래에 새로 제안하는 신체 슬롯 수, 특성 획득 조건, 기술, 자원·수치, 직업 장비는 아직 사용자가 승인한 사실이 아니다.

## 1. 역할 — '생물을 부리는 직업'이 아니라 '자신이 생물로 변하는 직업'

- 정신 지배자: 원래 몬스터의 AI와 능력을 **그대로 살아 있는 몬스터로 지배·운용**.
- 인형술사: 원자재로 **외부 마리오네트 개체를 만들고 자동전투**.
- **기생술사: 자신의 신체 안에서 살아 있는 기생체가 생물의 특성을 흡수하고, 플레이어의 **신체/행동/외형**을 직접 변화시켜 싸움.**
- 근접 전투를 중심으로 신체 기관을 조합하되 수중·탐험·이동도 실질적인 선택지를 갖도록 한다.
- 다른 생물을 잠시 정신 지배하거나, 적 몬스터를 복사해 부하로 소환하거나, 모든 몹에 대해 원본 능력을 무제한 복제하는 기능으로 설계하지 않는다.
- 전용 장비는 직업 공통 **한 계열/규격→변조→변칙→이형→불가해** 5등급 원칙만 우선 적용. 조종틀의 '등급당 슬롯 +1' 규칙을 다른 직업에 무단 복사하지 않는다.
- 기존 직업의 마나/연료/제작 재화 규칙을 그대로 전용하지 않는다. 기생술사에게 자체 부담을 둔다면 전투에서 직관적인 단일 부하로 설계한다.

## 3. 핵심 루프

**생물 탐색 → 특성 표본 획득 → 영구 특성 해금 → 자신의 신체에 일부 장착(변이) → 전투·탐험 → 다른 특성/개조 선택 → 더 어려운 생물 도전.**

- 한 번 해금한 종별 특성은 **영구 기록**. 원래 생물을 무한히 사냥해 아이템 수십 개를 쌓아 둬야만 조합을 바꿀 수 있는 설계는 피한다.
- 일반적인 바닐라 생존 행동·장비는 유지. 기생술사 직업 선택 전부터 가지고 있던 장비·이동·거래를 부당하게 차단하지 않는다.
- **적대 생물**은 자신이 '침식 표식'을 부여한 후 전투에 기여하고 대상이 사망하면 표본 획득을 판정하는 방안. 순수 킬스틸, 원거리 자동 농장만으로 최상위 능력을 다 얻지 않도록 기여 조건 검토. 기생술사는 **직접 전투의 위험**을 감수.
- **중립·비적대 동물**은 반복 학살이 필수가 되지 않도록 **비치명적인 근거리 생체 표본 채취** 방안도 제공(대상별 긴 재채집 간격). 주민 등 민감한 AI/거래 개체는 기본 표본 대상이 아니고, 무해/비전투 허용 대상을 별도 정의.
- **보스와 외부 몬스터**도 종별 특성을 제공할 수 있으나, 원본 보스 전체 스킬 자동 복제는 아님. 최고급 특성도 인게임에서 시각적으로 보여지는 능력/보스 패턴을 단순화한 **플레이어 전용 변이 능력**으로 개별 설계. 보스만으로 종별 일괄 면역을 두지 않는다. 지원하지 않는 외부 종은 안전한 일반 전투 보상으로 처리하고 '모든 모드에 무조건 완전 호환'을 주장하지 않는다.
- 특성 수집이 **별도의 화폐/일회성 소모 아이템을 계속 요구하는 제작 노동**이 되지 않게 한다. 습득한 특성의 강화는 공용 레벨/스킬 포인트 + 실제 전투 경험으로 진행하는 쪽을 먼저 검토.

## 7. 자원 — 별도 복잡한 통화 대신 '기생 부하' 후보

- **기생 부하(0~100)**: 기생체가 변형 능력을 강하게 발휘할수록 누적되는 단일 직업 상태. 공격·기동 특수 액티브가 발동하면 일정량 상승하고, 일반적인 전투/평시에는 시간이 지나며 회복(부하 감소).
- 예: **기생 침식 +8 / 변이 분출 +24 / 탈피 +18 / 자가 재생 +30**, 평시 초당 -7·전투 중 초당 -3 등의 시험 수치. 보스전에서도 활동이 중단되지 않게 조절. **모든 수치 미확정**.
- 부하 한계에 가까우면 일시적으로 비상 고부하 기술 사용이 제한되며, 기본 이동·바닐라 공격·기초 변이 장착 능력은 중단되지 않는다. **기생체를 매초 먹이거나 인벤토리 재료를 바치는 유지 노동 없음**.
- 이 자원은 **계약술사의 '대가와 위험'이라는 정체성과 중복되지 않게**, '계약 위반/장기 저주'가 아닌 **순간적인 신체 변형 과부하**를 표현한다. 사용자 조작을 막는 과한 장기 디버프는 추가하지 않는다.
- 기생 부하의 회복과 스킬 사용 규칙은 실제 공격 주기/기본 체력과 함께 수치 시뮬레이션 후 결정.

## 8. 패시브/레벨/장비 방향 (향후 구체화)

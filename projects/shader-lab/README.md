# Shader Lab 0.3.0-alpha.3

Minecraft Java 26.2 + NeoForge용 클라이언트 전용 JAR 쉐이더 실험이다. 배포용 모드가
아니며, 모드 JAR 하나만으로 화면 후처리·몽환적 밤하늘·화면 공간 물 표현을 시험한다.

## 0.3의 목표

0.2는 적용은 정상적이었지만 다단계 블룸 때문에 원본 선명도가 약해졌고, 물과 밤하늘의
형태 자체는 거의 바뀌지 않아 전후 차이가 모호했다. 0.3은 다음을 우선한다.

- 주변 픽셀 기반 선명화로 원본 디테일 회복
- 블룸 추출 임계값과 합성 강도를 낮춰 뿌연 화면 억제
- 깊이 버퍼상 하늘이며 실제 화면이 어두울 때만 나타나는 동적 오로라
- 청록·보라·분홍빛이 접히며 흐르는 3중 오로라 커튼
- 하늘이 아닌 파랑·청록 계열 표면을 판정하는 화면 공간 물 마스크
- 물에 움직이는 파문, 진주광 색변화, 밝은 물결 마루와 반짝임 추가
- 낮에는 선명하고 생생하게, 밤에는 몽환적이되 검은색이 뭉개지지 않도록 조정
- 흔들림, 모션 블러, 잔상은 사용하지 않음

## 렌더링 구조

`shaderlab:lush_grade`는 총 7개 패스로 동작한다.

1. 높은 임계값으로 밝은 픽셀만 추출
2. 좁은 가로 광휘 확산
3. 좁은 세로 광휘 확산
4. 넓은 가로 광휘 확산
5. 넓은 세로 광휘 확산
6. 원본 선명화·물 판정·오로라·광휘·톤매핑 합성
7. 최종 화면 출력

오로라는 `minecraft:globals.glsl`의 `GameTime`으로 움직이며, 역방향 깊이 버퍼와 화면
밝기를 함께 사용해 낮·동굴·일반 지형에 무작정 겹치지 않도록 한다.

물 표현은 아직 월드 좌표 기반 반사·굴절을 가진 완전한 물 렌더러가 아니라 화면 공간
판정 방식이다. 이번 단계에서는 물이 즉시 달라 보이는지와 색·파문 방향을 먼저 검증한다.
다음 단계에서 필요하면 물 전용 렌더 파이프라인으로 교체한다.

## 테스트 환경

- Minecraft Java 26.2
- Java 25
- NeoForge 26.2.0.40-beta
- NVIDIA GTX 1660 SUPER / OpenGL 3.3 우선
- Iris, OptiFine, Oculus 및 다른 쉐이더 모드는 제외
- e4mc는 함께 있어도 렌더링 효과에 관여하지 않음

## 게임에서 확인

1. 이전 Shader Lab JAR를 삭제한다.
2. `shaderlab-0.3.0-alpha.3.jar` 하나만 `mods` 폴더에 넣는다.
3. 게임을 완전히 종료했다가 다시 실행한다.
4. 낮의 강·바다에서 청록·보라 진주광 파문이 움직이는지 확인한다.
5. `/time set midnight` 후 하늘을 넓게 바라보고 오로라가 나타나는지 확인한다.
6. 동굴 천장과 지형 위에는 오로라가 겹치지 않는지 확인한다.
7. 0.2보다 화면의 글자·블록 경계가 선명해졌는지 확인한다.

## 로컬 빌드

```bash
gradle wrapper --gradle-version 9.2.1 --distribution-type bin
./gradlew --no-daemon clean build --stacktrace
python3 scripts/verify_jar.py build/libs/shaderlab-0.3.0-alpha.3.jar
```

Windows에서는 두 번째 명령부터 `gradlew.bat`를 사용한다.

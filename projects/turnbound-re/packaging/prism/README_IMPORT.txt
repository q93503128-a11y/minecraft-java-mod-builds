TURNBOUND: RE — Prism Launcher 패키지

1. Prism Launcher에서 Add Instance -> Import를 선택합니다.
2. 이 ZIP을 그대로 선택합니다.
3. TURNBOUND RE 인스턴스를 실행합니다.
4. 첫 실행 전에 공식 Drehmal: APOTHEOSIS v2.2.2f 월드(약 4GB 압축)와 리소스팩을 공식 GitHub 릴리스에서 자동 다운로드하고 검증합니다.
5. 설치가 끝나면 Minecraft가 시작됩니다. 싱글플레이에서 "TURNBOUND RE - Drehmal APOTHEOSIS 2.2.2f" 월드를 선택합니다.
6. 해당 월드는 첫 입장 시 TURNBOUND가 자동으로 바인딩하고 Hub로 이동시킵니다.

주의:
- 첫 설치에는 최소 12GiB의 여유 공간을 권장합니다.
- 외부 월드/리소스팩 원본은 TURNBOUND ZIP에 재배포하지 않습니다. bootstrap이 Drehmal Team 공식 릴리스 URL에서 직접 받습니다.
- Java 25가 필요합니다. Prism의 Java 자동 다운로드/선택 기능을 사용할 수 있습니다.
- APOTHEOSIS는 원래 1.20.1-era 월드이므로 Java 26.2 최초 migration 결과는 아직 실제 플레이 검증이 필요합니다.

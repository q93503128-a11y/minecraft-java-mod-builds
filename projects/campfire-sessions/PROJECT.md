# Campfire Sessions

Status: ALPHA.2 VISUAL / PLAYLIST SLICE

- Mod ID: campfiresessions
- Version: 0.2.0-alpha.1
- Minecraft: 26.2
- Java: 25
- Loader: NeoForge 26.2.0.87
- Goal: turn the functional prototype into a compact themed music player with believable held/placed assets.

## Alpha.2 acceptance
1. Acoustic Guitar uses replacement CC0 GLB-derived geometry and is scaled for inventory/first/third person.
2. Timber Dining Chair uses replacement CC0 geometry, rotates on placement, has a chair-shaped collision and seats the player facing forward.
3. Playlist contains four verified CC0 tracks.
4. Playlist shows only three rows and supports mouse-wheel scrolling.
5. Selecting tracks changes the visual theme; clean, neon and ocean are exercised by real tracks.
6. Desert and rough theme tokens exist for later tracks.
7. Player uses external Kenney CC0 sci-fi glass/metal UI artwork.
8. clean build packages every converted model, palette, OGG and UI resource.

## Scope boundary
Multiplayer synchronized positional performance, strumming animation and large song unlock progression remain later work. Alpha.2 focuses on the user-visible problems found in the first in-game screenshots.

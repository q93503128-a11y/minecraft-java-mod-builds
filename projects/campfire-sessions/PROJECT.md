# Campfire Sessions

Status: ALPHA.1 TEST SLICE

- Mod ID: campfiresessions
- Version: 0.1.0-alpha.1
- Minecraft: 26.2
- Java: 25
- Loader: NeoForge 26.2.0.87
- Goal: validate one imported guitar, one imported chair, one CC0 song and the selection UI.

## Alpha.1 acceptance
1. Acoustic Guitar appears in the Campfire Sessions creative tab.
2. Guitar uses the external CC0 Voxel Classical Guitar geometry.
3. Right-clicking the guitar opens the song screen.
4. The screen uses imported Kenney CC0 UI artwork.
5. Etirwer can be started and stopped.
6. Wooden Chair uses external CC0 chair geometry.
7. Right-clicking the chair seats the player.
8. clean build produces a JAR containing generated OBJ/MTL/OGG resources.

## Scope boundary
This first slice intentionally has one song and client-local playback. Nearby-player synchronization, playing animations, playlists and more furniture come after this slice is visually accepted.

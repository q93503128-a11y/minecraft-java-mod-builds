# Third-party assets

Campfire Sessions uses open assets with explicit redistribution-friendly licensing.

## Guitar model
- Project: **Musical Instruments Pack** — Tchongas
- Source repository: https://github.com/Tchongas/datapacks
- Pinned source commit: `0ff8ae11584f357129beec8cba145cf67b08f1ba`
- Source model: `1.21/flute/assets/minecraft/models/item/guitar.json`
- License: MIT
- Use here: the Minecraft/Blockbench geometry and display transforms are retained; texture slots use vanilla Minecraft wood textures.

## Chair model
- Project: **Voxelized Furniture** — okil6dev
- Source repository: https://github.com/okil6dev/Voxelized-Furniture
- Pinned source commit: `e83c183de66c1b7114eb6b39a24f58bc87ab9d96`
- Source model: `src/main/resources/assets/voxelized_furniture/models/custom/chair_oak.json`
- License: MIT
- Use here: the model geometry is retained and mapped to vanilla `stripped_oak_log`.

## Theme UI assets
All UI sprites below originate from Kenney CC0 UI packs. The build downloads pinned copies from the public `shorepine/kenney` mirror at commit `3694c6879e487c108f55677be7dd2ca75b07cc3b`.

### Clean
- UI Pack - Adventure: `panel_grey.png`
- UI Pack: grey rectangle button assets

### Neon
- UI Pack - Sci-Fi: `glassPanel.png`, `metalPanel_blue.png`, blue sci-fi header button

### Ocean
- UI Adventure Pack: blue panel, blue inset panel, blue long button

### Desert
- UI Adventure Pack: beige panel, beige-light inset panel, beige long button

### Rough
- UI Pack - Adventure: damaged dark brown panel, damaged brown panel, brown button

License for these Kenney packs: CC0. Attribution is not required, but the source is kept here for provenance.

# Third-party assets

All assets in this prototype are from sources that explicitly state CC0 / public-domain dedication.

## Guitar
- Voxel Classical Guitar — MonoTone
- https://opengameart.org/content/voxel-classical-guitar
- Download: https://opengameart.org/sites/default/files/voxelclassicalguitar.zip
- License: CC0
- The original MagicaVoxel geometry is downloaded and deterministically converted to OBJ/MTL at build time.

## Chair
- 3D Lowpoly Chair — Lyricsz
- https://opengameart.org/content/3d-lowpoly-chair
- Download: https://opengameart.org/sites/default/files/chair_cc0.obj
- License: CC0
- Original OBJ geometry is normalized to Minecraft scale; geometry is not redrawn.

## Music
- Etirwer (Looped) — Kistol
- https://lpc.opengameart.org/content/etirwer
- Download: https://lpc.opengameart.org/sites/default/files/Etirwer%20%28Looped%29_0.ogg
- License: CC0
- Streamed OGG used as the first selectable track.

## UI
- Kenney UI Pack - Adventure — Kenney
- Mirror: https://github.com/shorepine/kenney
- Original publisher: https://kenney.nl/
- License: CC0
- Exact used file: ui/UI Pack - Adventure/panel_brown.png

The asset preparation task prints SHA-256 hashes for every downloaded runtime asset during clean builds.

# TURNBOUND Battle/UI & Player Shell Delta — alpha.6

상태: `01_세부기획서_v0.4.md`의 방향성을 실제 P0 테스트 결과와 사용자 제공 R_PG 전투 스크린샷에 맞춰 구체화하는 개발 정본 델타.

이 문서는 수치/캐릭터/턴 공식은 수정하지 않는다. 전투 HUD와 Minecraft 플레이어 껍데기의 역할만 확정한다.

## 1. alpha.4~alpha.5 전투 UI 전면 폐기

다음 구조는 더 이상 재사용하지 않는다.

- 좌우를 거대한 아군/적 패널이 점유하는 구조
- 화면 중앙을 좁은 세로 통로처럼 남기는 레이아웃
- 늘린 GUI 프레임/텍스처를 화면 대부분에 사용하는 방식
- 아군/적 전원을 큰 클릭 버튼 카드로 만드는 방식
- 화면 중앙/상단에 게임 제목, 디버그 상태, 조작 안내를 상시 중첩하는 방식
- `TURN_READY`, combatant instance id, pulse 등 내부 문자열 노출
- 전투원 커스텀 Nameplate 상시 표시

alpha.6는 기존 `BattleScreenLayout`, `GlassButton`, `KenneyButton` 계열을 제거하고 HUD geometry/control을 새로 만든다.

## 2. 새 전투 화면 원칙

R_PG 참고에서 가져오는 것은 자산이 아니라 공간/정보 구조다.

- 3D 전투 장면이 화면 대부분을 차지한다.
- HUD는 가장자리에 작은 정보 단위로만 배치한다.
- 아군 4명은 하단의 얇은 party bar로 표시한다.
- 적 최대 5명은 상단 우측의 작은 summary bar로 표시한다.
- 턴 예측은 상단 중앙의 얇은 timeline만 사용한다.
- 현재 행동 가능한 캐릭터의 스킬만 우측에 문맥적으로 나타난다.
- Auto / 배속 / 도주는 우하단의 작은 보조 제어다.
- 타겟 HUD 강조와 3D 위치 마커는 같은 target id를 사용한다.
- 전투 외 월드와 캐릭터가 가려지지 않도록 full-screen tint를 사용하지 않는다.

R_PG의 UI 텍스처, 아이콘, 폰트, 색 배치, 정확한 좌표는 복제하지 않는다.

## 3. Minecraft 플레이어는 생존 캐릭터가 아니다

TURNBOUND에서 Minecraft Player entity는 다음 역할만 담당한다.

- 필드 이동
- NPC/오브젝트 상호작용
- 카메라와 입력의 주체
- 서버 세션의 소유자

플레이어 본체의 바닐라 생존 수치는 RPG 전투 규칙으로 사용하지 않는다.

### 3.1 플레이어 체력

- 바닐라 하트는 게임플레이 체력으로 사용하지 않는다.
- 필드/전투에서 플레이어 entity가 피해를 받아 죽는 생존 루프를 사용하지 않는다.
- 전투 HP는 오직 파티 캐릭터의 `CombatantState.hp`가 정본이다.
- 필드 위험을 추가할 경우 바닐라 하트를 깎지 말고, 전용 이벤트/조우/체크포인트 규칙으로 설계한다.
- 바닐라 Player Health HUD는 숨긴다.

### 3.2 허기

- 허기/포만도/음식 생존 관리는 존재하지 않는다.
- sprint 가능 여부나 자연 회복을 허기로 제어하지 않는다.
- 음식 섭취를 회복/성장 루프로 사용하지 않는다.
- 바닐라 Food HUD는 숨긴다.
- 기술적으로는 플레이어 허기를 항상 충족 상태로 유지하여 이동 제약이 생기지 않게 한다.

### 3.3 설계 경계

다음은 금지한다.

- 허기 때문에 탐험을 중단하고 음식을 구하는 루프
- 플레이어 하트 회복을 위해 음식/포션을 파밍하는 루프
- 바닐라 갑옷/방패/인챈트로 플레이어 본체 생존력을 올리는 성장
- 전투 파티 HP와 Minecraft 플레이어 하트를 동시에 관리하게 만드는 이중 체력 시스템

즉 TURNBOUND는 Minecraft의 월드/카메라/엔티티/렌더링을 사용하지만 survival game은 아니다.

## 4. alpha.6 P0 입력

- LMB: HUD/타겟 선택, 빈 전투 장면 drag 시 orbit
- RMB: 현재 스킬/타겟 선택 취소
- Wheel: zoom
- 1~5: 행동 선택
- Tab / Shift+Tab: 유효 타겟 순환
- Enter: 타겟 확정
- A: Auto
- X: 1.0x / 2.0x
- R: 일반전 확정 도주 / 결과 후 복귀
- Esc: 전투 설정 overlay

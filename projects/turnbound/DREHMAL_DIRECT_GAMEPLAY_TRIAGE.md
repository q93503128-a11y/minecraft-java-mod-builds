# Drehmal 직접 게임 명령 분리 선별 조사 — 2026-11-10

## 목적
이전 5종 통합 분리 경계는 검증되었지만, 원작 명령 블록 중 `give` 37, `advancement` 3, `effect` 127, `kill` 20, `summon` 81개는 **명령 내용과 장치 기능의 관계**가 불명확하다. 이름만 보고 일괄 차단하면 원작 맵의 문·퍼즐·특수 연출 또는 시설 유지 기능까지 제거할 위험이 있다.

## 이번 단계
- [공식 2.2.2f 명령 감사](https://github.com/q93503128-a11y/minecraft-java-mod-builds/actions/runs/42591982023)의 전체 2,232개 명령 블록 목록과 SHA를 정본으로 고정하고, **직접 게임 명령 268개를 포함한 72개 지역 파일의 모든 명령 블록**을 재스캔하여 실제 명령 문자열·차원·지역 파일·좌표·청크 슬롯 SHA를 대조한다. 관련 없는 나머지 지역 전체를 다시 스캔했다는 뜻이 아니다.
- 이 중 직접 게임 명령 다섯 종류 268개를 정적 분류한다.
- 실제 대상 아이템·효과·엔티티·업적의 **식별자만** 추출하고 원본 명령문/NBT/선택자 내부 조건은 결과에 포함하지 않는다.
- 주변 4블록 이내 다른 명령 블록의 명령 **종류**를 집계해 구조물 장치의 연관 가능성을 표시한다. **공간적 인접은 실제 레드스톤 연결이나 조건부 체인의 증거가 아니다.**
- 분석 결과 모든 268건을 `PRESERVE_UNTIL_GAMEPLAY_AND_MECHANISM_REVIEW`로 남기고, 정적 명령 종류만으로 **자동 차단 대상에 넣지 않는다**.

## 안전 기준
현재 원작 지도·데이터팩·TURNBOUND 코드 수정 **0건**. 원작 기능 이식·재사용 **0건**. 본 조사에서 직접 명령 차단이 허용되는 것은 아니다. 구조물 및 맵 보존을 우선하며, 실제 분리 범위는 원작 아이템/NBT·업적/설비 의존성과 인접 블록의 사용 목적을 확인한 뒤 가역적 사본에서만 확정한다.

검증: [TURNBOUND 직접 게임 명령 검사 CI](https://github.com/q93503128-a11y/minecraft-java-mod-builds/actions/workflows/turnbound-drehmal-direct-gameplay-triage.yml).

## 첫 공식 실행 실패 및 수정 이유

[첫 검사 #1](https://github.com/q93503128-a11y/minecraft-java-mod-builds/actions/runs/42726728774)은 모든 명령 SHA 대조 후 `summon` 명령 중 일부의 **NBT 좌표가 비어 있어 안전하게 중단**됐다. 해당 항목은 명령 내용/해시가 있어도 블록 위치를 추정하지 않고 `MISSING_NBT_COORDS_NO_PATCH`로 보고하도록 고쳤다. 첫 전체 스캔이 11분 이상 걸렸기 때문에 후속 검사는 **검증된 원본 감사 전체 목록을 고정한 상태에서 목표가 포함된 72개 지역만 재스캔**한다.

## 추가 식별자 정규화

공식 268개 검사 재현 완료([CI](https://github.com/q93503128-a11y/minecraft-java-mod-builds/actions/runs/42728511852)). `give` 명령 37개 중 20개는 첫 분류에서 리소스 ID를 확인하지 못했으므로, Minecraft 1.20.1에서 허용되는 **네임스페이스를 생략한 바닐라 아이템 ID**도 `minecraft:...`로 정규화한다. 아이템에 붙은 NBT 데이터는 계속 출력하지 않으며, 해당 항목이 실제 원작 보상인지 구조물 필수 아이템인지는 아직 별도 검토가 필요하다.

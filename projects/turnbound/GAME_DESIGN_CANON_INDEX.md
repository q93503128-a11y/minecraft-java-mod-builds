## 1. 게임 정체성과 전체 플레이 루프

**[확정/방향]** 기존 TURNBOUND의 범용 턴제 전투 시스템을 재사용하되 기존 작가 제작 캐릭터·보스·스토리·지역·전투 콘텐츠는 폐기한다. 바닐라처럼 자연 생성된 Minecraft Java 서바이벌 월드에서 **탐험·채굴·건축·제작·NPC 의뢰·몹 전투·던전 탐험·소환·파티 성장**을 연결한다. 메인 스토리 강제 진행은 없다.

**플레이 루프를 한 줄로 정리하면:** Minecraft 월드에서 생존·탐험 → 필드 적/의뢰/발견한 던전 공략 → 보석·골드·몬스터 재료·광물·경험치 → 캐릭터 소환/성장/장비 제작 → 새로운 지역과 더 어려운 도전에 도전.

**[기술 스택]** Minecraft Java 26.2 / NeoForge 26.2.0.62 / Java 25 / Gradle 9.2.1. 현재 진행 중 프로젝트의 스택이며 임의로 Fabric으로 바꾸지 않는다.

## 2. 이동·전투·월드 생태

**[확정]**
- Minecraft 본래 방식으로 걷고, 점프하고, 채굴하고, 제작/건축한다. 턴제 전투의 주체는 **소환·육성한 캐릭터 최대 4명**이며, Minecraft 플레이어 아바타는 탐험·제작을 맡고 전투의 다섯 번째 참가자가 아니다.
- 필드 적과 접촉하면 **별도 전투 차원/평면 경기장으로 옮기지 않고 만난 실제 월드 지형에서** 전투 카메라/UI로 전환한다.
- 적대적 필드 몬스터는 플레이어를 발견하면 `!` 경고 → 반응/추격 → 물리 접촉으로 턴제 전투를 시작한다. 일반 이동 중 전투가 과도하게 발생하면 안 된다. 도망가 거리를 벌려 추격을 떼는 필드 회피도 허용한다.
- 평화로운 신규 동물은 평소 공격하지 않으나 플레이어가 **의도적으로 공격하면** 턴제 전투로 대응한다. 먹이주기·번식·정상적인 자원 채집은 자동 전투를 유발하지 않는다.
- 장기 목표는 **바닐라의 모든 살아 있는 몹을 TURNBOUND 세계관의 생물/NPC로 교체**하는 것이지만, 바닐라 생존 재료/거래/농장/네더·엔더 진척이 깨지지 않게 대체 공급원을 먼저 마련해야 한다. 비생물 Entity 전체 제거가 아니다.

**[전투 시스템 유지]** 기존 1000 고정소수점 턴 게이지, 속도(SPD) 기반 턴 획득, 기본 공격 CD0, 액티브 스킬·패시브·상태 효과·타겟 지정, 수동 선택 중 전투 논리 일시 정지, AUTO와 1x/2x 연출. 기존 구체 캐릭터 능력/수치까지 재사용한다는 뜻은 아니다.

- **특수 의뢰:** NPC 또는 특별한 월드 상호작용/사건에서만 발생. 일반 게시판에 무차별 혼합하지 않는다.
- 의뢰 등급이 **실제 난이도와 골드·보석 보상 수준**에 영향을 준다. 처치 의뢰는 무조건 골드, 탐사 의뢰는 무조건 보석처럼 종류별 재화를 고정하지 않는다.
- 일반·특수 의뢰의 출현 여부는 확률적이며 제공 주민도 고정 명단이 아니다. 같은 뻔한 의뢰를 별도의 무한 반복 의뢰 카테고리로 늘리지 않는다.
- 의뢰 제공 창구가 여러 곳이더라도 **진행·수령·완료·보상은 하나의 공통 시스템**이 다룬다. 의뢰를 받지 않고도 던전을 찾아 입장 가능하다.

**[미정/제안]** 의뢰 등급의 정확한 이름/단계(예시 E~S는 미확정), 생성 빈도/분포, 동시 수락 수·취소, 세부 미션 카테고리, 의뢰가 던전 정보를 제공하는 NPC/입구 상호작용의 비율, 보상량·장기 보석 공급 속도. 고정 반복 퀘스트 없이 **새로운 개별 의뢰가 계속 생성되는 모델**은 제안이지만 생성 규칙은 미승인.

## 6. 던전 시스템 — **핵심 방향 기획 완료 / 상세 제작 보류**

**[확정]**
- 일반 서바이벌 월드에 발견 가능한 **던전이 많이** 자연 생성된다. 테마 종류를 무리하게 늘리기보다 같은 테마 안에서 레이아웃·방/적 구성·난이도·보상이 다양하게 생성되며, 한 번 생성된 물리적 구조는 저장되어 안정적이다.
- 던전 안에서도 **마인크래프트식 자유 3D 이동**. 미탐험 방의 적/보상/내용은 공개하지 않는다. 전투방은 카메라와 최대 네 명의 아군 및 적이 여유롭게 배치될 만큼 넓다.
- 모든 방에서 싸울 필요는 없지만 **전투방에 들어가면 전투가 시작**되며, 승리/성공적인 전투 도주/파티 전멸로 세션이 해결되기 전에는 방을 벗어나지 못한다. 도주 확률의 정확한 값은 미정.
- **클리어 판정은 탈출 방의 오브젝트에 상호작용한 뒤 실제로 던전을 나갈 때에만** 발생한다. 탈출 방에 먼저 도착해도 남은 방을 자유롭게 탐험 가능.
- 탈출 시 모든 던전 전투 적/그룹을 처치했다면 **올클리어 보너스**, 그렇지 않으면 일반 클리어. 보물방을 전부 찾거나 비전투 퍼즐을 모두 풀어야 올클리어인 것은 아니다.
- 전투/방 클리어·보물방·일반 클리어·올클리어 등 **층별 보상**을 제공한다. 던전 보상은 보석, 골드, 장비 제작 재료 등에 가치가 있어야 한다. 클리어/보상/전투 결과 UI를 보는 플레이어에게 적이 접근하거나 피해를 주지 않게 하되 월드 전체를 멈추지 않는다.
- 첫 완료 이전에는 적/전리품 재생성 없음. 실제 탈출 클리어 후 **1시간 재공략 쿨타임**을 거쳐 다음 공략에서 **최초와 같은 보상 기준**으로 리필된다. 반복 보상을 억지로 깎거나 하루 획득 상한을 만들지 않는다.
- 한 플레이어가 **같은 물리적 던전에서 세 번 파티 패배 시 해당 던전 30분 입장 금지**, 이 **30분은 온라인 접속 누적 시간**만 인정한다. 다른 던전에는 영향 없음. 만료 시 패배 횟수 0으로 초기화.
- 전투 시스템은 필드와 **동일한 일반 협동 턴제 시스템**. 던전만 별도 전투 규칙을 만들지 않는다.

**[공동 공략 확정]**
- 활성 팀원은 던전의 적 처치 및 방 진행도를 **공유**하고, 서로 다른 방에서 동시 전투 가능. 처치/방/클리어/올클리어의 게임 시스템 보상을 **누가 싸웠든 팀원 모두 같은 액수**로 받는다(분할 없음).
- 정상 탈출 시 **활성 탐험 팀원 전원이 탈출 방에 모여 함께** 나간다. 한 명만 탈출구를 눌러 부재중 팀원까지 강제로 끌고 나가지는 않는다.
- 동료가 **게임 접속을 종료**하면 남은 활성 인원으로 진행; 혼자 남으면 **싱글 공략**으로 계속.
- 동료가 **개인 세 번째 패배**를 하면 입장금지 상태는 유지하되 **다른 생존 팀원을 관전**한다. 관전자는 직접 던전에 다시 들어가거나 싸우지 않으며, **생존 팀원이 클리어하면 동일한 클리어·올클리어 보상 수령 가능**. 관전자는 탈출 방 집결 의무에서 제외한다.

**[미정/기술 설계 대기]** 정확한 월드 생성 밀도와 방 유형/보스 목록, 전투별·보상방별 수치, 1시간 쿨타임의 '오프라인 포함 현실 시간 vs 온라인 접속 시간' 여부, 탈출 장치의 디자인, 동료 전원 패배/관전 중 재접속/전원 이탈, 늦게 합류한 파티원과 실제 마인크래프트 보물상자·채굴 보상의 소유권, 공유 던전 리셋 타이밍. 상세 던전 보스/테마 기획은 **현재 보류**하고 메인 게임 루프로 돌아간다.

## 8. 우선순위: 이제 던전에서 메인 게임 기획으로 전환

1. **기본 플레이 흐름을 연결:** 스타터 선택 → 안전한 서바이벌 이동 → 자발적인 필드 몬스터와 턴제 전투 → 전리품/경험치 → 의뢰 및 보석 → 소환/성장/제작 → 새로운 선택과 다음 목표. 게임다운 반복 루프가 실제로 성립하는지 검토한다.
2. **전투 공통 경계:** 필드·던전에서 공유할 적 접근/참전/도주/패배/협동 규칙과 실제 플레이어 아바타 보호. 이미 확정된 게이지와 캐릭터 4인 전투를 재설계하지 않는다.
3. **초반 콘텐츠 최소 수직 단위 기획:** 스타터 ★3 선택지, 평화로운 자원 동물 및 적대적 몬스터의 대표 1계열, 첫 퀘스트/재료·보석 지급, 캐릭터 성장/무기 제작 연결을 서로 모순 없이 설계한다. 실제 캐릭터 정체성·수치는 협의 후 결정한다.
4. **성장/경제 접합:** 소환 비용/획득 시간, 스타 승급 재료·각성 조건, 대장간 레시피, 장비와 재료 드롭이 생존 채굴 및 전투와 연결되는지 결정한다.
5. 던전은 **이후 별도 구현 단계에서** 실제 카메라, 월드 생성, 멀티플레이, 제작 보상과 함께 다시 검토한다. 지금 던전의 방 개수·구체 테마·보스 이름·추가 난이도 체계를 확정하지 않는다.

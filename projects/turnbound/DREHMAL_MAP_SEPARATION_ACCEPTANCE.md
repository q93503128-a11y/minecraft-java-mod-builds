## 2. 실제 완료를 막는 남은 경계

1. **원작 명령 실행 경로:** 기존 검증상 전체 원작 함수 약 18,771개, 직접 함수 호출 명령 블록에서 Terminus 62개를 차단한 뒤에도 별도 함수 호출 명령 블록 **17개**와 각종 `setblock`/`clone`/`give`/`particle` 등 비함수 명령 블록이 남는다. 총 2,232개 명령 블록과 그동안의 지역 스캔 경고 737개를 모두 안전·불필요로 판정한 것은 아님. 단순 전체 삭제 금지.
2. **업적·보상:** 비무기 `reward.function` 181개 가운데 8단계 실험으로 **9개만 선택 차단**, 잔여 **172개**는 시설/스토리·게임 기능 의존성 확인이 필요. 원작 업적 보상 기능을 새 TURNBOUND 경제·성장·전투 로직에 재사용하지 않는다.
3. **예약 함수·저장 상태:** 원작 함수 중 명시적 예약 호출을 포함하는 함수 672개, scoreboard/objective 539개 및 command storage 12개가 원본에 확인됐다. 저장 예약 1개 차단은 검증했으나 서버 틱 동안 원작 일정이 다시 생성되지 않는다는 전체 증거는 없다. 원작 점수판/저장소를 무조건 지우면 건축물/퍼즐 동작을 파괴할 수 있다.
4. **핵심 구조물:** 특히 Av'Sal 터미널, Foundry 레버, Godmachine 버튼의 원작 callback이 `setblock`/순간이동/scoreboard 등에 정적으로 연결되어 있다. 실제로 누르고 이동·상태 변화를 확인하기 전까지 무단 비활성화 또는 기능 제거 금지.
5. **START와 탐험 동선:** 원본 시작 장치 57개를 비우는 것과 새로운 게임 진입 좌표를 확인하는 것은 다르다. CI 임시 좌표를 게임의 START로 승격하지 않는다. 서버 복귀/Adventure 모드와 마을·던전 진입 경로를 별도 사본에서 조사·검증한다.
6. **시각/플레이:** 실제 Minecraft 클라이언트의 문·퍼즐·포탈 조작, 리소스팩 대응, 4인/동시 사용자 안정성, 원작 진행/보상 재진입 차단 검증이 필요. GitHub 빌드 성공 또는 headless 봇 접속은 대체 불가.
7. **저작권:** 원작 지도 사본·리소스팩 및 원본 코드의 재배포/이식 권한은 별도 승인 대상. 현재 자동 검증은 다운로드한 원본을 runner에서만 소모하고 원본 바이너리를 게시하지 않는다.

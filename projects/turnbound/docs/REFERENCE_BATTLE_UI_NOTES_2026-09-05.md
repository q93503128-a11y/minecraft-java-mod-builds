# TURNBOUND Battle UI Reference Notes — 2026-09-05

이 문서는 문승준이 제공한 원본 게임 전투 스크린샷 2장을 TURNBOUND 전투 UI/카메라 개선에 사용할 때의 작업 메모다.

`docs/QUALITY_STANDARD.md`의 원칙에 따라 특정 게임의 아트 자산을 복사하는 문서가 아니라, **정보 구조·시각 계층·상호작용·카메라 구도**를 분리하여 참고한다.

## 1. 가장 중요한 관찰

- 전투의 주인공은 HUD가 아니라 3D 캐릭터와 전장이다.
- 파티 상태는 화면 하단 가장자리에 얇게 붙는다.
- 적 HP/이름은 대상 근처 월드 공간에 붙어서 눈이 화면 구석과 전장을 왕복하지 않게 한다.
- 현재 행동은 우측 하단 한 곳에서 처리한다.
- 선택 가능한 행동은 세로 목록으로 빠르게 훑을 수 있다.
- 타겟 선택은 대상 위의 크고 즉시 알아볼 수 있는 표식으로 전달한다.
- 자동/도주 같은 보조 조작은 핵심 스킬보다 시각적으로 한 단계 낮다.
- 카메라는 높은 3/4 시점이지만 완전 탑다운은 아니며, 아군과 적군이 동시에 들어오도록 대각선으로 전장을 잡는다.
- 캐릭터는 너무 작아지지 않는다. UI를 줄이는 목적은 전장을 더 크게 보여주기 위함이다.

## 2. TURNBOUND에 적용할 원칙

### 유지

- TURNBOUND 고유 Turn Gauge/행동 순서는 전투 핵심이므로 삭제하지 않는다.
- 단, 상단 중앙의 얇은 보조 스트립으로 제한한다.
- 1x/2x, 자동, 도주는 유지하되 우선순위를 낮춘다.
- 마우스 타겟 선택 + 키보드 1~5/Tab/Enter를 모두 유지한다.

### 수정

- 스킬은 우측 하단 세로 1열.
- 활성 스킬은 어두운 중립 바탕, 현재 선택만 녹색 계열의 강한 상태색을 사용한다.
- 쿨다운은 버튼 전체를 장식하지 않고 작은 수치 칩으로 표시한다.
- 파티 HP는 하단 얇은 스트립.
- 적 HP는 월드 투영 오버레이.
- 전투 카메라 기본값만으로 양측 진형이 읽혀야 한다. 드래그/휠은 보정 수단이다.

## 3. 피할 것

- 검은 반투명 카드 4~5개를 전장 위에 쌓기.
- 스킬을 2열 카드 그리드로 만들기.
- 화면 오른쪽 전체를 패널로 막기.
- 적 정보를 우측 상단 별도 목록으로 중복 표시하기.
- 선택 표식, 서버 월드 표식, HUD 표식을 겹쳐 같은 정보를 여러 번 표시하기.
- 카메라가 너무 높아져 캐릭터가 작은 보드게임 말처럼 보이게 하기.
- 카메라 흔들림을 매 프레임 좌우 반전시키는 식의 거친 진동.

## 4. 현재 개선 배치의 체크 포인트

- 16:9 기준 스킬 도크가 화면 폭 약 15~18% 이내인가.
- 파티 상태가 전장 높이를 거의 침범하지 않는가.
- 선택 상태가 색상만이 아니라 밝기/윤곽/레이아웃으로도 구분되는가.
- 비활성/쿨다운 스킬이 사용 가능 스킬과 즉시 구별되는가.
- 기본 카메라에서 아군 4 + 적 5 최대 구성도 프레임 안에 들어오는가.
- 줌이 순간이동하듯 바뀌지 않고 부드럽게 수렴하는가.
- 피격 카메라 흔들림이 정보 판독을 방해하지 않는가.

실제 Minecraft 테스트 스크린샷을 받은 뒤 이 메모와 원본 레퍼런스를 나란히 놓고 다시 조정한다.

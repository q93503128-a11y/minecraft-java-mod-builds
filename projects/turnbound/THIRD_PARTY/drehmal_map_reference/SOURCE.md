# DrehmalMap reference source

Reference-only spatial data for TURNBOUND route zoning and candidate X/Z placement.

- Repository: https://github.com/zachaa/DrehmalMap
- Reviewed revision: `72d82180cbe3f950f068cf2d8e8668c6b09d5c58`
- Referenced: `data/paths.geojson`, `data/locations.json`, `data/towers.json`

TURNBOUND uses this only to understand road/POI topology and to author a small set of coordinate seeds.
No map tiles, screenshots, world blocks, or source assets are bundled.

No explicit repository-wide license was identified during this integration pass, so this source is treated as
**reference / unknown-license**, not a directly reusable asset.

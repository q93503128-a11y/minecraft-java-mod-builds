# TURNBOUND Southgate Chapter 1 Delta — alpha.11

상태: alpha.10 Production Gate의 P2 첫 실제 콘텐츠 묶음.

## 1. 이번 버전의 목적
P0/초기 A01 검증용 한 파티를 반복하는 대신, 한 필드 셀 안에서라도
`NPC → 가시적 적 조우 여러 개 → 전투 → 보상 → 진행도 → 보스 해금 → Chapter 1 클리어`
루프가 실제로 이어지는지 검증한다.

기존 정본에서 확정된 원칙은 유지한다.
- 랜덤 인카운터가 아니라 필드에 보이는 적 파티와 접촉
- PATROL → ALERT → ENGAGE
- 전투 후 정확한 필드 위치 복귀
- 플레이어 shell은 생존 전투원이 아님
- 전투 참여 4인은 같은 전투 보상 XP를 받는 구조를 P3 성장 시스템에서 연결
- 실제 경제 보상량은 이후 경제 테스트에서 재조정 가능

## 4. 퀘스트/보상/진행
A01 입구에 `남문 정찰관` 임시 NPC를 배치한다.
NPC 우클릭 또는 `/turnbound status`로 현재 Chapter 1 진행을 확인한다.

진행 단계:
1. 적 무리 정리 0/5
2. ENC_M01~M05 최초 승리
3. B01 그라울 해금
4. 그라울 승리
5. Chapter 1 클리어 / 남문 봉쇄 해제

이번 버전의 XP/Gold 수치는 경제 정본이 아니라 플레이 루프 검증용 tuning 값이다.
동일 조우의 중복 보상은 발생하지 않는다.
P3 saveSchemaVersion 4에서 이 진행/재화/XP를 영속 성장 데이터에 연결한다.

## 5. 필드 배치
A01 64×64 셀 안에 다섯 파티를 서로 다른 길/수로/다리/봉쇄선 동선에 배치한다.
목적은 모든 적을 일렬로 강제하는 것이 아니라, 보이는 적을 피하거나 다른 쪽부터 처리하는 선택을 만드는 것이다.

## 6. 합격 기준
- `/turnbound field` 진입 시 5개 일반 적 파티가 서로 다른 위치에 보임
- 적마다 순찰/경계/추적/접촉 전투가 독립적으로 동작
- 각 조우의 실제 전투 구성과 필드 구성 일치
- 승리한 조우는 현재 세션에서 제거
- 도주/패배는 유예 후 해당 조우만 복귀
- 5/5 후 B01 출현
- B01 승리 후 Chapter 1 완료 상태
- NPC/`/turnbound status`가 현재 진행/누적 보상 표시
- 기존 직접 3D 타겟, 명시적 확정, hover 툴팁, 전장 카메라 회귀 없음

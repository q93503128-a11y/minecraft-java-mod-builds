# TURNBOUND Battle Presentation Delta — alpha.5

상태: `01_세부기획서_v0.4.md` / `02_수치규칙위키_v0.4.md` / `03_캐릭터설계위키_v0.4.md`의 전투 UI·카메라 항목을 실제 P0 테스트와 2026-08-29 사용자 제공 R_PG 전투 스크린샷을 기준으로 구체화하는 개발 정본 델타.

이 문서는 전체 기획을 다시 쓰지 않는다. 아래 항목만 v0.4의 추상적인 UI 배치를 더 구체적인 구현 규칙으로 좁힌다. 수치·캐릭터·턴 규칙은 v0.4를 그대로 유지한다.

## 1. 직접 테스트에서 폐기된 alpha.4 패턴

다음 패턴은 사용하지 않는다.

- 좌우에 아군/적 전체를 거대한 버튼 카드로 배치
- 화면 중앙 3D 전투 공간을 좁은 세로 틈으로 축소
- 전체 화면을 어둡게 덮는 전투 GUI
- 늘린 프레임 텍스처가 대부분의 화면 면적을 차지
- 내부 combatant ID / TURN_READY / pulse 같은 디버그 문자열 노출
- 전투 참가자 머리 위 바닐라식 커스텀 이름표 상시 노출

## 2. R_PG에서 확인한 정보 구조

사용자 제공 실제 플레이 스크린샷에서 확인한 핵심은 특정 색/텍스처가 아니라 정보 구조다.

- 3D 전투 월드가 화면 대부분을 차지한다.
- 아군 파티 정보는 화면 하단 가장자리에 얇게 분산된다.
- 적 전체 상태는 상단/상단 우측에서 빠르게 훑을 수 있다.
- 현재 선택 가능한 행동만 우측에 문맥적으로 나타난다.
- 선택 대상은 3D 모델 위치와 직접 연결되는 강한 월드 마커로 구분한다.
- Auto/도주는 우하단의 작은 보조 제어다.
- 카메라는 전투 장면을 자유롭게 읽을 수 있는 3인칭 오버뷰이며 UI가 카메라 움직임을 방해하지 않는다.

R_PG의 UI 자산, 아이콘, 색상, 텍스처, 코드, 정확한 레이아웃 수치는 복제하지 않는다.

## 3. TURNBOUND alpha.5 전투 HUD 정본

### 3.1 장면 우선순위

- 기본 상태에서 화면의 주인공은 항상 3D 전투 장면이다.
- 중앙을 막는 상시 대형 패널 금지.
- 전투 HUD는 가장자리와 작은 문맥 패널만 사용한다.
- 전투 화면 전체에 반투명 검정 veil을 깔지 않는다.

### 3.2 아군 HUD

- 기본 위치: 하단 party strip.
- 최대 4명을 한 줄로 배치하고 작은 logical viewport에서는 2×2로 접는다.
- 각 항목: 이름 / HP / 보호막 / 전투불능 / 현재 행동자 강조.
- v0.4의 ‘좌측 초상화’는 최종 portrait 자산이 준비될 때 선택적으로 다시 합칠 수 있으나, P0에서는 3D 장면 면적을 우선해 하단 strip을 정본으로 한다.

### 3.3 적 HUD

- 상단 우측 compact summary.
- 최대 5명을 2~3열 grid로 표시.
- 이름 / HP / 보호막 / 전투불능.
- 선택된 적과 현재 행동 적만 accent를 강하게 표시.
- 거대한 우측 적 목록 패널을 만들지 않는다.

### 3.4 행동 UI

- 플레이어 캐릭터가 행동 가능한 때에만 우측 소형 action panel을 표시.
- Basic/Active를 실제 보유 개수만큼 노출, 최대 5 슬롯.
- 쿨타임은 버튼 안에 짧게 표시.
- 단일 타겟 기술을 누르면 동일 위치에서 `타겟을 선택하십시오` 상태로 전환하고, HUD/월드 마커로 대상을 지정한다.
- 적 행동 중 또는 Auto 중에는 스킬 패널을 숨겨 3D 장면을 더 보여준다.

### 3.5 타겟 Presentation

- 선택 타겟은 3D 위치 위에 명확한 하향 화살표를 표시한다.
- HUD 선택 강조와 월드 마커는 같은 target ID를 가리켜야 한다.
- Tab/Shift+Tab은 무효/전투불능 대상을 건너뛴다.
- 향후 실제 모델 renderer가 들어오면 outline/바닥 ring을 추가한다.

### 3.6 상단 타임라인

- 최대 8개 예측 슬롯.
- 작은 토큰 형태로 유지.
- 현재 행동자는 별도 강조.
- 게임 제목이나 긴 조작 안내와 겹치지 않는다.

## 4. 입력 / 카메라

v0.4 §38.6을 다시 정본으로 사용한다.

- LMB: UI/타겟 선택
- RMB: 현재 스킬/타겟 선택 취소
- Mouse Drag: 빈 전투 장면에서 orbit
- Wheel: zoom
- 1~5: 행동 슬롯
- Tab / Shift+Tab: 타겟 순환
- A: Auto
- X: 1.0x / 2.0x
- R: 일반전 확정 도주
- Esc: 전투 설정 overlay

P0 카메라:

- Battle 진입 시 3인칭 후방 오버뷰로 전환.
- 기본 distance 11.
- zoom clamp 6~18.
- pitch clamp -10°~58°.
- drag 감도는 v0.4 수치 위키 값을 사용한다.
- 전투 종료 시 진입 전 카메라 타입/yaw/pitch를 복구한다.

## 5. 도주

alpha.4에서 잘못 들어간 ‘전투 중 도주 없음’ 규칙은 폐기한다.

P0 일반 전투는 v0.4 정본대로 R 또는 도주 버튼으로 확정 종료 가능하다.
보스/이벤트의 도주 불가 플래그는 encounter 데이터 단계에서 추가한다.

## 6. P0 임시 모델 경계

ArmorStand는 여전히 최종 캐릭터가 아니다.
alpha.5에서는:

- 상시 커스텀 이름표를 숨긴다.
- formation을 아군 4 / 적 5가 화면에서 명확히 분리되도록 넓힌다.
- 역할을 구분할 최소 장비 실루엣만 준다.
- 실제 영웅 모델/애니메이션은 GeckoLib 캐릭터 단계에서 교체한다.

이 임시 표현 때문에 최종 UI/카메라 구조를 다시 ArmorStand 중심으로 설계하지 않는다.

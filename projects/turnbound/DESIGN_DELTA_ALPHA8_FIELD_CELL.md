# TURNBOUND Field / Encounter Delta — alpha.8

상태: `01_세부기획서_v0.4.md`의 Aster March / Southgate Meadow / 필드 플레이 / 가시적 적 조우 명세를 alpha.7 전투 코어에 연결하는 첫 P2 구현 정본.

## 1. 범위

전체 1024×1024 Aster March를 한 번에 만들지 않는다.

이번 버전은 **Southgate Meadow의 64×64 한 셀(A01)만** 만든다.

- Aster March 정본 좌표: X/Z `-512..511`
- Southgate Meadow 정본 범위: X `-80..430`, Z `120..360`
- A01: X `-32..31`, Z `128..191`
- 기준 지표면: Y `64`
- Radia의 계획된 남쪽 경계 Z 128 바로 바깥에서 시작

목적은 `필드 이동 → 보이는 적 발견 → 회피/접근 → 경계/추적 → 조우 → 3D 턴제 전투 → 원래 필드 복귀`를 한 덩어리로 검증하는 것이다.

## 2. A01 공간 구성

빈 평지/테스트 박스가 아니라 첫 남문 초원 셀처럼 읽히게 한다.

- 북쪽(Radia 쪽) 진입 게이트 잔해
- +Z 방향으로 굽는 주도로
- 서쪽 관개 수로와 작은 보행 다리
- 중앙~남부의 넓은 조우/전투 공터
- Relay 계열 파손 석벽 landmark
- 양옆 숲/석재 경계
- 아직 만들지 않은 다음 Southgate 셀 방향을 무너진 길로 봉쇄

노골적인 world border는 사용하지 않는다.

## 3. 조우 방식

랜덤 인카운터를 기본으로 사용하지 않는다.

A01에는 실제로 보이는 적 파티가 존재한다.

첫 파티는 v0.4 정본의 실제 Southgate 적:
- E001 부패 보행자
- E002 뼈 사수
- E005 야전 치유사

필드 상태:
1. `PATROL` — 지정 구간 왕복
2. `ALERT` — 플레이어가 경계 반경에 들어오면 추적
3. `ENGAGE` — 접촉 반경에서 전투 세션으로 전환

플레이어가 충분히 떨어지면 ALERT에서 PATROL로 돌아가므로, 적을 보고 피해 가는 필드 플레이도 가능하다.

## 4. 필드 파티와 전투 파티의 동일성

보이는 적과 전투 데이터를 분리해 가짜 연출로 만들지 않는다.

A01 전투는 같은 E001/E002/E005 EnemyDefinition을 사용한다.

- E001: HP 720 / ATK 92 / DEF 68 / SPD 82 / `썩은 주먹` 1.00x / `끈질김` 최초 30% 이하 Barrier 10%
- E002: HP 560 / ATK 100 / DEF 54 / SPD 105 / `뼈 화살` 0.95x / `조준 사격` 1.45x CD2
- E005: HP 590 / ATK 82 / DEF 60 / SPD 94 / `응급 봉합` 0.55x Heal / `전열 정비` 적군 전체 DEF +15% 2행동 CD3

필드 ArmorStand는 임시 시각 stand-in일 뿐, 전투 수치/스킬은 훈련용 가짜 적으로 대체하지 않는다.

## 5. 전투 연결

ENGAGE 시 alpha.7 안전 전장 탐색을 그대로 사용한다.

- 접촉 직전 필드 위치/yaw/pitch 저장
- 인접 안전 전투 공간 탐색
- player shell을 전투 지휘자 상태로 전환
- 4인 아군 vs E001/E002/E005
- 승패/도주 후 정확한 필드 위치로 복귀

승리:
- 현재 A01 필드 세션에서 순찰대 제거

패배/도주:
- 짧은 재조우 유예
- 순찰대 원위치 복원

## 6. 필드 규칙

가능:
- 걷기/달리기
- 점프
- 길/다리/공터 탐험
- 적 회피
- 적에게 접근해 추적/조우 유도

이번 셀에서 차단:
- 블록 파괴
- 블록 설치
- 바닐라 아이템 사용을 통한 생존 진행
- 바닐라 근접 공격으로 필드 적 직접 처치

NPC/상점/퀘스트/보물상자는 A01 첫 검증 범위에 억지로 넣지 않는다. 먼저 이동과 조우 밀도를 검증한다.

## 7. Presentation 경계

E001/E002/E005의 최종 시각 정본은 수치 위키의 별도 모델/애니메이션 명세다.

alpha.8의 ArmorStand는 다음 구조 검증 전용이다.
- 적이 필드에 실제로 보이는가
- 순찰/경계/추적이 조우 감각을 만드는가
- 적을 피해 갈 수 있는가
- 조우가 전투로 자연스럽게 이어지는가
- 전투 후 필드 상태가 맞게 복원되는가
- 64×64 한 셀의 이동 밀도가 적절한가

이 검증 뒤 실제 GeckoLib 모델/field_walk/field_idle 및 후속 Southgate 셀을 붙인다.

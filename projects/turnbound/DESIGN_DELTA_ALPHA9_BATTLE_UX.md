# TURNBOUND Battle UX Delta — alpha.9

상태: `01_세부기획서_v0.4.md`의 전투 카메라/직접 타겟/전투 UI 원칙과 alpha.8 실제 플레이 피드백을 합쳐 고정하는 구현 델타.

## 1. 카메라
- orbit 기준점은 Minecraft Player 엔티티의 임의 시점이 아니라 **현재 전투 참여자 anchor들의 평균 위치**다.
- 기본 카메라는 전투원 전체가 한 장면에 들어오는 중거리 3인칭 시점으로 시작한다.
- 기본 Pitch를 낮춰 위에서 찍는 감시 카메라처럼 보이지 않게 한다.
- LMB 드래그 orbit은 입력 직후 반응하고 짧은 보간만 사용한다.
- 카메라 렌더 각도와 실제 3인칭 카메라 위치 계산에 쓰이는 Player shell 회전을 동기화한다. 둘을 따로 돌리지 않는다.
- 권장 범위는 수치 위키 v0.4의 거리 6~16 blocks, Pitch -15~+60도를 따른다.

## 2. 직접 타겟 선택
- 단일 대상 스킬을 고른 직후 첫 유효 대상을 자동 확정하지 않는다.
- `스킬 선택 → 실제 3D 캐릭터 클릭 또는 Tab → 타겟 강조 → 사용 확정` 순서를 기본으로 한다.
- 3D 클릭 판정은 캐릭터 중심 한 점이 아니라 발~머리의 화면상 capsule 영역을 사용한다.
- HUD 상태바 클릭과 Tab/Shift+Tab은 접근성/보조 입력으로 유지한다.
- 선택된 대상은 월드 `▼` 마커와 HUD 강조가 동시에 갱신되어야 한다.

## 3. 스킬 UI
- 화면 우측의 세로형 긴 메뉴를 축소하고 **2열 action dock**을 기본으로 한다.
- 표준 화면에서 스킬 버튼은 수치 위키의 권장 클릭 크기(56~72 logical px에 가까운 footprint)를 확보한다.
- Basic 1 + Active 1~4의 동적 2~5개 버튼만 노출한다.
- 행동 선택 헤더/확정 버튼/AUTO/배속/도주는 서로 겹치지 않는다.
- 전투 장면 중앙을 가리는 패널을 추가하지 않는다.

## 4. Hover 상세 설명
모든 플레이어 스킬 버튼은 hover 시 상세 설명을 표시한다.

필수 정보:
- 스킬명
- 대상 타입
- 기본 쿨타임
- 현재 남은 쿨타임
- 실제 효과를 설명하는 문장/수치

툴팁은 버튼 왼쪽 또는 빈 영역에 뜨고 전투원/타겟을 과도하게 가리지 않는다.

## 5. 행동 커밋
- 모든 스킬은 첫 클릭으로 발동하지 않는다.
- SELF / ALLY_ALL / ENEMY_ALL도 `스킬 선택 → 사용 확정`을 유지한다.
- 단일 대상은 유효 대상 선택 전까지 확정 버튼이 비활성이다.
- 최종 확정 전 Gauge/CD/논리 전투시간을 변경하지 않는다.

## 6. 이후 제작 방향
alpha.9에서 P0/P1 입력·카메라·UI 불편을 고정한 뒤 P2~P4를 기획서 순서대로 확장한다.

1. P2: Southgate Meadow 확장, NPC, 퀘스트, 보상, 지역 이동, B01
2. P3: 캐릭터 보유/레벨/성급/파티 UI/가챠/장비/골드 강화/CP
3. P4: ★6 각성, 전용 장비, 보스/스토리/지역/캐릭터/고난도 반복 콘텐츠

각 단계는 기존 전투 규칙 정본을 깨뜨리지 않고 데이터 주도 구조로 추가한다.

CI에서 두 가상 플레이어를 원작 시작 장치 주변의 **검증용 좌표**로 이동시킨 뒤 2초가 지났을 때, **7단계와 8단계가 동일하게 첫 플레이어의 위치가 `(+62,-46,+201)` 블록 바뀌었다.** 원래 CI 요청 위치 바로 아래 블록은 `minecraft:air`이었다.

- **단순 중력 낙하만으로 X +62, Z +201 이동을 설명할 수 없다.** 포탈/명령/플레이어 조작/기존 스폰 이동 등 실제 원인은 이번 실험에서 구분하지 못했다.

- 이 좌표를 실제 TURNBOUND START 또는 패배 복귀 위치로 지정하지 않는다. 다음 시험에서 이동 전후 차원·정확한 관측 타임라인·서버 로그 내부 이벤트/기기 및 주변 지형과 포탈/명령 블록 위치 관계를 분리 확인한다. 원작 지도와 플레이어 개인 데이터를 퍼블리시하지 않는다.
